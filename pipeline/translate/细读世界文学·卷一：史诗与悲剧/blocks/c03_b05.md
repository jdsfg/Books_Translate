#### 结构提示

**Q2.** 格劳科斯观点的最小化版本不过就是：“人会死，别人会出生。”荷马却给了我们整整四行关于青春、枯萎、春天、相继兴衰的内容。这些“额外”的行完成了最小版本无法完成的什么？（这就是史诗明喻的“延伸”。）

提示

想想时间与尺度。最小版本覆盖多长时间？扩展版本让你感受到多长时间？扩展版本把你带到了哪里，当你回到战场时，你带回了什么？

**答案：** 额外的行让喻体变成一个我们置身其中的场景，而不仅仅是一个我们登记在册的观点。通过让森林经历完整的季节循环，荷马把诗的时间尺度从单个致命的下午拓宽到岁月与世代无尽轮转，并把我们提升到包含战斗却不在意战斗的辽阔、耐心而冷漠的自然秩序中。然后他带我们回到战斗，而我们此刻带着这巨大背景来观看它。最小版本提供信息；扩展版本提供一种**尺度的体验**——突然的拉远与拉近，这正是《伊利亚特》的情感引擎。有力的回答会把这种拓宽与收窄命名为“延伸”的具体效果。


#### 译本比较提示

**Q3.** 比较 Pope 的 “They fall successive, and successive rise” 与 Butler 的 “the new spring up as the old are passing away”。哪个版本倾向慰藉，哪个倾向失去？指出具体哪些词造成这种效果。

**答案：** Pope 倾向慰藉。他的行押韵、均衡，重复的 “successive … successive” 上演了一个平稳、令人安心的循环，一个不断转动的车轮；音乐本身就抚慰人。Butler 倾向失去。“The old are passing away” 是一个 dying fall，平实、无音乐性，没有押韵来缝合伤口，所以我们听到的更多是消逝而非更新。线索在于分句的平衡：Pope 给落下与升起以同等、呼应的重量（“fall … rise”），而 Butler 把新生从属于消逝，句子以死亡作结。有力的回答不会说哪个“更好”，而是把每一个都说成是对同一希腊文本的可辩护阅读：Pope 听见了循环的安慰，Butler 听见了循环的悲伤，而两者确实都在荷马之中。
