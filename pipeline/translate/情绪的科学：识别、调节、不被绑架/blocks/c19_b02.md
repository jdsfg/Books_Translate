### 此卡未覆盖的情绪

上面十二种是本书的主要集合。有几种重要的情绪被命名但未设专章：**希望**、**悲悯**、**惊讶**、**自豪**、**尴尬**、**内疚**（与羞耻区分）、**惊奇**与**崇敬**（作为敬畏的近亲），以及两种十二种情绪的**混合状态**（嫉妒+轻蔑、羞耻+愤怒、感恩+悲伤）。框架可迁移：每种都包含身体状态、概念和情境，都可被同样六个动作处理。对其中某种未被覆盖情绪居于中心的读者，可直接应用框架，并辅以附录 C 的原始来源。


### 贯穿十二种情绪的五个教训

1. 情绪是建构的（身体状态 + 概念 + 情境），不是给定的。
2. 颗粒度是最可行动的单项干预。
3. 行动冲动不是行动；间隔是技能所在。
4. 元情绪常常做了大部分工作。
5. 架构塑造一切。


### 格罗斯情绪调节五大家族

1. 情境选择（进入哪些情境）
2. 情境修正（进入后改变特征）
3. 注意分配（看向哪里）
4. 认知改变（重评）
5. 反应调整（情绪产生后）

较早的干预通常更有效；五种各有其位。


### 紧急序列（不堪重负时）

1. 暂停。做三次缓慢呼气。
2. 身体。我在哪里感受到它？它在做什么？
3. 标注。最精确的词是什么？
4. 冲动。这种情绪想让我做什么？具体命名它。
5. 选择。鉴于这股冲动，什么行动符合我的价值观？
6. 架构（稍后）。什么加载了身体状态？睡眠、饮食、接触、时间。


### 何时寻求帮助

若以下任何一项持续两周或以上，考虑专业评估：

* 持续低落情绪，即使短暂也不缓解
* 对通常带来快乐的事物失去兴趣
* 显著睡眠紊乱或食欲改变
* 影响工作的注意力困难
* 无望感或自伤想法
* 严重焦虑干扰日常功能
* 浮现出练习无法容纳的创伤材料
* 物质使用已成为应对策略并滑向依赖
* 严重关系困难（虐待、持续慢性轻蔑、信任崩塌）
