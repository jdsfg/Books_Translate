#### 概念检测

**Q1.** 从身体状态、概念和时间方向三个维度定义焦虑，并在每个维度上与恐惧对比。

提示

本章明确命名了这种对比。

**答案：** _焦虑_：交感神经激活的身体状态；弥散、常常未指定的威胁概念；时间方向指向未来。威胁不在眼前；行动冲动没有当下目标；认知活动倾向于循环。_恐惧_：交感神经激活的身体状态（与焦虑相似）；具体、可识别的威胁概念；时间方向指向当下。威胁在此地；行动冲动有清楚目标（逃跑、僵住、战斗、讨好）；认知活动短，指向即时反应。相同身体状态，不同概念，不同时间方向，不同行动冲动，不同失败模式。身体状态重叠是读者有时混淆两者的原因；概念和时间差异是它们需要不同调节策略的原因。

**Q2.** 解释 Wegner 压抑的悖论效应，以及它对"别想了"这种建议意味着什么。

提示

看白熊研究和监控机制。

**答案：** Wegner 的白熊研究：被告知不要想白熊的参与者在压抑期想到白熊更多，释放后还有反弹。机制是：试图压抑一个想法需要大脑监控压抑是否成功，而监控让被压抑内容在注意中保持活跃。含义："别担心它"这个标准建议平均会产生更多担忧。建议失败不是因为听者缺乏意志力，而是因为它要求的认知操作产生与意图相反的结果。更好的建议是：用接纳（"让担忧存在，继续做你正在做的事"）、重定向（"注意到担忧，然后把注意带到具体当下任务"），或计划性安排（"把担忧推迟到指定窗口"）来替代压抑。这些方法减少了压抑创造的监控负荷。

**Q3.** 什么是焦虑的身体状态重评？为什么有时有效？

提示

回想第1章的建构观。

**答案：** 焦虑的身体状态重评把身体感觉重新贴标签为表演准备，而不是对威胁的反应。同样感觉（心跳快、呼吸急促、注意收窄、能量）被重新解读为身体在为重要时刻做准备，大脑建构的情绪也随之改变。当这种重评确实适合两种读法时最有效：身体状态是高唤醒为事件做准备，情境是表演导向而非明确威胁。第1章的建构观解释了它为何有效：情绪由身体状态 + 概念 + 情境组装而成；如果你改变概念，且身体状态能支持这种改变，情绪就会改变。重评不会抹去激活；它给激活不同意义，而意义很大程度上决定了体验的不适。实验工作（Crum、Jamieson）中效应小但可靠，且可泛化到许多表演情境：演讲、面试、表演、困难对话。
