#### 应用题

**Q1.** 一位朋友刚经历痛苦的分手，告诉你他们“没事”。你注意到他们没睡好、对同事易怒、上周看了一部通常不会让他们落泪的电影却哭了。用建构观提出三种关于发生了什么的假设，并提出一个可以帮助你区分这些假设的观察。

提示

建构观说情绪 = 身体状态 + 概念 + 情境。这三种原料都可能出问题。

**答案：** 三种假设，分别对应哪一种原料受限。（1）_身体状态被误标_：朋友处于慢性激活状态（睡眠不足、应激激素升高、容易发火），却把这些感觉解释为普通疲惫，而没有贴上“悲伤”的标签。概念“我很伤心”没有被应用到现有的身体状态上。（2）_概念缺失_：朋友有身体状态，也意识到有些不对，但缺乏足够的颗粒度来精确命名。他们只感到“糟”或“不对劲”，标签太钝，导致体验无法被处理。（3）_概念被压抑_：朋友有身体状态和概念，但主动回避“我正在哀伤”这个标签，因为这个标签会带来他们不想面对的后果：必须谈论它、在别人面前哭泣、如果命名就会更尖锐地感受它。一个能帮助区分的观察：当你温和地问“你此刻身体里是什么感觉？”他们是给出身体描述（支持假设 1），含糊地说“我不知道，就是糟”（支持假设 2），还是快速转移话题（支持假设 3）？每种假设对应不同的下一步：第一种是休息与架构调整，第二种是词汇工作，第三种是在不强迫贴标签的情况下温和见证。建构观把“他们在否认”变成了更有用的东西：哪一种原料卡住了？

**Q2.** 一位同事在谈及最近的人员变动时用了“情绪触发因素（emotional triggers）”这个说法。用两句话把它翻译成建构观，再用两句话解释为什么这个翻译对你给出的实用建议很重要。

提示

“触发”是一个刺激-反应词。建构观拒绝这个框架。

**答案：** _翻译_：人员变动并不是在触发一个固定情绪反应；它被同事的大脑根据他们今天所处的身体状态、在公司多年的经历以及当下情境，解读为某个特定概念（也许是“背叛”或“失去地位”）的实例。不同的概念和身体状态会从同一个事件中产生不同的情绪。_为什么重要_：如果你把变动当作“触发因素”，你仅有的选择就是移除触发或教同事“管理”情绪。如果你把变动视为建构过程的输入，你就可以问：哪个概念在做主要工作？这个概念准确吗？什么情境会让另一个概念更容易被调用？同事的身体状态——睡眠、工作量、近期会议——正在塑造哪个概念被优先调取。建构观扩大了杠杆点；触发观把所有杠杆都坍缩到事件本身。
