#### 概念检测

**Q1.** 用一句话陈述宣泄假说，再用两句话陈述反驳它的实验发现。

提示

假说是关于压力释放；发现是关于演练。

**答案：** _宣泄假说_：愤怒像压力一样在人体内积累，必须通过表达（大喊、击打、倾诉）释放，否则会病态渗漏。_反驳发现_：在 Bushman 系列实验中，边想侮辱自己的人边打沙袋的参与者，事后表现出的攻击性比安静坐着的参与者更强，而不是更弱。所谓的“释放”活动并没有释放愤怒；它以挑衅者为目标演练了攻击反应，而演练让下一次攻击行为更可能发生。

**Q2.** 为什么愤怒的身体状态几乎与恐惧、剧烈运动和突然惊吓的身体状态相同？这对愤怒如何建构有何启示？

提示

用建构观：身体状态 + 概念 + 情境。

**答案：** 这四种状态都涉及交感神经激活：心率与血压升高、血液重新分配向大肌肉、肾上腺素释放、瞳孔放大、注意范围收窄。身体状态是通用的行动准备状态。某一实例之所以是愤怒而非恐惧、激动或惊吓，取决于大脑在同时调用的概念。当身体状态与……结合“我被一个能动者冤枉”的概念时，产生愤怒；与“我面对具体威胁”结合时，产生恐惧；与“我想要的东西即将发生”结合时，产生兴奋。这正是建构观：身体提供能量，概念提供意义。同样的能量，根据匹配的概念可以变成几种不同情绪。

**Q3.** 区分沮丧、愤慨、怨恨和恼火，并各给一例。

提示

每一种都是愤怒加上不同的附加元素。

**答案：** _沮丧_ 是目标被阻时的恼怒，对象常是非人或情境，而非个人。例：提交表格时网站一直卡死。_愤慨_ 是目睹道德侵犯时的愤怒，尤其不是亲自受害，而是见证不公。例：读到一家公司系统性地欺诈顾客。_怨恨_ 是因未解决的委屈而对某人持续存在的低度愤怒。例：对两年前抢了你功劳的同事仍怀有隐隐敌意。_恼火_ 是愤怒混着疲惫，通常在同一问题反复出现后出现。例：孩子本周第三次打翻果汁；你感到的愤怒不是新鲜的，而是疲惫的。
