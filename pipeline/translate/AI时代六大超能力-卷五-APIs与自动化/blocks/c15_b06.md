### 本章小结

最后一个星期一，站在 Mara 的工作室里，我们看见她的杂务并不是被一个单独工具替代，而是被一小片**领地**替代；我们也把它穿过本系列全部五张工具地图追踪了一遍，看见的是一次能够工作的合流，而不是一串高光回放。它的**四肢是 API 调用**（第五卷）：它对世界做的每一件事，都是通过柜台窗口完成的，读取带标签盒子，尊重诚实的“不”，并由自己的**日记**记录每一次运行。它的**配方住在带历史的 repo 里**（第一卷），在那里它可以被演进、被找回，而密钥绝不能进去。一个**私有本地模型可以成为它的一名工人**（第二卷），处理那些触及敏感个人数据的部分。它**运行在终端的世界里**（第三卷），也就是文件、进程和定时任务的世界。而它永远在线的部分，急单委托门铃，**住在服务器上**（第四卷），每一个小时都醒着，接收响铃。拿走任何一张地图，一个具体能力就会消失；五者不是并排摆着的技能，而是因为全都在场，才共同组成一个能工作的东西。

这次合流之所以配得上压顶石的位置，是因为它让 Mara _更有能力_，而不是更惊叹：她现在能巡视任何新服务，判断是否要把它接进来，安放它，约束它，再把它折进自己已经掌握的领地；因为五张地图已经咔哒合成一张，而一片你读得懂的景观，就是一片你能延展的景观。我们也为贯穿整个工具弧线的**勇气之梯**命了名：从“自动化是工程师的事”，走到“我看得见管道，我能委托新的管道，而且我知道该检查什么”；这段攀爬倚靠每一卷，而不只是本卷。本章收拢了本书的每一条线。剩下一项任务：用白话收集那些能让你指挥整片领地的词语，也就是第 15 章的地图集。
