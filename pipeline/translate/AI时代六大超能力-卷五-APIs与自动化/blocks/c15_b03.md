五张地图，五件工作：伸出去的 API 四肢，负责记忆的 repo，可以在屋内工作的私有模型，它运行其上的终端世界，以及服务器永远敞开的耳朵。拿走任何一张地图，一个具体能力就会消失：没有 repo，她就无法安全演进或找回管道；没有本地模型选项，私密起草就必须离开房间；没有终端的世界，她就无法看着它运行，也无法把它放上日程；没有服务器，她就无法在凌晨 3 点被响铃叫醒；没有柜台窗口，根本就没有四肢。这不是五项技能并排坐着。它是一个东西之所以能工作，是因为五者都在场，而且各自不可替代。


### 14.3 为什么合流让她更有能力

很容易在这里用一段漂亮话收尾，说 Mara 已经走了多远。相反，让我们问那个真正能衡量压顶石的问题：正因为这五张地图已经合为一体，Mara 现在能_做_什么，而这些事是她以前做不到的？

她可以站在一个从未见过的服务面前——她会计的软件、一个新市场、一家物流服务商——并且知道怎样巡视它（能力扫描），怎样安全地向它提问（柜台窗口、密钥、权限范围），怎样判断它值不值得接线（什么值得自动化），接线应该住在哪里（三个家），以及怎样在任何不可逆的事情上保留一只手（安全姿态套件）。她可以在一个下午委托一条新管道，在沙盒里证明它，观察它一周，再把它折进自己已经掌握的领地。她可以看着一条坏掉的管道，读懂诚实的“不”，检查日记，十分钟内照料好它。这些都不是因为她背下了一本手册。全部都是因为她握着五张已经咔哒合成一张的地图，而一片你读得懂的景观，就是一片你能延展的景观。

这就是压顶石和回顾之间的区别。回顾会提醒你每一卷说了什么。压顶石交到你手里的，是_合并后的力量_：只有当 repo、模型、终端、服务器和 API 不再是你学过的五件东西，而成为你能指挥的一片领地时，才会存在的那个具体新能力。Mara 并不比第 1 章时更惊叹。她是更_有能力_了，而且她能逐件、逐部分地说清楚为什么。
