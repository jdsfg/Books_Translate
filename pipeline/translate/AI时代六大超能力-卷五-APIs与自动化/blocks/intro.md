每个周一早晨，陶工 Mara 都会变成一台机器。她把周末店铺里的每笔订单抄进电子表格，给每位买家写一封感谢信，再把新作品发到邮件列表。这些事都不难——难就难在太不难了。她成了工具之间的那段管道：那些工具各自待在不同的房间里造出来，从来没人给它们接上管子。这本书讲的就是那根管子，以及一个安静的事实：在 AI 助手的时代，你不必再亲自充当那段管道。

这部书和其他所有「学 API」的书不一样：它拒绝当手册。它从不塞给你一个要背的端点、一张状态码表，或一条 curl 命令——因为这些事你的 AI 助手都会做，而且反正每个月都在变。它交给你的是一张地图：API 是服务的柜台窗口，一扇专为机器开的侧门；JSON 不过是贴了标签的盒子，你打开看看，核对本助手有没有办对；密钥并不「像」你的身份——它就是机器形态的你，谁拿着它，谁就是你。握住这张地图，你走到一个从未见过的服务面前，也知道该要什么。死记二十个端点，等于什么都没学会。

这本书对判断力也出奇地诚实——而判断力，恰恰是任何工具都给不了你的那部分。它教你区分读取（廉价、可逆）与发送（不可逆，值得人手把关），并在每条自动化上线前反复追问同一个问题：要是这条流水线凌晨 3 点误触发、而我还在睡觉，最坏能捅出多大娄子？读到最后，Mara 的整个周一会自己跑起来，同时她仍把手按在一切花钱或给客户发邮件的环节上——并且，作为本系列五本工具卷的综合收束，这本书把版本控制、你自己的本地 AI、终端、服务器和 API 收成一片你能指挥的疆域，再把技能交到你手里：去给任何尚未存在的工具画出地图。

你不需要编程背景。你需要的是一个你怀疑自己用得不够的 AI 助手，以及一个你想要回来的无聊周一。

**目标读者**：AI 智能体时代里有野心的普通读者——写作者、研究者、学生、创始人、知识工作者——已经有 AI 助手却用得不够。不预设编程背景。

**先修要求**：无技术门槛。愿意用白话指挥 AI 智能体即可。熟悉本系列卷一至卷四（Git 与 GitHub / 开源 LLM 与 Ollama / 命令行 / 服务器与部署）会让综合项目更丰富，但并非必需——每个概念都能独立站稳。

**学习时长**：与同伴进行 12–16 小时苏格拉底式对话（大约每章一节）。
