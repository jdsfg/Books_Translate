#### 概念检测

**Q1.** 用正式标准定义慢性失眠。为什么持续时间要求（3 个月）重要？

提示

本章列出了五个标准。

**答案：** 慢性失眠定义为：

  1. 入睡困难、维持睡眠困难，或两者兼有（或早醒无法再入睡），每周至少 3 晚。
  2. 可归因于睡眠困难的日间功能受损。
  3. 持续至少 3 个月。
  4. 有充足睡眠机会（非外部限制造成）。
  5. 不能更好地用另一种睡眠障碍或物质解释。

3 个月持续时间要求重要，原因有几个：

* _急性失眠是正常的_。大多数成年人都会在某个时候经历短暂失眠——压力、疾病或旅行中的几晚糟糕睡眠。这不是病态的，会自行消失。将其当作障碍治疗是不适当的医学化。
* _从急性到慢性的转变涉及条件化过程_。大约 1-3 个月，床-唤醒条件化有时间建立；灾难性信念有时间发展；回避行为有时间固化。这时行为治疗才开始与“等着它过去”有意义地区分开。
* _治疗指征_：短期失眠很少需要超出安慰和基本睡眠卫生的正式治疗。慢性失眠从 CBT-I 中大幅受益。持续时间区分需要积极治疗的患者与可自行缓解的患者。
* _3 个月阈值略显武断_，但代表模式已成为自我维持的临床共识。若模式严重，1-2 个月患者也可能受益；该阈值是指南，不是绝对规则。

更深教训：并非每个糟糕睡眠期都是障碍。障碍是 _已进入慢性领域的自我维持模式_。知道这一点有助于患者（他们可能因偶尔糟糕夜晚正常而松一口气）和临床医生（可把治疗目标对准真正需要的人）。

**Q2.** 用自己的话解释“失眠的核心悖论”。为什么越努力想睡会让失眠更糟？

提示

“努力”对身体有什么作用，入睡需要什么？

**答案：** 入睡需要降低交感神经系统激活——身体必须处于心率减慢、肌张力放松、思维安静的副交感主导状态。这与“努力”本质相反。

当慢性失眠患者躺在床上努力入睡时：

  1. 他们将注意力集中在睡觉上，这本身产生唤醒——持续注意力需要交感神经激活。
  2. 他们看钟、计算如果现在入睡能睡多久，并感到时间压力。
  3. 他们担心明天后果，激活威胁反应系统。
  4. 他们尝试各种技巧（呼吸、意象），失败增添沮丧。
  5. 累积的应激激活与入睡所需的副交感主导状态相反。
