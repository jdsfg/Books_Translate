  2. _规律作息_。睡眠瘫痪更常见于昼夜节律被打乱——轮班工作（shift work）、时差（jet lag）、不规律就寝。保持规律时间可降低概率。

  3. _避免仰卧_。原因不明，仰卧睡姿与更高睡眠瘫痪率相关。侧卧可降低频率。

  4. _管理压力_。读者注意到压力相关聚集，这与文献一致。压力扰乱睡眠结构并增加尴尬阶段转换概率。

  5. _避免酒精和某些物质_。酒精和一些助眠药片段化睡眠并增加 REM-清醒转换概率。

发作时什么有帮助：

* _认识到正在发生什么_。知道机制——它是短暂的、无害的、会过去——显著降低感受到恐惧。幻觉的“存在感”是大脑状态的特征，不是真实实体。
* _尝试活动小肌肉_。许多人发现专注于动一根手指、脚趾或面部肌肉有助于“打破”瘫痪。技术有效，部分原因是引导自愿运动努力可加速弛缓解除。
* _缓慢呼吸_。平复自主神经激活可减少感受到恐惧，即使瘫痪仍持续那几秒钟。

什么没有帮助：

* _恐慌并试图猛力挣扎_。弛缓会自行解除；挣扎无助。
* _开灯睡觉或其他扰乱睡眠的补偿_。这些可能降低睡眠质量并产生更多发作。

何时寻求专业评估：

* 频繁发作（每周多次）
* 发作伴白天嗜睡或其他提示嗜睡症的症状
* 发作造成严重恐惧或睡眠回避
* 中年或以后新发频繁发作

大多数偶尔睡眠瘫痪的读者主要受益于安慰、睡眠卫生改善和了解正在发生什么。该现象对大多数人不具病理性；理解它就能消除大部分惊慌。

这也是有用提醒：睡眠阶段的分类描述——清醒、NREM 1-3、REM——代表的是典型模式而非僵化边界。边界可以模糊，短暂混合状态产生不适合任何标准类别的体验。这对睡眠瘫痪、睡眠异常行为、清醒梦和许多其他睡眠相关现象都成立。
