### 13.4 前面更困难的问题

本章表明，即使是 *计算* 穷人也不是看起来的中性技术行为：贫困线嵌入了一个有争议的观念——绝对还是相对、生存还是参与——定义中埋藏着价值承诺；测量决定数字，因此任何贫困统计在不知道哪条线画出它之前都毫无意义。我们看到真实测量（美国官方与补充贫困率）是混合体，揭示它们被 built 来揭示的东西；贫困的生活现实——动态、多维、被体验——escape 任何单一 threshold。

但使贫困成为不平等研究中最带电问题的，不是 *多少* 人贫困。而是 *为什么*。为什么有些人贫困，在一个其他人并不贫困的社会里？这是 Thread C 结构对绩效辩论最热、最人性的点，结构、文化、个人等竞争解释在这里最激烈碰撞，而全书中最具 caricature 的观念“贫困文化”正等待被误解。下一章以本书能 muster 的最大谨慎处理这个问题，因为 nowhere else 更容易滑向 either 活动家的小册子 or 辩护者的冷笑，也 nowhere else 诚实、公正的思考对所涉及人的尊严更重要。我们学会了数穷人。现在我们必须公平地尝试理解他们为什么贫困，以最强形式 hold 每一种解释，但不 crown 任何一种。
