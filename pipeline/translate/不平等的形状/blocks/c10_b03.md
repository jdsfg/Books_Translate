#### 定义：惯习与场域

**惯习（habitus）** 是一个人从社会环境中、尤其是童年吸收的 deeply ingrained 的一套性情、习惯、品味和感知世界的方式。它在意识思维之下运作，塑造一个人感觉自然、舒适和 obvious 的东西，使社会位置的产物被体验为“我就是我”。**场域（field）** 是一个特定的社会 arena（一种职业、一个学校系统、艺术界），有它自己关于什么有价值的规定。文化资本只在 *承认它的场域* 中才有价值；同一性情在一个场域中可能是资本，在另一个场域中可能一文不值。

plain 语言：惯习是继承来的第二天性，场域是这第二天性能否得到回报的舞台。面试者的 ease 是她的惯习，在家中形成；专业面试是一个 field，其规则碰巧奖励它。把她放进不同场域——一个她从未被培养进入的行业、一个 code 不同的社区——同样的性情可能把她标记为 outsider。这就是文化资本如此容易被误读为绩效的深层原因：因为惯习在 *意识思维之下* 运作，优势者根本不把自己的文化资本体验为优势。她体验为她自己、她的品味、她天生的存在方式，然后她 quite sincerely 把它归功于自己。奖励它的守门人也把它体验为不是识别一种继承，而是识别质量。整个交易对双方都 invisible，这正是它作为有效机器的原因：一种所有参与者都不视为继承的继承。

现在我们就能精确地看到文化资本如何穿回第7章的学校梯度，这正是布迪厄最 sharp 的主张之一。他认为，学校把自己呈现为中立的、奖励能力的绩效主义（meritocratic）分拣器。但它们奖励的“能力”在很大程度上是文化资本——某些孩子从家里带来的词汇、对特定知识类型的熟悉、对抽象和权威的 comfort。学校没有创造这些能力；它 *要求* 它们，然后奖励那些 arrive 时已经拥有它们的孩子，好像这些能力是孩子自己天赋的产物。因此学校真诚相信自己在测量绩效，却部分测量了继承，并把继承的文化资本转换成制度化的文化资本——文凭，然后看起来像纯 earned 成就。这是戴着绩效主义面具的再生产，是布迪厄最有 consequence 也最受争议的主张。
