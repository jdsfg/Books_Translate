#### 深入思考

**问1.** 累积优势意味着，当我们观察到两个成年人时，他们之间的差距是始于童年早期、大多不可见的长期复利的最终产物。有人认为这使成年人的结果很大程度上“不应得”，因为复利运行在出生的偶然之上，在任何人能选择之前就已开始。也有人认为一路上父母和孩子的选择是真实原因，“出生偶然”框架抹杀了这些选择。为双方给出最强版本，然后思考：优势累积的时机（大多在童年早期）是否会改变道德图景，相比优势在成年后通过个人选择累积？

**讨论：** 这是 Thread C 被尖锐化到细点的问题，而时机转折使它真正困难。先处理两个最强版本，再处理转折。

“很大程度上不应得”的最强版本：累积优势意味着决定性差异在童年早期就已埋下，通过阅读组、安全的家庭、稳定的家、上学前吸收的词汇，所有这些都是孩子接受而非挣得的，而且都可追溯到父母的位置，而父母位置本身大多继承。当一个人足够大去做我们归功于他的选择时，场地已经陡峭地倾斜，同样的努力因起点不同而产生非常不同的回报。因此把成年人结果归功于成年人自身的绩效，是把被操纵的比赛的过程误当成公平比赛的胜利；许多看起来像应得的东西是复利化的运气。

“选择是真实原因”的最强版本：结构不行动；人行动。复利每一步都有真实选择——身无分文仍读书的父母、学习或放弃的孩子、抓住或浪费机会的少年——这些选择真实地改变了结果，这就是为什么相同起点的孩子最终如此不同。因为早期条件不平等就把结果称为“不应得”，是否认每个人的能动性，侮辱了努力的穷孩子也像滑行的富孩子一样，并使责任变得无法理解。不均匀场上的努力仍然是努力，仍然重要。
