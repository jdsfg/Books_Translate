#### 定义：文化资本

**文化资本（cultural capital）**，按布迪厄的意义，是一个人拥有并被 *制度奖励* 的累积的能力、知识、品味、性情和文凭。它有三种形式：**身体化的（embodied）**（技能、说话和举止方式、熟悉与 ease，主要在童年吸收）、**客观化的（objectified）**（人拥有的文化物品，书籍、乐器、艺术品），以及 **制度化的（institutionalized）**（正式证明文化能力的文凭和资格，如学位）。其定义特征是它主要 *在家庭内部传递*，然后当学校、雇主、守门人 *视之为有价值* 时 *转换* 为优势。

plain 语言：文化资本是你随身携带的那部分优势，在家 pick up 得如此之早，以至于你体验它就是你自己。面试者的 ease 就是身体化的文化资本。它不是她表演的 trick；而是一种 disposition，像她吸收口音一样，从在拥有它的人中间长大而吸收。这里是保护这一观念免受第一种 caricature 的关键 move：文化资本 *不是* 主张一种文化内在优于另一种文化。它主张的是 *制度奖励什么*。这位候选人的举止并非客观上更优越；而是 *碰巧与守门制度所重视的东西 alignment*，这种 alignment 是她继承的。改变制度，就会改变什么算作资本。整个概念是关系式的：文化资本就是有权势的制度决定当作归属标志的任何能力。

这就是为什么势利者的 caricature——“布迪厄只是说富人更有文化”——把它完全说反了。布迪厄的论点恰恰相反：优势者的品味和举止 *并非* 在任何宇宙意义上更有文化，而只是制度被建立来 recognize 的那些，因此真正是继承的东西被 *误认（misrecognized）* 为绩效、 refinement 或天生优越。这个理论是对势利者的 debunking，而不是表达他。它说皇帝的“文化”在很大程度上是一套碰巧符合守门者 dress code 的制服。


### 9.2 惯习与场域：为什么它感觉像天性

两个进一步概念完善了这一观念，并解释为什么文化资本如此难见，又如此容易被误认为人格。布迪厄称它们为 *惯习（habitus）* 和 *场域（field）*。
