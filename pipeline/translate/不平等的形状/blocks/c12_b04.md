### 11.3 Rank 的 stickiness

现在转向相对流动——“白手起家”故事实际承诺的 rank 改变——这里的发现随时间更稳定，但对许多人来说，其程度更令人惊讶。

诚实的大标题是：rank 是 *sticky 的*，在每个被测量的社会中都是如此，尽管某些社会比其他社会更 sticky。出生在高收入梯级顶部附近的孩子平均倾向于最终落在顶部附近；出生在底部附近的孩子平均倾向于最终落在底部附近。流动是真实的，很多人确实改变 rank，有时剧烈地，但它是 *有限的*，而且这种限制比“白手起家”故事暗示的更大。极端尤其 sticky：出生在顶端或底端是你最终落在哪里最强的预测器，因为顶层拥有最多资源来维持其位置，而底层面对着第7章那张网最深的相关劣势。中间更流动；两端更固定。


#### 定义：Rank 持续性（位置的 stickiness）

**Rank 持续性（rank persistence）** 是孩子在收入分配中的位置追踪父母位置的程度。高持续性（stickiness）意味着孩子的 rank 被父母的 rank 强烈预测，因此梯级倾向于跨代再生产自己；低持续性（流动性）意味着孩子的 rank 仅 weakly 与父母的相连，所以起点几乎不能预测终点。没有真实社会显示完美持续性（种姓）或完美流动性（彩票）；所有社会都位于中间某处，而它们位于 *何处* 既可测量，也在不同社会间惊人地不同。

plain 语言：rank 持续性测量苹果多靠近树。对我们的目的而言，关键发现是双重的。第一，持续性 *在任何地方都 substantial*：没有 measured 社会接近出生什么也预测不了的流动理想。第二，这正是比较章 ahead 如此重要的原因，持续性 *在不同社会间差异巨大*：有些孩子出生 rank 对成年 rank 预测很强；另一些社会则弱得多。梯级在某些社会比另一些更 sticky，这意味着 stickiness 不是自然法则，而是社会安排方式的特征——正是第8章地点-学校渠道 foreshadowed 的 lesson。


#### 常见误解

一个常见且 consequential 的错误是把 *任何* 流动都当作承诺被兑现的证据——“看，有人确实上升，所以系统是开放的”；或者把 *stickiness* 当作承诺是谎言的证据——“穷人始终穷，所以一切都是 rigged”。两者都以现在熟悉的方式误读数据。真相是一个 *程度*，不是 yes-or-no：同时存在真实流动 *和* substantial stickiness，而诚实的问题是 *各有多少*，以及 *一个社会如何与其他社会及其自身理想比较*。指着上升者只能证明持续性不是 total（没人这样主张）；指着 stuck 者只能证明流动性不是 total（也没人这样主张）。有趣的事实存在于量级中：多 sticky、与什么比较、朝哪个方向变化。这与我们用于健康梯度和 schooling 差距的纪律相同，拒绝让乐观者或悲观者把测量到的程度 collapse 成口号。
