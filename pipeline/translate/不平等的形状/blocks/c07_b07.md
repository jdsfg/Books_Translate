#### 概念检查

**Q1.** 解释是什么让健康中的社会梯度成为 *梯度* 而非 *悬崖*，以及为什么 Whitehall 研究对此是有力证据。

**提示：**

健康只在大“穷人”与“其他人”之间有差异，还是追踪每一步的位置？为什么有保险、有工作的公务员是一个 revealing 测试案例？

**答案：** *悬崖* 意味着除底部一个被剥夺群体外，其他所有人健康都好，这个群体跌落。*梯度* 意味着健康沿 *整个* 阶梯逐步改善：每向上一级，平均而言都比下一级更健康，一直到顶端。Whitehall 研究是强力证据，因为它追踪英国公务员，全都有工作、稳定白领、共享同一国民医疗，却仍然发现按办公室 *职级* 的清晰阶梯式梯度：职级越低，死亡率越高，平滑地贯穿每个职级，最低职级死亡率是最高职级的数倍。由于这些人不是缺医生的赤贫者，结果说明 *位置本身*，而不仅仅是绝对剥夺，一路向上追踪健康，这就是它得名“地位综合征”并超越简单贫困致病故事的原因。

**Q2.** 区分健康梯度的 *因果* 与 *选择* 解释，并解释为什么 Whitehall 发现使大多数研究者倾向 substantial 因果，但本身不能证明它。

**提示：**

“是低位让你生病，还是生病让你低位？”为什么第二种解释在一群健康的受雇公务员中站不住脚？

**答案：** *因果* 说低位置导致更差健康（通过更差条件、压力、更少资源），因此提升位置会改善健康。*选择* 说糟糕健康导致低位置，因为疾病把人拖下阶梯，因此梯度部分反映病人向下 sorting，而不是低位置使人生病。诚实观点是 *两者都运作*，争论在混合比例。Whitehall 发现倾向 substantial 因果，因为研究对象是相对健康、稳定就业、按办公室职级排序的群体；很难把这样一群人中的清晰逐级梯度主要解释成病人向下漂移。它本身不能 *证明* 因果，选择仍然真实，一些 sorting 肯定存在，但它让纯选择故事严重 strained。这是强研究 shift 有争议 balance 却不关闭问题的很好例子。
