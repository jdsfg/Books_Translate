连续 | 正态 | 恒等 | 均值变化
二元 | 二项 | Logit | 对数优势变化
计数 | Poisson | 对数 | 对数率变化
正连续 | Gamma | 对数 | 对数均值变化
事件时间 | 指数/Weibull | 对数 | 对数风险变化

每个 GLM 讲述关于数据生成过程的故事：

* **正态/线性**：结果是许多小影响的总和（CLT）
* **逻辑**：二元结果来自随预测变量变化的概率
* **Poisson**：固定窗口中独立罕见事件的计数
* **Gamma**：结果是许多正效应的乘积（乘法过程）

选择适当 GLM 需要理解故事：什么过程生成了数据，这暗示了什么约束？

### 16.6 超越 GLM——非参数和灵活模型

GLM 将线性回归扩展到非正态结果，但它们仍假设期望值的链接函数是预测变量的线性组合。如果真实关系即使在链接尺度上也不是线性的呢？

**多项式回归**：将 $X, X^2, X^3, \ldots$ 作为预测变量纳入。模型在参数上仍线性，但与 $X$ 的关系现在是多项式曲线。风险：高次多项式在观测数据范围外可能剧烈振荡。

**样条**：拟合在节点处平滑连接的分段多项式函数。比高次多项式更稳定同时仍能捕获灵活曲线。

**广义可加模型（GAM）**：GLM 的扩展，其中每个预测变量贡献一个平滑（可能非线性）函数：

$$g(\mu) = \beta_0 + f_1(X_1) + f_2(X_2) + \cdots + f_p(X_p)$$

每个 $f_j$ 是从数据估计的平滑函数。GAM 高度灵活同时保持相对可解释——你可以绘制每个 $f_j$ 来理解每个预测变量与结果之间的关系。

这些灵活模型更尖锐地引入偏差-方差权衡：更灵活的模型可以更好地拟合数据，但有过拟合噪声的风险。此权衡——所有建模的核心挑战——是下一章的主题。

### 16.7 习题

#### 概念检查

**Q1.** GLM 的三个组件是什么？解释逻辑回归如何融入此框架。

**答：** GLM 的三个组件是：

1. **随机组件**：假设 $Y$ 的概率分布。对于逻辑回归：二项（每个结果是概率为 $p$ 的独立 Bernoulli 试验）。

2. **系统组件**：线性预测变量 $\eta = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p$，是预测变量的线性组合。

3. **链接函数**：连接均值 $\mu = E[Y]$ 到线性预测变量的函数 $g$，$\eta = g(\mu)$。对于逻辑回归：logit 链接 $g(\mu) = \log(\mu/(1-\mu))$。

逻辑回归融入 GLM 框架为：$Y_i \sim \text{Binomial}(n=1, p_i)$（Bernoulli），线性预测变量 $\eta_i = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p$，链接函数 $\eta = \text{logit}(p) = \log(p/(1-p))$。逆链接映射回：$p = 1/(1 + e^{-\eta})$。

**Q2.** 在逻辑回归中，$e^{\beta_j}$ 代表什么？你如何解释 $e^{\beta_j} = 1.5$ 和 $e^{\beta_j} = 0.6$？

**答：** $e^{\beta_j}$ 是预测变量 $X_j$ 增加一个单位的**优势比**（OR），保持所有其他预测变量不变。

$e^{\beta_j} = 1.5$：$X_j$ 增加一个单位与事件优势增加 50% 相关（事件在优势方面变为 1.5 倍可能）。例如，如果疾病基线优势为 1:3（25% 概率），$X_j$ 增加一个单位后优势变为 1.5:3 = 1:2（33% 概率）。

$e^{\beta_j} = 0.6$：$X_j$ 增加一个单位与优势减少 40% 相关（乘以 0.6 减少优势）。如果基线优势为 1:1（50% 概率），增加一个单位后优势为 0.6:1，对应概率 0.6/1.6 = 37.5%。

重要注意事项：优势比不是相对风险。对于罕见事件（概率 < 10%），$e^\beta \approx$ 相对风险。对于常见事件，$e^\beta$ 大幅高估相对风险。
