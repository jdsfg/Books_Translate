Metropolis-Hastings 算法虽然在概念上优雅，但对复杂、高维后验在计算上效率低下。现代贝叶斯计算使用更复杂的算法。

**Hamiltonian Monte Carlo（HMC）**使用梯度信息——对数后验对参数的导数——来做出更高效的提议。HMC 不提议随机小步，而是模拟粒子在保守"Hamiltonian"力下通过后验地形移动的动力学。粒子遵循高效穿越后验的轨迹，在保持高接受率的同时迈大步。

**No-U-Turn Sampler（NUTS）**，HMC 的自适应扩展，是 Stan 和 PyMC（两个广泛使用的概率编程系统）的底层算法。NUTS 自动调优步长和轨迹长度，使其对广泛模型有效而无需大量手动调优。

结果：HMC/NUTS 可以高效地从数百或数千维的后验中采样，使复杂模型的贝叶斯分析在计算上可行。

### 14.6 概率编程——统计即计算

MCMC 算法和现代软件的结合产生了**概率编程语言**——允许分析者在代码中指定统计模型（先验 + 似然）并自动推断后验的系统。

流行系统：**Stan**（C++ 后端，R 和 Python 接口）、**PyMC**（Python）、**TensorFlow Probability**、**Pyro**（基于 PyTorch）。

在 Stan 中（伪代码）：

```
parameters {
  real mu;       // 均值参数
  real<lower=0> sigma;   // 标准差（必须为正）
}
model {
  mu ~ normal(0, 10);    // 先验
  sigma ~ exponential(1); // 先验
  y ~ normal(mu, sigma); // 似然
}
```

Stan 读取此模型规范，自动计算对数后验的梯度（使用自动微分），运行 NUTS 采样，并返回后验样本。分析者编写统计模型；系统处理计算细节。

这是"编译器"类比：统计学家编写模型（"源代码"），概率编程系统将其编译为高效采样算法（"可执行文件"）。这种分工使十年前在计算上不可行的模型的贝叶斯分析成为可能。

### 14.7 与 AI 的联系——MCMC 和扩散模型

**线索 C——AI 与统计（章节）**

这里是 MCMC 和现代 AI 图像生成之间一个令人惊讶的联系。

**扩散模型**（DALL-E、Stable Diffusion 及类似系统的底层技术）通过一个与 MCMC 有深层数学相似性的过程生成图像：

1. 扩散模型学习反转加噪过程。从干净图像开始，噪声被逐步添加直到图像变为纯高斯噪声。模型学习反转此过程——取噪声图像并逐步去噪。

2. 在生成时，模型从纯噪声开始（先验样本——高斯分布）并应用许多小去噪步骤，每步由类梯度更新引导，将样本推向学习到的数据分布。

这类似于 MCMC：从参数空间中的随机点开始，采取许多小的梯度信息步骤来探索目标分布。在 MCMC 中，目标是后验分布。在扩散模型中，目标是自然图像（或文本条件图像）的分布。

数学形式化是相关的：两者都使用**分数函数**（对数概率的梯度）来引导探索。在 HMC 中，对数后验的梯度引导 Hamiltonian 动力学。在扩散模型中，学习到的分数函数（去噪神经网络）引导反向扩散。

此联系不仅是类比——它使研究者能够将 MCMC 诊断和理论应用于扩散模型分析，并开发在神经网络生成中使用类 MCMC 采样的混合方法。"贝叶斯统计"和"生成式 AI"之间的边界比看起来更薄。
