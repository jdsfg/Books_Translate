(a) OLS 会失败，因为 p = 800 > n = 150：预测变量数量超过观测值数量。OLS 需要求矩阵 X'X（一个 800 x 800 矩阵）的逆，但该矩阵是奇异的（秩 <= 150 < 800）——无法求逆。OLS 没有唯一解；这个系统欠定，有无穷多个系数向量都能给出恰好为 0 的训练误差。由此得到的过拟合预测在新数据上会有巨大的方差。

即使可以计算 OLS（例如使用伪逆），它也会产生一个使用全部 800 个预测变量完美拟合 150 个训练样本的模型——严重过拟合，测试表现几乎必然很糟。

(b) 岭回归加入惩罚项 lambda sum beta_j2，使得即便 p > n，优化问题仍然定义良好。岭回归可以把全部 800 个基因的系数向 0 收缩，产生一个具有以下性质的模型：

* 无论 p/n 比例如何，都有唯一、稳定的解
* 通过收缩参数 lambda 控制模型复杂度
* 比 OLS 更好地处理多重共线性（相关的基因表达）

通过交叉验证选择 lambda，可以估计最优收缩量——足以降低方差，同时不引入过多偏差。

(c) LASSO 特别合适，因为基因调控网络是**稀疏**的：在 800 个基因中，大多数很可能不是目标基因的调控伙伴。一个典型基因通常只受到少数其他基因的直接调控——也许是 800 个中的 10–30 个。LASSO 会把无关基因的系数收缩到恰好为 0，只保留相关基因，从而产生一个可解释的稀疏模型。

贝叶斯解释（拉普拉斯先验）也与这种领域知识一致：大多数调控效应为 0，而 LASSO 的拉普拉斯分布在 0 附近尖峰的先验，正好编码了这种稀疏性信念。

此外，稀疏模型具有生物学可解释性——研究者可以识别 LASSO 选择出来的具体预测基因，并从机制上研究它们，检验它们是已知调控伙伴还是新的发现。
