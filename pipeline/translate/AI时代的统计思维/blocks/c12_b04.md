6. 检查模拟数据集：它们是否显示合理的结果范围？是否有不可能的值（负血压、概率 > 1）？汇总统计量（均值、标准差、分位数）是否与领域知识一致？

如果模拟数据集包含荒谬值（偏离对照组 ±50 个标准差的结果，或远超 1 的比例），先验（或似然）需要修订。如果它们看起来像合理的临床试验数据，先验是适当的。

**Q3.** 什么是先验敏感性分析，其结论何时最有用？

**答：** 先验敏感性分析用几种不同合理先验重新运行贝叶斯分析并比较产生的后验。它回答："我的结论在多大程度上依赖先验选择？"

**最有用时——两种情境**：

_情境 A（先验一致）_：所有合理先验给出相似后验。结论：数据足够强以压倒先验不确定性。分析是稳健的；特定先验选择不太重要。这令人安心——无论起始信念如何，结论都得到支持。

_情境 B（先验不一致）_：不同合理先验给出实质不同的后验。结论：数据不足以解决不确定性；结论依赖先验信念。这是重要信息——意味着你需要更多数据或更仔细论证的先验。分析应与敏感性分析一起报告，让读者看到不同先验信念如何导致不同结论。

敏感性分析最不有用（应提及但不强调）当先验明显正确时——例如，先验来自大型高质量荟萃分析且没有理由怀疑它。

**Q4.** 解释对贝叶斯推断的主要哲学异议并给出两个回应。

**答：**

**异议**：科学旨在产生客观知识。贝叶斯推断需要先验，不同分析者可能有不同先验。两位科学家用不同先验分析相同数据得到不同后验——一种与科学客观性不相容的主观性形式。

**回应 1——所有推断都涉及假设**：频率派推断也嵌入主观选择——检验哪个零假设、假设哪个模型、使用哪个停止规则。贝叶斯先验是众多明确假设中的一个。明确假设可以被辩论和纠正；隐式假设不能。

**回应 2——大数据克服先验**：如果两位分析者同意用证据更新先验，他们的后验随数据积累而收敛。贝叶斯主张不是我们从相同起点开始；而是有足够证据时我们收敛到相同位置。先验中的主观性在大数据极限中变得无关——正如赌徒谬误在大样本中消失。

**其他值得知道的回应**：

* 先验选择可受一致性要求（Jeffreys 先验）、类似研究的经验数据（经验贝叶斯）或明确领域知识约束
* 先验透明性使富有成效的辩论成为可能——批评者可以识别他们不同意的特定先验选择并提出替代，导致更好校准的结论

#### 应用题

**Q1.** 一位公共卫生研究者正在估计新人群中高血压的患病率 $p$。她有三个先验选项：

**选项 A**（无信息）：$p \sim \text{Beta}(1, 1)$（[0,1] 上均匀） **选项 B**（弱信息）：$p \sim \text{Beta}(3, 9)$（先验均值 25%，先验标准差约 12%） **选项 C**（信息）：$p \sim \text{Beta}(20, 60)$（先验均值 25%，先验标准差约 4.8%）

她调查了 $n = 30$ 名个体，发现 10 人有高血压。

(a) 对每个先验，计算后验参数（$\text{Beta}(\alpha_0 + k, \beta_0 + n - k)$）和后验均值。(b) 三个后验如何比较？这告诉你关于样本量 vs. 先验强度的影响什么？(c) 她将样本增加到 $n = 300$（相同 1/3 比例：300 中 100）。重新计算后验并比较。先验的影响发生了什么？

提示

先验均值：A = 1/(1+1) = 50%，B = 3/(3+9) = 25%，C = 20/(20+60) = 25%。后验均值 = $(\alpha_0+k)/(\alpha_0+\beta_0+n)$。

**答：**

(a) $n = 30$，$k = 10$：

**选项 A**：后验 = $\text{Beta}(1+10, 1+20) = \text{Beta}(11, 21)$。后验均值 = $11/32 \approx$ **34.4%**

**选项 B**：后验 = $\text{Beta}(3+10, 9+20) = \text{Beta}(13, 29)$。后验均值 = $13/42 \approx$ **31.0%**

**选项 C**：后验 = $\text{Beta}(20+10, 60+20) = \text{Beta}(30, 80)$。后验均值 = $30/110 \approx$ **27.3%**

(b) 三个后验有相同数据（10/30 = 33.3%），但不同均值：34.4%、31.0%、27.3%。样本比例为 33.3%。

选项 A（无信息，无先验偏好）给出最接近样本比例的后验均值。选项 B 和 C 向 25%（它们的先验均值）拉动，C 拉动更强因为它更有信息。信息先验（C）实质上将后验从数据拉离——从 33% 拉向 27%。
