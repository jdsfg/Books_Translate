(a) 有效性的先验优势：

$$\text{先验优势} = \frac{P(\text{有效})}{P(\text{无效})} = \frac{0.20}{0.80} = 0.25$$

(b) 后验优势：

$$\text{后验优势} = \text{LR} \times \text{先验优势} = 6 \times 0.25 = 1.5$$

后验概率：

$$P(\text{有效} | \text{数据}) = \frac{\text{后验优势}}{1 + \text{后验优势}} = \frac{1.5}{2.5} = 0.60$$

药物有效的后验概率为 60%。

(c) 同事的陈述（"无效的概率只有 4%"）是经典的 p 值误解：将 $P(\text{数据} | H_0)$ 当作 $P(H_0 | \text{数据})$。

正确的贝叶斯计算显示药物无效的概率为 40%（1 − 60%）。这与暗示的 4% 非常不同。

差异出现因为有效性的先验概率只有 20%——大多数在 II 期试验中测试的药物是无效的。即使中等有利的似然比（6:1）也只能将概率带到 60%，而非 96%。先验在此影响巨大。

这就是为什么药物开发如此困难：即使 II 期试验中 p < 0.05，此阶段测试的大多数药物是无效的，有效性的后验概率可能远低于 p 值所暗示的。

**Q2.** 你正在估计用户界面的平均响应时间（秒）。从过去类似产品的 UX 研究中，你相信均值可能在 2.5 秒左右，有相当大的不确定性（信念标准差 ≈ 1 秒）。所以你的先验是 $\mu \sim \mathcal{N}(2.5, 1)$。

你运行了 $n = 16$ 名用户的可用性测试，观测到 $\bar{X} = 3.2$ 秒，已知总体标准差 $\sigma = 1.6$ 秒。

(a) 使用正态-正态更新公式计算 $\mu$ 的后验分布。(b) 使用后验计算 $\mu$ 的 95% 可信区间。(c) 如果你有 $n = 100$ 名用户且相同的 $\bar{X} = 3.2$，重新计算后验。这展示了样本量在贝叶斯推断中的什么作用？

提示

后验精度 = 先验精度 + 数据精度 = $1/\tau^2 + n/\sigma^2$。后验均值是先验均值和样本均值的精度加权平均。

**答：**

给定：$\mu_0 = 2.5$，$\tau^2 = 1$（先验方差），$\sigma^2 = 2.56$（已知方差），$n = 16$，$\bar{X} = 3.2$。

(a) 后验精度：

$$\frac{1}{\tau_n^2} = \frac{1}{\tau^2} + \frac{n}{\sigma^2} = \frac{1}{1} + \frac{16}{2.56} = 1 + 6.25 = 7.25$$

后验方差：$\tau_n^2 = 1/7.25 \approx 0.138$。后验标准差：$\tau_n \approx 0.371$。

后验均值：

$$\mu_n = 0.138 \times \left(\frac{2.5}{1} + \frac{16 \times 3.2}{2.56}\right) = 0.138 \times (2.5 + 20) = 0.138 \times 22.5 = 3.105$$

后验：$\mu | \text{data} \sim \mathcal{N}(3.105, 0.138)$。

(b) 95% 可信区间：$3.105 \pm 1.96 \times 0.371 = 3.105 \pm 0.728 \approx [2.38, 3.83]$ 秒。

此区间有贝叶斯解释：给定数据和先验，真实平均响应时间在 2.38 和 3.83 秒之间的概率为 95%。

(c) 当 $n = 100$：

$$\frac{1}{\tau_n^2} = 1 + \frac{100}{2.56} = 1 + 39.06 = 40.06$$

后验方差：$\tau_n^2 \approx 0.025$，$\tau_n \approx 0.158$。

后验均值：$\mu_n = 0.025 \times (2.5 + 125) = 0.025 \times 127.5 = 3.188$

后验均值（3.188）现在比先验均值（2.5）更接近 $\bar{X} = 3.2$。后验置信区间：$3.188 \pm 1.96 \times 0.158 = [2.88, 3.50]$。

**这展示了什么**：$n = 16$ 时，先验（均值 2.5）有实质影响——后验均值（3.105）被有意义地拉向先验。$n = 100$ 时，数据压倒先验——后验均值（3.188）几乎与样本均值（3.2）相同。后验置信区间也窄得多（宽度 ≈ 0.62 vs. 1.45）。

这说明了贝叶斯推断的基本原理：大样本时，后验集中在数据附近，无论先验如何。先验在数据稀少时最为重要。
