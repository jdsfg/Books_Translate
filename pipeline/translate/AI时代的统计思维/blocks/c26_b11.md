1. **留出验证集（如果可用）**：在运行任何分析之前，留出30–40名患者。用剩余的110–120名患者拟合 LASSO 模型。把选择出的47基因模型应用到留出的患者上，并评估预测性能（AUROC、校准）。这会提供一个对泛化能力的诚实估计。

  2. **用于预测性能的交叉验证**：使用嵌套交叉验证——外层循环用于模型评估，内层循环用于 LASSO 超参数 λ 的选择。外层循环得到的性能估计不会被内层循环中的变量选择所偏倚。

  3. **稳定性选择**：在训练数据的100个 bootstrap 样本上运行 LASSO，每次记录哪些基因被选中。把在超过80%的 bootstrap 样本中被选中的基因报告为“稳定选中”。只在少数 bootstrap 样本中被选中的基因很可能是假阳性。

  4. **独立验证队列**：这是金标准。获得一个独立数据集（不同医院、不同技术平台），并测试47基因模型。真正的预测因子会通过验证；虚假的选择不会。

  5. **生物学合理性**：检查这47个基因是否聚集在已知与癌症相关的通路中。真实的生物学机制更可能产生机制上连贯的发现。这不是统计验证，但会支持或削弱选择结果的可信度。

**Q2.** 一家社交媒体公司有 n = 10,000 名用户和 p = 50,000 个描述用户行为的特征（发帖内容、互动模式、社交连接、活动时间）。他们希望建立一个预测用户流失的模型。

(a) 为什么 OLS 不可行？Ridge 可行吗？为什么？ (b) 数据科学团队运行 PCA，发现前30个成分解释了82%的方差。他们在这30个 PCA 成分上拟合 Ridge 回归。他们正在做什么假设？这种方法什么时候可能失败？ (c) 另一种做法是直接在所有50,000个特征上运行 LASSO。LASSO 对真实信号做了什么假设？这与 PCA 方法有何不同？ (d) 团队最终使用 LASSO 选择了200个特征（非零系数）。一位研究者认为：“这200个特征就是流失的真实驱动因素——我们应该把它们作为因果因素来研究。”这引发了什么统计担忧？

提示

对于 (b)：PCA 寻找最大方差方向——但最大方差不一定等于与流失最相关。对于 (d)：考虑变量选择中的多重检验问题。

**答案：**

**(a) OLS 与 Ridge 的可行性**：OLS 需要求逆 X'X，这是一个 50,000 × 50,000 的矩阵。当 p > n 时，该矩阵的秩至多为 n - 1 = 9,999 < 50,000——它是奇异的，无法求逆。OLS 有无穷多个解，并且都能精确拟合训练数据。

Ridge 回归会给 X'X 加上 λI：Ridge 解需要求逆 (X'X + λI)。只要 λ > 0，给对角线加上这一项就会使矩阵满秩并可逆，而不管 p/n 的比例如何。因此当 λ > 0 时，Ridge 总是可行的（并且有唯一解）。通过交叉验证选择 λ，就能确定合适的正则化强度。
