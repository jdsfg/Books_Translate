#### LASSO——通过正则化进行变量选择

**LASSO**（Least Absolute Shrinkage and Selection Operator，L1 正则化）使用绝对值惩罚：

beta_hat_LASSO = arg min_beta [sum_{i=1}^n (Y_i - X_i' beta)2 + lambda sum_{j=1}^p |beta_j|]

它与岭回归的关键区别在于：L1 惩罚在 0 处有一个角点，这会导致某些系数被恰好设为 0。这赋予了 LASSO **变量选择**属性——它同时收缩系数并选择要纳入的变量。

对于稀疏问题（预测变量很多，但真正重要的很少），LASSO 极其强大：它会自动识别相关变量，并丢弃其余变量。


#### 正则化的贝叶斯解释

**线索 C——AI 与统计学（连载）**

正则化有一个漂亮的贝叶斯解释：正则化惩罚等价于对系数的先验分布。

**岭回归** ↔ 每个系数上的正态先验 beta_j ~ N(0, 1/lambda)。在这个正态先验下，岭回归估计就是 MAP（最大后验）估计。放置正态先验意味着：“我相信系数大概率较小；系数越大，概率越低。”

**LASSO** ↔ 每个系数上的拉普拉斯先验 p(beta_j) proportional to exp(-lambda |beta_j|)。与正态先验相比，拉普拉斯先验有更厚的尾部，允许某些系数较大，但也会产生恰好为 0 的系数。

这种联系不只是数学上的优雅——它有实际含义：

1. **选择 lambda**：正则化参数可以解释为“系数较小”这一先验信念的强度。强先验 = 大 lambda = 更多收缩。

2. **神经网络正则化**：训练神经网络时使用的权重衰减，正是应用于网络权重的岭回归。Dropout 正则化（训练期间随机将单元置零）被解释为一种带有特定隐含先验的贝叶斯近似。深度学习中的 L2 正则化就是权重上的高斯先验。

3. **为什么正则化有效**：从贝叶斯角度看，小系数先验体现了一种信念：大多数预测变量应该只有适度影响。这个先验通常是正确的——在大多数实际场景中，大多数候选预测变量的效应很小或为 0。先验会把有噪估计向 0 收缩，而 0 通常正是真相所在的位置。

正则化（频率学派的模型选择工具）与贝叶斯先验（第 11 章）之间的联系，是本书最深刻的概念桥梁之一：它们从不同角度描述的是同一种现象。
