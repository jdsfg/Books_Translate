### 2.2 概率公理

无论采用哪种解释，所有概率都必须遵守同一套数学规则。这些规则称为**柯尔莫哥洛夫公理**，以1933年将其形式化的俄罗斯数学家安德雷·柯尔莫哥洛夫命名。

考虑一个**样本空间** $S$，即某个实验或情境的所有可能结果构成的集合。一个**事件** $A$ 是样本空间的一个子集：一组结果。**概率** $P(A)$ 是赋给每个事件的一个数。

#### 定义：柯尔莫哥洛夫公理

函数 $P$ 为事件赋予概率，并且必须满足：

**公理1（非负性）：** 对任意事件 $A$，$P(A) \geq 0$。

**公理2（规范化）：** $P(S) = 1$。

**公理3（可加性）：** 对任意两个互斥事件 $A$ 和 $B$（也就是说它们不能同时发生），$P(A \cup B) = P(A) + P(B)$。

用普通语言说：概率是非负数；样本空间中总会有某件事发生；如果两个事件不能同时发生，那么其中一个发生的概率就是它们各自概率之和。

这三条规则看起来几乎显然到平凡。但它们是整个概率数学大厦的基础。

为什么它们不是任意规定？因为它们反映了理性信念的结构。如果你给某个事件赋予负概率，那究竟意味着什么？如果“有事发生”的总概率不是1，剩下的概率去了哪里？如果两个互斥事件的概率不能相加，概率就无法成为任何一致意义上的度量。

从这三条公理可以推出其他一切。例如：

事件不发生的概率是 $P(A^c) = 1 - P(A)$。（证明：$A$ 与 $A^c$ 互斥且穷尽，所以 $P(A) + P(A^c) = P(S) = 1$。）

不可能事件（空集）的概率是0。（证明：空集与 $S$ 互斥且并集为 $S$，所以 $P(\emptyset) + P(S) = P(S)$，得到 $P(\emptyset) = 0$。）

对任意事件 $A$ 和 $B$：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$。（这就是容斥原理——我们减去重叠部分，因为它被计算了两次。）

### 2.3 条件概率

有一个概念比其他任何概念都更支撑统计推断：**条件概率**。

你掷一枚六面骰。掷出4的概率是多少？显然是 $\frac{1}{6}$。

但现在假设我告诉你结果是偶数。它是4的概率是多少？

结果为偶数这一信息改变了你所知道的内容。样本空间实际上从 $\{1,2,3,4,5,6\}$ 缩小为 $\{2,4,6\}$。在这个缩小后的空间中，4的概率是 $\frac{1}{3}$。

这就是条件概率。它表示在事件 $B$ 已经发生的条件下，事件 $A$ 发生的概率。
