无论哪种解读，所有概率都必须遵守相同的数学规则。这些规则就是**柯尔莫哥洛夫公理（Kolmogorov axioms）**。

考虑一个**样本空间** $S$——某个实验或情境的所有可能结果的集合。一个**事件** $A$ 是 $S$ 的一个子集。概率 $P(A)$ 是分配给每个事件的一个数。

**公理 1（非负性）：** 对于任意事件 $A$，$P(A) \geq 0$。

**公理 2（归一性）：** $P(S) = 1$。

**公理 3（可加性）：** 对于任意两个互斥事件 $A$ 和 $B$（即它们不能同时发生），$P(A \cup B) = P(A) + P(B)$。

用通俗的话说：概率是非负数；样本空间中总有某事发生；如果两个事件不能同时发生，那么其中之一发生的概率等于它们各自概率之和。

这三条规则看起来几乎是平凡地显而易见。但它们是整个概率论数学大厦所赖以建立的基础。

为什么它们不是任意的？因为它们反映了理性信念的结构。如果你给某个事件分配了负概率，那意味着什么？如果"某事发生"的总概率不是 1，剩余的概率去了哪里？如果两个互斥事件的概率不能相加，概率就无法成为任何连贯之物的度量。

从这三条公理出发，其他一切都随之而来。例如：

事件不发生的概率是 $P(A^c) = 1 - P(A)$。（证明：$A$ 和 $A^c$ 互斥且穷尽，所以 $P(A) + P(A^c) = P(S) = 1$。）

不可能事件（空集）的概率是 0。（证明：空集和 $S$ 互斥且并集为 $S$，所以 $P(\emptyset) + P(S) = P(S)$，得 $P(\emptyset) = 0$。）

对于任意事件 $A$ 和 $B$：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$。（容斥原理——我们减去重叠部分因为它被计算了两次。）
