**决定系数** $R^2$ 衡量 $Y$ 的方差中被回归"解释"的比例：

$$R^2 = 1 - \frac{\sum_i (Y_i - \hat{Y}_i)^2}{\sum_i (Y_i - \bar{Y})^2} = 1 - \frac{\text{残差平方和}}{\text{总平方和}}$$

$R^2$ 范围从 0（回归什么都不解释）到 1（回归解释所有方差）。在简单回归中它等于 $X$ 和 $Y$ 之间相关系数的平方。

#### 常见误解

**误解：高 $R^2$ 意味着模型好。**

$R^2$ 衡量样本内拟合——回归线对你用于估计的数据拟合得多好。这与以下非常不同：

* **样本外预测**：模型对新数据预测多好
* **因果结构**：$X$ 是否导致 $Y$
* **实际重要性**：关系是否大到有意义

一个模型可以有 $R^2 = 0.95$ 却是糟糕的预测模型（严重过拟合，如我们将在第 17 章看到的）。一个模型可以有 $R^2 = 0.05$ 却识别出有巨大实际重要性的因果关系。永远不要仅凭 $R^2$ 评判回归模型。

### 15.3 多元回归——保持其他变量不变

简单回归告诉你 $X$ 和 $Y$ 之间的二元关系。多元回归向模型添加更多变量：

$$Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \cdots + \beta_p X_{pi} + \varepsilon_i$$

现在每个系数 $\beta_j$ 有特定解释：$X_j$ 增加一个单位时 $Y$ 的预期变化，**保持模型中所有其他变量不变**。

此"保持不变"语言是回归分析中最重要的短语。它意味着：我们在比较所有其他变量（$X_1, \ldots, X_{j-1}, X_{j+1}, \ldots, X_p$）值相同且只在 $X_j$ 上不同的个体。

#### "保持不变"的威力和危险

**威力**：控制其他变量允许你将 $X_j$ 和 $Y$ 之间的关系从相关变量的污染影响中隔离出来。

吸烟和肺癌例子：烟草业的混淆论点是遗传倾向可能同时导致吸烟和肺癌。如果你能测量和控制遗传风险，吸烟和肺癌之间的关联要么保持（真实因果效应）要么消失（混淆关联）。Bradford Hill 的设计更进一步——他控制了许多人口统计变量，剂量-反应关系清晰且大，动物实验支持了机制。

**危险**："保持不变"只控制你实际测量并纳入模型的变量。未测量的混淆因素仍然污染估计。

例子：你运行考试分数对学习时间的回归，控制 IQ。学习时间系数估计相同 IQ 学生中学习时间的效应。但你没有控制家庭收入、辅导机会、学校质量、睡眠量或动机。所有这些可能与学习时间和分数都相关。学习时间系数仍反映所有未测量的混淆因素。

这是观察性回归的永恒局限：你永远无法控制一切。回归系数只相对于模型中的变量是"干净的"。未知或未测量的混淆因素仍然存在。

### 15.4 混杂因素和虚假关联

**混杂因素**是与预测变量和结果都相关的变量，在它们之间创建虚假或膨胀的关联。

#### 定义：混杂因素

变量 $Z$ 是 $X$ 和 $Y$ 之间关系中的**混杂因素**，如果：

1. $Z$ 与 $X$（感兴趣的因果）相关
2. $Z$ 与 $Y$（结果）相关
3. $Z$ 不在 $X$ 和 $Y$ 之间的因果路径上

用通俗语言说：$Z$ 是 $X$ 和 $Y$ 的"共同原因"，即使没有直接因果关系也在它们之间创建关联。

经典例子：

* 冰淇淋销量（$X$）和溺水死亡（$Y$）：正相关。混杂因素：炎热天气（$Z$）导致两者。
* 鞋码（$X$）和儿童阅读能力（$Y$）：正相关。混杂因素：年龄（$Z$）驱动两者。
* 咖啡饮用（$X$）和心血管疾病（$Y$）：某些研究中正相关。疑似混杂因素：吸烟（$Z$），与咖啡消费和心脏病都相关。
