统计联系：在负对数似然上的梯度下降在执行 MLE。算法只是当解析解不可行时寻找最大似然估计的计算方法。

当损失函数是交叉熵（分类的标准）：

$$\ell(y, f(x)) = -\sum_k y_k \log p_k(x)$$

最小化此恰是最小化真实标签分布和模型预测概率之间的 KL 散度——等同于最大化模型下标签的似然。神经网络训练就是最大似然估计。

#### 常见误解

ML 社区中一个普遍信念是深度学习与统计根本不同——神经网络"只是找模式"而没有任何统计假设。这不正确。每个神经网络都编码假设：假设类（架构）决定能表示哪种函数；损失函数决定优化什么误差度量；优化算法（带早停的 SGD）隐式正则化模型。这些都是统计选择，即使由工程师而非统计学家做出。"无统计假设"本身就是统计假设——且通常是错误的。

### 19.3 正则化即先验：完整图景

在第 17 章中，我们介绍了 Ridge 和 LASSO 正则化作为控制过拟合的方法。我们注意到它们可解释为特定先验下的 MAP 估计。现在我们可以使此联系完整并扩展到神经网络设置。

**每种正则化技术都编码关于模型复杂度的先验信念。**

#### Ridge = 高斯先验

Ridge 回归最小化 $\sum(y - f(x))^2 + \lambda\|\beta\|_2^2$。如第 17 章所示，这是每个系数独立 $\mathcal{N}(0, \sigma^2/\lambda)$ 先验下的 MAP 估计。先验说："我相信大多数系数很小。除非数据强烈要求否则向零收缩。"

#### LASSO = Laplace 先验

LASSO 回归最小化 $\sum(y - f(x))^2 + \lambda\|\beta\|_1$。这是 Laplace 先验下的 MAP：$p(\beta_j) \propto \exp(-\lambda|\beta_j|)$。Laplace 分布比正态在零处有更尖锐的峰和更重的尾部，这就是为什么 LASSO 将系数精确设为零（稀疏解）：先验要求我们相信大多数系数恰好为零。

#### Dropout = 贝叶斯模型平均

**Dropout** 是神经网络特有的正则化技术：在每个训练步骤中，以概率 $p$ 随机"丢弃"（置零）每个神经元。测试时，将权重缩放 $1-p$。

为何有效？直觉上，dropout 训练一个略有不同的网络集合（每个丢弃不同神经元）并平均其预测。平均减少方差——与统计中集成方法有效的相同原因（回忆第 17 章的偏差-方差权衡）。

更正式地，dropout 可解释为**变分贝叶斯推断**的一种形式：每个 dropout 掩码对应网络权重近似后验中的一个不同样本。测试时平均 dropout 掩码近似地对这些后验进行边际化。

Dropout 说："我对这个网络的确切权重不确定。我将把它们视为有分布并对该分布进行平均。"这是第 11 章线索 C 章节中的贝叶斯神经网络思想，现在作为简单工程技巧实现。

#### 早停 = 隐式正则化

**早停**意味着在模型完全收敛到最小训练损失之前停止训练。这也是正则化：早停使参数保持在初始值附近，有效惩罚远离初始值的解。

等价性精确：梯度下降的早停近似等价于 Ridge 正则化。训练步数扮演 $1/\lambda$ 的角色——更少步数对应更强正则化。

统计直觉：我们在零附近（或某个先验信念附近）初始化参数。随着训练进行，参数移离初始值以更好地拟合训练数据。早停意味着保持接近先验——恰是 Ridge 正则化所做的。

### 19.4 训练/验证/测试分割作为序列模型选择

ML 实践者普遍使用三向数据分割：

* **训练集**：用于拟合模型参数
* **验证集**：用于选择超参数（学习率、架构、正则化强度）
* **测试集**：使用一次，仅用于最终评估

为何三组？因为使用相同数据同时拟合和选择导致与使用训练误差评估模型相同的偏差。

这是微妙问题：如果我们通过选择在验证集上表现最好的配置来调超参数，我们实际上在拟合验证集。在验证上看起来最好的模型可能因偶然最好——碰巧在_这些_验证样本上表现好的超参数。我们报告的验证性能有乐观偏差。

测试集完全独立保留，仅触碰一次，以给出真实泛化的诚实估计。如果我们用测试集做任何决策（包括"我应该再试一个超参数吗？"），它变成第二个验证集并失去其完整性。
