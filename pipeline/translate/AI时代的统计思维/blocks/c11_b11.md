后验精度 = 先验精度 + 数据精度 = $1/\tau^2 + n/\sigma^2$。后验均值是先验均值与样本均值按精度加权的平均。

**答案：**

已知：$\mu_0 = 2.5$，$\tau^2 = 1$（先验方差），$\sigma^2 = 2.56$（已知方差），$n = 16$，$\bar{X} = 3.2$。

(a) 后验精度：

$\frac{1}{\tau_n^2} = \frac{1}{\tau^2} + \frac{n}{\sigma^2} = \frac{1}{1} + \frac{16}{2.56} = 1 + 6.25 = 7.25$

后验方差：$\tau_n^2 = 1/7.25 \approx 0.138$。后验标准差：$\tau_n \approx 0.371$。

后验均值：

$\mu_n = \tau_n^2 \times \left(\frac{\mu_0}{\tau^2} + \frac{n\bar{X}}{\sigma^2}\right) = 0.138 \times \left(\frac{2.5}{1} + \frac{16 \times 3.2}{2.56}\right) = 0.138 \times (2.5 + 20) = 0.138 \times 22.5 = 3.105$

后验：$\mu \mid \text{data} \sim \mathcal{N}(3.105, 0.138)$。

(b) 95% 可信区间：$\mu_n \pm 1.96\tau_n = 3.105 \pm 1.96 \times 0.371 = 3.105 \pm 0.728 \approx [2.38, 3.83]$ 秒。

这个区间具有贝叶斯解释：给定数据和先验，真实平均响应时间有 95% 的概率位于 2.38 到 3.83 秒之间。

(c) 当 $n = 100$ 时：

$\frac{1}{\tau_n^2} = 1 + \frac{100}{2.56} = 1 + 39.06 = 40.06$

后验方差：$\tau_n^2 \approx 0.025$，$\tau_n \approx 0.158$。

后验均值：

$\mu_n = 0.025 \times (2.5 + 125) = 0.025 \times 127.5 = 3.188$

后验均值（3.188）现在比起先验均值（2.5），更接近 $\bar{X} = 3.2$。后验可信区间：$3.188 \pm 1.96 \times 0.158 = [2.88, 3.50]$。

**这说明了什么**：当 $n = 16$ 时，先验（均值 2.5）有相当大的影响——后验均值（3.105）被明显拉向先验。当 $n = 100$ 时，数据压倒先验——后验均值（3.188）几乎与样本均值（3.2）相同。随着数据增多，后验可信区间也窄得多（宽度约 0.62，相比之下原来约为 1.45）。

这说明了贝叶斯推断的基本原则：在大样本下，无论先验如何，后验都会集中在数据附近。先验在数据稀少时最重要。
