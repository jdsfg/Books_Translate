逻辑回归是二项分布和 logit 链接的 GLM。

Poisson 回归是 Poisson 分布和对数链接的 GLM。

所有 GLM 都通过最大似然估计（第 6 章）——相同原则，应用于不同似然。

### 16.3 逻辑回归——建模二元结果

逻辑回归是预测二元结果（是/否、成功/失败、有病/无病）的主力工具。

#### Logit 链接和 Sigmoid 函数

关键约束：概率必须在 0 和 1 之间。我们需要一个将全实数轴（线性预测变量 $\eta$）映射到区间 $(0, 1)$ 的函数。

**logistic 函数**（也称 **sigmoid**）恰好做到此：

$$p = \sigma(\eta) = \frac{e^\eta}{1 + e^\eta} = \frac{1}{1 + e^{-\eta}}$$

当 $\eta \to \infty$：$p \to 1$。当 $\eta \to -\infty$：$p \to 0$。当 $\eta = 0$：$p = 0.5$。sigmoid 是将所有实数映射到 $(0, 1)$ 的 S 形曲线。

logistic 函数的逆是 **logit** 函数：

$$\text{logit}(p) = \log\left(\frac{p}{1-p}\right) = \eta$$

所以逻辑回归模型是：

$$\text{logit}(p_i) = \log\left(\frac{p_i}{1-p_i}\right) = \beta_0 + \beta_1 X_{1i} + \cdots + \beta_p X_{pi}$$

#### 定义：逻辑回归

二元结果 $Y_i \in \{0, 1\}$ 的**逻辑回归模型**为：

$$P(Y_i = 1 | X_i) = \sigma(\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p)}}$$

参数通过最大似然估计：找到最大化观测二元结果概率的 $\beta$ 值。

#### 对数优势和优势比

$p$ 的 logit 是**对数优势**：$\log(p/(1-p))$。事件的**优势**是 $p/(1-p)$——事件比其不发生可能多少倍？

例如，如果 $p = 0.75$（75% 概率）：优势 $= 0.75/0.25 = 3$（"三比一优势"）。

逻辑回归系数 $\beta_j$ 解释为 $X_j$ 增加一个单位时对数优势的变化：

$$e^{\beta_j} = \text{优势比（OR），} X_j \text{ 增加一个单位}$$

优势比为 2 意味着：$X_j$ 增加一个单位，事件的优势翻倍（保持其他变量不变）。优势比为 0.5 意味着：优势减半。

#### 例子：从风险因素预测疾病

逻辑回归从年龄（$X_1$）、BMI（$X_2$）和家族史（$X_3$，二元）预测 2 型糖尿病（是/否）：

$$\text{logit}(\hat{p}) = -7.5 + 0.04 X_1 + 0.12 X_2 + 1.3 X_3$$

解释：

* 年龄（$\beta_1 = 0.04$）：$e^{0.04} \approx 1.04$。每增加一岁年龄使糖尿病优势乘以约 4%——每年年龄优势增加 4%，保持 BMI 和家族史不变。
* BMI（$\beta_2 = 0.12$）：$e^{0.12} \approx 1.13$。每增加一个 BMI 单位使优势乘以 13%。
* 家族史（$\beta_3 = 1.3$）：$e^{1.3} \approx 3.67$。有糖尿病家族史使优势乘以 3.67——近四倍——与无家族史相比，保持年龄和 BMI 不变。
