在第 15 章中，我们建立回归模型时假定结果 Y 是一个连续数值，并且它与预测变量之间的关系是线性的。这些都是强有力的简化。但如果结果不是连续的呢？例如，患者是否存活、一场比赛进了多少球、或距离复发还有多少天？我们还能使用回归吗？

还有那些明显不是线性的关系怎么办？药物剂量-反应曲线常常显示收益递减。概率不能超过 1，因此任何预测概率的模型都必须受到约束。计数不能为负，因此把计数建模为正态分布会有问题（正态分布一直延伸到负无穷）。

这些局限推动了**广义线性模型**的发展。广义线性模型是一个统一框架，它把回归扩展到能够处理不同类型的结果以及不同形状的关系。广义线性模型把线性回归作为一个特例，并将其扩展到逻辑回归（二元结果）、泊松回归（计数结果）以及许多其他模型。

理解广义线性模型不只是一个技术练习。每个模型都编码了一个关于数据如何生成的故事，而选择错误的模型意味着讲述错误的故事。


### 16.1 线性回归在非连续结果上的局限

想象要预测一名贷款申请人是否会违约（0 = 否，1 = 是）。你可以尝试线性回归：Y_hat = b0 + b1 X。但预测值 Y_hat 可能小于 0 或大于 1，而这对于概率来说毫无意义。此外，线性回归假定误差方差恒定，但伯努利结果（0/1）的方差是 p(1 - p)，它会随 p 改变。

更根本地说，线性回归假定结果可以取任意实数值。概率必须位于 0 和 1 之间；计数必须是非负整数。把不合适的模型强行套到这些结果上，会产生在生物学或实践上不可能的预测。

解决方法是：使用**联系函数**，把线性预测子转换到合适的尺度上。


### 16.2 广义线性模型框架

广义线性模型把不同结果类型的回归统一在 3 个组成部分之下：


#### 定义：广义线性模型

一个广义线性模型规定：

1. **随机部分**：结果 Y 的概率分布（来自指数族：正态、二项、泊松等）。

2. **系统部分**：线性预测子 eta = beta0 + beta1 X1 + ... + betap Xp。

3. **联系函数** g：把期望值 mu = E[Y] 与线性预测子相连接的函数：g(mu) = eta。

反联系函数把线性预测子映射回均值：

mu = g^{-1}(eta) = g^{-1}(beta0 + beta1 X1 + ... + betap Xp)

这个框架表达的是：_结果具有某种特定分布，而该分布的均值是预测变量线性组合的某种（可能非线性的）函数_。

线性回归是具有正态分布和恒等联系的广义线性模型：g(mu) = mu，因此 mu = eta。

逻辑回归是具有二项分布和 logit 联系的广义线性模型。

泊松回归是具有泊松分布和 log 联系的广义线性模型。

所有广义线性模型都通过最大似然估计（第 6 章）来估计参数：同一个原则，应用到不同的似然函数上。
