**多样化评估**：而非单一基准，跨许多任务、领域和输入类型评估。在一切上表现优秀的模型不太可能是人为产物。

**污染测试**：检查模型在出现在训练数据中的基准问题上与未出现的是否表现不同。显著差异表明泄漏。

**效应量报告**：不仅报告准确度还报告基准比较的置信区间（第 7 章），考虑测试集样本量。500 题基准上 1% 改善在统计上与零不可区分。

### 21.6 线索 C 结论：AI 思维的统计

我们跟随线索 C 走过 21 章。它始于第 1 章 AI 可运行检验但不能提问的观察。它出现在本书每个主要部分。这里，在第 21 章，我们到达最终综述。

大语言模型在统计上做什么？

它执行**后验预测采样**——它从文本合理续写的隐式分布中采样，条件于它从训练语料学到的一切。这恰是贝叶斯统计学生成预测时做的：取先验（训练数据分布），在观测上下文（当前对话）上更新，从后验预测采样。

LLM 的先验编码在其权重中。更新由注意力机制执行，它允许模型条件于整个上下文窗口。预测是采样的 token。

这是统计上精密且计算上非凡的操作。模型可通过从此后验预测分布采样解决复杂问题。它对训练信号清晰的恰当问题的回答通常优秀。

**LLM 不能做什么，以及为什么：**

1. **知道自己不知道什么**：模型无法在没有显式不确定性量化的情况下区分其分布的高置信和低置信区域。

2. **因果推理**：模型学习的分布反映文本中的关联而非因果结构。它可以产生描述因果推理的文本，但不能执行 do-calculus（第 18 章）——它不能模拟干预。

3. **建立真实基准**：模型的分布条件于其训练数据，后者可能包含错误、偏见和过时信息。模型没有对真实基准的独立访问。

4. **提出正确问题**：模型回应给定的问题。它不评估问题是否恰当、是否有相关数据可回答、或此问题的答案是否是决策者实际需要的。这是人类统计学家角色。

人类统计学家贡献的，LLM 无法提供的：

* **问题构建**：我们应问什么因果问题？需要什么数据？此问题可回答吗？
* **假设审计**：i.i.d. 假设是什么？是否有分布偏移？是否有混杂因素？
* **不确定性沟通**：置信区间是什么？它们对决策意味着什么？
* **因果解释**：这是关联还是原因？如果我们干预会怎样？

AI 极大放大了统计学家的计算能力。它不替代统计判断。两者一起——AI 作为强大计算引擎，人类作为统计推理者——比任一单独更强大。

### 21.7 习题

#### 概念检查

**Q1.** 用统计术语解释为何大语言模型"幻觉"。为何它以与正确答案相同的自信散文产生错误答案？

**答：** 语言模型通过从学习的条件分布 $P(w_{k+1}|w_1,\ldots,w_k)$ 采样下一 token 生成文本。模型通过训练（MLE / 交叉熵最小化）从文本数据模式产生此分布。

对频繁观察的模式（"法国的首都是"），条件分布高度集中：大部分概率质量在"巴黎"上。模型可靠地采样正确 token。

对罕见观察的模式（"1872 年人口普查中巴黎的人口"），条件分布弥散：概率分散在许多合理数字上。模型采样一个——可能正确，可能不——且它以与生成任何其他 token 相同的方式生成此数字：通过采样。

**自信的散文不是对准确度的自信。**它是训练数据的默认风格。模型学到人类关于事实的写作以自信陈述。它在生成 token 时重现此风格，无论这些 token 来自集中还是弥散的分布。模型没有独立于其 token 概率分布的"我对此不确定"的表示——且该内部不确定性不在生成文本中表达。

这在统计上不可避免：点预测（采样的 token）不携带不确定性信息。模型产生样本；它不报告从中采样的分布形状。

**Q2.** 什么是保形预测？用通俗语言解释覆盖保证。为何此保证比模型简单报告自身置信度更强？

**答：** 保形预测是构建**预测集**——可能输出的集合——的方法，有真实答案被包含的严格统计保证。

**过程简述**：使用留出校准集表征模型错误通常有多"意外"（非一致性分数）。测试时，将每个"不比"$(1-\alpha)$ 最差校准错误"更意外"的可能答案纳入预测集。
