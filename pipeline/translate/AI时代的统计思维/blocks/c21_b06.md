$$s(x_{\text{new}}, y) = 1 - \hat{p}(y | x_{\text{new}}) \leq \hat{q}_{0.90} = 0.55$$

等价地，如果 $\hat{p}(y | x_{\text{new}}) \geq 1 - 0.55 = 0.45$ 则纳入标签 $y$。

对第一个示例：

* A：$\hat{p} = 0.60 \geq 0.45$ ✓ → 纳入
* B：$\hat{p} = 0.25 < 0.45$ ✗ → 排除
* C：$\hat{p} = 0.10 < 0.45$ ✗ → 排除
* D：$\hat{p} = 0.03 < 0.45$ ✗ → 排除
* E：$\hat{p} = 0.02 < 0.45$ ✗ → 排除

**预测集**：{A}。模型自信预测类别 A。

**(b) 覆盖保证**：在 $\alpha = 0.10$ 下，保形预测集以至少 $1 - \alpha = 0.90$ 的概率包含真实标签。对从与校准集相同分布抽取的至少 90% 测试案例，真实类别在预测集中。这是边际（总体级）保证：它在许多测试案例上平均成立，不一定对任何个别案例。

**(c) 第二个示例**：如果 $\hat{p}(y | x_{\text{new}}) \geq 0.45$ 则纳入标签 $y$。

* A：$\hat{p} = 0.98 \geq 0.45$ ✓ → 纳入
* B：$\hat{p} = 0.01 < 0.45$ ✗ → 排除
* C：$\hat{p} = 0.005 < 0.45$ ✗ → 排除
* D：$\hat{p} = 0.003 < 0.45$ ✗ → 排除
* E：$\hat{p} = 0.002 < 0.45$ ✗ → 排除

**预测集**：{A}。同样仅 A 被纳入。

**大小告诉你什么**：两个预测集都包含一个元素——但第二个示例的预测远更确定（概率 0.98 vs 0.60）。预测集大小相同（都仅含 A），但模型内部置信度差异显著。在此情况下，两者按保形标准都是"自信单标签预测"。如果阈值 $\hat{q}$ 更高（如 0.80，意味着允许非一致性分数到 0.80，或概率 ≥ 0.20），第一个示例的集会扩展包含 B，揭示其真正不确定性。第一个示例是边缘确定的；第二个是真正确定的。此阈值下的保形集对两者同等对待——单阈值方法的局限。自适应保形预测方法可解决此问题。

**Q2.** 一位研究者声称："我们的 LLM 在 MedQA 基准上达到 91.3% 准确度，以 1.6 个百分点超越先前最优（89.7%）。这证明我们的模型有更优的医学知识。"

识别此声明的所有统计顾虑。

**答：**

**顾虑 1——统计显著性未确立**：MedQA 包含 1273 道测试题。在 91.3% 准确度下，标准误约为 $\sqrt{0.913 \times 0.087 / 1273} \approx 0.008$（0.8%）。准确度的 95% CI 约为 $91.3\% \pm 1.6\%$，范围从 89.7% 到 92.9%。1.6 个百分点的改善约在统计显著性边界——两个模型的置信区间可能大幅重叠。"超越"的声明未明确统计支持。

**顾虑 2——多重比较/到处看效应**："先前最优"89.7% 本身是多次先前尝试的最佳结果。新声明 91.3% 反映（推测）多个模型变体和训练配置的最佳结果。比较混淆两个多次最佳结果而未校正多重比较。真正公平单一比较上的真实改善可能为零。

**顾虑 3——基准污染**：MedQA 问题公开可用。如果新模型在包含这些问题的互联网数据上训练，或在来自同源（USMLE 问题）的任何数据集上训练，91.3% 可能部分反映训练数据记忆而非真正医学推理。

**顾虑 4——"更优医学知识"的推断**：基准准确度衡量特定多选题集上的表现。它不衡量：校准（模型置信度水平是否可靠？）、开放式案例的临床推理质量、罕见或新颖病症上的表现、对分布偏移的稳健性（不同医院、不同问题表述），或安全性（模型在边缘案例中会给出危险建议吗？）。"更优医学知识"暗示广泛能力声明；单一基准准确度仅支持狭窄任务特定声明。

**顾虑 5——无不确定性量化**：模型达到 91.3%——但它在答错的问题上表现如何？它对困难案例表达不确定性吗，还是幻觉自信的错误答案？对医学应用，校准和不确定性量化（第 21.3 节）与准确度同等重要。

更谨慎的声明："在 MedQA 测试集上，我们的模型达到 91.3% 准确度（95% CI：89.7%-92.9%），相比先前报告最佳 89.7%。此改善虽统计上边际且可能被基准污染混淆，但值得在带校准评估的留出临床问题集上进一步评估。"

**Q2.** 一个医学 AI 系统使用保形预测（在教学医院 2,000 名患者上校准）产生诊断分类预测集。系统部署在服务非常不同人口统计群体的农村诊所。

(a) 保形预测的覆盖保证需要什么具体假设？此部署场景中此假设是否满足？(b) 如果校准集代表性不足老年患者（校准中 5% 老年 vs. 农村诊所 35% 老年），具体描述预测集对老年患者可能如何不同表现。(c) 一位放射科医生论证："如果覆盖保证无效，保形预测集无用。我们应该只用模型的原始概率。"评估此论点。(d) 提出对此部署情境更合适的保形预测方法修改。

**答：**

**(a) 所需假设**：保形预测的覆盖保证需要**可交换性**——校准示例和测试示例从同一分布抽取（更精确地，校准+测试的完整集可交换，意味着任何排列等可能）。当校准和测试数据来自同一总体时近似满足。

此部署场景中：**假设不满足**。校准数据来自教学医院总体，而测试数据来自人口统计、疾病患病率、病例组合和可能不同成像设备和扫描协议非常不同的农村诊所。从教学医院总体推导的非一致性分数不能正确表征农村诊所患者的错误有多"意外"。
