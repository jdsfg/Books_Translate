#### 应用题

**Q1.** 一个分类模型在 5 个类别中进行预测。在包含 500 个样本的校准集上，非一致性分数 $s_i = 1 - \hat{p}(y_i | x_i)$ 的范围从 0.02 到 0.97。校准非一致性分数的第 90 百分位数为 $\hat{q}_{0.90} = 0.55$。

(a) 对于一个新样本，模型给出的概率为：类别 A = 0.60，B = 0.25，C = 0.10，D = 0.03，E = 0.02。在 $\alpha = 0.10$ 下构造保形预测集合。(b) 覆盖保证是什么？(c) 另一个新样本得到的概率为：A = 0.98，B = 0.01，C = 0.005，D = 0.003，E = 0.002。它的预测集合是什么，集合大小告诉你什么？

提示

每个标签 $y$ 的非一致性分数是 1 减去该标签的预测概率。如果该标签的非一致性分数 $\leq$ 校准分位数，就包含该标签。

**答案：**

**(a) 预测集合构造**：如果标签 $y$ 满足以下条件，就把它包含在 $C(x_{\text{new}})$ 中：

$s(x_{\text{new}}, y) = 1 - \hat{p}(y | x_{\text{new}}) \leq \hat{q}_{0.90} = 0.55$

等价地，如果 $\hat{p}(y | x_{\text{new}}) \geq 1 - 0.55 = 0.45$，就包含标签 $y$。

对于第1个样本：

* A：$\hat{p} = 0.60 \geq 0.45$ → 包含
* B：$\hat{p} = 0.25 < 0.45$ → 排除
* C：$\hat{p} = 0.10 < 0.45$ → 排除
* D：$\hat{p} = 0.03 < 0.45$ → 排除
* E：$\hat{p} = 0.02 < 0.45$ → 排除

**预测集合**：{A}。模型自信地预测类别 A。

**(b) 覆盖保证**：在 $\alpha = 0.10$ 下，保形预测集合以至少 $1-\alpha = 0.90$ 的概率包含真实标签。对于至少 90% 的、与校准集来自同1分布的测试案例，真实类别会在预测集合中。这是1个边际（总体层面）保证：它在许多测试案例的平均意义上成立，而不一定适用于任何单个案例。

**(c) 第2个样本**：如果 $\hat{p}(y | x_{\text{new}}) \geq 0.45$，就包含标签 $y$。

* A：$\hat{p} = 0.98 \geq 0.45$ → 包含
* B：$\hat{p} = 0.01 < 0.45$ → 排除
* C：$\hat{p} = 0.005 < 0.45$ → 排除
* D：$\hat{p} = 0.003 < 0.45$ → 排除
* E：$\hat{p} = 0.002 < 0.45$ → 排除

**预测集合**：{A}。同样只有 A 被包含。

**集合大小告诉你什么**：两个预测集合都只包含 1 个元素——但第2个样本的预测确定性要高得多（概率 0.98 vs. 0.60）。预测集合大小相同（都只包含 A），但模型的内部信心差异很大。在这个例子中，按保形准则，两者都是“有信心的单标签预测”。如果阈值 $\hat{q}$ 更高（例如 0.80，意味着我们允许非一致性分数最高到 0.80，或者概率 $\geq 0.20$），第1个样本的集合会扩展为包含 B，从而显示其真正的不确定性。第1个样本处在确定性的边界；第2个样本则确实确定。这个阈值下的保形集合把它们同等对待——这是单阈值方法的1个局限。自适应保形预测方法可以处理这个问题。
