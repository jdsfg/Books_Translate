#### 概念检查

**Q1.** 广义线性模型的 3 个组成部分是什么？解释逻辑回归如何符合这个框架。

**答案：** 广义线性模型的 3 个组成部分是：

1. **随机部分**：对 Y 所假定的概率分布。对于逻辑回归：二项分布（每个结果都是概率为 p 的独立伯努利试验）。

2. **系统部分**：线性预测子 eta = beta0 + beta1 X1 + ... + betap Xp，它是预测变量的线性组合。

3. **联系函数**：连接均值 mu = E[Y] 与线性预测子 eta = g(mu) 的函数 g。对于逻辑回归：logit 联系 g(mu) = log(mu / (1 - mu))。

逻辑回归作为广义线性模型可以写成：Y_i ~ Binomial(n = 1, p_i)（伯努利），线性预测子为 eta_i = beta0 + beta1 X1 + ... + betap Xp，联系函数为 eta = logit(p) = log(p / (1 - p))。反联系函数映射回概率：p = 1 / (1 + e^{-eta})。

**Q2.** 在逻辑回归中，e^{beta_j} 表示什么？你会如何解释 e^{beta_j} = 1.5 和 e^{beta_j} = 0.6？

**答案：** e^{beta_j} 是预测变量 X_j 增加 1 个单位时的**优势比**（OR），这里所有其他预测变量保持不变。

e^{beta_j} = 1.5：X_j 增加 1 个单位与事件优势增加 50% 相关（从优势角度看，事件变为 1.5 倍可能）。例如，如果疾病的基线优势是 1:3（25% 概率），X_j 增加 1 个单位后，优势变为 1.5:3 = 1:2（33% 概率）。

e^{beta_j} = 0.6：X_j 增加 1 个单位与事件优势降低 40% 相关（乘以 0.6 会降低优势）。如果基线优势为 1:1（50% 概率），增加 1 个单位后的优势是 0.6:1，对应概率 0.6 / 1.6 = 37.5%。

重要提醒：优势比不是相对风险。对于罕见事件（概率 < 10%），e^beta approx 相对风险。对于常见事件，e^beta 会显著高估相对风险。

**Q3.** 一名研究者拟合泊松回归来建模每年急诊就诊次数，并发现二元变量“患有糖尿病”的系数为 0.15。解释这个系数。

**答案：** 系数 0.15 表示：在模型中所有其他变量保持不变时，患有糖尿病的患者预期急诊就诊次数是没有糖尿病患者的 e^{0.15} approx 1.162 倍。

用通俗语言说：在控制模型中的其他预测变量后，糖尿病与年度急诊就诊预期次数高约 16.2% 相关。

举例来说：如果没有糖尿病的患者每年预期急诊就诊 2.0 次，那么患有糖尿病的患者预期为 2.0 x 1.162 approx 2.32 次/年，即每年约多 0.32 次。

注意：由于 log 联系，泊松系数在计数尺度上具有乘法解释，这不同于线性回归系数的加法解释。
