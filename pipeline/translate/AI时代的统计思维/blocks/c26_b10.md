#### 应用题

**Q1.** 一个生物信息学团队正在用基因表达数据预测癌症复发。他们有 n = 150 名患者和 p = 20,000 个基因表达特征。

(a) 解释为什么 OLS 回归在这个情形中不可能。 (b) 比较这个问题中的 LASSO 和 Ridge——你更倾向于哪一个，为什么？ (c) 团队使用 LASSO，并发现47个基因具有非零系数。他们应该如何验证这47个基因确实具有预测性，而不是选择过程的产物？

提示

思考：自由度、基因组稀疏性假设、过拟合，以及变量选择和已确认预测因子之间的区别。

**答案：**

**(a) 为什么 OLS 不可能**：

OLS 最小化 ||y - Xβ||_2^2，并需要求解 (X'X)β = X'y。当 p = 20,000 > n = 150 时，矩阵 X'X 是 20,000 × 20,000 的，但秩至多为 n - 1 = 149。它是奇异的——不可逆。OLS 没有唯一解；相反，有无穷多个解，并且都能完美拟合训练数据（无论选择哪个 β，训练误差都等于0）。这些解都无法泛化到新患者。

直观地说：有20,000个自由度却只有150个观测值，我们可以在20,000维空间中为任意有限的150个点拟合一个精确通过它们的平面。模型记住了训练数据，但没有学到任何关于底层生物学的东西。

**(b) 基因表达问题中的 LASSO 与 Ridge**：

在这个情形中**更倾向于 LASSO**，原因有2个：

  1. **科学上的稀疏性假设**：癌症复发通常由少数具有生物学相关性的通路和基因改变驱动。与 Ridge 的“许多小效应”假设相比，LASSO 的“少数大效应”假设在生物学上更合理。20,000个基因中的大多数很可能与特定癌症类型的复发无关。

  2. **可解释性**：如果目标是识别哪些基因预测复发（用于临床应用、生物学后续研究或生物标志物开发），LASSO 的变量选择会给出候选基因列表。Ridge 会为所有20,000个基因给出小的非零系数——在模型层面可解释，但对识别哪些基因具有生物学意义帮助不大。

如果研究问题只是纯粹的预测准确率，而不关心哪些基因驱动预测，Ridge（或弹性网）可能更稳健（尤其是在基因表达存在许多相关簇时）。

**(c) 对47个被选择基因的验证**：

LASSO 选择出的47个基因是候选基因，而不是已确认的预测因子。LASSO 选择是在训练数据上完成的，而选择过程本身会夸大被选变量的表观重要性。需要担心的问题包括：

**担忧1——系数估计中的选择偏差**：LASSO 所选变量的系数会向上偏，因为它们被选择，部分原因是它们碰巧拟合了训练数据。这就是“赢家诅咒”——被选变量在选择数据集中看起来比在新数据中更重要。

**担忧2——多重比较**：在检查20,000个基因时，即使没有 p-hacking，也很可能有一些基因被偶然地虚假选中。
