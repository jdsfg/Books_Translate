#### 定义：可信区间

一个 **$(1-\alpha)$ 可信区间**（也称为贝叶斯区间或后验区间）是一个区间 $[L, U]$，使得：

$P(L \leq \theta \leq U | \text{data}) = 1 - \alpha$

用普通语言说：给定数据和先验，参数落在这个区间内的概率为 $(1-\alpha)$。

这**就是**置信区间使用者通常想要但不能做出的概率陈述（第 7 章）。可信区间可以直接解释：“真实点击率在 13% 到 37% 之间的概率为 95%。”

**与频率派 CI 的比较**：

|  | 置信区间 | 可信区间 |
|---|---|---|
| 解释 | 95% 的这类区间（跨许多样本）包含真实参数 | 真实参数位于这个区间内的概率为 95% |
| 需要先验？ | 否 | 是 |
| 允许关于 $\theta$ 的概率陈述？ | 否 | 是 |
| 大数据时 | 数值上与可信区间相似 | 数值上与 CI 相似 |
| 小数据时 | 可能校准很差 | 严重依赖先验 |

#### 常见误解

**误解：贝叶斯可信区间只是“更好”的置信区间——它们给出相同的解释，但有更多自由。**

这在一定程度上是对的（可信区间有更自然的解释），但忽略了一个限定条件：可信区间只相对于先验才是正确的。一个 95% 可信区间是在给定先验和数据的情况下具有 95% 后验概率。如果先验是错的，可信区间可能不具有良好的频率派覆盖性质。

例子：如果你使用一个非常有信息量、且远离真实值的先验，后验会被拉离真值，可信区间在重复抽样中可能不会有 95% 的时间包含真实值。贝叶斯可信区间以使解释更直观为收益，代价是把先验有效性的假设变得明确且具有约束力。

对于大样本，这一区别偏于学术性——数据会压倒任何合理的先验。对于小样本和强先验，它极其重要。贝叶斯使用者必须为先验辩护；频率派使用者只需为抽样程序辩护。
