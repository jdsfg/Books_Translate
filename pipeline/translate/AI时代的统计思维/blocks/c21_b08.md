#### 概念检查

**Q1.** 用统计术语解释为什么大语言模型会“幻觉”。为什么它会用与正确答案相同的自信文字生成错误答案？

**答案：**语言模型通过从学得的条件分布 $P(w_{k+1} | w_1,\ldots,w_k)$ 中采样下1个 token 来生成文本。模型通过 MLE / 交叉熵最小化训练，从文本数据中的模式生成这个分布。

对于频繁观测到的模式（“法国的首都是”），条件分布高度集中：大部分概率质量都在“巴黎”上。模型会可靠地采样到正确 token。

对于罕见观测到的模式（“1872年人口普查中巴黎的人口”），条件分布是弥散的：概率分散在许多看似合理的数字上。模型会采样其中1个——可能正确，也可能不正确——而它生成这个数字的方式与生成其他任何 token 的方式相同：通过采样。

**自信的文字并不是对准确性的信心。** 它是训练数据的默认风格。模型学到的是，人类关于事实的写作通常以自信方式陈述。它在生成 token 时会复现这种风格，无论这些 token 来自集中分布还是弥散分布。除了 token 概率分布之外，模型没有“我对此不确定”的独立表示——而这种内部不确定性不会在生成文本中表达出来。

这在统计上不可避免：点预测（被采样的 token）不携带不确定性信息。模型生成1个样本；它并不报告自己是从什么形状的分布中采样的。

**Q2.** 什么是保形预测？用通俗语言解释覆盖保证。为什么这种保证比模型单纯报告自身信心更强？

**答案：**保形预测是1种构造**预测集合**的方法——预测集合是一组可能输出——并带有严格的统计保证：真实答案被包含在其中。

**流程简述**：使用留出的校准集刻画模型错误通常有多“意外”（非一致性分数）。在测试时，把所有“不比”第 $(1-\alpha)$ 个最差校准错误“更意外”的可能答案都纳入预测集合。

**覆盖保证的通俗说法**：在至少 $1-\alpha$ 的所有测试问题中（例如，如果 $\alpha = 0.05$，则为 95%），真实答案会包含在预测集合中。这是1个频率学派保证：它关心许多测试案例上的长期覆盖频率。

**为什么强于自报信心**：模型自报的信心（例如，“我有 90% 把握答案是 X”）可能未校准——模型可能在报告 90% 信心的情况下实际上只有 60% 正确率（过度自信）。这要求我们相信模型的内部校准，而这种校准可能很差。

保形预测的保证来自留出数据，而不是模型的内部表示。校准集对模型实际错误率提供经验刻画。由此产生的覆盖保证不管模型原始概率有多么未校准都成立，只要求校准数据和测试数据具有可交换性（从同1分布中抽取）。保证针对的是流程本身，而不是要求我们相信模型的自我评估。
