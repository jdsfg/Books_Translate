### 14.5 现代 MCMC——哈密顿蒙特卡洛

Metropolis-Hastings 算法在概念上很优雅，但对于复杂、高维后验来说计算效率不高。现代贝叶斯计算使用更复杂的算法。

**哈密顿蒙特卡洛（HMC）**使用梯度信息——对参数而言的对数后验导数——来提出更高效的提议。HMC 不是提议随机的小步移动，而是模拟一个粒子在保守的“哈密顿”力作用下穿过后验地形的动力学。粒子沿着能够高效穿越后验的轨迹运动，在保持高接受率的同时迈出大步。

**No-U-Turn Sampler（NUTS）** 是 HMC 的自适应扩展，也是 Stan 和 PyMC（两个广泛使用的概率编程系统）背后的算法。NUTS 会自动调节步长和轨迹长度，因此无需大量手动调参，也能适用于广泛模型。

结果是：HMC/NUTS 能够高效地从数百维或数千维的后验中抽样，使复杂模型的贝叶斯分析在计算上可行。


### 14.6 概率编程——作为计算的统计

MCMC 算法与现代软件的结合产生了**概率编程语言**——这类系统允许分析者用代码指定统计模型（先验 + 似然），并自动推断后验。

流行系统包括：**Stan**（C++ 后端，提供 R 和 Python 接口）、**PyMC**（Python）、**TensorFlow Probability**、**Pyro**（基于 PyTorch）。

在 Stan 中（伪代码）：
    
    parameters {
      real mu;       // 均值参数
      real<lower=0> sigma;   // 标准差（必须为正）
    }
    model {
      mu ~ normal(0, 10);    // 先验
      sigma ~ exponential(1); // 先验
      y ~ normal(mu, sigma); // 似然
    }
    

Stan 读取这个模型规范，自动计算对数后验的梯度（使用自动微分），运行 NUTS 抽样，并返回后验样本。分析者编写统计模型；系统处理计算细节。

这就是“编译器”类比：统计学家编写模型（“源代码”），概率编程系统把它编译成高效的抽样算法（“可执行程序”）。这种分工使得一度在计算上不可行的模型，如今也能进行贝叶斯分析。
