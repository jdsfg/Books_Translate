模型选择的目标是找到"恰好"的模型复杂度——足够复杂以捕获真实模式，足够简单以不追逐噪声。

#### 训练误差 vs. 测试误差

基本诊断：

**训练误差**：模型在用于拟合的数据上的预测误差。这随模型复杂度增加总是减少——更复杂的模型总能至少和更简单的模型一样好地拟合训练数据。

**测试误差**：模型在从未见过的新数据上的预测误差。这随模型复杂度增加而减少（更少偏差），但然后随过拟合开始而再次增加（更多方差）。测试误差曲线的最小值识别最优模型复杂度。

训练误差和测试误差之间的差距是过拟合的标志。训练误差为 0 而测试误差为 50 的模型没有学到关于总体的任何东西——它记住了训练样本。

### 17.2 偏差-方差分解

**偏差-方差权衡**数学上形式化了过拟合-欠拟合张力。

对于在新输入 $X_0$ 处预测 $Y$ 的回归模型，期望预测误差可分解为：

$$\text{期望预测误差} = \text{偏差}^2 + \text{方差} + \text{不可约误差}$$

**偏差**：估计量的系统误差。期望预测离真实值多远？遗漏真实非线性结构的模型有高偏差——它在一致、系统的方向上错误。

**方差**：预测跨不同训练数据集的变异性。复杂模型学习每个训练数据集的特定怪癖；当训练数据变化时其预测大幅变化。高方差意味着模型不稳定。

**不可约误差**（$\sigma^2$）：数据中任何模型都无法预测的噪声。即使最好的模型也无法比内在随机性更好地预测 $Y$。

#### 定义：偏差-方差分解

$$\text{MSE}(\hat{f}(X_0)) = \left[\text{Bias}(\hat{f}(X_0))\right]^2 + \text{Var}(\hat{f}(X_0)) + \sigma^2$$

其中：

* $\text{Bias}(\hat{f}(X_0)) = E[\hat{f}(X_0)] - f(X_0)$ 是系统误差
* $\text{Var}(\hat{f}(X_0)) = E[\hat{f}(X_0)^2] - (E[\hat{f}(X_0)])^2$ 是预测方差
* $\sigma^2$ 是不可约噪声

用通俗语言说：

* **简单模型**：高偏差（平均上错误——太僵硬无法捕获真实形状），低方差（预测跨数据集稳定）
* **复杂模型**：低偏差（能适应真实形状），高方差（不稳定——过拟合训练数据）

最优模型最小化偏差²和方差之和——在两种误差之间权衡。

#### 射箭比喻

将偏差和方差想象为两种射箭失败：

* **高偏差，低方差**：箭都聚集在一起，但都击中靶的错误部分。一致地错。
* **低偏差，高方差**：箭平均居中于靶上，但散布各处。平均正确，不可预测。
* **理想**：箭聚集在靶上。低偏差且低方差。
* **高偏差，高方差**：散布且居中于错误位置。两种世界的最差（非常错误指定的复杂模型的特征）。

#### 常见误解

**误解：最好的模型是最能拟合训练数据的模型。**

这对复杂模型恰好相反。完美拟合训练数据的模型训练误差 = 0，但测试误差可能巨大。训练数据是来自总体的样本；过拟合样本意味着模型学习了样本的特性而非总体的模式。

预测模型的正确评估标准始终是测试误差——在模型从未见过的数据上的表现。训练误差衡量模型记住了多少；测试误差衡量模型学到了多少。
