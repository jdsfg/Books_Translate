**Q2.** 二项比例 $p$ 的 Jeffreys 先验是 $\text{Beta}(1/2, 1/2)$，它在 0 和 1 附近比 0.5 附近分配更多概率密度。这可能看起来奇怪——"无信息"先验不应该是平坦的吗？

(a) 为什么 Jeffreys 先验在比例的 0 和 1 附近分配更多密度？（提示：思考极端值附近 vs. 0.5 附近的 Fisher 信息是什么。）

(b) 假设你正在测试一种非常罕见疾病的新检测。你相信患病率可能低至 0.1% 或高至 50%。Jeffreys 先验在此比均匀先验更有意义还是更少意义？解释。

(c) 对于大多数实际问题，Jeffreys 先验、均匀先验和 $\text{Beta}(1,1)$（也是均匀）先验之间的选择重要吗？何时重要？

**讨论：**

(a) Jeffreys 先验正比于 $\sqrt{I(p)}$，其中二项分布的 $I(p) = 1/(p(1-p))$。所以 $\sqrt{I(p)} \propto 1/\sqrt{p(1-p)}$，当 $p$ 接近 0 或 1 时大，接近 0.5 时小。直觉：当 $p$ 接近 0 或 1 时，大多数观测给出相同结果（全 0 或全 1），所以数据中变化很少——关于 $p$ 确切值的 Fisher 信息低。Jeffreys 先验通过在这些低信息区域放置更多先验质量来补偿，确保先验相对于数据能告诉你的东西更"分散"。

(b) 对于非常罕见的疾病（患病率可能低至 0.1%），Jeffreys 先验（$\text{Beta}(1/2, 1/2)$）在 0 附近放置大量先验概率。这很好地匹配了场景——它不假设患病率接近 50%。均匀先验（$\text{Beta}(1,1)$）对患病率 = 0.1% 和患病率 = 50% 分配等概率密度，对于已知罕见的疾病似乎不太适当。在此情况下，Jeffreys 先验可以说比均匀先验更合理。

(c) 对于大多数中到大样本的实际情境，$\text{Beta}(1/2, 1/2)$、$\text{Beta}(1,1)$ 甚至 $\text{Beta}(2,2)$ 作为比例先验的选择很少重要。有 50+ 观测时，数据压倒这些弱信息先验中的任何一个，后验几乎相同。选择最重要时：(i) 样本量非常小（$n < 10$），(ii) 参数接近边界（接近 0 或 1），或 (iii) 你在计算敏感依赖尾部区域先验的量（如极端分位数）。在检测少且疾病罕见的筛查场景中，先验选择可能影响很大——而 Jeffreys 先验在理论上更有理有据。

### 本章小结

选择先验分布是贝叶斯推断最具争议的方面，也是其最有力异议的来源。先验从无信息（平坦）到弱信息（排除不合理的值）到强信息（纳入大量先验知识）。

无信息先验并非真正无假设：平坦性依赖参数化（参数化问题），且平坦先验可能暗示不合理的数据分布。Jeffreys 先验通过 Fisher 信息不变性解决参数化问题。弱信息先验——现代贝叶斯分析的实用默认——编码实质合理性但不强烈约束后验。

先验预测检查评估先验（结合似然）是否会生成合理数据。先验敏感性分析确定结论是否关键依赖先验选择。这些工具共同将先验选择从主观猜测转变为结构化、可辩护的过程。

经验贝叶斯使用数据估计先验超参数，将贝叶斯推断与分层建模连接。其主要局限——低估不确定性——应被理解和报告。

主观性异议有真实力量但可以回答：所有推断都涉及假设；明确假设可以被辩论；大数据压倒先验；先验透明性使富有成效的科学对话成为可能。

在下一章中，我们退后一步诚实地比较贝叶斯和频率派推断——不是作为圣战而是作为工具箱问题：哪种方法在哪种情境中出色，为什么务实的统计学家会两者都用？

## 第 13 章：贝叶斯 vs. 频率派——诚实的比较

在 20 世纪大部分时间里，贝叶斯-频率派之争是一场真正的思想战争。频率派争辩贝叶斯推断不科学——主观先验在追求客观知识中没有位置。贝叶斯争辩频率派推断不连贯——在假设重复上校准的程序告诉你关于你实际运行的特定实验的什么。

杰出统计学家写了长篇的、有时轻蔑的批评对方阵营的文章。学生被教导选择一方。这场辩论产生的热量比 20 世纪科学中几乎任何其他方法论争端都多。

当前共识——大多数工作统计学家持有但并非普遍——大致是：两个框架都是工具，不是宗教。每个都有对方缺乏的真实优势。每个都有对方避免的失败模式。务实的统计科学家两者都用，知道在哪种情境中使用哪种，且不混淆哪种解释适用于何时。

本章诚实地进行比较，不宣布赢家。

### 13.1 哲学分歧

贝叶斯和频率派推断之间最深的差异在于概率的含义。

**频率派概率**由长期频率定义。当频率派说"此 95% 置信区间 95% 的时间包含真实参数"时，她意味着：如果我们在相同条件下无限次重复研究，构造的区间将在 95% 的重复中包含真实参数。概率是程序的属性，不是特定结果的。

**贝叶斯概率**由信念程度定义。当贝叶斯说"参数在此可信区间内的后验概率为 95%"时，她意味着：给定先验信念和数据，我将 95% 的概率质量分配给此区间。概率是认知主体知识状态的属性。

这些是真正不同的对象。频率派不能对特定未知量做概率陈述（如"此药物有效的概率"），因为只有一个真相——药物要么有效要么无效，没有自然的"长跑"来计算频率。贝叶斯可以做此类陈述，但它们依赖先验信念。

实践中，大多数科学家想要贝叶斯陈述（药物有效的概率）但使用频率派工具（p 值、置信区间）。此错配是第 7 章和第 8 章中编目的误解的来源。
