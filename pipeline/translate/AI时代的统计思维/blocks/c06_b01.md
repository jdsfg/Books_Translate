在上一章中，我们证明了样本均值收敛到真实均值。但这引出了一个我们悄悄略过的问题：我们试图估计的"真实均值"是什么？它从何而来？为什么样本均值是正确的估计量——有没有替代方案，它们可能更好吗？

这些是关于**估计**的问题，它们比看起来更微妙。

考虑这个：你想估计一个城市的家庭收入中位数。你调查了 200 个家庭并计算样本均值收入。样本均值是总体收入中位数的正确估计量吗？（不是——样本均值和样本中位数都是不同总体参数的估计量。）如果你认为收入分布是偏斜的呢？如果你想要一个对少数极高收入异常值稳健的估计量呢？

或者考虑这个：你想估计给定人口统计特征的客户点击广告的概率。你观察了 50 个来自特定群体的客户，发现 3 个点击了。你的估计是 3/50 = 6%。但 6% 是最好的估计吗？贝叶斯方法——纳入关于类似群体点击率的先验知识——能给你更好的答案吗？

本章发展了思考估计的概念框架：什么使一个估计量好，存在哪些替代方案，以及自助法如何给我们一种极为通用的方法来量化任何估计量的不确定性。

### 6.1 参数与估计量

首先要弄清的区别是我们想知道什么和我们如何估计它。

#### 定义：参数

**参数**是总体或数据生成过程的数值特征。它是我们想了解的真相。参数通常是未知的和不可观测的——它们描述整个总体，而我们永远无法完全观测总体。

例子：

* $\mu$：一个国家所有成年人的真实平均身高
* $p$：随机选取的选民偏好候选人 A 的真实概率
* $\beta$：学习时间与考试分数之间关系的真实斜率（在总体中）
* $\sigma^2$：所有患者血压测量的真实方差

#### 定义：估计量

**估计量**是样本数据的函数，我们用它来对参数做猜测。它是一个配方："这是如何从你的样本中计算一个数字，我们希望它接近参数。"

将估计量应用于特定数据集的结果是一个**估计值**——一个单独的数字。估计量（作为函数）是一个随机变量，因为它的值在从同一总体抽取的不同样本间变化。

记号约定：我们通常对估计量使用"帽子"记号。$\hat{\mu}$ 是 $\mu$ 的估计量，$\hat{p}$ 是 $p$ 的估计量。

例子：

* **样本均值** $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$ 是 $\mu$ 的估计量
* **样本比例** $\hat{p} = k/n$（其中 $k$ 是成功次数）是 $p$ 的估计量
* **样本中位数**是总体中位数的估计量
* **样本方差** $s^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$ 是 $\sigma^2$ 的估计量

同一参数的不同估计量可以有不同的性质。这是估计理论的核心问题：你应该使用哪个估计量，什么使一个比另一个更好？
