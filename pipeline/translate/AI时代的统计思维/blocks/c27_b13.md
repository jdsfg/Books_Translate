(a) 假设 SD = 5 kg，计算 n = 12000 时 0.3 kg 效应的 95% 置信区间。这个 CI 传达了什么？(b) 用一段话说明你会如何改写文章标题和前两句话，以诚实地沟通这一发现。(c) 原文章违反了第 27 章的哪些沟通原则？

提示

对于 (a)：使用 SE = SD / sqrt(n) 计算均值的标准误；或对于两组差异，使用 SE ≈ SD × sqrt(2 / n)，其中 n 为每组样本量。

**答案：**

**(a) 置信区间**：

对于两个规模相等的组（每组 n/2 = 6000）且每组 SD = 5 kg 的比较：

SE = sqrt(5^2 / 6000 + 5^2 / 6000) = sqrt((25 + 25) / 6000) = sqrt(50 / 6000) = sqrt(0.00833) ≈ 0.0913。

95% CI：-0.3 ± 1.96 × 0.0913 = -0.3 ± 0.179 = (-0.48, -0.12) kg。

95% CI 从 -0.48 到 -0.12 kg——这是围绕一个微小效应的微小区间。狭窄的 CI 告诉我们：在 12000 名参与者中，平均体重差异估计得非常精确。它几乎肯定不是 0。但它也几乎肯定非常小——不到半公斤。

**这传达了什么**：效应是真实的（不包含 0），但小到微不足道。统计精度很高；实际重要性可以忽略。0.3 kg 的差异（约半磅）是 1 年自报体重变化中的差异，低于测量噪声，没有实际饮食意义。

**(b) 诚实改写**：

**标题**：“观察性研究发现早餐与 12000 名成年人体重之间存在小幅关联”

**前两句话**：“一项针对 12000 人的自报调查研究显示，报告每天吃早餐的成年人在 1 年后平均比不吃早餐者少重 0.3 kg（0.7 磅）。然而，这一效应太小，不具有临床意义；研究设计无法确定因果关系——该样本中的吃早餐者也更多运动且收入更高——而且自报体重测量存在相当大的误差。”

**(c) 违反的沟通原则**：

**原则 1——没有因果证据却使用因果语言**：“发现吃早餐的人减重更多”暗示吃早餐导致减重。该研究是观察性的，存在多个未测量混杂因素（运动、收入、睡眠）。违规之处是对关联性发现使用因果语言（“吃早餐减重”）。

**原则 2——只有显著性，没有实际重要性**：报告 p < 0.001 却不报告效应大小（0.3 kg），会让读者推断一个非常显著的结果必定很重要。文章违反了始终在显著性旁报告效应大小的原则。

**原则 3——未能分解混杂因素**：文章省略了吃早餐者与不吃早餐者在运动、睡眠和收入方面也不同——这些都会独立影响体重。诚实报告要求披露这些混杂因素，并承认在观察性研究中它们无法被完全控制。
