### 16.3 逻辑回归——建模二元结果

逻辑回归是预测二元结果（是/否、成功/失败、有病/无病）的主力工具。


#### Logit 联系与 Sigmoid 函数

关键约束是：概率必须位于 0 和 1 之间。我们需要一个函数，把整条实数轴（线性预测子 eta）映射到区间 (0, 1)。

**逻辑函数**（也称为 **sigmoid**）正好做到这一点：

p = sigma(eta) = e^eta / (1 + e^eta) = 1 / (1 + e^{-eta})

当 eta -> infinity 时，p -> 1。当 eta -> -infinity 时，p -> 0。当 eta = 0 时，p = 0.5。Sigmoid 是一条 S 形曲线，把所有实数映射到 (0, 1)。

逻辑函数的反函数是 **logit** 函数：

logit(p) = log(p / (1 - p)) = eta

因此，逻辑回归模型是：

logit(p_i) = log(p_i / (1 - p_i)) = beta0 + beta1 X_{1i} + ... + betap X_{pi}


#### 定义：逻辑回归

对于二元结果 Y_i in {0, 1}，**逻辑回归模型**为：

P(Y_i = 1 | X_i) = sigma(beta0 + beta1 X1 + ... + betap Xp) = 1 / (1 + e^{-(beta0 + beta1 X1 + ... + betap Xp)})

参数通过最大似然估计得到：寻找使观测到的二元结果出现概率最大的 beta 值。


#### 对数优势与优势比

p 的 logit 是**对数优势**：log(p / (1 - p))。一个事件的**优势**是 p / (1 - p)，表示该事件相对于不发生而言有多可能。

例如，如果 p = 0.75（75% 的概率），则优势 = 0.75 / 0.25 = 3（“3 比 1 的优势”）。

逻辑回归系数 beta_j 被解释为 X_j 增加 1 个单位时对数优势的变化：

e^{beta_j} = X_j 增加 1 个单位对应的优势比（OR）

优势比为 2 意味着：在其他变量保持不变时，X_j 增加 1 个单位，事件的优势翻倍。优势比为 0.5 意味着：优势减半。
