### 本章小结

回归是建模响应变量 $Y$ 与一个或多个预测变量 $X_1, \ldots, X_p$ 之间关系的统计框架。OLS 找到最小化残差平方和的系数；在正态误差下，这等价于最大似然估计。

多元回归中的斜率系数有特定、精确的解释：$X_j$ 增加一个单位时 $Y$ 的预期变化，保持所有其他纳入变量不变。此"保持不变"是使用回归理清关系的关键——但它只控制测量的、纳入的变量。未测量的混杂因素仍可使系数有偏。

混杂因素创建虚假关联：同时导致预测变量和结果的变量膨胀或反转表观关系。多元回归控制测量的混杂因素；随机实验消除未测量的。

多重共线性——预测变量间高相关——使个体系数估计不稳定但不影响整体预测质量。VIF 诊断识别问题情况。

独立性假设关键且常在聚类数据中被违反。忽视聚类内相关大幅低估标准误差，产生虚假信心和膨胀的显著性。

线索 B：混杂因素是复现失败背后的主要机制——不测量和控制重要混杂因素的研究发现的关联在更好设计的复现中消失。线索 C：ML 模型和回归共享相同的基本统计结构——两者都最小化预测损失，都面临偏差-方差权衡，都需要对数据生成过程的假设。

在下一章中，我们将回归扩展到直线以外，扩展到能捕获弯曲关系、二元结果和计数数据的模型——构成应用统计实践核心的广义线性模型。

## 第 16 章：超越线性——GLM 和灵活模型

在第 15 章中，我们在结果 $Y$ 是连续数且与预测变量关系为线性的假设上构建回归。这些是有力的简化。但如果结果不是连续的——如患者是否存活、比赛中进了多少球、或复发前多少天——怎么办？我们还能用回归吗？

如果关系明显非线性呢？药物剂量-反应曲线常显示递减回报。概率不能超过 1，所以任何预测概率的模型必须被约束。计数不能为负，所以将计数建模为正态是有问题的（正态分布延伸到负无穷）。

这些局限推动了**广义线性模型（GLM）**的发展——一个统一框架，将回归扩展到处理不同类型的结果和不同形状的关系。GLM 包含线性回归作为特例并将其扩展到逻辑回归（二元结果）、Poisson 回归（计数结果）等。

理解 GLM 不仅是技术练习——每个模型编码了关于数据如何生成的故事，选择错误模型意味着讲述错误故事。

### 16.1 线性回归对非连续结果的局限

想象预测贷款申请人是否违约（0 = 否，1 = 是）。你可以尝试线性回归：$\hat{Y} = b_0 + b_1 X$。但预测值 $\hat{Y}$ 可以小于 0 或大于 1——这对概率无意义。而且，线性回归假设误差恒定方差，但 Bernoulli 结果（0/1）的方差为 $p(1-p)$，随 $p$ 变化。

更根本地，线性回归假设结果可取任何实数值。概率必须在 0 和 1 之间；计数必须是非负整数。将不适当模型强加于这些结果给出生物学上或实际上不可能的预测。

解决方案：将线性预测变量转换到适当尺度的**链接函数**。

### 16.2 GLM 框架

广义线性模型在三个组件下统一不同结果类型的回归：

#### 定义：广义线性模型

GLM 指定：

1. **随机组件**：结果 $Y$ 的概率分布（来自指数族：正态、二项、Poisson 等）

2. **系统组件**：线性预测变量 $\eta = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p$

3. **链接函数** $g$：将期望值 $\mu = E[Y]$ 链接到线性预测变量的函数：$g(\mu) = \eta$

逆链接函数将线性预测变量映射回均值：

$$\mu = g^{-1}(\eta) = g^{-1}(\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p)$$

此框架捕获：_结果有特定分布，该分布的均值是预测变量线性组合的（可能非线性的）函数_。

线性回归是正态分布和恒等链接的 GLM：$g(\mu) = \mu$，所以 $\mu = \eta$ 直接。
