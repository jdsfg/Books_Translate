#### 赤池信息准则 (AIC) 和贝叶斯信息准则 (BIC)

**赤池信息准则 (AIC)** 和 **贝叶斯信息准则 (BIC)** 会在对数似然上加入复杂度惩罚：

AIC = -2 log L(theta_hat) + 2k

BIC = -2 log L(theta_hat) + k log(n)

其中，L(theta_hat) 是最大化后的似然，k 是参数个数，n 是样本量。

对赤池信息准则 (AIC) 和贝叶斯信息准则 (BIC) 来说，都是**越低越好**。第 1 项（-2 log L）奖励更好的拟合（更高的似然）。惩罚项（2k 或 k log n）惩罚复杂度（更多参数）。

**直觉**：多 1 个参数的模型，其似然总是至少与受限制模型一样高（你总能拟合额外参数）。问题在于，似然的改进是否值得付出额外复杂度。赤池信息准则 (AIC) 和贝叶斯信息准则 (BIC) 通过要求对数似然的改进超过某个阈值来回答这个问题。

**赤池信息准则 (AIC) 与贝叶斯信息准则 (BIC) 的区别**：

* 赤池信息准则 (AIC) 使用惩罚项 2k——与交叉验证误差的渐近近似一致
* 贝叶斯信息准则 (BIC) 使用惩罚项 k log(n)——当 n 很大时，贝叶斯信息准则 (BIC) 对复杂度的惩罚比赤池信息准则 (AIC) 更重
* 赤池信息准则 (AIC) 倾向于选择预测效果更好的模型；贝叶斯信息准则 (BIC) 倾向于选择更简单、更可解释的模型
* 贝叶斯信息准则 (BIC) 是一致的（如果真实模型在候选集合中，当 n -> infinity 时会选择真实模型）；赤池信息准则 (AIC) 不是一致的，但在有限样本中可能优于贝叶斯信息准则 (BIC)


#### 解释赤池信息准则 (AIC)/贝叶斯信息准则 (BIC) 差异

比较 2 个模型时：

* Delta AIC > 10：有“实质性”证据表明更好的模型（赤池信息准则 (AIC) 更低）确实更好
* Delta AIC < 2：差异证据“很少”——模型近似等价
* Delta AIC 在 2 到 10 之间：证据“中等”

贝叶斯信息准则 (BIC) 差异通常也以类似方式解释，但带有贝叶斯含义：Delta BIC 近似等于用于比较模型的对数贝叶斯因子的 2 倍。


### 17.5 正则化——编码关于复杂度的先验信念

控制过拟合的另一种方法是：在估计准则中加入惩罚项，直接抑制过大的系数值。


#### 岭回归

**岭回归**（L2 正则化）加入一个与系数平方和成正比的惩罚：

beta_hat_ridge = arg min_beta [sum_{i=1}^n (Y_i - X_i' beta)2 + lambda sum_{j=1}^p beta_j2]

调节参数 lambda 控制惩罚强度。当 lambda -> 0 时，岭回归收敛到 OLS。当 lambda -> infinity 时，所有系数都会收缩到 0。

岭回归会把所有系数都向 0 收缩，但不会把任何系数恰好设为 0。它在处理多重共线性、以及当预测变量相关时稳定估计方面非常有效。
