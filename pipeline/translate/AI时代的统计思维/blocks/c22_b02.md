#### 代码生成与调试

这也许是 AI 对统计工作最直接有价值的能力：

* **把方法翻译成代码**：“给我写一个两样本 t 检验的功效分析，效应量 0.4，alpha 0.05，功效 0.80” → 比查找 `pwr` 包语法更快地得到正确的 R 或 Python 代码。
* **调试**：粘贴错误信息和产生错误的代码；AI 会识别问题并建议修复方式——对于常见错误，通常是正确的。
* **在语言之间转换**：把 R 代码转换为 Python，把 Python 转换为 Stan，把 SQL 转换为 pandas——AI 很擅长处理这些机械性的转换。

限定条件和以往一样：AI 会为被问到的问题生成代码。如果问题描述不精确，代码就会回答那个不精确的问题。验证代码是否回答了_真正想问_的问题，需要人类提供统计判断。

#### 文献综合

综合大量科学文献——识别主要发现、追踪共识的演化、注意研究之间的矛盾——如果手工完成，既耗时又容易出错。AI 可以通过以下方式提供帮助：

* 总结许多论文的摘要和关键发现
* 识别某一文献中的常见方法学路径
* 标记研究之间的矛盾，以便进一步检查
* 建议分析师可能忽略的相关文献

关键限制是：AI 可能歪曲、虚构或漏掉关键论文。幻觉（第 21 章）在文献综合中特别危险，因为错误引用看起来和正确引用一模一样。关于文献的每一个事实性主张，都必须对照真实论文验证。用 AI 来导航；但要核实地图。


#### 假设文档与沟通

AI 可以帮助起草统计假设文档——而这在实践中经常做得不够。给定一项分析的描述，AI 可以生成：

* 所作统计假设的清单
* 每个假设含义的通俗解释
* 如果每个假设被违反会发生什么的说明
* 敏感性分析建议

这确实很有价值。书面、明确的假设是机构记忆，使一项分析能够被审查、批评和改进。AI 可以比人类更快地生成这类文档的初稿，从而提高它最终被写出来的概率。
