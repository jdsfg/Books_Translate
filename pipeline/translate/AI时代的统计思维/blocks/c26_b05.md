#### Johnson-Lindenstrauss 引理：意外的礼物

下面是高维几何中最引人注目的结果之一，对机器学习有深远影响。

**Johnson-Lindenstrauss 引理**：给定 R^p 中的 n 个点，对于任意 ε > 0，存在一个到 R^k 的线性映射（投影），其中：

k = O(log n / ε^2)

使得所有两两距离都能在 (1 ± ε) 的因子范围内得到保留：

(1 - ε)||u - v||^2 ≤ ||f(u) - f(v)||^2 ≤ (1 + ε)||u - v||^2

用普通语言说：你可以把 n 个点从 p 维投影到 k = O(log n) 维——与 p 无关——同时近似保留所有两两距离。

**为什么这很了不起**：目标维度 k 取决于点的数量 n，而不是原始维度 p。如果你在 p = 1,000,000 维中有 n = 1,000 个点，就可以把它们投影到 k ≈ 100 维，同时把距离保持在10%的误差范围内——无论那个百万维空间多么复杂。

**奇迹之处**：你不需要寻找“正确”的投影。一个**随机投影**——简单地把数据乘以一个由随机高斯元素组成并适当缩放的矩阵——就能以高概率达到 JL 保证。这意味着降维可以在完全不了解数据结构的情况下完成。

**实际用途**：随机投影被用作高维任务的预处理步骤（用于近似最近邻搜索的局部敏感哈希、作为核近似的高斯随机特征、流式数据中的草图算法）。它们让原本在高维空间中不可行的计算，可以在降维空间中近似完成。
