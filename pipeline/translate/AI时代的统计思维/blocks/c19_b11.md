#### 概念检查

**Q1.** 说明普通最小二乘是经验风险最小化的一个特例。假设类是什么？损失函数是什么？

**答案：** 经验风险最小化寻找：

\[
\hat{f} = \arg\min_{f \in \mathcal{F}} \frac{1}{n}\sum_{i=1}^n \ell(y_i, f(x_i))
\]

对于 OLS：

* **假设类 \(\mathcal{F}\)**：线性函数 \(f(x) = x'\beta = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p\)，由 \(\beta \in \mathbb{R}^{p+1}\) 参数化。
* **损失函数 \(\ell\)**：平方误差 \(\ell(y, f(x)) = (y - f(x))^2\)。

因此，OLS 在所有 \(\beta\) 上最小化：

\[
\frac{1}{n}\sum_{i=1}^n (y_i - x_i'\beta)^2
\]

这就是 OLS 目标函数（忽略不影响 \(\arg\min\) 的 \(1/n\)）。解 \(\hat{\beta} = (X'X)^{-1}X'y\) 是在线性函数类、平方误差损失下的经验风险最小化器。

这也是最大似然：最小化平方误差等价于最大化高斯似然（第 6 章）。ERM、OLS 和高斯噪声下的 MLE，是从 3 个不同角度看到的同一个估计量。

**Q2.** 解释训练/验证/测试的 3 路划分。为什么多次使用测试集会有问题，即使你没有查看单个测试误差？

**答案：** 3 路划分服务于 3 个不同目的：

* **训练集**（约 60-70% 的数据）：拟合模型参数。模型“看到”这些数据，并调整其权重/系数以最小化训练损失。
* **验证集**（约 15-20%）：选择超参数。对每一种候选超参数配置，在训练集上训练，并在验证集上评估。这个数据不用于权重更新，但模型选择会隐式地拟合它。
* **测试集**（约 15-20%）：诚实评估。在所有模型选择完成之后，只在测试集上评估选定模型 1 次，以估计真实泛化误差。只有当测试集没有被用于任何决策时，这个估计才有效。

**为什么多次使用测试集有问题**：每当你在测试集上评估并使用这些信息做出决策（即使只是“测试表现很差，让我试一个不同模型”），你实际上都在把测试集用作第 3 个验证集。结果会向上偏倚——碰巧在测试集上表现最好的模型会被选中，即使这种表现有一部分只是运气。这与用训练误差做模型选择是同一个问题：你越是针对某个指标优化，这个指标作为真实性能估计的可靠性就越低。

统计原则是：在用于选择模型的同一份数据上计算出的统计量，是真实表现的有偏估计量。测试集作为诚实估计的价值，完全取决于直到最后才触碰它。

**Q3.** 解释为什么神经网络中的 dropout 可以被解释为一种正则化。它连接到什么统计概念？

**答案：** Dropout 通过同时训练一个神经网络集成来实现正则化。
