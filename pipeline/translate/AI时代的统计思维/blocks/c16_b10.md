#### 深入思考

**Q2.** 一家医院使用泊松回归来建模每个病区每月的患者跌倒次数。估计平均跌倒次数为 mu_hat = 3.2 次/病区/月。分析师使用标准泊松标准误报告回归系数的置信区间。

一位同事怀疑存在过度离散，并计算了各病区跌倒次数的方差：观测方差为 12.8，而泊松模型预测的方差 = 均值 = 3.2。

(a) 计算过度离散因子 phi_hat = 观测方差 / 预测均值。这个值对标准误意味着什么？(b) 分析师认为：“过度离散不影响回归系数的点估计，只影响标准误。所以这些估计仍然有效。”这个论点正确吗？(c) 一名护士长使用泊松回归来识别“跌倒显著多于预期”的病区（标记泊松 p 值 < 0.05 的病区）。在存在过度离散的情况下，解释这个决策规则的后果。(d) 提出 2 种能正确处理过度离散的建模方法，并简要说明每种方法如何工作。

**答案：**

**(a) 过度离散因子**：phi_hat = 12.8 / 3.2 = 4.0。观测方差是泊松预测的 4 倍。

对标准误的含义：泊松回归假定 Var(Y) = mu。当真实方差为 phi x mu 时，泊松标准误会偏小，偏小因子为 sqrt(phi) = sqrt(4) = 2。所有置信区间大约窄了 2 倍。所有 p 值都过小，其中一些可能小一个数量级。

**(b) 点估计的有效性**：这个论点**部分正确，但具有误导性**。

根据准似然理论，在存在过度离散时，如果均值函数 E[Y | X] = e^{X beta} 被正确设定，泊松最大似然系数估计仍然是**一致的**。因此，当 n -> infinity 时，点估计会收敛到真实系数。

然而，这些估计不再是**有效的**（最小方差），而且标准误是错误的，这使所有推断（假设检验、置信区间）失效。就实践而言，报告的系数估计可以作为有用近似，但如果不校正过度离散，关于统计显著性或精度的结论都无效。

**(c) 对标记决策的后果**：当过度离散因子 phi_hat = 4 时，标准泊松 p 值会因为与 sqrt(phi) = 2 有关的因子而过小。一个在泊松模型下得到 p = 0.04 的病区（被标记为跌倒显著更多），在正确设定的模型下可能得到 p approx 0.04 x phi = 0.16，远远不显著。
