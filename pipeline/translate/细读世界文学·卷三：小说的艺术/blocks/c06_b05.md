#### 概念检查

**Q1.** 把 “She was quite convinced of Mr. Elton's being in the fairest way of falling in love, if not in love already” 先改写成带标签的直接引语，再改写成叙述者措辞的平实被报道思想。每次改写丢失了什么，原句保留了什么？

提示

直接 = 引号 + “《爱玛》（Emma）想”。平实被报道 = 以中性词语写“爱玛相信……”。

**答案：** _直接引语：_ “他肯定正在爱上哈丽雅特，”爱玛想，“即使还没真爱上。” 这保留了爱玛的话，却用引号和“想”标签打断了叙述，并把这个念头标成只是她的，所以我们不再自己也半信半疑。_平实被报道：_ 爱玛相信埃尔顿先生开始爱上哈丽雅特了。这流动顺畅，却用爱玛热切的措辞（“坠入爱河的最佳途中”）换取叙述者的中性总结，丢失了她的声音和她自我满足的确信。原句的自由间接引语同时保留了**流动的无标记无引号**和**爱玛自己的色彩**，使她错误的信念以叙述事实般的平静权威抵达，并悄悄把我们征召进她的错误，这是两种改写都做不到的。

**Q2.** 列出识别自由间接引语的四个标记，以及不能与之混淆的两件事。

**答案：** _标记：_（1）第三人称、（2）过去时（因此不是直接引语）；（3）没有“她想”标签和引号（因此不是被报道言语）；（4）属于**人物**而非中立叙述者的措辞、判断、感叹、疑问或指示语（“明天”“肯定”）。_不能混淆于：_ **内心独白**（第一人称且无标签）和**普通被报道思想**（保留**叙述者**措辞而非人物措辞）。唯一检验：这些是以叙述者语法穿着的人物的话吗？


#### 应用题

**Q1.** 在羞惭段落（第三卷第十一章）中，找出叙述**退向**叙述者自己语域的从句，以及**最深入**爱玛声音的从句。用措辞证明。

提示

一个从句用冷静、正式的词“总结”；一个从句用优雅叙述者不会选择的苦涩、笨拙措辞。

**答案：** 叙述在“**She was proved to have been universally mistaken**”处**退后**：被动式“was proved”与正式的“universally”属于叙述者更冷、更具总结性的语域，拉开了半步距离。叙述在“**she had not quite done nothing—for she had done mischief**”处**最深入**爱玛：扭曲的双重否定“not quite done nothing”和平淡受伤的“she had done mischief”是一个心灵抓住自己正在最小化、并拒绝最小化时笨拙、自嘲的精确措辞，是追求优雅的叙述者不会写出的。这两套语域在没有标签、不间断的第三人称过去时中并置，使叙述者与人物的距离在一句之内开合。这就是全书训练的逐从句阅读动作。

本章的讨论涉及叙述对事件的**概述（summary）**与逐句展开之间的张力。
