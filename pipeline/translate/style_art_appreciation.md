# 风格简报 · 艺术细品系列（look_vangogh / rembrandt / vermeer / monet / hokusai / caravaggio）

> 覆盖：细品大师系列（梵高 / 伦勃朗 / 维米尔 / 莫奈 / 北斋 / 卡拉瓦乔）。视觉艺术赏析，描述性语言为主，**核心验收项 = 保住画面感与赏析口吻**。

## 1. 系列定位
艺术史 / 大师作品细品。作者以引导"观看"的方式解析构图、色彩、笔触、光影、题材。语言具画面感与感官性。

## 2. 质量 bar（核心）
- **保住画面感**：色彩、光影、质感、空间的描述须鲜活，不干巴巴列术语。
- **保住赏析口吻**：保留作者带鉴赏的近距引导（"注意看这里…"）。
- **不压平**：不把赏析写成百科词条。

## 3. 人称 / 语气
- 保留第二人称"你"的观看引导（如有）。
- 主观鉴赏克制但允许（这是赏析书，不是论文）。

## 4. 术语处理
- 艺术术语首次出现加注原文：chiaroscuro（明暗对照法）、impasto（厚涂）、composition（构图）、perspective（透视）、genre painting（风俗画）、woodblock（木刻）等。
- 作品名、收藏馆、地名用通用中译。

## 5. 禁忌译法
- movement 在艺术语境非"运动"，指"创作阶段/时期"时按语境译（如 "his late movement" ≈ 晚期创作），勿直译"运动"。
- 不把色彩词翻错（ultramarine = 群青，not 紫外）。

## 6. 结构保全
- 作品图注、章节标题层级、引文、脚注原样保留。
- 若文中有画作编号/馆藏编号保留。

## 7. 数字规则
- **年代 / 尺寸 / 馆藏编号**保留阿拉伯数字 + 原单位（如 "1889"、"73.7 × 92.1 cm"）。
- 约数可用中文（"十九世纪晚期"）。

## 8. 示例
- 源：`Van Gogh's impasto makes the cypress almost sculptural.`
- 译：`梵高用厚涂（impasto）让那株柏树近乎有了雕塑般的体量。`
- 源：`Note the chiaroscuro in Caravaggio's tenebrism.`
- 译：`注意卡拉瓦乔的暗调主义中那道明暗对照法（chiaroscuro）。`
