#### 概念检查

**Q1.** 比较均度为 10、n=10000 的 Erdős-Rényi 图的聚类系数与典型真实社交网络的聚类系数。它们相差多少倍？

提示

ER 聚类约为 p = \bar{k}/(n-1)。典型社交网络聚类约 0.1 到 0.4。

**答案。** Erdős-Rényi 聚类系数为 C_{ER} ≈ p = 10/9999 ≈ 0.001。典型社交网络聚类系数 C_{real} ≈ 0.1 到 0.4（对于个人友谊网络，常约 0.3）。所以真实网络的聚类系数在相同大小和密度下比 ER 基线大 100 到 400 倍。这一数百倍的差异是真实社交网络不是随机的主要经验标志之一。

在真实网络中产生高聚类的机制是_三元闭合_：朋友的朋友成为朋友。这是一个优先构建三角形的动力学过程，创造高局部聚类。它在 ER 模型中不发生（其中边独立添加，没有闭合三角形的偏好）。Watts-Strogatz 等模型通过构造重现高聚类；偏好附着模型除非修改以显式包含三元闭合动力学否则不会。

**Q2.** 幂律度分布的形式为 P(k) ∼ k^{-γ}。为什么二阶矩 ⟨k²⟩ 在 γ ≤ 3 时发散？这对友谊悖论有什么实际后果？

提示

计算 ⟨k²⟩ = ∫ k² P(k) dk。对于有截断 k_{max} 的幂律，积分随 k_{max} 增长。

**答案。** 二阶矩为

⟨k²⟩ = ∫_{k_{min}}^{k_{max}} k² · k^{-γ} dk = ∫_{k_{min}}^{k_{max}} k^{2-γ} dk.

对于 γ > 3，指数 2-γ < -1，积分在 k_{max} → ∞ 时收敛。对于 γ ≤ 3，指数 2-γ ≥ -1，积分无界增长（γ=3 时对数增长，γ<3 时幂增长）。

在实际网络中总有有限的 k_{max}（最高度顶点），所以二阶矩在实践中总有界；但它以随 γ ≤ 3 的大网络增长而变大的方式随 k_{max} 标度。

对友谊悖论的实际后果：\bar{k}_f = \bar{k} + σ²/\bar{k}，而 σ² = ⟨k²⟩ - \bar{k}²。对于 γ ≤ 3，σ² 随网络增长变大，所以友谊悖论变得极端：你的朋友平均比你多得多朋友。这对大多数真实社交网络成立（其中 γ 通常在 2 到 3 范围内），也是友谊悖论在大真实网络上实际计算时如此引人注目的原因之一。
