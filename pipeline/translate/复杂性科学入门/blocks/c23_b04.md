### D.11 常见安装问题

**问题：** `pip install scipy` 在 macOS 上因编译器错误失败。**修复：** 改用 `mamba install -c conda-forge scipy` 安装。SciPy 需要 Fortran 和 C 编译器；conda 提供预编译二进制。

**问题：** `import matplotlib.pyplot as plt` 在 Jupyter 中可用但在脚本中不可用。**修复：** 在不需要显示的脚本中导入 pyplot 前添加 `matplotlib.use('Agg')`，或在需要显示的脚本中使用 `matplotlib.use('TkAgg')`。

**问题：** 程序运行比附录 B 中预期运行时间慢得多。**修复：** 检查 NumPy 是否使用快速 BLAS 后端。运行 `np.show_config()` 确认。conda-forge 的 NumPy 构建使用 OpenBLAS 或 MKL；pip 的默认可能不。

**问题：** 即使设置了 `np.random.seed(42)`，随机结果在运行间仍变化。**修复：** 如果你的程序导入了其他使用随机数的库（如 Python 的 `random` 模块、NetworkX 的内部随机性），分别设置种子。NetworkX 使用自己的 RNG；向图生成器传递 `seed=42`。

**问题：** `nx.barabasi_albert_graph(n, m)` 对大 `n` 慢。**修复：** 对 `n > 10⁵`，直接使用附录 B.6 中的实现（比 NetworkX 的通用版本更快），或切换到 graph-tool/igraph。
