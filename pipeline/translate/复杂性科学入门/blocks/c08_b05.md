#### 标度的推导

P(k) ~ k^{-3} 结果的启发式推导。设 k_i(t) 为顶点 i 在时刻 t 的度。每个时间步添加一个带 m 条边的新顶点。边落在顶点 i 上的速率与 k_i(t) 成正比：

\frac{dk_i}{dt} = m \cdot \frac{k_i(t)}{\sum_j k_j(t)}.

时刻 t 的总度约为 ∑_j k_j(t) = 2mt（每个新顶点添加 m 条边，对总度贡献 2）。所以

\frac{dk_i}{dt} = m \cdot \frac{k_i(t)}{2mt} = \frac{k_i(t)}{2t}.

这是一个可分离 ODE：dk_i / k_i = dt / (2t)。从出生时间 t_i（其中 k_i(t_i) = m，因为顶点以 m 条边进入）到当前时间 t 积分给出 ln(k_i / m) = (1/2) ln(t / t_i)，因此

k_i(t) = m \left(\frac{t}{t_i}\right)^{1/2}.

所以顶点在任意时刻的度按当前时间与其出生时间之比的平方根标度。

现在计算均匀随机选择的顶点的累积分布 P(k_i < k)。k_i(t) < k 当且仅当 m(t/t_i)^{1/2} < k，当且仅当 t_i > m²t/k²。对于 [0, t] 中均匀随机的 t_i，此概率为 1 - m²/k²。概率密度则为 P(k) = -d/dk [m²/k²] = 2m²/k³，给出指数为 3 的幂律。

（完整推导涉及更仔细的平均，但关键标度结果是正确的。）

#### 代码：模拟偏好附着

    import networkx as nx
    import numpy as np
    import matplotlib.pyplot as plt

    n = 10000; m = 3
    G = nx.barabasi_albert_graph(n, m)
    degrees = [d for n, d in G.degree()]

    bins = np.logspace(0, np.log10(max(degrees)), 30)
    hist, edges = np.histogram(degrees, bins=bins, density=True)
    centers = 0.5 * (edges[:-1] + edges[1:])
    plt.loglog(centers, hist, 'o-')
    plt.xlabel('degree k'); plt.ylabel('P(k)')
    plt.show()


图在双对数轴上近似为斜率 -3 的直线，确认了预测的标度。斜率最好使用最大似然拟合来估计（参见 Clauset、Shalizi 和 Newman，2009，标准方法），而非双对数轴上的最小二乘拟合（后者有偏差且不可靠）。
