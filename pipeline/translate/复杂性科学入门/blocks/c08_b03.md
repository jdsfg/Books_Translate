Watts 和 Strogatz 在 1998 年提出的一个关键洞察是，小世界结构 _不是_ 随机网络或规则网络的特殊属性。它是一种混合……

n 个顶点上的 _规则环_ 格，每个顶点连接到圆上其 k 个最近邻，具有非常高的聚类（邻居的邻居很可能也是邻居）但非常长的平均路径长度（你必须遍历环的大部分才能到达对面，给出 \bar{d} ~ n/(2k)）。具有相同顶点数和边数的 _随机图_ 具有非常短的路径长度（\bar{d} ~ log n / log \bar{k}）但非常低的聚类……

Watts-Strogatz 构造在两者之间插值。从一个规则环格开始。然后，对于每条边，以某个小概率 p_w（_重连概率_），移除该边并用一条连接原端点到环上其他位置随机顶点的边替换。对于 p_w = 0，图保持规则（高聚类，长路径）。对于 p_w = 1，图本质上是随机的（低聚类，短路径）。对于中间的 p_w，有趣的事情发生了。

Watts 和 Strogatz 展示了（这是他们 1998 年著名 _Nature_ 论文的核心）平均路径长度随非常小的 p_w 急剧下降（仅几条重连边就足以创建跨越环的捷径），而聚类系数下降得慢得多（只要大多数边保持在原位置，局部聚类结构就被保留）。对于 p_w 在一个宽范围内，通常 0.01 < p_w < 0.1，图 _同时_ 具有短路径 _和_ 高聚类。这就是 _小世界体制_：两全其美。

数学内容是少数长程捷径急剧减少平均路径长度，同时对局部聚类的影响微乎其微。Watts-Strogatz 模型表明，真实网络通过结合主要是局部的连通性（保持聚类）和少量长程边（全局短路网络）来实现其小世界性质。

#### 代码：模拟 Watts-Strogatz

    import networkx as nx
    import numpy as np
    import matplotlib.pyplot as plt

    n = 1000; k = 10
    p_values = np.logspace(-4, 0, 25)
    clustering = []; path_length = []

    for p in p_values:
        G = nx.watts_strogatz_graph(n, k, p)
        clustering.append(nx.average_clustering(G))
        path_length.append(nx.average_shortest_path_length(G))

    # Normalize to p=0 values
    C0, L0 = clustering[0], path_length[0]
    plt.semilogx(p_values, [c/C0 for c in clustering], 'o-', label='C(p)/C(0)')
    plt.semilogx(p_values, [l/L0 for l in path_length], 's-', label='L(p)/L(0)')
    plt.xlabel('rewiring probability p'); plt.legend(); plt.show()


图再现了著名的 Watts-Strogatz 图。路径长度 L 在 p_w 增加超过约 0.001 时急剧下降。聚类 C 下降得慢得多，仅在 p_w ~ 0.1 以上才开始显著下降。"小世界平台"是中间 p_w 的宽范围，其中 L 已经短但 C 仍然高。这是大多数真实社交网络所在的区域。
