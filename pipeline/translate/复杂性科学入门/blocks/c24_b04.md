**巨分量（Giant component）。** 图的最大连通分量；在_Erdős-Rényi_阈值（kˉ=1\bar{k} = 1kˉ=1）以下占比趋于零，以上为有限比例。**定义：**第6章 §6.4。

**滑翔机（Glider）。** _生命游戏_中在网格上平移而不改变形状的模式。最简单的"飞船"。**定义：**第12章 §12.2。

**Granovetter 阈值模型。** 每个代理有加入行为的个人阈值的社会采纳模型。**定义：**第8章 §8.4，第11章 §11.6。

**Gutenberg-Richter 定律。** 地震大小分布的经验_幂律_关系：log⁡N=a−bM\log N = a - bMlogN=a−bM。最干净的经验 SOC 特征。**定义：**第10章 §10.3。

**意识的困难问题（Hard problem of consciousness）。** Chalmers 的术语，指为什么主观体验存在（相对于大脑如何处理信息的"简单"问题）。_强涌现_主张的主要动机。**定义：**第15章 §15.5。

**Hausdorff 维度。** _分形维度_的数学形式化；对本书的分形等价于_盒计数维度_。**定义：**第4章 §4.2。

**重尾分布（Heavy-tailed distribution）。** 尾部衰减慢于指数的概率分布；稀有大事件主导长期统计。_幂律_和_对数正态_是常见例子。**定义：**第7章 §7.2；**发展：**第10章。

**枢纽（Hub）。** _无标度网络_中的高_度_顶点。枢纽主导传播动力学并驱动网络的鲁棒性/脆弱性属性。**定义：**第7章 §7.2。

**信息级联（Information cascade）。** 每个代理的选择受先前代理可见选择影响的决策序列。与_简单传染_不同的动力学。**定义：**第8章 §8.4。

**Ising 模型。** 有二元自旋的磁性系统的_元胞自动机_式模型；典范_相变_模型。**定义：**第9章 §9.2。

**迭代映射（Iterated map）。** 形如 xn+1=f(xn)x_{n+1} = f(x_n)xn+1​=f(xn​) 的离散_动力系统_。_逻辑斯蒂映射_是典范例子。**定义：**附录 A §A.4.1；**发展：**第3章。

**Kaplan-Yorke 公式。** 用_Lyapunov 谱_表示_奇异吸引子_的_分形维度_的公式。**定义：**第4章 §4.3。

**Kuramoto 模型。** 具有正弦交互的耦合振荡器模型。在去同步和同步状态间表现出_相变_。**定义：**第5章 §5.2。

**极限环（Limit cycle）。** _相空间_中轨迹收敛到的闭合周期轨道。**定义：**第4章 §4.1。

**对数正态分布（Lognormal distribution）。** 对数为高斯的分布；产生_重尾_但与_幂律_不同。真实数据中幂律的常见替代。**定义：**附录 A §A.3.1。

**逻辑斯蒂映射（Logistic map）。** 迭代映射 xn+1=r xn(1−xn)x_{n+1} = r\,x_n(1-x_n)xn+1​=rxn​(1−xn​)。故事线 A 的运行数学角色。**定义：**第3章 §3.1；**重访：**第4、9、12、17章。

**Lorenz 系统。** Edward Lorenz 1961 年引入的三维 ODE；原始的_奇异吸引子_。**定义：**第3章 §3.5；**重访：**第4章 §4.3。

**Lyapunov 指数。** 附近轨迹间渐近指数发散率。正_Lyapunov 指数_定义_混沌_。**定义：**第3章 §3.3。
