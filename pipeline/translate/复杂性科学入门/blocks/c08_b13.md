**Q6.** 考虑度指数 γ=2.5、n=10^7 的无标度网络。使用自然截断 k_{max} ~ n^{1/(γ-1)} 估计此类网络中的最大度（最高度节点）。

提示

求解 k_{max} 使得度超过 k_{max} 的期望节点数约为 1。

**答案。** 幂律分布的自然截断是我们期望约一个节点超过的值。随机节点度至少为 k 的概率为

P(k' ≥ k) = ∫_k^∞ C k'^{-γ} dk' = \frac{C}{γ - 1} k^{-(γ - 1)}.

对于总共 n 个节点，度至少为 k_{max} 的期望数为 n · P(k' ≥ k_{max}) ≈ 1，给出 k_{max} ~ n^{1/(γ-1)}。

对于 n=10^7, γ=2.5：

k_{max} ~ (10^7)^{1/1.5} = 10^{7/1.5} ≈ 10^{4.67} ≈ 47000.

所以最高度节点的度预计在 47,000 量级。在 1000 万节点、此指数的网络中，连接最多的节点连接了整个网络的近半个百分点。这比相同均值泊松分布的预期（最大值为几十或几百，而非几万）高出多个数量级。

这种被极端节点主导的特征是无标度网络的定义特征。它是网络、互联网、社交媒体和许多生物网络中枢纽-辐射架构的结构起源。
