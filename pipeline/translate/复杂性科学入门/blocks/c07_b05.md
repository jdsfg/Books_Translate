#### PageRank

PageRank 是为有向图（如网络）设计的特征向量中心性的精炼版本。其洞察是：一个重要页面向其链接的页面发送"投票"，但每张投票按链接页面的重要性加权并除以该页面的出链数（因此一个有 100 条出链的页面只将其重要性的 1/100 贡献给每个被链接页面）。

顶点 i 的 PageRank 递归定义为：

PR(i) = \frac{1 - d}{n} + d \sum_{j: j \to i} \frac{PR(j)}{L(j)}

其中 L(j) 是 j 的出链数，d 是阻尼因子（通常 d=0.85），求和遍历所有链接到 i 的顶点 j。第一项 (1-d)/n 代表均匀"传送"概率：以概率 1-d，随机冲浪者跳转到均匀随机页面而非跟随链接。这一项确保算法即使在存在无出链页面时也有定义（否则迭代不会收敛）。

PageRank 可通过幂迭代计算：从所有 i 的均匀值 PR(i) = 1/n 开始，反复应用递推，对于典型网络规模图，值在 50 到 100 次迭代中收敛到稳态。稳态是带传送的网络随机游走的平稳分布，这给出了 PageRank 的另一个自然解释：PR(i) 是随机冲浪者（以概率 d 点击链接，以概率 1-d 传送）落在页面 i 上的长期概率。

PageRank 在数学上等价于找到修改邻接矩阵的主特征向量

\hat{A}_{ij} = \frac{1 - d}{n} + d \cdot \frac{A_{ji}}{L(j)}

（注意索引交换以处理方向性）。\hat{A} 的主特征值为 1（因为 \hat{A} 是列随机矩阵），其主特征向量就是 PageRank 向量。

Google 这家数万亿美元企业的全部基础就在这一线性代数计算上，加上如何在网络规模上执行它的巨大工程工作。同一算法今天被用于排名从期刊引用（特征因子）到科研人员（h 指数变体）到社交媒体影响力的一切。

#### 代码：计算中心性

    import numpy as np
    import networkx as nx

    # A small example graph
    G = nx.karate_club_graph()  # the famous Zachary karate club graph

    print("Degree centrality:", nx.degree_centrality(G))
    print("Betweenness centrality:", nx.betweenness_centrality(G))
    print("Eigenvector centrality:", nx.eigenvector_centrality(G))
    print("PageRank:", nx.pagerank(G))


Zachary 空手道俱乐部是一个经典例子：一个 1970 年代大学空手道俱乐部的真实社交网络，分裂为两个派系。高中心性顶点（按四种度量中任一种）是两个派系领袖。四种度量给出相似但不完全相同的排名；跨节点比较它们本身就是有教益的。
