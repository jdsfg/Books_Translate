在转变附近，u ≈ 1，所以 m² ≈ 3(u - 1)，利用 u = Jz/(k_B T) ≈ T_c/T（因为 k_B T_c = Jz）：

m \sim (T_c - T)^{1/2}.

平均场序参量临界指数为 β = 1/2。这与我们的 Kuramoto 结果匹配，是普适的平均场值。

平均场理论中的完整标度指数：α = 0（比热跳跃），β = 1/2，γ = 1，ν = 1/2。这些满足标度关系，在 Ising 普适类的_上临界维度_ d_u = 4 以上正确。在 d_u 以下，涨落重要且平均场指数错误；这就是为什么 2D 和 3D Ising 有不同于平均场的指数。

普适性分类可以更精确地陈述：在上临界维度以上，广义 Ising 类中的所有系统具有平均场指数。在以下，指数依赖于维度。平均场开始正确的维度取决于普适类，对于短程 Ising 类系统通常为 4。
