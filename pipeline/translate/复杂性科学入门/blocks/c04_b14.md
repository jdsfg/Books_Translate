**Q6.** 用 Python 实现洛伦兹的三个方程（使用 `scipy.integrate.solve_ivp` 或手写四阶龙格-库塔法），并在三维中绘制轨迹。使用参数 σ=10, ρ=28, β=8/3，从 t=0 运行到 t=50，起始点为 (1, 1, 1)。然后从 (1.0001, 1, 1) 再次运行并叠加两条轨迹。大致识别两条轨迹首次变得视觉可区分的时间。

提示

两条轨迹在前几秒内看起来几乎完全相同，然后突然分离。

**答案。** 示例代码：

    import numpy as np
    from scipy.integrate import solve_ivp
    import matplotlib.pyplot as plt

    def lorenz(t, state, sigma=10.0, rho=28.0, beta=8.0/3.0):
        x, y, z = state
        return [sigma*(y - x), x*(rho - z) - y, x*y - beta*z]

    t_span = (0, 50)
    t_eval = np.linspace(*t_span, 5000)

    sol1 = solve_ivp(lorenz, t_span, [1.0,    1.0, 1.0], t_eval=t_eval, rtol=1e-9)
    sol2 = solve_ivp(lorenz, t_span, [1.0001, 1.0, 1.0], t_eval=t_eval, rtol=1e-9)

    fig = plt.figure(figsize=(10, 8))
    ax = fig.add_subplot(projection='3d')
    ax.plot(sol1.y[0], sol1.y[1], sol1.y[2], lw=0.5)
    ax.plot(sol2.y[0], sol2.y[1], sol2.y[2], lw=0.5, color='red', alpha=0.7)
    plt.show()

    # Distance over time
    d = np.sqrt(((sol1.y - sol2.y)**2).sum(axis=0))
    plt.semilogy(t_eval, d)
    plt.xlabel('t')
    plt.ylabel('distance')
    plt.show()


两条轨迹在大约前 10 秒内看起来视觉上完全相同。到 t ≈ 15 时它们开始可见地分离。到 t ≈ 25 时它们完全不相关，在任何给定时刻通常在吸引子的相对两瓣上。半对数距离图显示指数上升（在对数轴上大致线性），直到约 t=25 处饱和到接近吸引子的直径。

这个实验是你在现代笔记本电脑上能最接近重现洛伦兹 1961 年发现的方式。两条起始相差 0.0001 的轨迹在仅几十秒模拟时间后变得与吸引子上随机选取的一对轨迹无法区分，这一事实就是蝴蝶效应的全部经验内容。
