### 13.5 现代 ABM 工具

几个软件平台已涌现用于基于代理建模，各有优劣。

_NetLogo_（在西北大学连接学习中心开发）是使用最广泛的教育 ABM 平台。其语言是高级的且对非程序员可及；可视化内置；模型库包括数十个经典示例（Schelling、生命游戏、Boids、Lotka-Volterra 等）。NetLogo 非常适合教学和原型设计。其主要局限是性能：对超过几千个代理的模型较慢。

_Mesa_（Python 库）是研究级工作中最受欢迎的 ABM 框架。它比 NetLogo 更灵活和更快，与更广泛的 Python 数据科学生态集成，适合数万到数十万代理的模型。其主要局限是需要 Python 编程技能。

_Repast_（基于 Java 的框架）是超大规模模型（数百万代理）和高性能计算应用的选择。它比替代方案更难学但扩展性更强。

_自定义代码_（C++、Julia 或其他语言）有时适合性能关键或不适合现有框架的不寻常 ABM。

工具的选择很重要，现代 ABM 实践常涉及跨多个平台重写模型以验证结果对实现选择稳健。这是从下面讨论的可复现性问题中涌现的方法论改进之一。
