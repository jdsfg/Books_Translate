#### 概念检查

**Q1.** 用自己的话陈述 Kuramoto 模型。识别方程 dθ_i/dt = ω_i + (K/N) ∑_j sin(θ_j - θ_i) 中的每一项并解释其物理含义。

提示

右边恰好有两项。第一项设定自然节律；第二项将振子与群体耦合。

**答案。** Kuramoto 模型描述 N 个振子的群体，每个以相位变量 θ_i 表征，随时间连续增长，全部通过简单的正弦拉力相互耦合。每个振子有自己的_自然频率_ ω_i（如果与其他振子解耦时它循环的速率），从某个概率分布 g(ω) 中抽取，表征群体的异质性。

右边第一项 ω_i 是振子的固有相位增长率。没有耦合时，每个振子永远以自己的 ω_i 循环。

第二项 (K/N) ∑_j sin(θ_j - θ_i) 是耦合项。因子 K 是_耦合强度_（每个振子影响邻居的强度）；因子 1/N 对求和归一化，使得随群体增长任一振子受到的总影响保持有界。被加项 sin(θ_j - θ_i) 是振子 j 对振子 i 施加的拉力：当 j 在相位上领先于 i 时为正（使 i 加速），当 j 落后时为负（使 i 减速）。对所有 j 求和后，耦合项试图将振子 i 与群体的平均相位对齐。

自然频率异质性（倾向于分散振子）与耦合（倾向于对齐它们）之间的相互作用决定了群体是否同步。耦合弱时，异质性胜出，群体不相干。耦合强时，对齐胜出，群体锁定到共同节律。

**Q2.** 当自然频率分布在区间 [-1, 1] 上均匀时，计算 Kuramoto 模型的临界耦合 K_c。（使用公式 K_c = 2 / [π g(\bar{ω})]。）

提示

[-1, 1] 上的均匀分布在 ω ∈ [-1, 1] 时 g(ω) = 1/2，在外为 0。

**答案。** [-1, 1] 上均匀分布的均值为 \bar{ω} = 0。均值处的概率密度为 g(0) = 1/2（因为分布均匀，总概率 1 分布在长度为 2 的区间上）。代入：

K_c = 2 / (π · 1/2) = 4/π ≈ 1.273.

所以当耦合强度超过约 1.27 时群体同步。对于更宽的均匀分布（例如 [-2, 2]，g(0) = 1/4），临界耦合翻倍为 8/π ≈ 2.55。自然频率散布越宽，同步所需的耦合越强，这与直觉一致。
