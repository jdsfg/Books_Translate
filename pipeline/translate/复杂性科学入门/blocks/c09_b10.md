#### 概念检查

**Q1.** 写出三个 SIR 方程并物理解释每项。然后从 I 方程导出 R_0 的表达式。

R_0 是一个初始感染者的预期继发感染数；通过计算在感染期间产生多少感染来求得。

\frac{dS}{dt} = -\beta \frac{SI}{N}：易感者以每次 S-I 接触速率 β 因感染而损失，接触数与 SI/N 成正比。

\frac{dI}{dt} = \beta \frac{SI}{N} - \gamma I：感染者因感染获得减去以每个感染者速率 γ 因康复损失。

\frac{dR}{dt} = \gamma I：康复者从感染者康复获得。

R_0 的推导：平均传染期为 1/γ（康复率的倒数）。在此期间，感染者以速率 βS/N 产生继发感染。在完全易感群体中的爆发初期，S/N ≈ 1，所以感染率约为每单位时间 β。一个感染者的总继发感染数：

R_0 = \beta \cdot \frac{1}{\gamma} = \frac{\beta}{\gamma}.

如果 R_0 < 1，每个感染者平均产生不到一个继发感染，链指数消亡。如果 R_0 > 1，链在早期阶段指数增长，直到易感池耗尽到有效 R（通过 R_{eff} = R_0 · S/N 依赖于 S/N）降到 1。此时流行病达峰并开始下降。

**Q2.** 一种病毒在均匀混合群体中 R_0 = 2.5。需要为多大比例的人口接种疫苗才能实现群体免疫（即将有效再生数降到 1 以下）？

提示

当剩余易感者比例 S/N 足够小使得 R_0 · S/N < 1 时实现群体免疫。

**答案。** 当 R_{eff} = R_0 · (S/N) < 1 时实现群体免疫。阈值为 S/N < 1/R_0 = 1/2.5 = 0.4。所以最多 40% 的人口可以保持易感；其余 60% 必须通过疫苗接种或先前感染获得免疫。

群体免疫公式 p_c = 1 - 1/R_0 是所有疫苗接种计划目标的基础。对于 R_0 ≈ 2.5 的 COVID-19（alpha 变种）约为 60%；对于 R_0 ≈ 5.0（delta 变种）约为 80%；对于 R_0 ≈ 10.0（某些 omicron 子变种在低干预条件下）约为 90%。R_0 更高的病毒需要相应更高的覆盖率。
