### 5.3 数值示例

考虑 N=1000 个 Kuramoto 振子，自然频率从标准高斯分布（均值 0，标准差 1）中抽取。该分布的临界耦合可计算：K_c = 2 / (π · 1/\sqrt{2π}) = 2\sqrt{2π} / π ≈ 1.596。

模拟动力学的 Python 示例代码：

    import numpy as np
    import matplotlib.pyplot as plt

    N = 1000
    omega = np.random.randn(N)  # natural frequencies, Gaussian
    theta = 2 * np.pi * np.random.rand(N)  # initial phases, uniform
    dt = 0.05
    T = 50

    K_values = [0.5, 1.0, 1.5, 2.0, 2.5, 3.0]
    fig, axes = plt.subplots(len(K_values), 1, sharex=True, figsize=(10, 12))

    for ax, K in zip(axes, K_values):
        th = theta.copy()
        rs = []
        for _ in range(int(T / dt)):
            z = np.mean(np.exp(1j * th))
            r = np.abs(z); psi = np.angle(z)
            th = th + dt * (omega + K * r * np.sin(psi - th))
            rs.append(r)
        ax.plot(np.arange(len(rs)) * dt, rs)
        ax.set_ylim(0, 1.05)
        ax.set_ylabel(f'r, K={K}')
    axes[-1].set_xlabel('time')
    plt.tight_layout()
    plt.show()


你应该看到：在 K=0.5 和 K=1.0（低于 K_c）时，r 在小值附近涨落而不增长。在 K=1.5（恰低于 K_c）时，r 小但非零。在 K=2.0（恰高于 K_c）时，r 增长到中等稳态值。在 K=2.5 和 K=3.0（远高于 K_c）时，r 快速攀升到高值，接近 1，表明强同步。

绘制稳态 r（在每次模拟的后半段平均，瞬态之后）对 K 的图给出 Kuramoto 模型的经典分岔图：r 在 K < K_c 时约为零，在 K > K_c 时按 \sqrt{K - K_c} 增长。曲线的形状——尖锐阈值和逐渐饱和——是连续相变的几何标志。

### 5.4 自然界中的同步

Kuramoto 模型不仅是数学好奇心。它已成功应用于许多真实同步现象。

#### 起搏细胞

你心脏的窦房结包含约 10000 个起搏细胞，每个都能以略微不同的固有速率（大约每分钟 60 到 100 次脉冲）自发产生电脉冲。细胞通过间隙连接电耦合，间隙连接允许离子电流在相邻细胞间直接流动。这本质上是一个 Kuramoto 式群体，具有强耦合，远高于临界值。整个节点一致发放，产生定义正常心脏功能的"规律"心跳。

当耦合失效（因心脏病发作的损伤、电解质失衡、药物效应），起搏细胞可能去同步，导致心律失常。_心房颤动_，最常见的心律失常，本质上是起搏细胞滑落到同步阈值以下；心脏上腔颤动而非协调收缩。恢复同步（用除颤器）是医疗干预。
