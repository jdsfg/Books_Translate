大多数复杂性科学教科书要么用隐喻（鸟群、萤火虫、蚁穴）来安抚你，要么用统计力学将你淹没。本书两者皆不取。它将复杂性科学视为一套连贯的工具箱——6 个概念锚点、3 条贯穿全书的故事线、18 章构建一个统一论证——并且从头到尾坦诚地指出，这个领域在哪些地方兑现了承诺，在哪些地方夸大了其能力。

这一论证建立在 3 条刻意反复出现的主线之上。故事线 A 追踪一个方程——逻辑斯蒂映射 x n + 1 = r x n ( 1 − x n ) x_{n+1} = r\,x_n(1-x_n) x n + 1 ​ = r x n ​ ( 1 − x n ​ ) ——从它在第3章的首次登场，到随后 5 章中以不同面貌回归：分岔图、奇异吸引子、相变、离散元胞自动机的表亲，最终作为复杂性科学能预测什么和不能预测什么的测试案例。故事线 B 追踪幂律分布——横跨地震、神经雪崩、金融崩盘和友谊悖论——然后在第17章中诚实地追问，分布的尾部究竟能让我们预测什么。故事线 C——谢林教训——追踪一个令人不安的事实：温和的个体偏好常常产生无人选择的严重集体后果，从第1章的椋鸟群到交通、隔离和 2008 年金融危机。

使本书与众不同的是第17章——审计。大多数入门书跳过这一步。本书点名了复杂性科学夸大其词的具体时刻（2000年代严格的无标度网络主张；一些神经临界性结果；预测金融崩盘的梦想），解释了后来的证据揭示了什么，并告诉你哪些结果仍然经得起检验。最后一章将工具箱综合为一个 8 步实用工作流程，你可以将其应用于自己领域的系统。附录B中的 16 个可运行的 Python 程序让你能够复现每一个经典结果，所有代码均经过执行验证。

本书在数学上是严肃的——导数、特征向量、平均场论证、重整化（精神上而非细节上）——但始终贯穿跨学科视角。如果你完成了数学、物理、计算机科学或工程的本科课程序列，本书在你的能力范围之内；如果没有，概念性章节（1、2、15、16、17、18）仍然可以理解，附录A的自测题会准确告诉你，在攻克第3至14章之前需要在哪里复习。
