#### 概念检查

**Q1.** 手动（或在计算器上）计算 r=3.2 和 x_0=0.5 时逻辑斯蒂映射的前 10 次迭代。每个值四舍五入到 4 位小数。识别长期轨道的周期。

提示

大约 5 次迭代后序列将进入轨道。识别该循环。

**答案。** 从 x_0=0.5 迭代 x_{n+1} = 3.2 x_n (1 - x_n)：

* x_1 = 3.2 · 0.5 · 0.5 = 0.8000
* x_2 = 3.2 · 0.8 · 0.2 = 0.5120
* x_3 = 3.2 · 0.512 · 0.488 = 0.7995
* x_4 = 3.2 · 0.7995 · 0.2005 = 0.5129
* x_5 = 3.2 · 0.5129 · 0.4871 = 0.7994
* x_6 = 3.2 · 0.7994 · 0.2006 = 0.5132
* x_7 = 3.2 · 0.5132 · 0.4868 = 0.7995
* x_8 = 3.2 · 0.7995 · 0.2005 = 0.5129
* x_9 ≈ 0.7994
* x_{10} ≈ 0.5130

序列在约 0.7995 和 0.5130 之间振荡，因此长期周期为 2。

**Q2.** 求一般 r 下逻辑斯蒂映射的不动点。（不动点满足 x = rx(1-x)。）代数求解。然后验证，对于 r=2.5，非平凡不动点与 §3.1 中找到的长期值一致。

提示

将 x = rx(1-x) 重排为 x[1 - r(1-x)] = 0 并求解。

**答案。** 方程 x = rx(1-x) 因式分解为 x[1 - r(1-x)] = 0，给出解 x=0 和 1 - r(1-x) = 0，后者解得 x = (r-1)/r。对于 r=2.5，非平凡不动点为 (2.5-1)/2.5 = 1.5/2.5 = 0.6，与 §3.1 中计算的值一致。

这些不动点的稳定性由不动点处导数 f'(x^*) = r - 2rx^* 的大小决定。x^*=0 处的不动点有 f'(0)=r，在 r < 1 时稳定。x^*=(r-1)/r 处的非平凡不动点有 f'(x^*)=2-r，在 |2-r| < 1 即 1 < r < 3 时稳定。在 r=3 处导数大小达到 1，不动点失去稳定性，通过倍周期分岔产生周期 2 轨道。
