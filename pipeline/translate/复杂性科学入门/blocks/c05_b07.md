### 4.4 逻辑斯蒂映射的奇异吸引子

r=4 的逻辑斯蒂映射有一个奇异吸引子，它在视觉上不如洛伦兹吸引子引人注目，因为映射是一维的，吸引子本质上是整个区间 [0, 1]。使吸引子奇异的不在于其几何形状（它只是一个区间），而在于其 _测度论_ 结构。

对于 r=4 的逻辑斯蒂映射，预热后 x 值的长期分布精确地由

p(x) = \frac{1}{\pi \sqrt{x(1 - x)}}

给出，其中 x ∈ (0, 1)。该分布在端点 x=0 和 x=1 处（温和地）发散，反映了映射在这些值附近变慢的事实。该分布是 _不变的_：如果你从按 p(x) 分布的 x 值群体开始并应用映射，你得到的群体仍然按 p(x) 分布。

r < r_∞（周期体制中）的映射具有有限点集作为吸引子：r < 3 时单个点，3 < r < 3.4495 时两个点，然后 4 个、8 个，等等。随着 r 趋近 r_∞，周期吸引子对任意大的 k 有 2^k 个点；当 r 从下方趋近 r_∞ 时的极限结构是一个类康托尔集，分形维数约等于 0.538（这是另一个 Feigenbaum 常数）。所以在混沌的边缘，逻辑斯蒂映射的吸引子是一个具有分数维数的显式分形。

这是奇异吸引子与分形几何之间关系的最清晰例证之一。随着参数 r 通过倍周期级岔调向 r_∞，吸引子从单个点（维数 0）经过周期轨道（仍为维数 0，但点数更多）到分形类康托尔集（在 r = r_∞ 处维数 0.538），然后到混沌区间（维数最高到 1，取决于 r）。吸引子的维数编码了动力学的定性体制。
