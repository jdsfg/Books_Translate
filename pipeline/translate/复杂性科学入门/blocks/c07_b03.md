### 6.2 度、聚类与路径长度

顶点最简单的局部属性是其 _度_（degree）：与之关联的边数。在无向图中，顶点 i 的度为 k_i = ∑_j A_{ij}。在上例中，度为 k_1=2, k_2=2, k_3=3, k_4=1。平均度为 \bar{k} = (1/n) ∑_i k_i = 2m/n（因为每条边对度之和贡献 2）。对于我们的四顶点图，\bar{k} = 2·4/4 = 2。

_度分布_ P(k) 是随机选择的顶点具有度 k 的概率。对于均匀随机图（Erdős-Rényi，§6.4），P(k) 近似为均值为 \bar{k} 的泊松分布。对于真实世界图（第7章），P(k) 通常是重尾的且常为幂律。

顶点 i 的 _聚类系数_（clustering coefficient）度量 i 的邻域中三角形的密度。定义为

C_i = \frac{\text{i 的邻居之间的边数}}{k_i (k_i - 1) / 2}

（分母是 k_i 个邻居之间最大可能的边数）。对于我们的四顶点图：顶点 1 的邻居为 {2, 3}，它们相连（边 (2,3) 存在），所以 C_1 = 1/(2·1/2) = 1。顶点 3 的邻居为 {1, 2, 4}；其中唯一的边是 (1,2)，所以 C_3 = 1/(3·2/2) = 1/3。图的平均聚类系数为 \bar{C} = (1/n) ∑_i C_i。

聚类度量图的"团性"：高聚类意味着三角形常见（朋友的朋友是朋友）。真实社交网络与相同密度的随机图相比具有非常高的聚类。这是我们在第7章中将研究的真实网络的普遍特征之一。

两个顶点之间的 _最短路径长度_ d(i, j) 是从 i 到 j 的任何路径中最少的边数。图的 _直径_ 为 max_{i,j} d(i,j)。_平均路径长度_ 为 \bar{d} = (2 / [n(n-1)]) ∑_{i < j} d(i, j)。对于我们的四顶点图：d(1,4) = 2（路径 1-3-4），直径为 2。对于有 n 个顶点的连通图，平均路径长度最多为 n-1。对于随机图和小世界图，它增长得慢得多：通常为 log n 或 (log n)^α（某个 α）。这种对数增长是"六度分隔"发现的数学内容（第7章）：七十亿人网络中的平均路径长度约为 6，而非七十亿。
