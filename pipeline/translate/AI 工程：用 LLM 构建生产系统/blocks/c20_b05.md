* **调试**：如客户报告错误答案，团队看到调用了什么工具、检索了什么数据、agent 在每步做了什么推理。
* **成本归因**：追踪显示 0.018 美元按 span 分解；你可以看到 agent 的 3 次 LLM 调用主导成本。
* **延迟分析**：3.4s 总计分解：240ms 分类 + 800ms + 700ms + 650ms LLM + 工具延迟。团队可以看到时间花在哪里。
* **质量监控**：eval 分数（生产中采样）告知此轨迹的答案是否高质量。生产中低于阈值的分数标记调查。
* **模式分析**：跨多条追踪，团队可以看到分布：平均延迟、常见工具序列、按租户成本。

设置工程量：初始集成 2-3 工程师周；随功能发布持续每功能插桩。


### 19.6 HIPAA 可观测性张力

追踪工具存储 prompt 和响应。对 Beacon Health AI 的临床流水线，prompt 和响应包含 PHI（受保护健康信息）。在 SaaS 可观测性工具中存储 PHI 触发 HIPAA 业务伙伴协议（BAA）要求：

* 供应商必须签署 BAA。
* 数据驻留、访问控制、加密、保留都必须满足 HIPAA 标准。
* 团队必须持续监控合规。

一些 SaaS 可观测性供应商提供 BAA（Langfuse Cloud 在某些计划层级提供 BAA；其他参差不齐）。BAA 选项对一些团队可行。

但对 Beacon，BAA 不够。临床流水线的 PHI 暴露比团队希望交给供应商的更深。团队的决定：**对触及 PHI 的路径自托管可观测性；对非 PHI 内部工具使用 SaaS 可观测性**。

架构：

* **临床笔记摘要器流水线**：追踪流到 Beacon HIPAA 合规基础设施上自托管的 Langfuse。数据驻留保持内部；供应商的 SaaS 层看不到 PHI。
* **CodeReview Bot**（无 PHI）：追踪流到 Langfuse Cloud（SaaS）。更快上手；更低运维负担；适合非监管路径。

分叉可观测性是由数据敏感性驱动的架构选择。2026 年大多数受监管行业团队有类似分割。
