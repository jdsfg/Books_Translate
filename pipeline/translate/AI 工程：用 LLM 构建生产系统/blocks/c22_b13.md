#### 应用题

**Q1.** _设计生产 eval 采样策略_。你的团队客户支持 agent 每月处理 1M 条轨迹。不同功能有不同风险。设计采样策略：按功能采样率、评判模型选择、成本估算、告警集成。

**答案：**

**按功能采样率**：

* 标准客户支持轨迹（700K/月，个体低风险）：3%
* 退款处理轨迹（50K/月，中风险）：8%
* 账户修改轨迹（20K/月，高风险）：15%
* 升级交接（30K/月，间接质量信号）：5%
* 语音轨迹（200K/月，复杂且需不同评判需求）：5%

每月总采样：3% × 700K + 8% × 50K + 15% × 20K + 5% × 30K + 5% × 200K = 21K + 4K + 3K + 1.5K + 10K = 约 40K 采样轨迹。

**评判模型**：gpt-4o-2024-08-06（与主系统 Claude 不同族；避免相关失败）。对语音轨迹，使用能评分语音特定维度（轮次交替、自然度）的模型——可能需要专用评判或扩展评分标准。

**成本估算**：40K × 约 0.003 美元/评判调用 = 120 美元/月。相对于总推理成本可忽略。

**告警集成**：

* 均值分数下降 >0.3（7 天滚动）→ 告警到 AI 工程 Slack。
* 均值分数下降 >0.5（1 天滚动）→ 关键到 PagerDuty。
* 按功能均值下降 vs 基线 → 功能特定告警。
* 按租户均值下降 → 通知客户成功团队。
* 灾难性失败检测 → 即时到安全 + AI 值班。

**仪表板**：生产 eval 仪表板显示按功能/按租户/随时间的均值分数。链接到追踪（第 19 章）以供调查。

**AI 协作子问题**：你会如何请 LLM 帮助完成这个练习，你会在它的回答中验证什么？

**答案：** 有用的 prompt：_为 1M 轨迹/月设计生产 eval 采样策略：按功能采样率、评判模型、成本、告警。_ 你验证 (a) 高风险功能获得更高采样率（LLM 可能默认均匀采样；坚持差异化），以及 (b) 评判模型与生产系统不同族（相关失败预防；LLM 可能忽略此纪律）。

**Q2.** _执行模型升级_。你正在将生产系统从 Claude Sonnet 4 升级到 Claude Sonnet 4.5。规划六阶段的具体活动、时间线和门控标准。

**答案：**

**阶段 1：迁移前评估（第 1-2 周）**

* _活动_：对 Sonnet 4.5 运行生产 eval（2,000+ 黄金轨迹）。比较按维度分数。识别回归和增益。
* _门控标准_：如总体通过率达到或超过基线，或识别的回归被认为可通过 prompt 修复，则进入阶段 2。
* _输出产物_：书面 eval 比较文档。

**阶段 2：prompt 调整（第 3 周）**

* _活动_：对每个识别的回归，调查原因；调整 prompt；重新运行 eval；迭代直到回归解决。
* _门控标准_：如最终 eval 显示无按维度回归 >0.2 分，则进入阶段 3。
* _输出产物_：更新的 prompt 注册表版本；调整后 eval 比较。
