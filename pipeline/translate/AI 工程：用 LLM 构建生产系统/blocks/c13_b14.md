#### 应用题

**Q1.** _设计视觉优先摄取管道_。你的团队有 20 万页保险理赔文档语料库（打字理赔、扫描表格、扫描签名、偶尔手写笔记的混合）。设计视觉优先摄取管道。指定：(a) 每页处理；(b) 故障处理；(c) 成本估算。

提示

§12.5 有管道结构；适配保险理赔。

**答案：**

(a) **每页处理**：

* 将传入 PDF 在 250 DPI 拆分为每页图像（对打字文本和扫描合理的分辨率）。
* 将每页图像发送给 Claude Sonnet 4 Vision（或 GPT-4o Vision），带保险理赔专用提取 prompt：
        提取此保险理赔页面的结构化内容。包括：
        - 文档类型（理赔表、支持文档、签名页等）
        - 理赔人标识（姓名、理赔号）
        - 日期字段
        - 金额
        - 签名（存在性、位置、可读性）
        - 表单字段及其值
        - 任何手写内容（可读则转录）
        - 表格（markdown）


* 将响应解析为 `ClaimPage` Pydantic schema（第 7 章）；验证失败时重试。
* 每页生成块带元数据：页面图像来源、提取置信度、文档类型、理赔人 ID、日期。

(b) **故障处理**：

* VLM 处理失败的页面按原因记录（损坏图像、VLM API 错误、schema 验证失败）。
* 失败页面进入重试队列，用 (i) 不同 prompt 措辞，(ii) 更强模型（前沿 vs 工作马），(iii) 降采样分辨率。恢复率：约 50%。
* 永久失败页面在文档元数据中标记；命中受影响文档的查询包含"不完整文档"警告。

(c) **成本估算**：

* 每页成本：视觉输入（1500 token × 3 美元/1M = 0.0045 美元）+ 文本输入（200 token × 3 美元/1M = 0.0006 美元）+ 输出（1500 token × 15 美元/1M = 0.0225 美元）= **约 0.028 美元/页**。
* 20 万页初始：0.028 美元 × 200,000 = **5,600 美元一次性**。
* 持续：取决于传入理赔量。每天 1,000 个新理赔 × 20 页/理赔 = 2 万页/天 = **约 560 美元/天 = 约 17K 美元/月**。

使用批处理（非时间敏感摄取 50% 折扣）：一次性变为约 2,800 美元；持续约 8,500 美元/月。

对保险公司这是健康投资；工程回报（恢复签名、表格数据、表单字段）相对于成本可观。

**AI 协作子问题**：你会如何请 LLM 帮助完成这个练习，你会在它的回答中验证什么？

**答案：** 有用的 prompt：_为 20 万页保险理赔设计视觉优先摄取管道：每页处理、故障处理、成本估算。_ 你验证 (a) 每页成本分解匹配你检查日期的实际 provider 定价，以及 (b) 故障处理策略操作上可实现（用更强模型重试路径需要显式门控：何时升级？何时放弃？）。
