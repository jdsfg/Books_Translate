### 14.8 Helios 的有界 agent 路径

Helios 的客户支持 agent 经历了三代。进展说明纪律。

**v1（2024）**：5 个工具；无正式界；事件后添加临时断路器。生产失败率：约 3% 轨迹有严重问题。成本方差：巨大（某些轨迹 0.02 美元；罕见轨迹 30 美元+）。

**v2（2025 年初）**：15 个工具；迭代上限（20）；每调用 max-tokens；基本成本跟踪。生产失败率降至约 1%；成本方差显著收紧。

**v3（2026 当前）**：40 个工具；完整四界模式；结构化记忆架构；每工具和每会话断路器；可观测性和告警。生产失败率：约 0.2%。成本方差：第 95 百分位在中位数的 3 倍内。

旅程花了 18 个月。v1 → v3 的成本节省不来自基础设施；来自 _没有异常值轨迹_。高成本尾部主导 v1 的平均成本；通过界消除它们大幅降低平均值而中位性能不变。

达到 v3 的成本：大约 2 个工程师季度的专注工作加持续维护。节省：每月数万美元推理成本避免 + 事故率大幅降低。ROI 一旦测量就清晰。

### 14.9 Triangle Trade-off 侧栏：agent 设计选择（成本分解格式）

单一 Helios 客户支持轨迹的成本分解在生产轨迹分布中平均约 0.18 美元。分解：

* **初始 LLM 推理调用**（约 1500 输入 token + 约 300 输出）：**0.0090 美元**（3 美元/1M 输入，15 美元/1M 输出）
* **工具结果 LLM 续写调用**（平均 3 次工具调用，约 3000 累积输入 token + 约 500 输出）：**0.0165 美元**
* **工具执行成本**：
    * search_knowledge_base（RAG 检索）: 0.0006 美元
    * lookup_order（DB 查询）: 0.0001 美元
    * process_refund 或其他操作: 0.0010 美元
    * **工具执行总计**：0.0017 美元
* **记忆操作**（摘要压缩偶尔触发；每客户档案加载）：**0.0030 美元**
* **可观测性开销**（追踪摄取、日志写入）：**0.0005 美元**
* **每轨迹总计**：**约 0.031 美元**

注意分解总和为 0.031 美元而非 0.18 美元。差距是 _轨迹长度分布_：大多数轨迹短（3-4 次迭代，约 0.03 美元）；一部分长（10-15 次迭代，0.50 美元–1.50 美元）；平均值落在约 0.18 美元因为长尾拉高。上面分解是中位轨迹，非均值。

在 Helios 的规模（每月 1000 万工单，约 50% 有 agent 参与，每月约 500 万轨迹，平均每条 0.18 美元），agent 推理成本约每月 90 万美元，接近报告的每月 100 万+美元推理支出。

要解读的：

1. **工具执行是成本的极小部分**（约 1% 轨迹成本）。纪律在推理层，非工具层。
2. **长尾轨迹主导平均值**。有界工程（§14.4）控制尾部。无界时，平均值将高 3-5 倍。
3. **记忆操作非平凡**（约 10% 轨迹成本）当摘要触发时。值得投资不过度触发的好摘要。
