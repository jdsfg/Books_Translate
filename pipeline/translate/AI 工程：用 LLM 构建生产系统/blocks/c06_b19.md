**Q3.** _合成 PHI eval 构建草图_。为 Beacon Health AI 合成 PHI eval 管道绘制数据流。指出 (a) 输入；(b) 输出；(c) 四个主要转换步骤；(d) 验证步骤。对每个，指出一个风险及其缓解措施。

提示

§5.3 有结构。风险包括重新识别、临床失真和标注者不一致。

**答案：**

(a) **输入**：真实口述临床笔记（含 PHI）；由临床医生标注的结构化参考摘要；结构化 PHI 标注（姓名、日期、病历号等位置）。

(b) **输出**：合成 PHI 笔记（统计等价、HIPAA 安全）；合成 PHI 参考摘要（PHI 替换；临床内容保留）；记录替换映射的清单（保密，永不与合成集共存）。

(c) **四个转换步骤**：

1. **PHI 检测**。使用命名实体识别模型（或为临床 PHI 调优的基于规则的系统）定位每个 PHI 元素。_风险_：遗漏 PHI（假阴性检测）将真实数据泄漏到合成集中。_缓解_：双重检测（两个独立检测器；标记不一致供人工审查）。
2. **替换**。用保留类型和分布的合成等价物替换每个 PHI 元素（姓名 → 同人口统计的随机姓名；日期 → 按每患者偏移移动的日期；病历号 → 随机生成的有效格式标识符）。_风险_：替换保留足够结构以允许重新识别（例如，日期偏移太小；罕见姓名替换确定性地映射）。_缓解_：随机化每元素偏移；大姓名池；审查不寻常案例。
3. **临床保留**。状况、药物、剂量、化验值：精确保留。_风险_：临床细节本身在小人群中是 PHI（例如，小诊所中非常罕见的诊断）。_缓解_：标记罕见临床细节供额外审查；排除无法缓解重新识别风险的案例。
4. **参考摘要映射**。临床医生标注的参考摘要针对合成笔记重新生成（替换映射同时应用于笔记和摘要，使摘要中的 PHI 与合成笔记中的 PHI 匹配）。_风险_：笔记和摘要之间的映射不一致创建 eval 会解释为模型失败的人为错误。_缓解_：确定性映射应用；自动检查合成摘要仅引用合成 PHI 元素。

(d) **验证步骤**：10% 样本的临床医生审查。临床医生确认合成笔记临床现实、替换保留临床信号且无真实 PHI 泄漏。_风险_：验证样本太小无法检测罕见泄漏。_缓解_：分层抽样（过采样 PHI 密度更高的类别，如心理健康就诊）；定期全面审计。
