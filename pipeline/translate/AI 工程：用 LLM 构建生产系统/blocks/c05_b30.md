**讨论：** **支持完全替代**：2026 年的 LLM 评判者在量表清晰且领域在分布内的任务上已经比人工更一致（无疲劳、无会话间校准漂移、无班次间变异性）。模型能力轨迹表明这将会扩大。到 2030 年，在领域特定标注指南上微调的前沿评判者模型可能在许多任务上超越中位人工标注者，成本差异（人工 50–400 美元/小时 vs LLM 评判者每案例几分之一美分）将强力推动团队走向仅评判者 eval。§4.5 构建的纪律（校准、不同家族评判者、长度中立、位置偏见控制）成为标准实践，人工标注缩小到无法建立校准的案例。

**反对完全替代**：人工标注因至少三个结构性原因持续存在。第一，**校准需要 ground truth**，而 ground truth 本身在链条某处由人工产生；链条可能远离生产循环但不能消失。从未对人工校准的评判者是偏见未知的评判者。第二，**监管和可审计性期望**在医疗、法律和金融等领域将人工审查视为程序上重要的，无论统计性能如何；仅 LLM 的 eval 管道可能统计上健全但在监管纠纷中程序上不可辩护。第三，**边缘案例漂移**，注意到漂移的人工是标注新边缘的人工；在昨天标签上训练的 LLM 评判者不会浮现明天的新颖输入。系统需要定期新鲜的人工信号。

LLM 作为评判者首先替代人工的领域可能是 **面向消费者内容的风格和语气相关量表**（这封邮件听起来友好吗？这个产品描述匹配品牌声音吗？）。错误分数的代价低，校准可大规模进行，人工在这些维度上已经足够不一致以至于匹配中位人工一致性的 LLM 评判者是可接受的。

人工标注持续最久的领域可能是 **临床和安全关键判断，其中错误分数的代价是灾难性的且监管标准将人工审查视为程序上必不可少的**。成本差异在每案例高风险时不太重要；可审计性故事更重要；出错的案例恰恰是人工信号最有价值的案例。Beacon 的药物处理维度（上面 Q6）正是这类案例：即使 2030 年的 LLM 评判者平均能评分好，标注投资承载着产生评判者本应对其校准的 ground truth 的负担，而那个负担在安全关键领域不会消失。

诚实的答案是 LLM 作为评判者将在边际上取代大量人工标注并在长尾中作为互补而非替代持续存在。eval 纪律比以往更重要；改变的是产生标签的劳动力组合。
