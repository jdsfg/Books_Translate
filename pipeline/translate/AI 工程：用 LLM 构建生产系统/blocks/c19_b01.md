### 18.1 Token 经济学：你实际在为什么付费

回顾第 3 章 §3.7 的每调用成本分解。一般形态：

* **输入 token** 按百万计费；因模型而异。
* **输出 token** 按百万计费；通常为输入费率的 4-5 倍。
* **视觉 token**（图像输入）单独计费；通常按输入费率定价。
* **音频 token**（输入/输出）对语音模型单独计费。
* **Prompt 缓存**（适用时）将输入成本转为两种费率：写入（略高于基线）和读取（远低）。
* **批量推理** 对异步工作负载按折扣计费。

2026 年成本经济学现实：

* **输出是大多数生产系统的主导成本**。5 倍输出乘数意味着 1000 token 输出每 token 成本是 1000 token 输入的 5 倍。减少输出（无质量损失）的工程举措产生超比例成本节省。
* **缓存输入几乎免费**。以 Anthropic 0.1 倍读取费率，缓存的 1500 token 系统 prompt 每调用成本约 0.0005 美元（vs 未缓存 0.0045 美元）。在高量时，缓存 vs 未缓存的差距是盈利与不盈利的区别。
* **工作马模型比前沿模型便宜 10-25 倍**。路由（第 17 章）是最大杠杆；缓存是第二。

成本优化的三个原则：

**原则 1：缓存稳定内容**。系统 prompt、工具定义、few-shot 示例、跨调用稳定的检索内容前缀。prompt 缓存功能在此部分提供 90% 成本降低。

**原则 2：批量非时间敏感工作**。文档摄取、eval 运行、回填、摘要任务。如你能容忍异步，50% 批量折扣是免费的。

**原则 3：减少输出长度**。结构化输出格式比散文更短；停止序列限制不必要续写；prompt 中"简洁"指令产生更短输出。每次减少乘以输出成本费率。
