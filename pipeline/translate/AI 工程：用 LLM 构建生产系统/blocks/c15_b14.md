2. **目标导向行为与中间决策。** 在一次性工具调用中，LLM 不在调用工具或组合答案之间 _选择_；schema 决定是否需要工具。在有界循环中，LLM 在每步决定：_调用另一个工具、向用户提澄清问题、升级到人工，或组合最终答案_。这是代理的结构定义：LLM 对自己的下一步行动做决策，而非仅对固定输入生成响应。

为什么这些证明 _agent_ 术语合理：_agent_ 一词暗示通过自主行动追求目标的系统。工具增强 LLM 用一次工具调用响应一次查询；agent 跨多次工具调用追求目标，选择行动以推进目标，有界循环是其行动选择机制。界使自主性安全（灾难尾部裁剪）；无界时，自主工具调用危险；有界时，它是生产 agent 的基础。

框架对工程决策重要。构建"我们希望 LLM 也调用此 API"的团队可保持为一次性工具增强 LLM（更简单架构、无 agent 循环、无界基础设施）。构建"我们希望 LLM 调查问题并追求解决"的团队需要承担 agent 的完整基础设施（循环、界、记忆、可观测性）。跳过基础设施产生 §14.1 所称的 _无界原型_：它们在演示中工作在生产中崩溃。

交叉引用：第 15 章将此进一步扩展到多个有界循环协调的多 agent 系统；每个 agent 仍是本章意义上的 agent，系统层添加协调作为新涌现属性。
