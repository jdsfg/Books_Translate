#### 应用题

**Q1.** _估算特定功能的缓存节省_。你的团队有客户支持聊天机器人。系统 prompt：2000 token，稳定；工具定义：1500 token，稳定；每调用用户消息：约 200 token；输出：约 400 token。流量：10 万调用/天。当前无缓存。估算对稳定部分启用 Anthropic prompt 缓存的节省。

**答案：**

当前每调用成本（Sonnet 4 定价）：

* 输入（稳定系统 + 工具 + 动态用户）：(2000 + 1500 + 200) × 3 美元/100 万 = 0.0111 美元
* 输出：400 × 15 美元/100 万 = 0.006 美元
* 总计：0.0171 美元

对系统 + 工具缓存（3500 稳定 token）：

在 5 分钟窗口的首次调用上：

* 3500 token 的写入溢价：3500 × 3.75 美元/100 万 = 0.0131 美元（vs 未缓存 0.0105 美元 — +0.0026 美元）
* 动态输入：200 × 3 美元/100 万 = 0.0006 美元
* 输出：0.006 美元
* 总计：0.0197 美元（因写入溢价略多）

在同一 5 分钟窗口的后续调用上：

* 3500 token 的缓存读取：3500 × 0.30 美元/100 万 = 0.00105 美元
* 动态输入：200 × 3 美元/100 万 = 0.0006 美元
* 输出：0.006 美元
* 总计：0.00765 美元

假设缓存命中率 80%（窗口中大多数调用命中缓存）：

* 每调用：0.2 × 0.0197 美元 + 0.8 × 0.00765 美元 = 0.00394 美元 + 0.00612 美元 = 0.01006 美元

相比未缓存的节省：(0.0171 美元 - 0.01006 美元) / 0.0171 美元 = 约 41% 降低。

日节省：10 万 × (0.0171 美元 - 0.01006 美元) = 704 美元/天。

月节省：约 21K 美元/月在此功能上。

启用缓存的工程量约 1 工程师天（用 `cache_control` 标记稳定前缀）。回本以天计。

**AI 协作子问题**：你会如何请 LLM 帮助完成这个练习，你会在它的回答中验证什么？

**答案：** 有用的 prompt：_估算 Anthropic prompt 缓存节省：2000 token 系统 prompt、1500 token 工具、200 token 用户消息、400 token 输出、10 万调用/天、80% 缓存命中率。_ 你验证 (a) LLM 使用正确的缓存写入/读取乘数（1.25 倍 / 0.1 倍，非其他值），以及 (b) 算术正确通过重新乘一遍。

**Q2.** _设计语义缓存_。Strata 法律科技 RAG 有约 5 万查询/天。约 30% 查询与近期查询释义等价。设计语义缓存：相似度阈值、TTL、假阳性控制、预期节省。

**答案：**

**相似度阈值**：0.94。法律查询有特定术语；0.94 阈值过滤大多数非释义匹配同时捕获大多数真正释义。

**TTL**：2 小时。法律信息可变（法规修订、案例推翻）；2 小时平衡缓存效用与过时风险。对时间敏感查询（日期限定），TTL 更短（10 分钟）或不缓存。

**假阳性控制**：

1. _保守阈值_（0.94 vs 不太仔细的团队可能用的更低 0.92）。
2. _LLM 验证步骤_：当找到缓存候选时，快速 Haiku 级 LLM 调用验证它是真正释义（"这两个查询对法律研究目的是否语义等价？回答是/否并简述理由。"）。成本约 0.0005 美元；相对于 Sonnet RAG 调用（约 0.014 美元）小。
3. _按领域调优_：涉及管辖权或时间约束的查询用更高阈值（0.97）或不缓存，因为这些领域的释义等价性脆弱。
4. _漂移检测_：每周采样缓存响应对新鲜查询重新 eval；如质量下降，提高阈值。
