**答案：** 有用的 prompt：_为语音 agent 工程化回退到文本路径：失败检测、状态保留、延迟预算、优雅恢复。_ 你验证 (a) 失败检测覆盖多种模式（非仅一种），以及 (b) 状态保留在语音 API 如何暴露其状态的现实中可行（LLM 可能假设 API 暴露比实际更多；对照实际提供商文档检查）。

**Q4.** _计算语音部署成本_。基于章节数据估算 Helios 语音渠道的每通话成本。假设：5 分钟通话、8 次 LLM 往返、通话一半音频用 TTS（其余是端到端模型音频）。用 2026 定价：OpenAI Realtime 约 200 美元/百万输入音频 token、约 400 美元/百万输出音频 token；文本 LLM 按第 3 章；ElevenLabs TTS 约 0.30 美元/1000 字符。

**答案：** 粗略估算（2026 定价近似；因提供商计划而异）：

对 5 分钟通话（注意：2026 年语音定价按分钟报价；OpenAI Realtime 约 0.30 美元/分钟合并输入+输出）：

* **语音模型**：5 分钟 × 0.30 美元/分钟 = **1.50 美元**
* **文本 LLM 往返**（用于工具执行；8 轮）：8 × 0.012 美元（典型 Sonnet 4 调用）= **0.10 美元**
* **回退部分 TTS**（2.5 分钟，约 2500 字符/分钟 = 6250 字符）：6.25K × 0.30 美元/1K = **1.88 美元**
* **归档 STT**（Deepgram，0.005 美元/分钟）：5 × 0.005 美元 = **0.025 美元**

**列表价格每次通话总计**：约 3.50 美元，处于 §20.8 引用的无批量合同团队 1-4 美元/通话列表费率范围顶部。

章节 §20.8 的 0.28 美元/通话数字是 Helios 的 _合同_ 成本：占 10M 工单/月的 12%，Helios 处于其语音模型提供商和 TTS 供应商的最高每分钟定价层级（此量的企业折扣通常为列表的 80-92% 折扣，这就是 3.50 美元 → 0.28 美元压缩的来源）。上面的列表费率估算是一个新团队首次建模语音时应预期的；一旦达到生产量，边际成本大幅压缩。结构性教训——语音明显比文本贵且必须由量、差异化或人工交接成本节约证明合理——在任一价格点都成立。

练习说明：**语音成本是真实的且非平凡的**。对比文本渠道（0.18 美元/通话），语音明显更贵。语音的商业案例必须证明成本合理：通常通过量、客户体验差异化或成本 vs 人工 agent 的权衡（人工 agent 全面成本 5-10 美元/通话；即使昂贵的 AI 语音也胜过它）。
