### O

**可观测性**：让你实时理解 AI 系统在做什么的收集实践（追踪、日志、指标、生产数据上的 eval）（第 19 章，§19.1）。

**观察验证**：在将工具输出反馈给 agent 前检查其匹配预期 schema 和策略。对抗基于工具结果的注入的防御（第 13 章，§13.5，第 23 章，§23.3）。

**OCR**：光学字符识别。许多文档 RAG 管道的前置步骤；2026 年越来越多被直接多模态检索（ColPali）替代（第 12 章，§12.4）。

**Ollama**：带简单 CLI 和库 API 的本地模型运行器。在开发者笔记本上运行开放权重模型的默认方式（第 22 章，§22.6）。

**设备端推理**：在用户设备而非服务器上运行模型。以模型大小换取隐私、离线能力和零边际成本（第 22 章，§22.6）。

**OpenAI Realtime**：OpenAI 基于 WebSocket 的实时语音到语音 API。低延迟语音 agent 的参考平台（第 20 章，§20.5）。

**开放权重**：参数可公开下载的模型，有无完全开放许可。2026 年技术栈建立在闭源 API 和开放权重模型的混合之上（第 22 章，§22.1）。

**编排者-工作者**：一个 agent 将子任务分派给专门工作者并综合结果的多 agent 模式。最可靠的多 agent 拓扑（第 15 章，§15.2）。

**OSWorld**：在真实桌面任务上评估计算机使用 agent 的基准。当前分数展示了演示与生产之间的差距（第 15 章，§15.6）。

**输出安全**：在模型输出到达用户或工具前应用的安全检查类别：PII 脱敏、内容过滤、拒绝分类器、schema 验证（第 23 章，§23.2）。

**输出验证**：在下游使用前在代码中对输出应用的 schema、策略和语义检查。最后一道可靠防线（第 23 章，§23.3）。

**现成模型**：通过托管 API 可用且无需训练的模型。2026 年几乎每个 AI 功能的起点（第 22 章，§22.1）。
