### H

**幻觉**：自信、流畅但事实上错误的输出。通过 RAG、引用接地和拒绝训练缓解但未消除（第 2 章，§2.6，第 11 章，§11.7）。

**Helicone**：开源 LLM 可观测性平台，成本和缓存分析强。Langfuse 的轻量替代（第 19 章，§19.3）。

**分层上下文**：将 prompt 上下文组织为树（系统 → 任务 → 检索 → 查询）而非扁平列表。改善模型对指令的遵从（第 8 章，§8.4）。

**分层分解**：顶层 agent 将目标分解为子目标分派给专门 agent 的多 agent 模式。"编排者-工作者"模式（第 15 章，§15.2）。

**HIPAA**：美国医疗隐私法规，治理 PHI。定义什么算 PHI、谁可访问以及供应商的 BAA 框架（第 19 章，§19.6）。

**混合搜索**：结合词法（BM25）和语义（向量）检索，通常用 RRF 融合。2026 年的默认检索设置（第 10 章，§10.5）。

**HyDE**：假设文档嵌入。查询扩展技术，生成假的"理想答案"并嵌入它而非原始查询。查询比文档短得多时有用（第 11 章，§11.2）。

**人在回路**：人类在 LLM 输出生效前批准、编辑或覆盖的工作流。任何不可逆操作的正确默认（第 13 章，§13.6）。

### I

**"我不知道"模式**：显式训练或提示使模型在证据不足时拒绝或推迟。校准的行为表达（第 23 章，§23.5）。

**幂等性**：请求发送一次或多次产生相同效果。提供商幂等键让你安全重试不重复收费或重复操作（第 3 章，§3.5）。

**间接 prompt 注入**：恶意指令嵌入在检索或工具获取内容（网页、文档、邮件）中的攻击。LLM 安全威胁中最难的类别（第 23 章，§23.3）。

**指令模型**：经过指令微调和对齐的基础模型。你几乎总是实际想调用的（第 2 章，§2.3）。

**中断处理**：检测用户开始对 agent 说话并停止或让步的逻辑。自然语音 UX 必需（第 20 章，§20.6）。

**轨迹内摘要**：上下文窗口紧张时将 agent 轨迹的先前步骤压缩为摘要。标准记忆压力缓解（第 14 章，§14.5）。

**迭代上限**：agent 在强制终止前可运行的最大思考-行动-观察循环数。总是设定；默认值太高（第 14 章，§14.4）。

**推理成本**：生产中运行模型的变量成本，托管模型由 token 主导，自托管由 GPU 时间主导（第 18 章，§18.1）。

**推理端点**：暴露模型用于推理的 URL，无论由提供商托管还是自部署（第 22 章，§22.5）。
