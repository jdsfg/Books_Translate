### 22.3 2026 年的开放权重格局

开放权重模型（由实验室发布且权重可下载）在 2026 年是真实的生产选项。主要家族：

**Llama 4+（Meta）**：部署最广泛的开放权重家族。多种尺寸（8B、70B、405B）。强大的通用性能；大多数用途的宽松许可。大多数团队的默认开放权重选择。

**Qwen（阿里巴巴）**：多语言任务上表现强劲；在相似尺寸上与 Llama 竞争力相当；强大的中文支持。

**DeepSeek（DeepSeek Inc.）**：竞争成本下的强大推理能力；2026 年的 DeepSeek V3 是工作模型级别的替代。

**Mistral（Mistral AI）**：欧洲基地；7B-22B 范围的强大模型；特别适合欧洲数据驻留重要的任务。

**Gemma（Google）**：更小模型（2B、7B、27B）；强大的每参数质量比。

开放权重模型何时在实践中替代托管 API 模型？

**开放权重适用**：

* 数据敏感性排除托管 API（PHI；机密；气隙环境）。
* 在非常高量下成本经济有利于自托管（通常持续 >50M+ token/天）。
* 托管提供商不支持的定制微调需求。
* 边缘/设备端部署（§22.5）。

**开放权重不适用**：

* 质量要求需要前沿（开放权重模型有竞争力但前沿闭源 API 模型——Claude Sonnet 4、GPT-4o、Gemini 2.5 Pro——通常领先几个百分点）。
* 团队缺乏自托管的运维能力（真实工程工作）。
* 量不足以证明运行推理基础设施的固定成本。

2026 年实践中：开放权重存在于边缘或成本敏感的专门案例；托管 API 处理一般生产用途。
