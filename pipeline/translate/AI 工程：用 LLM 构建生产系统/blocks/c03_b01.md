### 2.1 LLM 实际是什么：工程师层面

让我们剥开来看。

大语言模型是一个函数。这个函数接受一个 token 序列（我们稍后讨论那些是什么）并返回下一个 token 应该是什么的概率分布。这就是整个函数签名：

    next_token_distribution = model(token_sequence)

其他一切（聊天机器人、agent、RAG、结构化输出、语音助手、使用计算机的 agent）都是围绕这一个函数的封装。你取一个 token 序列，你问模型下一个 token 应该是什么，模型给你一个分布，你从分布中采样，你把采样的 token 追加到你的序列中，你用更长的序列再次调用模型。你这样做直到模型发出一个表示 _停止_ 的特殊 token，或者直到你从外部决定停止（max tokens、stop sequence、你的耐心耗尽了）。

这就是循环。把上一段读两遍；整个领域从中展开。你在接下来 23 章中看到的每一个架构模式都是一种巧妙地准备输入序列、或巧妙地约束输出采样、或巧妙地将输出反馈到其他东西中的方式。模型本身做那一件事：_给定一个序列，给我下一个 token 的分布。_
