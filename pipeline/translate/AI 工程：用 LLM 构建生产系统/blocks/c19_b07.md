### 18.7 推理延迟优化，简述

成本和延迟相关但不同。延迟的快速笔记：

* **流式**（第 3 章 §3.2）减少首 token 时间，即使总挂钟时间不变也改善用户感知。
* **并行化**：多个工具调用并行；多个 LLM 调用并行（当独立时）。有时是正确架构（RAG 检索 + LLM 调用并行；LLM 调用不等待检索）。
* **推测解码**（提供商侧优化）：模型一次推测预测多个 token；推测成功时更快。大多数主要提供商在 2026 年透明地提供此功能。
* **工作马模型既快又便宜**。对延迟敏感路径路由到工作马是双赢。

延迟工程是独立纪律；对成本优化，相关延迟笔记是：**工作马层模型同时给你成本和延迟收益**。路由决策应权衡两者。
