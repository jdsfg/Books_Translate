#### 应用题

**Q1.** 你在谈判法律和解。对方现在给你 150,000 美元以撤诉。你的律师估计有 60% 的概率你会在审判中胜诉并获得 300,000 美元，40% 的概率你会败诉并一无所获。无论结果如何，审判费用都是 30,000 美元。你应该接受和解吗？展示你的期望值计算。

提示

记住在计算打官司的 EV 时，要从审判结果中减去审判费用。

**答案：** 和解的 EV：150,000 美元（无审判费用）。

打官司的 EV：

* 胜诉（60% 概率）：获得 300,000 美元 − 30,000 美元审判费用 = 270,000 美元
* 败诉（40% 概率）：获得 0 美元 − 30,000 美元审判费用 = −30,000 美元

EV(审判) = 0.60 × 270,000 美元 + 0.40 × (−30,000 美元) = 162,000 美元 − 12,000 美元 = 150,000 美元

打官司的 EV 是 150,000 美元，恰好等于和解出价。在期望值基础上，你无差异。但额外因素重要：（1）风险承受力：和解是确定的；审判有方差（你可能得到 270,000 美元或 −30,000 美元）。如果你很快需要钱或无法承受 30,000 美元损失，就和解。（2）非货币因素：审判的压力、时间和情感成本。（3）概率准确度：60% 是可靠估计还是不确定？如果概率不确定，和解减少了那种不确定性。（4）当 EV 相等时，这些考量一般偏向和解——确定性有独立价值。

**Q2.** 你有机会用 10 美元买一份 50 美元电器的延保。历史上，这些电器中有 8% 在保修期内需要维修，平均维修成本是 80 美元。你应该买延保吗？计算期望值，并解释 EV 之外什么因素可能影响你的决策。

**答案：** 维修风险的 EV（无延保）：

* 需要维修的概率：8% = 0.08
* 期望维修成本：0.08 × 80 美元 = 6.40 美元

买延保的 EV：你付 10 美元来覆盖 6.40 美元的期望成本。延保的 EV 是 −3.60 美元（你比覆盖的期望值多付了 3.60 美元）。这是负 EV——平均而言，不买延保你会省钱。然而，可能证明购买合理的因素：（1）方差减少：没有延保，你面对 92% 的概率付 0 美元和 8% 的概率付 80 美元。如果当时 80 美元维修确实痛苦，方差减少对你可能值 3.60 美元。（2）安心：有些人觉得不确定性本身就有压力，花 3.60 美元减少焦虑可能是理性购买。一般而言，低成本物品上的低成本延保不是好的财务决策，因为负 EV 在所有此类购买中累积。一般规则：为你无法承受的损失买保险；对你能轻松承受的损失自我保险。

**Q3.** 一位风险投资家在决定对初创公司 S 投资多少。她估计：5% 概率初创回报投资的 50×；20% 概率回报 3×；75% 概率回报 0×（完全损失）。她在考虑投资 100,000 美元或 500,000 美元。计算每个投资金额的 EV，并讨论还有什么其他考量重要。

**答案：** EV 计算（每投资一美元）：每美元 EV = 0.05 × 50 + 0.20 × 3 + 0.75 × 0 = 2.50 + 0.60 + 0 = 3.10
