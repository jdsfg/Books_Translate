#### 概念检查

**Q1.** 计算以下决策的期望值：你投资 1,000 美元。有 40% 的概率你的投资增长到 1,800 美元，40% 的概率它返回你原来的 1,000 美元，20% 的概率你失去一切。

**答案：**

* 结果 1：1,000 美元投资增长到 1,800 美元 → 净收益 = 800 美元，概率 40%
* 结果 2：返回 1,000 美元 → 净收益 = 0 美元，概率 40%
* 结果 3：返回 0 美元 → 净损失 = 1,000 美元，概率 20%

EV = 0.40 × (+800 美元) + 0.40 × (0 美元) + 0.20 × (−1,000 美元)
EV = 320 美元 + 0 美元 − 200 美元
EV = +120 美元

这一投资的期望值是每投资 1,000 美元 +120 美元，或 12% 的期望回报。这是否是好投资取决于方差（结果范围很宽）、你的风险承受力，以及是否存在更好的替代方案。

**Q2.** 解释为什么彩票的期望值几乎总是负的，而理性的人可能仍选择购买。买彩票是非理性的吗？

提示

想想参与彩票的价值是否完全被票的美元回报所捕获。

**答案：** 彩票有负期望值，因为彩票被设计成那样——组织者保留利润空间。典型的大型彩票每美元期望奖金价值约返回 0.40–0.60 美元。因此一张 2 美元的票 EV 大约是 −0.80 到 −1.20 美元。从纯粹财务角度看，这是负 EV 购买。然而，若干事情使购买彩票并非明显非理性：（1）娱乐价值：许多人买彩票是为了期待的体验和短暂参与"如果……会怎样"的情景——一种对他们有价值的服务。如果 2 美元买到 2 美元的娱乐价值，包含非货币因素的总 EV 约为零。（2）边际效用：对收入非常有限的人，小概率的改变人生的头奖可能代表一种真正被珍视的不对称，期望美元捕获不了。（3）然而，习惯性买彩票（把显著收入花在彩票上）很难合理化——在规模上，负 EV 显著累积。判断：偶尔买彩票并非明显非理性；习惯性大量购买则是。
