### 21.5 用 AI 做决策分析：大语言模型

大语言模型（LLM）——支撑 ChatGPT、Claude 及其他工具的技术——具有与决策制定特别相关的能力：

**选项生成：** LLM 可以快速生成你可能未考虑的广泛选项集。它们读得足够广，知道领域专家因其专业化而例行错过的替代方案。

**事前复盘协助：** 你可以请 LLM"想象这一决策已做出并失败——哪里出了错？"并收到多样的失败情景。这不是真正团队事前复盘的替代，但可以补充它。

**论证钢人化：** LLM 可以生成你不同意之论证的最强版本——有助于测试你自己立场的极限。

**框架效应重述：** LLM 可以用多个框架重述决策（收益框 vs. 损失框、不同参照点），帮助你检查评估是否依赖框架。

**对 LLM 局限的敏感：** LLM 会幻觉——它们生成听起来自信但事实不正确的文本。它们在以下方面特别不可靠：特定数字（人口、日期、统计）、近期事件（训练数据有截止点），以及训练覆盖之外的狭窄技术问题。用 LLM 做思维结构与选项生成；独立核实特定事实主张。
