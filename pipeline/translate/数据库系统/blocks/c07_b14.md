#### 应用问题

**Q1.** 考虑如下关系：

    EnrollmentLog(student_id, student_name, course_id, course_title,
                  instructor_id, instructor_name, enrollment_date, grade)

FD 如下：

* student\_id \rightarrow student\_name
* course\_id \rightarrow course\_title, instructor\_id
* instructor\_id \rightarrow instructor\_name
* \{student\_id, course\_id\} \rightarrow enrollment\_date, grade

(a) 候选键是什么？(b) 这个 Schema 是否满足 2NF、3NF、BCNF？说明理由。(c) 把它分解到 BCNF，并检查你的分解是无损连接且依赖保持的。

提示

(a) 从那些从未出现在任何 FD 右侧的属性开始——它们必须在每个候选键中。

**答案：**

**(a) 候选键。** `student_id` 和 `course_id` 从不出现在任何 FD 的右侧，所以它们必须在每个候选键中。计算 \{student\_id, course\_id\}^+：

* 起始：\{student\_id, course\_id\}。
* student\_id \rightarrow student\_name：加入 `student_name`。
* course\_id \rightarrow course\_title, instructor\_id：加入这些。
* instructor\_id \rightarrow instructor\_name：加入 `instructor\_name`。
* \{student\_id, course\_id\} \rightarrow enrollment\_date, grade：加入这些。

闭包覆盖所有属性。\{student\_id, course\_id\} 是超键，且最小（单独一个不够）。因此**唯一候选键是** \{student\_id, course\_id\}。

**(b) 范式。**

* **2NF？** `student_name` 只依赖于 `student_id`（对复合键的部分依赖）。违反。不满足 2NF。
* **3NF？** 连 2NF 都不满足，自然不满足 3NF。
* **BCNF？** 连 3NF 都不满足，自然不满足 BCNF。

**(c) BCNF 分解。** 对每个有问题的 FD 进行分解：

* 通过 student\_id \rightarrow student\_name 分离 `student_name`：

        Students(student_id, student_name)

* 通过 course\_id \rightarrow course\_title, instructor\_id 分离 `course_title`、`instructor\_id`：

        Courses(course_id, course_title, instructor_id)

* 通过 instructor\_id \rightarrow instructor\_name 分离 `instructor\_name`：

        Instructors(instructor_id, instructor_name)

* 剩余：

        Enrollments(student_id, course_id, enrollment_date, grade)
