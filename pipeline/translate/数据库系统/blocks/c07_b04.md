#### 算法：计算 X^+

    X_plus = X
    repeat:
      for each FD Y -> Z in F:
        if Y \subseteq X_plus:
          X_plus = X_plus \cup Z
    until X_plus stops changing
    return X_plus

工作示例。考虑关系 R(A, B, C, D, E)，FD 集合：

* A \rightarrow B
* BC \rightarrow D
* D \rightarrow E

计算 \{A, C\}^+：

起始：\{A, C\}。应用 A \rightarrow B：A \in \{A, C\}，加入 B。现在 \{A, B, C\}。  
应用 BC \rightarrow D：\{B, C\} \subseteq \{A, B, C\}，加入 D。现在 \{A, B, C, D\}。  
应用 D \rightarrow E：D \in \{A, B, C, D\}，加入 E。现在 \{A, B, C, D, E\}。  
无法再扩展。

因此 \{A, C\}^+ = \{A, B, C, D, E\} —— 即 \{A, C\} 决定 R 的_每一个_属性。这使 \{A, C\} 成为 R 的一个**超键（superkey）**。


#### 用闭包找候选键

定义（回顾）：R 的候选键是最小超键。找一个候选键的方法：

  1. 从候选集 X 开始（通常是全部属性）。
  2. 对 X 中的每个属性 A，检查：X - \{A\} 的闭包是否仍等于 R？
     * 若是，从 X 中去掉 A。
     * 若否，A 是必需的——保留。

工作示例，沿用上面的 R(A, B, C, D, E) 和 FD A \rightarrow B、BC \rightarrow D、D \rightarrow E：

从 \{A, B, C, D, E\}（所有属性）开始。它显然是超键。现在剪枝：

* 去掉 E？\{A, B, C, D\}^+ = ? \{A, B, C, D\} 已含 D，且 D \rightarrow E，所以闭包是 \{A, B, C, D, E\}。仍是超键。去掉 E。
* 去掉 D？\{A, B, C\}^+ = ? A \rightarrow B 已覆盖。BC \rightarrow D —— \{B, C\} \subseteq \{A, B, C\}，所以加入 D。然后 D \rightarrow E，加入 E。闭包为全部五个属性。仍是超键。去掉 D。
* 去掉 B？\{A, C\}^+ —— 我们上面计算过：全部五个属性。超键。去掉 B。
* 去掉 A？\{C\}^+ —— 只有 C，没有 FD 可触发，闭包是 \{C\}。不是超键。保留 A。
* 去掉 C？\{A\}^+ —— A \rightarrow B 给出 \{A, B\}。BC \rightarrow D 需要 C，不能触发。闭包是 \{A, B\}。不是超键。保留 C。

候选键：\{A, C\}。最小超键——去掉 A 或 C 都会破坏超键性质。

如果需要找_所有_候选键（而不只一个），则系统性地尝试越来越大的属性子集并检查闭包。小 Schema 可以手算；大 Schema 则机械完成。
