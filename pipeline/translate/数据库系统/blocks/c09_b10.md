#### 应用问题

  7. 把下面相关子查询改写成连接：

         SELECT s.id, s.name
         FROM Students s
         WHERE s.gpa = (SELECT MAX(gpa) FROM Students WHERE dept_id = s.dept_id);

     说明改写是否在所有情况下等价，以及如果一个院系两名学生并列最高 GPA 会发生什么。

  8. 写两条 SQL 都回答“列出当前没有选课的所有课程”，一条用 `NOT EXISTS`，一条用 `LEFT JOIN ... WHERE ... IS NULL`。当 `Enrollments.course_id` 可为 NULL 时，哪个更安全？为什么？

提示

想清楚每种形式实际检查什么。`NOT EXISTS` 测试该课程是否存在任何匹配行；`LEFT JOIN ... IS NULL` 测试连接右侧是否没有产生匹配。再问：当 `Enrollments.course_id` 本身为 NULL 时，各自会怎样？

  9. 用窗口函数写一条 SQL：对每名学生，显示其当前 GPA 以及有记录以来的最高 GPA（假设有表 `gpa_history(student_id, term, gpa)`）。使用 `MAX(gpa) OVER (PARTITION BY student_id)`。

  10. 视图 `recent_enrollments` 定义为 `SELECT * FROM Enrollments WHERE term >= '2025-Fall'`。查询 `SELECT * FROM recent_enrollments WHERE student_id = 42` 运行时，引擎会扫描整张 Enrollments 表还是只扫描 2025-Fall 及以后的行？解释谓词下推。

  11. 一个 `CREATE MATERIALIZED VIEW` 在 200 GB 事务型数据库上刷新需要 8 小时。提出两种策略，在不每天停机 8 小时的前提下保持视图相对新鲜。

提示

200 GB 里实际有多少在两次刷新之间变化？如果只是一小部分，问题就变成如何避免重算其余部分。考虑按时间分区并交换分区，或在写入到达时增量维护视图。

  12. 使用 Schema `Orders(order_id, customer_id, order_date, amount)`，写一条窗口查询：对每条订单，返回该客户按日期排序的累计消费额。然后把它改成**7 天滑动窗口和**。

提示

两种形式都使用 `PARTITION BY customer_id ORDER BY order_date`。差别在 frame 子句：运行总和默认 frame 是 `ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`。7 天窗口则要用基于时间的 RANGE frame，而不是基于行。
