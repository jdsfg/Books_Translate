#### 为什么 SQL 翻译用双重否定

除法表达**全称量词**（“对所有”）。SQL 没有直接的全称量词——它有 `EXISTS`（存在量词）和否定。逻辑恒等式

\forall y \in S,\ P(y) \quad\Leftrightarrow\quad \neg\, \exists y \in S,\ \neg P(y)

让我们可以把“对 S 中每个 y，某性质成立”重写为“不存在 S 中使该性质不成立的 y”。这就是双重 `NOT EXISTS` 翻译的形式依据。应用到本例：

* 外层查询选一个学生 `s`。
* *全称条件*：对每门必修课 `rc.course_id`，在 `Enrollments` 中都存在一条 `(s.id, rc.course_id)` 记录。
* *双重否定形式*：不存在一门必修课 `rc.course_id`，在 `Enrollments` 中找不到匹配记录。

    SELECT s.id FROM Students s
    WHERE NOT EXISTS (                             -- 不存在必修课...
      SELECT 1 FROM RequiredCourses rc
      WHERE NOT EXISTS (                           -- ...使得没有匹配选课...
        SELECT 1 FROM Enrollments e
        WHERE e.student_id = s.id AND e.course_id = rc.course_id
      )
    );

两层 `NOT EXISTS` 不是风格选择——而是 SQL 缺少 `\forall` 量词所迫。这是 SQL 中最有用的模式之一：当问题包含“每个”“所有”或“对每个……必须”时，双重 `NOT EXISTS` 通常是正确形状。（第 8 章会再次遇到这个模式。）
