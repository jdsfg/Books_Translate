#### 定义：标量子查询

**标量子查询**返回恰好一列、至多一行。它可以出现在任何需要单值的地方——SELECT 表达式、WHERE 比较、ORDER BY。

    SELECT s.id, s.name,
           (SELECT AVG(grade) FROM Enrollments WHERE student_id = s.id) AS gpa
    FROM Students s;

对每个学生行，标量子查询运行并返回一个平均值。如果内部查询意外返回两行，数据库会抛出运行时错误——“subquery returned more than 1 row”。


#### 定义：行子查询

**行子查询**返回一行多列。它与一个元组比较。

    SELECT * FROM Students
    WHERE (year, major) = (SELECT year, major FROM Students WHERE id = 42);

行子查询很优雅但不常用。大多数方言都实现了它们；以可读性为准调优。


#### 定义：表子查询

**表子查询**返回一个完整关系，必须出现在需要表的地方：FROM 内部、IN 内部、EXISTS 内部、ANY/ALL 内部。

    SELECT d.name, t.avg_gpa
    FROM Departments d
    JOIN (
      SELECT s.dept_id, AVG(e.grade) AS avg_gpa
      FROM Students s JOIN Enrollments e ON s.id = e.student_id
      GROUP BY s.dept_id
    ) AS t ON d.id = t.dept_id;

FROM 子句中的表子查询常被称为**内联视图（inline view）**或**派生表（derived table）**。别名 `AS t` 是强制的——没有名字的表无法被引用列。


#### 权衡：位置与复用

FROM 中的表子查询运行一次，其结果被外部查询扫描。SELECT 中的标量子查询*可能*对每个外部行运行一次。“可能”，因为优化器有时会把它提升为常量子查询。当子查询依赖外部行时，优化器自由度更小——这就引出相关子查询。


### 8.3 相关子查询

如果一个子查询引用了外层查询的列，它就是**相关的**。内部查询在知道外部行之前无法算完。

    SELECT s.id, s.name
    FROM Students s
    WHERE s.gpa > (
      SELECT AVG(s2.gpa)
      FROM Students s2
      WHERE s2.dept_id = s.dept_id      -- 相关
    );

读作：“对每位学生 `s`，检查 `s` 的 GPA 是否超过 `s` 所在院系的平均 GPA。”


#### 定义：相关性

当子查询至少引用外层查询 FROM 列表中的一个列或别名时，它是**相关的**。没有这类引用的子查询是**非相关的**——它可被求值一次，然后把结果代入。
