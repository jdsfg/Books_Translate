**Q3.** 写一段 Python 脚本，给定本章开头的 `students.csv` 和 `enrollments.csv`，输出报表“每位学生选课数量，按降序排列”。然后写出等价的 SQL。比较两者并讨论：(a) 哪个更容易写，(b) 如果问题变成“也排除 0 选课的学生”哪个更容易修改，(c) 哪个更容易被引擎优化。

提示

按 `student_id` 统计 `enrollments.csv` 行数，再与 `students.csv` 的 `id` 连接，按计数降序排序。

**答案：**

Python（一个合理版本）：

    import csv
    from collections import Counter

    with open('enrollments.csv') as f:
        counts = Counter(row['student_id'] for row in csv.DictReader(f))

    with open('students.csv') as f:
        students = {row['id']: row['name'] for row in csv.DictReader(f)}

    report = sorted(
        ((students[sid], cnt) for sid, cnt in counts.items()),
        key=lambda x: -x[1]
    )

    for name, cnt in report:
        print(f"{name}: {cnt}")

SQL（同一问题）：

    SELECT s.name, COUNT(*) AS course_count
    FROM students s
    JOIN enrollments e ON s.id = e.student_id
    GROUP BY s.name
    ORDER BY course_count DESC;

(a) **更容易写：** 显然是 SQL。Python 代码必须显式表达*如何*计算聚合（计数、连接、排序）。SQL 表达的是*想要什么*。

(b) **更容易修改：** SQL。要排除 0 选课的学生，SQL 的 `JOIN` 已经做到了（它是内连接）。要*包含*他们，改为 `LEFT JOIN` 即可，其余不变。在 Python 中，处理 0 选课学生需要重构代码——改为遍历 `students` 而非 `counts`，使用 `counts.get(sid, 0)` 等。问题的每次修改都要求重写过程。
