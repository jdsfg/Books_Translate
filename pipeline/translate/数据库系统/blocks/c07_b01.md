第 2 章我们发现，Schema 中不受控制的冗余会产生更新、删除和插入异常。第 3 章我们通过把 `enrollments.csv` 拆成多张表修复了具体异常。第 5 章我们用 ER 建模把设计过程形式化。

但一个挥之不去的问题仍在：**我们怎么*知道*一个 Schema 没有异常？** 四张表、关系明显的 Schema 可以靠目测说“看起来不错”。但一个有 150 张表的医院病历系统，隐藏依赖潜藏在看似无辜的字段里，目测就行不通。

本章给我们形式化答案。我们引入**函数依赖（functional dependencies）**——一种精确表达“属性 X 决定属性 Y”的方式——以及**范式（normal forms）**，它们是 Schema 上的条件，保证特定异常类不会发生。过程中我们会遇到 Armstrong 公理、属性闭包、通过闭包推导候选键、最小覆盖，以及实践中最关键的两个范式（3NF 和 BCNF）。

到本章结束时，叙事 A 的第 3 章 Schema 可被证明没有异常。而另一面——何时反规范化是_正确_的——也将成为有原则的选择，而不是一种罪过。
