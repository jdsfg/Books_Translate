#### 用基本算子表达除法

完整地说：除法不是六个基本算子之一（\sigma、\pi、\times、\cup、-、\rho）。它可由它们构造为

R \div S = \pi_X(R) - \pi_X\big((\pi_X(R) \times S) - R\big)

用自然语言：从所有候选 X 值（\pi_X(R)）出发；减去任何与某个 s \in S 配对 (t, s) **缺失**的 X 值 t。剩下的就是与 S 中*每个* s 都配对的 X 值。真正执行的是这个构造，而不是 `\div` 符号本身。

**工作示例——验证基本算子构造。**

设 `R(student_id, course_id)` 包含：

student_id | course_id  
---|---  
1 | CS101  
1 | CS201  
2 | CS101  
3 | CS101  
3 | CS201  
3 | CS301  
  
设 `S(course_id)` = { CS101, CS201 }（毕业必修课）。

**步骤 1：\pi_X(R)** —— R 中出现的所有 student_id：{ 1, 2, 3 }

**步骤 2：\pi_X(R) \times S** —— 所有候选 (student_id, course_id) 对：{ (1,CS101), (1,CS201), (2,CS101), (2,CS201), (3,CS101), (3,CS201) }

**步骤 3：(\pi_X(R) \times S) − R** —— 在 R 中缺失的候选对：候选对中只有 (2, CS201) 不在 R 中。结果：{ (2, CS201) }

**步骤 4：\pi_X(步骤 3)** —— 至少缺失一个配对的 student_id：{ 2 }

**步骤 5：\pi_X(R) − 步骤 4** —— 没有缺失配对的 student_id：{ 1, 2, 3 } − { 2 } = { 1, 3 }

**结果：** 学生 1 和 3 已修 CS101 与 CS201；学生 2 没有。这与定义一致：R \div S = { 1, 3 }。✓

这个构造很巧妙：与其问“S 的每个元素都出现了吗？”，不如问“S 中有没有缺失的元素？”然后把这些学生减掉。双重否定结构与双重 `NOT EXISTS` 的 SQL 翻译完全对应。

除法在日常 SQL 中较少见，但概念上重要：它是全称量词算子，是“对所有”这头野兽。大多数查询用“存在”（半连接）就够了；“对所有”（除法）更少见，但当问题真正问“每个必需项”时至关重要。
