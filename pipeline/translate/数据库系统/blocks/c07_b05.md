### 6.4 最小覆盖

当 FD 很多时，其中一些是冗余的。**最小覆盖（minimal cover）**（或_规范覆盖_）是 FD 集合 F 的一个最小集合 F_c，它逻辑蕴含与 F 相同的约束。

> ### 定义：最小覆盖

集合 F_c 是 F 的**最小覆盖**，当且仅当：

  1. **蕴含相同：** F 蕴含的每个 FD 也都被 F_c 蕴含，反之亦然。
  2. **右侧单属性：** F_c 中每个 FD 的右侧恰好一个属性。
  3. **左侧无冗余属性：** 对 F_c 中每个 FD X \rightarrow A，不存在真子集 X' \subsetneq X 使得 X' \rightarrow A 也被 F_c 蕴含。
  4. **无冗余 FD：** 从 F_c 中移除任何 FD 都会改变蕴含集合。


#### 算法：计算最小覆盖

    1. 把每个 FD X -> Y 拆成多个 FD X -> A（Y 的每个属性 A 一个）。
    2. 对每个 FD X -> A，对 X 中的每个属性 B：
         如果 (X - {B}) -> A 被当前 FD 集合蕴含，则从 X 中移除 B。
    3. 移除每个冗余 FD（移除后不影响蕴含集合）。

工作示例。F = \{A \rightarrow BC, B \rightarrow C, AB \rightarrow D\}。

**步骤 1**（右侧单属性）：F_1 = \{A \rightarrow B, A \rightarrow C, B \rightarrow C, AB \rightarrow D\}。

**步骤 2**（剪枝左侧冗余）。检查 AB \rightarrow D：若从 F_1 中去掉 B 后是否仍蕴含它？\{A\}^+ 在 F_1 下：从 \{A\} 开始，A \rightarrow B 加入 B，B \rightarrow C 加入 C。闭包 = \{A, B, C\}。包含 D 吗？不包含。若去掉 A？\{B\}^+ = \{B, C\}。也不含 D。两边都不能去掉；AB \rightarrow D 保持原样。

**步骤 3**（移除冗余 FD）。逐一检查每个 FD 是否冗余：

* 移除 A \rightarrow B？在 F_1 - \{A \rightarrow B\} 中计算 \{A\}^+。从 \{A\} 开始。A \rightarrow C 给出 \{A, C\}。B \rightarrow C 不触发（不含 B）。AB \rightarrow D 不触发。闭包 = \{A, C\}。缺少 B。所以 A \rightarrow B 不冗余——保留。
* 移除 A \rightarrow C？在 F_1 - \{A \rightarrow C\} 中计算 \{A\}^+。从 \{A\} 开始。A \rightarrow B 给出 \{A, B\}。B \rightarrow C 给出 \{A, B, C\}。所以 C 可通过 A \rightarrow B 再 B \rightarrow C 推导。A \rightarrow C 冗余——移除。
* 移除 B \rightarrow C？在 F_1 - \{B \rightarrow C\} 中计算 \{B\}^+。从 \{B\} 开始，没有 FD 触发。闭包 = \{B\}。缺少 C。不冗余——保留。
* 移除 AB \rightarrow D？没有它时 \{A, B\}^+：\{A, B\} 经 A \rightarrow B、B \rightarrow C 增长到 \{A, B, C\}。缺少 D。不冗余——保留。

**最终最小覆盖：** F_c = \{A \rightarrow B, B \rightarrow C, AB \rightarrow D\}。

这个覆盖用于规范化决策。范式定义引用“非平凡 FD”；把它们写成最小形式能保持分析干净。
