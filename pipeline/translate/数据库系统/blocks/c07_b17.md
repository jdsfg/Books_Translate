**步骤 3.** 移除冗余 FD。

* A \rightarrow C 是否冗余？在没有它的情况下，用 \{A \rightarrow D, D \rightarrow C\} 计算 \{A\}^+：\{A\} → D → C。包含 C。**冗余——移除。**
* A \rightarrow D 是否冗余？在没有它的情况下，用 \{D \rightarrow C\} 计算 \{A\}^+：\{A\}（没有 FD 触发）。不包含 D。不冗余。
* D \rightarrow C 是否冗余？在没有它的情况下，用 \{A \rightarrow D\} 计算 \{D\}^+：\{D\}。不包含 C。不冗余。

**最小覆盖：** F_c = \{A \rightarrow D, D \rightarrow C\}。

合理性检查：它是否蕴含原始 AB \rightarrow C？在 F_c 下计算 \{A, B\}^+：\{A, B\} → A \rightarrow D → \{A, B, D\} → D \rightarrow C → \{A, B, C, D\}。是的，C 可推导。验证通过。

它是否蕴含 AB \rightarrow D？\{A, B\} → A \rightarrow D，包含 D。验证通过。

两条 FD 就 capture 了原来的四条。这就是最小覆盖的意义——它暴露了不可约结构。
