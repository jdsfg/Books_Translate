* **RESTRICT / NO ACTION：** 如果有子行引用父行，则阻止删除。_例子：_ 学生还有当前选课时，不允许删除该学生。
* **CASCADE：** 删除父行以及所有引用它的子行。_例子：_ 删除订单时同时删除其订单明细——明细离开订单没有意义。
* **SET NULL：** 删除父行，并将子行的引用设为 NULL。_例子：_ 用户删除账户，其帖子保留但作者显示为“已删除用户”（FK 设为 null）。
* **SET DEFAULT：** 删除父行，并将子行的引用设为默认值。_例子：_ 某个分类被删除，受影响商品被重新分配到“杂项”分类。

对于依赖数据绝不能意外擦除的关系选择 RESTRICT；对于严格属于父级所有的数据选择 CASCADE；对于引用是附带而非本质的关系选择 SET NULL / SET DEFAULT。
