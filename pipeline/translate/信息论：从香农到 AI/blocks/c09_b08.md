#### 概念检查

**Q1.** 计算 p = (0.5, 0.5) 和 q = (0.9, 0.1) 的 D(p \| q)。然后计算 D(q \| p)。它们相等吗？不对称性告诉了我们什么？

**答案：** D(p \| q) = 0.5 \log(0.5/0.9) + 0.5 \log(0.5/0.1) = 0.5 \cdot (-0.848) + 0.5 \cdot 2.322 \approx -0.424 + 1.161 = 0.737 比特。

D(q \| p) = 0.9 \log(0.9/0.5) + 0.1 \log(0.1/0.5) = 0.9 \cdot 0.848 + 0.1 \cdot (-2.322) \approx 0.763 - 0.232 = 0.531 比特。

它们不同（0.737 vs 0.531）。不对称性反映了 p（均匀）在 q 认为罕见的结果（第二个结果）上放了可观的概率质量，所以用为 q 优化的码描述来自 p 的数据代价高。反之，q 更集中，用为 p 优化的码描述来自 q 的数据代价较低，因为 p 没有 q 的典型结果那样严重地排除。

**Q2.** 证明 H(p, q) \geq H(p) 对所有 p, q 成立，当且仅当 p = q 时取等。

提示

使用 H(p, q) - H(p) = D(p \| q)。

**答案：** H(p, q) - H(p) = D(p \| q) \geq 0 由 Gibbs 不等式，当且仅当 p = q 时取等。所以 H(p, q) \geq H(p)，当且仅当 p = q 时取等。

这就是为什么交叉熵以熵为下界：p 的最优码使用 H(p) 比特每符号，任何其他码使用更多。

**Q3.** 陈述 KL 散度的链式法则，并应用它计算 D(p(x, y) \| q(x, y))，其中 p(x, y) = p(x) p(y) 和 q(x, y) = q(x) q(y)，p(x) \neq q(x) 但 p(y) = q(y)。

**答案：** 链式法则：D(p(x, y) \| q(x, y)) = D(p(x) \| q(x)) + D(p(y \mid x) \| q(y \mid x))。

对于独立分解：p(y \mid x) = p(y)，q(y \mid x) = q(y)。由于 p(y) = q(y)，D(p(y) \| q(y)) = 0。

所以 D(p(x, y) \| q(x, y)) = D(p(x) \| q(x))。联合分布之间的 KL 恰为 x 上边际之间的 KL。y 边际的差异会增加；此处不会因为 y 边际一致。

**Q4.** Pinsker 不等式用 \sqrt{D \ln 2 / 2} 界总变差。如果 D(p \| q) = 1 比特，它说了什么？

**答案：** \delta(p, q) \leq \sqrt{1 \cdot \ln 2 / 2} \approx \sqrt{0.347} \approx 0.589。

所以如果 KL 为 1 比特，总变差至多为 0.589，意味着没有事件在 p 和 q 之间的概率差异超过 58.9 个百分点。这是一个相当大的差距但远低于最大总变差 1。

对比：KL 为 0.1 比特给出 \delta \leq 0.186；KL 为 0.01 比特给出 \delta \leq 0.059。界大致随 KL 的平方根收紧。
