#### 参数

* 块长 n，信息长 k，最小距离 n - k + 1（MDS）。
* 可纠正至多 (n-k)/2 个错误和至多 n - k 个擦除。
* 对于 q = 256, n = 255，例如可纠正 255 中的 16 字节错误，速率 223/255 \approx 87%（标准 CCSDS 深空码）。


#### 解码：Berlekamp-Massey

Berlekamp 1968 年和 Massey 1969 年独立提出的经典解码算法是迭代的，运行时间 O(n^2)。现代变体使用基于 FFT 的方法达到 O(n \log^2 n)。更快的是，Sudan 1997 年提出并由 Guruswami 和 Sudan 1998 年扩展的列表解码算法可以纠正超过一半最小距离的错误，输出一个小候选码字列表。

#### 部署地位

Reed-Solomon 码是纠错的_主力_：

* **CD**：\mathbb{F}_{2^8} 上的 (32, 28) RS 码，交织。
* **DVD**：类似，更强的交织。
* **旅行者号**及其他深空探测器：速率 1/2 卷积码 + (255, 223) RS 码级联。
* **QR 码**：\mathbb{F}_{2^8} 上的 Reed-Solomon 码，参数取决于 QR 版本。
* **RAID-6 存储阵列**：RS 码提供对两块磁盘同时故障的容忍。

它们的持久性源于强纠错能力、成熟理解的解码算法和 q = 256 的字节对齐，后者与现代计算机架构自然契合。

### 7.4 卷积码

**卷积码**是一种滑动窗口码：每个输出比特依赖于最近输入比特的窗口。编码器是一个有限状态机；码可以用网格图表示。


#### 简单例子：速率 1/2，约束长度 3

每个输入比特产生两个输出比特；输出依赖于当前输入和前两个输入：

c_t^{(1)} = u_t \oplus u_{t-1} \oplus u_{t-2}, \quad c_t^{(2)} = u_t \oplus u_{t-2}.

编码器有 2^2 = 4 个状态（u_{t-1}, u_{t-2} 的值）。网格图表示随时间的所有可能状态转移。


#### Viterbi 解码

Viterbi 算法（1967）在给定接收序列时找到网格图中的最大似然路径。运行时间与块长成线性，与约束长度成指数。对于实际约束长度（通常 7-9），解码器足够快用于实时应用。

卷积码在 1980 和 1990 年代是数字蜂窝（GSM）和许多卫星系统的主导方案。它们在现代系统中已基本被 Turbo 和 LDPC 码取代。

### 7.5 Turbo 码

1993 年，Berrou、Glavieux 和 Thitimajshima 发表了题为"接近 Shannon 极限的纠错编码与解码：Turbo 码"的论文。社区最初的反应是怀疑：声称的性能（在中等块长下与 Shannon 容量相差 0.5 dB 以内）似乎好得不真实。

但 Turbo 码确实有效。到 1990 年代末，它们被标准化用于 3G 移动通信（UMTS）、深空遥测（CCSDS）和许多卫星系统。
