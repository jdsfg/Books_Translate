### D.3 TransformerLayer 定义

第 18 章引用了 `TransformerLayer` 但未定义。以下是定义：标准 pre-norm transformer 块，带多头自注意力和前馈 MLP。

    class CausalSelfAttention(nn.Module):
        def __init__(self, embed_dim, n_heads):
            super().__init__()
            assert embed_dim % n_heads == 0
            self.n_heads = n_heads
            self.head_dim = embed_dim // n_heads
            self.qkv = nn.Linear(embed_dim, 3 * embed_dim)
            self.out = nn.Linear(embed_dim, embed_dim)

        def forward(self, x):
            b, t, c = x.shape
            qkv = self.qkv(x).reshape(b, t, 3, self.n_heads, self.head_dim)
            qkv = qkv.permute(2, 0, 3, 1, 4)  # (3, b, h, t, d)
            q, k, v = qkv[0], qkv[1], qkv[2]
            # Scaled dot-product with causal mask.
            att = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_dim)
            mask = torch.triu(torch.ones(t, t, device=x.device), diagonal=1).bool()
            att = att.masked_fill(mask, float("-inf"))
            att = F.softmax(att, dim=-1)
            out = att @ v  # (b, h, t, d)
            out = out.transpose(1, 2).reshape(b, t, c)
            return self.out(out)


    class TransformerLayer(nn.Module):
        def __init__(self, embed_dim, n_heads, mlp_mult=4):
            super().__init__()
            self.ln1 = nn.LayerNorm(embed_dim)
            self.attn = CausalSelfAttention(embed_dim, n_heads)
            self.ln2 = nn.LayerNorm(embed_dim)
            self.mlp = nn.Sequential(
                nn.Linear(embed_dim, mlp_mult * embed_dim),
                nn.GELU(),
                nn.Linear(mlp_mult * embed_dim, embed_dim),
            )

        def forward(self, x):
            x = x + self.attn(self.ln1(x))
            x = x + self.mlp(self.ln2(x))
            return x


Pre-norm（LayerNorm 在注意力和 MLP 之前应用，残差连接环绕它们）是标准现代变体；比原始 post-norm 公式训练更稳定。
