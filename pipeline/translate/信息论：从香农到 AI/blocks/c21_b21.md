### 第 11 章——率失真

**应用题 Q1.** \sigma^2 = 4 的高斯信源以每样本 R = 1 比特压缩。最小可达 MSE 是多少？

解 R(D) = \tfrac{1}{2} \log_2 (\sigma^2 / D) = 1：\sigma^2 / D = 4，故 D = 1。每样本一比特将 MSE 缩减四倍——经典的每比特 6 dB 规则。

**应用题 Q2（p = 0.3 的二元 R(D)）。** 计算汉明失真下 p = 0.3 的二元信源在 D = 0.1 和 D = 0.3 处的 R(D)。解释。

R(D) = H_b(p) - H_b(D) 对 D \in [0, p]，对 D \geq p 为 0。在 p = 0.3, D = 0.1：R = 0.881 - 0.469 = 0.412 比特/符号。在 D = 0.3：R = 0——当失真等于少数类的源熵时，常数码字 \hat{X} = 0 已足够好。从正速率到零速率的转换在 D = p 处*锐利*，对应源不能被无损跳过的阈值。

**应用题 Q3（并行高斯注水）。** 三个并行高斯信道方差 \sigma^2 = (10, 4, 1)，总失真预算 D_{\text{total}} = 5。分配失真。

逆向注水：选"水位" \lambda，设 D_i = \min(\sigma_i^2, \lambda)，选 \lambda 使 \sum D_i = 5。试 \lambda = 2：D = (\min(10, 2), \min(4, 2), \min(1, 2)) = (2, 2, 1)，和 = 5。✓ 故分配失真 2, 2, 1 给三个信道。第三个信道失真等于其全部方差（被"淹没"——不分配速率）；前两个分剩余预算。速率：R_1 = \tfrac{1}{2}\log_2(10/2) = 1.16，R_2 = \tfrac{1}{2}\log_2(4/2) = 0.5，R_3 = 0。总速率：1.66 比特/样本。

**深入思考 Q1.** 为什么率失真逆定理与信道编码逆定理在相同意义上是"单字母"的？

两者都通过凸性和链式法则将 n 维向量问题归约为 1 维单符号问题。对信道编码（第 6 章），Fano + 链式法则给出 R \leq C + \epsilon。对率失真（第 11 章 §11.2），DPI + 链式法则 + Jensen 在凸 R^I(D) 上给出 R \geq R^I(\bar{D})。两者成功因为互信息链式法则项加性分解*且*每符号界归结到同一单字母量（C 或 R^I(D)）。此单字母化是信息论的结构奇迹；它不能干净地推广到多用户信道（第 12 章），这就是网络信息论仍然困难的原因。
