#### 性质 2：链式法则

这是信息论中的核心恒等式。

**熵的链式法则：**

H(X,Y)=H(X)+H(Y∣X)=H(Y)+H(X∣Y).H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y).H(X,Y)=H(X)+H(Y∣X)=H(Y)+H(X∣Y).

用通俗的话说：(X,Y)(X, Y)(X,Y) 的联合熵等于 XXX 的熵加上已知 XXX 后 YYY 的剩余熵。等价地，你可以先指定 XXX（代价：H(X)H(X)H(X) 比特），然后在已知 XXX 的条件下指定 YYY（平均代价：H(Y∣X)H(Y \mid X)H(Y∣X) 比特）。

**证明：** 从定义出发，

H(X,Y)=−∑x,yp(x,y)log⁡p(x,y).H(X, Y) = -\sum_{x, y} p(x, y) \log p(x, y).H(X,Y)=−x,y∑​p(x,y)logp(x,y).

利用 p(x,y)=p(x)p(y∣x)p(x, y) = p(x) p(y \mid x)p(x,y)=p(x)p(y∣x)：

H(X,Y)=−∑x,yp(x,y)[log⁡p(x)+log⁡p(y∣x)]=−∑xp(x)log⁡p(x)−∑x,yp(x,y)log⁡p(y∣x).H(X, Y) = -\sum_{x, y} p(x, y) [\log p(x) + \log p(y \mid x)] = -\sum_x p(x) \log p(x) - \sum_{x, y} p(x, y) \log p(y \mid x).H(X,Y)=−x,y∑​p(x,y)[logp(x)+logp(y∣x)]=−x∑​p(x)logp(x)−x,y∑​p(x,y)logp(y∣x).

第一项是 H(X)H(X)H(X)；第二项是 H(Y∣X)H(Y \mid X)H(Y∣X)。 □\square□

将 XXX 和 YYY 互换，同样的论证给出第二个等式。

#### 一般链式法则

链式法则推广到 nnn 个变量：

H(X1,X2,…,Xn)=∑i=1nH(Xi∣X1,X2,…,Xi−1).H(X_1, X_2, \ldots, X_n) = \sum_{i=1}^n H(X_i \mid X_1, X_2, \ldots, X_{i-1}).H(X1​,X2​,…,Xn​)=i=1∑n​H(Xi​∣X1​,X2​,…,Xi−1​).

这是该领域中最有用的恒等式；它使我们能够将任意序列的联合熵分解为逐步不确定性的求和。语言模型尤其是这一链式法则的自回归实例化：它们将 p(xi∣x1,…,xi−1)p(x_i \mid x_1, \ldots, x_{i-1})p(xi​∣x1​,…,xi−1​) 参数化为神经网络，而模型在语料库上的交叉熵恰好是通过链式法则计算的平均每 token 惊讶度。

#### 性质 3：条件作用降低熵

一个基本不等式：

H(Y∣X)≤H(Y),H(Y \mid X) \leq H(Y),H(Y∣X)≤H(Y),

当且仅当 XXX 和 YYY 独立时取等号。

**证明概要：** 定义互信息 I(X;Y)=H(Y)−H(Y∣X)I(X; Y) = H(Y) - H(Y \mid X)I(X;Y)=H(Y)−H(Y∣X)（我们将在 §2.4 中正式定义）；需要证明的是 I(X;Y)≥0I(X; Y) \geq 0I(X;Y)≥0。这等价于说 KL 散度 D(p(x,y)∥p(x)p(y))≥0D(p(x, y) \| p(x) p(y)) \geq 0D(p(x,y)∥p(x)p(y))≥0，即 Gibbs 不等式（第 8 章）。当且仅当 p(x,y)=p(x)p(y)p(x, y) = p(x) p(y)p(x,y)=p(x)p(y)，即独立时取等号。 □\square□

这个不等式在直觉上是显然的：平均而言，知道更多不会使你更不确定。但有一个微妙而重要的要点：它在 XXX 上_平均_成立，而非对 XXX 的每个值都成立。对于某个特定结果 X=xX = xX=x，条件熵 H(Y∣X=x)H(Y \mid X = x)H(Y∣X=x) 可以超过 H(Y)H(Y)H(Y)。设想 YYY 是一次公平硬币抛掷，而 XXX 是"硬币今早展示了一个不寻常的面"。对 XXX 的大多数值，YYY 仍然相当随机，但以一个罕见或令人意外的 XXX 为条件有时会留下比边缘分布更多关于 YYY 的不确定性。正是对 XXX 的平均才保证了不等式成立。

这个微妙之处是学生困惑的常年来源。不要把"条件作用降低熵"扁平化为"更多数据在每一点上都使事情更确定"。
