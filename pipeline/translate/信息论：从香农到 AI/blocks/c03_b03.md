#### 性质 2：链式法则

这是信息论的主力恒等式。

**熵的链式法则：**

H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y).

用通俗的话说：(X, Y) 的联合熵等于 X 的熵加上已知 X 后 Y 的剩余熵。等价地，你可以先指定 X（代价：H(X) 比特），然后在已知 X 的条件下指定 Y（平均代价：H(Y \mid X) 比特）。

**证明：** 从定义出发，

H(X, Y) = -\sum_{x, y} p(x, y) \log p(x, y).

使用 p(x, y) = p(x) p(y \mid x)：

H(X, Y) = -\sum_{x, y} p(x, y) [\log p(x) + \log p(y \mid x)] = -\sum_x p(x) \log p(x) - \sum_{x, y} p(x, y) \log p(y \mid x).

第一项是 H(X)；第二项是 H(Y \mid X)。□

将 X 和 Y 互换，同样的论证给出第二个等式。


#### 一般链式法则

链式法则推广到 n 个变量：

H(X_1, X_2, \ldots, X_n) = \sum_{i=1}^n H(X_i \mid X_1, X_2, \ldots, X_{i-1}).

这是该领域最有用的恒等式；它让我们把任意序列的联合熵分解为逐步不确定性之和。尤其是语言模型，正是这一链式法则的自回归实例化：它们把 p(x_i \mid x_1, \ldots, x_{i-1}) 参数化为神经网络，模型在语料上的交叉熵恰好就是通过链式法则计算的平均每词元惊异。


#### 性质 3：条件化降低熵

一个基本不等式：

H(Y \mid X) \leq H(Y),

当且仅当 X 和 Y 独立时取等号。

**证明概要：** 定义互信息 I(X; Y) = H(Y) - H(Y \mid X)（我们将在 §2.4 中正式定义）；断言是 I(X; Y) \geq 0。这等价于说 KL 散度 D(p(x, y) \| p(x) p(y)) \geq 0，即吉布斯不等式（第 8 章）。等号成立当且仅当 p(x, y) = p(x) p(y)，即独立。□

这个不等式在直觉上是显然的：平均而言，知道更多不会使你更不确定。但有一个微妙而重要的要点：它在 X 上_平均_成立，而非对 X 的每个值都成立。对于某个特定结果 X = x，条件熵 H(Y \mid X = x) 可以超过 H(Y)。设想 Y 是一次公平硬币抛掷，而 X 是“硬币今早展示了一个不寻常的面”。对 X 的大多数值，Y 仍然相当随机，但以一个罕见或令人意外的 X 为条件有时会留下比边缘分布更多关于 Y 的不确定性。正是对 X 的平均才保证了不等式成立。

这一微妙之处是学生长期困惑的来源。不要把“条件化降低熵”压扁成“更多数据在每一点上都让事情更确定”。
