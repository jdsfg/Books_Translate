#### 定理（KL 的链式法则）

对于联合分布 p(x, y) 和 q(x, y)，D(p(x, y) \| q(x, y)) = D(p(x) \| q(x)) + D(p(y \mid x) \| q(y \mid x)),

其中 D(p(y \mid x) \| q(y \mid x)) = \sum_x p(x) D(p(\cdot \mid x) \| q(\cdot \mid x))。

**证明**：

D(p(x, y) \| q(x, y)) = \sum_{x, y} p(x, y) \log \frac{p(x, y)}{q(x, y)} = \sum_{x, y} p(x, y) \log \frac{p(x) p(y \mid x)}{q(x) q(y \mid x)}

= \sum_{x, y} p(x, y) \log \frac{p(x)}{q(x)} + \sum_{x, y} p(x, y) \log \frac{p(y \mid x)}{q(y \mid x)} = D(p(x) \| q(x)) + D(p(y \mid x) \| q(y \mid x))。□

链式法则通过归纳法推广到多个变量。它是图模型中 KL 计算的主力。

交叉熵最小化与现代机器学习的联系如此深刻，我们无法在此完全展开。

每个神经网络分类器最小化交叉熵。网络输出是概率分布 q_\theta(y \mid x)（通常通过 logits 上的 softmax）。标记样本 (x, y) 的训练损失为 -\log q_\theta(y \mid x)。在训练集上取平均得到经验交叉熵。

用随机梯度下降最小化它是从 MNIST 分类器到 ImageNet ResNet 到 BERT 的标准配方。

#### 语言建模

语言模型是概率分布 q_\theta(x_t \mid x_1, \ldots, x_{t-1})。训练损失是语料上每 token 的平均负对数似然。由 KL 的链式法则，这是序列级别上数据分布与模型分布之间的交叉熵。

现代前沿模型（GPT-4、Gemini、Claude）都通过在网页级文本上的交叉熵最小化训练，加上各种形式的后训练（RLHF、宪法 AI）。

#### 变分推断

变分推断中使用的证据下界（ELBO）为

\text{ELBO}(\theta, \phi) = \mathbb{E}_{q_\phi(z \mid x)}[\log p_\theta(x, z) - \log q_\phi(z \mid x)] = \log p_\theta(x) - D(q_\phi(z \mid x) \| p_\theta(z \mid x)).

最大化 ELBO 等价于最小化变分后验 q_\phi 与真实后验 p_\theta(z \mid x) 之间的 KL。我们将在第 10 章详细讨论。
