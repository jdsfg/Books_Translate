### 第 9 章——超越 KL

**应用题 Q1.** 对 p = (0.5, 0.5), q = (0.9, 0.1) 计算 D(p \| q), D(q \| p) 和 TV。为什么两个 KL 如此不同？

D(p \| q) = \tfrac{1}{2} \log_2 \tfrac{0.5}{0.9} + \tfrac{1}{2} \log_2 \tfrac{0.5}{0.1} \approx 0.737 比特。D(q \| p) = 0.9 \log_2 \tfrac{0.9}{0.5} + 0.1 \log_2 \tfrac{0.1}{0.5} \approx 0.531 比特。TV = 0.4。不对称性：D(p \| q) 惩罚 q 在结果 1 处过轻（p 放 0.5 质量）；D(q \| p) 涉及更小的对数比因为 p 处处适中。这就是为什么"逆向 KL"训练模式寻找生成器而"正向 KL"训练模式覆盖生成器。

**应用题 Q2（Pinsker 不等式）。** 陈述 Pinsker 不等式并对上例从 KL 界 TV。

Pinsker：\mathrm{TV}(p, q) \leq \sqrt{\tfrac{1}{2} D(p \| q)}（KL 以 nats 计）。转换：D(p \| q) \approx 0.737 比特 = 0.511 nats，故 Pinsker 给出 \mathrm{TV} \leq \sqrt{0.255} \approx 0.505。实际 TV 为 0.4，界正确但不紧。Pinsker 在你有 KL 界（比 TV 更易从样本计算或估计）且需要 TV 推论时是正确工具。

**应用题 Q3（\chi^2 拟合优度）。** 六面骰子掷 600 次，结果 (110, 95, 105, 100, 90, 100)。计算相对公平骰子的 \chi^2 统计量并解释。

零假设下（公平骰子）期望计数各 100。\chi^2 = \sum (O_i - E_i)^2 / E_i = (10^2 + 5^2 + 5^2 + 0 + 10^2 + 0)/100 = 250/100 = 2.5。零假设下 5 自由度，\alpha = 0.05 临界值为 \chi^2_{0.05, 5} = 11.07。观测值 2.5 \ll 11.07，故不拒绝——数据与公平骰子一致。此处 \chi^2 散度是经验量 \hat\chi^2 = \chi^2 / N = 2.5/600 = 0.0042，即每样本类比，反映经验分布与模型的接近程度。

**深入思考 Q1.** 为什么 Wasserstein 距离在不相交支撑分布间有定义而 KL 没有？

0 处 delta 和 1 处 delta 之间的 KL 需要 \log(p/q)，但 p 在 q 为正处为零（反之亦然），给出 0/0 或 p \log p / 0 项。结果未定义或无穷。Wasserstein 有定义因为它问"多少*质量*移动多远"，此问题不管支撑重叠如何都有干净答案：此例中质量 1 移动距离 1，故 W_1 = 1。这正是 WGAN 替代 JS 散度 GAN 的原因——早期训练中生成器分布远离数据分布，故 JS 梯度消失而 W_1 梯度保持信息性。
