#### 深入思考

**Q1.** 信道容量是一个"单字母"公式：C = \max I(X; Y)，其中 X 和 Y 是单次信道使用，而非分组。然而操作含义涉及长分组。为什么单字母公式是正确的？

**讨论：** 单字母公式是一个非凡的事实。假设有人提出："也许分组编码允许比单字母容量更高的速率。"这将意味着 \frac{1}{n} I(X^n; Y^n) 对于某些联合输入分布超过 \max I(X; Y)。

Shannon 证明了对于无记忆信道这不可能发生。证明是精妙的：它利用了 I(X^n; Y^n) \leq \sum_i I(X_i; Y_i) \leq n \max I(X; Y)（互信息的链式法则加上信道无记忆的事实）。所以没有联合输入分布能超过 n 倍的单字母容量。

对于_有_记忆的信道（例如有码间干扰的高斯信道），单字母公式不成立，容量必须在分组上计算。这是一个困难得多的问题，许多此类信道的容量至今仍是研究课题。

单字母性质是使经典信息论变得可处理的优雅简化之一。它也是现代多用户信息论（第 12 章）困难得多的原因之一：许多多用户场景没有单字母解。

**Q2.** 容量为 0 的有噪信道对传输消息无用，但它可能仍能传递其他类型的信息。有哪些例子？

**讨论：** 容量为零的信道无法从输入到输出传输任何信息：输出与输入独立。但仍有一些场景：

1. **公共随机性**：两方可能想要共享随机性（例如用于加密的共享密钥）。容量为零的信道无法传输一方选择的随机串，但如果双方通过信道访问_同一_随机源（例如都观察一个公共有噪信号），它们可以导出共享密钥。
2. **识别**：不传输 M 条消息中哪一条被发送，双方可能只需验证是否发送了某条特定消息。这是"识别容量"，与传输容量不同（著名的 Ahlswede-Dueck 识别结果，1989 年）。对于某些信道，识别容量远高于传输容量。
3. **量子容量**：对于量子信道（第 16 章），存在多种容量（经典、量子、私有），一个信道可能对一种任务有正容量而对另一种为零。
4. **信令**：即使在容量为零的信道上，一方也可以通过发送信号来传递事件的_时间_。这不携带消息容量，但传达了可能对同步重要的定时信息。

教训：Shannon 意义上的"容量"只是可传输多少的一种概念。不同的通信任务产生不同的概念。
