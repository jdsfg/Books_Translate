第 1 章给出了熵 H(X)——单个随机变量的平均不确定性。这足以证明英语的熵有界、引出无损压缩、以及说明为什么交叉熵是正确的训练损失。但单个随机变量无法涵盖我们想讨论的许多信息问题。有趣的问题在两个或更多变量出现时才产生：一个变量对另一个变量透露了多少信息？天气对一个人是否带伞透露了多少信息？句子中的前一个词在多大程度上缩小了下一个词的范围？一项医学检查的结果在多大程度上减少了我们对另一项检查所诊断疾病的不确定性？这些问题中的每一个都有精确的信息论答案，而给出答案的机制就是本章的主题。

我们将熵的定义从一个变量扩展到两个，形式为联合熵，然后细化为条件熵（观察到 X 后关于 Y 的剩余不确定性），最后到互信息（由 X 的知识带来的关于 Y 的不确定性减少）。互信息将成为本书余下部分的核心量。第 5 章的信道容量是 I(X;Y) 在输入分布上的最大值；第 4 章的信源编码定理将互信息与冗余联系起来；第 14 章讨论的现代自监督学习在很大程度上也是基于互信息最大化。

### 2.1 联合熵

对于两个随机变量 X 和 Y，其联合分布为 p(x, y)，联合熵是将这对变量视为乘积空间上的单个随机变量时的熵：


#### 定义：联合熵

H(X, Y) = -\sum_{x, y} p(x, y) \log p(x, y).

用通俗的话说：H(X, Y) 是在使用最优编码时，联合指定 X 和 Y 所需的平均比特数。它依赖于联合分布，而不仅仅依赖于边缘分布。


#### 第一个观察：独立性即最大值

如果 X 和 Y 独立，则 p(x, y) = p(x) p(y)，联合熵分解为：

H(X, Y) = -\sum_{x, y} p(x) p(y) [\log p(x) + \log p(y)] = H(X) + H(Y).

如果 X 和 Y 不独立，则 H(X, Y) < H(X) + H(Y)。知道 X 减少了我们关于 Y 的不确定性，因此我们不需要在 H(X) 之上再加完整的 H(Y) 比特来指定这对变量。H(X) + H(Y) 与 H(X, Y) 之间的松弛量恰好是互信息 I(X; Y)，我们将在 §2.4 中定义它。
