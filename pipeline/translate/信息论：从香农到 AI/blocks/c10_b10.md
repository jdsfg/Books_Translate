* **对角 Fisher**：用对角近似 F（Adam、RMSprop）。廉价但丢失跨参数曲率。
* **块对角 Fisher（K-FAC）**：按层用 Kronecker 因子近似 F。捕获层内曲率。
* **Shampoo、AdaHessian**：使用高阶矩和 Kronecker 因子。
* **Gauss-Newton 近似**：对最小二乘损失，用 Jacobian 乘积替换 Hessian。

这些近似使自然梯度式方法在大规模下实用，并为许多模型在收敛速度上带来持续改进。

**Q4.** 比较集中在不相交支撑上的分布的 KL 和 Wasserstein：p 是 0 上的 delta，q 是 1 上的 delta。各自给出什么？

**答案：** KL: D(p \| q) = \infty（因为 p 在 q 为零的 0 上放质量）。D(q \| p) = \infty 类似。

Wasserstein-1: W_1(p, q) = |0 - 1| = 1（将一单位质量传输距离 1）。

Wasserstein 给出有限、合理的答案。KL 拒绝比较。这就是为什么当分布可能在不相交或近乎不相交支撑的子流形上时 Wasserstein 更受偏爱——恰好是 GAN 训练早期的情况，此时生成器分布是维度低于环境图像空间的流形。
