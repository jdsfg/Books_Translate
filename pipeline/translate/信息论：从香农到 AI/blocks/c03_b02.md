#### 例题：两枚相关硬币

抛掷两枚硬币，但它们以奇怪的方式粘在一起：总是同时正面或同时反面，两种结果等可能。所以 p(HH) = p(TT) = 1/2，且 p(HT) = p(TH) = 0。

边缘分布：P(X = H) = P(X = T) = P(Y = H) = P(Y = T) = 1/2。所以 H(X) = H(Y) = 1 比特。

联合分布：四个结果中只有两个概率非零，每个概率为 1/2。所以

H(X, Y) = -\frac{1}{2} \log \frac{1}{2} - \frac{1}{2} \log \frac{1}{2} = 1 \text{ bit}.

这对变量是_一比特_，而不是两比特，因为完全相关的随机变量合在一起只携带与其中一个相同的信息量。数据冗余是彻底的。我们将在第 12 章讨论分布式信源编码时再次使用这类例子。


### 2.2 条件熵

我们经常想问：给定我们已经知道 X，关于 Y 的不确定性还剩多少？这就是条件熵。


#### 定义：条件熵

Y 给定 X 的**条件熵**为

H(Y \mid X) = \sum_x p(x) H(Y \mid X = x) = -\sum_{x, y} p(x, y) \log p(y \mid x).

用通俗的话说：H(Y \mid X) 是观察到 X 后关于 Y 的平均不确定性。平均是在 X 的分布上进行的；对每个特定值 x，我们计算 H(Y \mid X = x) = -\sum_y p(y \mid x) \log p(y \mid x)，即条件分布 p(y \mid x) 的熵，然后取平均。

这不是对称的：一般而言 H(Y \mid X) \neq H(X \mid Y)。知道疾病往往能钉住症状；知道症状很少能钉住疾病。
