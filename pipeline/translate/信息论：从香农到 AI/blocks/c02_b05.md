#### 定义：香农熵

离散随机变量 X 的**香农熵**（Shannon entropy），其概率质量函数为 p(x)，定义为

H(X) = \mathbb{E}[I(X)] = -\sum_{x} p(x) \log p(x),

其中求和遍历所有满足 p(x) > 0 的值 x，并采用约定 0 \log 0 = 0（由 \lim_{p \to 0^+} p \log p = 0 给出）。

用通俗的话说：如果你使用最高效的编码，熵就是从长远来看传达 X 的一个结果所需的平均比特数。

熵仅依赖于_分布_ p，而不依赖于结果的标签。两个状态空间完全不同、但概率向量相同的随机变量，将具有相同的熵。这令人放心：一个系统中不确定性的数量是概率如何分布的性质，而非结果叫什么。


#### 第一次计算：二元熵函数

考虑一个二元随机变量 X，P(X = 1) = p，P(X = 0) = 1 - p。其熵为

H_b(p) = -p \log_2 p - (1 - p) \log_2 (1 - p).

这个函数，即**二元熵函数**（binary entropy function），出现得如此频繁，值得拥有自己的名字。让我们考察它的行为。

* 在 p = 0 处：两项均为 0（使用 0 \log 0 = 0）。H_b(0) = 0。结果是确定的（始终为 0）；不需要信息。
* 在 p = 1 处：同理。H_b(1) = 0。始终为 1。
* 在 p = 1/2 处：H_b(1/2) = -\frac{1}{2} \log \frac{1}{2} - \frac{1}{2} \log \frac{1}{2} = -\log \frac{1}{2} = 1 比特。
* 在 p = 0.99 处：H_b(0.99) = -0.99 \log 0.99 - 0.01 \log 0.01 \approx 0.0144 + 0.0664 \approx 0.0808 比特/次掷硬币。

因此，一枚公平硬币的每次掷动携带 1 比特。一枚严重偏斜的硬币（99/1）平均每次掷动携带不到十分之一比特，因为大多数掷动只是说“正面”，并不令任何人意外。该函数关于 p = 1/2 对称，并在该点取得最大值。

H_b(p) 的形状是从 (0, 0) 上升到 (1/2, 1) 再下降到 (1, 0) 的平滑凸起，全程为凹。这种凹性并非偶然；它是后续章节中许多不等式的来源。
