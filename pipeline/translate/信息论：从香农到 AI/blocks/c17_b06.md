### 16.7 AI 关联：量子机器学习

量子机器学习（QML）被大力推广为量子计算的潜在应用。若干提出的算法声称对 ML 任务有量子加速：HHL（线性系统）、量子 SVM、变分量子分类器、量子神经网络。

截至 2026 年的诚实评估：

1. **理论加速存在**：Harrow、Hassidim 和 Lloyd 于 2009 年提出的 HHL 算法在特定条件下对线性系统提供指数加速。一些量子核方法在人造数据集上有可证明的优势。
2. **实际加速未经验证**：没有量子 ML 算法在真实世界 ML 任务上展示了明确优势。硬件限制（退相干、门误差）使运行大型量子电路不可行。
3. **特定优势可能出现**：化学模拟、材料设计和某些优化问题比通用 ML 更有前景。这些是量子优势更容易展示的领域。
4. **经典硬件上的量子启发方法**：张量网络，最初来自量子物理，已为特定任务产生了有效的经典 ML 算法。"量子启发"框架在实际 ML 中比真正的量子计算更有用。

公允的说法：QML 是一个有理论兴趣的真实研究领域，但对主流机器学习的实际影响微乎其微。这是否在下一个十年改变取决于量子硬件进展，而后者比预测的更慢。

### 常见误解

* **误解**："一个量子比特可以同时处于两个态。"

更准确地说：量子比特处于基态的*叠加*。测量时，它给出一个经典结果。"同时两个态"的说法是隐喻性的，可能误导。

* **误解**："量子隐形传态可以超光速传输信息。"

不能。量子隐形传态需要两个比特的经典通信。经典信道将信息传输速度限制为光速。隐形传态是优美的协议但不违反狭义相对论。

* **误解**："量子计算机将主宰机器学习。"

截至 2026 年，没有令人信服的证据表明量子计算在主流 ML 中有实际优势。量子计算机可能革命某些特定任务（化学、优化），但主流 ML 在经典硬件上如此成功，量子 ML 面临很高的门槛。
