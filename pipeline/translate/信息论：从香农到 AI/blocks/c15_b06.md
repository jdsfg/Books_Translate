### 本章小结

高维互信息估计在根本上困难。McAllester-Stratos 界形式化了这一点：从 n 个样本对 d 维分布的任何估计量精度被 O(\log n / n^{1/d}) 限制。

现代神经估计量（MINE、InfoNCE）基于 Donsker-Varadhan 表示提供下界。它们作为训练目标有用（InfoNCE 用于对比学习）但作为 MI 的点估计量不可靠。

与自监督学习的联系：对比方法最大化增广视图间的 MI 下界，产生对下游任务有用的表示。MI 在这一成功中的角色在经验上确立但理论上存在争议。

更广泛的教训：对深度学习中的经验 MI 主张保持谨慎。估计量有偏且含噪；界是松的。将 MI 用作框架和启发式，而非精确测量。

### 14.X 习题


#### 概念检查

**Q1.** 陈述 KL 散度的 Donsker-Varadhan 表示。

**答案：** D(p \| q) = \sup_T [\mathbb{E}_p T - \log \mathbb{E}_q \exp T]，上确界遍取函数 T: \mathcal{X} \to \mathbb{R}。最优为 T^*(x) = \log(p(x)/q(x)) + c。

**Q2.** 什么是 MINE，它产生什么？

**答案：** MINE（互信息神经估计）将 T_\theta 参数化为神经网络，利用 Donsker-Varadhan 表示从样本计算互信息的下界。

输出是 I(X; Y) 的下界，通过最大化 \theta 上的界来训练。实践中，MINE 有偏（可能高估或低估）且方差大，尤其在高维中。

**Q3.** 什么是 InfoNCE，它如何界定 MI？

**答案：** InfoNCE：I(X; Y) \geq \mathbb{E}[\log(\exp f(x, y) / (\frac{1}{K} \sum_j \exp f(x, y_j)))] + \log K，其中 y 是正样本，y_j 是 K 个负样本。

当 f(x, y) = \log p(y \mid x) + c 且 K 大时界是紧的；它在 \log K 处饱和。对于 K = 10000，上限约 13 比特。

**Q4.** 为什么高维 MI 估计困难？

**答案：** 三个原因：

1. **统计方面**：McAllester-Stratos 界表明精度随 n^{-1/d} 退化——在维度上指数级恶化。
2. **计算方面**：经典基于密度的估计量（KDE）随维度扩展性差。
3. **偏差**：神经估计量通常有偏；偏差方向取决于网络和范围。

在高维中，任何已知方法都无法从合理样本量可靠估计 MI。
