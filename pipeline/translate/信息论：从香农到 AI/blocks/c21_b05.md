**深入思考 Q2.** 输入 X 的表示 T = f(X) 对标签 Y *充分*如果 I(T;Y) = I(X;Y)。证明充分性是马尔可夫链条件，并解释为什么"充分 + 最小"与第 13 章的信息瓶颈相关。

充分性要求 I(X;Y \mid T) = 0，等价于 Y \perp X \mid T，即链 Y - T - X 成立（连同原始 T = f(X) 的确定性）。一个表示可以充分但仍编码关于 X 的无关信息；最小性还要求 I(X;T) 尽可能小。IB 拉格朗日量 \mathcal{L} = I(X;T) - \beta I(T;Y) 恰好实现此权衡，且当 \beta \to \infty 时恢复任何最小 I(X;T) 的充分表示。
