### 13.2 IB 曲线

对不同的 \beta 绘制 I(T; Y) 对 I(X; T) 的图，得到**信息平面**轨迹。最优解描绘出一条曲线（IB 曲线），类似于率失真曲线。

关键性质：

* 曲线单调递增：更多压缩速率（I(X; T)）允许更多预测（I(T; Y)）。
* 曲线是凹的。
* 曲线上界为 I(X; Y)（数据处理不等式：I(T; Y) \leq I(X; Y)）。

曲线的"形状"取决于联合分布 p(X, Y)。对于结构丰富的数据（I(X; Y) 的大部分"容易"提取），曲线陡峭；少量压缩即可保留大部分相关性。对于"有噪"数据，曲线平坦。

这里一图胜千言。信息平面横轴为 I(X; T)（表示 T 记住了多少输入），纵轴为 I(T; Y)（表示告诉你多少关于标签的信息）。每个可能的表示是该平面中的一个点；IB 曲线是*可达*点的前沿上界：

       I(T; Y)
       (相关性)
            ▲
     I(X;Y) ┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ 上界 (DPI)
            │                       *  *  *
            │                  *
            │             *           ← IB 曲线
            │         *          (凹, 单调)
            │      *                   - 大 β: 右上
            │    *                     - 小 β: 左下
            │  *
            │ *
            │*
            ●─────────────────────────────────▶  I(X; T)
           0                    H(X)            (压缩速率)

       可行区域：曲线下方及右方的一切。
       曲线下方的每个 (压缩, 相关性) 对都可由某个表示实现；
       曲线上方的一切都不可实现。

将 \beta 从 0 滑到 \infty，最优解沿曲线从原点（常数 T，不含任何信息）走到 (H(X), I(X; Y))（平凡的 T = X）。"有趣的"表示位于中间：足够压缩以丢弃干扰，足够相关以预测标签。曲线的*凹性*意味着收益递减：一旦接近顶部，每多一比特压缩速率带来的相关性越来越少。
