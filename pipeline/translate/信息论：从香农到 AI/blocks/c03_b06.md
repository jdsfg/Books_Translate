#### 定义：条件互信息

I(X; Y \mid Z) = H(X \mid Z) - H(X \mid Y, Z).

等价地：

I(X; Y \mid Z) = \sum_{z} p(z) I(X; Y \mid Z = z) = \mathbb{E}_Z [I(X; Y \mid Z)].

它同样非负，同样在 X 与 Y 上对称，同样是许多应用中的自然量。特别地，条件互信息正是**数据处理不等式**所控制的量，我们现在陈述它。


#### 数据处理不等式

如果 X \to Y \to Z 是马尔可夫链（意思是给定 Y 时 Z 与 X 条件独立），则

I(X; Z) \leq I(X; Y).

用通俗的话说：处理数据只能破坏信息，绝不能创造信息。如果 Z 由 Y 计算得到（也许是随机的），则 Z 关于 X 携带的信息至多与 Y 一样多。关于 X 的信息不会在后处理下增加。

**证明：** 由链式法则和互信息的对称性，

I(X; Y, Z) = I(X; Y) + I(X; Z \mid Y) = I(X; Z) + I(X; Y \mid Z).

由于 X \to Y \to Z 构成马尔可夫链，I(X; Z \mid Y) = 0。且 I(X; Y \mid Z) \geq 0。因此

I(X; Y) = I(X; Z) + I(X; Y \mid Z) \geq I(X; Z)。□

数据处理不等式是一个极其直观事实的形式陈述：你对原始数据做的任何事情，都不可能让你获得比原始数据本身所含关于底层状态更多的信息。它约束着每个机器学习系统能做什么。如果深度网络的隐藏表示 T 是输入 X 的函数，则 I(T; Y) \leq I(X; Y)——网络关于标签 Y 所能提取的信息，至多与输入 X 起初所拥有的一样多。我们将在第 13 章讨论信息瓶颈时使用这一不等式。
