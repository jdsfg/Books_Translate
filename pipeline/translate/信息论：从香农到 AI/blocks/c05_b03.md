#### 定理（Shannon 信源编码定理，变长形式）

对于分布为 p 的随机变量 X 的任何前缀码 C，

L(C) \geq H(X).

反之，存在一个前缀码使得

L(C) < H(X) + 1.

用通俗的话说：H(X) 是平均码字长度的下界，而我们可以与之相差不超过 1 比特。

**逆向证明（可达性）**：对每个 x，选择 \ell(x) = \lceil -\log p(x) \rceil。则

\sum_x 2^{-\ell(x)} \leq \sum_x 2^{\log p(x)} = \sum_x p(x) = 1,

因此 Kraft 不等式成立，存在具有这些长度的前缀码。期望长度为

L = \sum_x p(x) \ell(x) = \sum_x p(x) \lceil -\log p(x) \rceil < \sum_x p(x) (-\log p(x) + 1) = H(X) + 1. \square

这一构造即 **Shannon 码**，码字长度为 \lceil -\log p(x) \rceil，它不是最优的（Huffman 是最优的，我们将在 §4.5 中证明），但足以支撑渐近论证。

**正向证明（逆定理）**：我们将使用 Kraft 不等式和 Gibbs 不等式（我们将在第 8 章作为 KL 散度的性质正式证明）。定义 q(x) = 2^{-\ell(x)} / \sum_y 2^{-\ell(y)}，这是一个概率分布。则

L(C) - H(X) = \sum_x p(x) \ell(x) - H(X) = -\sum_x p(x) \log 2^{-\ell(x)} - H(X).

代入 2^{-\ell(x)} = q(x) \cdot \sum_y 2^{-\ell(y)}：

L(C) - H(X) = -\sum_x p(x) \log q(x) - \log \sum_y 2^{-\ell(y)} - H(X) = D(p \| q) - \log \sum_y 2^{-\ell(y)}.

由 Kraft 不等式 \sum_y 2^{-\ell(y)} \leq 1，有 -\log \sum_y 2^{-\ell(y)} \geq 0。又由 Gibbs 不等式 D(p \| q) \geq 0。所以 L(C) - H(X) \geq 0，即 L(C) \geq H(X)。□

证明告诉我们等号_何时_成立：当 D(p \| q) = 0（即 p = q）且 Kraft 和等于 1（即码用满了整棵树）。这要求 p(x) = 2^{-\ell(x)}；概率必须是 2 的逆幂（"二进"分布）。

#### 1 比特差距

变长定理留下了每符号至多 1 比特的差距。它来自哪里？整数取整步骤 \lceil -\log p(x) \rceil。在最坏情况下，每个 \ell(x) 被向上取整近 1。

两种策略可以缩小这一差距：

1. **分组编码**：一次编码 n 个符号的块。1 比特差距在 n 上摊销，因此每符号差距缩小到 1/n。对于大的 n，速率趋近 H(X)。
2. **算术编码**：一种单一编码，实际上对任意块长度进行分组编码，达到每符号 O(1/n) 比特的差距。

我们接下来讨论分组编码，然后是 Huffman（逐符号方案的最优变长码），最后是算术编码。
