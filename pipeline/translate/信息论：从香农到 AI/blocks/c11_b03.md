### 10.3 实例：高斯均值推断

考虑观测 x_1, \ldots, x_n 独立同分布地从 \mathcal{N}(\mu, 1) 中抽取，先验为 \mu \sim \mathcal{N}(0, \sigma_0^2)。后验是高斯的且可以解析计算，但我们将用变分方法来推导它，作为练习。

变分族：q_\phi(\mu) = \mathcal{N}(m, s^2)，以 \phi = (m, s^2) 为参数。

ELBO：

\text{ELBO} = \mathbb{E}_q[\log p(x_1, \ldots, x_n, \mu)] - \mathbb{E}_q[\log q(\mu)].

具体展开：

\log p(x_i \mid \mu) = -\frac{1}{2}(x_i - \mu)^2 + \text{const},

\log p(\mu) = -\frac{1}{2 \sigma_0^2} \mu^2 + \text{const},

\log q(\mu) = -\frac{1}{2 s^2}(\mu - m)^2 + \text{const}.

\mathbb{E}_q[(x_i - \mu)^2] = (x_i - m)^2 + s^2, \quad \mathbb{E}_q[\mu^2] = m^2 + s^2, \quad \mathbb{E}_q[\log q] = -\frac{1}{2} \log(2 \pi e s^2).

代入：

\text{ELBO}(m, s^2) = -\frac{1}{2} \sum_i [(x_i - m)^2 + s^2] - \frac{1}{2 \sigma_0^2}(m^2 + s^2) + \frac{1}{2} \log s^2 + \text{const}.

对 m 求导并令其为零：

\sum_i (x_i - m) - m / \sigma_0^2 = 0 \Rightarrow m^* = \frac{\sum_i x_i}{n + 1/\sigma_0^2}.

当 \sigma_0^2 \to \infty（无信息先验）时，m^* \to \bar{x}，即样本均值。当 \sigma_0^2 有限时，m^* 向 0（先验均值）收缩。

对 s^2 求导并令其为零：

-\frac{n}{2} - \frac{1}{2\sigma_0^2} + \frac{1}{2 s^2} = 0 \Rightarrow s^{*2} = \frac{1}{n + 1/\sigma_0^2}.

这与精确的贝叶斯后验一致，正如预期，因为变分族包含了真实后验。

#### 当变分族不包含真实后验时

对于一个非共轭模型，如果真实后验是——比如说——高斯混合分布，那么单高斯变分族无法匹配它。ELBO 的最大值给出真实后验的"最佳高斯近似"——通常是一个集中在某个众数上的单高斯。这种**寻众数**（mode-seeking）行为是反向 KL 目标的特征，也是变分推断的实际权衡之一。
