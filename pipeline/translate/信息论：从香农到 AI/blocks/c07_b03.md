§6.2–6.4 中的证明将三个要素编织在一起，初次阅读时试图同时追踪三者会感到困难。以下是路线图，让你知道每一步的权重：

| 步骤 | 发生什么 | 概念权重 |
|---|---|---|
| 1. 随机码本（§6.2） | 从 p(x) 中 i.i.d. 抽取每个码字的符号 | **核心技巧。** 通过平均绕过构造。 |
| 2. 联合典型性解码（§6.3） | 解码到与 y^n 联合典型的唯一码字 | 次优但_可分析_。ML 解码更紧但更复杂。 |
| 3. 两个错误事件：E_0 和 E_m（§6.3） | 真实码字不联合典型，或某个其他码字联合典型 | 标准记账。 |
| 4. 用联合 AEP 界 \Pr(E_0) | 由联合典型性性质 1，\to 0 | 机械的（第 3 章结果）。 |
| 5. 用性质 3 界 \Pr(E_m) | 每个错误码字 \leq 2^{-n(I(X;Y) - 3\epsilon)} | **核心不等式。** 容量 I(X;Y) 在此进入。 |
| 6. 联合界 + 计数：2^{nR} 个错误码字 | 总错误 \leq 2^{nR} \cdot 2^{-n(I-3\epsilon)} \to 0 当且仅当 R < I | 机械的，但揭示了阈值。 |
| 7. 平均 → 存在（§6.4） | 如果码本上的平均 \to 0，某个码本达到它 | "概率方法"——非构造性但铁证如山。 |

真正做实质工作的两步是 **1**（随机编码装置）和 **5**（联合典型性计数）。其余都是记账。如果你只内化一件事，请内化：**速率 R 通过 2^{nR} 进入，错误码字概率以 2^{-nI} 缩减，两者恰好在 R = I 处平衡**。这种平衡——码本大小的指数增长对抗碰撞概率的指数缩减——就是信道编码定理的全部内容。

现在给出正式论证。

Shannon 的天才之举：不构造一个特定的好码，而是对所有随机抽取的码取平均。

固定一个输入分布 p(x)（我们最终将选择容量达到分布）。通过从 \prod_{i=1}^n p(x_i) 独立抽取每个码字 x^n(m) 来生成随机码本 \mathcal{C}，即每个码字的每个符号独立地从 p(x) 采样。

码本现在是一个随机对象。我们将计算_期望_错误概率，在随机码本和信道噪声上取平均。如果这个期望错误趋于零，那么至少一个特定码本（事实上，几乎所有码本）必定有小错误。

这是一种"概率存在性"证明。它是非构造性的：它告诉我们好码存在，但不告诉我们它是什么。
