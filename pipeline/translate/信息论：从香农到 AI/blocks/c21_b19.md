### 第 10 章——变分推断

**应用题 Q1.** 从 \log p(x) = \mathbb{E}_q[\log p(x)] 推导 ELBO。

插入 p(z \mid x) 并使用 p(x) = p(x, z) / p(z \mid x)：

\log p(x) = \mathbb{E}_q\!\left[\log \frac{p(x, z)}{p(z \mid x)}\right] = \mathbb{E}_q\!\left[\log \frac{p(x, z)}{q(z)}\right] + \mathbb{E}_q\!\left[\log \frac{q(z)}{p(z \mid x)}\right] = \mathrm{ELBO}(q) + D(q \| p(\cdot \mid x)).

由于 D \geq 0，\log p(x) \geq \mathrm{ELBO}(q)，当且仅当 q = p(\cdot \mid x) 时取等。最大化 ELBO 等价于最小化变分后验与真实后验之间的逆向 KL。

**应用题 Q2（ELBO 分解）。** 对编码器 q_\phi(z|x)、解码器 p_\theta(x|z) 和先验 p(z) 的 VAE，写出 ELBO 并识别"重构"和"正则化"项。

\mathrm{ELBO} = \mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)] - D(q_\phi(z|x) \| p(z)).

重构：\mathbb{E}_q[\log p_\theta(x|z)]——解码器下 x 的平均对数似然，对高斯解码器本质上是负 MSE。正则化：D(q_\phi(z|x) \| p(z))——将编码器后验拉向先验的 KL。第一项希望 z 对 x 有预测性；第二项希望 z 对来自哪个 x 无信息。此权衡恰是第 11 章的率失真结构。

**应用题 Q3（两个一元高斯间的 KL）。** 闭式计算 D(\mathcal{N}(\mu_1, \sigma_1^2) \| \mathcal{N}(\mu_2, \sigma_2^2))。

D = \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac{1}{2}.

合理性检查。(i) 相同分布（\mu_1 = \mu_2, \sigma_1 = \sigma_2）：D = 0 + 1/2 - 1/2 = 0。✓ (ii) 相同方差，不同均值：D = (\mu_1 - \mu_2)^2 / (2\sigma^2)——以标准差为单位的均方差距，除以 2。✓ 此公式是 p(z) = \mathcal{N}(0, I) 时 VAE KL 项的工作马：D(q_\phi(z|x) \| p(z)) = \tfrac{1}{2}\sum_d (\mu_d^2 + \sigma_d^2 - \log\sigma_d^2 - 1)，对潜在维度求和。
