### 3.3 示例：计数典型序列

设 \(p(0)=0.8\)，\(p(1)=0.2\)。熵为

\[
H_b(0.2)=-0.2\log_2 0.2-0.8\log_2 0.8\approx0.722\text{ 比特}.
\]

当 \(n=100\) 时，典型集长什么样？

一条典型序列大约有 \(np(0)=80\) 个零和 \(np(1)=20\) 个一（由大数定律）。此类序列的数量为

\[
\binom{100}{20}\approx5.36\times10^{20}.
\]

每条此类序列的概率为

\[
0.8^{80}\cdot0.2^{20}\approx1.86\times10^{-22},
\]

所以总概率约为

\[
\binom{100}{20}\cdot0.8^{80}\cdot0.2^{20}\approx0.0993,
\]

约为十分之一。

实际上，主导的典型集由具有_一定范围_组合的序列组成（比如 70 到 90 个零），当 \(n\) 足够大时，这个范围上的总概率接近 1。此类序列的数量约为

\[
2^{nH(X)}=2^{72.2}\approx5.4\times10^{21},
\]

与我们的二项式系数相当。

长度为 100 的二元序列总数为

\[
2^{100}\approx1.27\times10^{30}.
\]

典型集约为总数的 \(10^{-9}\)。然而它携带了几乎所有的概率。

用一张图来概括：

       序列空间（大小为 2^n；当 n = 100 时约为 10^30）
       ┌──────────────────────────────────────────────────────┐
       │                                                      │
       │                                                      │
       │      ┌───── 典型集 ──────┐                           │
       │      │ 大小 ≈ 2^{nH} ≈ 10^21 │                       │
       │      │ 概率质量 ≈ 1       │                           │
       │      │ 每个成员的概率：   │                           │
       │      │   ≈ 2^{-nH} ≈ 10^-22 │                        │
       │      └─────────────────────┘                           │
       │                                                      │
       │ 非典型：10^30 条序列，但总概率 → 0                    │
       │                                                      │
       └──────────────────────────────────────────────────────┘

需要内化的两个事实：典型集是环境空间中的_指数级小岛_（其大小相对于 \(2^n\) 以 \(2^{-n(\log_2|\mathcal{X}|-H(X))}\) 收缩），然而它携带了_几乎全部_概率。压缩之所以有效，恰恰是因为我们可以丢弃岛外所有事物的地址。
