**公理 4（归一化）**：H(1/2, 1/2) = 1，从而使一次公平的二元提问携带一个熵单位。

这是单位的选择，把对数底固定为 2。

**定理（Khinchin / Shannon）**：满足公理 1 到 4 的唯一函数是

H(p_1, \ldots, p_n) = -\sum_{i=1}^n p_i \log_2 p_i.

完整证明是技术性的，由 Khinchin 在 1950 年代首次以完整形式给出。Shannon 1948 年的原始推导使用了略有不同的公理集，但得到了相同结论。对我们而言，要点是：这个公式不是猜测。一旦你认定信息应连续、在等可能选项数上单调、并在分组下一致，公式就被强制确定了。

这类公理化唯一性在应用数学中很少见。正是它使信息论具有普适性：对概率分布的任何合理的平均不确定性定义，在相差一个尺度因子的意义下都等价于 Shannon 的定义。


#### 常见误解

许多读者初次接触香农熵时，会把它与以下两个相邻量混淆，从而误用：

* **误解**：“熵不过是结果个数的 \log。”

这只对均匀分布成立。对非均匀分布，熵严格小于 \log n，且仅当所有结果等可能时才等于 \log n。八面作弊骰子的熵小于 3 比特，正如我们的例题所示。

* **误解**：“熵度量的是某个_特定_结果的信息量。”

不是——那是自信息，I(x) = -\log p(x)。熵是自信息在分布上的_平均值_：H(X) = \mathbb{E}[I(X)] = \sum p(x) I(x)。X 的熵是概括整个分布的一个数，而非某个特定结果的函数。

在教授信息论时，这两种误解大概占早期错误的一半。请把它们记在心上。


### 1.5 熵的性质

我们在此汇集熵最有用的初等性质。其中多数是 -x \log x 凸性的直接推论，全书将反复用到这一点。


#### 性质 1：非负性

H(X) \geq 0.

**证明**：当 0 \leq p(x) \leq 1 时，每一项 -p(x) \log p(x) 非负，因为在 [0, 1] 上 \log p(x) \leq 0。非负项之和非负。□

等号成立当且仅当 X 是确定性的，即某个结果的 p(x) = 1，其余为 0。
