容量是最大互信息；最大值在输入分布上取，因为信道是固定的。

**答案：** 转移分布为 p(y \mid x) 的离散无记忆信道的容量为 C = \max_{p(x)} I(X; Y) = \max_{p(x)} [H(Y) - H(Y \mid X)]。

这是正确的定义，原因有二。(1) 操作上，第 6 章将证明低于 C 的任何速率都可达且错误趋于零；高于 C 的速率不可达。(2) 数学上，这是自然的最大化：信道是固定的（由物理给定），但输入分布由我们选择（由编码器选择）。

**Q2.** 计算 \epsilon = 0.1 和 \epsilon = 0.5 时的 C_{\text{BSC}}。

提示。C = 1 - H_b(\epsilon)。

**答案：** \epsilon = 0.1：H_b(0.1) \approx 0.469 比特，C \approx 0.531 比特每次使用。
\epsilon = 0.5：H_b(0.5) = 1 比特，C = 0 比特每次使用。

第一个信道每次使用传输约半比特；第二个无用（输出与输入独立）。

**Q3.** 计算 SNR = 10, 100, 1000 时的 C_{\text{AWGN}}。

提示

C = \frac{1}{2} \log_2(1 + \text{SNR})。

**答案：** SNR = 10：C = 0.5 \log_2 11 \approx 1.73 比特每次使用。SNR = 100：C = 0.5 \log_2 101 \approx 3.33 比特每次使用。SNR = 1000：C = 0.5 \log_2 1001 \approx 4.98 比特每次使用。

SNR 每增加十倍增加 0.5 \log_2 10 \approx 1.66 比特每次使用。这就是为什么发射功率翻倍约增加半比特每次使用，而增加一个数量级约增加 1.66 比特。

**Q4.** 为什么 BEC 容量是 1 - \epsilon，而不是像 BSC 那样是 1 - H_b(\epsilon)？

提示

接收端知道擦除何时发生。

**答案：** 在 BEC 中，接收端总是知道擦除何时发生——符号 "?" 与 "0" 或 "1" 明确不同。所以接收端在给定非擦除输出时对输入的不确定性为零（它完全知道发送了什么），唯一的损失是被擦除比特的比例 \epsilon，这些比特不携带信息。

在 BSC 中，接收端不知道翻转何时发生。每个接收比特带有一些关于它是原始版还是翻转版的不确定性。每比特的不确定性为 H_b(\epsilon)，在 \epsilon < 1/2 时大于 \epsilon。这就是为什么对于相同的 \epsilon，BSC 比 BEC "更难"。
