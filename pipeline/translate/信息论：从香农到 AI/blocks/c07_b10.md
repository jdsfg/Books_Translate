#### 深度学习中的随机初始化

不太直接地：深度学习依赖网络权重的随机初始化。训练的成功取决于初始化落在权重空间的"好"区域。虽然这不是字面上的 Shannon 论证，但精神是相同的——高维分布的随机样本倾向于具有 desirable 性质。

这些都是同一普遍原理的实例：**在高维空间中，随机对象倾向于具有出人意料的好性质**。Shannon 的编码定理是第一个戏剧性的实例，但这一现象在现代计算机科学中反复出现。

### 常见误解

* **误解**："信道编码定理说你可以以速率 C 无错传输。"

不对。定理说你可以以_低于_ C 的速率传输且错误趋于零。恰好在 C 时，情况更微妙：错误是否趋于零取决于信道。高于 C 时，错误有正下界。

* **误解**："Shannon 告诉我们如何构建好码。"

不对。Shannon 的证明是非构造性的：它展示好码存在但不指定它们。五十年寻找接近容量码的工程努力恰恰因为 Shannon 定理是一个存在性结果。

* **误解**："随机编码论证说随机码是最优的。"

不对。随机码只是_足够好_：平均随机码达到容量，因此至少一个特定码达到。特定的结构化码（Reed-Solomon、LDPC、Polar）通常比典型随机码表现更好，同时可以用实用算法解码。

### 本章小结

Shannon 信道编码定理是经典信息论中最深刻的结果：

1. **可达性**：任何速率 R < C 可达且错误趋于零。证明：随机编码 + 联合典型性解码。
2. **逆定理**：任何速率 R > C 无法达到趋于零的错误。证明：Fano 不等式 + 数据处理不等式。

容量 C = \max_{p(x)} I(X; Y) 是可达与不可达速率之间的_尖锐_边界。速率和错误之间没有连续的权衡；低于容量，你可以兼得两者。

随机编码的证明技术是 Shannon 最有影响力的方法论贡献。它展示所有码的平均足够好；因此至少一个特定码是好的。工程师花了五十年追赶，才构造出在实践中接近容量的码。
