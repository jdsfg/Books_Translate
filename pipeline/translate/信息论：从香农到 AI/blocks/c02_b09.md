#### 性质 2：有限集合上的最大熵

对定义在 n 个结果集合上的离散随机变量 X，

H(X) \leq \log n,

等号成立当且仅当 X 均匀分布。

**证明**：这由詹森不等式作用于凹函数 \log 得到。对任意概率分布 p，

H(X) = \sum_x p(x) \log \frac{1}{p(x)} \leq \log \sum_x p(x) \cdot \frac{1}{p(x)} = \log n,

其中我们对凹函数 \log 使用了詹森不等式。詹森不等式取等当且仅当自变量为常数，即对所有 x，1/p(x) 相同，也就是对所有 x 有 p(x) = 1/n。□


#### 性质 3：对分布的凹性

H(p) 是 p 的凹函数。也就是说，对两个概率分布 p、q 以及 \lambda \in [0, 1]，

H(\lambda p + (1 - \lambda) q) \geq \lambda H(p) + (1 - \lambda) H(q).

**证明**：函数 f(t) = -t \log t 在 [0, 1] 上凹（求导验证：f''(t) = -1/(t \ln 2) < 0）。熵是 f(p(x)) 的和，凹函数之和仍凹。□

这一凹性有一个漂亮的解释：混合两个分布只会增加熵。直觉上，混合产生了更不确定的合成分布；你必须先决定自己是从哪个分布中抽样的。


#### 性质 4：联合熵分解

对一对 (X, Y)，**联合熵**为

H(X, Y) = -\sum_{x, y} p(x, y) \log p(x, y).

这不过是把联合分布当作乘积空间上的单个随机变量时的熵。它满足

\max(H(X), H(Y)) \leq H(X, Y) \leq H(X) + H(Y),

右边不等式取等当且仅当 X 与 Y 独立。

我们将在第 2 章回到联合熵，以及它更丰富的近亲——条件熵与互信息。
