#### 概念检查

**Q1.** 计算 p = (0.5, 0.5) 和 q = (0.9, 0.1) 之间的 Hellinger 距离。

**答案：** d_H(p, q) = \sqrt{\frac{1}{2}[(\sqrt{0.5} - \sqrt{0.9})^2 + (\sqrt{0.5} - \sqrt{0.1})^2]} = \sqrt{\frac{1}{2}[(0.707 - 0.949)^2 + (0.707 - 0.316)^2]} = \sqrt{\frac{1}{2}[0.0586 + 0.1531]} \approx \sqrt{0.106} \approx 0.325。

与之前约 0.737 比特的 KL 相比。Hellinger 是度量且以 1 为界；KL 上无界且不对称。

**Q2.** 证明 D(p \| q) = D_f(p \| q) 对 f(t) = t \log t。

**答案：** D_f(p \| q) = \sum_x q(x) f(p(x)/q(x)) = \sum_x q(x) \cdot (p(x)/q(x)) \log(p(x)/q(x)) = \sum_x p(x) \log(p(x)/q(x)) = D(p \| q)。□

**Q3.** 陈述 Kantorovich-Rubinstein 对偶。为什么它对训练 Wasserstein GAN 有用？

**答案：** W_1(p, q) = \sup_{|f|_L \leq 1} [\mathbb{E}_p f - \mathbb{E}_q f]。

对 Wasserstein GAN 有用，因为上确界可以通过将 f 参数化为带 Lipschitz 约束的神经网络（通常通过梯度惩罚或权重裁剪来强制）来近似。判别器成为 Lipschitz 函数 f，生成器被训练以最小化 \mathbb{E}_p f - \mathbb{E}_q f。这避免了基于 JS 的 GAN 的饱和问题。

**Q4.** 高斯 \mathcal{N}(\mu, \sigma^2) 关于 \mu 的 Fisher 信息是什么？

提示

I(\mu) = \mathbb{E}[(\partial \log p / \partial \mu)^2]。

**答案：** 对于 p(x; \mu) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp(-(x-\mu)^2/(2\sigma^2))：\partial \log p / \partial \mu = (x - \mu) / \sigma^2。I(\mu) = \mathbb{E}[(X - \mu)^2 / \sigma^4] = \sigma^2 / \sigma^4 = 1/\sigma^2。

Fisher 信息是方差的倒数。Cramér-Rao 界说任何 \mu 的无偏估计量对 n 个样本的方差至少为 \sigma^2 / n——恰好是样本均值所达到的。所以样本均值是渐近有效的（饱和 CR 界）。
