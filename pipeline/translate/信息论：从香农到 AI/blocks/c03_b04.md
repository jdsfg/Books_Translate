### 2.3 示例：诊断中的条件熵

一位医生有一位患者，患有以下两种疾病之一：常见病（概率 0.9）或罕见病（概率 0.1）。她进行了一项检查 X，其条件分布如下：

p(X = + \mid \text{common}) = 0.1, \quad p(X = - \mid \text{common}) = 0.9, \quad p(X = + \mid \text{rare}) = 0.95, \quad p(X = - \mid \text{rare}) = 0.05.

该检查高度敏感（真阳性率 0.95）且具有合理的特异性（真阴性率 0.9）。检查前疾病的熵是多少？检查后呢？

设 Y 为疾病，X 为检查结果。

检查前：

H(Y) = H_b(0.1) = -0.1 \log 0.1 - 0.9 \log 0.9 \approx 0.469 \text{ bits}.

检查的边缘概率：

p(X = +) = 0.9 \cdot 0.1 + 0.1 \cdot 0.95 = 0.09 + 0.095 = 0.185, \quad p(X = -) = 1 - 0.185 = 0.815.

阳性检查后的后验概率：

p(Y = \text{rare} \mid X = +) = \frac{p(X = + \mid \text{rare}) p(\text{rare})}{p(X = +)} = \frac{0.95 \cdot 0.1}{0.185} \approx 0.514.

阴性检查后的后验概率：

p(Y = \text{rare} \mid X = -) = \frac{0.05 \cdot 0.1}{0.815} \approx 0.0061.

因此，阳性检查后，患者患罕见病的几率约为五五开。阴性检查后，罕见病几乎被排除。条件熵：

H(Y \mid X = +) = H_b(0.514) \approx 0.9996 \text{ bits}, \quad H(Y \mid X = -) = H_b(0.0061) \approx 0.052 \text{ bits}, \quad H(Y \mid X) = 0.185 \cdot 0.9996 + 0.815 \cdot 0.052 \approx 0.185 + 0.042 \approx 0.227 \text{ bits}.

注意 H(Y \mid X = +) > H(Y) \approx 0.469 比特：在这种情况下，阳性检查_增加_了不确定性（因为它使患者在两种疾病之间大致五五开）。但 H(Y \mid X = -) 非常低。平均值 H(Y \mid X) \approx 0.227 小于 H(Y) \approx 0.469，正如不等式所要求的。

检查获得的信息量为 H(Y) - H(Y \mid X) \approx 0.242 比特。换言之，这项检查平均消除了约半比特的疾病不确定性。这个数字，即**互信息**，是本章的下一个主题。
