#### 收敛与大数定律

随机变量序列 X_n 收敛到 X：

* **依概率**：对每个 \epsilon > 0，\Pr(|X_n - X| > \epsilon) \to 0。
* **几乎必然**：\Pr(X_n \to X) = 1。
* **依分布**：累积分布函数在所有连续点收敛。

**弱大数定律**说对于独立同分布 X_1, X_2, \ldots 且有限均值 \mu，样本平均 \bar X_n = (1/n) \sum_{i=1}^n X_i 依概率收敛到 \mu。**强大数定律**将此加强为几乎必然收敛。

渐近等分性质（第 3 章）是大数定律对序列 -(1/n) \log p(X_1, \ldots, X_n) 的直接应用；当 X_i 独立同分布时，此平均依概率收敛到 H(X)。

### A.2 微积分


#### 常用导数

* \frac{d}{dx} \log x = 1/x（自然对数；对 \log_2，除以 \ln 2）。
* \frac{d}{dx} (x \log x) = \log x + 1。
* \frac{d}{dp} (-p \log p - (1-p) \log(1-p)) = \log\frac{1-p}{p}；在 p = 1/2 处为零，确认二元信源的最大熵。

#### 拉格朗日乘子

在约束 g(x_1, \ldots, x_n) = c 下最大化 f(x_1, \ldots, x_n) 导致方程组

\nabla f = \lambda \nabla g, \qquad g = c.

这就是我们如何求解"在 \sum p_i = 1 约束下找到最大化 H(p) 的分布 p"（均匀分布），以及如何在矩约束下推导最大熵分布（固定方差时为高斯，正半轴上固定均值时为指数）。

#### 泰勒展开

在点 x_0 附近，光滑函数满足

f(x) = f(x_0) + f'(x_0)(x - x_0) + \tfrac{1}{2} f''(x_0)(x - x_0)^2 + O((x - x_0)^3).

信息几何（第 9 章）使用 KL 散度在 \theta_0 附近的二阶泰勒展开；二阶导数是 Fisher 信息矩阵。

### A.3 线性代数


#### 向量、矩阵、特征值

实对称 n \times n 矩阵 A 有 n 个实特征值 \lambda_1, \ldots, \lambda_n 和正交特征向量基。A **半正定**（PSD）当且仅当所有 \lambda_i \geq 0，当且仅当对所有 x 有 x^\top A x \geq 0。协方差矩阵总是 PSD。

**迹** \mathrm{tr}(A) = \sum_i A_{ii} = \sum_i \lambda_i 在正交基变换下不变。

#### 矩阵指数与对数

对于有谱分解 A = U \Lambda U^\dagger 的厄米矩阵 A，矩阵函数按特征值定义：\exp(A) = U \exp(\Lambda) U^\dagger，\log(A) = U \log(\Lambda) U^\dagger（后者要求 A \succ 0）。密度矩阵 \rho 的**冯·诺依曼熵**（第 16 章）为 -\mathrm{tr}(\rho \log \rho)，等于 \rho 特征值谱的香农熵。
