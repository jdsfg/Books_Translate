#### 概念检查

**Q1.** 陈述率失真定理。

**答案：** 对于分布为 p(x)、失真度量为 d 的无记忆信源 X，操作率失真函数等于信息率失真函数：

R(D) = \min_{p(\hat{x} \mid x) : \mathbb{E}[d(X, \hat{X})] \leq D} I(X; \hat{X}).

这是在保持平均失真低于 D 的条件下，对信源进行有损压缩的最低比特率。

**Q2.** 方差为 \sigma^2、平方误差失真的高斯信源的率失真函数是什么？

**答案：** R(D) = \frac{1}{2} \log(\sigma^2 / D)，当 0 \leq D \leq \sigma^2；当 D \geq \sigma^2 时为 0。

每样本每增加一比特将均方误差降低 4 倍。速率翻倍（多一比特）使均方误差降低 4 倍。

**Q3.** 什么是反向注水？为什么叫"反向"？

**答案：** 对于 K 个方差为 \sigma_i^2 的独立高斯信源，总失真 D 下的最优比特分配是将每个分量的失真降至 D_i = \min(\sigma_i^2, \lambda)，其中 \lambda 是一个"水位"，选择使得 \sum D_i = D。

"水"是失真预算；"容器底部"是方差。方差低于水位的分量不分配比特（直接置零）。称之为"反向"注水是因为失真是过程的*输出*而非输入——与高斯信道的正向注水形成对比，后者中输入方差是子信道容量。

**Q4.** 解释为什么率失真函数对 D 单调递减。

**答案：** 允许更大失真意味着约束集 \{p(\hat{x} \mid x) : \mathbb{E}[d] \leq D\} 扩大。在更大集合上的最小值至多等于在更小集合上的最小值。因此 R(D) 随 D 增大而减小。直觉上：如果允许更多误差，所需比特就更少。
