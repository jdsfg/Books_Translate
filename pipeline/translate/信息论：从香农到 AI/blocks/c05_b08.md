### 4.8 AI 联系：语言模型即压缩器

现在我们建立定义本书 AI 半边的联系。

语言模型是一个在给定历史条件下对下一个 token 的概率分布 p_\theta(x_t \mid x_1, \ldots, x_{t-1})。其训练目标是最小化语料上的交叉熵

\mathcal{L} = -\frac{1}{n} \sum_{t=1}^n \log p_\theta(x_t \mid x_1, \ldots, x_{t-1})

由链式法则，这等价于

\mathcal{L} = -\frac{1}{n} \log p_\theta(x_1, \ldots, x_n).

如果我们用这个语言模型作为算术编码中的概率分布，每 token 的期望编码长度约为 \mathcal{L} 比特。所以：

**语言模型在文本上的交叉熵恰好等于用该模型作为信源分布进行算术编码时的每符号比特开销。**

这不是比喻。这是精确的数学恒等式。

因此，**交叉熵为每 token \mathcal{L} 比特的语言模型，使用算术编码时以 \mathcal{L} 比特每 token 的速率压缩文本。**

这与 gzip 相比如何？在大型英文语料上：

* gzip（基于 LZ77）：约 2.0-2.5 比特每字符（1.6:1 到 2.5:1 压缩比）。
* xz / LZMA：约 1.5-2.0 比特每字符。
* 小型 Transformer（124M 参数，GPT-2 small）：在多样英文上约 1.0-1.2 比特每字符。
* 前沿模型：在多样英文上约 0.7-0.9 比特每字符。

前沿数字在 Shannon 1951 年对英文熵的估计（基于人类预测实验，约 0.7-1.5 比特每字符）的两倍以内。现代语言模型正在压低经验熵估计——在许多子样本上，它们预测英文比人类更好。

**困惑度**是一个密切相关的指标：2^{\mathcal{L}}。它衡量模型在每步从中选择的"有效词汇表大小"。困惑度 32 意味着模型平均而言像在 32 个等概率 token 中选择。维基百科或网络文本上的前沿困惑度现在已是个位数；对于原始字节级预测，前沿模型达到约每字节 1.5-2 个有效选择。

深层主张，也是使信息论成为现代 AI 数学基础的关键：**预测和压缩是同一个问题**。如果你有一个预测得好的模型，你就有一个压缩得好的模型，反之亦然。语言模型的交叉熵训练在数学上就是训练算术编码器以良好压缩文本。语言模型的"缩放律"（Hoffmann, Chinchilla; Kaplan）描述了压缩速率如何随模型大小和数据改善——它们是一个熵估计器的缩放律。
