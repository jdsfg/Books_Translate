#### 概念检查

**Q1.** 写出 ELBO 及恒等式 \log p(x) = \text{ELBO} + D(q \| p(\cdot \mid x))。

**答案：** \text{ELBO}(q_\phi) = \mathbb{E}_{q_\phi}[\log p(x, z) - \log q_\phi(z)]。

等价地：\text{ELBO} = \mathbb{E}_q[\log p(x \mid z)] - D(q \| p(z))（重构减去与先验的 KL）。

恒等式：\log p(x) = \text{ELBO}(q_\phi) + D(q_\phi(z) \| p(z \mid x))。由于 D \geq 0，ELBO 是对数证据的下界。在 \phi 上最大化 ELBO 等价于最小化与真实后验的 KL。

**Q2.** 为什么 ELBO 被称为"下界"？

**答案：** 因为 \log p(x) = \text{ELBO} + D(q \| p(\cdot \mid x)) 且 D \geq 0，所以 \text{ELBO} \leq \log p(x)。ELBO 至多等于对数证据；我们无法使其超过真实值。

**Q3.** 什么是重参数化技巧？为什么需要它？

**答案：** 重参数化技巧：如果 z \sim q_\phi(z) = \mathcal{N}(\mu_\phi, \sigma_\phi^2)，将其重写为 z = \mu_\phi + \sigma_\phi \cdot \epsilon，其中 \epsilon \sim \mathcal{N}(0, 1) 是固定的。现在 z 是 \phi 的可微函数（加上一个随机样本 \epsilon），梯度可以流通。

没有这个技巧，从 z \sim q_\phi 采样是一个不可微的操作，无法通过样本反向传播来更新 \phi。有了这个技巧，整个变分下界就可以通过随机梯度下降来优化。

**Q4.** VAE 的"重构项"度量什么？"KL 项"度量什么？

**答案：** 重构项 \mathbb{E}_{q_\phi}[\log p_\theta(x \mid z)]：给定编码后的隐变量，数据的期望对数似然。度量解码器从 q_\phi(z \mid x) 的样本中重构 x 的能力。越大越好。

KL 项 D(q_\phi(z \mid x) \| p(z))：编码器输出与先验之间的 KL 散度。度量编码后的分布与先验"差异"多大。越小越好。

权衡：更好的重构通常需要编码器分布更"展开"（使用更多比特），这会增加 KL。ELBO 选择最优的平衡。
