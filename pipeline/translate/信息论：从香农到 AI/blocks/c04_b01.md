想象抛掷一枚公平硬币 1000 次。恰好有 2^{1000} 种可能的正反面序列，这个数有 301 位十进制数字，远大于可观测宇宙中的原子数。按任何朴素的计算，你可能会认为结果是不可想象的多样性中的一种。确实如此，在这个意义上，任何特定的结果序列本质上是不可能预测的。

但令人惊讶的是。在这 2^{1000} 种序列中，绝大多数共享一个性质：它们大约有 500 次正面和 500 次反面，偏差不过几个标准差。70 次正面的序列，或全正面的序列，或正反面以固定周期交替的序列，理论上可能但实际上从未被观察到。“典型”序列的空间远小于全空间，却包含了几乎所有的概率。

这就是**渐近均分性**（AEP），它是概率论中最美丽的结果之一。它是熵的抽象定义与压缩的操作含义之间的桥梁：熵 H(X) 恰好是描述从 X 中抽取的长序列的渐近每符号代价，因为长序列集中在 2^{nH(X)} 条典型序列上，且它们大致等概率。

在本书的所有章节中，第 3 章是最“神奇”的。从大数定律应用于对数概率的一个陈述中，整套压缩和信道编码的操作理论便自然涌现。我们感谢 Shannon（1948）提供了这一视角；现代教科书证明归功于 McMillan 和 Breiman。


### 3.1 AEP 的陈述

设 X_1, X_2, \ldots 为从有限字母表 \mathcal{X} 上的分布 p(x) 中独立同分布（i.i.d.）抽取的随机变量序列。任意特定序列 (x_1, x_2, \ldots, x_n) 的概率为

p(x_1, x_2, \ldots, x_n) = \prod_{i=1}^n p(x_i).

取对数：

\log p(x_1, \ldots, x_n) = \sum_{i=1}^n \log p(x_i).

右边是 n 个 i.i.d. 随机变量的和（每个为 \log p(X_i)，对随机样本 X_i）。由弱大数定律，该和在概率上收敛到 n \cdot \mathbb{E}[\log p(X)] = -n H(X)。除以 n：

-\frac{1}{n} \log p(X_1, \ldots, X_n) \to H(X) \quad \text{in probability}.
