#### 概念检查

**Q1.** 两个随机变量 X 和 Y 取值于 \{0, 1\}，联合分布为：p(0, 0) = 0.4，p(0, 1) = 0.1，p(1, 0) = 0.1，p(1, 1) = 0.4。计算 H(X)、H(Y)、H(X, Y)、H(Y \mid X) 和 I(X; Y)。

提示

先计算边缘分布 p(X) 和 p(Y)，然后使用公式。

**答案：** 边缘分布：p(X = 0) = 0.5，p(X = 1) = 0.5；Y 同理。所以 H(X) = H(Y) = 1 比特。

联合熵：H(X, Y) = -2(0.4 \log 0.4) - 2(0.1 \log 0.1) \approx 2(0.529) + 2(0.332) = 1.058 + 0.664 = 1.722 比特。

条件熵：H(Y \mid X) = H(X, Y) - H(X) = 1.722 - 1 = 0.722 比特。

互信息：I(X; Y) = H(Y) - H(Y \mid X) = 1 - 0.722 = 0.278 比特。

变量具有正的互信息，表明存在依赖性：事实上 p(X = Y) = 0.8 > 0.5，而在独立情况下该值为 0.5。

**Q2.** 直接从定义证明 I(X; X) = H(X)。

提示

使用 I(X; Y) = H(X) - H(X \mid Y)，令 Y = X。

**答案：** H(X \mid X) = 0（知道 X 后对 X 没有不确定性）。所以 I(X; X) = H(X) - H(X \mid X) = H(X) - 0 = H(X)。一个随机变量关于自身携带的信息恰好等于其自身的熵，不多不少。

**Q3.** 从定义 H(X, Y, Z) = -\sum p(x, y, z) \log p(x, y, z) 出发，验证链式法则 H(X, Y, Z) = H(X) + H(Y \mid X) + H(Z \mid X, Y)。

提示

分解 p(x, y, z) = p(x) p(y \mid x) p(z \mid x, y) 并取对数。

**答案：** 使用因式分解，

\log p(x, y, z) = \log p(x) + \log p(y \mid x) + \log p(z \mid x, y).

所以

H(X, Y, Z) = -\sum p(x, y, z) \log p(x) - \sum p(x, y, z) \log p(y \mid x) - \sum p(x, y, z) \log p(z \mid x, y).

每一项求和都可化简：第一项等于 H(X)（对 y、z 求和得到 p(x)）；第二项等于 H(Y \mid X)；第三项等于 H(Z \mid X, Y)。□
