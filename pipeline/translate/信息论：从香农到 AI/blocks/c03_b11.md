**Q1.** 两个随机变量 XXX 和 YYY 取值于 {0,1}\{0, 1\}{0,1}，联合分布为：p(0,0)=0.4p(0, 0) = 0.4p(0,0)=0.4，p(0,1)=0.1p(0, 1) = 0.1p(0,1)=0.1，p(1,0)=0.1p(1, 0) = 0.1p(1,0)=0.1，p(1,1)=0.4p(1, 1) = 0.4p(1,1)=0.4。计算 H(X)H(X)H(X)、H(Y)H(Y)H(Y)、H(X,Y)H(X, Y)H(X,Y)、H(Y∣X)H(Y \mid X)H(Y∣X) 和 I(X;Y)I(X; Y)I(X;Y)。

提示

先计算边缘分布 p(X)p(X)p(X) 和 p(Y)p(Y)p(Y)，然后使用公式。

**答案：** 边缘分布：p(X=0)=0.5p(X = 0) = 0.5p(X=0)=0.5，p(X=1)=0.5p(X = 1) = 0.5p(X=1)=0.5；YYY 同理。所以 H(X)=H(Y)=1H(X) = H(Y) = 1H(X)=H(Y)=1 比特。

联合熵：H(X,Y)=−2(0.4log⁡0.4)−2(0.1log⁡0.1)≈2(0.529)+2(0.332)=1.058+0.664=1.722H(X, Y) = -2(0.4 \log 0.4) - 2(0.1 \log 0.1) \approx 2(0.529) + 2(0.332) = 1.058 + 0.664 = 1.722H(X,Y)=−2(0.4log0.4)−2(0.1log0.1)≈2(0.529)+2(0.332)=1.058+0.664=1.722 比特。

条件熵：H(Y∣X)=H(X,Y)−H(X)=1.722−1=0.722H(Y \mid X) = H(X, Y) - H(X) = 1.722 - 1 = 0.722H(Y∣X)=H(X,Y)−H(X)=1.722−1=0.722 比特。

互信息：I(X;Y)=H(Y)−H(Y∣X)=1−0.722=0.278I(X; Y) = H(Y) - H(Y \mid X) = 1 - 0.722 = 0.278I(X;Y)=H(Y)−H(Y∣X)=1−0.722=0.278 比特。

变量具有正的互信息，表明存在依赖性：事实上，p(X=Y)=0.8>0.5p(X = Y) = 0.8 > 0.5p(X=Y)=0.8>0.5，而在独立情况下该值为 0.50.50.5。

**Q2.** 直接从定义证明 I(X;X)=H(X)I(X; X) = H(X)I(X;X)=H(X)。

提示

使用 I(X;Y)=H(X)−H(X∣Y)I(X; Y) = H(X) - H(X \mid Y)I(X;Y)=H(X)−H(X∣Y)，令 Y=XY = XY=X。

**答案：** H(X∣X)=0H(X \mid X) = 0H(X∣X)=0（知道 XXX 后对 XXX 没有不确定性）。所以 I(X;X)=H(X)−H(X∣X)=H(X)−0=H(X)I(X; X) = H(X) - H(X \mid X) = H(X) - 0 = H(X)I(X;X)=H(X)−H(X∣X)=H(X)−0=H(X)。一个随机变量关于自身携带的信息恰好等于其自身的熵，不多不少。

**Q3.** 从定义 H(X,Y,Z)=−∑p(x,y,z)log⁡p(x,y,z)H(X, Y, Z) = -\sum p(x, y, z) \log p(x, y, z)H(X,Y,Z)=−∑p(x,y,z)logp(x,y,z) 出发，验证链式法则 H(X,Y,Z)=H(X)+H(Y∣X)+H(Z∣X,Y)H(X, Y, Z) = H(X) + H(Y \mid X) + H(Z \mid X, Y)H(X,Y,Z)=H(X)+H(Y∣X)+H(Z∣X,Y)。

提示

分解 p(x,y,z)=p(x)p(y∣x)p(z∣x,y)p(x, y, z) = p(x) p(y \mid x) p(z \mid x, y)p(x,y,z)=p(x)p(y∣x)p(z∣x,y) 并应用对数。

**答案：** 利用分解，

log⁡p(x,y,z)=log⁡p(x)+log⁡p(y∣x)+log⁡p(z∣x,y).\log p(x, y, z) = \log p(x) + \log p(y \mid x) + \log p(z \mid x, y).logp(x,y,z)=logp(x)+logp(y∣x)+logp(z∣x,y).

所以

H(X,Y,Z)=−∑p(x,y,z)log⁡p(x)−∑p(x,y,z)log⁡p(y∣x)−∑p(x,y,z)log⁡p(z∣x,y).H(X, Y, Z) = -\sum p(x, y, z) \log p(x) - \sum p(x, y, z) \log p(y \mid x) - \sum p(x, y, z) \log p(z \mid x, y).H(X,Y,Z)=−∑p(x,y,z)logp(x)−∑p(x,y,z)logp(y∣x)−∑p(x,y,z)logp(z∣x,y).

每个求和化简：第一个等于 H(X)H(X)H(X)（对 y,zy, zy,z 求和得到 p(x)p(x)p(x)）；第二个等于 H(Y∣X)H(Y \mid X)H(Y∣X)；第三个等于 H(Z∣X,Y)H(Z \mid X, Y)H(Z∣X,Y)。 □\square□
