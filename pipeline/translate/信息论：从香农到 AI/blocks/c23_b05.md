### D.6 压缩恒等式检查

为验证第 15 章的核心恒等式——交叉熵等于使用该模型的最优算术编码器的压缩速率——我们在同一留出文本上计算两个量并比较。

    @torch.no_grad()
    def measured_bits_per_char(model, test_ids, ctx=256, max_chars=10_000):
        """Compute the actual compressed bit-length under arithmetic coding
        with the model as the predictor."""
        device = next(model.parameters()).device
        model.eval()
        total_bits = 0.0
        n_chars = min(len(test_ids) - ctx, max_chars)
        for i in range(n_chars):
            x = test_ids[i : i + ctx].unsqueeze(0).to(device)
            target = test_ids[i + ctx].item()
            logits = model(x)[0, -1]
            log_probs = F.log_softmax(logits, dim=-1)
            # Information content of the target under the model:
            # -log_2 p(target) is the arithmetic coder's per-symbol bit cost
            # (within an O(1/n) overhead from the coder's finite precision).
            total_bits += -log_probs[target].item() / math.log(2)
        return total_bits / n_chars


要验证的恒等式：`measured_bits_per_char(model, test_ids)` 应匹配 `evaluate()` 报告的留出交叉熵（单位转换后）至舍入误差以内。§18.2 声称的 1% 差距来自算术编码器的有限精度开销，非任何概念松弛。
