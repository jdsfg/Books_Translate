#### 错误概率分析

不失一般性，假设发送了消息 1。则 y^n 是输入 x^n(1) 的信道输出。解码错误在以下情况发生：

* **事件 E_0**：(x^n(1), y^n) _不_联合典型（正确码字未被识别）。
* **事件 E_m, m \neq 1**：(x^n(m), y^n) _是_联合典型（错误码字被误识别）。

\Pr(\text{error} \mid m = 1) = \Pr(E_0 \cup \bigcup_{m \neq 1} E_m) \leq \Pr(E_0) + \sum_{m \neq 1} \Pr(E_m).

**\Pr(E_0) 的界**：由联合 AEP（§3.7），\Pr((X^n, Y^n) \text{ 联合典型}) \to 1 当 n \to \infty，所以 \Pr(E_0) \to 0。

**\Pr(E_m), m \neq 1 的界**：对于 m \neq 1，码字 x^n(m) 独立于 x^n(1) 生成，因此也独立于 y^n（后者仅依赖于 x^n(1) 和信道噪声）。对 (x^n(m), y^n) 具有独立边际：x^n(m) \sim \prod p(x)，y^n 具有将 x^n(1) 通过信道后得到的某个边际分布 p(y^n)。

由联合典型性性质 3（§3.7），"独立"对看起来联合典型的概率为 \Pr(E_m) \leq 2^{-n(I(X; Y) - 3\epsilon)}，其中 \epsilon 是典型性松弛量。

所以：

\Pr(\text{error} \mid m = 1) \leq \Pr(E_0) + (2^{nR} - 1) \cdot 2^{-n(I(X; Y) - 3\epsilon)} \leq \Pr(E_0) + 2^{nR} \cdot 2^{-n(I(X; Y) - 3\epsilon)}.

当 R < I(X; Y) - 3\epsilon 时，第二项为 2^{-n(I(X; Y) - 3\epsilon - R)} \to 0 当 n \to \infty。第一项 \Pr(E_0) \to 0 由联合 AEP。

所以 \Pr(\text{error} \mid m = 1) \to 0，只要 R < I(X; Y) - 3\epsilon。由于 \epsilon 是任意的，这对任何 R < I(X; Y) 成立。

由随机码本上的对称性，同样的界对每个 m 成立。对 m 取平均，

\bar{P}_e = \frac{1}{2^{nR}} \sum_m \Pr(\text{error} \mid m) \to 0.

这是在随机码本上取平均的。所以至少一个特定码本达到 \bar{P}_e \to 0。

我们已证明：任何速率 R < I(X; Y) 是可达的，对于任何输入分布 p(x)。选择 p(x) 最大化 I(X; Y)，得到：任何速率 R < C 是可达的。□
