#### 示例：BSC 互信息

对于交叉概率为 \epsilon、输入分布 p(0) = p, p(1) = 1 - p 的 BSC：

H(Y \mid X = 0) = H_b(\epsilon), \quad H(Y \mid X = 1) = H_b(\epsilon), \quad H(Y \mid X) = H_b(\epsilon).

输出分布：p(0) = p(1 - \epsilon) + (1 - p) \epsilon = p + \epsilon - 2p\epsilon。

H(Y) = H_b(p + \epsilon - 2p\epsilon).

互信息：

I(X; Y) = H_b(p + \epsilon - 2p\epsilon) - H_b(\epsilon).

当 p = 1/2（均匀输入）时，p + \epsilon - 2p\epsilon = 1/2，所以 H(Y) = 1 且 I(X; Y) = 1 - H_b(\epsilon)。

对于其他输入，互信息严格更小。均匀输入最大化 I，因此决定了信道容量。我们将在 §5.4 中看到为什么这是普遍的。

#### 示例：BEC 互信息

对于擦除概率为 \epsilon、均匀输入 p(0) = p(1) = 1/2 的 BEC：

p(Y = 0) = \frac{1}{2}(1 - \epsilon), \quad p(Y = 1) = \frac{1}{2}(1 - \epsilon), \quad p(Y = ?) = \epsilon.

H(Y) = (1 - \epsilon) + H_b(\epsilon).

H(Y \mid X) = H_b(\epsilon).

I(X; Y) = H(Y) - H(Y \mid X) = (1 - \epsilon) + H_b(\epsilon) - H_b(\epsilon) = 1 - \epsilon.

所以 BEC 在均匀输入下的互信息恰好为 1 - \epsilon 比特每次信道使用，即未被擦除比特通过的速率。这也是 BEC 的容量。

### 5.4 信道容量


#### 定义：信道容量

转移矩阵为 p(y \mid x) 的离散无记忆信道的**容量**为

C = \max_{p(x)} I(X; Y),

其中最大值在 \mathcal{X} 上的所有输入概率分布上取。

用通俗的话说：容量是通过选择输入分布可达到的最高互信息。它是可可靠传输的每信道使用比特数的_上确界_。

容量的操作含义将在第 6 章（Shannon 信道编码定理）中精确化。目前，作为一个口号：**低于 C 的速率是可达的；高于 C 的速率不可达**。
