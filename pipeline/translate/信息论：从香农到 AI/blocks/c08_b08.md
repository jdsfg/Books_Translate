### 本章小结

本章概述了接近 Shannon 容量的实用码：

* **Hamming**：第一个纠错码（1950）；单纠错；奠基性。
* **Reed-Solomon**：MDS 代数码；从 CD 到深空探测器无处不在。
* **卷积码 + Viterbi**：1990 年代蜂窝和卫星的主导方案。
* **Turbo 码**：1993 年突破；第一个实用的接近容量码。
* **LDPC**：1996 年重新发现；接近容量且解码更简单；用于 Wi-Fi、DVB、5G 数据。
* **Polar**：2009 年；可证明达到容量；用于 5G 控制。

从 Shannon 1948 年定理到现代实用容量达到码的 50 年旅程是现代工程中最美丽的故事之一。Shannon 承诺了花费半个世纪才实现的东西。实现者（Hamming、Reed、Solomon、Berrou、MacKay、Arıkan）是数字通信的英雄。

与 AI 最深刻的联系是通过置信传播，它既是 LDPC 解码器，_也是_图模型中变分推断的主力。我们将在第 10 章继续这条线索。

下一章转向信息论的散度方面：KL 散度、交叉熵，以及它们在现代机器学习损失函数中的核心角色。


### 7.X 习题


#### 概念检查

**Q1.** (7, 4) Hamming 码的速率和最小距离是多少？能纠正多少个错误？

**答案：** 速率 = 4/7 \approx 0.571。最小距离 = 3。可纠正 \lfloor (3-1)/2 \rfloor = 1 个错误每块。

**Q2.** \mathbb{F}_{2^8} 上的 Reed-Solomon 码有 n = 255 和 k = 223。速率？能纠正多少字节错误？

**答案：** 速率 = 223/255 \approx 0.875。最小距离 = n - k + 1 = 33。可纠正 \lfloor (33-1)/2 \rfloor = 16 字节错误每块。这是标准 CCSDS 深空遥测码。

**Q3.** 什么是 Singleton 界，哪些码达到它？

**答案：** Singleton 界：d_{\min} \leq n - k + 1 对于任何 (n, k) 码。以等号达到此界的码称为 MDS（最大距离可分）。Reed-Solomon 码是 MDS。大多数二元码不是（因为 Singleton 界对二元字母表是松弛的）。

**Q4.** 给定可比速率，为什么 LDPC 和 Turbo 码比 Hamming 或 Reed-Solomon 好得多？

**答案：** Hamming 和 Reed-Solomon 为_最坏情况_解码设计：它们纠正任何重量 \leq t 的错误模式。LDPC 和 Turbo 为_平均情况_解码设计：它们在无记忆信道的典型噪声模式上表现良好。平均情况性能可以比最坏情况界好得多，尤其在长块长下。

粗略地说：Reed-Solomon 达到最小距离的 Singleton 界，但该界本身远离 Shannon。LDPC 和 Turbo 通过利用典型噪声的结构接近 Shannon 界。
