#### 历史地位

Hamming 码是第一个纠错码。它们用于现代计算机内存（单比特 ECC RAM 使用扩展 Hamming 码；双比特 ECC 使用 BCH 码）。Hamming 的洞见——冗余不仅可以用于检测还可以用于_定位和纠正_错误——是后续一切的概念基础。

* **生成矩阵** G，大小 k \times n：码字 \mathbf{c} = \mathbf{d} G。
* 码字构成 \mathbb{F}_q^n 的子空间（通常 q = 2）。它由以下参数指定：
* **速率**：R = k/n。
* 奇偶校验矩阵 H，大小 (n-k) \times n：对所有码字 H \mathbf{c}^T = \mathbf{0}。
* **最小距离**：d_{\min} = \min_{\mathbf{c} \neq \mathbf{c}'} d(\mathbf{c}, \mathbf{c}')。等价地，非零码字的最小重量（对于线性码）。
* **纠错能力**：t = \lfloor (d_{\min} - 1)/2 \rfloor。保证每块纠正 t 个错误。

对于任何 (n, k) 码，最小距离为 d，可纠正 d_{\min} - 1 个擦除。

d \leq n - k + 1.

以等号达到此界的码称为**最大距离可分（MDS）**码。Reed-Solomon 码是 MDS；大多数二元码不是。


#### 标准例子

* **重复码**：(n, 1, n)——每个比特重复 n 次。速率 1/n，纠正 (n-1)/2 个错误。低效但简单。
* **单奇偶校验**：(n, n-1, 2)——附加一个奇偶比特。检测 1 个错误，纠正 0 个。用于串行通信。
* **Hamming**：(2^m - 1, 2^m - 1 - m, 3)。速率随 m 趋近 1；单纠错。
* **扩展 Hamming**：(2^m, 2^m - 1 - m, 4)——Hamming + 总奇偶比特。单纠错 + 双检错。
* **Reed-Muller**：具有各种参数的码族。用于 Mariner 深空探测器（1969）。
* **BCH**：强大的二元循环码。多纠错。
* **Reed-Solomon**：强大的非二元码——见 §7.3。
* **Goppa**：推广 BCH；用于 McEliece 密码系统（后量子密码候选）。


### 7.3 Reed-Solomon 码

Reed-Solomon（RS）码于 1960 年引入，是历史上部署最广泛的编码族。它们用于 CD、DVD、蓝光、深空通信（旅行者号、卡西尼号）、QR 码、RAID-6 存储等众多领域。

#### 构造

选择有限域 \mathbb{F}_q（字节对齐应用通常取 q = 2^8 = 256）。\mathbb{F}_q 上长度为 n 的 RS 码（n \leq q - 1）将长度为 k 的消息编码如下：

* 将消息视为次数 < k 的多项式 p(x) 的系数。
* 在 n 个不同点 \alpha_1, \ldots, \alpha_n \in \mathbb{F}_q 上求值 p。
* 码字为 (p(\alpha_1), p(\alpha_2), \ldots, p(\alpha_n))。

恢复：给定 n 个求值中的任意 k 个（无错误），多项式插值唯一重建 p。
