#### 实例：高斯 MAC

对于两个功率约束为 P_1, P_2、加性高斯噪声方差为 N 的用户：

R_1 \leq \frac{1}{2} \log\left(1 + \frac{P_1}{N}\right), R_2 \leq \frac{1}{2} \log\left(1 + \frac{P_2}{N}\right), R_1 + R_2 \leq \frac{1}{2} \log\left(1 + \frac{P_1 + P_2}{N}\right).

和速率约束最具约束力：两个用户合在一起可以以合并功率的单用户速率传输。所得五边形区域内的任何操作点 (R_1, R_2) 都是可达的；角点可通过**逐次干扰消除**实现（先解码用户 1，减去其贡献，然后以更高有效信噪比解码用户 2）。

这是多个手机共享单个基站频谱的基础，并适当推广到衰落和多天线场景。

### 12.2 广播信道

**广播信道**有一个发送端向多个接收端发送不同消息。输入 X；输出 Y_1, \ldots, Y_K；转移概率 p(y_1, \ldots, y_K \mid x)。

容量区域关键取决于信道结构。对于**退化广播信道**（一个接收端的输出是另一个的退化版本），容量区域已知，由**叠加编码**给出。

对于非退化广播信道，容量区域通常未知——只有内界和外界。

#### 退化广播信道的叠加编码

考虑两个接收端，接收端 1 的信道比接收端 2 "更强"。策略：

1. 编码消息：一个"基础层"消息，速率 R_2（面向两个接收端）；一个"增强层"消息，速率 R_1 - R_2（仅面向接收端 1）。
2. 传输叠加：X = X_1 + X_2，其中 X_2 携带基础层（强编码），X_1 携带增强层（在基础层"之上"的弱编码）。
3. 接收端 2（弱）仅解码基础层（将增强层视为噪声）。
4. 接收端 1（强）先解码基础层（因为接收端 1 的信道优于接收端 2，所以容易），减去它，然后解码增强层。

这种**叠加编码**达到了退化广播信道的容量区域。它是分层视频编码等技术的基础（基础层为所有接收端提供低质量，增强层为信道更好的接收端提供更高质量）。
