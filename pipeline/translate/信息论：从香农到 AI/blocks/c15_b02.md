### 14.2 Donsker-Varadhan 表示

现代神经 MI 估计量依赖于 KL 散度的 **Donsker-Varadhan 表示**。对于任意一对分布 p, q：

D(p \| q) = \sup_T \mathbb{E}_p[T] - \log \mathbb{E}_q[\exp T],

其中上确界遍取所有函数 T: \mathcal{X} \to \mathbb{R}。最优的 T^*(x) = \log(p(x)/q(x)) + c。

这是一个变分表示：KL 是测试函数上泛函的最大值。通过限制为神经网络测试函数，我们得到参数化下界。

对于互信息，I(X; Y) = D(p(X, Y) \| p(X) p(Y))，所以

I(X; Y) = \sup_T \mathbb{E}_{p(X, Y)}[T(X, Y)] - \log \mathbb{E}_{p(X) p(Y)}[\exp T(X, Y)].

用样本估计并将 T = T_\theta 参数化为神经网络，得到 Belghazi 等人 2018 年的 **MINE** 估计量。

### 14.3 MINE：互信息神经估计

MINE 估计量：

1. 将 T_\theta: \mathcal{X} \times \mathcal{Y} \to \mathbb{R} 参数化为神经网络。
2. 采样联合对 (x_i, y_i) 和"打乱"对 (x_i, y_{\pi(i)})（其中 \pi 是随机排列）。
3. 对 \theta 最大化 \mathbb{E}_{\text{joint}}[T_\theta] - \log \mathbb{E}_{\text{shuffled}}[\exp T_\theta]。

结果是 I(X; Y) 的下界。

#### 实际问题

MINE 在理论上有吸引力但在实践中棘手：

* **高方差**：估计量的方差随 I 指数增长，因此高 MI 估计非常含噪。
* **有偏梯度**：随机梯度估计偏向零。
* **收敛速度**：每次 MI 估计需要大量训练 T_\theta。
* **过估计**：实践中，当网络过参数化时 MINE 常过估计 MI。

已提出变体（NWJ 界、JS 界、InfoNCE）来缓解这些问题，效果不一。

### 14.4 InfoNCE

Oord、Li 和 Vinyals 于 2018 年提出的 InfoNCE 界，最初用于对比预测编码，已成为自监督学习的主力。它在数学上是互信息的下界：

I(X; Y) \geq \mathbb{E}\left[\log \frac{\exp f_\theta(x, y)}{\frac{1}{K} \sum_{j=1}^K \exp f_\theta(x, y_j)}\right] + \log K,

其中 y_j 是 K 个"负"样本（从 p(Y) 抽取），y 是"正"样本（从 p(Y \mid X = x) 抽取）。

当 f_\theta(x, y) = \log p(y \mid x) + c 且负样本从 p(Y) 独立同分布抽取时，界是紧的。当 K 大时，界逼近 I(X; Y)，差距为 \log K。
