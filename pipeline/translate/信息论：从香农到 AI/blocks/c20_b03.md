#### 多元高斯

随机向量 X \in \mathbb{R}^n 为 \mathcal{N}(\mu, \Sigma) 如果其密度为

f(x) = \frac{1}{(2\pi)^{n/2} |\Sigma|^{1/2}} \exp\!\left(-\tfrac{1}{2} (x - \mu)^\top \Sigma^{-1} (x - \mu)\right).

\mathcal{N}(\mu, \Sigma) 的微分熵为 \tfrac{1}{2} \log\left((2\pi e)^n |\Sigma|\right)——用于第 8、11 和 13 章。

#### 矩阵不等式

* **Hadamard**：对 PSD A，|A| \leq \prod_i A_{ii}，当且仅当 A 为对角矩阵时取等。高斯最大熵结果是直接推论。
* **Lieb 联合凸性**：(A, B) \mapsto \mathrm{tr}(K^\dagger A^t K B^{1-t}) 在 (A, B) \succ 0 上对 t \in [0, 1] 联合凹。这是量子强次可加性（第 16 章）背后的深刻要素。

### A.4 比特、Nats 与对数底

信息论量是无量纲比率；对数底的选择是单位的选择：

* \log_2：比特。
* \ln（\log_e）：nats；1 nat = 1/\ln 2 \approx 1.443 比特。
* \log_{10}：哈特利（或"班"），偶见于旧文献。

转换是乘法的：\log_a x = \log_b x / \log_b a。本书在推导界时多用比特，在自然对数使微积分更干净时切换到 nats（信息几何、MINE、变分界）。

### A.5 渐近记号

我们使用标准 Bachmann-Landau 符号。对于函数 f, g : \mathbb{N} \to \mathbb{R}_{\geq 0}：

* f = O(g)：最终 f \leq c \cdot g，对某常数 c > 0。
* f = \Omega(g)：最终 f \geq c \cdot g。
* f = \Theta(g)：既是 O(g) 又是 \Omega(g)。
* f = o(g)：f / g \to 0。
* f \sim g：f / g \to 1（其中最强；常见于缩放定律陈述）。

在信息论中，"指数快速 \to 0"意味着对某 c > 0 有 f(n) \leq 2^{-n c}；**错误指数**是最大的这样的 c。第 6 和 7 章依赖此语言。
