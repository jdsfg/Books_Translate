### 第 2 章——联合、条件与互信息

**应用题 Q1（二元对称对）。** 令 X \sim \mathrm{Bern}(1/2) 且 Y = X \oplus Z，其中 Z \sim \mathrm{Bern}(p) 独立于 X。计算 H(X), H(Y), H(X,Y), H(X \mid Y), I(X;Y)。

X 和 Y 各为伯努利(1/2)，所以 H(X) = H(Y) = 1 比特。H(X,Y) = H(X) + H(Y \mid X) = 1 + H(Z) = 1 + H_b(p)。则 H(X \mid Y) = H(X,Y) - H(Y) = H_b(p)，I(X;Y) = H(X) - H(X \mid Y) = 1 - H_b(p)。在 p = 1/2 时信道无用：I = 0。在 p \in \{0, 1\} 时信道完美：I = 1。

**应用题 Q2（数据处理实例）。** 二元信源 X \sim \mathrm{Bern}(0.5) 通过两个级联 BSC，交叉概率 p_1 = 0.1, p_2 = 0.1，产生 Y 然后 Z。计算 I(X;Y) 和 I(X;Z) 并验证数据处理不等式。

I(X;Y) = 1 - H_b(0.1) \approx 1 - 0.469 = 0.531 比特。级联信道 X \to Z 是交叉概率 p = p_1(1-p_2) + p_2(1-p_1) = 2 \cdot 0.1 \cdot 0.9 = 0.18 的 BSC。所以 I(X;Z) = 1 - H_b(0.18) \approx 1 - 0.680 = 0.320 比特。确实 I(X;Z) \leq I(X;Y)，如数据处理不等式所要求；第二个 BSC 进一步降低了信息。

**应用题 Q3（分类对的互信息）。** 令 X \in \{0, 1\} 和 Y \in \{a, b, c\}，联合分布为

p(0, a) = 0.3, p(0, b) = 0.1, p(0, c) = 0.1, p(1, a) = 0.05, p(1, b) = 0.25, p(1, c) = 0.2.

直接从定义计算 I(X;Y)。

边际：p(X=0) = 0.5, p(X=1) = 0.5；p(Y=a) = 0.35, p(Y=b) = 0.35, p(Y=c) = 0.30。H(X) = 1，H(Y) = 1.581。H(X,Y) = -\sum p \log_2 p \approx 2.448。因此 I(X;Y) = H(X) + H(Y) - H(X,Y) = 1 + 1.581 - 2.448 \approx 0.133 比特——小但非零，反映弱关联。

**深入思考 Q1。** 用例子说明 I(X;Y \mid Z) 可以超过 I(X;Y)。

取 Z \sim \mathrm{Bern}(1/2)，X \sim \mathrm{Bern}(1/2) 独立于 Z，Y = X \oplus Z。边际上，Y \sim \mathrm{Bern}(1/2) 独立于 X，所以 I(X;Y) = 0。但给定 Z，Y 确定 X：I(X;Y \mid Z) = 1。条件化可以通过移除混淆因子*创造*互信息；反向也可能。"更多信息是好的"的朴素直觉在此误导。
