#### 概念检查

**Q1.** 计算一枚公平硬币和一枚公平六面骰子的熵。写出计算过程。

提示

对于 n 个结果上的均匀分布，H(X) = \log_2 n。

**答案：** 对于公平硬币，p(\text{heads}) = p(\text{tails}) = 1/2。则

H(X) = -\frac{1}{2} \log_2 \frac{1}{2} - \frac{1}{2} \log_2 \frac{1}{2} = -\log_2 \frac{1}{2} = 1 \text{ bit}.

对于公平六面骰子，x \in \{1, 2, 3, 4, 5, 6\} 时 p(x) = 1/6。则

H(X) = -\sum_{x=1}^{6} \frac{1}{6} \log_2 \frac{1}{6} = -\log_2 \frac{1}{6} = \log_2 6 \approx 2.585 \text{ bits}.

骰子比硬币更不确定，因为有更多等概率结果；对于均匀分布，熵随结果数量对数增长。

**Q2.** 一个气象站将明天的天气报告为四个类别之一：晴、阴、雨、雪。各类别的分布为 p(\text{sunny}) = 0.5，p(\text{cloudy}) = 0.25，p(\text{rainy}) = 0.125，p(\text{snowy}) = 0.125。计算预报的熵。

提示

直接应用熵公式 H(X) = -\sum p(x) \log_2 p(x)。

**答案：**

H(X) = -0.5 \log 0.5 - 0.25 \log 0.25 - 0.125 \log 0.125 - 0.125 \log 0.125.

逐项计算（比特）：

* -0.5 \log_2 0.5 = 0.5
* -0.25 \log_2 0.25 = 0.5
* -0.125 \log_2 0.125 = 0.375
* -0.125 \log_2 0.125 = 0.375

求和：H(X) = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 \text{ bits}。

注意，熵小于 \log_2 4 = 2 比特——四个结果上的最大熵。非均匀分布使信源更可预测。

**Q3.** 计算概率为 0.001 的结果的自信息（比特）以及概率为 0.5 的结果的自信息。比较两者。

提示

自信息为 I(x) = -\log_2 p(x)。

**答案：**

* I(p=0.001) = -\log_2 0.001 = \log_2 1000 \approx 9.97 \text{ bits}.
* I(p=0.5) = -\log_2 0.5 = 1 \text{ bit}.

罕见事件携带的信息约为五五开事件的十倍。这就是"罕见事件信息量大"的操作含义。如果气象学家按正常权重的预报突然报告了一个罕见事件，你应当密切关注：那条预报传达了约 10 比特信息，而典型预报只传达一两个比特。
