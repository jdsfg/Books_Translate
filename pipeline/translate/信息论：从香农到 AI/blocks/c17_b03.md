#### 量子熵不等式

经典熵不等式链（非负性、次可加性、条件降低熵、单调性）在量子世界中部分存活，但有两个著名的偏差。

**次可加性**，由 Lanford 和 Robinson 于 1968 年证明：

S(\rho_{AB}) \leq S(\rho_A) + S(\rho_B),

当且仅当 \rho_{AB} = \rho_A \otimes \rho_B 时取等。这与经典类比一致，由量子互信息 I(A:B) = S(A) + S(B) - S(AB) 的非负性推出。

**强次可加性**，由 Lieb 和 Ruskai 于 1973 年证明：

S(\rho_{ABC}) + S(\rho_B) \leq S(\rho_{AB}) + S(\rho_{BC}).

等价地，量子条件互信息 I(A : C \mid B) = S(AB) + S(BC) - S(B) - S(ABC) 非负。这是量子信息中最深刻的不等式；其证明高度非平凡（依赖 Lieb 的联合凸性定理），量子香农理论中大多数有用结果——包括 Holevo 界、信道容量可加性论证和量子相对熵的数据处理不等式——都源于它。

**Araki-Lieb 三角不等式**（1970）：对经典行为的真正量子偏离：

\bigl|S(\rho_A) - S(\rho_B)\bigr| \leq S(\rho_{AB}) \leq S(\rho_A) + S(\rho_B).

经典地，H(A, B) \geq \max(H(A), H(B))：联合熵不小于任一边际。量子地，该不等式**不成立**。对于纠缠纯态，S(\rho_{AB}) = 0 而 S(\rho_A) = S(\rho_B) > 0——整体的熵*小于*每个部分。Araki-Lieb 下界 S(\rho_{AB}) \geq |S(\rho_A) - S(\rho_B)| 是正确的量子替代，且恰好在纯态时取到零。这单一不等式编码了纠缠的奇异性：一个量子系统可以在全局处于完全确定的状态，而从任何局部视角看起来最大随机。

一个后果：量子**条件熵** S(A \mid B) := S(\rho_{AB}) - S(\rho_B) 可以**为负**。它作为纠缠的定量度量；其操作含义由 Horodecki、Oppenheim 和 Winter（2005）给出：当 Alice 和 Bob 分别持有 A 和 B 时，每份拷贝可恢复 -S(A \mid B) 比特的纯纠缠。
