#### 应用题

**Q1.** 一个二元信源有 p(0) = p(1) = 1/2。计算汉明失真下 D = 0.1 时的 R(D)。

提示

R(D) = H_b(p) - H_b(D)，对称二元信源。

**答案：** H_b(0.5) = 1 比特。H_b(0.1) \approx 0.469 比特。

R(0.1) = 1 - 0.469 = 0.531 比特每信源符号。

因此我们可以在保持 10% 误码率的条件下以 0.531 比特每符号表示信源。对比无损速率（D = 0）：1 比特每符号。10% 的失真节省了约一半的速率。

**Q2.** 一个高斯信源方差为 1。我们希望 MSE \leq 0.01。最低速率是多少？

提示

R = \frac{1}{2} \log(\sigma^2 / D)。

**答案：** R = \frac{1}{2} \log(1 / 0.01) = \frac{1}{2} \log 100 = \log 10 \approx 3.32 比特每样本。

要达到每样本 MSE 0.01（即标准差 0.1），需要约 3.3 比特——恰好足以指定值落在分布的哪个"十等分区间"。

**Q3.** 三个高斯信源的方差为 \sigma_1^2 = 4, \sigma_2^2 = 1, \sigma_3^2 = 0.25。总失真预算为 D = 1。求反向注水分配。

提示

尝试水位 \lambda，找出哪些分量在水面以上。

**答案：** 尝试 \lambda = 0.25：分量 1 和 2 在水面以上，分量 3 在水面以下。D_1 = 0.25, D_2 = 0.25, D_3 = 0.25。总和：0.75 < 1。需要更多失真。

尝试 \lambda = 0.5：D_1 = 0.5, D_2 = 0.5, D_3 = 0.25。总和：1.25 > 1。太多了。

尝试 \lambda = 0.375：D_1 = 0.375, D_2 = 0.375, D_3 = 0.25。总和：1.0。✓

因此 \lambda = 0.375：分量 1、2 在水面以上。比特分配：

* 分量 1：R_1 = \frac{1}{2} \log(4 / 0.375) \approx \frac{1}{2} \log 10.67 \approx 1.71 比特。
* 分量 2：R_2 = \frac{1}{2} \log(1 / 0.375) \approx \frac{1}{2} \log 2.67 \approx 0.71 比特。
* 分量 3：R_3 = 0 比特（水面以下）。

总计：约 2.42 比特每信源向量。最低方差的分量被"丢弃"。

**Q4.** 一个图像神经压缩器以损失 \mathcal{L} = -\log p(z) + \lambda \cdot \text{MSE}(x, \hat{x}) 训练。当 \lambda = 0.001 时，达到速率 0.5 比特/像素、MSE 50（8 比特像素尺度）。当 \lambda = 0.01 时，达到速率 0.2 比特/像素、MSE 200。哪个 \lambda 正确？

**答案：** 权衡在于速率（比特/像素）和失真（MSE）之间。不同的 \lambda 描绘出率失真曲线上的不同点。两个点都是有效的；选择取决于应用。

较高 \lambda（更大失真惩罚）：MSE 低但速率更高。较低 \lambda（更小失真惩罚）：MSE 高但速率更低。

对于存储受限的应用，用低 \lambda。对于视觉保真关键的应用，用高 \lambda。
