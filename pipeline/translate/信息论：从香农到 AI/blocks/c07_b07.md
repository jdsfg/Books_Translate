#### 逆定理

对于在容量为 C 的信道上使用的速率为 R 的码，消息 W 在 \{1, \ldots, 2^{nR}\} 上均匀分布，所以 H(W) = nR。编码器产生 X^n（W 的确定性函数），信道产生 Y^n，解码器产生 \hat{W}。

由数据处理不等式和 W \to X^n \to Y^n 是马尔可夫链的事实：

I(W; \hat{W}) \leq I(X^n; Y^n) \leq \sum_{i=1}^n I(X_i; Y_i) \leq nC.

（中间不等式使用链式法则 + 无记忆信道；最后使用 I(X_i; Y_i) \leq C。）

现在，I(W; \hat{W}) = H(W) - H(W \mid \hat{W}) = nR - H(W \mid \hat{W})。

由 Fano 不等式：

H(W \mid \hat{W}) \leq H_b(P_e) + P_e \log(2^{nR} - 1) \leq 1 + n R P_e.

综合起来：nR \leq nC + H(W \mid \hat{W}) \leq nC + 1 + nRP_e。

对于 P_e \to 0 和 n \to \infty，得到 R \leq C。等价地，如果 R > C，P_e 不能趋于零。

事实上，对于 R > C，可以证明更强的结论：P_e \to 1（不仅仅是远离零）当 n \to \infty。这是信道编码定理的**强逆定理**，由 Wolfowitz 建立。

直觉是几何的。低于容量时，码字可以被打包到输出空间中，噪声云互不重叠；高于容量时，云必须重叠，一个典型的接收 y^n 与指数级多的候选码字一致。具体地，Arimoto 证明了对于 R > C，

P_e \geq 1 - \exp\!\left(-n E_{sp}(R)\right)

对于某个正的**球填充指数** E_{sp}(R) > 0 当 R > C。指数随 R 远离 C 而增大，所以_正确_解码的概率随 n 指数衰减。因此高于容量的速率不仅仅是不可靠的——它们是灾难性的：以压倒性概率，接收端选错码字。

这将容量图景锐化为一个**相变边界**。对于任何 \epsilon > 0，速率 C - \epsilon 下可靠通信是可能的，而速率 C + \epsilon 下本质上不可能；过渡不是渐进的。我们在此不推导 E_{sp}(R)；Cover 和 Thomas 第 7.9 节以及 Gallager（1968）第 5 章给出了完整论证。□

我们现在证明了两个半部分：低于 C 的速率可达且错误趋于零；高于 C 的速率无法达到趋于零的错误。这就是 Shannon 编码定理。□
