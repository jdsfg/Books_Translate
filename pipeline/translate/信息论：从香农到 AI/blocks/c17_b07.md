### 本章小结

量子信息将香农框架推广到量子比特和密度矩阵。关键概念：

* **量子比特**：2 维复单位向量。多量子比特存在于指数大的希尔伯特空间中。
* **密度矩阵**：半正定厄米矩阵，迹为 1。编码混合和纯量子态。
* **冯·诺依曼熵**：S(\rho) = -\text{tr}(\rho \log \rho)。香农熵的量子类比。
* **Holevo 界**：量子编码的经典互信息受 Holevo 信息约束。
* **量子信道**：完全正保迹映射。具有多种容量（经典、量子、私钥、纠缠辅助）。
* **不可加性**：量子容量一般不可加——Hastings 于 2009 年证明了这一点——两次并行使用可传输超过单次使用两倍的速率。

两个引人注目的量子通信现象：超密编码（1 个量子比特 + 纠缠 = 2 个经典比特）和量子隐形传态（2 个经典比特 + 纠缠 = 1 个传输的量子态）。

对量子机器学习的诚实结论：有理论兴趣，实际影响有限。量子 ML 是否产生实际优势取决于比预测更慢的硬件进展。

下一章综述信息论的开放前沿，包括网络编码、衰落信道、深度学习理论和量子容量问题。

### 16.X 习题


#### 概念检查

**Q1.** 什么是量子比特？

**答案：** 量子比特是 2 维复希尔伯特空间中的单位向量。一般写为 |\psi\rangle = \alpha |0\rangle + \beta |1\rangle，其中 |\alpha|^2 + |\beta|^2 = 1。在标准基下测量时，以概率 |\alpha|^2 得到结果 0，以概率 |\beta|^2 得到结果 1。

**Q2.** 定义冯·诺依曼熵。

**答案：** 对于密度矩阵 \rho，冯·诺依曼熵为 S(\rho) = -\text{tr}(\rho \log \rho)。等价地，如果 \rho 的特征值为 \lambda_i，则 S = -\sum_i \lambda_i \log \lambda_i——特征值分布的香农熵。

纯态时为零（单一非零特征值），最大混合态时最大（\log d）。

**Q3.** 陈述 Holevo 界。

**答案：** 对于量子态系综 \{p_i, \rho_i\}，任何测量能提取的经典互信息受 Holevo 信息约束：

I(X; Y) \leq \chi(\{p_i, \rho_i\}) = S(\sum_i p_i \rho_i) - \sum_i p_i S(\rho_i).

它是香农互信息界的量子类比。

**Q4.** 量子隐形传态使用什么，产生什么？

**答案：** 输入：

* Alice 处的未知量子态 |\psi\rangle。
* Alice 和 Bob 之间的一个共享贝尔对。
* 从 Alice 到 Bob 的经典通信信道。

输出：

* 态 |\psi\rangle 出现在 Bob 处。
* Alice 处的原始态被破坏（不可克隆）。
* 传输了两个经典比特。
* 贝尔对被消耗。

没有物理发送量子比特，但态被忠实地传输。
