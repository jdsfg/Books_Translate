### 第 6 章——信道编码定理

**应用题 Q1.** 信道容量 C = 0.5。使用速率 R = 0.4 的码以消失错误发送 1000 比特所需的最小块长 n 是多少？

块长由消息大小决定：n = 1000 / 0.4 = 2500。速率低于容量（0.4 < 0.5），所以足够长的随机码达到消失错误。R = 0.4 处的错误指数控制 P_e 缩减的速度；关于 n 必须*多大*才能将 P_e 驱动到目标以下的更精细问题取决于信道和所选码集。

**应用题 Q2（消失错误的容量差距）。** BSC 交叉概率 p = 0.1，容量 0.531 比特/使用。实用码以速率 R = 0.4 运行，实测 P_e = 10^{-6}。如果保持 R = 0.4 将 n 增加 2 倍，P_e 如何变化？

由随机编码界，P_e \lesssim 2^{-n E_r(R)}，其中 R < C 时 E_r(R) > 0。在随机编码区域内 n 翻倍将界平方：如果 n 时 P_e \approx 10^{-6}，则 2n 时 P_e \approx 10^{-12}。现实码（LDPC、极化）一旦进入瀑布区域近似遵循此指数 in-n 缩放，这就是为什么翻倍块长是实现近无错通信的有力工具。

**应用题 Q3（为更好错误指数牺牲速率）。** 对同一 BSC（p = 0.1, C = 0.531），设计者愿意牺牲速率以获得更大错误指数。定性比较 R = 0.4 和 R = 0.2 的随机编码错误指数。

随机编码指数 E_r(R) 在 R 上递减，在 R = C 处为零，对足够小的 R 以 I(X;Y) - R 为界。在 R = 0.4 处，指数 \approx 0.531 - 0.4 = 0.131（非正式地；真值涉及 Gallager 函数但差距是正确量级）。在 R = 0.2 处，指数跳到 \approx 0.531 - 0.2 = 0.331——翻倍多。所以对目标 P_e = 10^{-12}，低速率码约需 n \approx 12 \log 10 / 0.331 \approx 84 次信道使用，而 R = 0.4 时 n \approx 211。低速率买到更快衰减；实践中速率-距离权衡取决于目标 P_e。

**深入思考 Q1.** 为什么强逆定理意味着锐利相变？

容量以下，错误以正指数指数衰减。容量以上，错误以正指数趋近 1（Wolfowitz-Arimoto 定理）。两个错误指数在 R = C 处相遇，指数消失。对任何 \epsilon > 0，R = C - \epsilon 和 R = C + \epsilon 位于*操作*行为不连续性的两侧，即使解析的 C 是信道参数的光滑函数。容量是相边界，如同统计力学中 T_c 是相边界。
