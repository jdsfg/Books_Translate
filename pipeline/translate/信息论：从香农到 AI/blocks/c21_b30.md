数学事实，非比喻。精确陈述：交叉熵为每 token \mathcal{L} 比特的语言模型，用作算术编码的信源分布时，达到恰好 \mathcal{L} 比特每 token 的压缩速率（在 O(1/n) 尾部以内）。这是信源编码定理（第 4 章）应用于 LLM 作为信源分布；算术编码构造性地达到此速率。因此最小化训练数据上的交叉熵最小化所得模型即编码器的（训练数据）压缩速率。两种表述之间无滑移；它们是同一优化的不同词汇（NLP vs 信息论）。

**深入思考 Q2.** 现代 LLM 在大部分可索引网页上训练。当它们接近"可用文本"的熵底时，这对未来能力意味着什么？

三个含义。(i) **每 token 交叉熵改进将饱和**，因为存在硬下界（数据的香农熵），一旦在 ~0.1 比特以内，进一步增益指数昂贵。这是 Chinchilla 缩放中已可见的"递减回报"现象。(ii) **剩余熵是语言的*不可约*熵**给定条件上下文——它代表关于下一个内容的真正不确定性，无论多少额外训练都无法解决。(iii) **能力增益将越来越多来自非交叉熵目标**：RLHF、宪法 AI、工具使用、多步推理。这些都不能很好地用压缩建模。所以信息论对后训练方法的指导不如预训练，下一个十年的前沿工作需要不同的理论框架。
