#### 应用题

**Q1.** 一个分类器在正确类上输出概率 0.7，在竞争类上 0.2，在第三类上 0.1。真实分布是正确类上的 one-hot。交叉熵损失是多少？

提示

对于 one-hot 真实分布，交叉熵退化为真实标签的负对数概率。

**答案：** 交叉熵：H(p, q) = -\sum_y p(y) \log q(y) = -1 \cdot \log 0.7 - 0 \cdot \log 0.2 - 0 \cdot \log 0.1 = -\log_2 0.7 \approx 0.515 比特。

这也是真实标签在模型分布下的自信息。最小化此损失推动 q(正确) 趋向 1，此时损失消失。

**Q2.** 两个语言模型在同一英文测试集上评估。模型 A 达到每字符 1.2 比特的交叉熵；模型 B 达到每字符 1.0 比特。(a) 哪个更好？(b) 相对压缩效率？(c) 如果英文的熵约为每字符 0.9 比特，每个模型与真实分布的 KL 散度是多少？

**答案：** (a) 模型 B 更好：更低的交叉熵意味着更接近真实分布。

(b) 压缩：模型 A 使用 1.2 比特/字符；模型 B 使用 1.0 比特/字符。模型 B 每字符效率高 16.7%。

(c) KL = 交叉熵 - 熵。模型 A：D \approx 1.2 - 0.9 = 0.3 比特/字符。模型 B：D \approx 1.0 - 0.9 = 0.1 比特/字符。

两个模型都在真实熵的一个比特分数以内。从模型 A 到模型 B 的差距与从模型 B 到熵底的剩余差距相同——有意义但绝对值不大。

**Q3.** 两个强化学习策略 \pi_{\text{old}} 和 \pi_{\text{new}} 在一个状态上比较。\pi_{\text{old}}(a) = (0.4, 0.3, 0.3)；\pi_{\text{new}}(a) = (0.7, 0.2, 0.1)。计算它们的 KL 散度（以 nat 为单位）。新策略是"小"还是"大"的变化？

提示

D(\pi_{\text{new}} \| \pi_{\text{old}}) = \sum_a \pi_{\text{new}}(a) \log [\pi_{\text{new}}(a) / \pi_{\text{old}}(a)]。

**答案：** D(\pi_{\text{new}} \| \pi_{\text{old}}) = 0.7 \ln(0.7/0.4) + 0.2 \ln(0.2/0.3) + 0.1 \ln(0.1/0.3) = 0.7 \cdot 0.5596 + 0.2 \cdot (-0.4055) + 0.1 \cdot (-1.0986) \approx 0.3917 - 0.0811 - 0.1099 \approx 0.201 nat。

对于典型 KL 界 \delta \approx 0.01 的 PPO/TRPO，这是一个_大_更新——约为信赖域阈值的二十倍。PPO 会缩减更新或应用裁剪以约束在信赖域内。

**Q4.** 知识蒸馏训练学生模型匹配教师的软分布。如果教师输出 (0.5, 0.3, 0.2)，学生输出 (0.4, 0.4, 0.2)，蒸馏损失（教师对学生的 KL）是多少？
