#### 应用题

**Q1.** 一个训练好的 Transformer 在基准上达到困惑度 50。其交叉熵以比特和 nats 计是多少？

**答案：** 比特：\log_2 50 \approx 5.64 每词元比特数。Nats：\ln 50 \approx 3.91 nats 每词元。

**Q2.** 一个模型使用算术编码将 100 KB 文本语料压缩到 25 KB。其平均交叉熵以每字节比特计是多少？

**答案：** 25 KB = 200,000 比特。100 KB = 100,000 字节。平均：200,000 / 100,000 = 2.0 每字节比特数。

**Q3.** 简述如何在训练好的 Transformer 中计算逐层 MI。

**答案：**

1. 将测试序列通过训练好的模型传递，提取每层的隐藏状态。
2. 对每层 \ell，收集 (h_\ell^{(i)}, x^{(i)}, y^{(i)}) 的样本（表示、输入、目标）。
3. 对每层，训练 MINE 网络估计 I(h_\ell; X) 和 I(h_\ell; Y)。
4. 在信息平面中绘制轨迹：I(h_\ell; Y) vs. I(h_\ell; X)，\ell = 1, 2, \ldots, L。

警告：MINE 估计在高维中有噪声；值应定性对待。

**Q4.** 解释为什么完美训练的语言模型交叉熵等于信源熵。

**答案：** 交叉熵 = 熵 + KL 散度：H(p, q) = H(p) + D(p \| q)。

如果 q = p（模型完美捕获信源分布），则 D = 0，交叉熵等于熵。

所以任何模型交叉熵的下界是 H(p)，信源熵。没有模型能做得更好。现代前沿模型在英文上接近此界（约 0.7 每字符比特数，对比香农的 0.6-1.3 每字符比特数估计）。
