到目前为止，我们将信息视为经典的：一个比特是 0 或 1；传输要么成功要么失败。微观世界是量子的，规则不同。一个量子比特可以同时处于 0 和 1 的叠加态。两个量子比特可以纠缠，共享一种没有经典类比的关联。量子信道可以传输经典比特、量子态或两者同时传输，其容量常常超过经典类比。

### 16.1 量子比特与量子态

**量子比特**是 2 维复向量空间中的单位向量。两个基态记为 |0\rangle 和 |1\rangle。一般的纯量子比特态为

|\psi\rangle = \alpha |0\rangle + \beta |1\rangle,

其中 \alpha, \beta \in \mathbb{C} 且 |\alpha|^2 + |\beta|^2 = 1。

量子比特*不是* 0 和 1 上的概率分布。振幅 \alpha, \beta 是复数；它们在量子操作下相互干涉。只有当我们*测量*量子比特时才得到经典结果：以概率 |\alpha|^2 观测到 0，以概率 |\beta|^2 观测到 1。测量后，量子比特"塌缩"到观测到的基态。

#### 多量子比特

n 个量子比特的系统存在于 2^n 维复空间中。一般的纯态为

|\psi\rangle = \sum_{x \in \{0, 1\}^n} \alpha_x |x\rangle,

其中 \sum |\alpha_x|^2 = 1。

2^n 个振幅赋予系统比 n 个经典比特更多的自由度。这是量子计算潜在能力和量子信息独特特性的来源。
