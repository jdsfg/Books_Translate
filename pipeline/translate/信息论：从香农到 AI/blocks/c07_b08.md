### 6.6 为什么这令人震惊

要理解编码定理，你必须理解它推翻的传统观念。

Shannon 之前，通信工程师将错误视为连续的权衡：更多冗余 → 更少错误但更慢传输。要将错误率减半，你可能需要翻倍冗余（例如，每个比特重复两次）。再减半，再翻倍冗余。要将错误驱动到零，你需要无限冗余，即零速率。

Shannon 定理说：不，你可以_同时_拥有固定正速率和任意低错误，只要你保持在容量以下。存在一个尖锐的阈值，而非连续的权衡。低于阈值，错误指数衰减；高于阈值，错误不趋于零。

这之所以可能：**足够长块中的冗余可以被利用**，而单符号冗余做不到。通过在 n 个符号的块上编码，编码器可以选择在高维输出空间中分散的码字，使其在信道噪声下仍可被解码器区分。块越长，维数越高，码字可以越分散。

这与 AEP（第 3 章）密切相关：对于大的 n，信道将输出 y^n 集中在输入 x^n 周围的典型"噪声云"中，大小约为 2^{n H(Y \mid X)}。总输出空间大小约为 2^{n H(Y)}。可区分码字数（每个有自己不重叠的噪声云）至多为 2^{n H(Y)} / 2^{n H(Y \mid X)} = 2^{n I(X; Y)}。从典型输入分布中随机选择码字给出大约这么多可区分信号。容量 C = \max I(X; Y) 恰好是我们能以此速率打包码字的速率。

这幅**填充与覆盖**图景是信息论中最美丽的图景之一。它使编码定理在事后看来_几乎_显而易见——尽管如我们所见，严格的证明需要仔细的工作。
