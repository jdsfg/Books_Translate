#### 概念检查

**Q1.** 陈述 Kraft 不等式并解释其操作含义。

提示

该不等式约束任何前缀码的码字长度；逆定理说满足它的任何长度都存在对应码。

**答案：** Kraft 不等式说，对于任何码字长度为 \ell_1, \ldots, \ell_n 的前缀二进制码，\sum_i 2^{-\ell_i} \leq 1。反之，给定满足该不等式的任何正整数长度，存在具有这些长度的前缀码。

操作含义：前缀码对应二叉树的叶子，Kraft 不等式恰好是说码字所占据的互不相交子树不能超过整棵树。该不等式是前缀码码字能有多短的通用约束。

**Q2.** 为分布 p(a) = 0.5, p(b) = 0.25, p(c) = 0.125, p(d) = 0.125 构建 Huffman 码。其期望长度是多少？与熵比较。

提示

合并两个最小概率，重复。

**答案：** 步骤 1：合并 c（0.125）和 d（0.125）：\{cd\}，权重 0.25。步骤 2：合并 b（0.25）和 \{cd\}（0.25）：\{b, cd\}，权重 0.5。步骤 3：合并 a（0.5）和 \{b, cd\}（0.5）：根。

码字：a = 0, b = 10, c = 110, d = 111。长度：1, 2, 3, 3。

期望长度：0.5 \cdot 1 + 0.25 \cdot 2 + 0.125 \cdot 3 + 0.125 \cdot 3 = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 比特。

熵：H(X) = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 比特。

Huffman 码恰好达到熵。这是因为分布是二进的，即每个 p(x) 是 2 的负幂；因此整数长度问题不会出现。

**Q3.** 计算 p(a) = 0.7, p(b) = 0.2, p(c) = 0.1 的信源的熵和 Shannon 码长度。Shannon 码的期望长度是多少？与 Huffman 比较。

提示

Shannon：\ell(x) = \lceil -\log p(x) \rceil。Huffman：构建树。

**答案：** 熵：H(X) = -0.7 \log 0.7 - 0.2 \log 0.2 - 0.1 \log 0.1 \approx 0.360 + 0.464 + 0.332 \approx 1.157 比特。

Shannon 码长度：\lceil -\log 0.7 \rceil = 1，\lceil -\log 0.2 \rceil = 3，\lceil -\log 0.1 \rceil = 4。期望：0.7 + 0.6 + 0.4 = 1.7 比特。

Huffman 树：合并 b 和 c：\{bc\}，权重 0.3。合并 a（0.7）和 \{bc\}（0.3）：根。码字：a = 0, b = 10, c = 11。长度：1, 2, 2。期望：0.7 + 0.4 + 0.2 = 1.3 比特。

Huffman 优于 Shannon（1.3 vs 1.7），且与熵相差 0.143 比特。这是典型的：Shannon 码偏保守；Huffman 在逐符号码中是最优的。
