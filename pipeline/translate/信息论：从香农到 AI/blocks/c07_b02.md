### 6.1 设定

让我们精确说明我们要主张什么。速率为 R、长度为 n 的码是：

1. 一个**码本** \mathcal{C} = \{x^n(1), x^n(2), \ldots, x^n(2^{nR})\}，包含 2^{nR} 个码字，每个是输入字母表 \mathcal{X} 上长度为 n 的序列。
2. 一个**编码器**，将每条消息 m \in \{1, 2, \ldots, 2^{nR}\} 映射到其码字 x^n(m)。
3. 一个**解码器**，将每个接收序列 y^n \in \mathcal{Y}^n 映射到猜测消息 \hat{m} \in \{1, 2, \ldots, 2^{nR}\}。

**错误事件**是 \{\hat{m} \neq m\}。**平均错误概率**（假设每条 m 等概率发送）为

\bar{P}_e = \frac{1}{2^{nR}} \sum_{m=1}^{2^{nR}} \Pr(\hat{m} \neq m \mid \text{发送 } m).

**最大错误概率**为 P_e^{\max} = \max_m \Pr(\hat{m} \neq m \mid \text{发送 } m)。

速率 R 是**可达的**，如果存在一列码（每个块长度 n = 1, 2, 3, \ldots 对应一个），速率至少为 R（最多使用 2^{nR} 个码字），使得 \bar{P}_e \to 0 当 n \to \infty。可达速率的上确界称为**操作容量** C_{\text{op}}。

Shannon 定理断言 C_{\text{op}} 等于第 5 章定义的**信息容量** C = \max_{p(x)} I(X; Y)。

#### 定理（Shannon 信道编码定理）

对于任何信息容量为 C 的离散无记忆信道：

1. **可达性**：对于任何速率 R < C，存在一列速率为 R 的码，\bar{P}_e \to 0 当 n \to \infty。
2. **逆定理**：对于任何速率为 R > C 的码列，\bar{P}_e 有正下界，且 P_e^{\max} \to 1 当 n \to \infty。

用通俗的话说：低于 C 的速率可达且错误趋于零；高于 C 的速率无法避免固定正错误。容量是尖锐的边界。

我们在 §6.2-6.4 中证明可达性，在 §6.5 中证明逆定理。
