#### 第二个实例：高斯混合上的均值场变分推断

上面的共轭高斯例子令人放心但不具代表性；在实际中，我们恰恰是在共轭性失效时才使用变分推断。下面是第二个例子，展示了迭代过程的实际运作。

**设置。** 从 K = 3 个一维高斯混合中生成 N = 50 个样本，真实均值为 \mu_1 = -3, \mu_2 = 0, \mu_3 = 3，每个方差为 1，混合权重相等 \pi_k = 1/3。每个观测的隐变量是其簇分配 z_n \in \{1, 2, 3\}。我们不知道真实均值和分配；我们想要两者的后验。

**均值场族。** 近似为

q(\mu_{1:K}, z_{1:N}) = \prod_k q_k(\mu_k) \cdot \prod_n q_n(z_n),

其中每个 q_k 是高斯分布，每个 q_n 是 \{1, 2, 3\} 上的类别分布。将 \mu_k 和 z_n 之间的因子化是"均值场"假设：它强制均值和分配的后验相互独立，这是一个粗糙的近似，但使得更新具有闭式解。

**坐标上升更新**（通过固定所有其他 q 后令 \partial \text{ELBO} / \partial q_n = 0 导出，然后对 q_k 对称地导出）：

q_n(z_n = k) \propto \exp\!\left(-\tfrac{1}{2}\left(x_n^2 - 2 x_n \mathbb{E}_q[\mu_k] + \mathbb{E}_q[\mu_k^2]\right)\right),

q_k(\mu_k) = \mathcal{N}\!\left(m_k, s_k^2\right) \quad \text{其中} \quad m_k = \frac{\sum_n q_n(z_n = k) \cdot x_n}{1/\sigma_0^2 + \sum_n q_n(z_n=k)}, \quad s_k^2 = \frac{1}{1/\sigma_0^2 + \sum_n q_n(z_n=k)},

先验为 \mu_k \sim \mathcal{N}(0, \sigma_0^2 = 100)（模糊先验）。将 m_k 在 [-5, 5] 中随机初始化，q_n 在三个簇上均匀初始化。
