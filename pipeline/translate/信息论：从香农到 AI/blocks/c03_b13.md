**Q1.** 两位通信专家各自独立地从同一语料库估计英文字母的熵。专家 A 使用一元统计量，得到 H(Xt)=4.07H(X_t) = 4.07H(Xt​)=4.07 比特每字母。专家 B 使用二元统计量，计算连续字母的联合熵，得到 H(Xt,Xt−1)=7.18H(X_t, X_{t-1}) = 7.18H(Xt​,Xt−1​)=7.18 比特每对。用链式法则推导专家 B 对_给定_前一个字母时每字母熵的估计，并解释为什么它低于专家 A 的估计。

提示

由链式法则，H(Xt∣Xt−1)=H(Xt,Xt−1)−H(Xt−1)H(X_t \mid X_{t-1}) = H(X_t, X_{t-1}) - H(X_{t-1})H(Xt​∣Xt−1​)=H(Xt​,Xt−1​)−H(Xt−1​)。将信源视为平稳的，因此 H(Xt−1)=H(Xt)=4.07H(X_{t-1}) = H(X_t) = 4.07H(Xt−1​)=H(Xt​)=4.07 比特。

**答案：** 由链式法则和平稳性：

H(Xt∣Xt−1)=H(Xt,Xt−1)−H(Xt−1)=7.18−4.07=3.11 bits per letter.H(X_t \mid X_{t-1}) = H(X_t, X_{t-1}) - H(X_{t-1}) = 7.18 - 4.07 = 3.11 \text{ bits per letter}.H(Xt​∣Xt−1​)=H(Xt​,Xt−1​)−H(Xt−1​)=7.18−4.07=3.11 bits per letter.

专家 B 的每字母条件熵低于专家 A 的边缘熵，因为英语中的字母不是独立的：在 qqq 之后，下一个字母几乎总是 uuu；在 ttt 之后，通常是 hhh。每字母对的互信息为

I(Xt;Xt−1)=H(Xt)−H(Xt∣Xt−1)=4.07−3.11=0.96 bits per pair.I(X_t; X_{t-1}) = H(X_t) - H(X_t \mid X_{t-1}) = 4.07 - 3.11 = 0.96 \text{ bits per pair}.I(Xt​;Xt−1​)=H(Xt​)−H(Xt​∣Xt−1​)=4.07−3.11=0.96 bits per pair.

每个字母与其前驱共享约 1 比特的信息。当我们转向三元组、四元组和更长的上下文时，每字母条件熵继续下降，一直到非常长的上下文下大约 1.01.01.0 比特每字母。我们将在第 15 章讨论语言模型困惑度时回到这一点。

这个问题也以更严格的方式说明了第 1 章的英文文本计算：并非一元熵是错误的；而是一元熵是每字母熵的_上界_，以上下文为条件将其向下推向英语的真实熵。
