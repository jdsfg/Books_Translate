#### 示例：5 符号信源的 Huffman 编码

概率：p(a) = 0.4, p(b) = 0.2, p(c) = 0.2, p(d) = 0.1, p(e) = 0.1。

步骤 1：最小权重是 d, e（各 0.1）。合并：\{de\}，权重 0.2。
步骤 2：最小权重是 \{de\}, b, c（各 0.2）。合并 b 和 c：\{bc\}，权重 0.4。
步骤 3：最小权重是 \{de\}（0.2）和 a（0.4）。合并：\{a, de\}，权重 0.6。
步骤 4：合并 \{a, de\}（0.6）和 \{bc\}（0.4）：根，权重 1。

树（一种有效分配）：

* 根：左 = \{bc\}（标 0），右 = \{a, de\}（标 1）。
* \{bc\}：左 = b（00），右 = c（01）。
* \{a, de\}：左 = a（10），右 = \{de\}（11）。
* \{de\}：左 = d（110），右 = e（111）。

码字：a = 10, b = 00, c = 01, d = 110, e = 111。长度：2, 2, 2, 3, 3。

期望长度：0.4 \cdot 2 + 0.2 \cdot 2 + 0.2 \cdot 2 + 0.1 \cdot 3 + 0.1 \cdot 3 = 0.8 + 0.4 + 0.4 + 0.3 + 0.3 = 2.2 比特。

熵：

H(X) = 0.4 \log \frac{1}{0.4} + 0.2 \log \frac{1}{0.2} + 0.2 \log \frac{1}{0.2} + 0.1 \log \frac{1}{0.1} + 0.1 \log \frac{1}{0.1} \approx 2.122 \text{ bits}.

Huffman 给出 2.20 比特，仅比熵高 0.078 比特。优于 Shannon 码，后者会用 \lceil -\log p(x) \rceil 长度 2, 3, 3, 4, 4，期望长度 2.6 比特。

#### Huffman 的最优性

**定理**：对于给定分布，Huffman 码在所有前缀码中最小化期望码字长度。

证明使用两个引理：

1. 在任何最优码中，两个概率最小的符号具有相同长度且仅在最后一位不同。
2. Huffman 的树合并规则保持最优性：在（n-1）符号分布（将两个最小概率合并后）上的最优码可以扩展为原始 n 符号分布上的最优码。

对 n 的形式归纳给出完整定理。

这种最优性是逐符号的，不是渐近的。Huffman 在逐符号前缀码中达到最佳速率；对于非常偏斜的分布（一个符号概率 0.99），由于整数取整的损失，它可能远差于熵。要任意接近熵，我们或者使用分组编码，或者转向算术编码。
