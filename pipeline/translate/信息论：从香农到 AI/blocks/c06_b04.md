1. **非负性**：C \geq 0（因为 I(X; Y) \geq 0 恒成立）。
2. **上界**：C \leq \min(\log |\mathcal{X}|, \log |\mathcal{Y}|)。信道每次使用传输的比特数不能超过其字母表允许的范围。
3. **凹性**：I(X; Y) 对于固定的 p(y \mid x) 是 p(x) 的凹函数。

凹性使得容量计算变得可行：任何局部最大值都是全局最大值，标准凸优化技术（拉格朗日乘子、KKT 条件、Blahut-Arimoto 算法）可以找到它。

#### 计算容量：BSC

对于 BSC，由对称性（信道在 0 \leftrightarrow 1 下不变），容量达到输入分布是均匀的：p(0) = p(1) = 1/2。则

C_{\text{BSC}} = 1 - H_b(\epsilon).

合理性检查：

* \epsilon = 0：C = 1 比特每次使用（无噪）。
* \epsilon = 1/2：C = 0（随机输出）。
* \epsilon = 1：C = 1（确定性翻转）。


#### 计算容量：BEC

对于 BEC，同样由对称性，均匀输入是最优的：

C_{\text{BEC}} = 1 - \epsilon.

合理性检查：每个未被擦除的比特传输一比特信息。未被擦除比特的比例为 1 - \epsilon。所以长期传输速率恰好为 1 - \epsilon。

对于相同的 \epsilon，BEC 比 BSC "更容易"：在 0 \leq \epsilon \leq 1/2 时，1 - \epsilon \geq 1 - H_b(\epsilon)，除端点外严格不等。这符合直觉：接收端知道擦除何时发生；而 BSC 不知道翻转何时发生。

#### 计算容量：AWGN

对于带限 AWGN 信道，输入功率约束 \mathbb{E}[X^2] \leq P，噪声方差 \sigma^2，容量达到输入是高斯的：X \sim \mathcal{N}(0, P)。输出则为 Y \sim \mathcal{N}(0, P + \sigma^2)，且

C_{\text{AWGN}} = h(Y) - h(Y \mid X) = \frac{1}{2} \log[2\pi e (P + \sigma^2)] - \frac{1}{2} \log[2\pi e \sigma^2] = \frac{1}{2} \log \left(1 + \frac{P}{\sigma^2}\right).

量 P / \sigma^2 是**信噪比（SNR）**。Shannon 容量公式说容量随 SNR 对数增长——SNR 翻倍约增加半比特每次使用。

对于带宽为 B Hz 的连续带限信道，以比特每秒为单位的容量为

C_{\text{bps}} = B \log \left(1 + \frac{P}{N_0 B}\right),

其中 N_0 是噪声功率谱密度。这就是著名的 **Shannon-Hartley 定理**，EE 系墙上展示最多的方程。
