#### 定义：互信息

X 和 Y 之间的**互信息**为

I(X; Y) = H(Y) - H(Y \mid X) = H(X) - H(X \mid Y).

等价地，通过链式法则展开，

I(X; Y) = H(X) + H(Y) - H(X, Y).

以及最常用的形式，

I(X; Y) = \sum_{x, y} p(x, y) \log \frac{p(x, y)}{p(x) p(y)} = D(p(x, y) \| p(x) p(y)).

最后一种形式把互信息表示为联合分布与边缘乘积之间的 KL 散度。它是证明中最方便的形式。

用通俗的话说：I(X; Y) 是知道 X 后对 Y 的不确定性的减少量（或由对称性，反之亦然）。它是 X 和 Y 之间依赖程度的度量。


#### 性质

1. **非负性**：I(X; Y) \geq 0，当且仅当 X 和 Y 独立时取等号。
2. **对称性**：I(X; Y) = I(Y; X)。X 携带的关于 Y 的信息与 Y 携带的关于 X 的信息相同。
3. **有界性**：I(X; Y) \leq \min(H(X), H(Y))。你从 X 中提取的关于 Y 的信息不可能超过 Y 本身所拥有的，你从 X 中提取的信息也不可能超过 X 本身所拥有的。
4. **自互信息**：I(X; X) = H(X)。一个变量关于自身恰好携带其自身熵那么多的信息。

性质 1、3、4 的证明直接由公式得出；对称性已内置于对称形式 H(X) + H(Y) - H(X, Y)。


#### 一幅值得记住的图景

信息论者常画一幅类似维恩图的图景（口头描述，因为我们没有插图）：想象两个重叠的圆，分别代表 H(X) 和 H(Y)。它们的并是 H(X, Y)。它们的交是 I(X; Y)。H(X) 圆在重叠之外的月牙是 H(X \mid Y)；H(Y) 圆在重叠之外的月牙是 H(Y \mid X)。本节每个恒等式都可以从图上读出：

* H(X, Y) = H(X) + H(Y) - I(X; Y)（容斥）。
* H(X \mid Y) = H(X) - I(X; Y)（减去重叠）。
* I(X; Y) = H(X) + H(Y) - H(X, Y)（由并与部分得到重叠）。

维恩图_不是_完全严格的工具；对三个变量它可能误导，因为 I(X; Y; Z)（三方版本）可以为负。但对两个变量，它是忠实且有用的摘要。
