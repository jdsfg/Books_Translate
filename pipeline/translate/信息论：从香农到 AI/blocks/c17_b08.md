#### 应用题

**Q1.** 一个量子比特处于态 |\psi\rangle = (|0\rangle + |1\rangle) / \sqrt{2}。其密度矩阵是什么？测量得到 0 的概率是多少？

**答案：** \rho = |\psi\rangle\langle\psi| = \frac{1}{2}(|0\rangle\langle 0| + |0\rangle\langle 1| + |1\rangle\langle 0| + |1\rangle\langle 1|) = \frac{1}{2}\begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}（在基 \{|0\rangle, |1\rangle\} 下）。

测量得到 0 的概率：\langle 0 | \rho | 0\rangle = 1/2。对 1 对称。

这是最大不确定性的单量子比特态；测量产生 1 比特经典信息。

**Q2.** 计算最大混合两量子比特态的冯·诺依曼熵。

**答案：** 最大混合两量子比特态：\rho = I/4，其中 I 是 4×4 单位矩阵。特征值全为 1/4。

S = -4 \cdot \frac{1}{4} \log \frac{1}{4} = \log 4 = 2 比特。

对于 n 量子比特最大混合态，S = \log 2^n = n 比特。

**Q3.** 贝尔态 |\Phi^+\rangle = (|00\rangle + |11\rangle) / \sqrt{2} 由 Alice 和 Bob 共同持有。Alice 的约化密度矩阵是什么？纠缠熵是多少？

**答案：** |\Phi^+\rangle\langle\Phi^+| = \frac{1}{2}(|00\rangle\langle 00| + |00\rangle\langle 11| + |11\rangle\langle 00| + |11\rangle\langle 11|)。

对 Bob 的量子比特（子系统 2）取迹：\rho_A = \frac{1}{2}(|0\rangle\langle 0| + |1\rangle\langle 1|) = I/2。

Alice 的约化态是单量子比特上的最大混合态。S(\rho_A) = 1 比特。

这是贝尔态的纠缠熵：Alice 和 Bob 之间共享 1 比特纠缠。

**Q4.** 为什么超密编码允许 Alice 用 1 个量子比特传输发送 2 个经典比特？

**答案：** 预共享的贝尔态充当"额外资源"。Alice 的局部操作（四种酉操作之一）将共享态变换为四个正交贝尔态之一。通过将她的量子比特传输给 Bob，Alice 让他可以访问贝尔态的两个量子比特，它们一起携带 2 比特经典信息（贝尔态索引）。

没有预共享纠缠，一个量子比特只能携带 1 个经典比特（Holevo 界）。纠缠实质上将信道容量"放大"了 2 倍。

超密编码是纠缠作为信息论资源的最清晰演示之一。它不违反 Holevo 界（后者假设无共享纠缠）；它利用了不同的资源。
