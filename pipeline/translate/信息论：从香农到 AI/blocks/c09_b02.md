#### 定理（Gibbs 不等式）

对于同一字母表上的任意两个概率分布 p 和 q，

D(p \| q) \geq 0,

当且仅当 p = q（除可能的零测集外处处）时取等。

**证明**：使用不等式 \ln x \leq x - 1（当且仅当 x = 1 时取等）。则 \log x = \ln x / \ln 2 \leq (x - 1) / \ln 2。等价地，-\log x \geq (1 - x) / \ln 2。所以

D(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = -\sum_x p(x) \log \frac{q(x)}{p(x)} \geq -\sum_x p(x) \cdot \frac{q(x)/p(x) - 1}{\ln 2} = \frac{1}{\ln 2}\left(1 - \sum_x q(x)\right) = 0,

利用 \sum_x q(x) = 1。\ln x \leq x - 1 中的等号要求对所有 p(x) > 0 的 x 有 x = 1，即 q(x) = p(x) 在 p 的支撑集上。□

这是信息论的核心不等式。前述章节中的许多不等式都可归结为 Gibbs 不等式：

* **有限集上的最大熵**：H(p) \leq \log |\mathcal{X}| 是 D(p \| u) \geq 0，其中 u 是均匀分布。
* **条件化降低熵**：H(Y \mid X) \leq H(Y) 是 D(p(X,Y) \| p(X)p(Y)) \geq 0，即互信息的非负性。
* **信源编码界**：L(C) \geq H(X) 涉及隐式码分布 q 的 D(p \| q)。

所以 Gibbs 不等式是主力。记住这个证明。


### 8.3 互信息即 KL 散度

我们在第 2 章已经遇到过这个恒等式：

I(X; Y) = D(p(X, Y) \| p(X) p(Y)).

用文字说：互信息是联合分布与边际乘积之间的 KL 散度。它度量联合分布与"独立"（对应 p(X, Y) = p(X) p(Y)）有多远。

该恒等式也立即证明了互信息的非负性：I(X; Y) = D(\cdot \| \cdot) \geq 0 由 Gibbs 不等式。

这一视角是信息论中最强大的统一之一。许多量——包括熵、条件熵、互信息和信道容量——都可归结为精心选择的分布之间的 KL 散度。通用工具包归结为：选择正确的分布对，应用 Gibbs 不等式。

### 8.4 交叉熵


#### 定义：交叉熵

分布 q 相对于 p 的**交叉熵**为

H(p, q) = -\sum_x p(x) \log q(x).

用通俗的话说：交叉熵是用为 q 优化的码编码来自 p 的样本所需的平均比特数。
