#### 深入思考

**Q1.** Shannon 的证明展示随机码达到容量。但实践中使用结构化码（Reed-Solomon、LDPC），而非随机码。为什么？

**讨论：** 随机码"平均而言好"，但没有解码结构：要解码一个接收向量，你必须枚举所有 2^{nR} 个码字并找到最可能的。这在 n 上是指数的——对任何实际块长完全不可行。

结构化码（Reed-Solomon、LDPC、Polar）的解码器利用其结构在 n 的多项式时间（通常是拟线性）内解码。这些结构化码与随机码相比损失少量容量，但在计算可处理性上获得巨大收益。

一般教训：Shannon 定理证明的是_信息论上_可达的。它不约束_计算上_可达的。后者是工程师必须解决的独立问题。

这种双重视角——信息论 vs 计算可处理性——贯穿理论计算机科学。现代复杂性理论（P vs. NP、平均情况复杂性）经常依赖类似的区分。

**Q2.** 随机编码论证是非构造性的。信道编码定理有构造性证明吗？

**讨论：** 有。Arıkan 2009 年的 Polar 码为对称信道给出了构造性的容量达到码族。构造是显式的：使用递归矩阵变换将信道"极化"为纯好和纯坏子信道，通过仅在好子信道上传输来达到容量。

Polar 码具有所有实用码中最强的理论保证：它们可证明地对任何二元输入对称信道以低解码复杂度（O(n \log n)）达到容量。它们现在在 5G 标准的控制信道中。

对于非对称信道，最好的构造性结果使用"空间耦合"LDPC 码，可证明以低复杂度接近容量。这是一个活跃的研究领域。

**Q3.** 容量公式 C = \max I(X; Y) 假设无记忆信道。真实信道（包括现代无线）有记忆。理论如何扩展？

**讨论：** 对于有记忆的信道，每符号互信息 I(X; Y) 被多字母对象取代。容量为

C = \lim_{n \to \infty} \frac{1}{n} \max_{p(X^n)} I(X^n; Y^n).

对于平稳信道，由次可加性该极限存在，但很少能以闭式计算。

对于特定信道类：

* **有码间干扰的高斯信道**：频域中的注水解给出闭式容量。用于 DSL 和 OFDM 系统。
* **衰落信道**：容量取决于衰落是否为发射端、接收端、两者或都不知道。出现多种容量定义（遍历、中断、延迟受限）。
* **Markov 信道**：对于低阶 Markov 模型，容量可通过动态规划计算。

对于大多数有记忆的信道，容量是近似而非精确计算的。Shannon 定理推广到多字母容量的通用框架普遍适用但很少可处理。
