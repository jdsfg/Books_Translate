#### 与 KL 的恒等式

H(p, q) = H(p) + D(p \| q).

**证明**：直接计算：D(p \| q) = \sum p(x) \log p(x) - \sum p(x) \log q(x) = -H(p) + H(p, q)。重排即得。□

这个恒等式是现代机器学习的主力。当我们在 q 上最小化 H(p, q)（p 由数据固定）时，我们在最小化 D(p \| q)，因为 H(p) 是常数。所以**交叉熵最小化等价于 KL 最小化等价于最大似然**。

压缩-预测对偶在此与散度机制相遇。一个在来自 p 的数据上交叉熵为 H(p, q) 的模型，当用作算术编码器（第 4 章）时恰以 H(p, q) 比特每符号压缩。与最优速率 H(p) 的差距恰为 D(p \| q)。所以最小化交叉熵就是最小化压缩开销：训练语言模型就是训练压缩器，损失函数度量压缩冗余。

#### 计算示例：为什么交叉熵是正确的损失

考虑一个分类器，给定输入 x 输出标签 y 上的概率分布 q_\theta(y \mid x)，参数为 \theta。对于训练样本 (x_i, y_i)（其中 y_i 是真实标签），负对数似然为

-\log q_\theta(y_i \mid x_i).

在训练集上取平均，

\mathcal{L}(\theta) = -\frac{1}{N} \sum_i \log q_\theta(y_i \mid x_i).

如果我们将训练集视为来自真实分布 p^*(x, y) 的样本，则在期望下：

\mathbb{E}_{(x, y) \sim p^*}[-\log q_\theta(y \mid x)] = H(p^*(\cdot \mid x), q_\theta(\cdot \mid x))

（对 x 取平均）。

这是真实条件分布与模型预测分布之间的交叉熵。由 KL 恒等式，最小化它等价于最小化真实与模型之间的 KL 散度。

等价地，由最大似然：\arg\min_\theta \mathcal{L}(\theta) = \arg\max_\theta \prod_i q_\theta(y_i \mid x_i)——\theta 的最大似然估计。

所以交叉熵损失_不是_任意选择。它是唯一满足以下条件的损失：

1. 等价于最大似然估计。
2. 当模型精确匹配数据分布时等于零。
3. 梯度是模型的得分函数（用于现代随机梯度下降）。

对于语言模型，同样的逻辑在每 token 层面成立。训练损失是真实下一 token 分布（集中在实际下一 token 上）与模型预测分布之间的交叉熵。由链式法则，整个序列的交叉熵是每 token 交叉熵之和。
