#### 定义：对称信道

一个离散无记忆信道是**对称的**，如果 P 的每一行都是其他行的排列，且 P 的每一列都是其他列的排列。

BSC 是对称的。BEC 在广义意义上是对称的（行是排列；列满足较弱性质）。Z 信道_不是_对称的：它的两行 (1, 0) 和 (\epsilon, 1 - \epsilon) 不是彼此的排列（前者是确定性的；后者不是）。

#### 定理：对称信道的容量

对于对称信道，容量达到输入是均匀的，容量为

C = \log |\mathcal{Y}| - H(\text{P 的任一行}).

**证明**：均匀输入下，

H(Y \mid X) = \sum_x p(x) H(P(\cdot \mid x)) = H(\text{P 的行})

（任一行，因为它们都有相同熵）。输出 p(y) = \frac{1}{|\mathcal{X}|} \sum_x P_{xy}。对于对称信道，由列排列性质，这在 \mathcal{Y} 上是均匀的。所以 H(Y) = \log |\mathcal{Y}|，且

I(X; Y) = \log |\mathcal{Y}| - H(\text{P 的行}).

均匀输入达到最大值需要证明其他输入更差。由 I(X; Y) 对 p(x) 的凹性和信道的对称性，任何非均匀输入可以与其排列取平均得到均匀输入，而平均值有更高的 I。□

这在实践中极其有用：工程中大多数感兴趣的信道至少近似对称，容量达到输入是均匀的。

#### 非对称信道：拉格朗日乘子

对于非对称信道（如 Z 信道），容量必须通过直接优化计算。KKT 条件给出：在最优点，对每个 p(x) > 0 的 x，

\sum_y p(y \mid x) \log \frac{p(y \mid x)}{p(y)} = C,

其中 p(y) = \sum_x p(x) p(y \mid x) 是最优点的输出分布。对 p(x) = 0 的 x，同一表达式 \leq C。

寻找最优点的两种策略：

1. **直接优化**：参数化 p(x) 并数值求解 KKT 条件。
2. **Blahut-Arimoto 算法**：一种迭代过程，收敛到容量，交替更新输入分布和"反向信道" q(x \mid y)。

对于参数为 \epsilon 的 Z 信道，容量（经过一些代数运算）为

C_Z = \log_2 \left(1 + (1 - \epsilon) \cdot 2^{-H_b(\epsilon)/(1-\epsilon)}\right),

不如对称情形的公式优雅。这在光通信和神经科学中脉冲序列编码的讨论中出现。
