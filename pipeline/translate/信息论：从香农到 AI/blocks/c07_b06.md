### 6.4 从平均错误改进到最大错误

上面的证明给出了一个_平均_错误小的码。但我们要的是_最大_错误小的码。有一个小差距需要弥补。

**引理（清除）**：如果一个码的 \bar{P}_e \leq \delta，则通过删除最差的一半码字（那些个体 \Pr(\hat{m} \neq m \mid m) 最大的），剩余码的最大错误 \leq 2\delta。

**证明**：最多一半的码字其个体错误超过 2\bar{P}_e（否则平均将超过 \bar{P}_e）。删除这些得到一个大小减半、最大错误至多 2\bar{P}_e 的码。

码减半使每块速率减少 1/n（删除 2^{nR-1} 个码字）。对于大的 n，这可忽略。所以如果平均错误趋于零，我们可以清除以得到最大错误趋于零的码，速率几乎不变。□

### 6.5 逆定理：Fano 不等式

逆定理声称高于容量时没有任何方案能避免固定正错误率。证明使用 **Fano 不等式**。

设 X 和 \hat{X} 是字母表 \mathcal{X} 上的随机变量（其中 \hat{X} 是 X 的估计）。设 p_e = \Pr(\hat{X} \neq X)。则

H(X \mid \hat{X}) \leq H_b(p_e) + p_e \log(|\mathcal{X}| - 1).

用通俗的话说：给定估计 \hat{X} 时 X 的熵受错误概率的二元熵加上与错误概率和 log 字母表大小成正比的项约束。如果 p_e 小，H(X \mid \hat{X}) 小。

**证明**：定义指示变量 E = \mathbb{1}[\hat{X} \neq X]。由链式法则，

H(X, E \mid \hat{X}) = H(E \mid \hat{X}) + H(X \mid E, \hat{X}) = H(X \mid \hat{X}) + H(E \mid X, \hat{X}).

最后一项为零（E 由 X 和 \hat{X} 确定）。且 H(E \mid \hat{X}) \leq H(E) = H_b(p_e)。所以

H(X \mid \hat{X}) \leq H_b(p_e) + H(X \mid E, \hat{X}).

条件熵 H(X \mid E, \hat{X}) 分解：当 E = 0（无错误）时，X = \hat{X}，熵为 0。当 E = 1（错误）时，X 取 |\mathcal{X}| - 1 个不同于 \hat{X} 的值之一，熵至多为 \log(|\mathcal{X}| - 1)。取平均：

H(X \mid E, \hat{X}) \leq p_e \log(|\mathcal{X}| - 1).

代入得 Fano 不等式。□
