#### 概念检查

**Q1.** 陈述 Shannon 信道编码定理。

**答案：** 对任意容量为 C = \max_{p(x)} I(X; Y) 的离散无记忆信道：

（可达性）对任意 R < C，存在一列码（每个块长 n 一个）速率为 R，且错误概率趋于零。

（逆定理）对任意 R > C，任何速率为 R 的码，其错误概率与零之间有正的下界。

简言之：低于容量的速率可达；高于容量的速率不可达。

**Q2.** 联合典型性在可达性证明中起什么作用？

**答案：** 联合典型性是解码器将输出匹配到输入的规则。解码器声明与接收输出联合典型的唯一码字。驱动证明的两个事实是：

1. 正确码字与信道输出联合典型的概率趋于 1（联合 AEP）。
2. 一个“独立”码字与信道输出联合典型的概率为 2^{-n I(X;Y)}，指数级小。

所以有 2^{nR} 个码字时，联合界给出错误概率 \leq 1 \cdot 2^{nR} \cdot 2^{-n I(X;Y)} = 2^{n(R - I(X;Y))}，当 R < I(X;Y) 时趋于零。

**Q3.** 陈述 Fano 不等式并解释其在逆定理中的作用。

**答案：** Fano 不等式：对于字母表 \mathcal{X} 上 X 的估计 \hat{X}，错误概率为 p_e，有 H(X \mid \hat{X}) \leq H_b(p_e) + p_e \log(|\mathcal{X}| - 1)。

在逆定理中的作用：在速率为 R 的码中，消息 W 在 2^{nR} 个值上均匀分布，所以 H(W) = nR。数据处理不等式给出 I(W; \hat{W}) \leq nC。所以 H(W \mid \hat{W}) \geq nR - nC。Fano 不等式给出 H(W \mid \hat{W}) \leq 1 + nR P_e。综合：nR - nC \leq 1 + nR P_e，即 R \leq C/(1-P_e) + 1/(n(1-P_e))。当 P_e \to 0 且 n \to \infty 时，R \leq C。

**Q4.** 可达性证明中的“清除”是什么意思，为什么需要它？

**答案：** 清除是删除个体错误概率最差的一半码字的技巧。修剪后，没有存留码字的错误超过原码平均错误的两倍。

可达性证明最初给出一个_平均_错误小的码。但我们要_最大_错误小。由清除引理，删除最差的一半给出最大错误至多原平均两倍的码。减半码本的速率代价是每块 1/n，对于大的 n 可忽略。
