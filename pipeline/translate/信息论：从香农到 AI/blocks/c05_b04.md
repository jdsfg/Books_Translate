### 4.4 分组编码与渐近界

如果我们把 n 个信源符号视为一个"超符号" X^n 并对 X^n 应用 Shannon 变长定理，得到

H(X^n) \leq L_n < H(X^n) + 1,

其中 L_n 是分组的期望码字长度。对于 i.i.d. 信源，H(X^n) = n H(X)，所以

\frac{H(X^n)}{n} \leq \frac{L_n}{n} < \frac{H(X^n) + 1}{n} = H(X) + \frac{1}{n}.

当 n \to \infty 时，每符号速率趋近 H(X)。这就是**渐近信源编码定理**：通过编码足够长的块，我们可以压缩到任意 \epsilon > 0 比特每符号以内。

第 3 章的组合图景是相同的：约有 2^{n H(X)} 条典型序列，因此需要约 n H(X) 比特来索引它们。

Shannon 变长定理说我们可以通过一种特定构造达到 L < H(X) + 1。但它并没有说这种构造是最优的。逐符号最优前缀码是 **Huffman 码**。

给定概率分布 p(x_1), \ldots, p(x_n)：

1. 将每个 x_i 视为权重为 p(x_i) 的叶子。
2. 找到权重最小的两个叶子；将它们合并为一个权重等于其和的内部节点。
3. 重复直到只剩一个节点（根）。
4. 将每个内部节点的两个子节点任意分配 0 和 1。x_i 的码字是根到叶子路径上的比特串。
