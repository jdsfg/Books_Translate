### 4.4 分组编码与渐近界

如果我们把 n 个信源符号视为一个“超符号” X^n 并对 X^n 应用 Shannon 变长定理，得到

H(X^n) \leq L_n < H(X^n) + 1，

其中 L_n 是该分组的期望码字长度。对于独立同分布（i.i.d.）信源，H(X^n) = n H(X)，因此每符号期望长度为

\frac{H(X^n)}{n} \leq \frac{L_n}{n} < \frac{H(X^n) + 1}{n} = H(X) + \frac{1}{n}。

当 n \to \infty 时，每符号速率趋近 H(X)。这就是**渐近信源编码定理**：通过编码足够长的分组，可以使每个符号的平均码率距 H(X) 不超过任意给定的 \epsilon 比特（即 H(X) \leq R < H(X) + \epsilon）。

第 3 章的组合图景是相同的：约有 2^{n H(X)} 条典型序列，索引它们大约需要 n H(X) 比特。分组编码使这一图景成为可构造的。


### 4.5 霍夫曼编码

Shannon 变长定理说，我们可以通过一种特定构造达到 L < H(X) + 1。但它并没有说这种构造是最优的。逐符号最优的无前缀码是 **霍夫曼码**，由 David Huffman 在 1951 年作为课堂作业给出。

#### 霍夫曼算法

给定概率分布 p(x_1), \ldots, p(x_n)：

1. 将每个 x_i 视为权重为 p(x_i) 的叶子。
2. 找到权重最小的两个叶子；将它们合并为一个权重等于二者之和的内部节点。
3. 重复直到只剩一个节点（根）。
4. 将每个内部节点的两个子节点任意分配 0 和 1。x_i 的码字是根到叶子路径上的比特串。
