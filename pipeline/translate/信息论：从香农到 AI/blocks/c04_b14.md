典型集占总数的 375/1024 \approx 36.6%。对于 n = 10，AEP 尚未强烈生效，因为 n 较小，典型集仍占相当比例。随着 n 增长，该比例将趋于零（典型集大小以 2^{n H(X)} = 2^{n \cdot 0.881} 增长，而总数以 2^n 增长）。

**Q3.** 用 AEP 证明：对于独立同分布信源，当 H(X) < \log_2 |\mathcal{X}| 时，Hartley 函数（使用每符号 \log_2 |\mathcal{X}|）高估了每符号描述长度。

提示

比较在整个字母表上使用定长码的每符号描述长度，与只使用典型集的描述长度。

**答案：** 定长码使用 \lceil \log_2 |\mathcal{X}| \rceil 比特每符号，与分布无关。n 符号消息的总长度为 n \lceil \log_2 |\mathcal{X}| \rceil 比特。

利用 AEP，我们仅编码典型序列（约 2^{n H(X)} 条），使用 \lceil n H(X) + n \epsilon \rceil 比特，外加一个比特的典型性标志。对于非典型序列（概率小于 \epsilon），使用 n \lceil \log_2 |\mathcal{X}| \rceil 比特作为回退。平均每符号长度为

L \approx (1 - \epsilon)(H(X) + \epsilon) + \epsilon \log_2 |\mathcal{X}| \to H(X) \quad \text{as } \epsilon \to 0。

当 H(X) < \log_2 |\mathcal{X}| 时，这严格优于 Hartley 界。改进量 \log_2 |\mathcal{X}| - H(X) 就是信源的“冗余”。

例如，英文字母的 H(X) \approx 4 比特，而 Hartley 界为 \log_2 27 \approx 4.75 比特，冗余约 0.75 比特/字母，即 15%。当我们以上下文为条件时（熵率约为 1 比特/字母），冗余增至约 80%。

**Q4.** 从大小为 8 的字母表上的均匀分布中抽取 n = 1000 个独立同分布样本。熵是多少？典型集大小是多少？为什么在这种情况下每条序列都是典型的？

提示

对于均匀分布，H(X) = \log_2 |\mathcal{X}|，且每条序列的概率相同。

**答案：** H(X) = \log_2 8 = 3 比特每符号。H(X^n) = 3000 比特。

典型集大小为 2^{3000}，恰好等于 8^{1000}，即序列总数。

每条序列都是典型的，因为每条序列的概率恰好为 8^{-n} = 2^{-3000}，所以其每符号经验对数概率恰好为 3 比特，等于 H(X)。“典型集”就是整个空间。

这是极限情形：当信源均匀时，AEP 没有提供有用信息（每条序列的经验对数概率已经等于熵）。AEP 的全部意义在于非均匀信源中 H(X) 与 \log |\mathcal{X}| 之间的差距，这导致典型集成为一个小切片。
