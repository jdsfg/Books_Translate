典型集占总数的比例为

$\frac{375}{1024}\approx 36.6\%.$

当 $n=10$ 时，AEP 尚未强烈显现，因为 $n$ 很小，典型集仍占相当大的比例。随着 $n$ 增长，该比例将趋于 $0$：典型集的大小按

$2^{nH(X)}=2^{n\cdot 0.881}$

增长，而总数按 $2^n$ 增长。

**Q3.** 使用 AEP 证明：对独立同分布信源，只要

$H(X)<\log|\mathcal{X}|,$

则 Hartley 函数——每符号使用 $\log_2|\mathcal{X}|$——会高估每符号描述长度。

提示

比较在整个字母表上使用定长码的每符号描述长度，与只为典型集编码时的每符号描述长度。

**答案：** 定长码不依赖分布，每个符号使用

$\left\lceil\log_2\lvert\mathcal{X}\rvert\right\rceil$

比特。一个长度为 $n$ 的消息总共使用

$n\left\lceil\log_2\lvert\mathcal{X}\rvert\right\rceil$

比特。

利用 AEP，我们只对典型序列编码。典型序列约有 $2^{nH(X)}$ 条，可用

$\left\lceil nH(X)+n\epsilon\right\rceil$

比特编码，另加 $1$ 个比特作为典型性标志。对非典型序列（其概率小于 $\epsilon$），则回退为使用

$n\left\lceil\log_2\lvert\mathcal{X}\rvert\right\rceil$

比特。每符号期望长度为

$L\approx(1-\epsilon)(H(X)+\epsilon) +\epsilon\log_2|\mathcal{X}| \to H(X) \quad \text{当 } \epsilon\to 0.$

只要 $H(X)<\log|\mathcal{X}|$，这就严格优于 Hartley 界。改进量

$\log_2|\mathcal{X}|-H(X)$

就是信源的冗余。

例如，英文字母的 $H(X)\approx 4$ 比特，而 Hartley 界为

$\log_2 27\approx 4.75\ \text{比特},$

冗余约为每字母 $0.75$ 比特，即约 $15\%$。若考虑上下文，熵率约为每字母 $1$ 比特，冗余则增至约 $80\%$。

**Q4.** 从大小为 $8$ 的字母表上的均匀分布中抽取 $n=1000$ 个独立同分布样本。熵是多少？典型集大小是多少？为什么在这种情况下每条序列都是典型的？

提示

对均匀分布，

$H(X)=\log_2|\mathcal{X}|,$

且每条序列具有相同的概率。

**答案：**

$H(X)=\log_2 8=3\ \text{比特每符号},$

并且

$H(X^n)=3000\ \text{比特}.$

典型集大小为

$2^{3000}=8^{1000},$

恰好就是序列总数。

每条序列都是典型的，因为每条序列的概率都恰为

$8^{-n}=2^{-3000},$

所以其每符号经验对数概率恰为 $3$ 比特，等于 $H(X)$。“典型集”就是整个空间。

这是极限情形：当信源均匀时，AEP 没有提供有用信息，因为每条序列的经验对数概率本就等于熵。AEP 的全部意义在于非均匀信源中 $H(X)$ 与 $\log|\mathcal{X}|$ 之间的差距；正是这一差距使典型集成为一个很小的切片。
