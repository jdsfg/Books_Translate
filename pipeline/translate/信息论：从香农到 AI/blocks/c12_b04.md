### 11.3 R(D) 的性质

率失真函数有几个优雅的性质：

1. **单调递减**：R(D) 随 D 增大而减小（允许更大失真 → 所需速率更低）。
2. **凸性**：R(D) 是 D 的凸函数。凸性是时分论证的推论。
3. **R(0) = H(X)**：对于汉明失真下的离散信源，零失真意味着无损压缩，代价为 H(X) 比特。
4. **R(D_{\max}) = 0**：在足够高的失真下，可以使用常数再生（完全不传递信息）仍满足约束。

R(D) 的一般形状是一条光滑凸曲线，从 D = 0 处的 H(X) 下降到某个 D_{\max} 处的 0。

### 11.4 实例：汉明失真下的二元信源

信源：X \in \{0, 1\}，p(X = 1) = p \leq 1/2。失真：汉明。

信息率失真函数：

R(D) = \begin{cases} H_b(p) - H_b(D) & \text{若 } 0 \leq D \leq p, \\ 0 & \text{若 } D \geq p. \end{cases}

合理性检查：

* D = 0：R = H_b(p)。无损速率等于熵。✓
* D = p：R = 0。在失真 p 下，我们可以使用常数再生 \hat{X} = 0，这给出失真 p（被错误预测的 1 的比例），速率为零。✓
* 对于 D \in (0, p)：函数平滑插值。最优条件分布是"\hat{X} 是 X 的带交叉概率 D 的噪声版本"——在某种意义上，这是信道编码的对偶。

### 11.5 高斯信源：闭式解

对于高斯信源 X \sim \mathcal{N}(0, \sigma^2) 和平方误差失真，率失真函数为

R(D) = \begin{cases} \frac{1}{2} \log \frac{\sigma^2}{D} & \text{若 } 0 \leq D \leq \sigma^2, \\ 0 & \text{若 } D \geq \sigma^2. \end{cases}

这是有损压缩中被引用最多的公式。它表明：每增加一比特速率，失真（均方误差）降低 4 倍。等价地：速率翻倍（每样本多一比特）使失真降低 4 倍。
