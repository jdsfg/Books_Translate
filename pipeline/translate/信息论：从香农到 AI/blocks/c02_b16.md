#### 应用题

**Q1.** 一枚有偏硬币 p(\text{heads}) = 0.7。你掷三次并观察到序列 HHT。该特定序列的自信息是多少（假设独立）？

提示

对于独立事件，自信息相加：I(\text{HHT}) = I(H) + I(H) + I(T)。

**答案：** 一次正面的自信息：I(H) = -\log_2 0.7 \approx 0.515 比特。一次反面的自信息：I(T) = -\log_2 0.3 \approx 1.737 比特。

对于序列 HHT（独立掷动）：

I(\text{HHT}) = 2 \cdot I(H) + I(T) \approx 2 \cdot 0.515 + 1.737 \approx 2.767 \text{ bits}.

等价地，p(\text{HHT}) = 0.7^2 \cdot 0.3 = 0.147，因此 I(\text{HHT}) = -\log_2 0.147 \approx 2.767 比特，结果一致。这联系到一个我们将在全书使用的原理：自信息在独立分量上可加，正如我们在 §1.2 中选择对数时所要求的。

**Q2.** 一个信源从 \{a, b, c, d\} 中发射符号，概率为 p(a) = 1/2, p(b) = 1/4, p(c) = p(d) = 1/8。其熵是多少？与 \log_2 4 = 2 比特（同一字母表上均匀信源的熵）相比如何？

提示

计算每一项 -p(x) \log_2 p(x) 并求和。

**答案：**

H(X) = \frac{1}{2}(1) + \frac{1}{4}(2) + \frac{1}{8}(3) + \frac{1}{8}(3) = \frac{1}{2} + \frac{1}{2} + \frac{3}{8} + \frac{3}{8} = 1.75 \text{ bits}.

这小于均匀信源的熵 \log_2 4 = 2 比特。非均匀性使每个符号的平均不确定性降低了 0.25 比特。

该信源有一个特别简洁的结构：每个 -\log_2 p(x) 都是整数，即 1, 2, 3, 3。我们将在第 4 章看到，这种"二进"分布可以用 Huffman 编码_精确_达到熵界。这不是巧合；这是熵 H(X) = 1.75 可无损失实现的特殊情形。一般分布会多花一点。

**Q3.** 考虑来自熵为 H(X) 的分布的 n 个 i.i.d. 样本序列。整个序列的熵是多少？

提示

利用独立下熵的可加性：独立时 H(X_1, X_2) = H(X_1) + H(X_2)。

**答案：** 由独立性，联合分布为 p(x_1, \ldots, x_n) = \prod_{i=1}^n p(x_i)，因此

H(X_1, \ldots, X_n) = -\sum_{x_1, \ldots, x_n} \prod_i p(x_i) \log \prod_i p(x_i) = -\sum_{x_1, \ldots, x_n} \prod_i p(x_i) \sum_i \log p(x_i).
