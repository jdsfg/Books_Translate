#### 概念检查

**Q1.** 说出竞争激烈院校申请高峰期招生官阅读一篇文书的估计时间，并用自己的话解释为什么这个估计是写作的核心约束。

提示

这个数字是几分钟。约束来自读者在有限时间内会做什么、以及无法做什么。

**答案：** 平均每篇六到七分钟。这是核心约束，因为个人说服性写作的几乎其他所有规则都由此推出。六到七分钟足够读者**决定**仔细阅读，但读者在前三十秒就会做出这个决定。所以开头必须赢得剩下的阅读；正文必须用能在扫视中存活的具体细节来奖励持续关注；结尾必须留下难忘的画面。篇幅无法弥补参与的失败：1200 字在两分钟扫视中读完，不如 650 字在五分钟专注中读完。

**Q2.** 说出导致大多数申请文书被拒的四种文体混淆，并用一句话概括每一种。

**答案：**

  1. **把文书当文学回忆录**：使用缓慢、抒情、氛围化的长篇回忆录笔调，在任何主张出现之前就用完了读者的时间钟。
  2. **把文书当简历散文**：把成就列成句子清单，告诉读者简历里已有的事。
  3. **把文书当情书**：对机构表演式崇拜，而在该机构工作的读者会识破这是表演并打折处理。
  4. **把文书当"读者想要什么就写什么"**：猜测读者想要什么然后写那个，结果千篇一律，因为每个人的猜测都差不多。

**Q3.** 什么是具体物象检验？

**答案：** 具体物象检验是一种写作诊断，要求作者数出文中有多少只有作者（或身处作者具体生活的人）才能写出的物象、地点或行动。基准是至少三个。它是一种回忆训练，不是写作花招——你通过更仔细地回忆来通过它，而不是更努力。

**Q4.** 判断正误：一篇足够惊艳的文书可以挽救薄弱的成绩单。

**答案：** 错误。文书位于申请整体之中。它的任务是让申请的其他部分变得难忘，而不是取代它们。相反的信念——认为文书只是装饰、在上面花时间浪费——在选择性院校中也是错误的，因为在技术条件合格者中，文书正是做出区分的东西。两种极端都误读了文书的作用。
