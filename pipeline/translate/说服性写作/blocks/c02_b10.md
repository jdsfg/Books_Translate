1. 它是否通过具体物象检验？（你完整的开头段落中是否至少有三个具体物象、地点或行动？）
  2. 它是否犯了四种文体混淆中的任何一种？
  3. AI 是否可能生成完全一样的这个开头？
  4. 这个开头的作者**是否让人认出是你**？

用一两句话分别诚实回答每个问题。如果任何答案不尽如人意，_先不要修改_——第 2 章会给你系统修改的动作。这个练习的目的是在治疗前把诊断做精准。

提示

这里的诚实比圆滑更有用。你保存的开头句只是一个草稿。草稿可以被不带评判地诊断。

**答案：** 答案因人而异。一个有用的模板：_我的开头包含零 / 一 / 二 / 三个具体物象。_/_我的开头犯了[文学回忆录 / 简历散文 / 情书 / 泛泛猜测]混淆，因为[具体证据]。_/_AI [可以 / 不可以]生成这个开头，因为[具体证据]。_/_这个开头的作者[明显是我 / 还不是我 / 部分是我]，因为[具体证据]。_

如果你发现自己在四个答案中某一处写了"我不确定"，这本身就是一个有用的诊断：这个开头还没有充分到可以被诊断。一个无法被诊断的开头，也无法赢得六分钟的注意力。
