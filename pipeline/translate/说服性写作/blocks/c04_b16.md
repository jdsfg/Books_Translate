#### 概念检查

**Q1.** 给出申请高峰期选拔性院校招生官每篇文书的平均阅读时间。

**答案：** 六到七分钟。有些读者花更多时间（最终委员会里的院系教师：10–20 分钟）。有些花更少（高流量院校的第一轮读者：3 分钟）。综合选拔性院校各轮阅读，平均在六到七分钟之间。

**Q2.** 为什么创伤到胜利的模板被过度使用，补救办法是什么？

**答案：** 这个模板被过度使用，因为很多候选人都经历过艰难的事，并认为正确的结构是 _难事 → 克服 → 学到的东西_。Janet 见过太多，能在开头段就认出来。补救办法是：不用这个模板讲同一个故事——跳过教训式结尾，让读者推断，把更多字数花在艰难事件中的具体场景，而不是艰难事件的情感总结。

**Q3.** 具体物象检验对美国大学申请文书要求什么？

**答案：** 至少三个具体物象——只有作者自己能写的特定时间、地点、行动或物件。一篇 650 字的文书通常受益于四到六个具体物象，分布全文，不要集中在开头段。

**Q4.** 在大学申请文书中，_展示_领导力与_断言_领导力有何区别？

**答案：** 展示领导力是把读者放进一个场景，看候选人在具体情境下做出领导决策（"下半场对 Westview 时，守门员扭了脚踝并朝我挥手，我有九秒时间在界外球前喊换人"）。断言领导力是用一般性声明来描述候选人的领导品质（"我通过挑战展示了领导力"）。展示持久且难忘；断言泛泛且易被扫视。
