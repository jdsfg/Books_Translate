### 9.2 奖学金评审者实际在做什么

奖学金评审者因奖学金而异。大型基金会奖学金（Truman、Marshall、Rhodes、Mitchell、Fulbright）由受过培训的委员会按明确评分细则评审。较小的院系和机构奖学金可能由教师或职员按不太正式流程评审。奖学金阅读的惯例在这些情境中通用。

大型基金会奖学金的典型评审流程：

  1. **先读奖学金声明的标准**（在评审会议开始时，不是逐篇读）。标准定义了评审者将应用的评分细则。
  2. **把每篇文书对照评分细则读。** 评审者问：_这位候选人是否满足标准，用什么具体证据？_
  3. **按每条标准打分。** 多数大型奖学金有明确评分细则（例如，_领导力：1–5；公共服务承诺：1–5；计划：1–5_）。
  4. **汇总。** 所有标准都有强证据的候选人晋级；满足部分标准但不满足其他的通常不会。

关键不对称：一篇文笔好但不回应标准的文书，得分会低于一篇没那么打磨但具体回应标准的文书。奖学金评审者不是为一般文学价值而读；他们读的是标准特有的证据。

奖学金评审者透过评分细则镜片应用 §2.10 的普遍规律，逐条标准打分：

  1. **直接回应每条声明标准。** 满足五条标准中的四条、却忽视第五条的候选人，很可能输给五条都满足的候选人。
  2. **把过往行动对应到标准所指的_品质_。** 领导力、服务承诺、智识好奇心——候选人必须浮现能展示标准所指品质的具体过往行动，而不是在它旁边堆形容词。
  3. **使用资金的具体计划。** 多数奖学金资助特定类型的工作。计划必须展示与奖学金声明目的相符的资金具体用途。
  4. **由行动暗示而不是直接声明价值观。** 直接声明价值观却没有具体证据的候选人，读起来像在表演；展示_暗示_价值观的具体行动的候选人，读起来才真实。

这种文体的特定制败模式：

  1. **泛泛的大学申请文书叙事。** 文笔好但不回应标准的文书，得分低于回应标准的、没那么打磨的文书。
  2. **声望信号。** 列出令人印象深刻的活动，却不阐明相关价值观，不能为该标准给候选人加分。


### 9.3 文体惯例


#### 标准即评分细则惯例

写作前，候选人应把奖学金公布的标准当作评审者会使用的 明确评分细则来读。许多奖学金直接公布评分细则。没有公布的，标准文件就是替代。候选人应：

  1. 识别每条声明标准。
  2. 识别每条标准要求的证据类型。
  3. 规划自己生活中哪些证据对应哪条标准。
  4. 让文书每条标准都用具体证据命中。

没有逐条标准用具体证据回应的奖学金文书，按该文体标准是不完整的，无论文笔多好。
