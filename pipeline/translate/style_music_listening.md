# 风格简报 · 音乐细听系列（listen_bach / beethoven / mozart / schubert / brahms / chopin / tchaikovsky / classical）

> 覆盖：细听系列（巴赫 / 贝多芬 / 莫扎特 / 舒伯特 / 勃拉姆斯 / 肖邦 / 柴可夫斯基 / 古典音乐欣赏指南）。音乐赏析，**核心验收项 = 保住听觉意象与赏析节奏**，且**术语高度易错**。

## 1. 系列定位
音乐赏析 / 作品导听。作者以引导"聆听"的方式解析曲式、主题、配器、结构、历史语境。语言具听觉意象与律动感。

## 2. 质量 bar（核心）
- **保住听觉意象**：音色、织体、力度、主题发展须鲜活可感。
- **保住赏析节奏**：曲式推进（呈示—展开—再现）的讲解语气保留。
- **术语零容错**：音乐术语译法是本系列最高频坑，严格按 §5。

## 3. 人称 / 语气
- 保留第二人称"你"的聆听引导（如有）。
- 主观鉴赏允许（赏析书属性）。

## 4. 术语处理（关键）
- 曲式 / 结构术语首现加注原文：sonata（奏鸣曲）、fugue（赋格）、symphony（交响曲）、concerto（协奏曲）、concerto grosso（大协奏曲）、overture（序曲）、cadenza（华彩段）、variation（变奏）、theme（主题）、motif（动机）、opus（作品号）、movement（乐章）、recitative（宣叙调）、aria（咏叹调）。
- 编号体系保留原文缩写：BWV（巴赫作品号）、KV（克歇尔，莫扎特）、Op.（作品号）、No.（编号）、D.（德意许，舒伯特）。
- 乐器名用通用中译（viola = 中提琴，not 维奥拉）。

## 5. 禁忌译法（务必遵守）
- **movement = 乐章**，绝不可译"运动"。
- **training 在练耳/听觉训练语境 = 练耳 / 训练**，非 ML 的"训练"。
- **movement / piece / work** 区分：work = 作品，piece = 乐曲，movement = 乐章。
- 不把 op. 误解为"操作"。

## 6. 结构保全
- 作品编号（BWV/KV/Op./D.）、乐章标记（I–IV / Allegro / Adagio）原样保留。
- 谱例、引文、脚注、章节层级原样。

## 7. 数字规则
- **作品号 / 编号 / 速度标记 / 年代**保留阿拉伯数字 + 原单位（"Op. 131"、"BWV 846"、"1882"）。
- 乐章序号（第一乐章）可用中文，但编号体系用阿拉伯。

## 8. 示例
- 源：`The fugue's subject recurs in the alto voice.`
- 译：`赋格（fugue）的主题在女低音声部再现。`
- 源：`Beethoven's Op. 131 spans seven movements.`
- 译：`贝多芬的 Op. 131 跨越七个乐章（movements）。`
