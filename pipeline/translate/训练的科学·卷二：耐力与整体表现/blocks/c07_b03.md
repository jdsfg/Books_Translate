#### 完整示例：Jordan 的一周

假设 Jordan 每周训练约 5 小时，分布在几次跑步中，我们统计每个分区带的时间（使用第 5 章分区：轻松为 Zone 1–2，中间为 Zone 3，艰苦为 Zone 4–5）。以下是一周示例，单位为分钟：

| 训练 | 轻松（Z1–2） | 中等（Z3） | 艰苦（Z4–5） | 训练总计 |
|---|---|---|---|---|
| 周一 轻松跑 | 50 | 0 | 0 | 50 |
| 周二 间歇 | 25 | 0 | 20 | 45 |
| 周三 轻松跑 | 55 | 0 | 0 | 55 |
| 周五 间歇 | 35 | 0 | 25 | 60 |
| 周六 阈值 | 25 | 15 | 0 | 40 |
| 周日 长轻松跑 | 75 | 0 | 0 | 75 |
| **周总计** | **265** | **15** | **45** | **325** |

注意艰苦工作集中在两次真正艰苦的训练中（周二、周五间歇，每次的轻松热身和冷身已并入轻松列），阈值日带来仅有的中等分钟数，而周日长跑从头到尾保持真正轻松——这正是本章强调的纪律。逐列相加：轻松 = 50+25+55+35+25+75 = 265 分钟，中等 = 15 分钟，艰苦 = 20+25 = 45 分钟。各训练总计为 50+45+55+60+40+75 = 325 分钟，265+15+45 = 325 验证了行列一致。

现在计算分布，即各分区分钟数除以周总计 325：

* 轻松 = 265 / 325 = 0.815 = 81.5%
* 中等 = 15 / 325 = 0.046 = 4.6%
* 艰苦 = 45 / 325 = 0.138 = 13.8%

因此 Jordan 这一周大致为 **82% 轻松、5% 中等、14% 艰苦**（四舍五入后合计 101%，提醒四舍五入百分比不一定恰好为 100）。与极化模板（约 75–80% 轻松，少量中等，15–20% 艰苦）相比：这一周比教科书极化稍偏轻松，但舒适地落在极化家族内——轻松占主导、灰色地带最小化、少量真正艰苦训练。对休闲运动员而言是合理的一周。


#### 对比周：灰色地带陷阱

现在假设 Jordan 犯了典型初学者错误：每次训练都以相同的"中等"舒适地艰苦努力进行，因为它感觉最有成效：

|  | 轻松（Z1–2） | 中等（Z3） | 艰苦（Z4–5） | 总计 |
|---|---|---|---|---|
| 周总计 | 130 | 165 | 30 | 325 |

分布：轻松 130/325 = 40%，中等 165/325 = 51%，艰苦 30/325 = 9%。这是 **阈值为主、灰色地带主导** 的一周：大部分时间花在中等中间段。按极化观点，这几乎是最差选择：疲劳足以损害恢复和下一次艰苦训练，轻松容量太少无法建设基础，真正艰苦训练又太少无法推动顶端适应。解决办法不是练更多；而是 _重新分配同样的 325 分钟_，把中间往轻松拉，并把艰苦工作集中到几次真正艰苦的训练中。

这种重新分配正是计算分布的全部意义：你无法修复一个还没测量的剂量。
