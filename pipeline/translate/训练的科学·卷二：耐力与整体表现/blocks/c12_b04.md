### 11.4 医疗边界：当疲劳不再是训练问题

有一条线，越过它，糟糕恢复就不再是训练管理问题，而变成健康问题；诚实的教练做法是指出它，而不是开出处方要求更刻苦训练来硬撑。**持续无法通过良好睡眠习惯改善的睡眠差、慢性无法解释的疲劳、尽管休息仍持续下降的表现、静息心率持续升高，或一组过度训练样症状** 都是 _看合格专业人士_ 的信号，而不是再加恢复设备或硬撑。这些可能反映真正的医学问题（从睡眠障碍到激素或其他问题），超出训练书能或应处理的范畴。这是红线 1：本书为想训练的健康人构建知识；一旦恢复问题进入可能生病的领域，指令只有一句话——看医生。恢复是训练变量，直到它变成健康信号；知道区别是成为完整、有良好指导的运动员的一部分。


### 11.5 恢复审计（给自己打分）

这里没有公式可算，所以你要 _评估_ 。诚实给自己每一项打分，模式会告诉你最大恢复收益在哪里——几乎总是在基础，而非设备。

| 恢复杠杆 | 诚实自检 | 你的状态 |
|---|---|---|
| 睡眠时长 | 我平均每晚是否至少 7 小时（大训练量时理想向 8–9 靠近）？ | |
| 睡眠质量 | 我入睡是否较顺利、整夜安稳、醒来感到恢复？ | |
| 休息日 | 我是否安排计划好的休息或轻松日，并真正让它们轻松？ | |
| 补给 | 我吃得是否足以支持训练（第 12 章），而非长期摄入不足？ | |
| 水合 | 我日常水合是否较充分？ | |
| 生活压力 | 我训练外压力是否可控，还是正在消耗我的恢复？ | |
| 疲劳信号 | 我的表现、静息心率、情绪是否稳定，还是正在漂移（第 10 章）？ | |

打分是定性的，目的在于诊断：前六行任何一项"否"，尤其睡眠行，都比你能买的任何设备更有机会。如果你发现自己恢复产品很多，睡眠和休息日得分却差，你就准确诊断出了本章警告的陷阱。如果最后一行在以上各项都诚实"是"的情况下仍持续漂移，那就是医疗边界的提示。这个审计是反复使用的工具：每当训练感觉比应有的更艰难，就重新打分，先处理最便宜、最高价值的缺口。
