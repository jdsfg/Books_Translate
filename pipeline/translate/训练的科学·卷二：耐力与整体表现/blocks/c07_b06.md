#### 自己算

**Q1.** 一位跑者记录的一周如下：轻松（Z1–2）300 分钟，中等（Z3）40 分钟，艰苦（Z4–5）60 分钟。(a) 计算百分比分布。(b) 将这一周归类（极化、金字塔或灰色地带主导），并对照模板说明理由。

提示：

先求总分钟数，再用各带除以总数。极化 ≈ 75–80% 轻松 / 少量中等 / 15–20% 艰苦；金字塔的中等多于艰苦；灰色地带主导是中等中间段占主导。

**答案：** (a) 总分钟数：300 + 40 + 60 = 400。分布：

* 轻松 = 300 / 400 = 75%
* 中等 = 40 / 400 = 10%
* 艰苦 = 60 / 400 = 15%

(b) 这是 **极化** 一周：轻松占 75%（极化轻松范围下限），中等中间段很小（10%），真正艰苦训练占 15%（极化艰苦范围下限）。它不是金字塔，因为金字塔中 Zone 3 带应超过艰苦带，而此处艰苦（15%）大于中等（10%）。它也肯定不是灰色地带主导，因为中等中间段被最小化。对训练有素的耐力运动员而言，这是教科书般合理的分配。

**Q2（现在用你自己的身体）。** 取最近一周自己的训练，估算各分区带花的时间（使用第 5 章分区，根据手表或主观努力感把每次训练的每一段分配进分区）。计算轻松 / 中等 / 艰苦百分比，对一周归类，并如果分布不对，决定下周一个具体改变。

**答案：** 答案是 _你的_ 分布，诚实统计并正确转为百分比（各带分钟数除以周总计）。自查：(1) 是否按实际分区而非训练标签分配分钟？一次名为"轻松"的跑如果中间漂到 Zone 3，那些分钟应计为中等。(2) 轻松百分比是否占主导？对多数休闲运动员应在 75–85% 左右；如果远低于此，你可能住在灰色地带，具体调整是 _放慢轻松日_（用第 4 章谈话测试强制执行），而不是增加训练。(3) 有没有任何真正艰苦训练？如果分布全是轻松到中等、没有任何真正艰苦训练，增加一次短促的真正艰苦训练可能有帮助。交付物不是完美的一周，而是 _测量剂量的习惯_，因为正如本章所说，你无法修复一个还没算过的分配。把选择的改变写进日志，两周后重新测量。
