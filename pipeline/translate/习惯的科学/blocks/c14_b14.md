* 睡眠差（深夜手机、不规律作息）→ 疲劳、认知受损。
* → 更多晨间咖啡因补偿。
* → 来自咖啡因和持续压力的下午皮质醇。
* → 晚间酒精“放松”。
* → 酒精和未处理认知负荷导致睡眠被打断。
* 循环重复，每次迭代略微更糟。

叠加：

* 认知控制降低 → 更难专注 → 拖延 → 一天结束时压力更大 → 补偿行为（吃零食、刷屏、喝酒）。
* 久坐模式 → 情绪差 → 更多安慰寻求。
* 社交孤立 → 孤独 → 强迫性技术使用 → 花在真实连接上的时间更少 → 更孤立。
* 注意力碎片化 → 没有感受意义 → 低度不满 → 更多强迫性消费填补缺口。

**结构对称性：**

同一复利机制在两个方向运作。习惯复利；复利是良性还是恶性，取决于哪些习惯在位。_处于恶性循环中的现代成年人不是弱；他们正居住在一个产生可预见行为失败的自我强化系统中。_ 这种模式是结构性的，不是性格性的。

**修正：**

通过改变锚定来逆转循环。睡眠被优先 → 认知功能改善 → 专注工作成为可能 → 社交参与获得时间 → 情绪改善 → 更少强迫性补偿需求 → 睡眠进一步改善。同一复利机制现在朝正向运作。

这是锚定习惯框架最深层的理由。杠杆在于整合。五个精心挑选的锚定让你进入系统自我支持的良性循环；分散改变让你留在系统自我破坏的恶性循环中。

读者任务：识别你目前在哪个循环中，并在需要时用锚定习惯框架逆转方向。这是一个数月项目；它产生真实改变。

**Q4.** 为什么本章主张“如果情境工程化良好，人的一生可以在很大程度上由程序性记忆承载”？H.M. 案例证明了什么，对非临床读者有什么教训？

**答案：**

本章基于 H.M. 临床案例（线索 A 的高潮）加上关于程序性记忆和情境的更广泛框架来论证这一点。

**H.M. 案例：**

1953 年手术后，Henry Molaison 无法形成新陈述性记忆。他无法记住新的人、事件或事实。每一天在重大方面都是第一天。然而，在适当的支架（scaffolding）下，他过着可辨认的生活：熟悉的早晨例程、熟悉的餐食、熟悉的照顾者。他的程序性系统完好；周围情境被结构化以支持程序性模式。完好程序性记忆 + 工程化情境的组合产生了功能性生活。

该案例证明，**构成“生活”的大部分依赖程序性记忆与工程化情境的合作。** 程序性系统运行每时每刻行为；情境提供触发程序性反应的线索；两者结合产生一天。没有程序性完好，情境无物可作用；没有情境，程序性系统没有线索可反应。两者一起产生活动。
