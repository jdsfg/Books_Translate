原则：**不要试图“不做”某事。在同一线索下做别的事。** 当线索触发时，程序性系统需要一个反应；如果你不提供替代，旧反应会默认触发。_压抑是意志力策略；替代是结构性策略。_ 结构性策略可靠获胜；意志力策略偶尔获胜且代价高昂。

**Q4.** 在替代背景下，什么是“功能匹配”？为什么它重要？为什么许多“健康替代”建议失败？

**答案：** **功能匹配**是指，一个替代反应要在不期望习惯的位置上生效，必须服务该不期望习惯所服务的相同心理功能。大多数成熟习惯都在为这个人做真正的工作——提供安慰、分心、仪式、社交连接、情绪调节、逃避等。可见行为（吸烟、吃零食、刷屏）是手段；功能才是真正被服务的。

**为什么功能匹配重要：**

程序性系统持续触发线索 → 反应链，因为反应提供了某种有价值的功能。如果替代品不能提供相同功能，程序性系统会拒绝它——因为线索的底层需求未被满足。替代会失败，不是因为人弱，而是因为替代没有做到原物所做的事。

**为什么“健康替代”建议常失败：**

流行自助常推荐“健康替代”，而不检查替代是否服务相同功能。经典失败替代：

* _用绿茶替代压力香烟。_ 香烟提供暂停 + 仪式 + 5 分钟抽离 + 尼古丁。绿茶提供一种饮料。没有功能匹配。
* _用冥想替代深夜焦虑刷屏。_ 刷屏提供新奇 + 刺激 + 低努力参与。冥想提供静止 + 内省 + 努力。没有功能匹配。
* _用长时间散步替代安慰性吃零食。_ 吃零食提供即时口腔满足 + 短暂情绪提升 + 低努力安慰。长时间散步提供延迟情绪提升 + 大量努力 + 无口腔满足。功能匹配不完美。

这些之所以失败，是因为替代因“更健康”而被选择，而非因功能匹配。诚实版本：健康替代要有效必须功能匹配；仅“更健康”不足够。

**更好的功能匹配替代：**

* 压力香烟 → 短暂外出散步（提供暂停、抽离、仪式；更接近匹配）。
* 深夜刷屏 → 读书（提供新奇、刺激、低努力；匹配）。
* 安慰性吃零食 → 喝茶仪式 + 简短电话（提供安慰、仪式、短暂情绪提升；更好匹配）。

原则推广：**不要问“这个习惯的更健康版本是什么？”而要问“这个习惯实际在为我做什么，还有什么能做到？”** 第一个问题肤浅；第二个产生程序性系统可接受的替代。

实践上，读者的练习是识别每个坏习惯服务的功能，并设计功能匹配的替代。第 9 章的执行意图格式——“如果线索 X，那么反应 Y”——是结构；功能匹配决定有效的 Y。
