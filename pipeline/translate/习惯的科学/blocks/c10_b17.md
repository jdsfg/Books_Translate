#### 应用问题

**Q1.** 一位读者一直想每天写作，但持续失败。他们设了“每天写作”的目标，向几个朋友公开承诺，试过各种激励技巧。他们每周写大约两次，没有可预测时间表。用执行意图框架，设计一个可能有效的具体计划。请精确说明线索、反应，以及区分好计划与弱计划的特征。

提示

这位读者日常生活中有什么可靠、具体、可识别的线索可以锚定写作？写作的*第一个动作*是什么，有别于目标？计划如何简单到能自动触发？

**答案：**

**诊断。** 这位读者一直以目标意图模式运作（“我会每天写作”），没有指定线索，也没有指定第一个动作。程序性系统没有东西可抓。公开承诺有点帮助，但不改变线索-反应架构。激励技巧在做意志力框架预测的事——对不是瓶颈的东西产生微小效应。瓶颈是结构性的：写作没有线索，也没有程序性预安装。

**具体执行意图计划。**

读者需要识别一个可靠、具体线索。大多数成年人有几个每天可靠触发的线索：晨间咖啡、吃完早餐、第一次坐到办公桌前、完成晨间洗漱等。读者应选择*一个*——哪个最可靠且在写作可行的时间出现。

假设读者识别出“倒完晨间咖啡后坐到办公桌前”是可靠的日常线索。执行意图：

> _如果我早上端着咖啡坐到办公桌前，我会打开笔记本并在打开邮件或任何浏览器标签前写三句话。_

用五个好计划特征检查：

  1. **具体、可识别的线索。** ✓ “早上端着咖啡坐到办公桌前”具体且可靠。
  2. **具体、可立即执行的反应。** ✓ “打开笔记本写三句话”是具体第一动作，有可测量完成标准。
  3. **线索可靠出现。** ✓ 对多数读者来说，咖啡-然后-书桌在工作日大多发生。
  4. **没有埋藏的斟酌。** ✓ 没有“如果我有时间”或“如果我不太累”条件。如果读者在办公桌前且端着咖啡，计划就触发。
  5. **关注第一动作而非整个目标。** ✓ “三句话”是第一动作，不是“今天写一章”。一旦写了三句话，作者已经在行动中，很可能继续。如果不继续，三句话也是进展。
