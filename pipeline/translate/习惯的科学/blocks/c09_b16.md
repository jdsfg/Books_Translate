**自我控制的分配观**把自我控制视为对每刻加权问题的解决。在任一给定时刻，大脑都在权衡多种输入——短期奖励、长期目标、当前疲劳、压力水平、认知负荷、社会情境、动机、框架——并产生一个我们称之为“自我控制”或“自我控制失败”的行为输出，取决于加权是否有利于长期目标。没有单一资源被耗尽。多种输入被加权，而加权在不同条件下转移。

**意志力-燃料观**（已被削弱的原始观点）把自我控制视为一种可耗尽资源，随努力使用而耗尽、随休息恢复。它是单一的、有限的、肌肉般的。

实践建议的差异：

| 建议 | 意志力-燃料观 | 分配观 |
|---|---|---|
| 为什么晚上失败 | 你的意志力燃料用完了 | 输入转移了：疲劳正在膨胀短期奖励估值 |
| 怎么办 | 把意志力留给重要的事；不要提前耗尽 | 管理输入：在疲劳膨胀奖励时安排更少线索暴露；降低长期目标轴上的决策负荷 |
| 为什么有人成功 | 他们有更多意志力/像练肌肉一样练出来了 | 他们更好地安排了输入：更好的线索环境、社会结构、基础设施 |
| 为什么有人失败 | 他们意志力更少 | 他们的输入设置产生了可预测的分配失败 |
| 补救 | 建立更多意志力 | 建立更好的输入结构 |
| 努力的角色 | 顶着耗损撑过去 | 通过改变输入减少对实时努力的需求 |

分配观直接通向基于结构-架构的干预，这正是本书的核心工具箱。意志力-燃料观通向激励和纪律干预，而数据不支持这些。两种框架产生显著不同的建议。

对读者的实践：当你发现自己处于自我控制不来的情境时，问题不应是“我的意志力去哪了？”而应改为**“哪些输入正在不利于长期目标，我如何改变输入？”** 这是结构性问题解决，而非品格建设，是现有数据支持的。

**Q3.** Lally 研究（或类似关于习惯形成的研究）对习惯实际多久自动化说了什么？为什么流行的“21 天”数字是错的？更诚实的预期时间线是什么？

**答案：** Lally 研究追踪参与者在日常生活中建立新的健康相关习惯，使用每日记录测量每种行为的渐进“自动化”。结果：

* **达到自动化的中位时间约为 66 天**——是流行 21 天数字的三倍。
* **范围是 18–254 天**——变异性极大。
* **有些习惯在研究窗口内没有达到自动化**——尤其可能根本不会完全习惯化的复杂行为。
* **时间取决于行为类型：** 简单行为（早餐喝水）比复杂行为（去健身房）自动化更快；内在奖励行为比延迟奖励行为更快。
