1943 年，Warren McCulloch 和 Walter Pitts 提出，大脑中的神经元可建模为简单二进制阈值单元：若输入之和超过阈值则放电（输出 1），否则不放电（输出 0）。这一生物学启发诞生了人工智能的第一个模型：**人工神经元（artificial neuron）**。

我们前几章一直在为此做准备。逻辑回归（第7章）已经是带 sigmoid 激活的单个神经元——阈值单元的连续、概率版本。神经网络强大之处在于把许多这样的神经元堆叠成层：一层的输出成为下一层的输入，组合函数可以表达任意复杂度。

但在进入深度网络前，我们需要理解基本单元：感知机。


### 14.1 感知机：二元线性分类器


#### 定义：感知机

一个有 n 个输入的 **感知机（perceptron）** 计算：

\hat{y} = \begin{cases} 1 & \text{if } \mathbf{w}^\top \mathbf{x} + b \geq 0 \\ -1 & \text{otherwise} \end{cases}

其中 \mathbf{w} \in \mathbb{R}^n 是权重，b 是偏置。

用平实的语言，感知机是线性分类器，根据输入加权和是否超过阈值输出 +1 或 -1。它是逻辑回归硬阈值祖先。

几何图像：\mathbf{w}^\top \mathbf{x} + b = 0 是 \mathbb{R}^n 中的超平面。一侧点分为 +1，另一侧为 -1。这与支持向量机（SVM，第11章）和逻辑回归（第7章）的决策边界相同——区别在于如何学习超平面。


### 14.2 感知机学习规则


#### 定义：感知机学习规则

初始化 \mathbf{w} = \mathbf{0}。重复直到收敛：

* 对每个训练样本 (\mathbf{x}_i, y_i)，y_i \in \{-1, +1\}：
    * 若 \hat{y}_i \neq y_i（误分类）：
      * \mathbf{w} \leftarrow \mathbf{w} + y_i \mathbf{x}_i
      * b \leftarrow b + y_i

用平实的语言：当样本被误分类时，调整权重使决策边界朝正确分类它移动。

**为何有效：** 若 y_i = +1 且该点被误分类（\mathbf{w}^\top \mathbf{x}_i + b < 0），给 \mathbf{w} 加上 \mathbf{x}_i 会增大 \mathbf{w}^\top \mathbf{x}_i，使下一轮更可能为正。更新是局部且即时的——基本形式没有梯度下降、没有学习率。

**感知机收敛定理：** 若训练数据 **线性可分** ，感知机学习规则保证在有限次更新内收敛到一个解。更新次数上界为 R^2 / \gamma^2，其中 R 是数据点最大范数，\gamma 是分离超平面的几何间隔。

**若数据不是线性可分：** 感知机永不收敛——它无限循环而找不到完美分隔器。这一根本性局限催生了多层网络的发展。
