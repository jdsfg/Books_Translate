#### 定义：线性回归模型

给定特征向量 \mathbf{x} = (x_1, x_2, \ldots, x_n)，**线性回归模型（linear regression model）** 预测：

\hat{y} = w_0 + w_1 x_1 + w_2 x_2 + \cdots + w_n x_n = w_0 + \mathbf{w}_{1:n}^\top \mathbf{x}

用平实的语言说，预测是特征的加权和，加上常数项 w_0，称为 *intercept*（截距）或 *bias*（偏置）。

参数 \mathbf{w} = (w_0, w_1, \ldots, w_n) 是我们从数据中学习得到的。对房价数据集：

\hat{y} = w_0 + w_1 (\text{area}) + w_2 (\text{bedrooms}) + w_3 (\text{age}) + w_4 (\text{garage})

**解释：** 若学得的权重 w_1 = 0.12（每平方英尺千美元），则意味着：*在其他特征保持不变的情况下，每增加一平方英尺，房价预计增加 120 美元*。

这种可解释性是线性回归最大的优点之一。权重直接具有边际效应的含义。

**截距的记号技巧：** 我们可以在每个数据点中加入一个常数特征 x_0 = 1，把截距吸收进权重向量。于是模型简化为：

\hat{y} = \mathbf{w}^\top \mathbf{x}, \quad \mathbf{w} = (w_0, w_1, \ldots, w_n), \quad \mathbf{x} = (1, x_1, x_2, \ldots, x_n)

这种记号更简洁，今后将一直使用。


### 5.3 什么是好的拟合？损失函数

给定 m 个训练样本 (\mathbf{x}_1, y_1), \ldots, (\mathbf{x}_m, y_m)，我们如何衡量某个权重向量 \mathbf{w} 对数据的拟合好坏？

最自然的度量是：预测值与真实标签差多远？


#### 定义：均方误差（MSE）

L(\mathbf{w}) = \frac{1}{m}\sum_{i=1}^m (y_i - \hat{y}_i)^2 = \frac{1}{m}\sum_{i=1}^m (y_i - \mathbf{w}^\top \mathbf{x}_i)^2

用平实的语言说，MSE 是所有训练样本预测误差平方的平均。

我们对误差取平方有两个原因：(1) 平方使所有误差为正（正负误差不互相抵消）；(2) 平方对大误差的惩罚比小误差更重。

如第3章所示，最小化 MSE 等价于在高斯噪声假设下进行最大似然估计。MSE 损失不是任意选择——它来自如下数据生成过程假设：

y_i = \mathbf{w}^\top \mathbf{x}_i + \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma^2)

另外两个有用的指标：**均方根误差（Root Mean Squared Error, RMSE）** = \sqrt{\text{MSE}}，它与 y 同单位；以及 **决定系数（coefficient of determination）** R^2：

R^2 = 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y})^2}

R^2 = 1 表示完美拟合；R^2 = 0 表示模型不比总是预测均值更好；R^2 < 0 表示模型比均值预测还差。
