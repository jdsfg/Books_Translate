#### 深入思考

**Q1.** "通过无意识实现公平"——从模型中移除受保护属性（种族、性别）——是一种幼稚的公平干预。用代理变量概念解释它为什么通常失败。然后讨论替代方案（显式使用受保护属性进行公平调整）是否也引发自身伦理关切。

**讨论：**

**为什么无意识失败：** 现代 ML 模型擅长从相关特征中恢复预测信号。即使移除种族和性别，许多剩余特征因系统性不平等而与这些属性相关：

* 邮政编码 → 种族（居住隔离）
* 大学名称 → 社会经济地位和种族
* 工作履历空白 → 常是怀孕/照护假 → 性别
* 信用历史长度 → 年龄和移民身份

模型学会这些相关性，实际上通过代理使用了受保护属性。研究表明，名义上盲于种族的模型，仅根据剩余特征预测种族的能力几乎与使用显式属性一样强。

**使用受保护属性实现公平：** 替代方案——显式包含受保护属性并在后处理（阈值调整）或处理中（公平性约束）使用它——按多数公平定义更有效，但引发关切：

  1. **差别待遇：** 在许多法律体系中，即使是出于惠及弱势群体的目的，在决策中显式考虑种族或性别也构成差别待遇——可能违法，即使减少了差别影响。这造成法律张力。

  2. **家长式作风与污名化：** 即使有益的差别待遇也可能污名化群体或被视为施舍。

  3. **选择哪个定义？** 显式优化某一公平定义（人口统计均等）可能恶化其他定义（机会均等）。选择需要价值判断。

  4. **博弈：** 若候选者知道模型会按群体身份调整，行为可能以破坏调整的方式改变。

**结论：** 偏见没有纯粹技术解。"无意识公平"不足。显式公平干预更有效，但涉及法律与伦理权衡，需要人类判断、利益相关者输入和社会辩论——而不仅是算法调参。

**Q2.** 一位同事提议用对抗训练保护医学影像分类器对抗对抗样本：每步训练生成对抗样本并加入 mini-batch（小批次）。讨论 (a) 为什么这是有效防御，(b) 一个重大实际缺点，(c) 提供更强形式化保证的替代防御。

**讨论：**

**(a) 为什么对抗训练有效：** 模型在训练中显式暴露于对手会使用的扰动类型，迫使它学习对输入小扰动鲁棒的决策边界。直观上，损失 landscape 在训练示例附近被"平滑"，向任何方向稍微移动都不会突然越过决策边界。Goodfellow 等的 FGSM 对抗训练表明，每 batch 做一次基于梯度的扰动步（Fast Gradient Sign Method）就足以显著提升鲁棒性。
