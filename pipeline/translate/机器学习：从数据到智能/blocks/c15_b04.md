#### 概念检测

**Q1.** 一个感知机权重 \mathbf{w} = (2, -1, 0.5)，偏置 b = -1。对输入 \mathbf{x} = (1, 2, 4)，计算输出。

**答案：**

z = \mathbf{w}^\top \mathbf{x} + b = 2(1) + (-1)(2) + 0.5(4) + (-1) = 2 - 2 + 2 - 1 = 1

由于 z = 1 \geq 0，感知机输出 \hat{y} = 1。

**Q2.** 解释为什么以下两层网络计算 XOR。隐藏层权重 W^{(1)} = \begin{pmatrix}1 & 1 \\ 1 & 1\end{pmatrix}，偏置 \mathbf{b}^{(1)} = (-0.5, -1.5)，输出权重 \mathbf{w}^{(2)} = (1, -1)，偏置 b^{(2)} = 0。使用阈值激活：f(z) = 1 若 z > 0，否则 0。

**答案：** 追踪全部四种输入：

对 \mathbf{x} = (0,0)：隐藏输入：[0+0−0.5, 0+0−1.5] = [-0.5, -1.5]。隐藏输出：f(-0.5)=0, f(-1.5)=0。输出：0(1)+0(−1)+0 = 0。f(0)=0。XOR = 0。

对 \mathbf{x} = (0,1)：隐藏输入：[0+1−0.5, 0+1−1.5] = [0.5, -0.5]。隐藏输出：[1, 0]。输出：1(1)+0(−1) = 1 > 0，输出 1。XOR = 1。

对 \mathbf{x} = (1,0)：隐藏输入：[1+0−0.5, 1+0−1.5] = [0.5, -0.5]。隐藏输出：[1, 0]。输出：1。XOR = 1。

对 \mathbf{x} = (1,1)：隐藏输入：[1+1−0.5, 1+1−1.5] = [1.5, 0.5]。隐藏输出：[1, 1]。输出：1(1)+1(−1) = 0。f(0)=0。XOR = 0。

第一个隐藏神经元在"至少一个输入为 1"时放电（OR 门）；第二个在"两个输入都为 1"时放电（AND 门）。输出计算 OR − AND = XOR。

**Q3.** 计算 ReLU 在 z = 2、z = 0、z = −3 处的导数。z = 0 处的不可微性为何不是实际问题？

**答案：**

f'(2) = 1（因为 z > 0，ReLU 等于恒等函数）
f'(−3) = 0（因为 z < 0，ReLU 等于 0；导数为 0）
f'(0) 未定义（z = 0 处不可微）

z = 0 处不可微实际上不是问题，因为：(1) 任何特定浮点计算恰好得到 0 的概率可忽略；(2) 实践中，z = 0 处任意赋予次梯度 0 或 1 不影响训练；(3) 小批量 SGD 本身有噪声，单个不可微点的零梯度完全被这种噪声掩盖。

**Q4.** 为什么不能在多层网络中使用恒等函数 f(z) = z 作为激活函数？
