### 7.3 训练：交叉熵损失

对逻辑回归，MSE 是糟糕的损失函数——它产生非凸优化景观。相反，我们使用 **交叉熵损失（cross-entropy loss）**，它来自最大似然。

模型下观测标签的概率为：

P(\mathbf{y} | \mathbf{w}) = \prod_{i=1}^m \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1 - y_i}

取负对数似然：


#### 定义：二分类交叉熵损失

L(\mathbf{w}) = -\frac{1}{m}\sum_{i=1}^m \left[ y_i \log \hat{p}_i + (1 - y_i)\log(1 - \hat{p}_i) \right]

其中 \hat{p}_i = \sigma(\mathbf{w}^\top \mathbf{x}_i)。

用平实的语言说，当模型自信且错误时（真实标签为 1 时预测接近 0，或反之），损失很大；当模型自信且正确时，损失很小。

交叉熵损失的梯度非常简洁：

\nabla_\mathbf{w} L = \frac{1}{m}\sum_{i=1}^m (\hat{p}_i - y_i) \mathbf{x}_i = \frac{1}{m} X^\top (\hat{\mathbf{p}} - \mathbf{y})

它与线性回归梯度的结构相同——只是把预测值换成了预测概率 \hat{\mathbf{p}}。更新"推动"权重使预测更正确：当模型低估（\hat{p}_i < y_i）时，梯度指向增加 \hat{p}_i 的方向。

交叉熵损失关于 \mathbf{w} 是 **凸** 的——因此梯度下降保证找到全局最小值。


#### 常见误解

逻辑回归名为"回归"却用于分类，这让许多初学者困惑。"回归"指的是对 *对数几率* 做回归——模型内部拟合一个线性函数，再对它做变换。输出仍是概率，最终预测是类别标签。这个名字是历史遗留。现代术语或许会叫它"逻辑分类"。


### 7.4 逻辑回归的正则化

与线性回归一样，没有正则化的逻辑回归在特征很多时会严重过拟合。实践中，**逻辑回归总要正则化**。

正则化目标如下：

**L2 正则化（岭回归逻辑回归）：**

L(\mathbf{w}) = -\frac{1}{m}\sum_i [y_i \log\hat{p}_i + (1-y_i)\log(1-\hat{p}_i)] + \frac{\lambda}{2}\|\mathbf{w}\|^2

**L1 正则化（Lasso 逻辑回归）：**

L(\mathbf{w}) = -\frac{1}{m}\sum_i [y_i \log\hat{p}_i + (1-y_i)\log(1-\hat{p}_i)] + \lambda\|\mathbf{w}\|_1

第6章的直觉同样适用：L2 收缩所有权重；L1 产生稀疏解。对文本分类（我们的 Thread B 应用），L1 常更受青睐，因为大多数词与标签无关。
