这说明逻辑回归的预测概率应谨慎解读：权重大小影响置信度，而不仅是方向。


#### 应用问题

**Q1.** 你正在构建一个医疗诊断分类器。疾病罕见：只有 1% 的患者患病。一个对所有患者都预测"无病"的基线模型准确率达到 99%。你的逻辑回归模型准确率为 96%。你应该偏好基线还是你的模型？该如何评估？

*提示*

回想第3章的基率谬误。想想医疗诊断中哪种错误成本更高。

**答案：** 96% 准确率的模型如果漏掉更多病例，可能比基线 **更差**。在患病率 1% 时：96% 准确率可能意味着它正确分类了 96% 的健康患者，但把 *大部分* 真正患者判错。

正确的指标是：

* **Sensitivity（正类召回率 recall）：** 模型捕获了多少真实病例？基线捕获 0%（从不预测患病）。即使你的模型只捕获 50%，也比 0% 好无穷倍。
* **Specificity：** 多少健康患者被正确排除？
* **Positive Predictive Value (PPV)：** 模型标记为阳性的患者中，真正患病的比例。

正确评估：计算 **混淆矩阵（confusion matrix）**（真正例、假正例、真反例、假反例）、**ROC 曲线**（所有阈值下的 sensitivity 对 1-specificity）和 **AUC**（ROC 曲线下面积）。基线的 AUC = 0.5（随机）。任何 AUC > 0.5 且 sensitivity 非零的模型都严格更好。第8章会详细讲这些指标。

**Q2.** 你正在构建一个类似 Thread B 的词袋模型情感分类器。词汇表有 20,000 个词。你训练 Lasso 逻辑回归，训练准确率 99%，测试准确率 78%。可能发生了什么？该做哪些改动？

*提示*

比较训练与测试准确率。这是第1章哪个问题的典型标志？

**答案：** 训练 99%、测试 78% 的巨大差距是过拟合的典型标志。模型记住了训练集特有的词汇模式——可能把特定影评人名字、电影标题或特殊表达方式与正/负面情感联系起来，而不是学到通用情感词。

原因与修复：

  1. **正则化太弱**（最可能）：Lasso 的 \lambda 太小。通过交叉验证增大 \lambda。更大的惩罚会把更多无关词归零，迫使模型关注最可推广的特征。
  2. **词汇表太大：** 删去出现次数少于 5 次的罕见词。它们是没有预测信号的噪声特征。
  3. **未去停用词：** "the"、"a"、"of" 等常见词增加噪声维度。应去除。
  4. **特征工程：** 用 TF-IDF 加权代替原始频次；它会自动降低极常见词的权重。
  5. **更多训练数据：** 如果可能，增加标注样本可减少任何正则化水平下的过拟合。

目标：把训练准确率降到约 88–90%（接受训练准确率略低），以把测试准确率提高到 85% 以上（Thread B 基线）。目标是 *泛化*，而不是训练表现。
