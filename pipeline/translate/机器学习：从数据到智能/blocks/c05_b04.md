#### 常见误解

许多学生假设梯度下降总能收敛到全局最小值。一般情况下，它只收敛到 *local minimum*（局部最小值）——梯度为零但不是全局最优的点。对凸函数（4.4节），所有局部最小值都是全局的，因此不必担心。对神经网络损失景观这样的非凸函数，收敛到局部最小值不保证是全局最小——但实践中，用 SGD 训练的深度学习模型往往能找到泛化很好的解。为什么？这是 ML 理论中最深刻的开放问题之一。


### 4.4 凸性：何时局部等于全局


#### 定义：凸函数

函数 f: \mathbb{R}^n \to \mathbb{R} 是 **凸（convex）** 的，如果对任意两点 \mathbf{x}, \mathbf{y} 和任意 t \in [0, 1]：

f(t\mathbf{x} + (1-t)\mathbf{y}) \leq t f(\mathbf{x}) + (1-t) f(\mathbf{y})

用平实的语言说：函数"向上弯曲"。图像上任意两点间的线段都位于图像上方。凸函数看起来像一个碗。

对二阶可微函数 f: \mathbb{R} \to \mathbb{R}，凸性等价于 f''(x) \geq 0 处处成立。对多变量函数，凸性等价于 Hessian 矩阵 H = \nabla^2 f 处处半正定。

**为什么凸性重要：** 对凸函数，任何局部最小值都是全局最小值。梯度下降保证收敛到全局最小值（在合适学习率下）。

**ML 中的例子：**

* 线性回归的 MSE 损失：关于 \mathbf{w} 凸 ✓
* 逻辑回归的交叉熵损失：凸 ✓
* 神经网络的损失：*不*凸 ✗（存在多个局部最小值）

从第5–8章（凸优化问题）过渡到第14–21章（非凸深度学习）是课程中重要的智力跳跃之一。


#### 二阶条件

**Hessian 矩阵** 是二阶偏导数矩阵：

H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}

在临界点（\nabla f = \mathbf{0}）处：

* 若 H 正定：局部最小值
* 若 H 负定：局部最大值
* 若 H 同时有正负特征值：鞍点

对大型神经网络，计算完整 Hessian 计算上不可行（n 个参数的 Hessian 是 n \times n）。现代优化方法（第18章）使用近似。
