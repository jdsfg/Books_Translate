**岭回归（Ridge regression）作为高斯先验。** 假设似然是高斯的，即 y_i = \mathbf{w}^\top \mathbf{x}_i + \epsilon_i，\epsilon_i \sim \mathcal{N}(0, \sigma^2)；并对每个权重独立放置高斯先验 w_j \sim \mathcal{N}(0, \tau^2)。对数后验为：

\log P(\mathbf{w} | \text{data}) = -\frac{1}{2\sigma^2}\sum_i (y_i - \mathbf{w}^\top \mathbf{x}_i)^2 - \frac{1}{2\tau^2}\|\mathbf{w}\|^2 + \text{const}

最大化它等价于最小化 \sum_i (y_i - \mathbf{w}^\top \mathbf{x}_i)^2 + \frac{\sigma^2}{\tau^2}\|\mathbf{w}\|^2，正是岭回归，其中 \lambda = \sigma^2 / \tau^2。

**Lasso 作为 Laplace 先验。** 现在对每个权重独立放置 Laplace 先验 w_j \sim \text{Laplace}(0, b)，PDF 为 p(w_j) = \frac{1}{2b}\exp(-\lvert w_j \rvert/b)。对数后验为：

\log P(\mathbf{w} | \text{data}) = -\frac{1}{2\sigma^2}\sum_i (y_i - \mathbf{w}^\top \mathbf{x}_i)^2 - \frac{1}{b}\|\mathbf{w}\|_1 + \text{const}

最大化它等价于最小化 \sum_i (y_i - \mathbf{w}^\top \mathbf{x}_i)^2 + \frac{2\sigma^2}{b}\|\mathbf{w}\|_1，即 Lasso，其中 \lambda = 2\sigma^2 / b。Laplace 分布在零点有尖峰，这从几何上解释了为什么 Lasso 促进精确稀疏：先验把大量质量集中在 w_j = 0 附近。

**从贝叶斯角度看选择 \lambda 的含义。** 对岭回归，\lambda = \sigma^2 / \tau^2；对 Lasso，\lambda = 2\sigma^2 / b。它编码了我们对噪声大小与先验尺度之比的信念。大 \lambda 表示先验方差 \tau^2 相对噪声很小，即我们强烈相信权重接近零。小 \lambda 表示先验很弥散，我们更信任数据。用交叉验证选 \lambda 是用数据经验估计这个比率的频率主义近似——完整贝叶斯方法会对 \lambda 使用超先验并做边缘化。贝叶斯视角因此揭示：正则化从不"任意"——它总编码了对真实权重大小的信念。


### 本章总结

正则化通过惩罚模型复杂度防止过拟合。两种基本方法：

* **岭回归（Ridge，L2）**：在损失中加入 \lambda\|\mathbf{w}\|^2；把所有权重压向零但不精确置零；等价于高斯先验；有闭式解 (X^\top X + \lambda m I)^{-1} X^\top \mathbf{y}；所有特征都有关时优先使用
* **Lasso（L1）**：在损失中加入 \lambda\|\mathbf{w}\|_1；把许多权重精确驱零；自动特征选择；等价于 Laplace 先验；特征稀疏时优先使用

**Thread A 检查点（A2）：** 把 Lasso 应用于扩展后的 25 特征房价模型，17 个特征被自动剔除。存活下来的 8 个更可解释，验证集泛化更好。这就是正则化的作用：不仅防止过拟合，还发现真正重要的事物。
