### 20.5 Transformer 块

完整 **Transformer 块** 将多头注意力与位置前馈网络结合，外加残差连接和层归一化：

    Input: X (T × d_model)
      ↓
    Multi-Head Self-Attention
      ↓ + Residual: X' = LayerNorm(X + MultiHead(X, X, X))
    Feed-Forward: FFN(x) = max(0, xW_1 + b_1)W_2 + b_2
      ↓ + Residual: output = LayerNorm(X' + FFN(X'))

**层归一化（LayerNorm）** 对每个位置跨特征维度归一化，而非像 BatchNorm 那样跨位置归一化。对变长输入的序列模型，LayerNorm 更受青睐。

**前馈网络（FFN）：** 独立应用于每个位置（所有位置共享权重——又一种权重共享）。通常 d_\text{ff} = 4 d_\text{model}（4 倍扩张）。这是模型大部分"知识"存储之处——近期研究表明 FFN 层类似键-值记忆。


### 20.6 编码器-解码器架构

原始 Transformer 用于机器翻译时采用编码器-解码器架构。

**编码器：** N 个 Transformer 块堆叠。读取源序列并生成上下文表示。

**解码器：** N 个 Transformer 块堆叠。逐 token 生成目标序列。两种注意力：

  1. **掩码自注意力：** 只关注先前目标 token（因果性——生成时不能看到未来目标）
  2. **交叉注意力：** 查询来自解码器；键和值来自编码器输出。解码器通过这种方式"读取"源句。

**分类任务**（如情感分析）只用编码器。在 [CLS] token（或所有 token 表示的平均）上加分类头。
