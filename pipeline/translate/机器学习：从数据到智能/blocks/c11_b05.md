#### 概念检测

**Q1.** 一个随机森林的 10 棵树对回归问题的预测为：[24, 27, 22, 31, 26, 25, 29, 23, 28, 25]。最终预测是什么？

**答案：** 最终预测是所有 10 棵树预测的平均：

\hat{y} = \frac{24 + 27 + 22 + 31 + 26 + 25 + 29 + 23 + 28 + 25}{10} = \frac{260}{10} = 26.0

注意：有些树高得多（31）或低得多（22）。集成把它们平滑掉了。单棵预测 31 的树与单棵预测 22 的树差异巨大，而集成的 26.0 比任一极端都更可靠。

**Q2.** 用偏差和方差的概念，用平实的语言解释为什么随机森林在未见数据上通常优于单棵决策树。

**答案：** 单棵深决策树偏差低（能拟合复杂模式）但方差很高（训练数据微小变化就产生很不同的树）。就像只问一个嘈杂的专家——他们可能对，也可能大错特错。

随机森林保持低偏差（每棵树仍然深且复杂），但通过平均多棵树大幅降低方差。平均有效是因为树的错误相对独立——一棵树在某个方向上错时，另一棵树可能在另一个方向上错，错误部分抵消。关键是信号（真实模式）在各树间一致，不会抵消。

结果：集成与单棵树偏差相近，但方差小得多——测试性能更好，且不牺牲模型容量。

**Q3.** 梯度提升中，学习率 \eta 是超参数。若 \eta = 1.0，每棵树直接以全权重预测当前残差。风险是什么？\eta < 1 如何解决？

**答案：** \eta = 1.0 时，每棵树试图完全拟合当前残差。但树拟合不完美（尤其深度有限），且每棵树自身有方差。如果树过拟合残差（记住噪声），后续树会放大这些错误——修正噪声而非信号。提升过程会变得不稳定。

\eta < 1（例如 \eta = 0.05）时，每棵树只贡献其修正量的一小部分。这迫使集成每步都做小且保守的修正，需要更多树但泛化更好。模型"缓慢而稳定地接近最优"，而不是对单棵树的噪声修正过度承诺。小 \eta 配合早停（验证误差开始上升时停止）是调好梯度提升的标准配方。

**Q4.** 什么是袋外（OOB）误差估计？为什么它是随机森林的有用性质？

**答案：** 随机森林中每棵树在包含约 63% 训练样本的 bootstrap 样本上训练。剩下的 37%——即该树的 **袋外（out-of-bag, OOB）样本**——未用于训练这棵树。对每个训练样本，可以找到所有 *没有* 用它训练的树，用这些树预测其标签并度量误差。所有训练样本的平均即为 OOB 误差估计。
