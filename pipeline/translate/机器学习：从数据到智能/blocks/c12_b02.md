#### 定义：软间隔支持向量机（SVM）

**软间隔 SVM** 允许部分样本违反间隔（甚至被误分类），引入 **松弛变量（slack variables）** \xi_i \geq 0：

\min_{\mathbf{w}, b, \boldsymbol{\xi}} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^m \xi_i \quad \text{subject to} \quad y_i(\mathbf{w}^\top \mathbf{x}_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0 \quad \forall i

参数 C > 0 控制权衡：

* **大 C**：严重惩罚违反 → 小间隔、少违反（接近硬间隔）
* **小 C**：允许更多违反以换取更宽间隔（更正则化）

这与第6章正则化的联系：小 C 对应岭回归（Ridge regression）中的大 \lambda——更愿意容忍训练错误以换取更小权重和更好泛化。

软间隔 SVM 可重写为 hinge loss 形式：

\min_\mathbf{w} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^m \max(0, 1 - y_i(\mathbf{w}^\top \mathbf{x}_i + b))

这是带 **hinge 损失** \ell(z) = \max(0, 1 - z) 的正则化损失，当样本以间隔 \geq 1 正确分类时损失为零。


#### 常见误解

学生常认为 SVM 总优于逻辑回归，因为 SVM 最大化间隔。实际上，在大多数真实数据集上，经过适当正则化后两者差异很小。SVM 真正的优势是核技巧（下一节），它能高效地获得非线性边界。


### 11.3 核技巧：无限维特征空间

SVM 目标可以只用数据点之间的 **点积** 重写。这是启用核技巧的关键观察。

通过拉格朗日乘子的 SVM 对偶形式涉及：

\max_{\boldsymbol{\alpha}} \sum_i \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j \mathbf{x}_i^\top \mathbf{x}_j

数据只通过点积 \mathbf{x}_i^\top \mathbf{x}_j 出现。
