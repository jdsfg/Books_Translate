#### 深入思考

**Q1.** SVM 解只依赖于支持向量。这表明间隔由"最困难"（最边缘）的样本决定。相比之下，逻辑回归受所有训练样本影响，远离边界的样本影响较小但仍有贡献。这一差异对异常值、噪声标签和实际部署有何影响？

**讨论：**

**异常值：** 对 *不靠近边界* 的异常值，SVM 更稳健（它们不会成为支持向量，影响为零）。但 *靠近边界* 的异常值可能成为支持向量并显著扭曲间隔——可能比逻辑回归更糟，因为逻辑回归对所有样本取平均。软间隔 SVM（合适 C）通过松弛变量限制每个样本影响。

**噪声标签：** 若一个标错标签的样本落在错误一侧的间隔上，它会成为支持向量并拉拽边界。小 C 时软间隔吸收它（高松弛、低影响）。大 C 时它显著扭曲边界。逻辑回归把标签噪声分散到所有样本，稀释其影响。

**实际部署：** SVM 的稀疏性（只有支持向量重要）既是优势（预测快、模型紧凑）也是弱点（模型可能对恰好成为支持向量的具体样本非常敏感）。训练集稍有不同，支持向量和边界可能完全不同。这是 SVM 在支持向量附近的高方差特性。交叉验证和合适 C 可缓解。

**Q2.** SVM 即使在特征数 p 远大于训练样本数 m 时也能很好泛化——即 p \gg m 区间，经典统计智慧认为泛化不可能。为什么会这样？请结合 VC 维理论和间隔的作用回答。

**讨论：** 经典直觉是，参数多于训练样本的模型总能完美拟合训练数据（因此过拟合）。对大多数模型族，p \gg m 意味着 VC 维超过样本数，经典泛化界 O(\sqrt{d_{\text{VC}} / m}) 变得空洞（大于 1，无保证）。

**SVM 不同：间隔挽救泛化。** SVM 理论的关键洞见是，相关复杂度度量不是维度，而是 **间隔**。fat-shattering 维（以及相关的基于间隔的 VC 界）取决于间隔 \gamma 和权重向量范数 \|\mathbf{w}\|，而非环境维度 p。

形式上，对数据半径 \|\mathbf{x}_i\| \leq R 的线性分类器，间隔为 \gamma，泛化界形如：

\text{Test error} \leq \text{Train error} + O\!\left(\sqrt{\frac{R^2 / \gamma^2}{m}}\right)

关键量 R^2 / \gamma^2 是数据半径与间隔之比的平方——它控制复杂度。p 不出现。百万维空间中的大间隔分类器若间隔同样大，其泛化能力与二维空间中的大间隔分类器一样好。
