#### 应用问题

**Q1.** 你正在构建一个垃圾邮件分类器，有 10,000 个词特征。你预计只有约 50–100 个词对区分垃圾邮件和非垃圾邮件真正有用。该用哪种正则化？为什么？随着 \lambda 从 0 增加，正则化路径大概长什么样？

*提示*

想想 Lasso 与 Ridge 的特征选择性质。最终模型你预计有多少非零权重？

**答案：** 用 **Lasso**。在 10,000 个特征中只有约 50–100 个真正预测性强时，需要一个能显式把 9,900 个无关特征权重设为零的模型。Ridge 会保留全部 10,000 个特征，只是权重很小，使模型不可解释且可能过拟合。Lasso 的稀疏性质天然适合这种"大海捞针"的特征选择问题。

正则化路径：\lambda = 0（OLS）时，全部 10,000 个特征权重非零。随着 \lambda 从 0 增加，最弱的特征最先被置零。\lambda 继续增大，越来越多特征归零。最后只剩约 50–100 个真正预测 spam 的词（如 "WINNER"、"FREE"、"click here"、"unsubscribe"）。\lambda 非常大时，这些也被压到零，模型总是预测"非垃圾邮件"。

实际注：Naive Bayes 和 Lasso 逻辑回归都用于文本分类。Thread B（第7章）将把逻辑回归用于情感分析，正则化对高维 bag-of-words 特征至关重要。

**Q2.** 一个线性回归模型有 n = 5 个特征、m = 1,000 个样本，先用 OLS 拟合，再用 Ridge（\lambda = 0.01）和 Lasso（\lambda = 0.01）拟合。按期望训练误差从低到高排序并解释。然后假设真实模型只用 2 个特征，按期望测试误差排序。

**答案：**

**训练误差（低到高）：** OLS < Lasso \approx Ridge

OLS 训练误差最低，因为它无约束地最小化训练 MSE。Ridge 和 Lasso 为了最小化正则化项，牺牲了部分训练拟合，训练误差更高。

**测试误差（低到高）：** Lasso < Ridge < OLS

由于真实模型只用 2 个特征，其余 3 个是噪声。OLS 会拟合这些噪声特征，增加方差。Ridge 收缩但不消除它们。Lasso 把它们设为零（给定合适 \lambda），恢复到接近真实的 2 特征模型——偏差最低，也不会把方差浪费在无关特征上。

这个例子完美说明 bias-variance tradeoff：OLS 在训练数据上偏差最低但方差最高；Lasso 偏差略高但方差低得多，当真实模型稀疏时尤其如此。
