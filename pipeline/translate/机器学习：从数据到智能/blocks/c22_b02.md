### 21.3 BERT：基于掩码语言模型的预训练

**BERT（Bidirectional Encoder Representations from Transformers）** 采用另一种预训练方法：**掩码语言建模（Masked Language Modeling, MLM）**。

随机遮挡 15% 的输入 token（替换为 [MASK] token）。训练模型根据周围上下文预测被遮挡 token：

L_\text{MLM} = -\sum_{i \in \text{masked}} \log P(x_i \mid \text{other tokens})

与 GPT 不同，BERT 是双向的：每个位置可以关注所有其他位置（无因果掩码）。这产生更丰富的上下文表示——"bank" 的表示可利用前面 "river" 和后面 "was flooded" 两个方向，判断这是地理意义上的河岸。

**BERT 的第二预训练任务：** 下一句预测（NSP）——给定两个句子，预测第二句是否紧随第一句。（后续研究表明它不太重要；RoBERTa 去掉它而无性能损失。）

**BERT 微调：** 在 [CLS] token 表示或所有 token 表示之上添加任务特定头（如线性层），然后在标注数据上微调。


#### GPT vs. BERT：何时用哪个

| 特性 | GPT（因果） | BERT（双向） |
|---|---|---|
| 预训练任务 | 下一个 token 预测 | 掩码 token 预测 |
| 架构 | 解码器 | 编码器 |
| 最适合 | 生成（文本、代码、对话） | 分类、抽取、NLU |
| 上下文 | 只能看过去 | 完整双向上下文 |


### 21.4 缩放定律：为什么越大越好

Kaplan 等人（2020）表明，语言模型性能随以下因素呈平滑幂律：

* **模型大小** N（参数）：L \propto N^{-0.076}
* **数据量** D（token）：L \propto D^{-0.095}
* **计算量** C（FLOPS）：L \propto C^{-0.050}

这些定律跨越多个数量级成立。实用含义：改进语言模型可以 (1) 增大模型、(2) 用更多数据训练 或 (3) 训练更久。三个维度同时缩放带来最高效提升。

**计算最优前沿（Chinchilla 缩放）：** 给定计算预算，最优模型大小与数据量是多少？Hoffmann 等人（2022）证明原始 GPT-3 "训练不足"——用相同计算量，更小模型 + 更多数据能达到更好性能。"Chinchilla" 模型（70B 参数，1.4 万亿 token）匹配了 GPT-3（175B 参数，3000 亿 token），而计算量仅为 1/4。

**涌现能力：** 超过某些规模阈值（约 1000 亿参数）后，会突然出现定性新能力——模型能进行少样本推理、多步数学、代码调试，以及从未显式训练过的任务。这些"涌现能力"无法由基于损失的平滑缩放定律预测——它们代表模型能力的相变。
