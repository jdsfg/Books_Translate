#### 深入思考

**Q1.** 线性回归的 MLE（最小化 MSE）假设噪声是高斯的。如果我们改为假设噪声服从 *Laplace* 分布 f(\epsilon) = \frac{1}{2b}\exp(-|\epsilon|/b)，损失函数会是什么形式？它对应哪种著名的稳健回归方法？为什么对含异常值的数据集更合适？

**讨论：** Laplace 分布的 PDF 为 f(\epsilon) = \frac{1}{2b}\exp(-|\epsilon|/b)。对含 Laplace 噪声的数据取对数似然：

\ell(\mathbf{w}) = \sum_{i=1}^m \log f(y_i - \mathbf{w}^\top \mathbf{x}_i) = -m\log(2b) - \frac{1}{b}\sum_{i=1}^m |y_i - \mathbf{w}^\top \mathbf{x}_i|

最大化它（即最小化负对数似然）等价于最小化 \sum_i |y_i - \mathbf{w}^\top \mathbf{x}_i| —— 即 **MAE（Mean Absolute Error，平均绝对误差）** 或 **\ell_1 损失**。

这对应 **LAD（Least Absolute Deviations，最小绝对偏差）回归**，也叫"中位数回归"，是 OLS 的更稳健替代。

为什么对异常值更稳健？高斯分布的尾部很轻——它给大偏差分配极低概率，因此单个大残差的异常值会急剧增加 MSE。Laplace 分布尾部更重，大偏差不那么灾难性。几何上，MAE 损失随误差线性增长，而 MSE 损失随误差*平方*增长。远离回归线的数据点对 MAE 的贡献远小于对 MSE 的贡献，因此异常值影响更小。这就是为什么用 MAE 训练的模型对错误标注或测量误差更稳健。

**Q2.** 形式化证明：最小化交叉熵损失等价于在类别分布下最大化训练数据的对数似然。这对大多数分类神经网络意味着什么？

**讨论：** 考虑一个 K 类分类问题。模型对每个样本 i 输出一个概率分布 \hat{\mathbf{p}}_i = (\hat{p}_{i1}, \ldots, \hat{p}_{iK})，通常来自 softmax 层。真实标签 y_i \in \{1, \ldots, K\} 是一个 one-hot 类别观测。

**MLE 推导。** 类别分布给出 P(y_i = k | \mathbf{x}_i) = \hat{p}_{ik}。整个训练集的对数似然（假设 i.i.d.）为：

\ell = \sum_{i=1}^m \log P(y_i | \mathbf{x}_i) = \sum_{i=1}^m \log \hat{p}_{i, y_i} = \sum_{i=1}^m \sum_{k=1}^K \mathbf{1}[y_i = k] \log \hat{p}_{ik}

乘以 -1 把最大化变成最小化，就得到 **交叉熵损失**：

\mathcal{L}_{\text{CE}} = -\frac{1}{m}\sum_{i=1}^m \sum_{k=1}^K \mathbf{1}[y_i = k] \log \hat{p}_{ik}

两者等价：最小化交叉熵与在类别分布下最大化对数似然完全相同。
