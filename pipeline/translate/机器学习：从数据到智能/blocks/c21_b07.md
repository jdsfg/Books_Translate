#### 深入思考

**Q1.** Transformer 的自注意力是一种"软"检索机制：给定查询，返回所有值的加权组合，权重取决于查询-键相似度。这与"硬"键值数据库（查找精确键并返回对应值）有何关系？各有什么优缺点？

**讨论：** 硬键值数据库：给定查询 q，找到最接近的键 k，返回其值 v。这是 1-最近邻操作——离散且确定性。

软注意力：给定查询 q，返回 \sum_i \text{softmax}(q \cdot k_i / \sqrt{d}) \cdot v_i——所有值的加权平均，权重基于查询-键相似度。

**软注意力的优点：**

  1. **可微：** 梯度通过 softmax 和点积流动，支持端到端训练
  2. **组合式检索：** 可混合多个相关条目的信息，而非只取最相似的一个
  3. **处理不确定性：** 当多个条目相关（查询有歧义）时，软注意力适当地综合它们
  4. **对噪声鲁棒：** 键的小扰动不会导致输出剧烈变化（权重连续平滑变化）

**硬检索的优点：**

  1. **效率：** O(\log N) 查找 vs 精确软注意力 O(N)（不过两者都有 ANN 近似）
  2. **可解释性：** "检索到它是因为精确匹配"
  3. **精确事实：** 当你需要精确值（如人名拼写），软平均可能通过混合略有不同的事实而"幻觉"

这一比较揭示了 LLM 为何"幻觉"：它们用软注意力混合知识，当知识有歧义或冲突时，混合可能产生流畅但事实错误的平均值。检索增强生成（RAG）将软注意力与硬检索结合：用 LLM 推理，但在需要精确度时从数据库检索精确事实。


### 本章总结

Transformer 架构用并行自注意力取代顺序循环，使长程依赖直接建模和训练大幅提速成为可能。

核心思想：

* **缩放点积注意力** ：\text{Attention}(Q, K, V) = \text{softmax}(QK^\top / \sqrt{d_k}) V；以查询-键相似度为权重对值加权平均
* **多头注意力** ：h 个并行注意力，每个学习不同关系类型
* **位置编码** ：正弦/余弦（或可学习）编码注入位置信息
* **Transformer 块** ：多头注意力 + 残差 + LayerNorm + FFN + 残差 + LayerNorm
* **编码器-解码器** ：编码器读取源；解码器用掩码自注意力 + 交叉注意力生成目标

**Thread B 检查点（B4）：** Transformer 在情感分析上达到 **94% 准确率**——比 LSTM 更好，且因并行性训练更快。模型学会直接关注否定词和情感词，无论距离多远。

第21章将 Transformer 推向其逻辑结论：在数十亿词文本上预训练巨型 Transformer，再微调任何下游任务。这是 GPT、BERT 和每个现代大语言模型背后的配方。
