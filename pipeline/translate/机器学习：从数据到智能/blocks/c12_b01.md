考虑一个二分类问题，两类可以被一条直线完美分开。存在无数条直线能分开它们——该选哪一条？

逻辑回归可能会选择一条刚好分开两类、穿过某些训练样本附近的线。数据的微小扰动就可能把这些样本推到错误一侧。直觉上，我们想要一条尽可能远离两类的线——在误判之前留有最大"余地"的边界。

这就是支持向量机（Support Vector Machine, SVM）的核心思想：寻找最大间隔分类器。该算法优雅、理论扎实，并且通过一种称为 *核技巧（kernel trick）* 的惊人技巧，可以扩展到无限维特征空间中的非线性边界。


### 11.1 最大间隔分类器

假设类别 +1 和类别 -1 的样本被超平面 \mathbf{w}^\top \mathbf{x} + b = 0 分开。**间隔（margin）** 是两个类之间"街道"的宽度——即分隔超平面到最近点距离的两倍。


#### 定义：硬间隔 SVM

对标签 y_i \in \{-1, +1\} 的线性可分数据，**硬间隔 SVM** 寻找最大间隔超平面：

\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 \quad \text{subject to} \quad y_i(\mathbf{w}^\top \mathbf{x}_i + b) \geq 1 \quad \forall i

用平实的语言：找到最小范数的权重向量 \mathbf{w}，使得所有样本都被正确分类且间隔至少为 1（按 \|\mathbf{w}\| 缩放）。间隔为 2/\|\mathbf{w}\|，因此最小化 \|\mathbf{w}\|^2 就是最大化间隔。

恰好落在间隔边界 y_i(\mathbf{w}^\top \mathbf{x}_i + b) = 1 上的样本称为 **支持向量（support vectors）**——只有这些训练样本决定决策边界。移动非支持向量，边界不变。这与逻辑回归形成鲜明对比：逻辑回归中所有训练样本都影响决策边界。

**几何解释：** 间隔超平面 \mathbf{w}^\top \mathbf{x} + b = +1 和 \mathbf{w}^\top \mathbf{x} + b = -1 定义了一条宽度为 2/\|\mathbf{w}\| 的"通道"。SVM 找到能分开两类的最宽通道。


### 11.2 软间隔 SVM：处理不可分数据

真实数据几乎从不完全线性可分。某些样本可能是异常值或标错。硬间隔 SVM 将无法找到任何解。
