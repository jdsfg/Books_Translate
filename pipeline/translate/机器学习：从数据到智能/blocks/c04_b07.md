#### 概念检测

**Q1.** 某种疾病筛查：人群中有 1% 患病。该测试对真阳性的准确率为 95%（sensitivity = 95%），对真阴性的准确率为 90%（specificity = 90%）。如果你测出阳性，实际患病的概率是多少？

*提示*

用贝叶斯定理建立计算：先验 P(disease) = 0.01，似然 P(positive test | disease) = 0.95，似然 P(positive test | no disease) = 1 - 0.90 = 0.10。

**答案：** 定义事件：D = 患病，+ = 测试阳性。

先验：P(D) = 0.01，P(\text{not } D) = 0.99

似然：P(+ | D) = 0.95，P(+ | \text{not } D) = 1 - 0.90 = 0.10

证据：

P(+) = P(+ | D) \cdot P(D) + P(+ | \text{not } D) \cdot P(\text{not } D) = 0.95 \times 0.01 + 0.10 \times 0.99 = 0.0095 + 0.099 = 0.1085

后验：

P(D | +) = \frac{P(+ | D) \cdot P(D)}{P(+)} = \frac{0.95 \times 0.01}{0.1085} = \frac{0.0095}{0.1085} \approx 0.0876

只有约 **8.76%** —— 测出阳性的人中不到十分之一真的患病。这个反直觉的结果是因为疾病本身罕见（先验仅 1%）。大多数阳性来自健康人群中的假阳性（99% 的 10% = 9.9%）。这一现象称为 "base rate fallacy"（基率谬误），在医疗 AI、欺诈检测以及任何低患病率 ML 任务中都极为相关。

**Q2.** 设 X \sim \mathcal{N}(2, 9)（均值 2，方差 9，标准差 3）。计算 P(X > 5) 和 P(-1 < X < 5)。

**答案：** 标准化为 Z = (X - 2) / 3 \sim \mathcal{N}(0, 1)。

P(X > 5) = P(Z > (5 - 2) / 3) = P(Z > 1) = 1 - \Phi(1) \approx 1 - 0.8413 = 0.1587

其中 \Phi 是标准正态 CDF。

P(-1 < X < 5) = P((-1 - 2) / 3 < Z < (5 - 2) / 3) = P(-1 < Z < 1) = \Phi(1) - \Phi(-1) = 0.8413 - 0.1587 = 0.6827

这就是熟悉的 68% 规则：大约 68% 的高斯分布概率落在均值的一个标准差范围内。

**Q3.** 用自己的话解释 P(H | D) 与 P(D | H) 的区别。举一个具体 ML 例子，说明混淆二者会导致严重错误。

**答案：** P(H | D) 是在观察到数据 D 后假设 H 为真的概率——这是看到证据后我们想知道的。P(D | H) 是假设 H 为真时观察到 D 的概率——这通常容易从模型计算得到。
