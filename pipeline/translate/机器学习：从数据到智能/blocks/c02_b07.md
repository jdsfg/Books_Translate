#### 应用问题

**Q1.** 你正在为一家大公司构建一个筛选求职申请的模型。公司拥有五年历史数据：求职申请以及申请人是否被录用。请描述该问题的完整 ML 流水线，并指出模型在部署时可能失败的 *至少两种方式*。

*提示*

仔细思考标签代表什么，以及"被录用"是否等同于"会是优秀员工"。

**答案：** 流水线如下。第一步，问题定义：给定从求职申请中提取的特征（教育、经验、关键词），预测申请人是否应进入面试阶段。第二步，数据收集：标注为"录用"或"未录用"的历史申请。第三步，预处理：处理缺失字段、编码类别变量（学校名称、学位类型）、归一化数值特征（工作年限）。第四步，特征工程：可能从求职信中提取关键词、计算毕业至今年限等。第五步，训练模型（逻辑回归或梯度提升树是自然起点）。第六步，用精确率、召回率和公平性指标在 held-out 测试集上评估。第七步，部署并监控。

部署时可能失败的两种方式：

**(i) 标签编码了历史偏见。** "被录用"反映的是过去人类经理的招聘决策，他们可能（有意或无意）对特定人群存在偏见。模型学会了大规模复制这些偏见。如果过去经理录用的女性工程师较少，模型可能学会降低女性申请的优先级——不是因为它有性别特征，而是因为相关的代理变量（如学校名称或用词选择）隐式编码了性别。

**(ii) 反馈环 / 分布漂移。** 一旦模型筛选申请，公司只会面试（并可能录用）模型批准的申请人。公司永远不会知道被模型拒绝的人是否本来优秀。随着时间推移，训练分布向模型自己先前的决策偏移，强化其初始偏见，并可能降低质量。

**Q2.** 对每个以下场景，判断主要失败模式可能是高偏差还是高方差，并解释原因：

* (a) 一个用于图像识别的线性模型在训练数据上达到 51% 准确率，在测试数据上达到 49% 准确率
* (b) 一个100层神经网络在训练数据上达到 100% 准确率，在测试数据上达到 55% 准确率

**答案：** **(a) 高偏差（欠拟合）。** 模型在训练数据上表现也不好——51% 的准确率对典型分类问题来说不比随机猜测好多少。把线性模型应用于原始图像像素，其表达能力极其有限，无法捕捉区分不同类别的非线性模式（边缘、纹理、形状）。增加模型复杂度（换成 CNN）会显著降低偏差。训练准确率和测试准确率之间的差距很小，说明问题不是过拟合，而是能力不足。
