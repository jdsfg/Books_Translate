给定 10 个示例提示时，GPT-3 使用 **上下文学习**：把示例视为指定"影评文本到情感标签"映射的"模式"，并将该模式应用于测试评论。模型在预训练中见过数十亿（文本，标签/分类）模式，非常擅长续写此类模式。

这不需要梯度更新——模型根据上下文结构从预训练分布中"检索"正确的输入-输出模式。这与人类读两个 "new word: definition :: new word applied in sentence" 示例后立即正确使用该词是同一机制。

**Q4.** 解释为什么 RLHF 对把 GPT-3 变成 ChatGPT 是必要的。纯下一个 token 预测训练模型用作对话助手有什么问题？

**答案：** 纯在互联网文本上用下一个 token 预测训练的模型学会预测互联网文本中接下来出现的内容——包括垃圾信息、错误信息、仇恨言论、阴谋论和有害内容。预训练目标没有 helpfulness、honesty、harmlessness 概念。

被问问题时，纯 GPT 可能这样"续写"文本模式：

* 给出看似合理但编造的答案（优化流畅度而非准确率）
* 续写与互联网平均回复一致的答案（可能错误或低质量）
* 若训练数据存在，可能生成有害内容

RLHF 在人类偏好上训练奖励模型（人类评分者比较两个回复并选择更好的）。该奖励模型编码人类价值观：准确、简洁、安全、有帮助的回复获得更高奖励。然后用 RL（PPO）优化 LLM 以最大化奖励。

结果：模型学到的不仅是文本中接下来出现什么，还有 *有帮助、诚实、无害的助手* 会怎么回答。这些指令（"Be helpful and concise"）从人类反馈中学习，而非仅从文本模式。这就是 ChatGPT 与原始 GPT-3 续写截然不同的原因。

**Q5.** Chinchilla 缩放定律（Hoffmann 等，2022）指出，固定计算预算下，最优训练 token 数 D 与模型大小 N 成正比。GPT-3 用 N=175B 参数在 D=300B token 上训练。Chinchilla 结果表明计算最优比例约为 D \approx 20N。就数据而言，GPT-3 是训练过度还是不足，大约差多少倍？

**答案：** GPT-3 模型大小对应的计算最优数据量：

D_\text{optimal} \approx 20 \times N = 20 \times 175\text{B} = 3,500\text{B tokens}

GPT-3 只在 300B token 上训练，是 Chinchilla 最优量的 3,500 / 300 \approx 11.7 倍。GPT-3 **训练不足**——它的 175B 参数本可以从多得多的数据中学习。

这一发现有重大实用含义：用更小模型 + 更多数据就能匹配 GPT-3 性能。Chinchilla 模型（70B 参数，1.4T token）证实了这一点——以少 4 倍计算量达到或超过 GPT-3。后续模型如 Llama 在设计时就考虑 Chinchilla 比例，使其训练和部署都更高效（小模型推断更快）。
