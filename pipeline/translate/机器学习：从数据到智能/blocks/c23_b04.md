### 22.5 实验管理

**可复现性** 是 ML 中最被低估的实践技能之一。无法复现的实验毫无价值。

**每次实验应记录：**

  1. 代码版本（git commit hash）
  2. 数据版本（数据集 hash 或版本号）
  3. 超参数（全部）
  4. 训练指标（每轮 loss、验证指标）
  5. 测试指标（仅在最终模型选择后评估一次）
  6. 环境（库版本、硬件）
  7. 随机种子

**工具：** MLflow（开源）、Weights & Biases（W&B）、Comet ML。均提供：实验跟踪、模型注册、对比看板、产物存储。

**一个最小可复现 ML 实验：**

    import random, numpy as np, torch

    # Set all random seeds
    random.seed(42); np.random.seed(42); torch.manual_seed(42)

    # Log hyperparameters
    config = {"lr": 0.001, "batch_size": 64, "epochs": 50, "dropout": 0.5}

    # Train model
    model = MyModel(**config)
    train(model, config)

    # Evaluate on test set (ONCE, at the end)
    test_metrics = evaluate(model, test_data)
