#### 概念检测

**Q1.** 计算 f(x) = 3x^4 - 2x^2 + 5\log(x) - 7 的导数。

**答案：**

f'(x) = 3 \cdot 4x^3 - 2 \cdot 2x + 5 \cdot \frac{1}{x} - 0 = 12x^3 - 4x + \frac{5}{x}

**Q2.** 用链式法则求 g(x) = \log(\sigma(x)) 的导数，其中 \sigma(x) = \frac{1}{1 + e^{-x}} 是 sigmoid 函数。

*提示*

先计算 \sigma'(x)，再对 \log(\sigma(x)) 用链式法则。

**答案：** 先求 \sigma'(x)。令 u = 1 + e^{-x}，则 \sigma = 1/u。

\sigma'(x) = -\frac{1}{u^2} \cdot (-e^{-x}) = \frac{e^{-x}}{(1 + e^{-x})^2}

可以化简：\sigma'(x) = \sigma(x)(1 - \sigma(x))。验证：

\frac{e^{-x}}{(1 + e^{-x})^2} = \frac{1}{1 + e^{-x}} \cdot \frac{e^{-x}}{1 + e^{-x}} = \sigma(x) \cdot (1 - \sigma(x))

现在对 g(x) = \log(\sigma(x)) 用链式法则：

g'(x) = \frac{1}{\sigma(x)} \cdot \sigma'(x) = \frac{1}{\sigma(x)} \cdot \sigma(x)(1 - \sigma(x)) = 1 - \sigma(x)

这就是 log-sigmoid 函数的梯度——它直接出现在逻辑回归损失的梯度中（第7章）。结果非常简洁：g'(x) = 1 - \sigma(x)。当 x 很大且为正（预测很强）时，\sigma(x) \approx 1，于是 g'(x) \approx 0，意味着梯度几乎为零，不需要太多更新。

**Q3.** 对 f(w_1, w_2) = (w_1 - 2)^2 + 3(w_2 + 1)^2，在点 (1, 2) 处计算梯度 \nabla f，并判断梯度下降应朝哪个方向迈步。

**答案：**

\frac{\partial f}{\partial w_1} = 2(w_1 - 2), \quad \frac{\partial f}{\partial w_2} = 6(w_2 + 1)

在 (1, 2) 处：

\nabla f(1, 2) = \begin{pmatrix} 2(1 - 2) \\ 6(2 + 1) \end{pmatrix} = \begin{pmatrix} -2 \\ 18 \end{pmatrix}

梯度下降沿 *负梯度* 方向迈步：-(-2, 18) = (2, -18)（未归一化）。因此从 (1, 2) 出发，我们朝 w_1 增加、w_2 减少的方向移动——这很合理，因为最小值在 (2, -1)。

最小值满足 \nabla f = \mathbf{0}：w_1 = 2，w_2 = -1。可验证 f(2, -1) = 0，确实是这个凸函数的全局最小值。

**Q4.** f(w) = w^4 - 4w^2 是否凸？找出所有局部和全局最小值。

**答案：** 二阶导数 f''(w) = 12w^2 - 8。在 w = 0 处 f''(0) = -8 < 0，因此 f 不是处处凸的（在原点向下弯曲）。这是一个非凸函数。
