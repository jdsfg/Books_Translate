#### 应用问题

**Q1.** 你有一个电影评分数据集，每个用户的观影历史表示为 \mathbb{R}^{10000} 中的一个向量（每个电影一维，看过为 1，未看过为 0）。你想找到品味相似的用户。解释为什么单独使用点积在这里不是一个好的相似度度量，并描述更好的替代方案。

*提示*

想想一个用户看过 500 部电影，另一个只看过 5 部电影会怎样。

**答案：** 点积 \mathbf{x} \cdot \mathbf{y} 计算的是两位用户都看过的电影数量。一个看过 5,000 部电影的用户几乎与任何人都有点积——因为庞大的观影量自然产生大量重叠。他们的品味偏好不一定相似，只是看得更多。

更好的度量是 **余弦相似度（cosine similarity）**：

\text{cosim}(\mathbf{x}, \mathbf{y}) = \frac{\mathbf{x} \cdot \mathbf{y}}{\|\mathbf{x}\| \|\mathbf{y}\|}

它对每个向量的长度做了归一化，因此度量的是用户之间的夹角，而非共同观看电影的绝对数量。两位观影量差异很大的用户，只要看过的电影大量重叠，仍可以有接近 1 的余弦相似度。

具体地：如果用户 A 看过 5 部特定电影，用户 B 看过同样的 5 部电影外加 1,000 部其他电影，点积为 5（只反映 5 部共同电影），但余弦相似度为 5 / (5 \cdot \sqrt{1005}) \approx 0.0325 \approx 0.032—— correctly 说明他们口味不太相似。

**Q2.** 向量的 \ell_1 范数是 \|\mathbf{x}\|_1 = \sum_i |x_i|。比较 \mathbf{x} = (3, 4, 0, 0) 和 \mathbf{y} = (5/2, 5/2, 5/2, 5/2) 的 \ell_1 与 \ell_2 范数。两个向量的 \ell_2 范数相同。哪个的 \ell_1 范数更大？这对两种范数如何奖励或惩罚稀疏性说明了什么？

**答案：** 对稀疏（只有 2 个非零元）的 \mathbf{x} = (3, 4, 0, 0)：

\|\mathbf{x}\|_2 = \sqrt{9 + 16 + 0 + 0} = 5, \quad \|\mathbf{x}\|_1 = 3 + 4 + 0 + 0 = 7

对稠密（4 个元均非零）的 \mathbf{y} = (5/2, 5/2, 5/2, 5/2)：

\|\mathbf{y}\|_2 = \sqrt{4 \times (5/2)^2} = \sqrt{25} = 5, \quad \|\mathbf{y}\|_1 = 4 \times \frac{5}{2} = 10

两个向量的 \ell_2 范数都是 5，但稠密向量 y 的 \ell_1 范数更大（10 对 7）。

**解释：** \ell_1 范数 *penalizes spread*（惩罚分散）：在 \ell_2 范数相同的条件下，稠密向量（多个非零元）的 \ell_1 范数高于稀疏向量（少量非零元）。因此，在优化问题中把 \ell_1 范数作为正则项（Lasso，第6章）会鼓励稀疏解——优化器发现把许多权重精确设为零，比分摊到很多权重上"更便宜"。这一性质是高维问题中 *feature selection*（特征选择）的核心。
