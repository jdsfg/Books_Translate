#### 应用问题

**Q1.** 你正在用 RBF 核 SVM 训练，C = 1、\gamma = 0.01。观察到训练准确率 65%，测试准确率 63%。然后尝试 C = 1000、\gamma = 100：训练准确率 100%，测试准确率 55%。描述每种设置的偏差-方差情况，并提出更好的做法。

*提示*

第一种设置训练准确率低；第二种训练与测试准确率差距大。

**答案：**

**第一种设置（C = 1, \gamma = 0.01）：高偏差、低方差。** 小 C 表示模型被强正则化（宽间隔，允许许多违反）。小 \gamma 意味着所有样本对的相似性几乎相同。模型太简单——几乎是线性分类器，无法捕捉数据的非线性结构。训练 65%、测试 63%，两者接近（泛化差距小），证实是高偏差而非过拟合。

**第二种设置（C = 1000, \gamma = 100）：低偏差、高方差。** 大 C 接近硬间隔（不允许违反）。大 \gamma 意味着每个训练点几乎是孤立岛屿。模型记住每个训练样本（100% 训练准确率）但无法泛化（55% 测试准确率——比第一种还差！）。这是严重过拟合。

**更好做法：** 用 5 折交叉验证搜索 (C, \gamma) 网格。典型网格：C \in \{0.1, 1, 10, 100, 1000\}，\gamma \in \{0.001, 0.01, 0.1, 1, 10\}。最优点可能在 C = 10, \gamma = 0.1 附近——足够灵活捕捉非线性模式但不过拟合噪声。训练前先标准化特征（RBF 核对特征尺度敏感）。

**Q2.** 解释为什么 RBF 核 SVM 理论上能完美分离 *任何* 数据集（所有输入互异）。这是否意味着它们总能完美泛化？

**答案：** 当 \gamma 足够大时，RBF 核对任意两个不同点赋予接近零的相似性。极限情况下，每个训练样本在特征空间中占据一个孤立的"岛屿"，有自己的支持向量。SVM 可以独立地为每个样本赋予任意标签——训练准确率完美。

不，这绝不意味着完美泛化。对新测试点，SVM 基于与支持向量的相似性预测。若 \gamma 极大，每个测试点离所有训练样本都"太远"，预测就只是偏置项 b。模型记住了训练集，但没有信息泛化。

这说明过拟合风险：核模型 100% 训练准确率是警告信号，不是目标。模型必须平衡拟合训练数据（由 C 控制）和泛化到新点（由 \gamma 控制）。两个超参数都需仔细调优。
