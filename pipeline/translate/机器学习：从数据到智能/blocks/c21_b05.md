#### 概念检测

**Q1.** 缩放点积注意力中，为何要除以 \sqrt{d_k}？

**答案：** 当 d_k 较大时，点积 q_i \cdot k_j = \sum_{l=1}^{d_k} q_{il} k_{jl} 的幅度约为 O(\sqrt{d_k})（若 q, k 的分量是单位方差）。每个点积的方差为 d_k。大的点积把 softmax 推到接近 one-hot 的区域（除最大值外梯度极小）。除以 \sqrt{d_k} 将方差归一化回 O(1)，与 d_k 无关，使 softmax 保持在梯度可流动、注意力分布而非过度集中的区域。

具体：d_k = 64 时，未缩放点积标准差约 8。softmax(8, 8.1, 7.9, \ldots) \approx (0.03, 0.28, 0.01, \ldots)——几乎全部权重集中在一个条目。除以 \sqrt{64} = 8 后输入标准差约 1，softmax 将权重更均匀地扩散。

**Q2.** Transformer 自注意力层有 T = 50 tokens，d_\text{model} = 64，4 个注意力头，d_k = d_v = 16。多头注意力模块有多少参数（忽略位置编码）？

**答案：**

每个头需要：

* W^Q_i, W^K_i, W^V_i：每个 \mathbb{R}^{64 \times 16} = 1,024 参数

4 个头：3 \times 4 \times 1,024 = 12,288 参数（Q、K、V 投影）。

输出投影 W^O \in \mathbb{R}^{4 \times 16 \times 64} = \mathbb{R}^{64 \times 64}：4,096 参数。

总计：12,288 + 4,096 = 16,384 参数。

（加上偏置：3 \times 4 \times 16 + 64 = 192 + 64 = 256，视实现而定。）

**Q3.** 用平实语言解释解码器自注意力为何需要掩码，没有会怎样。

**答案：** 解码器在推断时逐个生成目标 token：先生成 token 1，再用 token 1 生成 token 2，再用 tokens 1-2 生成 token 3，依此类推。训练时我们已有完整目标序列，希望并行化——同时计算所有位置的梯度。

没有掩码，解码器在位置 t 的自注意力可以关注 t+1, t+2, \ldots, T——生成时还未"生成"的未来目标 token。训练时模型会作弊，提前读到答案。推断时这些未来 token 不存在，模型就会失败。

掩码在 softmax 前把未来位置的注意力权重设为 -\infty（softmax 后变为 0），确保每个位置只能关注自己和之前的 position。这使训练正确模拟推断。
