#### 定义：梯度提升

更一般地，梯度提升在 *函数空间* 中通过梯度下降最小化损失函数 L(y, F(\mathbf{x}))：

每阶段，用损失函数对当前集成的 **负梯度** 拟合一棵树：

r_i^{(t)} = -\left.\frac{\partial L(y_i, F(\mathbf{x}_i))}{\partial F(\mathbf{x}_i)}\right|_{F = F_{t-1}}

对 MSE 损失，负梯度正好是残差：r_i = y_i - F(\mathbf{x}_i)。对其他损失（交叉熵、Huber），负梯度是别的量。

这种表述表明梯度提升是 *函数空间中的梯度下降*——不是更新参数值，而是通过添加指向最陡下降方向的新函数（树）来"下降"。

**学习率 \eta：** 称为 *shrinkage* 参数，控制每棵树的贡献。小的 \eta（0.01–0.1）配合很多树通常优于大 \eta 配少树——更渐进的修正带来更好的泛化。在计算预算允许范围内使用最小的 \eta。


#### XGBoost 与 LightGBM

现代梯度提升实现远超基础算法：

**XGBoost（eXtreme Gradient Boosting）：** 加入损失的二阶 Taylor 展开（同时使用梯度和 Hessian 更准确地拟合树）、对树结构的 L1/L2 正则化，以及基于排序特征直方图的高效并行建树。

**LightGBM（Light Gradient Boosting Machine）：** 进一步优化，采用 *leaf-wise* 生长（选择使损失减少最大的单个叶进行分裂），并使用 Gradient-based One-Side Sampling (GOSS) 跳过无信息样本。对大数据集远快于 XGBoost。

**CatBoost：** 专门处理类别特征，无需 one-hot 编码。

三者在表格数据上都达到 state-of-the-art 性能。对新问题，尝试 XGBoost 或 LightGBM 是合理的起点。


#### 梯度提升关键超参数

| 超参数 | 作用 | 典型范围 |
|---|---|---|
| 树的数量 T | 越多损失越低；过多会过拟合 | 100–5000 |
| 学习率 \eta | 越低越慢但泛化越好 | 0.01–0.3 |
| 最大树深度 | 控制单棵树复杂度 | 3–8 |
| 叶节点最小样本数 | 正则化单棵树 | 5–50 |
| Subsample | 每棵树使用的数据比例（类似 bagging） | 0.5–1.0 |
| Colsample | 每棵树使用的特征比例 | 0.5–1.0 |

早停：在提升过程中监控验证误差，开始上升时停止——自动找到合适的 T。
