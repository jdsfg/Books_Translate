**Q4.** 比较以下三种场景及预期结果：(A) 大学习率，无动量；(B) 小学习率，高动量（\beta = 0.99）；(C) Adam 优化器默认设置。

**答案：**

**(A) 大学习率，无动量：** 早期进展快，但倾向于在最优解附近震荡而非收敛。对学习率极其敏感——稍大就发散。适合快速初始探索，不适合最终收敛。

**(B) 小学习率，高动量：** 高动量（\beta = 0.99）意味着沿一致梯度方向有效学习率被放大："速度"累积。在峡谷谷地中进展快。但高动量在梯度方向快速变化时会超调。极小基础学习率 + 高动量可表现良好，但需仔细调参。

**(C) Adam 默认：** 自适应每参数学习率使 Adam 对 (A) 的震荡和 (B) 的方向敏感性都鲁棒。多数任务开箱即用。一阶矩提供动量；二阶矩调整有效学习率。有时在最后几个百分点准确率上不如调好的 SGD+动量（调好的 SGD+动量在某些视觉任务上可持平或略超 Adam），但无需调参。

**实用建议：** 大多数任务先用 Adam。要追求最先进视觉模型且每零点几个百分点都重要时，再用精心调度的 SGD+动量。

**Q5.** 批量归一化在归一化后使用可学习参数 \gamma 和 \beta。为什么这些参数必要？如果只用归一化输出 \hat{z}_i，不用缩放和平移，会怎样？

**答案：** 归一化后每个神经元输出被构造为零均值、单位方差。没有 \gamma 和 \beta，网络每层都被迫在这个受限分布中运行——无法表示任意均值和方差的激活。这严重限制表达能力：例如，若某层最优激活分布均值 2.5、标准差 0.3，网络无法产出。

可学习 \gamma（缩放）和 \beta（平移）恢复网络表示任意分布的能力：y_i = \gamma \hat{z}_i + \beta 可通过设 \beta = \text{desired mean} 和 \gamma = \text{desired std} 复现任意均值和标准差。

关键是，若 \gamma = \sqrt{\text{Var}(z)} 且 \beta = \mu_z，该层可精确撤销归一化——因此批量归一化可表示恒等函数。这确保添加批量归一化绝不会损害网络容量；最差情况下，它学会绕过自己的归一化。
