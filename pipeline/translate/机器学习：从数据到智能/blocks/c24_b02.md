#### 状态价值函数

V^\pi(s) = \mathbb{E}_\pi\left[G_t \mid s_t = s\right] = \mathbb{E}_\pi\left[\sum_{k=0}^\infty \gamma^k r_{t+k} \mid s_t = s\right]

V^\pi(s) 是从状态 s 出发并遵循策略 \pi 的期望回报。V^\pi 高的状态是好状态。


#### 动作价值函数（Q-函数）

Q^\pi(s, a) = \mathbb{E}_\pi\left[G_t \mid s_t = s, a_t = a\right]

Q^\pi(s, a) 是从状态 s 出发、采取动作 a、然后遵循策略 \pi 的期望回报。

Q-函数更适用于控制：一旦知道所有动作的 Q(s, a)，就可以贪婪地行动：

\pi(s) = \arg\max_a Q(s, a)


#### 贝尔曼方程

由 G_t 定义导出的关键递归关系：

V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)\left[R(s,a) + \gamma V^\pi(s')\right]

通俗地说：状态 s 的价值等于期望即时奖励加上下一状态折扣价值。

对最优价值函数 V^*(s) = \max_\pi V^\pi(s)，**贝尔曼最优方程** 为：

V^*(s) = \max_a \sum_{s'} P(s'|s,a)\left[R(s,a) + \gamma V^*(s')\right]

对最优 Q-函数：

Q^*(s,a) = \sum_{s'} P(s'|s,a)\left[R(s,a) + \gamma \max_{a'} Q^*(s', a')\right]

贝尔曼方程是大多数 RL 算法的基础。若能精确求解，就有最优策略。挑战在于对巨大状态空间精确求解不可行——这就需要学习。


### 23.3 Q-Learning：学习最优 Q-函数


#### 表格 Q-Learning

对离散可数状态和动作的环境，可把 Q(s, a) 存在表中，并从经验增量更新。

**算法：Q-Learning**

任意初始化 Q(s, a)（如全零）；设置学习率 \alpha，折扣 \gamma。

每个 episode：

  1. 观察初始状态 s
  2. 用 \varepsilon-greedy 策略（见下）选择动作 a
  3. 执行 a，观察奖励 r 和下一状态 s'
  4. **Q 更新：**

Q(s, a) \leftarrow Q(s, a) + \alpha \left[r + \gamma \max_{a'} Q(s', a') - Q(s, a)\right]

  5. 令 s \leftarrow s'；重复

括号中的项是 **TD error（时序差分误差）** ：观测目标 r + \gamma \max_{a'} Q(s', a') 与当前估计 Q(s, a) 之差。

这一更新很了不起：目标 r + \gamma \max_{a'} Q(s', a') 本身由 Q 计算（"自举"更新）。但该算法在温和条件下收敛到最优 Q-函数。
