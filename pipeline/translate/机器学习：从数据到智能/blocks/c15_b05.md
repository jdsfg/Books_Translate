矩阵乘积 W^{(L)} W^{(L-1)} \cdots W^{(1)} 本身就是一个矩阵 W'。整个深度网络退化为单个线性变换 \mathbf{y} = W'\mathbf{x} + \mathbf{b}'。无论多少层，线性神经元网络都是线性函数——等价于单层网络。没有非线性，深度毫无意义。


#### 应用问题

**Q1.** 你试图把二维点分类为圆内（y=1）与圆外（y=0）。解释为什么感知机永远无法解决此问题，并描述最少需要何种架构。

*提示*

思考感知机的决策边界形状。一条直线能把圆内与圆外分开吗？

**答案：** 感知机的决策边界永远是直线（超平面）。圆内是曲线围成的凸区域，不是直线。没有任何一条直线能把所有内部点与所有外部点分开——"内部"类被"外部"类从四面八方包围。

**最少架构：** 至少 3 个神经元的单隐藏层可以近似圆形边界（神经元足够多时，任何光滑边界都可近似）。或者：给输入添加多项式特征 x_1^2, x_2^2。此时圆边界 x_1^2 + x_2^2 = r^2 在增广特征空间中成为线性边界，单个感知机作用于 (x_1, x_2, x_1^2, x_2^2) 即可精确求解。

带一个隐藏层的 MLP 通过自动学习非线性特征解决这个问题——这就是表示学习的力量。

**Q2.** 感知机在 m = 200 个线性可分样本上训练。最大数据点范数 R = 3，真实分离超平面的几何间隔 \gamma = 0.5。感知机学习规则在收敛前最多做多少次权重更新？

**答案：** 感知机收敛定理将更新次数上界定为 R^2 / \gamma^2：

\text{Updates} \leq \frac{R^2}{\gamma^2} = \frac{3^2}{0.5^2} = \frac{9}{0.25} = 36

感知机最多 36 次更新收敛，与数据集大小 m = 200 无关。该上界只取决于问题几何（数据范数和间隔）。几何间隔越大，上界越紧——更易分的数据收敛更快。
