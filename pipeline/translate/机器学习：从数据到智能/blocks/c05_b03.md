#### 定义：梯度下降

**梯度下降（gradient descent）** 通过迭代更新参数来最小化损失函数 L(\boldsymbol{\theta})：

\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla_{\boldsymbol{\theta}} L(\boldsymbol{\theta}_t)

用平实的语言说：每一步都沿梯度的 *相反* 方向走一小步（因为梯度指向上坡，我们往下坡走）。

标量 \eta > 0 称为 **learning rate（学习率）**（或步长），控制每步的大小。

**几何直觉：** 想象你站在浓雾中的山丘上，想找到最低点。你看不见全局，但能感受到脚下的坡度。梯度下降策略：始终朝下坡方向迈步。学习率太大，会越过谷底，甚至可能发散（"爆炸"）；学习率太小，则要花很久才能到达。

**具体示例：** 最小化 f(w) = (w - 3)^2。

梯度为 f'(w) = 2(w - 3)。从 w_0 = 0 开始，学习率 \eta = 0.1：

w_1 = 0 - 0.1 \cdot 2(0 - 3) = 0 + 0.6 = 0.6

w_2 = 0.6 - 0.1 \cdot 2(0.6 - 3) = 0.6 + 0.48 = 1.08

w_3 = 1.08 - 0.1 \cdot 2(1.08 - 3) = 1.08 + 0.384 = 1.464

每步都更接近最小值点 w^* = 3。越接近最小值，更新越小（因为梯度在平坦处变小）。


#### 选择学习率

学习率是实践中最重要的超参数之一。

* **太大（\eta 过高）：** 更新越过最小值，损失震荡甚至发散（"爆炸"）。
* **太小（\eta 过低）：** 训练极慢，可能一直停留在起点附近。
* **适中：** 平滑收敛到（接近）最小值。

实践中，学习率范围 [10^{-4}, 10^{-1}] 很常见。Adam 等现代优化器（第18章）会自动调节学习率，大幅降低敏感性。


#### 梯度下降的变体

**批量梯度下降（Batch gradient descent）：** 每次更新前在整个数据集上计算梯度。精确但大型数据集很慢——必须处理全部 m 个样本才能迈一步。

**随机梯度下降（SGD）：** 每步只在一个随机抽取的样本上计算梯度。很快但噪声大——每步方向不一定完全正确。

**小批量梯度下降（Mini-batch gradient descent）：** 在一个小的随机子集（mini-batch）B 个样本上计算梯度，B 通常取 32、64、128、256。现代深度学习的标准做法——在梯度估计精度与计算效率之间取得平衡。

\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \cdot \frac{1}{B} \sum_{i \in \mathcal{B}_t} \nabla_{\boldsymbol{\theta}} L_i(\boldsymbol{\theta}_t)

SGD 中的噪声其实是 *有益的* —— 它起到隐式正则化作用，帮助逃离尖锐局部最小值（第18章会进一步讨论）。
