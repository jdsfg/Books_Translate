#### 深入思考

**Q1.** 通用近似定理说单隐藏层足够。但现代深度网络使用 50、100 甚至 1000 层。如果一层在理论上足够，为什么从业者使用深网络？

**Q2.** Leaky ReLU 激活 f(z) = \max(0.01z, z)。计算 z = 5、z = −2、z = 0 处的导数 f'(z)。解释 Leaky ReLU 为何针对"死亡 ReLU"问题设计，并描述标准 ReLU 神经元在训练中可能系统死亡的场景。

**讨论：** 导数：

f'(5) = 1（因为 5 > 0，Leaky ReLU 等于恒等函数）
f'(−2) = 0.01（因为 −2 < 0，Leaky ReLU 等于 0.01z；导数为 0.01）
f'(0) 未定义（z = 0 处不可微；实践中赋予次梯度 0.01 或 1）

标准 ReLU 中，f'(z) = 0 对所有 z < 0。若一个神经元的预激活始终为负，其梯度永远为 0——该神经元完全停止学习（"死亡"）。Leaky ReLU 在 z < 0 时设 f'(z) = 0.01，因此梯度始终能流过负区间。

标准 ReLU 神经元可能死亡的场景：学习率过大导致一次大幅负权重更新，把许多神经元推到永久负区域。一旦卡住，它们收到零梯度，永远无法恢复。这会消除网络训练中期的大量容量。Leaky ReLU、ELU 和 GELU 通过保证处处非零梯度防止此问题。

**讨论：** 通用近似定理保证足够 *宽度* 可逼近任何函数——但所需宽度可能是输入维度的指数。深度网络能通过组合简单函数以指数级更少的神经元表示相同函数。

关键洞见：许多真实函数具有层次结构。图像识别函数"是否人脸"="是否有两眼、一鼻、一口"="正确相对位置是否有正确局部模式"="是否有正确边缘组合"。这种层次天然映射到层：早期层检测边缘，中间层检测部件，后期层检测物体。单层宽网络会冗余地同时编码所有层级。

形式上，存在某些函数，深度为 d 的电路可用 O(n) 个门计算，但深度为 d−1 的电路需要指数多个门（这与电路复杂度理论有关）。神经网络有类似分离结果。

经验上：在每个主要基准（图像、文本、音频、游戏）上，更深网络在参数量相同时持续优于浅网络。深度不仅提供表达能力，还提供 *高效* 表达能力——相同复杂度下参数更少，泛化更好。
