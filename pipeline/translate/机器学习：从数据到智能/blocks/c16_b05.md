#### 概念检测

**Q1.** 一个网络有 3 层：输入（4）→ 隐藏（3，sigmoid）→ 输出（1，sigmoid）。对输入 \mathbf{x} = (1, 0, -1, 0.5)，逐步写出前向传播方程。

**答案：**

**第 1 层 → 隐藏：**

\mathbf{z}^{(1)} = W^{(1)}\mathbf{x} + \mathbf{b}^{(1)} \quad (W^{(1)} \in \mathbb{R}^{3 \times 4}, \mathbf{b}^{(1)} \in \mathbb{R}^3)
\mathbf{a}^{(1)} = \sigma(\mathbf{z}^{(1)}) \quad \text{（逐元素 sigmoid）}

**第 2 层 → 输出：**

z^{(2)} = \mathbf{w}^{(2)\top}\mathbf{a}^{(1)} + b^{(2)} \quad (\mathbf{w}^{(2)} \in \mathbb{R}^3, b^{(2)} \in \mathbb{R})
a^{(2)} = \hat{p} = \sigma(z^{(2)})

总参数量：4 \times 3 + 3 + 3 \times 1 + 1 = 12 + 3 + 3 + 1 = 19。

**Q2.** 反向传播中，对二分类问题你计算 \boldsymbol{\delta}^{(L)} = \hat{\mathbf{p}} - \mathbf{y}。解释为何使用交叉熵损失与 sigmoid 输出时会出现如此简洁的公式。

**答案：** 交叉熵损失为 L = -[y\log\hat{p} + (1-y)\log(1-\hat{p})]，其中 \hat{p} = \sigma(z^{(L)})。

链式法则：\delta^{(L)} = \frac{\partial L}{\partial z^{(L)}} = \frac{\partial L}{\partial \hat{p}} \cdot \frac{\partial \hat{p}}{\partial z^{(L)}}

\frac{\partial L}{\partial \hat{p}} = -\frac{y}{\hat{p}} + \frac{1-y}{1-\hat{p}}

\frac{\partial \hat{p}}{\partial z^{(L)}} = \sigma'(z^{(L)}) = \hat{p}(1-\hat{p})

\delta^{(L)} = \left(-\frac{y}{\hat{p}} + \frac{1-y}{1-\hat{p}}\right) \cdot \hat{p}(1-\hat{p}) = -(y(1-\hat{p}) - (1-y)\hat{p}) = -y + y\hat{p} + \hat{p} - y\hat{p} = \hat{p} - y

sigmoid 与交叉熵以美妙的方式"抵消"，得到干净结果 \hat{p} - y。这是概率模型与神经网络梯度之间诸多优雅联系之一。

**Q3.** 权重初始化为何关键？零初始化会怎样？

**答案：** 所有权重为零时：隐藏层每个神经元计算 \mathbf{w}^\top \mathbf{a}^{(\text{prev})} + b = b（因所有权重为 0，同层所有神经元相同）。所有神经元产生相同激活。反向传播为同层所有神经元计算相同梯度，因此它们以相同方式更新。网络对称性永远保持——每层实际上只有一个神经元。

这种"对称性破缺"失败意味着网络每层实际只有一个神经元，无论宽度多大。它永远无法发展复杂问题所需的分化表示。
