**为什么梯度下降仍能逃离它们。** 考虑从鞍点附近初始化的精确梯度下降。如果初始点在任何负曲率方向（远离鞍点的"下坡"方向）上有分量，梯度就会沿该方向指数级快速把迭代拉走。鞍点是不稳定平衡点：只有从精确鞍点出发才会被困，而随机初始化下这种情况概率为零。从这个意义上说，梯度下降 *不会* 被鞍点吸引——它只在测度为零的初始点上收敛到鞍点。

**SGD 噪声的作用。** 精确的梯度下降在鞍点附近仍会减慢（在 \boldsymbol{\theta}^* 附近梯度非常小）。随机梯度下降的噪声——来自使用 mini-batch 而非全数据集——主动帮助逃离这一邻域。每个 mini-batch 梯度都是真实梯度的无偏估计加上噪声。即使真实梯度接近零（鞍点附近），带噪声的估计在负曲率方向上仍可能有非零分量。这个扰动把迭代点踢出鞍点邻域，之后真实负曲率接管，梯度下降加速离开。

**实际意义。** 这一分析解释了几个经验观察：(1) 更大的 batch size 有时会收敛到"更尖锐"的最小值（噪声小意味着逃离鞍点能力弱，可能被困在曲率较高的区域）；(2) 加入显式噪声（例如学习率先增后降的 schedule）有助于优化；(3) "初始化时加少量噪声"这一常见建议有逃离鞍点的理论基础。这一现象的正式研究属于非凸优化领域，自 2015 年左右以来一直很活跃。


### 本章总结

本章完成了数学工具包的最后一块——微积分与优化，它们是模型训练的根基。

核心思想：

* **导数** 度量变化率；**梯度** 把它推广到多变量函数，并指向最陡上升方向
* **链式法则** 用于复合函数的求导——它也是神经网络反向传播的数学基础（第15章）
* **梯度下降** 沿负梯度方向迭代最小化损失函数；学习率控制步长
* **凸函数** 只有一个全局最小值——梯度下降保证找到；非凸函数（神经网络）需要更谨慎处理
* 线性回归的 **MSE 梯度** 直接指向正规方程，把微积分与第2章的线性代数结果联系起来

我们现在已具备线性代数、概率论、微积分三大支柱，可以构建和理解 ML 模型。第5章将把三者结合起来：从几何、统计、优化三个互补视角推导线性回归，并把它应用于第一个贯穿数据集（Thread A：房价预测）。
