### 21.7 Thread B——GPT/BERT 情感分析微调（B5）

_[Thread B：情感分析 —— B5：微调预训练 GPT/BERT 模型；96%+ 准确率]_

现在将预训练范式应用到情感分析任务。

**使用 BERT-base（110M（1.1 亿）参数，在 Wikipedia + BooksCorpus 上预训练）：**

添加分类头：[CLS] token 表示 → Linear(768, 2)。在 25K 条训练影评（与此前所有实验相同数据）上微调 3 个 epoch（轮）。

**结果：**

* 测试准确率：**96.1%**
* 相比从头训练的 Transformer：+2.1 个百分点
* 相比词袋基线：+11.1 个百分点

**为什么预训练带来如此巨大提升？**

BERT 在约 3.3B（33 亿）词上训练，学到丰富语义表示。读到 "not very compelling" 时，它见过类似短语数十亿次，知道 "not very" 否定后面的形容词。微调的 BERT 无需从 25K 样本重新学习——它 already 知道。

25K 标注样本只需教会 BERT："情感标签如何映射到你已有的表示。"这比从零学习语言简单得多。

**Thread B 完整旅程：**

| 模型 | 准确率 | 关键创新 |
|---|---|---|
| 词袋模型（bag-of-words） + 逻辑回归 | 85% | 简单、可解释基线 |
| GloVe 嵌入 + LR | 88% | 预训练词表示 |
| LSTM（GloVe） | 93% | 序列处理，词序 |
| Transformer | 94% | 并行注意力，直接长程 |
| **BERT 微调** | **96.1%** | **完整句子级预训练** |

**教训：** 每次准确率跃升都对应语言表示方式的质化进步：

  1. 词频 → 语义结构（嵌入）
  2. 无序 → 序列（LSTM）
  3. 序列 → 全局上下文并行（Transformer）
  4. 任务特定训练 → 通用语言预训练（BERT）

最后一跳（BERT）最大，因为在数十亿词上预训练提供的语言知识质量，远非 25K 标注样本能教。
