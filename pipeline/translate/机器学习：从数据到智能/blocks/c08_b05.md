#### 概念检测

**Q1.** 某逻辑回归模型对特定输入预测 \hat{p} = \sigma(2.3)。数值上计算这个概率。预测类别是什么？

**答案：**

\hat{p} = \sigma(2.3) = \frac{1}{1 + e^{-2.3}}

e^{-2.3} \approx e^{-2} \cdot e^{-0.3} \approx 0.1353 \times 0.7408 \approx 0.1003

\hat{p} \approx \frac{1}{1.1003} \approx 0.909

类别 1 的预测概率约为 91%。由于 \hat{p} > 0.5，预测类别为 **1**。

**Q2.** 二分类交叉熵损失为 L = -[y \log \hat{p} + (1 - y)\log(1 - \hat{p})]。分别计算 y = 1, \hat{p} = 0.95 和 y = 1, \hat{p} = 0.05 时的损失。

**答案：**

当 y = 1, \hat{p} = 0.95：L = -[\log(0.95)] = -(-0.051) = 0.051（很小——模型自信且正确）

当 y = 1, \hat{p} = 0.05：L = -[\log(0.05)] = -(-3.00) = 3.00（很大——模型自信且错误）

这说明交叉熵的行为：对过度自信的错误的惩罚很重（损失 3.0），但对自信正确的预测惩罚很轻（损失 0.051）。

**Q3.** 对 K = 3 的 softmax，分数为 z_1 = 2.0, z_2 = 1.0, z_3 = 0.1。计算 softmax 概率。

**答案：**

取指数：e^{2.0} \approx 7.389，e^{1.0} \approx 2.718，e^{0.1} \approx 1.105。

和：7.389 + 2.718 + 1.105 = 11.212。

概率：P_1 = 7.389 / 11.212 \approx 0.659，P_2 = 2.718 / 11.212 \approx 0.242，P_3 = 1.105 / 11.212 \approx 0.099。

验证：0.659 + 0.242 + 0.099 = 1.000 ✓

类别 1 分数最高、概率最高。虽然 z_1 - z_3 = 1.9（并不大），但指数放大了分数差距：类别 1 的概率是类别 3 的约 6.7 倍。

**Q4.** 如果把逻辑回归的所有权重 \mathbf{w} 翻倍，但保持阈值 \hat{p} > 0.5，决策边界会如何变化？预测概率会如何变化？

**答案：** 决策边界（\mathbf{w}^\top \mathbf{x} = 0）**不变**——仍是同一个超平面。权重翻倍不会移动超平面（它只依赖于 \mathbf{w} 的方向，而非大小）。

但预测概率 *会* 变。权重翻倍后，\sigma(2\mathbf{w}^\top \mathbf{x})：边界附近的点（|\mathbf{w}^\top \mathbf{x}| 小）会被推向 0 或 1 的极端。模型变得更"自信"——概率更靠近 0 或 1——但分类边界不变。
