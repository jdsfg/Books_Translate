#### 定义：半正定矩阵

若对所有 \mathbf{x} \in \mathbb{R}^n 都有：

\mathbf{x}^\top A \mathbf{x} \geq 0

则对称矩阵 A \in \mathbb{R}^{n \times n} 是 **半正定（positive semi-definite, PSD）** 的。若对所有 \mathbf{x} \neq \mathbf{0} 严格大于 0，则称为 **正定（positive definite, PD）**。

用平实的语言说，半正定矩阵只能"非负地拉伸"向量。协方差矩阵和 Gram 矩阵总是半正定的。正定矩阵总是可逆的。


#### 定义：特征值与特征向量

对于方阵 A，若非零向量 \mathbf{v} 和标量 \lambda 满足：

A\mathbf{v} = \lambda \mathbf{v}

则 \mathbf{v} 和 \lambda 构成一对 **特征向量-特征值（eigenvector-eigenvalue）**。

用平实的语言说，\mathbf{v} 是 A 不旋转的方向——A 只把它沿该方向拉伸 \lambda 倍。

**谱定理（Spectral Theorem）** 指出：每个实对称矩阵 A 都可以写成 A = Q \Lambda Q^\top，其中 Q 是特征向量组成的正交矩阵，\Lambda 是特征值组成的对角矩阵。这种分解称为 *eigendecomposition*（特征分解），是 PCA（第13章）的基础。
