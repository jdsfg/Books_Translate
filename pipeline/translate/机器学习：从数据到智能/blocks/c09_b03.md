#### 混淆矩阵

二分类混淆矩阵：

|  | 预测正类 | 预测负类 |
|---|---|---|
| **实际正类** | 真正例（TP） | 假反例（FN） |
| **实际负类** | 假正例（FP） | 真反例（TN） |

由混淆矩阵定义：


#### 定义：精确率与召回率

\text{Precision} = \frac{TP}{TP + FP} \quad \text{（预测为正类的样本中，真正为正类的比例）}

\text{Recall (Sensitivity)} = \frac{TP}{TP + FN} \quad \text{（所有实际正类中，我们抓到了多少）}

\text{F1 Score} = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} \quad \text{（调和平均，平衡两者）}

**精确率-召回率权衡：** 调整分类阈值（不总是用 0.5），可以在召回率和精确率之间取舍：提高召回率通常以降低精确率为代价，反之亦然。**PR 曲线（precision-recall curve）** 展示所有可实现的精确率-召回率组合。

**Specificity** = TN / (TN + FP)：正确识别的负类比例。高 specificty 表示假正例少。


#### 定义：ROC 曲线与 AUC

**ROC 曲线（Receiver Operating Characteristic）** 随分类阈值从 0 到 1 变化，绘制 sensitivity（recall）对 1 - specificity（假正率）的曲线。

**AUC（ROC 曲线下面积）** 把 ROC 曲线总结为一个数字：

* AUC = 1.0：完美分类器
* AUC = 0.5：随机分类器（对角线）
* AUC < 0.5：比随机还差（通常说明标签搞反了）

AUC 与阈值无关，衡量分类器的 *排序能力*：随机选一个正例和一个负例，正例排在负例前面的概率。

**何时使用哪个指标：**

* **准确率（accuracy）**：仅当类别平衡且两类错误成本相同时
* **精确率/召回率**：正类罕见或假阴性与假阳性成本差异大时
* **F1**：需要一个同时平衡精确率和召回率的单一指标时
* **AUC**：需要跨所有阈值比较分类器；适合排序任务


#### 常见误解

高 AUC 不保证模型校准。一个 AUC = 0.95 的模型可能对负例预测概率 0.48、对正例预测 0.52——排序很好，但概率几乎无法用于决策。**校准（calibration）**（预测概率是否匹配实际频率？）是与区分能力（discrimination）分离的另一属性。
