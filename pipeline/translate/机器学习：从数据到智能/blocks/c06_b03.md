### 5.4 求解线性回归：三种视角

任务是求：

\mathbf{w}^* = \arg\min_\mathbf{w} L(\mathbf{w}) = \arg\min_\mathbf{w} \frac{1}{m}\|X\mathbf{w} - \mathbf{y}\|^2

其中 X \in \mathbb{R}^{m \times (n+1)} 是数据矩阵（含一列 1 以表示截距），\mathbf{y} \in \mathbb{R}^m 是标签向量。

我们给出三种视角，每种都阐明回归在做什么。


#### 视角 1：几何（投影）

我们想找一个权重向量 \mathbf{w}，使 X\mathbf{w} 尽可能接近 \mathbf{y}。

所有可能预测 \{X\mathbf{w} : \mathbf{w} \in \mathbb{R}^{n+1}\} 正是 X 的 *列空间（column space）* —— X 各列张成的空间。我们要在 X 的列空间中找离 \mathbf{y} 最近的点。

由第2章，这就是 \mathbf{y} 在 X 列空间上的 **正交投影（orthogonal projection）**：

\hat{\mathbf{y}} = X(X^\top X)^{-1} X^\top \mathbf{y}

最优预测就是该投影，最优权重为：

\mathbf{w}^* = (X^\top X)^{-1} X^\top \mathbf{y}

残差 \mathbf{e} = \mathbf{y} - X\mathbf{w}^* 与 X 的每一列正交：

X^\top \mathbf{e} = X^\top (\mathbf{y} - X\mathbf{w}^*) = X^\top \mathbf{y} - X^\top X \mathbf{w}^* = \mathbf{0}

这一正交条件正是投影为最近点的本质。


#### 视角 2：代数（正规方程）

对 MSE 损失求梯度并令其为零：

\nabla_\mathbf{w} L = \frac{2}{m} X^\top (X\mathbf{w} - \mathbf{y}) = \mathbf{0}

两边乘以 m/2：

X^\top X \mathbf{w} = X^\top \mathbf{y}


#### 定义：正规方程

\mathbf{w}^* = (X^\top X)^{-1} X^\top \mathbf{y}

（假设 X^\top X 可逆）

它们称为 *normal equations*（正规方程），因为它们编码了残差与列空间 *正交*（normal）的条件——这又联系回几何视角。

正规方程给出闭式精确解。对小数据集很高效。但当样本上百万或特征上千时，求逆 X^\top X（O(n^3) 运算）变得不切实际，这时我们用梯度下降。


#### 视角 3：概率（最大似然）

在高斯噪声模型 y_i = \mathbf{w}^\top \mathbf{x}_i + \epsilon_i，\epsilon_i \sim \mathcal{N}(0, \sigma^2) 下，第3章已证明 MLE 为：

\hat{\mathbf{w}}_{\text{MLE}} = \arg\min_\mathbf{w} \sum_{i=1}^m (y_i - \mathbf{w}^\top \mathbf{x}_i)^2

这正是 MSE 最小化。三种视角给出同一答案——这令人深感安心。
