#### 概念检测

**Q1.** 计算一个节点有 6 个正例、4 个负例时的 Gini 不纯度。

**答案：**

p_1 = 6/10 = 0.6（正例比例），p_0 = 4/10 = 0.4（负例比例）

G = 1 - (p_1^2 + p_0^2) = 1 - (0.36 + 0.16) = 1 - 0.52 = 0.48

与最坏情况比较：对 50/50 划分，G = 1 - (0.25 + 0.25) = 0.5。该节点接近最大不纯。

**Q2.** 一个节点有 10 个样本（5 正、5 负），被分裂为左子节点（4 正、1 负）和右子节点（1 正、4 负）。计算信息增益。

**答案：**

父节点熵：H = -0.5\log_2(0.5) - 0.5\log_2(0.5) = 1.0（最大不纯）

左子节点（4P, 1N）：p = 4/5 = 0.8。H_L = -0.8\log_2(0.8) - 0.2\log_2(0.2) = 0.8 \cdot 0.322 + 0.2 \cdot 2.322 = 0.257 + 0.464 = 0.722

右子节点（1P, 4N）：p = 1/5 = 0.2。由对称性，H_R = H_L = 0.722。

加权平均子节点熵：(5/10)(0.722) + (5/10)(0.722) = 0.722

信息增益：1.0 - 0.722 = 0.278

这次分裂把熵从 1.0 降到 0.722——信息增益为 0.278 比特。

**Q3.** 为什么深度不受限的决策树总能达到 0% 训练误差（假设没有两个训练样本特征相同但标签不同）？

**答案：** 若没有两个训练样本共享相同特征向量却有不同标签，树可以通过足够深的划分完美分开训练数据——最终每个训练样本一个叶（或每个唯一特征组合一个叶）。每个叶只含一个样本时，树以 100% 准确率预测该样本的标签。没有泛化发生；树记住了训练数据。

这说明为什么必须限制深度：无限深度 = 训练误差为 0，但测试性能可能灾难性（高方差）。最大深度超参数是决策树的主要正则化工具。

**Q4.** 解释为什么 Gini 不纯度和熵在实践中产生相似的树。

**答案：** Gini 不纯度 G = 1 - \sum p_k^2 和熵 H = -\sum p_k \log p_k 都是分布"不纯"或"混合"程度的度量。它们都：

* 节点纯净时最小化为 0（全属一类）
* 各类均等混合时最大化
* 是类比例 p_k 的凹函数

在极端和接近均匀分布处，它们对哪些分裂最好的排序非常接近。实证上，用 Gini 或熵构建的树最多只在少数几个分裂上不同，测试性能几乎一致。选择哪个通常不值得担心；Gini 计算略快（避免对数），因此是 scikit-learn 的默认选择。
