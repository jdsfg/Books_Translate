#### 概念检测

**Q1.** 智能体在简单 3 状态链中运行：状态 \{A, B, C\}，C 为终止状态。奖励为：R(A, \text{right}) = 0，R(B, \text{right}) = +10（终止）。折扣 \gamma = 0.9，从 A 出发，在两个状态都采取 "right" 的回报 G_0 是多少？

**答案：** 轨迹为 A \to B \to C，奖励 r_0 = 0（在 A），r_1 = 10（在 B，终止）。

G_0 = r_0 + \gamma r_1 = 0 + 0.9 \times 10 = 9

若智能体在 B：

G_1 = r_1 = 10

因此从 A 出发，折扣回报为 9（不是 10），反映奖励晚一步到来。

**Q2.** 对以下转移写出 Q-learning 更新：(s="A", a="right", r=0, s'="B")。当前估计：Q("A","right")=5，Q("B","right")=9。用 \alpha=0.1，\gamma=0.9。

**答案：**

TD target: r + \gamma \max_{a'} Q(s', a') = 0 + 0.9 \times 9 = 8.1

TD error: 8.1 - 5 = 3.1

更新：Q("A","right") \leftarrow 5 + 0.1 \times 3.1 = 5.31

估计朝观测目标（8.1）轻微移动。反复更新后会收敛到真实 Q 值。

**Q3.** DQN 中经验回放为何有助于训练稳定性？给出两个原因。

**答案：**

  1. **打破时间相关性：** 连续经验元组 (s_t, a_t, r_t, s_{t+1}) 高度相关——同一状态区域连续多次访问。用相关数据训练违反 SGD 的 i.i.d. 假设，导致更新震荡或发散。从缓冲区随机采样打破该相关性。

  2. **提高数据效率：** 每个经验元组可被多次使用（从缓冲区重复采样），而非单步梯度后就丢弃。这对环境交互昂贵时（真实机器人、慢仿真器）尤其宝贵。

**Q4.** 智能体使用 \varepsilon-greedy 策略，\varepsilon = 0.2。状态 s 的 Q 值为 Q(s, \text{left}) = 3.0，Q(s, \text{right}) = 7.0，Q(s, \text{up}) = 5.0。选择每个动作的概率是多少？

**答案：**

当 \varepsilon = 0.2，智能体：

* 以概率 0.2 探索（在 3 个动作中均匀随机选择）
* 以概率 0.8 利用（选择 \arg\max_a Q(s, a) = \text{right}）

各动作概率：

P(\text{right}) = 0.8 + \frac{0.2}{3} = 0.8 + 0.0\overline{6} \approx 0.867

P(\text{left}) = \frac{0.2}{3} \approx 0.0\overline{6}

P(\text{up}) = \frac{0.2}{3} \approx 0.0\overline{6}
