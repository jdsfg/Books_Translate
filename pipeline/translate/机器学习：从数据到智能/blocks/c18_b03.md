#### 定义：LSTM

LSTM 维护两个状态：隐藏状态 h_t 和单元状态 c_t。四个门控制信息流：

**遗忘门**——从上一单元状态中丢弃什么：

f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)

**输入门**——添加什么新信息：

i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)
\tilde{c}_t = \tanh(W_c [h_{t-1}, x_t] + b_c) \quad \text{（候选值）}

**单元状态更新**——长期记忆的高速公路：

c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t

**输出门**——基于单元状态输出什么：

o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)
h_t = o_t \odot \tanh(c_t)

用平实的语言：

* **遗忘门** 决定从记忆中"扔掉"什么（f_t \approx 0：遗忘；f_t \approx 1：保留）
* **输入门** 决定把什么新信息"写入"记忆
* **单元状态更新** 是加法：c_t = \text{forget} \cdot c_{t-1} + \text{input} \cdot \text{new}。这一加法是核心洞见——若 f_t = 1 且忽略输入路径，\partial c_t / \partial c_{t-1} = f_t \approx 1，梯度不衰减
* **输出门** 决定把单元状态的哪部分作为隐藏状态输出

**为什么单元状态对梯度重要：** 单元状态以加法而非乘法更新，并带有可学习门。\partial c_t / \partial c_{t-k} = \prod_{j=1}^k f_{t-j+1}——遗忘门乘积，网络学会对长程依赖保持接近 1。这被称为 **"常数误差旋转木马（constant error carousel）"**——梯度可在单元状态中循环多步。


#### GRU：简化替代

**门控循环单元（Gated Recurrent Unit, GRU）** 由 Cho 等人于 2014 年提出，通过把遗忘门和输入门合并为单一"更新门"并取消独立单元状态来简化 LSTM：

z_t = \sigma(W_z [h_{t-1}, x_t] + b_z) \quad \text{（更新门）}
r_t = \sigma(W_r [h_{t-1}, x_t] + b_r) \quad \text{（重置门）}
\tilde{h}_t = \tanh(W [r_t \odot h_{t-1}, x_t] + b)
h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t

GRU 参数比 LSTM 少，训练稍快，在大多数任务上性能相近。实践中，LSTM 和 GRU 对大多数序列任务可互换；Transformer（第20章）已在很大程度上取代两者。


#### 常见误解

学生常以为 LSTM 门由某种特殊算法训练，而非反向传播。并非如此。门只是计算图中额外的 sigmoid 和 tanh 非线性；反向传播像训练其他权重一样训练它们。创新在于单元状态的架构设计——训练算法（反向传播）完全相同。
