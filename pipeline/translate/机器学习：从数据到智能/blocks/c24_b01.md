迄今为止我们研究的每个模型都需要带标注样本的数据集。训练信号总是一样的：给定输入，给出正确输出，最小化差异。强化学习完全放弃这一假设。没有数据集，没有老师提供正确标签，只有 **智能体（agent）** 与 **环境（environment）** 交互，接收 **奖励（reward）** ，并通过试错 figuring out 如何行为以随时间最大化这些奖励。

这一范式听起来不同，因为它确实不同。国际象棋引擎不是从带正确走法标注的局面中学习。它自己与自己下数百万盘棋，赢 +1、输 −1，逐渐发现某些走法序列是好的。机械臂不是从正确抓取示范中学习。它尝试、掉落物体、再试，慢慢发现产生可靠抓握的运动指令。


### 23.1 强化学习框架


#### 智能体-环境循环

每个时间步 t，智能体：

  1. 观察当前 **状态** s_t
  2. 根据其 **策略** \pi 选择 **动作** a_t
  3. 从环境接收 **奖励** r_t
  4. 转移到新状态 s_{t+1}

该循环持续到 episode 结束（或持续任务中永远继续）。

**目标：** 找到最大化期望累积奖励的策略 \pi。


#### 定义：马尔可夫决策过程

RL 的标准形式化是 **马尔可夫决策过程（Markov Decision Process, MDP）** ：

一个 MDP 是元组 (S, A, P, R, \gamma)，其中：

* S：状态集合
* A：动作集合
* P(s' \mid s, a)：转移概率——在状态 s 采取动作 a 后到达状态 s' 的概率
* R(s, a)：在状态 s 采取动作 a 的期望奖励
* \gamma \in [0, 1)：**折扣因子**——未来奖励相对于即时奖励的权重

**马尔可夫性质：** 下一状态只依赖当前状态和动作，不依赖历史。这是使 MDP 可处理的关键假设。


#### 回报与折扣

智能体的目标是最大化 **回报** ——未来奖励的折扣和：

G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots = \sum_{k=0}^\infty \gamma^k r_{t+k}

折扣因子 \gamma 有两个作用：

  1. **数学上** ：保证级数收敛（对 \gamma < 1 且奖励有界）
  2. **行为上** ：编码时间偏好——现在奖励比未来奖励更值钱

当 \gamma = 0：短视智能体，只关心即时奖励。当 \gamma \to 1：远视智能体，平等对待所有未来奖励。

实践：\gamma = 0.99 常用于需要长程规划的任务；\gamma = 0.9 用于较短程任务。
