#### 应用问题

**Q1.** 你正在训练一个线性回归模型，m = 10 个样本，n = 1 个特征，学习率 \eta = 0.01。当前权重 w_0 = 0，梯度 \frac{\partial L}{\partial w}\big|_{w=0} = -12。计算前三次梯度下降更新。这个学习率会让损失收敛吗？

*提示*

检查更新是否朝合理方向（降低损失）进行。梯度的符号告诉你方向，学习率控制步长。

**答案：**

w_1 = w_0 - \eta \cdot (-12) = 0 + 0.01 \times 12 = 0.12

进一步更新需要在新 w 处重新计算梯度。没有具体数据集，我们来定性分析收敛性。

对一维二次函数 L(w) = c(w - w^*)^2，梯度为 \frac{dL}{dw} = 2c(w - w^*)。梯度下降给出：

w_{t+1} = w_t - \eta \cdot 2c(w_t - w^*) = w^* + (1 - 2c\eta)(w_t - w^*)

它收敛当且仅当 |1 - 2c\eta| < 1，即 0 < \eta < 1/c。

一般地，学习率 \eta = 0.01 对线性回归通常是安全的，但实际阈值取决于梯度的 Lipschitz 常数（与 X^\top X / m 的最大特征值有关）。对一个数据集收敛的学习率，对另一个特征值更大的数据集可能发散——这就是训练前要 *归一化特征*（第22章）的另一个原因。

**Q2.** 逻辑回归中出现 sigmoid 函数 \sigma(x) = 1/(1 + e^{-x})。证明它的输出总在 (0, 1) 内，并求其导数最大点。这对训练深度网络为何重要？

**答案：** 对任意 x，e^{-x} > 0，所以 1 + e^{-x} > 1，因此 \sigma(x) < 1。又 1 + e^{-x} > 0，故 \sigma(x) > 0。所以 \sigma(x) \in (0, 1)。

由概念检测 Q2 知 \sigma'(x) = \sigma(x)(1 - \sigma(x))。

求最大值：令 s = \sigma(x) \in (0, 1)，最大化 s(1 - s)。用 AM-GM 或微积分可知，最大值在 s = 1/2 处取得，即 \sigma'(0) = 1/4（x = 0 处梯度最大）。

当 |x| 很大时：\sigma(x) \approx 1（或 \approx 0），于是 \sigma'(x) \approx 0。梯度 *饱和*。

**这对深度网络为何重要：** 在深层网络中，若激活函数用 sigmoid，每一层的梯度都要乘上该层的 \sigma'（链式法则）。如果很多层的输入 |x| 很大，许多接近零的 \sigma' 相乘，乘积极其微小。前面层的梯度几乎为零——网络学不到东西。这就是 **vanishing gradient problem（梯度消失问题）**，也是现代深度学习用 ReLU（\max(0, x)）取代 sigmoid 的原因。ReLU 在 x > 0 时梯度为 1，x < 0 时梯度为 0，正输入不会饱和。我们将在第15、16章再讨论。
