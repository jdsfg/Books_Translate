### 13.4 t-SNE：可视化高维数据

PCA 的线性投影可解释，但可能不保留使高维数据有趣的局部结构。**t-SNE（t-distributed Stochastic Neighbor Embedding）** 专门用于 2D 或 3D 可视化。


#### t-SNE 思想

**步骤 1：** 对原始空间中每对点 (i, j)，用高斯核计算点 i 选择点 j 作为邻居的相似性（概率）：

p_{j|i} = \frac{\exp(-\|\mathbf{x}_i - \mathbf{x}_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|\mathbf{x}_i - \mathbf{x}_k\|^2 / 2\sigma_i^2)}

对称化：p_{ij} = (p_{j|i} + p_{i|j}) / (2m)

**步骤 2：** 在 2D 嵌入空间中，用 **Student's t 分布**（比高斯分布有更重的尾）定义类似相似性：

q_{ij} = \frac{(1 + \|\mathbf{y}_i - \mathbf{y}_j\|^2)^{-1}}{\sum_{k \neq l}(1 + \|\mathbf{y}_k - \mathbf{y}_l\|^2)^{-1}}

**步骤 3：** 找到使高维相似性 P 与低维相似性 Q 之间 KL 散度最小的 2D 嵌入 \{\mathbf{y}_i\}：

\text{KL}(P \| Q) = \sum_{i,j} p_{ij} \log \frac{p_{ij}}{q_{ij}}

嵌入空间中的 t 分布比输入空间的高斯分布有更重的尾部。这解决了"拥挤问题"：高维中相近点在 2D 中被推开到足够远（2D 中中等距离对应小 q_ij、大 p_ij，产生大 KL 梯度），因此不会都挤在中心。


#### 解读 t-SNE 图

t-SNE 保留局部结构（高维中相近的点在 2D 中仍相近），但 **不保留全局结构**（簇之间的距离无意义）。关键解读：

* t-SNE 图中的簇反映高维中的真实局部结构
* 图中簇 *之间* 的距离无意义
* 簇的大小和形状无意义
* **不同随机初始化会产生不同图**——务必检查结构在多次运行中是否一致

**perplexity** 超参数（通常 5–50）控制每个点考虑的有效邻居数。perplexity 高 → 保留更多全局结构；perplexity 低 → 更局部。


### 13.5 UMAP：现代替代方法

**UMAP（Uniform Manifold Approximation and Projection）** 是一种更现代的降维方法：

* 比 t-SNE 更快（尤其大数据集）
* 保留更多全局结构（簇之间的距离有意义）
* 可用作 ML 预处理（不像 t-SNE 只能用于可视化）
* 有基于黎曼几何的坚实数学基础

可视化方面：t-SNE 和 UMAP 结果定性相似；UMAP 更快。预处理方面：UMAP 更优，因为它保留全局结构且能投影新数据。
