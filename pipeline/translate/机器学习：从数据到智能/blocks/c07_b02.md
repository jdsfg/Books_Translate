#### \lambda 的影响

* **\lambda = 0**：恢复普通最小二乘（OLS），无正则化。
* **\lambda \to \infty**：惩罚主导，所有权重被压向零。模型退化为总是预测均值。
* **\lambda 适中**：权重被"收缩"向零，但不完全置零。收缩程度随 \lambda 增大而增加。

解集 \{\mathbf{w}^*_{\text{ridge}}(\lambda) : \lambda \geq 0\} 称为 **regularization path（正则化路径）**。绘制每个权重随 \lambda 变化的路径，可以看出在不同复杂度水平下哪些特征被"使用"。


#### 岭回归的贝叶斯解释

岭回归有一个优美的概率解释。假设我们在权重上放置一个高斯先验：

P(\mathbf{w}) \propto \exp\!\left(-\frac{\lambda}{2\sigma^2} \|\mathbf{w}\|^2\right) = \mathcal{N}(\mathbf{0}, \frac{\sigma^2}{\lambda} I)

该先验说：在看到任何数据之前，我们认为权重接近零。把这个先验与第5章的高斯似然通过贝叶斯定理结合，最大后验（MAP）估计为：

\mathbf{w}^*_{\text{MAP}} = \arg\max_\mathbf{w} P(\mathbf{w} | \text{data}) = \arg\min_\mathbf{w} \left[ \frac{1}{\sigma^2}\|X\mathbf{w} - \mathbf{y}\|^2 + \frac{\lambda}{\sigma^2}\|\mathbf{w}\|^2 \right]

正是岭回归。正则化强度 \lambda 编码了我们对权重大小的先验信念。大的 \lambda 表示强先验：权重应接近零。

**这一联系贯穿 ML：** 几乎每个正则化都有贝叶斯解释，即对参数的先验。理解这一点使正则化显得有原则，而非临时。


#### 常见误解

岭回归把所有权重压向零，但 *从不会把任何权重精确设为零*。这是与 Lasso（下一节）的关键区别。岭保留所有特征，只是削弱不那么重要的特征。如果你需要只使用特征子集的模型，岭不是合适工具。


### 6.3 Lasso 回归（L1 正则化）


#### 定义：Lasso 回归

**Lasso（Least Absolute Shrinkage and Selection Operator）** 使用 \ell_1 惩罚：

L_{\text{lasso}}(\mathbf{w}) = \frac{1}{m}\|X\mathbf{w} - \mathbf{y}\|^2 + \lambda \|\mathbf{w}\|_1 = \frac{1}{m}\sum_{i=1}^m (y_i - \mathbf{w}^\top \mathbf{x}_i)^2 + \lambda \sum_{j=1}^n |w_j|

用平实的语言说，我们不是惩罚权重的 *平方* 和，而是惩罚权重的 *绝对值* 和。

这个看似很小的改动带来戏剧性后果：**Lasso 让许多权重精确变为零**，产生稀疏解。
