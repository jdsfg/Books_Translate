校验：0.867 + 0.067 + 0.067 \approx 1.0。贪婪动作（right）被选中最频繁，两个非贪婪动作均分剩余探索概率。这确保智能体持续探索，防止过早收敛到次优策略。


#### 应用问题

**Q1.** 你正在构建一个推荐系统的 RL 智能体：每个时间步向用户推荐 10 个物品之一；若用户点击奖励 +1，否则 0。会话最长 20 步。设计 MDP：指定状态空间、动作空间、奖励函数和合理的折扣因子。指出该推荐场景特有的一个挑战。

**答案：**

**状态空间：** 用户上下文特征——过去浏览物品、过去点击、时间、人口统计（若有），以及当前会话已推荐物品。实用表示：最近交互向量（如最近 5 个点击物品嵌入 + 会话点击率 + 时间特征）。

**动作空间：** 离散，|A| = 10 个物品（或更大目录，先经检索步收窄为候选）。

**奖励函数：** 该时间步点击则 R = +1，否则 R = 0。可选：长停留时间奖励 +\alpha，明确负反馈（点踩）惩罚 -\beta。

**折扣因子：** \gamma = 0.8–0.95。会话短（20 步），适中折扣即可。太低：智能体忽视未来点击；太高：会话足够短，近视行为也可接受。

**特定挑战：** **探索代价高。** 向用户展示不相关物品探索有真实代价（错失点击、可能损害用户体验）。与游戏中探索无真实代价不同，推荐需仔细平衡探索。**部分可观测性** 也很严重：用户偏好随时间变化，无法被状态特征完全捕捉。

**Q2.** RL 智能体已训练解决迷宫并达到最优性能。然后将折扣因子从 \gamma = 0.5 加倍到 \gamma = 0.99（不重新训练）。定性描述智能体行为可能如何变化，为什么？

**答案：**

当 \gamma = 0.5 时，智能体优化即时奖励——5 步后的奖励只值 0.5^5 = 0.031 倍即时奖励。Q 值反映这种对快速奖励的强烈偏好。

当 \gamma = 0.99（但 Q 表不变），智能体使用为 \gamma = 0.5 校准的 Q 值，而在长期回报现在重要得多的环境中决策。Q 值不再准确反映新 \gamma 下的真实折扣回报。

实际效果：智能体仍遵循相同贪婪策略（因为策略依赖 Q 值相对排序，而非绝对尺度）。但该策略对 \gamma = 0.99 很可能次优——某些在 \gamma = 0.5 下次优的路径（因需等待更久才能获得更大奖励）在 \gamma = 0.99 下应更优，但智能体不会选择，因为其 Q 值未反映这一点。

**结论：** 必须在新 \gamma 下重新训练，因为 Q 值根本上是针对特定折扣因子校准的。
