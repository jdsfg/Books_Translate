我们已经知道如何表示数据（线性代数）以及如何建模不确定性（概率）。但还有一个问题未回答：一旦决定想要最小化什么（损失函数），我们该如何真正找到最小值？

答案是微积分。具体来说，我们需要计算 *gradient*（梯度）——导数在多变量情形的推广——然后沿着梯度向下走到最小值。这个过程称为 *gradient descent*（梯度下降），是几乎每一个现代 ML 模型训练的核心。

本章也是高中微积分中一个单一思想——链式法则——成为训练神经网络（数十亿参数！）计算上可行的关键。我们将在第15章明确这一联系，它称为 **反向传播（backpropagation）**。


### 4.1 导数：变化率


#### 定义：导数

函数 f: \mathbb{R} \to \mathbb{R} 在点 x 处的 **导数（derivative）** 为：

f'(x) = \frac{df}{dx} = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}

用平实的语言说，导数度量当 x 增加一个极小量时 f(x) 变化多少。若 f'(x) > 0，函数在 x 处递增；若 f'(x) < 0，递减；若 f'(x) = 0，则平坦——可能是极小或极大。

你需要知道的关键导数：

* \frac{d}{dx}[c] = 0（常数）
* \frac{d}{dx}[x^n] = nx^{n-1}（幂法则）
* \frac{d}{dx}[e^x] = e^x
* \frac{d}{dx}[\log x] = 1/x
* \frac{d}{dx}[\sin x] = \cos x


#### 链式法则

机器学习中最重要的一条求导法则：

\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)

或用莱布尼茨记号：若 y = f(u) 且 u = g(x)，则 \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}。

用平实的语言说：复合函数的变化率等于每一步变化率的乘积。

**示例：** 设 f(x) = (3x + 1)^5。令 u = 3x + 1，则 f = u^5。于是：

\frac{df}{dx} = 5u^4 \cdot 3 = 15(3x + 1)^4

链式法则在反向传播中变成了"计算的链式法则"：神经网络是许多函数的复合，反向传播逐层应用链式法则，计算损失对每个权重的依赖。


#### 常见误解

学生们常以为链式法则只适用于 `(3x+1)^5` 这种"嵌套"函数。事实上，它适用于任何函数复合——包括神经网络的整个前向传播，它计算 \text{loss} = L(f_n(f_{n-1}(\cdots f_1(\mathbf{x}) \cdots)))。正是链式法则让我们能高效地计算任意层 k 的 \partial L / \partial \mathbf{w}_k。
