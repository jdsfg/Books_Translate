到 2012 年，我们已有深度网络和使它们可训练的 ReLU 激活。但训练非常深网络（50+ 层）仍然不稳定：梯度不一致，收敛慢，性能对架构选择高度敏感。三项创新——批次归一化（batch normalization，也称批量归一化）、dropout 和残差连接——改变了局面，使数百层网络的训练成为可能。

这些技术不是细枝末节；它们是对深度网络构建和训练方式的结构改变。任何想在实践中训练深度网络的人都必须理解它们。


### 18.1 批次归一化（Batch Normalization，也称批量归一化）


#### 问题：内部协变量偏移

训练过程中，随着早期层权重变化，后续层输入分布也变化——这被称为 **内部协变量偏移（internal covariate shift）**。第 \ell 层必须不断适应变化的输入分布，减慢收敛。极端偏移还会把输入推入 sigmoid/tanh 激活的饱和区。


#### 定义：批量归一化

给定一个批次/小批量（mini-batch）中某神经元的预激活值 \{z_1, \ldots, z_B\}，批次归一化：

  1. 计算 mini-batch（批次）均值：\mu_\mathcal{B} = \frac{1}{B}\sum_{i=1}^B z_i
  2. 计算 mini-batch（批次）方差：\sigma^2_\mathcal{B} = \frac{1}{B}\sum_{i=1}^B (z_i - \mu_\mathcal{B})^2
  3. 归一化：\hat{z}_i = \frac{z_i - \mu_\mathcal{B}}{\sqrt{\sigma^2_\mathcal{B} + \epsilon}}
  4. 用 **可学习参数** \gamma 和 \beta 缩放与平移：y_i = \gamma \hat{z}_i + \beta

用平实的语言：把每个神经元的激活归一化为每个批次/小批量（mini-batch）内零均值、单位方差，再让网络学习按需重新缩放和平移分布。

**好处：**

* 减少内部协变量偏移 → 更快收敛
* 允许更高学习率 → 进一步加速（实践中训练速度 3–10 倍）
* 起到正则化作用（mini-batch 统计引入噪声）→ 减少过拟合
* 降低对权重初始化的敏感性

**推断时：** 使用训练时收集的 \mu 和 \sigma^2 的滑动平均（running statistics），代替 mini-batch/批次统计。这使预测确定且与批量大小无关。

**放置位置：** 通常在激活函数 *之前*：... → Linear → BatchNorm（批次归一化）→ ReLU → ...。某些架构（ResNet）放置不同；现代 Transformer 使用 **层归一化（LayerNorm）**——对每个样本跨特征归一化，而非对单个特征跨样本。


#### 常见误解

很多学生认为批量归一化只是通过减少内部协变量偏移起作用。Santurkar 等人 2018 年的论文证明，批量归一化主要让损失景观更平滑（更 Lipschitz），从而允许更大的梯度步。内部协变量偏移是最初动机，但不是主要机制。
