* 人类习惯、成瘾和动机可被理解为生物 RL 系统的表现：当状态-动作价值稳定时形成习惯；成瘾可能涉及 TD 预测误差信号失调
* 探索-利用权衡在人类好奇心和冒险行为中有对应
* 稀疏奖励 RL 问题的困难反映人类在没有反馈时学习困难

局限：生物 RL 与丰富的世界模型、先天结构和语言共同运作——纯 RL 智能体缺乏这些能力。大脑不只是 RL 引擎；它是 RL 引擎加上对世界的大规模生成模型。这就是现代 RL 研究越来越多地将基于模型的 RL（学习世界模型）与策略优化结合的原因。


### 本章总结

强化学习是从交互与奖励中学习、没有标注数据集的范式。

核心思想：

* **MDP 框架** ：状态、动作、转移概率、奖励、折扣因子 \gamma；马尔可夫性质使问题可处理
* **贝尔曼方程** ：递归关系 V^*(s) = \max_a [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s')]; 价值型 RL 基础
* **Q-learning** ：off-policy TD 方法；收敛到最优 Q-函数；\varepsilon-greedy 探索
* **DQN** ：用经验回放和目标网络扩展 Q-learning，以神经网络处理大状态空间
* **策略梯度（REINFORCE）** ：直接优化策略；通过优势估计降低高方差
* **Actor-critic（PPO）** ：结合策略梯度与价值函数；多数连续控制和离散动作任务的最先进方法
* **挑战** ：样本效率、奖励设定、部分可观测性、稀疏奖励
