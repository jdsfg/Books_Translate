#### 样本效率差距

人类可能只看十几只猫就学会识别猫。GPT-4 在数万亿 token 上训练。这一差距是数量级的。深度学习与生物学习相比样本效率极低。我们不知道生物学习为何如此高效，也不知道如何复制它。

部分方法：元学习（"学会学习"）、神经程序合成、组合泛化（学习可组合的规则而非记忆示例）。没有一种方法弥合差距。


#### 推理与组合性

语言模型表现出令人印象深刻但脆弱的推理。它们能解决新颖数学问题，但在轻微变体上失败。它们能生成语法合理的代码但包含语义错误。当前 Transformer 是否能进行真正的 **系统性泛化** ——把学到的规则组合地应用到新概念组合——仍存争议。

**SCAN、COGS 等组合基准** 反复表明标准 Transformer 无法组合泛化（把学到的规则应用到新组合）。链式思维提示在许多任务上显著提升推理，但机制不清：模型是在链中进行计算，还是模式匹配训练数据中的链式思维推理模式？


#### 世界模型与因果推理

语言模型训练来预测 token。预测 token 是否需要学习世界的因果模型，抑或仅学习表面统计模式就足够？

**支持世界模型的证据：** LLM 在因果推理问题、物理直觉任务和反事实场景上表现良好——暗示某种内部世界模型。

**反对的证据：** LLM 在分布外因果查询上系统性失败，混淆相关性与因果性，且对相同因果问题的简单重述敏感。

**苦涩的教训（Sutton，2019）：** 历史上，依赖人类设计结构（特征工程、知识图谱、因果图）的方法都被规模 + 计算超越。这表明从数据中直接学习因果表示可能比手工设计更有效——但我们尚不知如何保证它。


#### 幻觉与可靠性

大型语言模型会产生幻觉：它们生成流利、自信但事实上错误的断言。这是训练目标的根本结果：模型被训练生成合理的续写，而非经验证的事实。减少幻觉需要 grounding（检索增强生成——在生成前先获取相关事实）、可验证性（可检查显式步骤的链式思维）或不确定性量化（模型应对其主张表达适当置信度）。

这些问题都未解决。随着规模和 RLHF，幻觉率有所下降，但未归零——对于高风险领域（医学、法律、安全关键工程），即使罕见的幻觉也不可接受。
