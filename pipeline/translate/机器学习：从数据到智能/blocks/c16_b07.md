#### 应用问题

（以下"批量"均对应英文 batch，即批次。）

**Q1.** 你在一个数据集上训练 5 层 MLP。10 个 epoch 后查看梯度大小：最后一层梯度幅值约 1.0，但第一层约 10^{-6}。出现了什么问题？两种修复方法？

*提示*

症状是层间梯度幅值差异巨大。第14章在 sigmoid 激活语境中描述过此问题。

**答案：** 这是 **梯度消失问题**。梯度在反向传播逐层时指数衰减。第一层几乎收不到训练信号——其权重无意义更新。

**修复 1——换用 ReLU 激活：** 若使用 sigmoid 或 tanh，换为 ReLU（或 Leaky ReLU）。ReLU 正输入导数为 1，因此梯度不会在每层乘以小于 1 的因子。第一层获得与最后一层大小相近的梯度。

**修复 2——批量归一化/批次归一化（batch normalization，第18章）：** 归一化每层输入，防止激活值变得过大或过小。这使 sigmoid/tanh 输入处于非饱和区，防止梯度消失。

**额外修复：** 谨慎的权重初始化（Xavier/He）、残差连接（第18章）或梯度裁剪。

**Q2.** 一个 3 层网络架构：输入（2）→ 隐藏（3，ReLU）→ 输出（1，线性）。隐藏层权重矩阵 W^{(1)} = \begin{pmatrix} 1 & -1 \\ 0.5 & 0.5 \\ -1 & 2 \end{pmatrix}，偏置 \mathbf{b}^{(1)} = (0, 0, 0)^\top，输出权重 \mathbf{w}^{(2)} = (1, 1, -1)^\top，偏置 b^{(2)} = 0。对输入 \mathbf{x} = (1, 1)^\top 计算前向传播。网络总共有多少参数？

**答案：**

**隐藏预激活：**

\mathbf{z}^{(1)} = W^{(1)}\mathbf{x} + \mathbf{b}^{(1)} = \begin{pmatrix} 1(1) + (-1)(1) \\ 0.5(1) + 0.5(1) \\ (-1)(1) + 2(1) \end{pmatrix} = \begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix}

**隐藏激活（ReLU）：**

\mathbf{a}^{(1)} = \text{ReLU}(\mathbf{z}^{(1)}) = \begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix}

**输出：**

z^{(2)} = \mathbf{w}^{(2)\top}\mathbf{a}^{(1)} + b^{(2)} = 1(0) + 1(1) + (-1)(1) + 0 = 0

**总参数：** 隐藏层：2 \times 3 + 3 = 9；输出层：3 \times 1 + 1 = 4。总计 9 + 4 = 13 个参数。
