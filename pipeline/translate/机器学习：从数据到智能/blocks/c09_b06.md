**答案：** 训练准确率衡量模型对训练数据的拟合程度——但机器学习的全部意义在于对新数据泛化。一个逐字记忆训练集的模型训练准确率可达 100%，但在新数据上可能完全失败。训练准确率不提供泛化信息；它只衡量模型过拟合的程度。模型质量的正确度量永远是在训练过程中未使用的数据上的性能。


#### 应用问题

**Q1.** 你正在构建信用卡欺诈检测器。100,000 笔交易中：99,700 笔正常，300 笔欺诈。你的模型把 200 笔交易预测为欺诈，其中 150 笔确实是欺诈。计算：precision、recall、specificity、F1 和 accuracy。哪个指标最能反映模型的有用性？

*提示*

先填混淆矩阵：TP = 150，FP = 50，FN = 150，TN = 99,650。

**答案：** 由题意：

* TP = 150（正确标记的欺诈）
* FP = 200 - 150 = 50（正常却被标记为欺诈——误报）
* FN = 300 - 150 = 150（漏掉的欺诈）
* TN = 99,700 - 50 = 99,650（正确排除的正常交易）

**精确率 Precision** = TP/(TP+FP) = 150/200 = **75%（即 3/4）**——被标记为欺诈的交易中四分之三确实是欺诈

**召回率 Recall** = TP/(TP+FN) = 150/300 = **50%**——模型抓到一半欺诈

**Specificity** = TN/(TN+FP) = 99,650/99,700 = **99.95%**——几乎所有正常交易都被正确排除

**F1 分数（F1 Score）** = 2·(0.75·0.50)/(0.75+0.50) = 2·0.375/1.25 = **60%**

**准确率 Accuracy** = (TP+TN)/(total) = (150+99,650)/100,000 = **99.8%**——但这与"总预测正常"基线 99.7% 几乎相同

对欺诈检测而言，**recall** 可以说是最重要的（抓到欺诈），同时要与 precision（不让欺诈分析师被误报淹没）平衡。F1 60% 给出一个平衡的单一数字。Accuracy 几乎无用。实践中，你会调整分类阈值，找到最符合业务约束的精确率-召回率权衡（例如"每天最多调查 500 笔交易，尽可能多抓欺诈"）。

**Q2.** 描述下面问题中的数据泄漏场景："预测患者未来 30 天内是否会住院，使用电子病历提取的特征。"给出两个会泄漏目标的特征和两个不会泄漏的特征。

**答案：**

**会泄漏的特征：**

* "过去一个月的住院次数"——如果预测未来 30 天住院，最近住院的患者在该特征上计数为 1+。更重要的是，若训练数据跨越多年，该特征可能包含未来时间窗的信息。
* "未来 2 周内的专科转诊次数"——直接涉及未来信息。

**不会泄漏的特征（在事件之前可获得）：**

* "截至预测日期的慢性病数量（糖尿病、高血压等）"
* "预测日期最近一次门诊就诊时的年龄、性别、BMI"
* "预测日期前 12 个月内的急诊次数（截至预测日期）"

关键检验：这个特征能否在 30 天窗口 *开始之前* 观测到？如果可以，就是合法特征；如果它需要 30 天内或之后发生的任何信息，就会泄漏。
