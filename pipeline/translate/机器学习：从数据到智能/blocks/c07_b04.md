### 6.5 选择 \lambda：交叉验证

正则化强度 \lambda 是一个 *超参数（hyperparameter）* —— 训练前必须设定的参数，而非从数据中学得。\lambda 太小则正则化不足（过拟合）；太大则正则化过度（欠拟合）。

标准方法是 **k 折交叉验证（k-fold cross-validation）**：

  1. 把训练数据分成 k 个大小相等的 fold（通常 k = 5 或 k = 10）
  2. 对每个候选 \lambda：
     * 对 i = 1, \ldots, k：在除第 i 折外的所有折上训练；在第 i 折上验证
     * 平均 k 个验证误差
  3. 选择平均验证误差最小的 \lambda
  4. 用选定的 \lambda 在所有训练数据上重新训练

这给出了每个 \lambda 在未见过数据上表现的无偏估计，而又"不动"测试集。

一个实用捷径：用 **LARS 算法** 对 Lasso 或简单矩阵运算对 Ridge 一次性拟合整条正则化路径（所有 \lambda 值）。这比分别拟合每个 \lambda 更高效。


#### 常见误解

用于选择 \lambda 的验证误差不能作为 *最终* 泛化误差的估计。一旦根据验证表现选定 \lambda，你就已经把验证集"用于"模型选择。最终性能应在建模决策之前就留出的 *测试集* 上报告。第8章会正确处理这一点。


### 6.6 超越线性模型的正则化

L1 和 L2 正则化的思想不只适用于线性回归——它们适用于任何 ML 模型：

* **逻辑回归**（第7章）：对分类权重施加 Ridge/Lasso 正则化
* **神经网络**（第15章）：**权重衰减（weight decay）** 在损失中加入 \lambda \|\mathbf{w}\|^2 —— 等价于 L2 正则化
* **支持向量机**（第11章）：参数 C = 1/\lambda 控制间隔与误分类的权衡——具有 Ridge 风格
* **决策树**（第9章）：通过深度限制和最小叶节点大小来正则化，而不是惩罚权重

同样的直觉到处适用：正则化限制模型复杂度以防过拟合，正则化强度必须调节以平衡偏差与方差。
