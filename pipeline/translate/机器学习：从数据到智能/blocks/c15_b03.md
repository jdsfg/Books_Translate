#### 定义：双曲正切（tanh）激活

f(z) = \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} \in (-1, 1)

类似 sigmoid 但以零为中心（输出在 [-1, 1] 而非 [0, 1]）。对隐藏层通常优于 sigmoid；仍会饱和。


#### 定义：修正线性单元（ReLU）

f(z) = \max(0, z) = \begin{cases} z & z > 0 \\ 0 & z \leq 0 \end{cases}

**ReLU 改变了一切。** ReLU 出现前（2010 年前），深度网络几乎不可训练，因为梯度消失。ReLU 有几个关键性质：

  1. **正输入不饱和：** z > 0 时梯度恰好为 1，梯度可在活跃神经元中自由流动
  2. **计算便宜：** 仅 max 操作，无需指数
  3. **稀疏激活：** 约一半神经元对任何给定输入输出 0，产生生物学合理且计算高效的稀疏表示
  4. **经验上极优：** AlexNet（2012）证明 ReLU 网络在大规模图像识别上显著优于 sigmoid/tanh 网络

**问题：** "死亡 ReLU"——若神经元输入始终为负，输出永远为 0，梯度永远为 0。该神经元永不学习。

**变体：** Leaky ReLU 对负输入使用 f(z) = \max(0.01z, z)（永不完全死亡）。ELU（Exponential Linear Unit）和 GELU（Gaussian Error Linear Unit，Transformer 中使用）是更平滑的替代。


#### 常见误解

学生常以为任何可微函数都能当激活函数。事实上，一个关键要求是 **非线性** ——否则整个网络退化为线性函数。另一个是 **光滑性**（或至少分段光滑），以便梯度训练。而且函数不应处处饱和——若所有输入映射到相同输出，梯度处处消失，训练失败。


### 14.6 通用近似定理

神经网络理论中最引人注目的理论结果之一：


#### 定义：通用近似定理

一个具有 *足够宽度* 单隐藏层的前馈神经网络，使用非恒定、有界、连续激活函数，可以任意精度（precision，这里指数学近似精度，不是分类指标精确率）逼近 \mathbb{R}^n 的紧子集上的任意连续函数。

用平实的语言：单隐藏层原则上足以表示任何光滑函数。只是可能需要天文数字的隐藏单元。

**这意味着什么（以及不意味什么）：**

* 它保证 *表达能力*：神经网络能表示任何函数
* 它没有说明如何 *找到* 正确权重（优化问题）
* 它没有说明需要多少神经元（答案可能是输入维度的指数）
* 它不意味着浅层网络对 *实际* 学习足够——深度网络能通过组合简单操作高效表示复杂函数，事实证明如此

该定理主要是理论兴趣。实践中，深度（不仅是宽度）使神经网络能高效表示复杂函数，反向传播（第15章）是我们找到权重的方法。
