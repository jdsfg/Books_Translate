#### 概念检测

**Q1.** 对一维点集 {1, 2, 8, 9} 手动运行 K=2 的 K-means。初始中心 \mu_1 = 1, \mu_2 = 5。展示两次迭代。

**答案：**

**第 1 次迭代 — 分配：**

* 点 1：|1-1| = 0，|1-5| = 4 → 簇 1
* 点 2：|2-1| = 1，|2-5| = 3 → 簇 1
* 点 8：|8-1| = 7，|8-5| = 3 → 簇 2
* 点 9：|9-1| = 8，|9-5| = 4 → 簇 2

簇 1：{1, 2}，簇 2：{8, 9}

**第 1 次迭代 — 更新：** \mu_1 = (1+2)/2 = 1.5，\mu_2 = (8+9)/2 = 8.5

**第 2 次迭代 — 分配：**

* 点 1：|1-1.5| = 0.5，|1-8.5| = 7.5 → 簇 1
* 点 2：|2-1.5| = 0.5，|2-8.5| = 6.5 → 簇 1
* 点 8：|8-1.5| = 6.5，|8-8.5| = 0.5 → 簇 2
* 点 9：|9-1.5| = 7.5，|9-8.5| = 0.5 → 簇 2

分配不变 → **收敛**。最终簇 {1, 2} 与 {8, 9}，中心分别为 1.5 与 8.5。

**Q2.** K-means 用欧氏距离把每个点分配到最近质心。如果特征尺度差异很大（如收入以千美元计、年龄以年计）会怎样？

**答案：** 大尺度特征主导欧氏距离。若收入范围 20,000–200,000（跨度 180,000），年龄范围 20–80（跨度 60），收入差异主导聚类。年龄差异很大但收入相近的两个人会被分到同一簇；年龄相近但收入差异很大的两个人会被分到不同簇——无论哪种差异更有语义意义。

**修复：** 运行 K-means 前把所有特征标准化为零均值、单位方差。标准化后每个特征对距离计算贡献相同。这是任何基于距离的方法（K-means、KNN、DBSCAN、RBF 核支持向量机（SVM））必不可少的预处理。

**Q3.** 举出 DBSCAN 相对于 K-means 的一个优势，以及一个 DBSCAN 会失败的情形。

**答案：** **优势：** DBSCAN 能找到任意形状簇。K-means 只找凸（Voronoi）簇。对环形或月牙形簇的数据，DBSCAN 正确识别而 K-means 会错误分割。

**DBSCAN 失败：** 簇密度差异很大时（例如一个 10,000 点的密集簇和一个 100 点的稀疏簇）。固定 \epsilon 对密集簇合适时会把稀疏簇点判为噪声；对稀疏簇合适时密集簇会和其他所有点合并。HDBSCAN 通过变化密度阈值解决这个问题。
