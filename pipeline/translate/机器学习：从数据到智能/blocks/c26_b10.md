**答案：** 梯度裁剪约束梯度的 **敏感度（sensitivity）** ——若添加或移除单个训练样本，梯度最多变化多少。没有裁剪时，梯度敏感度无界：单个异常样本可能贡献任意大的梯度，为掩盖其贡献所需噪声也必须任意大。

DP 保证要求噪声尺度 \sigma 与敏感度 C（裁剪范数）成正比：添加 \mathcal{N}(0, \sigma^2 C^2 \mathbf{I}) 噪声即可提供 (\varepsilon, \delta)-DP，因为每个样本的贡献被限制在范数 C 内，噪声淹没了任何个体的具体梯度信号。

没有裁剪：敏感度无界，因此任何有限噪声都无法提供 DP。等价地，所需噪声必须大到覆盖最坏情况梯度幅值，从而完全破坏学习信号——模型无法有效训练。裁剪正是使隐私-准确率权衡可管理的原因。


#### 应用问题

**Q1.** 你正在为一家科技公司构建招聘模型。历史训练数据显示，在相同资质水平下，男性申请者被雇佣的可能性是女性 3 倍（由于过去招聘经理的偏见）。提出一个从数据收集到部署的完整公平性感知 ML 流程。

**答案：**

**数据收集与预处理：**

* 审计训练标签：识别历史录用/拒绝决定反映的是资质差异还是招聘经理偏见。如可能，让 HR 盲审过去被拒绝样本。
* 收集新评估标准：用标准化技术评估分数（编码测试、结构化面试评分）替代二值录用/拒绝标签，减少个体评估者偏见。
* 记录偏见：创建数据表，注明 3 倍差异及其可能原因。

**特征工程：**

* 从特征中排除姓名、性别、代词及任何直接性别代理
* 审计间接代理：某些大学、运动或课外活动可能与性别相关——评估并考虑排除或控制这些特征
* 聚焦可评估技能：编码测试分数、作品集项目、相关经验

**模型训练：**

* 使用机会均等作为公平性约束（跨性别群体相等 TPR 和 FPR）
* 应用对抗去偏：联合训练分类器和性别预测器；惩罚分类器使其无法从表示中推断性别
* 若仍使用历史数据：重加权样本以降低历史上偏见录用决策的影响

**评估：**

* 按性别群体分别评估准确率、FPR、FNR、精确率
* 测量交叉性表现：有色人种女性、非传统背景女性
* 进行 A/B 测试：比较新模型与人工审核者的结果

**部署与监控：**

* 所有模型推荐必须经过人工审核（模型辅助，不决策）
* 按人口群体季度追踪录用率；为差异设置告警阈值
* 为被拒候选者建立申诉流程
* 每年由独立第三方审计
