#### 为什么 Lasso 产生稀疏性：几何直觉

为了理解，考虑两种方法的约束形式：

**岭回归：** 在 \|\mathbf{w}\|^2 \leq t 约束下最小化 MSE（留在 \ell_2 球内）

**Lasso：** 在 \|\mathbf{w}\|_1 \leq t 约束下最小化 MSE（留在 \ell_1 球内，即"钻石"形区域）

\ell_2 球是光滑的球。\ell_1 球是钻石形，*棱角* 位于坐标轴上（如 (t, 0, 0, \ldots)、(0, t, 0, \ldots) 等点）。当 MSE 的椭圆形等高线（中心在未经正则化的 OLS 解）与约束区域"碰撞"时，它们更可能先碰到钻石的棱角，而不是任意一个面上的点。棱角对应稀疏解（大多数权重为零）。

相比之下，\ell_2 球没有棱角——碰撞可以发生在球面上任意一点，因此不偏好精确零权重。

**实际意义：** Lasso 自动进行 **特征选择** —— 识别哪些特征真正具有预测性，其余置零。当面对数百或数千特征并希望模型可解释时，这非常宝贵。


#### Thread A——正则化实战（A2）

_[Thread A：A2——给房价模型加入正则化；Ridge 和 Lasso 自动选择特征]_

假设我们把房价模型扩展到 25 个特征：原始 4 个加上社区统计、周边设施距离、历史纳税记录等。我们用交叉验证后的 \lambda 拟合 Ridge 和 Lasso。

**Ridge 结果：** 25 个特征全部保留，但弱特征（例如最近餐厅距离：w = 0.003）的权重被压到接近零。模型仍"使用"所有特征，只是对弱特征使用得非常轻。

**Lasso 结果：** 25 个特征中 17 个被精确设为零。存活的 8 个包括：居住面积、房龄、车库数、学区评分、到市中心距离以及三个社区统计量。验证集上的 RMSE 略优于 Ridge，因为模型把注意力集中在真正具有预测性的特征上。

这就是 Lasso"自动特征选择"性质的体现。我们无需手动决定包含哪些特征——Lasso 自己搞定了。


### 6.4 Elastic Net：两者兼得


#### 定义：Elastic Net

**Elastic Net** 同时结合两种惩罚：

L_{\text{elastic}}(\mathbf{w}) = \frac{1}{m}\|X\mathbf{w} - \mathbf{y}\|^2 + \lambda_1 \|\mathbf{w}\|_1 + \lambda_2 \|\mathbf{w}\|^2

用平实的语言说：既把权重压向零（岭回归性质），又鼓励稀疏（Lasso 性质）。当特征相关时，Elastic Net 比纯 Lasso 处理得更好（Lasso 可能任意地从一组相关特征中挑一个）。

比例 \alpha = \lambda_1 / (\lambda_1 + \lambda_2) \in [0, 1] 在纯 Ridge（\alpha = 0）和纯 Lasso（\alpha = 1）之间插值。
