#### 定义：随机变量

**随机变量（random variable）** X 是从样本空间到实数的函数，给每个结果赋予一个数值。

* **离散（discrete）** 随机变量：取值为可数集合（例如产品缺陷数：0, 1, 2, ...）
* **连续（continuous）** 随机变量：取值为一个区间（例如房价、温度）

对离散随机变量 X，**概率质量函数（probability mass function, PMF）** p(x) = P(X = x) 给出每个值的概率。

对连续随机变量 X，**概率密度函数（probability density function, PDF）** f(x) 满足：

P(a \leq X \leq b) = \int_a^b f(x) \, dx

PDF 本身不是概率——它是密度。对任意特定值都有 P(X = x) = 0；我们只能计算区间上的概率。


#### 定义：期望与方差

随机变量 X 的 **期望（expectation）**（或均值）为：

\mathbb{E}[X] = \sum_x x \cdot p(x) \quad \text{（离散）} \qquad \text{或} \qquad \mathbb{E}[X] = \int_{-\infty}^\infty x \cdot f(x) \, dx \quad \text{（连续）}

用平实的语言说，期望是以概率为权重的可能值的加权平均。

**方差（variance）** 度量围绕均值的分散程度：

\text{Var}(X) = \mathbb{E}[(X - \mathbb{E}[X])^2] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2

**标准差（standard deviation）** 是 \sigma = \sqrt{\text{Var}(X)}，与 X 具有相同单位。

期望的重要性质（在 ML 推导中频繁使用）：

* **线性性：** \mathbb{E}[aX + bY] = a\mathbb{E}[X] + b\mathbb{E}[Y]（即使 X 和 Y 相关也成立）
* **独立性：** 若 X 和 Y 独立，则 \mathbb{E}[XY] = \mathbb{E}[X] \mathbb{E}[Y]


### 3.4 常见概率分布

这些分布在 ML 中出现的频率最高。


#### 伯努利分布

一次二元试验：成功概率为 p，失败概率为 1 - p。

P(X = 1) = p, \quad P(X = 0) = 1 - p \qquad \mathbb{E}[X] = p, \quad \text{Var}(X) = p(1 - p)

**出现场景：** 二分类器的输出。如果逻辑回归模型输出 \hat{p} = 0.7，它就是在说标签 y 服从 Bernoulli(0.7)。
