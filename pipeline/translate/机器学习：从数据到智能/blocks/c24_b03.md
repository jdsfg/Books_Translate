#### 探索与利用

纯利用智能体总是选择 \arg\max_a Q(s, a)。若初始 Q 值不准确，智能体会陷入利用次优动作，永未发现更优动作。

**\varepsilon-greedy 策略：**

* 以概率 \varepsilon：选择随机动作（**探索**）
* 以概率 1-\varepsilon：选择 \arg\max_a Q(s, a)（**利用**）

**退火 schedule：** 从 \varepsilon = 1.0（纯探索）开始，训练过程中衰减到 \varepsilon = 0.01。早期 Q 值不可靠——广泛探索；后期 Q 值准确——利用。


#### 为什么 Q-Learning 是 Off-Policy

Q-learning 是 **off-policy** ：更新目标使用 \max_{a'} Q(s', a')，对应贪婪策略——而非正在执行的 \varepsilon-greedy 策略。这意味着 Q-learning 即使在非最优行为（如 \varepsilon-greedy）下也能学习最优策略。关键优势：来自任何行为策略（甚至随机）的数据都能改进最优 Q-函数估计。


### 23.4 深度 Q 网络（DQN）

表格 Q-learning 在状态空间大或连续时失效。Atari 游戏状态空间是 210 \times 160 \times 3 像素图像——对表格来说太大。

**思路：** 用神经网络 Q(s, a; \theta) 近似任何状态的 Q-函数。


#### DQN 算法（Mnih 等，2015）

DQN 对 Q-learning 有两项关键创新：

**1. 经验回放**

不是立即用每个转移更新网络，而是把转移 (s, a, r, s') 存入 **回放缓冲区**。从中采样随机小批量训练。

为什么有用：连续转移高度相关。用相关数据训练违反 SGD 的 i.i.d. 假设，使学习不稳定。随机小批量打破相关性。

**2. 目标网络**

维护两个网络：**在线网络** Q(s, a; \theta)（每步更新）和 **目标网络** Q(s, a; \theta^-)（每 C 步通过 \theta^- \leftarrow \theta 复制更新）。

用目标网络计算 TD 目标：

y = r + \gamma \max_{a'} Q(s', a'; \theta^-)

为什么有用：没有目标网络时，我们追逐移动目标——\theta 的更新同时改变当前估计和目标，导致震荡。冻结目标网络 C 步使训练稳定。

**DQN 更新：**

L(\theta) = \mathbb{E}_{(s,a,r,s') \sim \text{buffer}}\left[\left(y - Q(s, a; \theta)\right)^2\right]

DQN 用原始像素输入在 49 款 Atari 游戏上达到人类水平—— landmark 结果，证明深度学习可规模化解决 RL 问题。


### 23.5 策略梯度方法

Q-learning 学习价值函数并隐式导出策略（\pi(s) = \arg\max_a Q(s, a)）。替代方案：**直接参数化策略** \pi_\theta(a|s) 并用梯度上升优化。
