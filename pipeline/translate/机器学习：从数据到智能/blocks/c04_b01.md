你收集了 1,000 栋房屋的销售数据。你训练了一个模型，它预测某栋房子将以 420,000 USD 售出。你应当多自信？模型可能出错——也许它遗漏了信息，也许市场不可预测，也许你拥有的数据还不够。如何对不确定性进行推理的问题，正是概率论与统计学的领域。

概率论在机器学习中不只是形式化的摆设。它是许多算法为何有效的基础。逻辑回归是一个概率模型。神经网络产生输出的概率分布。设计损失函数最系统化的方式来自 *maximum likelihood estimation*（最大似然估计）。当我们说模型"泛化"时，我们在对未见过的数据做概率性断言。本章给你提供概率化思考的工具。


### 3.1 概率：量化不确定性


#### 定义：概率空间

一个 **概率空间（probability space）** 包括：

* **样本空间（sample space）** \Omega：所有可能结果的集合
* 一组 **事件（events）**：\Omega 的子集
* 一个 **概率测度（probability measure）** P，给每个事件分配 [0,1] 中的一个数

对任意事件 A 和 B：

* P(A) \in [0, 1]
* P(\Omega) = 1（某件事总会发生）
* P(A \cup B) = P(A) + P(B)，如果 A 和 B *互斥*（不能同时发生）

用平实的语言说，概率是介于 0 和 1 之间的数，度量一个事件发生的可能性。P(A) = 1 表示 A 必然发生；P(A) = 0 表示 A 不可能发生；P(A) = 0.7 表示从长远看 A 发生 70% 的时间。

**条件概率（conditional probability）** 是在已知事件 B 发生的情况下事件 A 发生的概率：

P(A \mid B) = \frac{P(A \cap B)}{P(B)}

这是统计学中最重要的公式之一。它的含义是：已知 B 发生，这些 B 结果中有多大比例同时也满足 A？例如，P(\text{spam} \mid \text{subject contains "FREE"}) 是主题含 "FREE" 的邮件中实际为垃圾邮件的比例。


#### 定义：统计独立性

若知道一个事件对另一个事件毫无影响，则 A 和 B **独立（independent）**：

P(A \mid B) = P(A) \quad \Leftrightarrow \quad P(A \cap B) = P(A) \cdot P(B)

独立性是极强的假设，能极大简化计算。"朴素贝叶斯"分类器（一种基础 NLP 方法）假设所有特征在给定类别标签下条件独立——"朴素"是因为这几乎不会严格成立，但该分类器却往往出奇地有效。


#### 常见误解

学生们常把独立性和 *mutual exclusivity*（互斥）搞混。互斥事件不能同时发生（P(A \cap B) = 0），这意味着它们高度 *dependent*（相关）——若 A 发生，你确定 B 没发生。独立事件没有这种限制；它们可以同时发生，一个发生与否不影响另一个。两次公平抛硬币是独立的，不是互斥的。
