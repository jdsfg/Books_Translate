#### 概念检测

**Q1.** 解释下一个 token 预测（GPT）与掩码语言建模（BERT）的区别。每种方法对下游任务各有什么优势？

**答案：**

**下一个 token 预测（GPT）：** 训练 P(x_t \mid x_1, \ldots, x_{t-1})。因果性——每个位置只看过去上下文。架构：因果解码器。预训练目标直接训练模型生成文本——天然适合生成任务（续写、对话、代码生成）。

**掩码语言建模（BERT）：** 训练预测被掩码 token P(x_i \mid \text{all other tokens})。双向——每个位置看完整上下文。架构：非因果编码器。因为每个表示可整合左右上下文，对理解任务产生更丰富的表示。不适合生成（推断时不能掩码未来 token）。

**各自优势：**

* GPT：天然生成；上下文学习（少样本提示）效果好；更容易扩展到长输出
* BERT：对分类/抽取任务的上下文表示更丰富；更适合需要完整输入理解的任务（如问答、共指消解）

现代趋势：GPT 风格模型（仅解码器）已大量取代 BERT 风格（编码器）模型，即使对分类任务，因为大规模足以弥补双向性优势。

**Q2.** 什么是灾难性遗忘？为什么在小型数据集上微调预训练 LLM 时要担心它？

**答案：** **灾难性遗忘（catastrophic forgetting）**（也叫灾难性干扰）指在微调预训练模型完成新任务时，覆盖编码旧知识的权重。在医疗问答上微调 GPT-3 后，模型可能在通用语言任务上表现更差——微调"遗忘"了一些通用知识。

对小型微调数据集（如 1000 条样本），灾难性遗忘尤其令人担忧：模型进行多次梯度更新以拟合小数据集，但每次更新只优化一个狭窄任务。预训练的通用表示被任务特定表示覆盖。

缓解方法：

  1. **低学习率：** 小更新保留更多预训练知识
  2. **早停：** 在模型过拟合小数据集前停止
  3. **PEFT/LoRA：** 冻结大部分权重，只更新小适配器——预训练知识被构造性保留
  4. **微调时正则化：** 如 Elastic Weight Consolidation（EWC）对预训练中重要的权重改变施加惩罚

**Q3.** GPT-3 从未在情感分析上微调，但用 10 个示例提示就能达到不错准确率。从第一原理解释原因。

**答案：** GPT-3 在 570 GB 互联网文本上的预训练包含了海量显式或隐式带情感标签的内容：产品评论、社交媒体、带编辑语调的新闻文章、评论文章。模型学会了积极情感短语（"excellent"、"highly recommend"、"masterpiece"）与评论评价语境之间的统计关联。
