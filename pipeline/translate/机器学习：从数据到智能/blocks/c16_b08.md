#### 深入思考

**Q1.** 反向传播需要保存前向传播的所有中间激活（以便反向传播时计算梯度）。对数百万参数、大批量（大 batch/大批次）的网络，这可能需要数 GB GPU 显存。你能想到减少反向传播显存占用的方法吗？可能需要付出更多计算代价。

**讨论：** 这就是实践中用于超大模型的 **梯度检查点（gradient checkpointing）** 或 **重计算（rematerialization）** 技术：

不保存所有中间激活，只保存某些"检查点"层的激活。反向传播中，当需要非检查点层的中间激活时，从最近的检查点重新运行前向传播以重新计算它们。

**权衡：** 对 L 层，最优检查点布置可将显存减少 O(\sqrt{L}) 倍；计算增加约 2 倍（为非检查点段额外前向传播）。这是计算换显存的标准权衡。

另一方法：**块级梯度检查点**——在 Transformer 模型（第20章）中，在每个 transformer 块开头检查点，反向传播时重新计算每个块内部。GPT-3 和 Llama 等模型使用这一技术使训练巨大模型可行。

现代框架如 PyTorch 提供 `torch.utils.checkpoint` 自动实现。


### 本章总结

多层网络与反向传播是现代深度学习的基础。

核心思想：

* **前向传播**：逐层计算 \mathbf{z}^{(\ell)} = W^{(\ell)}\mathbf{a}^{(\ell-1)} + \mathbf{b}^{(\ell)} 和 \mathbf{a}^{(\ell)} = f(\mathbf{z}^{(\ell)})
* **反向传播**：高效链式法则梯度计算；误差信号 \boldsymbol{\delta}^{(\ell)} 通过权重矩阵反向传播
* **梯度消失**：sigmoid 激活导致早期层梯度消失；ReLU 解决此问题
* **小批量 SGD** 配合适当初始化与学习率调参是标准训练配方
