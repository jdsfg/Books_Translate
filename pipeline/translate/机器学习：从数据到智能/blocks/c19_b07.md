#### 应用问题

**Q1.** 你正在训练 50 层残差网络。训练损失稳定下降，但验证损失在第 30 个 epoch（轮）后开始上升。你当前没有使用 dropout，权重衰减 \lambda = 10^{-5}。提出三种具体正则化干预，按所需 effort 排序。

**答案：**

**干预 1（最小 effort）——增大权重衰减：** 把 \lambda 从 10^{-5} 提高到 10^{-4} 或 10^{-3}。只需改一行。权重衰减均匀正则化所有参数。

**干预 2（中等 effort）——在 FC 层加 dropout：** 在最终分类层前放 dropout（率 0.5），全局平均池化后用较低比率（0.1–0.3）。不要先给所有残差块加 dropout（会削弱 BatchNorm（批次归一化）的有效批次（batch）大小）；先限制在 FC 层。

**干预 3（较大 effort）——数据增强：** 激进增强（随机裁剪、水平翻转、颜色抖动、mixup/cutmix）可在模型大于数据集支持时显著减少过拟合。在数据加载 pipeline 中实现增强。

**每次干预后评估：** 用早停重新训练；看训练/验证损失差距是否缩小。


#### 深入思考

**Q1.** "彩票假设"（Frankle 和 Carlin，2019）提出，大神经网络包含许多更小的"中奖彩票"子网络，若从头训练这些子网络，可用少得多的参数达到相当性能。Dropout 与此有关。解释联系，并讨论对神经网络设计的含义。

**讨论：** 每次训练步骤 dropout 随机采样子网络。若彩票假设正确，其中一些采样子网络就是"中奖彩票"——它们包含正确连接组合以高效学习。用 dropout 训练时探索许多子网络，能保留下来的参数是那些在不同子网络配置中可靠贡献良好性能的参数。

彩票假设的实用含义：

  1. **网络剪枝：** 训练后识别并删除低幅值权重。得到的稀疏网络通常可达到相似性能，降低推断成本。
  2. **神经架构搜索：** 不手工设计架构，而是搜索正确的"中奖彩票"结构。
  3. **理解深度与宽度：** 大网络之所以需要，可能不是因为问题需要那么多参数，而是因为需要在众多可能性中找到中奖彩票。

该假设仍有争议——从头重新训练"中奖彩票"有时不如用 dropout 训练的完整网络——但大网络部分关于探索这一总体方向被普遍接受。它把 dropout 正则化与过参数化网络为何泛化良好的深层理论联系起来。
