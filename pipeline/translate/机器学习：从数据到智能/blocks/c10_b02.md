#### 定义：熵与信息增益

也可以从信息论出发使用 **熵（entropy）**：

H = -\sum_{k=1}^K p_k \log_2 p_k

其中 0 \log_2 0 定义为 0。节点纯净时 H = 0；二分类完美混合时 H = 1。

一次分裂的 **信息增益（information gain）** 是熵的减少量：

\text{IG} = H(\text{parent}) - \left[\frac{n_L}{n} H(\text{left}) + \frac{n_R}{n} H(\text{right})\right]

其中 n_L、n_R 是左右子节点的大小，n = n_L + n_R。Gini 不纯度与熵在实践中通常产生相似的树；选择哪个 rarely matters。


#### 定义：方差减少（用于回归）

对回归树，使用 **方差减少** 作为分裂准则：

\Delta V = \text{Var}(\text{parent}) - \left[\frac{n_L}{n}\text{Var}(\text{left}) + \frac{n_R}{n}\text{Var}(\text{right})\right]

选择使方差减少最大的分裂——让子节点中的标签尽可能同质。

**贪心算法：** 在每个节点评估所有可能的分裂（所有特征、每个特征内所有可能的分裂值），选择信息增益或方差减少最大的那个。这是贪心方法——它不保证全局最优树，但全局最优树问题是 NP-hard。

**寻找分裂值：** 对连续特征有 n 个值，有 n-1 个可能分裂。评估所有并选最优。对类别特征，尝试所有可能的二类划分。


#### 常见误解

学生常以为每步选最优分裂（贪心）会得到全局最优树。不会。一个中等的第一分裂可能让后续分裂更好，整体超过任何"最优"第一分裂的树。这是贪心算法的根本局限。但全局最优树问题计算不可行，因此贪心法是标准做法。
