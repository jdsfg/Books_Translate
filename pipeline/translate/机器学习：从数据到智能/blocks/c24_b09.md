#### 深入思考

**Q1.** AlphaGo Zero（2017）仅用自我对弈和 RL 就在围棋上达到超人类水平——训练中没有人类棋谱。然而它发现了人类专家在 2500 年围棋历史中未曾考虑的策略。讨论：这对围棋等领域知识性质意味着什么？这种方法的局限是什么？

**讨论：**

**它表明：** 人类数千年发展的围棋策略受人类认知限制（模式识别、记忆、直觉、教学方法）塑造。AlphaGo Zero 不受人类启发式约束——它只在赢/输信号引导下探索完整策略空间。它发现的超人类策略（非常规开局、愿意为 tempo 牺牲实地）表明人类围棋知识在人类认知可及范围内是局部最优，但在完整策略空间中全局次优。

更广泛地说：对任何奖励信号明确且可完美仿真的任务，RL 可能发现人类从未探索过的策略，仅仅因为人类没有以该规模系统探索的机制。

**方法局限：**

  1. **需要完美仿真：** AlphaGo Zero 能廉价地玩数百万盘棋。对大多数真实任务（药物发现、机器人），仿真不完美、昂贵或不可能。真实世界探索有物理代价。

  2. **奖励信号明确：** 围棋目标清晰（赢或输）。大多数真实问题目标模糊、多维度。指定奖励函数往往比解决优化问题更难。

  3. **可迁移性：** AlphaGo Zero 的围棋知识无法迁移到其他任务。相比之下，人类围棋知识可迁移到其他策略游戏、谈判和模式识别。RL 智能体对分布偏移和任务变化的脆弱性仍是一个根本局限。

  4. **计算成本：** 训练 AlphaGo Zero 需要数千 TPU 数周。通过纯 RL 发现策略的计算成本比利用人类知识大几个数量级。

**Q2.** RL 与大脑的联系：哺乳动物的多巴胺神经元放电模式与时序差分（TD）误差惊人相似。动物收到意外奖励时多巴胺激增；预期奖励未出现时多巴胺下降。这一生物学类比如何影响你对 RL 作为学习理论（而非只是算法）的理解？

**讨论：**

生物奖励学习与 RL 理论在 1990 年代由 Schultz、Dayan 和 Montague 建立的收敛令人瞩目：从纯数学原理推导出的 TD 学习，准确描述了多巴胺神经元的实际计算。

这一类比表明 RL 不仅是一种工程算法，而是 **规范理论** ——描述任何智能体（生物或人工）应如何学习最大化奖励。正如信息论描述信息的最优编码、贝叶斯推断描述信念的最优更新，TD 学习可能描述从序列经验中估计长期价值的最优方式。
