### 15.2 反向传播：推导链式法则

损失 L(\mathbf{w}) 依赖于输出 \mathbf{a}^{(L)}，而输出依赖于每层每个权重。我们要求：

\frac{\partial L}{\partial W^{(\ell)}} \quad \text{对所有层 } \ell

链式法则连接它们。定义第 \ell 层的 **误差信号（error signal）** 为：

\boldsymbol{\delta}^{(\ell)} = \frac{\partial L}{\partial \mathbf{z}^{(\ell)}}

这是损失关于第 \ell 层预激活的梯度——当改变第 \ell 层加权输入时，损失变化多少。

**输出层（\ell = L）：** 对 MSE 损失 L = \frac{1}{2}\|\mathbf{a}^{(L)} - \mathbf{y}\|^2，输出激活为恒等：

\boldsymbol{\delta}^{(L)} = \mathbf{a}^{(L)} - \mathbf{y}

对带 softmax 输出的交叉熵损失（多分类）：

\boldsymbol{\delta}^{(L)} = \hat{\mathbf{p}} - \mathbf{y}

其中 \hat{\mathbf{p}} 是预测概率向量。

**隐藏层（反向传播递归）：** 反向应用链式法则：

\boldsymbol{\delta}^{(\ell)} = \left[(W^{(\ell+1)})^\top \boldsymbol{\delta}^{(\ell+1)}\right] \odot f'(\mathbf{z}^{(\ell)})

用平实的语言：把来自下一层的误差通过权重 W^{(\ell+1)} 反向传播，再乘以激活函数的局部梯度。\odot 表示逐元素相乘。

**权重梯度：** 一旦知道 \boldsymbol{\delta}^{(\ell)}：

\frac{\partial L}{\partial W^{(\ell)}} = \boldsymbol{\delta}^{(\ell)} (\mathbf{a}^{(\ell-1)})^\top
\frac{\partial L}{\partial \mathbf{b}^{(\ell)}} = \boldsymbol{\delta}^{(\ell)}

这是误差信号与前一层激活的外积——与感知机更新规则结构相同。


#### 定义：反向传播算法

  1. **前向传播**：计算所有 \mathbf{z}^{(\ell)}, \mathbf{a}^{(\ell)}，\ell = 1, \ldots, L；保存它们
  2. **反向传播**：从损失计算 \boldsymbol{\delta}^{(L)}；然后递归计算 \boldsymbol{\delta}^{(\ell)}，\ell = L-1, \ldots, 1
  3. **梯度**：由 \boldsymbol{\delta}^{(\ell)} 和 \mathbf{a}^{(\ell-1)} 组装 \partial L / \partial W^{(\ell)}
  4. **更新**：W^{(\ell)} \leftarrow W^{(\ell)} - \eta \partial L / \partial W^{(\ell)}

总计算成本：O(\text{参数数量})——与一次前向传播同阶。这就是反向传播如此高效的原因：计算所有梯度的成本不超过一次额外前向传播。


#### 常见误解

反向传播常被神秘化为复杂或神奇的东西。它实际上就是微积分中的链式法则，沿神经网络计算图反向应用。唯一的"技巧"是复用中间计算（前向传播保存的激活）来高效计算所有梯度。任何理解链式法则的 calculus 学生都理解反向传播的数学本质。
