在第5章中，我们用线性回归预测房价，在训练数据上得到 R^2 = 0.73。但有一件事还没检查：模型在训练时没见过的 *新* 房屋上表现如何？

想象一下给模型增加更多特征：学校评分、到公园的距离、窗户数量、墙面颜色、上次翻修年份、纳税历史……特征足够多时，线性模型可以完美拟合 500 套训练房屋（训练数据上 R^2 = 1.0）。但这样的模型在新房屋上会表现很差——它记住了训练数据，而没有学到底层规律。

这就是 **过拟合（overfitting）**。而 **正则化（regularization）** 就是防止它的一系列技术。


### 6.1 过拟合问题

让我们具体化过拟合。假设有 500 套训练房屋，但加入了 600 个特征——特征数多于样本数。数据矩阵 X \in \mathbb{R}^{500 \times 600} 的列数多于行数，于是方程组 X\mathbf{w} = \mathbf{y} 欠定：存在无穷多个精确解。最小二乘解的训练误差为零——但它严重过拟合，本质上是在记住每套房屋对应哪个价格，而不是学到可推广的东西。

即使特征数少于样本数，如果特征太多或噪声很大，模型也会开始拟合随机模式。模型权重的幅度变大，互相"补偿"。例如，一个特征权重 +50，另一个高度相关特征权重 -49，净效应很小，但方差巨大。

解决方案是 **正则化**：在损失函数中加入对权重大小的惩罚。大权重要付出代价。这迫使模型只使用真正具有预测性的特征，并为复杂度付费。


### 6.2 岭回归（L2 正则化）


#### 定义：岭回归

**岭回归（Ridge regression）** 在 MSE 损失上增加一个对权重的 \ell_2 惩罚：

L_{\text{ridge}}(\mathbf{w}) = \frac{1}{m}\|X\mathbf{w} - \mathbf{y}\|^2 + \lambda \|\mathbf{w}\|^2 = \frac{1}{m}\sum_{i=1}^m (y_i - \mathbf{w}^\top \mathbf{x}_i)^2 + \lambda \sum_{j=1}^n w_j^2

其中 \lambda \geq 0 是 **正则化强度（regularization strength）**（也称惩罚参数）。

用平实的语言说，我们最小化预测误差 *加上* 权重平方和。大权重被惩罚——模型必须让大权重带来成比例的预测误差下降才值得。

截距 w_0 通常 *不* 惩罚（因为它影响预测的整体尺度，而非复杂度）。

令 \nabla_\mathbf{w} L_{\text{ridge}} = 0 得到闭式解：

\mathbf{w}^*_{\text{ridge}} = (X^\top X + \lambda m I)^{-1} X^\top \mathbf{y}

注意关键改进：即使 X^\top X 奇异（第5章——特征线性相关时发生），给对角线加上 \lambda m I 也能保证矩阵可逆。岭回归既正则化又稳定解。
