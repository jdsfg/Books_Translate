大多数 ML 课程教算法。本章教实践。"在 Jupyter notebook 中对干净数据有效的模型"与"部署到生产并持续有效的模型"之间差距巨大——而且大多数 ML 失败发生在这个 gap 中，而非算法选错。

我们涵盖：系统化特征工程、处理真实世界数据脏乱、超参数搜索策略、实验管理，以及 Thread A 回顾——哪些特征在所有模型中真正重要。


### 22.1 特征工程

**特征工程** 是将原始数据转换为对模型更有信息量的表示的过程。即使对梯度提升和神经网络等强模型，好特征依然重要。


#### 数值特征

**缩放与归一化：**

* **最小-最大缩放** ：x' = (x - x_\text{min}) / (x_\text{max} - x_\text{min}) → 范围 [0, 1]。需要有界输出时有用。
* **标准化（Z-score）** ：x' = (x - \mu) / \sigma → 零均值、单位方差。PCA、KNN、支持向量机（SVM）和多数神经网络都需要。
* **对数变换** ：x' = \log(1 + x)。用于右偏特征（收入、价格、计数）。将乘法效应变为加法。
* **Box-Cox 变换** ：推广对数变换；寻找最优幂 \lambda。当合适尺度不明显时有用。

**分箱：** 把连续特征转为类别（如 age → [child, teen, adult, senior]）。决策树自然处理，但显式分箱有时帮助线性模型捕捉非线性。

**多项式特征：** 在线性模型中添加 x^2, x^3, x_1 x_2, \ldots 以捕捉非线性关系。慎用——多项式特征组合爆炸。

**交互特征：** x_1 \cdot x_2，若你认为特征 1 的效应依赖特征 2。房价例子：area × neighborhood_quality 可能比各自单独更有预测力。


#### 类别特征

**One-hot 编码：** 把 K 个类别的类别特征转成 K 个二元指示变量。线性模型、SVM、多数神经网络需要。问题：K 很大（数千/1000+ 类别）时产生高维稀疏特征。

**标签编码：** 把类别映射为整数（0, 1, 2, ...）。引入虚假序关系。仅适合真正有序类别（small, medium, large）或树模型（树可自然通过分裂处理任意整数编码）。

**目标编码（均值编码）：** 用训练集中该类别的目标均值替换每个类别。对高基数类别特征 + 树模型非常强大。必须在交叉验证 fold 内计算以避免泄漏。

**类别嵌入：** 对极高基数特征（百万级类别），与模型联合学习每个类别的嵌入向量（第19章介绍词嵌入；同样思想适用于用户 ID、商品 ID、邮编）。
