#### 定义：残差连接

不直接学习函数 F(\mathbf{x})，而是让残差块学习 **残差** F(\mathbf{x}) = H(\mathbf{x}) - \mathbf{x}，因此：

H(\mathbf{x}) = F(\mathbf{x}) + \mathbf{x}

其中 F(\mathbf{x}) 是 2–3 个卷积（或全连接）层的输出，\mathbf{x} 直接相加（跳跃连接）：

    x → [Conv → BN → ReLU → Conv → BN] → F(x)
             +
    x ────────────────────────────────→ + → ReLU → H(x)

用平实的语言：输入 \mathbf{x} 被加到变换输出上。该块只需学习相对恒等函数的 *修正*。

**残差连接为何有效？**

**梯度流动：** 跳跃连接创建直接梯度高速公路：\partial H / \partial \mathbf{x} = \partial F / \partial \mathbf{x} + I。即使 \partial F / \partial \mathbf{x} 接近零（块内梯度消失），I 也保证梯度至少为 I——不会消失。梯度可通过跳跃连接路径一直流向第一层。

**恒等捷径：** 若残差块变换无益，网络可学习 F(\mathbf{x}) \approx 0，该块几乎成为恒等函数。这使网络容易"跳过"不必要的层——若捷径是正确策略，深度几乎无代价。

**集成解释：** 有 L 个块的 ResNet 可视为 2^L 个不同深度网络的集成（每条通过跳跃连接的路径对应不同深度）。这提供隐式集成收益。

**Transformer 中的残差连接：** Transformer 架构（第20章）在每个注意力与前馈子层都使用残差连接。对训练 100+ 层 Transformer 至关重要。


### 18.4 SGD 之外的优化器

普通小批量 SGD 有效，但收敛慢且对学习率敏感。现代训练使用动量优化器。


#### 动量

带动量的 SGD 累积速度向量：

\mathbf{v}_{t+1} = \beta \mathbf{v}_t + (1-\beta) \nabla L_t
\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \mathbf{v}_{t+1}

\beta = 0.9 时，速度是过去梯度的衰减平均。这平滑噪声并沿一致梯度方向加速收敛（解决第4章的"峡谷"问题）。
