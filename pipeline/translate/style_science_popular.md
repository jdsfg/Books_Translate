# 系列风格简报：身体科普（科普 / 身体系列）

> 适用书目：身体这台机器：随身硬件巡礼（body-machine-en），后续同类科普书可复用并增量修订。
> 定位：本系列属「人文 / 科普散文」，文气是核心验收项（非技术书），须保留原文的生动与机械隐喻。

## 1. 语气基调（register）
- 原文把人体当作一座**不停运转的工厂 / 机器**来导览：器官 = 设备，生理过程 = 工业流程。
- 译文须**保留并统一这套机械隐喻**：心脏 = 水泵，肾脏 = 过滤工厂，肝脏 = 化工厂，血管 = 物流网络，免疫 = 常备军……不要中途把隐喻"软化"成纯医学术语。
- 整体是「工厂游览手册」口吻：带领读者逐panel参观，边拆机制边回看自己的身体。译文保持这种导览的亲切与笃定。

## 2. 人称（person）
- 第二人称 **"你"**（原文对 lifelong occupant 说话）。**保留"你"，不要改成"读者"或"我们"**。

## 3. 文气（tone）
- 科普散文：生动、有画面感，但**不轻佻、不堆形容词**。
- 原文明确反对"amazing journey"式安慰剂形容词——"wonder 靠机制本身赢得"。译文同理：靠准确机制令人惊叹，不要自行加戏成抒情散文，也不要翻成干瘪教科书腔。
- 保留原文那种"先把你震住、再拆给你看"的节奏。

## 4. 术语处理
- 解剖 / 生理专名**首次出现**：`中文标准名（English 原名）`，如 `稳态（homeostasis）`、`心室（ventricle）`；后文直接用中文。
- 工业隐喻词保留中文译法即可（水泵 / 过滤工厂 / 化工厂），不需回注英文。
- **数字规则（按体裁分类，铺开前定死，避免技术书出错）**：
  - 本系列属**科普散文**，**约整数 / 顺口数词可用中文**（如 "about 100,000 times a day" → "约十万次/天"、"sixty and a hundred" → "六十到一百"），更自然、可接受。
  - 但**精确测量值、单位、百分比、频率、统计数、日期、编号、型号、公式里的数**——无论科普还是技术书，**一律保留阿拉伯数字 + 原单位**，不得约化或改写（如 "3.5%"、"约 100,000 次/天"若强调精确则保留 "100,000"、"12 mg/dL"、"Chapter 4"、"2024"）。
  - **技术 / 统计 / 金融 / 会计 / 理科类书（machine-learning、statistical-thinking、accounting、investment 等）强制：所有数字保留阿拉伯数字 + 原单位**，"100,000→十万""3.5%→百分之三点五"这类约化在那些书里会出事，零容忍。
- 缩写首次出现给全称：REM（快速眼动，rapid eye movement）。

## 5. 禁忌译法
- ❌ 把 "you" 翻成"读者""我们"——保持"你"。
- ❌ 把工业隐喻软化成医学术语（如别把 "zero-downtime pump" 翻成"持续工作的心肌"——保留"零停机水泵"的机器味）。
- ❌ 加戏抒情 / 灌安慰性形容词。
- ❌ 数字、单位、专有名词擅自约化或本地化（技术/理科书尤其零容忍，见 §4 数字规则）。
- ✅ 被动语态可保留，贴合说明文体质。
- ✅ 原文加粗的概念词（**homeostasis** 等）译文中对应加粗。

## 6. 与同系列其他书的衔接
- 本书是"身体即机器"的导览总纲；后续若有更专门的生理 / 解剖书，复用本简报并补术语即可。
