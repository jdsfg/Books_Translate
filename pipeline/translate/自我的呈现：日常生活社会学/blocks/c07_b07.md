#### 保持开放问题

**Q1.** 我们不断地保护彼此的面子，包括陌生人的面子：让错误过去、掩盖失误、避免羞辱。这是真实人类体面的证据，一种相互关怀的真实道德秩序吗？还是说到底是一种交换——我保护你的尊严，以便我的尊严得到保护——一种互惠自我利益的市场？尽全力从两方面论证，不要解决它。

提示

每一方最难的案例都在相反极端：对一个再也不会见到的陌生人反射性友善（对市场读法很难），以及如果从不回报，整个实践会侵蚀（对它有利的一点）。两者都握住。

**答案：** 这是本章的开放问题，它正坐在主线 C 的核心。

_市场读法，最强版本。_ 用冷峻的眼光看。面子工夫是互惠的：我保护你的尊严，部分是因为如果我不这样做，我的尊严也不会被保护的世界就会出现。整个实践由相互期待维持；让一个人持续羞辱他人，别人就不再保护他。即使对陌生人的“反射性”友善，也可以被读作一种根深蒂固的习惯——这种生物的生存始终依赖于站在一个保护其成员的群体之中。按这种读法，神庙其实是个市场，而得体的仪式是这庞大古老交换的货币。

_道德秩序读法，最强版本。_ 但看看市场读法必须解释掉什么。你保护那个绊倒、随即从你生命中消失的陌生人的面子；你对房间另一头某个你甚至可能不喜欢的人的公开羞辱感到畏缩，没有任何回报可能。保护性反射恰恰在没有任何可获之处、也无人可回报的地方被触发。纯粹的交换会在这些案例中关闭；相反，它在那里运行得最猛烈、最自动，仿佛面前这个人的尊严对你提出了一种要求，与利益无关。这看起来不像交易，更像一种道德反射——一种已经成为我们一部分的关怀，甚至延伸到永远无法回报的地方。

保持开放，并注意分歧的形状。它不是关于事实（大家都同意我们会这样做，也同意它部分是互惠的），而是关于合作的深度：互惠是全部真相，还是某种真正道德的东西已经生长其上并超越了它。这不是靠更多观察就能解决的，它连接到全书最大的问题：社会生活中的温暖“根本上”是否是别的东西。我们不决定。但要标记这一点，因为它是主线 C 的脊梁：即使对面子工夫最 _冰冷_ 可用的读法——纯粹的互惠自我利益——仍然在描述一个人们不知疲倦地保护彼此尊严的世界。即使犬儒者的社会秩序，也充斥着相互关怀。这就是我们将在其上建立的地面。
