#### 对话种子

> 给讲授本章的同伴。（贴近许多人的生活；以谨慎处理。）

**Q1.** 引导学习者找到自己被贬损可能的自我——某些观众面前他们管理的某件事——并用它来消解“我们/他们”。然后立即安装护栏：这是结构相似性， _不是_ 苦难的等价。确保两半都落地：深刻的共性，巨大的利害关系差异。

**讨论：** 这个种子传递第5部分的人道回报，同时保护它免受最诱人的扭曲。同伴应首先帮助学习者找到自己的信息管理，并让他们感受到认识：看起来陌生的劳动其实是你自己的，被放大了，这消解了正常人从舒适距离观看污名的立场。但同伴必须 _立刻且清楚地_ 安装反对虚假拉平的护栏：共性是结构性的（同一种工作），差异在利害关系与代价（巨大，不公正分配），而“我们其实都一样”在温暖的伪装下抹消真实不平等的苦难。正确终点同时握住两半：没有虚假等同的认识。这很微妙，同伴应倾向于尊重严重污名的现实；目标是建立在真正共性基础上的团结，从来不是舒适的普遍性——它最小化一些人承担而另一些人不承担的东西。把它作为 _成为他人知情者_ 、延伸接纳的基础来落地，而不是抽象观察。

**Q2.** 探索自己人和知情者。问学习者他们在哪里拥有“自己人”的解脱（一个不必管理某事的空间），以及是否有人曾通过证明过的接纳而成为对他们“知情者”， 挣得了可以不加防备地面对他们的地位。具体引出知情者实际 _做了什么_ 。

**讨论：** 这个种子让主线 C 的节拍变得个人化且充满希望。同伴应引出自己的解脱（一个否则在前台的自我的后台），然后把真正时间花在知情者上，因为成为知情者是本章安静而美好的理念：一个“正常人”通过证明过的、持久的接纳，使自己成为另一个人可以放松的人，不是通过被污名者的劳动，而是通过优雅，弥合了污名缝隙。问知情者具体 _做了什么_ ，把这个从感伤变成具体、可学的东西：知情者是保护性面子工夫变成了关系，是污名可以通过我们如何相遇彼此而消解的活生生的证明。同伴应让温暖在这里落地（这是真正主线 C 的节拍），同时保持诚实：成为知情者是挣得的，不是欠的；知情者的存在并不抹消他们在场之处缺失时所承载的代价。结束于它暗示能动性：我们任何一个人都可以选择成为另一个人的知情者，这是日常生活中可对污名做出的最普通也最强大的回应。
