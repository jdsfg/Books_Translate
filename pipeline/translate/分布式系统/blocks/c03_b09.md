#### 概念检测

**Q1.** 陈述 Lamport 的 happens-before 关系。给出一个因果有序事件的例子和一个并发事件的例子。

提示

三条规则：同进程排序、消息先发送后接收、传递性。并发是三条都不满足。

**答案：** Happens-before，记作 a \to b，由三条规则定义：(1) 若 a 和 b 在同一进程且 a 先发生，则 a \to b；(2) 若 a 是消息发送，b 是消息接收，则 a \to b；(3) 传递性。

因果有序示例：进程 P_1 向键值存储写入 x = 5；P_2 读取含 x = 5 的响应，然后写入 y = 10。P_1 对 x 的写入 happens-before P_2 对 y 的写入，因为读响应是 P_2 上由 P_1 发送的消息接收，而 y 的写入又发生在同一进程该接收之后。

并发示例：进程 P_1 在某物理时钟时刻写入 x = 5，同时进程 P_2 写入 y = 10，两者未互相通信。没有 happens-before 链连接它们。它们在技术意义上并发；任一排序都与偏序一致。

**Q2.** 两个事件的 Lamport 时间戳分别为 5 和 7。关于它们的因果关系你能得出什么结论？

提示

Lamport 时间戳单向保持 happens-before，但逆命题不成立。

**答案：** 几乎得不出什么。Lamport 时间戳满足：若 a \to b，则 L(a) < L(b)。逆命题不成立。因此 L(a) = 5 < L(b) = 7 不蕴含 a \to b；两个事件可能并发。我们只知道 a 不 happens-after b。

这就是 Lamport 时间戳适合产生 happens-before 的全序扩展（例如日志排序），却不适合 _检测_ 并发的原因。要检测并发需要向量时钟。

**Q3.** 三进程系统（编号 1, 2, 3）中，进程 P_3 的向量时钟为 V_a = [3, 5, 2]。P_3 收到一个盖有 V_m = [4, 4, 2] 的消息。接收后 P_3 的向量是什么？该发送事件与本次接收前 P_3 的最近事件是否并发？

提示

接收规则：逐元素取最大值，然后自己的条目加 1。

**答案：** 首先逐元素取最大值：[\max(3, 4), \max(5, 4), \max(2, 2)] = [4, 5, 2]。然后 P_3 把自己的条目（第三个位置，因为进程编号 1-2-3）加 1：[4, 5, 3]。这就是接收后 P_3 的向量。

发送事件向量 V_m = [4, 4, 2]。接收前 P_3 的向量是 V_a = [3, 5, 2]。逐项比较：V_m 的第一项（4）大于 V_a 的第一项（3），所以 V_m \not\le V_a。而 V_a 的第二项（5）大于 V_m 的第二项（4），所以 V_a \not\le V_m。两者互不支配，因此该发送事件与本次接收前 P_3 的最近事件 _并发_。

这种分析区分了向量时钟与 Lamport 时钟：我们能检测这两个事件并发，而非因果关系。
