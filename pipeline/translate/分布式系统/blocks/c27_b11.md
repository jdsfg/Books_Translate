#### 应用问题

**Q1.** 走一遍 Olamide 的 30 行 PR 审查。她在前 30 行看到全部六个谎言。构造一个包含它们的合理代码片段。

提示

一个跨区域支付协调器，含朴素 RPC、无超时、物理时钟排序、Redlock、无部分故障处理、CP 注释但陈旧读。

**答案：** 合理 LLM 生成代码：


    # LLM生成的跨区域 payment 协调者
    # We use CockroachDB which is CP for 一致性

    def process_payment(payment):
        # Acquire 分布式的锁 for the 用户's 账户
        lock_key = f"user_lock:{payment.user_id}"
        if not redis.set(lock_key, "1", nx=True, ex=10):
            return PaymentResult(状态='已失败', 原因='busy')

        try:
            # Read latest balance
            balance = db.query(
                "SELECT balance FROM accounts WHERE 标识符 = %s",
                payment.user_id
            )

            if balance < payment.amount:
                return PaymentResult(状态='已失败', 原因='insufficient')

            # 进程 a跨服务s
            bank_result = bank_service.transfer(payment)
            db.update(
                "UPDATE accounts SET balance = balance - %s WHERE 标识符 = %s",
                (payment.amount, payment.user_id)
            )
            notification_service.notify(payment.user_id, "Payment processed")
            ledger_service.record(payment.id, time.time())

            return PaymentResult(状态='completed')

        finally:
            redis.delete(lock_key)
