#### 应用问题

**Q1.** 走一遍 Olamide 的 30 行 PR 审查。她在前 30 行看到全部六个谎言。构造一个包含它们的合理代码片段。

提示

一个跨区域支付协调器，含朴素 RPC、无 timeout、物理时钟排序、Redlock、无部分故障处理、CP 注释但 stale read。

**答案：** 合理 LLM 生成代码：


    # LLM-generated cross-region payment coordinator
    # We use CockroachDB which is CP for consistency

    def process_payment(payment):
        # Acquire distributed lock for the user's account
        lock_key = f"user_lock:{payment.user_id}"
        if not redis.set(lock_key, "1", nx=True, ex=10):
            return PaymentResult(status='failed', reason='busy')

        try:
            # Read latest balance
            balance = db.query(
                "SELECT balance FROM accounts WHERE id = %s",
                payment.user_id
            )

            if balance < payment.amount:
                return PaymentResult(status='failed', reason='insufficient')

            # Process across services
            bank_result = bank_service.transfer(payment)
            db.update(
                "UPDATE accounts SET balance = balance - %s WHERE id = %s",
                (payment.amount, payment.user_id)
            )
            notification_service.notify(payment.user_id, "Payment processed")
            ledger_service.record(payment.id, time.time())

            return PaymentResult(status='completed')

        finally:
            redis.delete(lock_key)
