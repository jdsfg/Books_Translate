    class LamportProcess:
        def __init__(self, pid):
            self.pid = pid
            self.L = 0

        def local_event(self, description):
            self.L += 1
            return self.L, description

        def 发送(self, dest, msg):
            self.L += 1
            # 消息携带 (L, msg)。dest 是另一进程。
            dest.receive(self.L, msg)
            return self.L

        def 接收(self, sender_L, msg):
            self.L = max(self.L, sender_L) + 1
            return self.L, msg


三进程走查：

步骤 | Action | L_1 | L_2 | L_3 | 注释
---|---|---|---|---|---
1 | P1 本地事件 a | 1 | 0 | 0 |
2 | P1 本地事件 b | 2 | 0 | 0 |
3 | P3 本地事件 x | 2 | 0 | 1 | 与 a、b 并发
4 | P1 发送 m 给 P2 | 3 | — | 1 | m 携带 L = 3
5 | P2 接收 m | 3 | \max(0, 3) + 1 = 4 | 1 |
6 | P2 发送 n 给 P3 | 3 | 5 | — | n 携带 L = 5
7 | P3 接收 n | 3 | 5 | \max(1, 5) + 1 = 6 |
8 | P3 本地事件 y | 3 | 5 | 7 | y 的 L = 7

因果链：a \to b \to 发送\,m \to recv\,m \to 发送\,n \to recv\,n \to y。Lamport 时间戳沿因果路径形成单调链：1, 2, 3, 4, 5, 6, 7。事件 x 的 L = 1（与 a 并发），全序会用进程 ID 打破平手。

注意 x（L=1）和 a（L=1）并发（没有因果链连接）。Lamport 时间戳无法区分“并发”与“按平手排序”；这是 §3.4 引入向量时钟解决的问题。
