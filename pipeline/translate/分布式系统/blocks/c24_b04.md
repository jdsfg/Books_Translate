### 24.4 NVIDIA NIM

NIM（NVIDIA Inference Microservices）是 NVIDIA 的企业推理部署平台。约 2024 年 GA 发布；企业 LLM 部署的商业参考设计。

特性：

(a) **容器化微服务**：每个模型是一个 NIM 容器（含模型权重、推理引擎、API 表面）。通过 Kubernetes 部署；由 NVIDIA 工具管理。

(b) **多引擎支持**：NIM 容器可按模型使用 vLLM、TensorRT-LLM（NVIDIA 优化引擎）或其他引擎。面向用户的 API 一致。

(c) **硬件优化**：NIM 容器包含 NVIDIA 的硬件专属优化（H100 / H200 / B100 / B200 调优）。每代 GPU 都有调优容器。

(d) **企业特性**：SSO、RBAC、审计日志、监控集成。面向企业采购而建。

(e) **GPU 共享**：在支持硬件上，多个 NIM 容器可通过 MIG（Multi-Instance GPU）共享一张 GPU。

NIM 是部署表面；vLLM（通常）是内部的推理引擎。区别是运维：NIM 提供 Kubernetes-native 部署、可观测性和企业集成；vLLM 提供推理优化。

对企业团队：NIM 是标准。对开源/成本优化团队：直接使用 vLLM 加自定义编排。


### 24.5 推理集群拓扑

2026 年生产推理集群（如 Tobias 在 Continuum）如下：


                     ┌──── Load Balancer ────┐
                     │                       │
                     ▼                       ▼
            ┌─────────────┐           ┌─────────────┐
            │  Inference   │           │  Inference   │
            │   Node 1     │           │   Node 2     │
            │  (8x H100)   │           │  (8x H100)   │
            │              │           │              │
            │ Model A: 4   │           │ Model A: 2   │
            │ Model B: 2   │           │ Model B: 4   │
            │ Model C: 2   │           │ Model C: 2   │
            └─────────────┘           └─────────────┘


每个节点有 8 张 H100 GPU（2026 年标准配置）。模型跨 GPU 分布（单模型 tensor parallelism；超大模型 pipeline parallelism）。负载均衡器基于模型可用性和当前负载将请求路由到节点。

Continuum 具体拓扑：

* 50 个节点，每个 8x H100（或 H200，混合）：共 400 张 GPU。
* 服务 8 种不同模型（不同尺寸、微调、每客户自定义模型）。
* 平均 GPU 利用率：60%（目标：80%+）。
* 成本：每月 120 万美元，包括 GPU 租赁、网络、存储和工程运维。

60% 利用率就是 Tobias 优化工作的空间。每个百分点的利用率约等于每月 2 万美元节省。接下来两章讲解能起作用的技术（disaggregated prefill/decode、KV cache sharding、智能路由）。
