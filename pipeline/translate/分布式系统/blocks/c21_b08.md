**Q3.** 用分布式系统术语重构 2003 年美国东北部大停电。哪些组件对应什么？

提示

输电线路 = 服务间连接。保护继电器 = 熔断器。发电厂 = 关键服务。

**答案：** 映射：

* **输电线路**：服务之间的连接。微服务 mesh 中，就是服务间的 API 调用。

* **电力流**：请求 / 负载。流过电网的电力就是流过服务 mesh 的请求。

* **线路上的保护继电器**：服务间连接上的熔断器。过载时跳闸；隔离故障。

* **发电厂**：产生工作供下游消费的源服务。等价：产生交易事件的支付服务。

* **发电厂跳闸（离线自保）**：过载服务的 load shedding。

* **电网互联**：服务 mesh；允许服务跨区域/数据中心相互调用。

* **Blackstart 孤岛**：cell-based 架构；能够隔离部分系统并独立重启。

2003 年序列用分布式系统术语：

(a) **触发器**：三个 “服务连接” 失败（线路倒下）。等价：下游数据库因迁移变慢。

(b) **缺乏可观测性**：监控系统（FirstEnergy 的）有 bug；运维看不到故障。等价：团队监控面板过期；on-call 几分钟内没看到数据库变慢。

(c) **放大**：电力重新分配到剩余线路；每条线路现在更接近容量。等价：慢数据库的调用者重试；数据库现在处于 6 倍正常负载。

(d) **级联**：过载线路跳闸；负载重新分配到更少线路；更多跳闸。等价：上游服务在数据库上超时并重试，然后在彼此上超时并重试；级联扩散。

(e) **完全失败**：整个东北地区电网崩溃。等价：服务 mesh 无法服务任何请求；全面中断。

(f) **恢复需要干预**：电力运维必须手动一片片重启电网。等价：SRE 团队必须限流、重启服务、手动重建服务 mesh。

对分布式系统工程师的教训：模式是普遍的。任何具有放大和缺乏遏制的互联系统都会发生级联故障。相同防御（熔断器、load shedding、可观测性）适用。
