### 20.6 取证 Trace

某些 trace 是特殊的：它们是特定操作的 _取证记录_。示例：

(a) **Payment trace**：每笔支付的全 trace 为合规和审计存储。Trace 是支付记录的一部分，不只是调试 artifact。

(b) **安全事件 trace**：调查安全事件时，攻击者请求流的 trace 是主要证据。

(c) **客户投诉 trace**：客户投诉时，支持团队需要其特定请求的 trace 来诊断。

取证 trace 与采样 trace 存储方式不同：对特定操作类型 100% 采样；保留数年（而非几天）；按客户或交易 ID 索引以便检索。

对 Crescent：每笔支付 trace 保存 7 年（监管要求）。Trace 存储成本显著，但被视为合规成本。
