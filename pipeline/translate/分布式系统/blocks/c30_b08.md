#### E.2 — Roblox 多日故障，2021-10-28 至 2021-11-02

* **触发**：部署新 Consul 版本，带有微妙行为变化（更长 heartbeat 给 Consul 集群带来负载）。
* **放大**：集群的 HashiCorp Consul 服务发现层过载；CPU 饱和导致逐渐 streaming 失败；streaming 失败导致队列积压；积压又带来更多 CPU 压力（灰色 + 亚稳态组合）。Consul gossip 协议的 BoltDB 状态在该故障模式下无边界增长。
* **时间线**：73 小时客户可见中断（Roblox 史上最大）；数百万用户受影响。
* **恢复**：需要多厂商事件响应（Roblox + HashiCorp）；最终 BoltDB 需要从快照恢复，streaming 子系统从干净状态重建。
* **章节映射防御**：
    * Ch.19（服务发现）：单一依赖 Consul 且无优雅降级；缺少纵深防御。
    * Ch.22（亚稳态故障）：自我维持的损坏状态需要外部干预才能打破。
    * Ch.21（级联故障）：streaming 子系统故障传播到依赖服务。
    * Ch.23（混沌工程）：该具体故障模式（高 heartbeat 负载下的 Consul）部署前未做 game-day 测试。


#### E.3 — Cloudflare 邮件路由故障，2024-04

* **触发**：一次配置错误的部署推出代码变更，导致邮件路由 worker 对某些消息类型进入无限循环。
* **放大**：循环 worker 保持连接池打开；新邮件流量排队；队列满；整个邮件路由服务降级。
* **时间线**：Cloudflare 邮件转发服务中断约 2 小时。
* **恢复**：通过追踪识别循环 worker 后回滚部署。
* **章节映射防御**：
    * Ch.20（分布式追踪）：trace 数据揭示了循环；没有追踪，诊断会耗时更久。
    * Ch.27（LLM 生成代码审查）：bug 模式未被 AI 辅助审查流水线捕获，因为循环条件依赖输入数据而非代码形状。


#### E.4 — CrowdStrike Falcon Sensor 崩溃，2024-07-19

* **触发**：CrowdStrike Falcon 内核模式 sensor 的内容更新包含 malformed 数据，触发 Windows 内核越界内存读取；读取导致蓝屏。
* **放大**：更新同时推送到数百万台 Windows 机器（无 canary）；受影响机器进入蓝屏循环，需要手动恢复。
* **时间线**：850 万台 Windows 机器同时变砖；多日恢复；航空、医院、金融服务严重受影响。
* **恢复**：每台机器手动恢复（启动到安全模式，删除坏 sensor 文件）。
* **章节映射防御**：
    * Ch.23（混沌工程，game-day 纪律）：部署应做 canary；"若 sensor 在数百万机器上崩溃" 场景应作为 game day。
    * Ch.21（级联故障，部署作为触发）：把部署视为触发；分阶段 rollout（1% → 10% → 100%）是标准防御。
    * Ch.27（LLM 辅助审查架构）：内核模式 sensor 的输入处理正是审查清单必须捕获缺失验证的代码类型。
