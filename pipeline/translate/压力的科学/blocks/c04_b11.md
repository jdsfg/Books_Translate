修正后的主张更窄：慢性压力的危害来自皮质醇暴露偏离其正常节律，正确目标是曲线形态，而非平均水平。“降低皮质醇”被误框，是因为它回答了一个与慢性压力实际提出的问题不同的问题。

**Q3.** 区分急性皮质醇暴露与慢性皮质醇暴露。为什么同一种分子在一个情况下产生健康效应，在另一个情况下产生损伤？

提示

机制相同；改变的是持续时间。这对哪些效应在脉冲中可容忍、持续时有害意味着什么？

**答案：** 急性暴露——皮质醇升高数小时后消解——产生有用效应：葡萄糖动员、血管张力、事件记忆巩固、免疫资源有策略重分配、暂时抑制长期工程（生殖、生长、消化）。可逆，无累积代价。

慢性暴露由持续施加的同样分子效应造成损伤：

* _持续糖异生_ → 慢性血糖升高、胰岛素抵抗、内脏脂肪。
* _持续蛋白质分解_ → 数年后肌肉流失。
* _持续海马皮质醇暴露_ → 神经元损伤、体积减少、HPA 负反馈减弱。
* _持续免疫重分配_ → 双向失调（疫苗反应受抑、过度炎症、自身免疫发作）。
* _持续长期工程抑制_ → 骨质疏松、生育问题、消化功能障碍。
* _持续心血管张力_ → 内皮功能障碍、加速动脉粥样硬化。

为什么同一机制产生相反结果？生物系统为 _间歇性_ 运转而优化。持续运转时，同样机器磨损底物——肌肉蛋白转化快于替换，海马神经元超过修复能力，骨密度丢失快于再生。这个模式在生理学中反复出现：在某占空比下健康的机制，在另一占空比下致病。这正是“急性机器在没有恢复的情况下持续运转”的精确基础。

**Q4.** 为什么艾迪生病和库欣综合征的存在——皮质醇调节的两个极端——对理解健康皮质醇功能重要？

提示

一个系统 _两个方向_ 都有病理意味着什么？

**答案：** 两个极端都导致严重疾病，这种框定告诉我们四件事。

皮质醇是一个 _严格调节的系统_，两个方向偏离都有病理。不存在“越低越好”的梯度——只有一个健康范围，向任一方向偏离都会产生特定疾病。这是反对“降低皮质醇=更好”最有力的论据。

库欣综合征（太高）产生内脏脂肪、肌肉萎缩、糖尿病、骨质疏松、高血压、抑郁、免疫功能障碍——慢性压力表型过度运转。艾迪生病（太低）产生低血压、低血糖、极度虚弱、免疫功能障碍、严重急性压力脆弱性——需要时无法动员。身体需要皮质醇正常运转，但不需要它持续运转。

库欣综合征在某种程度上 _就是_ 严重慢性压力在整个 HPA 层面的上演。大多数慢性压力患者没有肿瘤，但他们的症状谱在低振幅上复现库欣综合征。这种状态给了我们一个模型，展示亚临床慢性压力数年做什么。
