**Q4.** 本章认为“对压力的焦虑本身就是一种压力”，并以此作为精确区分哪些压力-疾病主张证据充分、哪些被夸大的理由之一。解释为什么诚实的证据层级自律本身可以作为一种压力干预。

提示

一种不加区分的信念——“压力导致所有坏事”——对当前正在承受压力的人会有什么影响？

**答案：** 如果你相信压力几乎导致所有重大疾病，那么注意到自己正在压力中就会激活你害怕的那种反应。这个循环自我放大：觉察 → 对后果的恐惧 → 更多压力 → 更多觉察。它相当于告诉失眠者“你必须睡够八小时，否则会死”。

证据层级自律打断这个循环。当读者了解到心血管贡献真实但温和、A 型人格文献方法学薄弱、大多数溃疡是幽门螺杆菌而非压力、癌症关联远比流行框架暗示的更弱——弥漫性恐慌缩小，而对证据充分通路的关注保留。结果是，比灾难化框架产生的慢性压力更少。校准本身就是一种干预。
