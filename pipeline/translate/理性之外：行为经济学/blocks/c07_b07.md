#### 应用题

**Q1.** 某国考虑将器官捐赠政策从 opt-in（默认非捐赠者，必须登记才能成为捐赠者）改为 opt-out（默认捐赠者，必须登记才能退出）。无需任何强制措施，仅改变默认设置，现状偏差研究预测捐赠率会大幅提高。解释其原因，使用现状偏差的心理机制。批评者可能提出哪些反对意见？

提示

思考默认如何改变参照点，以及惯性在 opt-in 与 opt-out 下如何不同运作。

**答案：** 在 opt-in 下，现状是“非捐赠者”。不登记是阻力最小的路径。主动登记的认知与情绪成本——包括思考自己的死亡并做出正式决定——使许多原本支持捐赠的人望而却步。在 opt-out 下，现状变为“捐赠者”。不登记仍是阻力最小的路径。主动退出的成本——思考为何不捐赠并正式决定退出——使同样心理类别的被动个体望而却步。现状偏差在两种情况下都有利于默认；只是默认被颠倒了。

行为预测：opt-out 下的捐赠登记率远高于 opt-in——已转换国家的研究发现，参与率从约 40-50% 上升到 85-95%。

批评意见：

1. _知情同意不足_：opt-out 下许多“同意”者可能未主动反思捐赠。他们的登记反映惯性而非真实偏好。器官捐赠是一项需要知情决策的道德严肃行为。
2. _少数群体负担_：出于宗教、文化或个人原因反对捐赠的人现在必须主动退出。这加重了默认偏好与新现状冲突者的负担。
3. _家庭否决复杂化_：实践中，家属经常在死亡时推翻已登记决定，无论法律默认如何。转向 opt-out 可能造成对捐赠率提升的错误信心，而实际上并未增加器官。
4. _滑坡担忧_：批评者认为，接受器官捐赠中的“默认助推”会为政府在其他规范理由更弱的领域操纵默认选择打开大门。

**Q2.**（与第 3 章交叉）禀赋效应由损失厌恶预测。但实验研究也发现，消费品显示出比交易品更大的禀赋效应——明确为交易而获得的商品几乎没有禀赋效应。这一发现如何挑战禀赋效应的纯损失厌恶解释？

提示

思考损失厌恶（作为价值函数的固定属性）是否应随所有者预期保留还是出售商品而变化。

**答案：** 前景理论中定义的损失厌恶是价值函数的稳定属性：无论情境如何，损失都比同等收益更显眼。如果禀赋效应完全由损失厌恶解释，那么它不应取决于所有者打算消费还是交易该商品——他们的损失厌恶系数不会随意图改变。
