#### 深入思考

**Q3.**（与第 1 章交叉）阿莱悖论在第 1 章被呈现为对独立性公理的违背。现在请用概率权重函数（probability weighting function）解释它。你的解释揭示了哪种认知机制——确定性效应（certainty effect）？

**答案：** 这同时用到第 1 章的材料（阿莱设置）和第 3 章的框架（概率权重函数）。

在阿莱悖论的问题 1 中，对 A（确定 1M USD）优于 B（89% 概率 1M USD，10% 概率 5M USD，1% 概率 0 USD）的偏好，由确定性的质上溢价驱动。概率权重函数给 A 的结果分配 \pi(1.00) = 1，但给 B 中 89% 概率的 1M USD 分配小于比例权重的值，因为 \pi(0.89) < 0.89。此外，从“确定”到“近确定”（100% 到 89%）的剧烈跳跃，在概率权重函数中表现为一个很大的心理跃升——远大于客观 11 个百分点差异所暗示的幅度。

在问题 2 中，两个选项都远离确定性。11% 与 10% 概率的差异被转换为 \pi(0.11) 与 \pi(0.10)，两者很接近——对小概率的高估对二者大致相当。当选项 C 不再享有确定性溢价后，选项 D 的更大奖金（5M USD）获胜。

其认知机制就是 **确定性效应** ：从概率 1.0 降到任何更小概率，都会触发一种质上不同的（更负面的）反应，而这种反应比两个低于确定概率之间的移动要强烈得多。这一效应自然地从概率权重函数在 p = 1.0 附近的曲率中涌现。
