这对金融沟通有直接影响：向客户展示用自然语言描述的具体历史损益，会比呈现等价的统计摘要引发更保守的行为。希望将客户组合与实际风险承受能力匹配的顾问，或许应当使用具体历史情景语言——但他们也应意识到，过于生动的损失描述可能使风险厌恶超出客户全面反思后会认可的程度。

**Q3.** 回顾第 1 章，阿莱悖论涉及在彩票之间选择。亚洲疾病问题也涉及在彩票之间选择。比较这两种现象：它们由同一认知机制引起，还是不同机制？

**答案：** 阿莱悖论与框架效应都可由前景理论预测，但运作机制不同。

_阿莱悖论_ 主要关乎 **概率权重函数** ——确定性效应使 100% 在质上不同于 89%，当概率成比例降低时产生偏好反转。即使所有结果在单一一致框架（所有收益，参照点 0 USD）下描述，悖论依然存在。

_框架效应_ 主要关乎 **参照点移动** 与 **不对称价值函数** ——通过将结果描述为收益或损失，框架改变了适用价值函数的域（凹形或凸形），从而在概率不变时翻转风险态度。

在亚洲疾病问题中，两种框架下的底层概率完全相同——因此概率权重函数在两帧中贡献相同。变化的是域：收益框架 → 凹形价值函数 → 风险厌恶；损失框架 → 凸形价值函数 → 风险寻求。

在阿莱悖论中，框架保持不变（所有收益），但两个问题之间的概率不同——而从确定到近确定的跳跃通过概率权重函数造成反转。

两种效应都是真实的，也都由前景理论捕捉。它们说明，对期望效用理论的违背并非铁板一块——至少来自两种同时运作的不同机制。
