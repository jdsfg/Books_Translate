2. _目标框架（Goal framing）_：健康或行为改变信息强调执行某行为的收益（“如果你锻炼，你会降低心脏病风险”）或不执行该行为的损失（“如果你不锻炼，你会增加心脏病风险”）。损失框架信息往往更具说服力，但效应量因情境而异。

3. _等价框架（Equivalence framing）_：同一统计事实的两种描述引发不同反应。“这种药有效率 90%”与“这种药 10% 无效”是等价的，但会导致不同的用药意愿——存活/成功框架感觉更正面。

**Q5.**（与第 3 章交叉）概率权重函数高估小概率。这与框架如何相互作用，产生风险态度的四重模式？

**答案：** 这连接了第 3 章与第 4 章。四重模式来自（a）价值函数的收益/损失域与（b）概率权重函数的结合。

对 _低概率_ 事件而言，\pi(p) 高估小概率会放大附于其上的任何收益或损失。在收益域（收益框架）：小概率的大收益被高估 → 风险寻求。在损失域（损失框架）：小概率的大损失被高估 → 风险厌恶。这解释了购买彩票（小概率大收益，收益框架）和购买保险（小概率大损失，损失框架）。

对 _高概率_ 事件而言，\pi(p) 对高但非确定概率的低估与价值函数形状相结合。在收益域：凹形价值函数加上对高概率的轻微低估 → 强烈风险厌恶。在损失域：凸形价值函数加上对高概率的轻微低估 → 强烈风险寻求。

框架设定参照点，从而决定域（收益或损失）；概率权重函数随后放大该域特有的风险态度。
