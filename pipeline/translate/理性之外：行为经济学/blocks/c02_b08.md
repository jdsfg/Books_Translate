#### 应用题

**Q1.** 一位农民面临 10% 概率干旱，干旱会使作物收入从 80,000 USD 降至 20,000 USD。一份作物保险价格为 6,000 USD，保证无论是否干旱都能获得 80,000 USD 收入。农民的效用函数为 u(w) = \sqrt{w}。这位理性农民应该购买保险吗？

提示

计算不购买保险时的期望效用，再与购买保险后确定性结果的效用比较。当且仅当（收入减保费）的效用高于未投保赌博的期望效用时，农民才会购买保险。

**答案：** 不购买保险时：

E[u] = 0.9 × \sqrt{80{,}000} + 0.1 × \sqrt{20{,}000} = 0.9 × 282.84 + 0.1 × 141.42 = 254.56 + 14.14 = 268.70

购买保险：收入确定为 80,000 USD - 6,000 USD = 74,000 USD。

u(74{,}000) = \sqrt{74{,}000} = 272.03

由于 272.03 > 268.70，该效用函数下的农民偏好购买保险。注意：不投保时的期望货币价值为 0.9 × 80,000 + 0.1 × 20,000 = 74,000 USD——与投保结果完全相同。但农民支付的 6,000 USD 高于精算公平保费（0.1 × 60,000 = 6,000 USD，因此这份保险实际上是精算公平的）。正因为效用函数是凹的，任何精算公平保险对风险厌恶主体都是值得购买的。

**Q2.** 一位投资者拥有 100,000 USD 财富，现有一项投资机会：40% 概率获得 200,000 USD，60% 概率获得 40,000 USD（该投资替代其全部财富，而非额外收益）。其效用函数为 u(w) = \ln(w)。（a）他应该投资吗？（b）该投资的确定性等价是多少？

提示

比较投资的期望效用与保留 100,000 USD 的效用。确定性等价是使确定财富水平产生与投资相同期望效用的那个值。

**答案：**（a）投资的期望效用：

E[u] = 0.4 × \ln(200{,}000) + 0.6 × \ln(40{,}000) = 0.4 × 12.206 + 0.6 × 10.597 = 4.882 + 6.358 = 11.240

保留 100,000 USD 的效用：

u(100{,}000) = \ln(100{,}000) = 11.513

由于 11.513 > 11.240，该投资者不应投资。

（b）确定性等价：解 \ln(CE) = 11.240：

CE = e^{11.240} \approx 75{,}786 USD

该确定性等价（75,786 USD）远低于投资的期望货币价值（0.4 × 200,000 + 0.6 × 40,000 = 80,000 + 24,000 = 104,000 USD）。风险溢价约为 104,000 - 75,786 = 28,214 USD。这位投资者风险厌恶程度相当高。
