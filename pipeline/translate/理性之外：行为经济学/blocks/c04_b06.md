#### 概念自查

**Q1.** 什么是框架效应（framing effect）？为什么理性主体模型预测框架效应不应存在？

**答案：** 框架效应是指由选项的 _描述_ 而非选项本身差异所导致的选择变化——逻辑等价的选项以不同措辞呈现，选择随之改变。理性主体模型预测零框架效应，因为理性偏好定义在最终结果的概率分布上——实际收益及其概率。结果如何 _标注_ 或 _描述_ 并不改变概率分布。既然只有概率分布重要，描述就不能影响选择。因此框架效应直接违背了理性主体模型的后果主义：理性主体只关心后果，不关心呈现方式。

**Q2.** 描述亚洲疾病问题（Asian disease problem）。关键操作是什么？典型结果模式显示什么？

**答案：** 亚洲疾病问题呈现一场预计会杀死 600 人的疫情。两组受试者收到结构上相同的选择问题，但以不同框架呈现。第 1 组（收益框架）：在确定救活 200 人（方案 A）与 1/3 概率救活 600 人、2/3 概率无人被救活（方案 B）之间选择。第 2 组（损失框架）：在确定 400 人死亡（方案 C）与 1/3 概率无人死亡、2/3 概率 600 人死亡（方案 D）之间选择。方案 A 与 C 完全相同；方案 B 与 D 完全相同。关键操作是框架：“被救活的生命”（收益）对“死亡”（损失）。

结果：第 1 组多数人偏好方案 A（收益框架下的风险厌恶）。第 2 组多数人偏好方案 D（损失框架下的风险寻求）。这种反转证明了框架效应——相同选项因框架不同而产生相反的多数偏好。

**Q3.** 前景理论如何解释收益框架产生风险厌恶、损失框架产生风险寻求？

**答案：** 在前景理论中，结果相对于参照点被评估。价值函数在收益域凹形（收益域敏感性递减 → 风险厌恶），在损失域凸形（损失域敏感性递减 → 风险寻求）。

收益框架：参照点是“零人获救”（最坏结果）。两个选项都在收益域。凹形价值函数 → 风险厌恶 → 偏好确定的小收益（方案 A）。

损失框架：参照点是“零人死亡”（最好结果）。两个选项都在损失域。凸形价值函数 → 风险寻求 → 偏好赌博（方案 D，有机会无人死亡），而非确定的大损失（方案 C 确定 400 人死亡）。

框架通过移动参照点，使同一彩票在收益域或损失域被评估，从而触发不同的风险态度。

**Q4.** 除了风险选择框架，请命名并简要描述三种框架效应。

**答案：**

1. _属性框架（Attribute framing）_：对象的单一属性以正面或负面方式描述。“含 90% 无脂”与“含 10% 脂肪”描述的是同一种酸奶，但产生不同评价——正面框架被认为更健康。关于“脂肪”的参照点随框架移动。
