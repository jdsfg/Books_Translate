**答案：** 将计划 B 设为默认很可能因现状偏差而显著提高计划 B 的加入率。大多数不主动选择的人会最终进入计划 B。这是任何默认设置的可预测后果——多数人会待在默认项。

计划 B 是否是正确默认，取决于它是否真的是大多数员工的最佳选择。若计划 B 对“普通”员工最合适（健康但有一定医疗使用、中等收入），则默认合适并服务多数员工。若员工群体高度异质（许多年轻健康、使用率低的人应选计划 A；许多高需求员工需要计划 C），单一中等默认可能只服务一小部分人。

建议：

1. _细分默认_：考虑公司能否根据员工特征（年龄、家庭状况、上年使用率、薪资）设置定制化默认。年轻单身员工默认计划 A；有慢性病家庭默认计划 C；四口中等收入家庭默认计划 B。
2. _使关键决策因素更显著_：工具不仅应呈现三个计划，还应在选择点让员工个人财务分析显著可见：“根据您上年医疗使用情况，计划 A 本将花费您 X USD，计划 B Y USD，计划 C Z USD。”这种个性化比较减少了使默认如此强大的信息不对称。
3. _简化比较_：并排列出各计划及员工自身预估费用的对比表，降低认知负荷，使选择退出默认者能更好决策。
4. _主动框架决策_：与其使用预填表，不如设计一个简短互动问卷（“您去年看过几次医生？是否预期大手术？”），引导员工到推荐计划。这样在不取消默认的前提下激活审议。

**Q3.**（与第 8 章交叉）自由家长主义旨在尊重自主，同时解决现时偏差及其他行为失败。但现时偏差的人在退出助推时也可能现时偏差——他们可能冲动、在时间压力下或因惯性（不愿主动选择）而退出。这会破坏助推尊重自主的自由主义主张吗？

**答案：** 这是行为经济学文献日益认识到的一个真正重要反对意见。自由家长主义框架基于如下想法：退出代表真正自主偏好的行使——如果你不喜欢助推，可以自由选择其他。但如果退出决定本身也受现时偏差影响（“我最终会退出，但一直没去做”），或退出是在时间压力下冲动做出而非反思性做出，那么退出的自由并不能完全代表自主偏好。
