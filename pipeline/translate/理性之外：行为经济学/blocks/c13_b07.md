#### 概念自查

**Q1.** 陈述半强式有效市场假说。它对基本面分析价值有何预测？

**答案：** 半强式有效市场假说认为资产价格充分且即时反映所有公开可得信息。这包括盈余公告、经济报告、分析师预测、财务报表以及任何其他公开可获取数据。

对基本面分析的预测：基本面分析——利用公开信息识别高估或低估股票——无法持续产生高于市场平均的超额收益（风险调整后）。若市场已把所有公开信息纳入价格，基本面分析师没有信息优势——他们分析的信息已经反映在价格中。在完全有效的半强式市场中，最佳策略是被动指数化而非基于公开信息的主动选股。

**Q2.** 什么是套利限制？列举并解释三种具体限制。

**答案：** 套利限制是阻止理性投资者即使识别出错误定价也充分纠正它的约束。三种限制：

1. _基本面风险_：即便正确识别了错误定价资产，它在修正前可能变得更错。押注修正的套利者面临价格进一步反向移动的风险——他们可能需要在修正发生前以亏损平仓。

2. _噪声交易者风险_：非理性投资者（噪声交易者）能把价格推向“错误”方向并使其保持。与噪声交易者情绪反向下注的理性投资者面临情绪在改善前恶化的风险——即使套利者对基本面正确，若噪声交易者未及时纠正，他们也会亏钱。这使得纯套利不可能——总是存在残余的噪声交易者风险，即反向错误定价的押注短期错误、长期正确。

3. _职业风险（制度约束）_：与市场共识反向下注的专业基金经理短期内可能跑输，这可能让他们失去客户或工作。即便正确识别了错误定价，基金经理也可能因职业风险而不愿重注反对共识。这创造了随大流而非套利纠偏的激励（incentive）——使理性经理识别但不愿攻击的错误定价得以持续。

**Q3.** 什么是处置效应？用第 3 章的价值函数解释它。

**答案：** 处置效应是投资者倾向于过早卖出盈利头寸（股价高于买入价）并过久持有亏损头寸（股价低于买入价）的倾向。

通过前景理论（第 3 章）解释：参照点是买入价。高于买入价的股票处于价值函数的收益域；低于买入价的处于损失域。从第 3 章可知，价值函数在收益域为凹形（产生风险厌恶），在损失域为凸形（产生风险寻求）。
