#### 定义：承诺装置

**承诺装置（commitment device）** 是一种限制未来选项的机制，使按当前偏好制定的计划无法（或代价高昂地）被未来偏离。它通过降低未来拖延的吸引力来发挥作用。

用大白话说：承诺装置就是“绑住未来自我的双手”，使其无法按现时偏差（present bias，亦称“现时偏误”）行动。

**承诺装置示例：**

* _带提前取款罚金的养老金计划_：在退休前动用退休储蓄代价高昂，防止未来自我“临时借用”退休账户。
* _自动工资扣款_：退休储蓄在工资到账前扣除，因此这笔钱从未被体验为可用于即时消费。
* _锁定储蓄账户_（如圣诞俱乐部）：存款在指定日期前不能取出。
* _奥德修斯与塞壬_：奥德修斯让人把自己绑在桅杆上，使未来自我无法响应游向塞壬的冲动——这是西方文学中最古老的承诺装置。

对承诺装置的需求本身就是老练的证据：不知道自己现时偏误的人不会付费限制未来选项。


### 8.5 拖延与现时偏误陷阱

现时偏误是拖延的机制。考虑一项任务：当下成本为 c（现在完成所需的努力），未来收益为 B（完成它的价值）。天真型主体评估如下：

在 t = 0 时：现在做吗（今天付出成本 c，明天获得收益 B）？

* 现在做：效用 -c + \beta\delta B
* 等待：效用 0 + \beta\delta(-c + \beta\delta B) = \beta\delta(-c) + \beta^2\delta^2 B ← 这是主体认为等待会带来什么（天真地假设下一期自己会做）

如果抽象地 \beta\delta B - c > 0，主体会偏好完成任务。但一旦成本在当下、收益在未来，比较变为 -c vs. \beta\delta B。若 c > \beta\delta B ——现时偏误使未来收益足够小——主体就会拖延。

悲剧在于：下一期，同样的计算再次发生。成本仍在当下（今天的成本），收益仍在未来（明天）。拖延陷阱：任务永远不会完成，即使主体真心希望它被完成。


#### 线索 A——为退休储蓄

线索 A 检查点：这是退休储蓄失败的核心机制。退休储蓄涉及当下成本（放弃当前消费）与未来收益（有保障的退休收入）。对现时偏误主体而言，由于收益在遥远未来，它被大幅贴现——而且 \beta 惩罚适用于所有未来时期。每个月，“这个月储蓄还是花掉？”的计算都带着现时偏误进行——每个月，天真型主体都得出结论：“我下个月开始储蓄。”

解决方案：自动加入通过使储蓄成为默认来利用现时偏误（第 7 章讨论过）。这消除了每一期做出积极储蓄决策的需要——现时偏误永远没有机会推翻计划。第 16 章将展示“明天多储蓄”如何通过使承诺与未来加薪挂钩来复合这一效果，让现时偏误主体永远不必经历薪资立即减少的直接成本。
