#### 概念自查

**Q1.** 什么是自动加入？为何把默认从 opt-in 改为 opt-out 会大幅提高参与率？

**答案：** 自动加入是一种退休计划特征，它自动以指定缴费率和投资基金让合格员工加入，除非他们主动选择退出。在 opt-in 下，员工必须采取行动（填表、指定缴费率、选择基金）才能参与；默认是不参与。在自动加入（opt-out）下，员工必须采取行动才能不参与；默认是参与。

参与率的显著提高（从 opt-in 的 30–50% 到 opt-out 的 85–95%）是因为多数员工从不主动选择——他们接受默认。在 opt-in 下，多数不主动选择的人不参与。在 opt-out 下，多数不主动选择的人参与。现状偏差（对当前状态的偏好，加上惯性和最小阻力路径）确保哪个选项是默认，哪个就囊括大部分“从不选择”人群。由于这部分人占多数，默认决定了总体参与率。

**Q2.** 描述 SMarT 项目。其每个设计特征如何解决特定行为失败？

**答案：** 明天多储蓄（SMarT）项目让员工预先承诺，每次未来加薪时自动提高缴费率。

特征 1——_加薪前承诺_：解决现时偏差。承诺当下没有减少当前消费（增长应用于未来加薪）。未来自我的现时偏差峰值——出现在有即时成本时——尚未到来。当下自我评估纯粹未来成本时更耐心（现时偏差更小），更愿意承诺。

特征 2——_来自加薪的钱缴费_：解决损失厌恶与心理账户。缴费增长来自从未进入消费预算的“新”收入。员工不感受到到手工资下降；他们只是收到稍小的加薪。这重构缴费为“未获得未来全部收益”而非“失去当前收入”——价值函数的收益域（相对风险厌恶但不强烈损失厌恶）而非损失域。

特征 3——_自动升级_：解决现状偏差。一旦加入 SMarT，缴费率无需任何主动决策自动提升。惯性——通常阻碍加入或提高缴费——现在支持升级。每次加薪都带来自动增长，没有决策负担。

特征 4——_保留退出_：保留选择自由（自由家长主义）。员工可随时退出 SMarT，确保机制不伤害面临意外财务困难的员工。很少有人行使这一选项——与员工在反思偏好中认可升级一致。
