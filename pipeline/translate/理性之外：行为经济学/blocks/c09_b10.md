#### 应用题

**Q1.** 一位朋友收到 3,000 USD 退税，用它买了一台新电视，说“这是捡到的钱——不如享受一下”。他的信用卡有 3,000 USD 余额，年利率 20%。从标准经济学角度，这个决策有什么问题？心理账户如何解释它？

提示

思考把退税用于电视相对于还信用卡余额的机会成本。再思考不同心理账户如何使这两种用途在心理上感觉不同。

**答案：** 从标准经济学角度：信用卡余额年利率 20%。偿还 3,000 USD 信用卡债务产生确定的 20% 回报（避免利息）。购买电视的有效回报低得多（对大多数消费品，每年效用远低于购买价格的 20%）。最优决策是先还信用卡余额，只有在还完仍能负担时才买电视。

心理账户解释：退税占据一个“意外之财”心理账户，参照点为零。它感觉像捡到的钱——不是常规收入流的意外收入。把它花在享乐的东西上，以令人满意的贷方（电视）结清意外之财账户。与此同时，信用卡债务占据一个独立的“持续债务”心理账户。把钱从意外之财账户转移到债务账户，感觉像是账户之间的转账——一种较不令人满意的捡到的钱用途。电视比还债更干净、更令人满意地结清意外之财账户，即使还债的经济回报更高。

这是非替代性的表现：如果朋友同等对待所有美元，20% 的还债保证回报显然占优。心理账户使退税与债务感觉像独立的财务领域，阻止了最优重新配置。

**Q2.** 一家制药公司将某种抗癌药定价为每月 1,000 USD，并提供优惠券计划，使患者实际自付为 0 USD。 另一种方案是，他们可以把药价定为患者私人保险下的 0 USD（向保险公司收取固定金额），让保险公司通过保费转嫁成本。从心理账户角度，哪种定价结构会带来更高的患者依从性（按处方服药），为什么？

提示

思考每种结构下药品成本借记哪个心理账户，以及成本的显著性如何影响持续行为。

**答案：** 0 USD 直接成本（由保险公司计费）的结构可能比优惠券计划产生更高依从性。

心理账户分析：在优惠券计划下，患者经历每月 1,000 USD 成本，然后被折扣为 0 USD。即使最终不付钱，患者也必须使用优惠券、看到 1,000 USD 价格、处理折扣，并可能在交易中遇到摩擦。1,000 USD 很显著——它以大额数字进入患者意识，即便最终未付。这激活“医疗支出”心理账户，可能在患者质疑是否续处方时制造决策点。
