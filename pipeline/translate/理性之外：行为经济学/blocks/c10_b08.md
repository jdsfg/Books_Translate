#### 应用题

**Q1.** 不平等厌恶模型预测，即使确定回应者会接受任何正提议，\beta_i > 0 的提议者在最后通牒博弈中也会提供高于最小额。计算：若 \beta_i = 0.5，提议者分配 100 USD 时最优提议是多少？假设回应者总是接受。

提示

写出提议者效用作为其提议 s 的函数（回应者得 s，提议者得 100 - s）。若提议者比回应者多（即 s < 50），有利不平等项适用。对 s 最大化提议者效用。

**答案：** 设提议者提议为 s（回应者得 s，提议者得 100 - s）。

若 s < 50（提议者更多）：提议者效用为：

U = (100 - s) - \beta \max((100-s) - s, 0) = (100 - s) - 0.5(100 - 2s) = 100 - s - 50 + s = 50

有趣：当 s < 50 时，效用恒为 50，与 s 无关。每转移 1 USD 给回应者（s 增加）使自身收益减 1，但不平等惩罚减 2\beta = 1 USD。两者对 \beta = 0.5 恰好抵消，使提议者在区间 [0, 50) 内无差异。

若 s = 50（均分）：U = 50 - 0 = 50（无任一方向不平等）。

若 s > 50（回应者更多）：提议者处于不利不平等。但未指定 \alpha_i。若假设提议者只有 \beta（内疚）而无 \alpha（嫉妒），则 s > 50 时没有不平等惩罚适用于提议者。于是 U = 100 - s，随 s 递减。故最优 s 恰好为 50——均分。

解释：\beta = 0.5 的提议者对 0 USD 到 50 USD 之间所有提议无差异，但任何高于 50 USD 的提议都会降低其自身效用（损失金钱而无不平等减少收益）。模型预测均分（50 USD）为自然焦点——它是消除所有内疚且不被任何替代方案占优的最低提议。

**Q2.** 一家商店平时卖雨伞 10 USD，并有不因坏天气涨价的标准政策。一场突如其来的暴雨中，竞争对手将雨伞涨到 20 USD（市场出清价）。运用公平偏好理论，预测消费者对两家商店定价的反应。这对存在公平偏好下的长期定价均衡有何含义？

提示

思考消费者如何相对参考价格评估价格变化，以及有公平关切的消费者可能对“哄抬价格”的商店采取什么行为。

**答案：** 消费者对两家商店的反应可能非常不同。

竞争对手涨价到 20 USD 违反了隐含的公平规范：价格不应在消费者脆弱时刻机会主义地上涨。有公平偏好的消费者将此体验为商店剥削他们——商店攫取了按隐性规范属于买方的消费者剩余。这触发负向互惠：消费者通过抵制、差评、光顾竞争对手来惩罚商店，即使竞争对手的产品略贵或稍不方便。
