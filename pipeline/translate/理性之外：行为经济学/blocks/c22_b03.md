#### 修正图景：智人经济人

人类决策者既不是完全理性的经济人，也不是最悲观行为解释中无可救药有偏差、可被操纵的自动机。更准确的图景：

**条件理性：** 人们在有利于理性的条件下（熟悉、清晰反馈、低认知负荷、激励一致、充分审议时间）是理性的，在削弱这些条件时系统性地有偏差。

**适应性启发：** 启发式是工具，不是错误。它们常在其适应环境中成功。它们在新奇、复杂或被剥削环境中可预测地失败——其中包含许多现代制度。

**制度依赖：** 决策质量与个体认知一样，也是制度架构的函数。同一个人，若默认更好、信息更简单、承诺时机恰当，会做出显著更好的决策。

**社会嵌入：** 决策发生在根本塑造偏好与判断的社会情境中。公平关切、社会规范、互惠和身份不是非理性噪音——而是人类动机的构成性特征。

**线索 B 最终答案：** 理性主体模型是有用的极限案例和宝贵分析工具。它不是大多数真实世界中人类决策的准确描述模型。行为经济学提供修正——不是替代，而是丰富，使其因更诚实而更有用。


#### 常见误解

**误解：** 行为经济学证明人类根本非理性——我们的偏差如此普遍且系统，以至于无法相信自己能为自己做出好决策。

**现实：** “非理性”一词意味着全局判断；行为经济学记录的是在特定条件下、相对于特定理性模型、特定领域可预测偏离。同一些在退休储蓄中表现现时偏差的人，也能成功驾驭复杂社会关系、习得语言、抚养子女、建立事业、在制度中合作。人类是极具能力的行动者，在大多数日常领域部署快速且常良好适应的认知工具。记录到的偏差是真实且有重要后果的——但它们集中在特定环境：新奇、复杂、情绪强烈或被设计以利用认知局限。线索 B 最终答案精确指出这一点：_条件理性_，而非全局非理性。实践含义不是对人类能动性悲观，而是致力于设计人类认知系统挣扎的具体环境——退休储蓄、健康保险、复杂金融产品——使这些环境支持而非利用我们实际拥有的认知架构。


### 22.3 线索 C 最终综合：行为经济学科学素养框架

线索 C 贯穿全书追踪行为经济学发现的证据质量。以自我损耗为中心的重复危机——但延伸更广——揭示，行为经济学与所有科学一样，需要持续批判评估而非不假思索接受。
