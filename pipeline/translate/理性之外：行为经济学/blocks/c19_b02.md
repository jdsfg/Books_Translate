#### 诊断优先原则

有效的 BIT 首先绘制公民尝试完成任务的行为旅程——申请福利、加入项目、报税、注册健康筛查。他们追问：人们在何处退出？何处犯错？摩擦在何处累积？

**BIT 常见行为障碍：**

* **注意力失败** ：人们未注意到重要信息
* **现时偏差** ：收益遥远、成本即时（今天加入，数月后受益）
* **摩擦** ：步骤太多、表格令人困惑、办公室难以到达
* **社会脱节** ：人们不知道与自己相似的人怎么做
* **身份威胁** ：申请帮助意味着软弱；于是不加入
* **复杂性** ：多部分资格条件超出工作记忆容量

一旦识别行为障碍，干预便可针对它。处理错误障碍——在人们因不知道项目存在而不读表时简化表格——会浪费资源。


#### RCT 标准

BIT 在政府中普及了随机对照试验（RCT）。BIT 不会推出政策变化后希望有效，而是对一部分人群测试变化，将结果与对照组比较，只有证据支持时才规模化。

**线索 C 检查：** 这是将实验标准最严格应用于政策的实践。但现场 RCT 也有局限：它们测量平均处理效应，可能掩盖亚组间巨大差异；常测量短期行为而非长期变化；也受同样影响学术研究的发表压力。运行良好的现场 RCT 证据强——但并非无懈可击。


### 19.2 行为税收政策


#### 罪恶税（Sin Taxes）与行为假设

传统经济分析将烟酒或糖的消费税视为庇古税（Pigouvian tax）修正：人们低估自己对他人施加的成本（二手烟、医疗体系）或对未来自己的成本，税收将真实社会成本内部化。

行为经济学增加了一层：人们还系统性地低估 **内部性（internality）** ——他们对未来自己施加的成本。偏好戒烟但戒不掉的吸烟者通过现时偏差对未来自己施加成本。一种同时纠正外部性和内部性的庇古税可从纳税人自身长期偏好视角增进福利——即便他们当下抵制。

**内部性逻辑：**

> 若一位 β = 0.5（强现时偏差）的吸烟者对未来健康成本权重少 50%，那么纠正这一内部性的税收会让吸烟者按自身长期偏好更好——即便他们当下反对。

这一论证比标准庇古逻辑更具伦理复杂性。它要求假设行为主体的“真实”偏好是其长期偏好，而非现时偏差偏好——这与第 18 章关于家长主义的哲学问题相同。

**线索 B：** 理性主体模型将罪恶税纯粹视为外部成本矫正。行为模型增加内部成本矫正，扩大了税收理由——但需要关于哪些偏好“真实”的有争议假设。
