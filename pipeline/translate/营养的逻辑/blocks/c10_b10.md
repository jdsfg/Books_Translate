**答案：** 墨西哥糖税创造了一个自然实验——政策改变以某种方式改变人群 SSB 暴露，近似（但不完美）随机分配。如何利用：(1) 双重差分分析：比较墨西哥税前后结局与同期可比对照国（如 2014 年未实施糖税的哥伦比亚）结局。超出对照国同期变化的差异可更自信地归因于税收。(2) 国内剂量—反应：不同社会经济群体消费不同量 SSB，价格敏感性不同。低收入家庭对价格更敏感，税收后消费减少更多。如果 SSB 消费驱动代谢疾病，你会预测低收入家庭税后代谢改善更大。(3) 追踪结局：短期（1–3 年）：通过销售数据很好测量的 SSB 购买量、全国调查中的体重/BMI 趋势、2 型糖尿病诊断、儿童龋齿率。长期：心血管死亡、2 型糖尿病患病率、NAFLD 率。(4) 现有证据前景：2016 年研究发现，墨西哥第一年征税饮料购买量平均下降 6%（低收入家庭下降更多）。后续分析发现儿童代谢标志物有适度但真实的改善。自然实验局限：并非完美随机（富裕家庭能吸收价格上涨，其他政策可能同时变化，跨境购买或转向未征税饮料）。但它们在人群层面提供了纯观察性研究无法提供的因果证据。
