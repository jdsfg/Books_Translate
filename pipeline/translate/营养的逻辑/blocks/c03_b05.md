#### 定义：胰高血糖素（glucagon）

胰高血糖素（glucagon）是胰腺 α 细胞分泌的一种激素，作用与胰岛素相反。当血糖下降时，胰高血糖素向肝脏发出信号，分解糖原并释放葡萄糖入血，同时促进脂肪组织中的脂肪分解。

用通俗的话说：如果胰岛素是“储存这些能量”的信号，胰高血糖素就是“释放储存能量”的信号。它们是一对拮抗激素，协同工作以维持血糖在狭窄范围内。

### 2.4 胰岛素的故事——区分事实与过度简化

胰岛素在大众营养文化中已沦为反派。其逻辑是：碳水化合物升高胰岛素 → 胰岛素是脂肪储存激素 → 碳水化合物导致脂肪堆积 → 因此碳水化合物不好、胰岛素也不好。

这个叙事有几分真实，但包裹着大量过度简化。

**叙事中正确的部分：**

* 胰岛素确实促进脂肪储存并抑制脂肪分解。
* 慢性高胰岛素血症（hyperinsulinemia）与胰岛素抵抗、2 型糖尿病和代谢综合征相关。
* 精制碳水化合物比富含纤维的全食物更快速、更强烈地升高胰岛素。

**叙事中错误的部分：**

**胰岛素并非只由碳水化合物触发。** 蛋白质也会显著升高胰岛素。一份乳清蛋白奶昔升高的胰岛素可以和白面包相当。脂肪升高胰岛素最少，但仍会升高。胰岛素的工作是管理所有进入体内的营养素，而不仅仅是碳水化合物。

**餐后胰岛素升高是正常且健康的，不是病理性的。** 每次进食都会升高胰岛素。这正是身体高效分配营养的方式。问题不是餐后胰岛素升高，而是当细胞对胰岛素信号变得抵抗时胰岛素长期居高不下。

**胰岛素不是脂肪储存的主要决定因素。** 脂肪增加最可靠的预测因素是总热量过剩，而不是胰岛素水平。控制性过量喂养研究显示，当卡路里匹配时，碳水化合物和脂肪产生相似的脂肪增加。“肥胖的胰岛素假说”——即胰岛素是主要驱动因素的观点——在严格代谢研究中并未得到很好支持（Hall 等，2017；多项其他研究）。

**胰腺以持续而精细的方式调节血糖。** 尽管人们吃什么、何时吃差异巨大，健康人的餐后血糖仍被维持在狭窄范围（约 70–140 mg/dL）内。这种调节来自胰岛素和胰高血糖素的持续动态分泌——一套精密的系统，而不是被碳水化合物“破坏”的系统。

#### 常见误解

**“晚上不该吃碳水，因为夜间胰岛素会把它们变成脂肪。”**

这是“碳水 = 胰岛素 = 脂肪储存”神话的变体，加上了昼夜节律维度。诚然，由于昼夜节律，晚间葡萄糖耐受能力（高效处理葡萄糖的能力）确实略低，但这种效应很小，对健康人吃正常量食物没有临床意义。多项对照试验发现，24 小时内的热量平衡远比进食时间重要。在热量赤字的情况下晚上吃碳水不会导致脂肪堆积。在热量盈余的情况下早上吃碳水也会。
