**讨论：** 这是一个真正困难的方法学问题。全食物营养素可能优于分离补充剂的机制包括：(1) 营养素协同作用——食物中的维生素和矿物质与辅因子、次级化合物及其他营养素共存，促进吸收和利用。例如，肉中的铁（血红素铁）形式最利于吸收；补充剂中的硫酸亚铁对相同剂量生物利用度较低。(2) 食物基质——纤维、多酚和其他食物化合物改变营养素吸收速率（例如，燕麦中的可溶性纤维减慢葡萄糖吸收，并可能提高某些矿物质生物利用度）。(3) 剂量校准——食物以经过演化和传统饮食校准的剂量提供营养素；补充剂则提供食物中从未出现的剂量范围（每天 400 毫克维生素 E、500 毫克维生素 C 是无法从食物中达到的剂量）。

然而，对这一方法学问题诚实的答案是：我们并不完全知道。测试补充剂的随机试验（维生素 E、β-胡萝卜素、硒在 SELECT 试验中，维生素 C 在许多试验中）通常呈阴性或有害——但这些试验测试的剂量远高于食物水平。测试食物形式或食物水平剂量补充剂的试验结果更混杂。“全食物更好”在生物学上合理，且与观察性数据一致，但在对照实验中难以证明，因为我们不能让人几十年只吃全食物饮食。务实结论仍是：吃多样化全食物，为已记录缺乏补充，对大剂量补充保持怀疑。
