#### 概念检查

**18.1** 一款早餐麦片声称“富含 13 种必需维生素和矿物质”和“由全谷物制成”。第一种配料是全谷物玉米，第二种是糖，配料表含 BHT、人工色素和“天然香料”。评估该产品。

**答案：** “富含”维生素声称反映强化——向工业产品添加合成维生素。这不表示该食品与天然维生素密集全食物营养相当；合成维生素生物利用度可能不同。“由全谷物制成”技术上因全谷物玉米为第一种配料而满足，但不表示产品主要是全谷物——糖作为第二种配料意味着按重量产品可能几乎与糖一样多。BHT（有争议的防腐剂）、人工色素和“天然香料”添加剂的存在将其归类为 NOVA 第 4 组（超加工）。营销声称技术上合法，但营造了与实际配料不符的良好健康印象。这款产品应视为偶尔食品，而非每日早餐主食。

**18.2** 区分“授权健康声称”和“结构/功能声称”。哪种需要 FDA 预先批准？

**答案：** 授权健康声称是经预先批准的声称，具体描述食物成分与疾病或健康状况之间的关系，基于显著科学共识标准。必须经 FDA 预先批准，并由大量证据支持。例：“低饱和脂肪和胆固醇饮食可能降低心脏病风险。”结构/功能声称描述食物或营养素在正常身体结构或功能中的作用，而不声称预防或治疗疾病。不需要 FDA 批准——只需备案。例：“支持免疫健康。”关键区别是结构/功能声称可对具体产品作出，证据支持很少或不存在，因此作为已证明健康益处指标远不可靠。

**18.3** 产品标注“每份 0 克反式脂肪”。在什么情况下这可能误导？

**答案：** FDA 允许产品每份反式脂肪低于 0.5 克即可标“0 克反式脂肪”。由于份量可能不现实，吃多份可导致有意义的反式脂肪摄入而不在标签上体现。例如，每份 0.4 克反式脂肪的产品，每天吃 3 份，摄入 1.2 克反式脂肪——生理有意义的量——而所有三份都显示“0 克”。自 2021 年起部分氢化油已被禁止，因此新产品中该来源反式脂肪较少。然而，反刍动物产品（乳制品、牛肉）中天然存在的反式脂肪不受该法规限制，可能少量存在。因此“0 克”声称应结合配料表阅读，检查是否还有氢化油配料。
