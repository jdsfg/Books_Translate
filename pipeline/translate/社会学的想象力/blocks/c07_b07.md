#### 应用问题

**Q1.** 列出你最近一天中占据的地位，注意“你”如何随它们变化（声音、被允许的感受、幽默、会说与不会说的话）。然后挑出两个角色最接近_冲突_的地位，分析这个冲突：它是角色紧张还是角色冲突，你感到的困难更好被看作私人烦恼、结构性议题，还是两者兼具？

提示

本章开头是你的模型。冲突问题取决于它发生在一个地位_内部_还是两个地位_之间_，以及同样的碰撞是否可预测地影响许多处于你同样位置的人。

**答案：** 回答因人而异，但好的回答会干净地应用这些区分。假设两个接近冲突的地位是“雇员”（被期待为截止日期加班）和“成年子女”（被期待开车送父母就医）。这是_角色冲突_（两个不同地位，同时提出合法要求），而不只是紧张。在烦恼或议题问题上，诚实答案通常是_两者兼具_：你如何处理它确实涉及真实的个人选择（你可以提前计划、求助、做出不同选择），_同时_这种碰撞是结构性产生且有模式的，因为雇员角色广泛地按工作者没有照护责任来设计，所以大量处于你两个地位的人以同样方式面对这一碰撞。只见个人层面（“我处理得不好”）是个体化错误；只见结构层面（“体制让我如此”）则抹去了你此刻的真实能动性。成熟分析同时命名两者，而这种双重视野正是本章的核心技能。

**Q2.** 本章说角色“不只是戏服”，因为它向内延伸、重塑自我，_同时_又“小于完全占有”，因为人与自己所演部分保持距离。在你自己的生活中找一个随时间真正重塑你是谁（而不仅是你的行为）的角色，同时找出你与自己之间保持的缝隙。同时持守这两个观察，对线索 C 有何启示？

提示

6.2 是你的模型：新晋父母_成为_父母（戏服穿着他们），同时也能感到“我在做这件事，但我不仅仅只是这件事”（缝隙）。

**答案：** 回答因人而异，价值在于同时持守两半。假设角色是“年迈亲属的照护者”。向内重塑：几个月来，你不只是执行照护任务；你在反射与自我感中_成为_了照护者，更耐心或更疲惫，有了新的恐惧和改变的身份，这个角色成为你“客我”的一部分。你保持的缝隙：即便如此，你仍可私下感到“我在做这件事，但这并非我的全部”，这是角色看不见的保留，是超越角色的自我。同时持守两者，就是线索 C 的缩影：角色_造就_了你（所以你确实是社会产品），_同时_你保持一个不可还原为角色的自我（所以你确实比产品更多）。这个练习表明，主线张力不是抽象辩论，而是你自己日常经验的纹理；诚实描述需要两半，既非“角色只是戏服”，也非“我除了角色什么都不是”。
