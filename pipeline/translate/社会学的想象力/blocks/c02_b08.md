#### 应用问题

**Q1.** 想一想这周你曾有过的一种看似完全私人的感受：尴尬、焦虑、骄傲或愤怒的一闪。花几分钟用社会学问题来审视它：有没有一种社会结构站在这私人感受背后，披着它的外衣？写下个人解释和可能的结构解释。不要判定“哪一个才是真的”。

提示

柜台前队伍的案例（1.3）是你的模型。愤怒感觉私人，但它属于队伍。你的感受可能属于哪一条“队伍”？

**答案：** 没有唯一正确答案，但好的回答诚实地让_两种_解释同时存在。假设这种感受是对“到了这个年纪还没取得足够成就”的焦虑。个人解释：也许你确实一直在漂泊，也许你忽略了具体目标。结构解释：“到了某个年龄就该取得某些成就”这个想法本身就是一个社会事实，是你的社会所持有的一种时间表，并非所有社会都持有它，甚至有的社会根本没有。你当作私人不足来感受的焦虑，可能部分是一种公共时间表从外部施加的压力。这个练习的成功之处在于你能同时持有两种解释而不坍缩为“全怪我自己”或“全怪社会”。这种不坍缩正是 1.4 中的纪律，你将在全书不断练习。

**Q2.** 大规模失业是米尔斯所说的公共议题。选一个你认识的许多人都在面对的困难，试着把它说两遍：一遍作为个人烦恼（一个个体体验到什么、可以做什么），一遍作为公共议题（它属于什么模式、什么安排制造了这种模式）。诚实地看，两者之间的界线在哪里难以划定？

提示

困难案例才有趣。找一个_一部分_明显是个人、_一部分_明显是模式的情况。

**答案：** 以存钱困难为例。作为烦恼：某个具体的人花的比挣的多，冲动消费，不做预算；解决之道在他的习惯。作为议题：横跨一整代人或收入阶层，住房、医疗、教育的成本与工资之间的差距在一段可测量时期内朝某个方向移动，以至于该阶层里即使善于储蓄的人也举步维艰；解决之道（如果有）在于结构安排，而不在习惯。界线难以划定，正是因为两者通常都在运作：一个消费习惯不好的人身处惩罚性成本结构中，面对的是复合问题，你无法只修复其中一层就解决全部。指出“难以划定界线”才是正确的结果，而不是消除它。
