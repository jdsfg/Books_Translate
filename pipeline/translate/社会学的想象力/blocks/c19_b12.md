**答案：** 回答因人而异，但好回答会精确定位两种错误。**第一种滑移**（“X是建构的，因此改变它”）：假设有人说“性别角色是社会建构的，因此它们不合法，应被废除”。逻辑错误发生在“因此”：偶然性（被建构、本可不同）在道德上是中性的，不能单独交付“不合法”的裁决，因为七天一周同样被建构且值得保留，所以额外价值前提被偷运进来。_有效_地论证改变 X 必须做真实的规范工作：正视该安排持续性的最强论证（角色服务什么功能、谁捍卫它们、移除代价是什么），然后在价值与后果上论证害处大于收益、某个具体替代方案会更好——这是关于价值与后果的论证，而非关于建构。_相反的便宜动作_（“X是自然的，因此别动它”）：假设有人说“这种等级只是人性，所以不能也不应改变”。错误在于去自然化已经表明“自然”是需要检视的_主张_，不是王牌；很多被称为“自然”的东西原来是偶然的人类安排（第 3 章），所以诉诸自然常常只是假的；而且即使某物部分自然，“自然”也不蕴含“善”或“不可改变”（这是自然主义的同种是/应该错误）。有效捍卫 X 必须从另一方做同样真实的工作：承认安排是偶然的，然后在实质价值上论证它服务值得保留的真实功能且替代方案更糟。这个练习展示本章最深层观点：**“建构，所以废除”和“自然，所以保留”都不是有效论证**，两者都是跳过真实规范性问题的逻辑技巧，而纪律迫使每种政治立场的人都回到实际理由栖居、严肃人士分歧的真实规范问题。
