### 3.3 阅读历史

现在到了收获的时候。你有了一本相册，里面装满了连成链的快照。那你实际要怎样**阅读**它？

最常见、也最有用的方式，是最朴素的一种：把它当作一个列表来读，最新的在最上面，最旧的在最下面。每个快照占一行。每一行都带着你拍下快照时写的说明，也带着足够指向那个准确时刻的标记（一个日期、一个标识符）。

那个下雨的星期二，Maya 请智能体显示这本指南的历史时，返回来的东西大致像这样：
    
    
    （最新）
      重写了介绍部分——新的开头句              星期日晚上
      加入 Theo 的雨天照片                     星期六
      把博物馆清单删到真正重要的四个            星期四
      重写了 Alfama 步行路线                    星期三
      ...
      介绍部分的第一版真正草稿                  （两周前）
    （最旧）
    

从上往下读，你读到的就是项目最近故事的倒序：这是我们做的最新一件事，这是它之前的一件事，再之前又是一件。也正因为如此，你在拍快照时写下的说明才如此重要。它们不是文书工作。它们就是这个列表里的句子。一个说明写成 **"一些东西"** 或 **"改动"** 的快照，会在历史里变成一行对未来的你毫无帮助的话。一个说明写成 **"重写了介绍部分，新的开头句"** 的快照，会变成几周后你能靠它导航的一行，正如 Maya 刚刚做到的那样。说明才是关键，而历史就是它真正派上用场的地方。

注意 Maya **不**需要做什么。她没有打开旧文件。她没有手工比较副本。她没有猜哪个 `FINAL` 才是对的。她只是用普通话请求查看按最新在前排列的历史，沿着列表往下读，直到通过说明认出星期天那个快照，然后看了它。寻找过去，变成了阅读一张目录。

这里也正好要划出一条诚实的边界，因为我不希望你带着超过事实的信念离开。

**这本相册还不是备份。** 本章里的所有东西（链、repository、可阅读的历史）到目前为止都住在一个地方：Maya 笔记本电脑上的那个文件夹。如果那台笔记本电脑丢了、掉进 Tagus 河里，或者被偷了，这本指南连同它整条漂亮的历史都会一起消失。一台机器上保存得很深、很好的相册，是一件了不起的事，也是一件脆弱的事。历史保护你免受**自己**伤害：防止覆盖、后悔的重写、找不到的版本。它本身并不能保护你免受一场房屋火灾。让相册住在不止一个地方，让一台丢失的笔记本电脑不会带走任何东西，是一个真实而重要的步骤，而且它有自己的章节：第 8 章。在那之前，请同时握住两个真相。你已经获得了过去从未拥有过的工作记忆。你还没有为它获得第二个家。
