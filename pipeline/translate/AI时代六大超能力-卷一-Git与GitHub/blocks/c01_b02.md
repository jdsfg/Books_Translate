**如何把这本书用到最值。** 它写来是让你慢慢读、像对话一样读的。每一章都是自成一体的一步；章内的问题不是测验，而是邀请：在真正遇见一件工具之前，先预测它会做什么；并练习把想要的事，变成可以说出口的请求。别急着去“用 Git”。先让地图成形。等到真要动手时，那感觉会像在请求一件你早已理解的事——因为本来就是如此。

这是六卷中的第一卷。其余各卷为有志者如今能通过智能体指挥的其他工具绘制地图：你自己运行的开源模型、命令行、服务器与部署、API 与自动化，以及最终——你自己的知识，做成智能体可用的形态。每一样都曾是专属于专家的超能力，如今不必再如此。我们从 Git 开始，因为在你能有把握地指挥这一切之前，你得先不再害怕改动自己的作品。

翻过这一页吧。故事的开头，一如既往，是某样已经失去的东西。
