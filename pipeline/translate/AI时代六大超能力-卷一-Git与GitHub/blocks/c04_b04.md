#### 常见误解

几乎每个人都会在这个点提出同一个反对意见，而且它值得一个直接的回答。

**"如果相册会永远保存每一个版本，那一定会占用巨大的空间。我的指南已经很大了。50 个快照就一定是 50 倍那么大。这不可能实际可行。"**

这听起来无懈可击。它也是错的。理解它**为什么**错，会让你真正看见历史是怎样被保存的。

隐藏的假设是：每个快照都是整个项目的一份完整、独立的副本；第 50 个快照就是所有东西的一份完整复制，堆在另外 49 份完整复制上面。如果事情真是这样，这个反对意见就是对的，保存很深的历史确实会浪费空间。

但快照之间的关系不是这样。记得吗，每个快照都紧跟在前一个快照之后，而且通常只改了一点点。Maya 的"重写了 Alfama 步行路线"这个快照，并没有碰 Theo 的照片，没有碰介绍部分，没有碰博物馆清单，也没有碰这本指南 90% 的内容。那些内容和前一个快照是**完全相同**的。所以，历史不会把这 90% 的指南再存一遍。没有变化的材料会在快照之间共享，而不是重新复制一份。实际上的快照，大部分是指向相册中已经存在的材料的一组指针，再加上那一小部分真正新的内容。

可以把它想成一本好的家庭相册，记录的是一个只有一张沙发的家庭。一张又一张照片里都有同一张沙发，但相册里并没有 50 张沙发。它有的是 50 张碰巧都拍到了沙发的照片，而沙发本身就只是……那张沙发，那张不断出现的沙发。让每张照片不一样的，是改变了的那一小部分：谁坐在那里，他们穿着什么，光线如何。历史遵循的是同一种直觉。一个快照和下一个快照之间真正保存的，大多是**差异**，也就是实际改变的部分；而所有保持不变的东西会被共享，不会被一遍遍重新囤起来。

实际结果才是对你最重要的：每完成一段有意义的工作就拍一个快照，成本很低；保存一条又长又深的历史，成本也很低。你不必为了省空间而限量使用快照。放心地拍，好好地描述。相册生来就是为了容纳大量快照，而且会以精简的方式容纳它们。

我故意不告诉你这种共享具体是怎么安排的，因为你不需要知道，那些细节是智能体该操心的，不是你该操心的。你要带走的是这个概念：**快照会共享它们共同拥有的东西；只有变化才真正有成本。** 只要抓住这个想法，"这一定会占用巨大空间"的担心就会完全消散。无论你的项目是一本旅行指南、一篇学位论文，还是一家面包店的价目表，这都是真的。
