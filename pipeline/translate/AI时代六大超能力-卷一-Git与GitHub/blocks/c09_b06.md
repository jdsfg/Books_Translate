#### 概念检查

**Q1.** Theo 的笔记本电脑坏了，向导在那台电脑上。Maya 的笔记本电脑有一个克隆；共享工作坊也有一个克隆。确切地说，丢失了什么？Theo 全新的替换笔记本电脑能找回多少历史？

提示

问问一个克隆实际包含什么。它是“当前文件”，还是整本相册？

**答案：** 什么都没有丢失。克隆是**整本相册**（从第一次提交开始的每一个快照、每一个分支、每一条说明），不只是当前文件。Maya 的机器和共享工作坊各自都保存着完整、独立的历史。当 Theo 的新笔记本电脑把项目克隆下来时，它会收到全部内容：他可以重访上个月的版本，重新打开旧分支，阅读任何提交上的说明。那台坏掉的笔记本电脑没有保存任何另外两份副本中没有的东西。这正是“一台笔记本电脑丢了也不会丢东西”的全部意义：当每一份副本都是完整的，任何单一副本的死亡都无法带走历史。

#### 应用题

**Q1.** 你的朋友说：“我很安全：我的小说在一个仓库里，我每天都做一次快照，历史全在那里。”他们的整个项目，连相册在内，只存在一台笔记本电脑上，别处没有。用一句直白的话说，他们备份了吗？你会问他们的唯一一个问题是什么？

提示

把两种不同的保护分开：防止你自己的编辑出错，以及防止机器坏掉。一台机器上的仓库能提供哪一种？

**答案：** 他们**没有**备份，值得温和但清楚地告诉他们这一点。一台笔记本电脑上的仓库能完全保护他们免受自己错误的影响，比如糟糕的编辑、后悔的删减，因为他们可以沿着历史回到过去。但它完全不能保护他们免受笔记本电脑坏掉的影响，因为整本相册都住在那一块硬盘上，并且会随它一起死去。死掉磁盘上的快照，和从未纳入版本控制的文件一样确定地消失了。要问他们的唯一问题是：**“这个项目的完整副本，是否存在于那一台笔记本电脑之外的任何地方？”** 如果答案是否定的，每日快照就是珍贵而脆弱的；修复方法只需要一句直白的话：把相册放到第二个地方。仓库只有也存在于别处时，才算备份。
