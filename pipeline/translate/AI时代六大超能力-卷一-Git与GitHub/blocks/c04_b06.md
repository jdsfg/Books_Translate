### 3.4 你实际获得了什么

退一步看看，从第 1 章到现在，发生了什么变化。

在第 1 章里，你的工作没有过去。只有当前文件，还有一堆因为害怕而做出的副本；它们没有顺序，也没有记忆。触碰已经好用的内容是危险的，因为前一个好版本可能在一次保存中消失，就像 Maya 的那三段文字一样。

现在，你的工作有了过去，而且过去是安全的。项目曾经到达过的每一个有意义的状态，都坐在相册里，按顺序排好，每一个都有说明来解释自己，也没有任何一个会因为你的下一次编辑而处于危险之中。你可以像打开一个列表那样打开历史，按最新在前的顺序阅读工作的故事。你可以在几秒钟内通过说明找到上个星期天的介绍部分，而且不会打扰今天草稿里的任何一个字。

你还没有学会**使用**那个过去，也就是实际回去把一段被删掉的文字带回现在，或者把项目恢复到更早的状态。到目前为止，你只是学会了**阅读**它。事实证明，这正是正确的顺序，因为阅读会让"回去"这件事变得平静。下一章，当 Maya 走回上个星期天的版本时，她会清楚地知道那里有什么，也清楚地知道自己要拿什么，因为她已经知道怎样阅读自己的历史。相册教给她的是她自己过去的地图。现在，她可以在里面旅行了。


### 3.5 练习

和之前一样：没有什么要计算，也没有什么要背。这些问题是请你预测相册会怎样表现，并练习把你想要的东西变成一句可以提出的请求。读每一道题，停一停，再读讨论。


#### 概念检查

**Q1.** 有人告诉你："我这一年来每天都给自己的小说拍一个快照。那就是磁盘上放着一本 300 页书的 365 份完整副本。我的空间要用完了。" 根据本章内容，这笔账错在哪里？

提示

问问自己，昨天的快照和今天的快照之间，实际改变了什么。一个快照是全部 300 页的一份全新副本，还是更精简的东西？

**答案：** 这笔账假设每天的快照都是整本 300 页书的一份完整、独立的副本，所以一年的快照就要花掉 365 本书那么多空间。但大多数日子里，他们只是改了几个段落，而不是改了整份手稿。他们没有碰的 297 页会在快照之间共享，而不是每天重新存一次；某一天的快照真正增加的，大多只是那一点差异，也就是真正改变的部分。一部逐渐增长、逐渐编辑的小说，它的 365 个快照所占的空间会远远少于 365 本完整小说，因为历史保存的是变化，不是无穷无尽的重复副本。正确的直觉正好和他们相反：他们可以继续每天拍快照，不用担心空间，而且他们应该这么做，因为一年标注清楚的历史，正是让他们能在几秒钟内找到这本书任何过去状态的东西。
