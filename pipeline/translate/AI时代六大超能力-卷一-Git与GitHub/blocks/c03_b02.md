#### 定义：提交（一个快照）

**提交**就是一个快照：它是在某一个时刻对你整个项目完整、永久的记录，并且和一小段说明一起保存；这段说明（称为**提交信息**）描述改了什么以及为什么改。

用普通话说，这意味着：提交就是你整个项目的一张照片，带着一条图注。不是你刚好正在编辑的某个文件的一张照片，而是所有东西在同一瞬间、按下快门时的样子。而那条图注，那条关于**为什么**的说明，会永远跟着这张照片。当用这种方式工作的人说“我会提交那个”时，他们的意思是：“我要给项目此刻的样子拍一张快照，并写下这个时刻是什么。”

“提交”这个词有点不好听，你可以在整本书里悄悄把它在脑子里翻译成“快照”或“照片”。没有任何损失。你的AI智能体知道“提交”这个词；你只需要知道这个想法，而这个想法就是一张带图注的照片。


#### 常见误解

关于快照，最常见的错误画面是这样的：**提交会保存我此刻正在处理的那个文件。**人们会把它想象成一个强化版的“保存”按钮，一个把当前文档保存得更永久一点的按钮。

它保存的不是你的一个文件。它记录的是整个项目。如果你的指南由十二章、一个照片文件夹和一个标题页组成，那么一个快照会把**所有**这些东西的状态作为同一个连贯时刻一起捕捉下来，甚至包括你今天没有碰过的部分。这件事比一开始看起来更重要。正因为如此，稍后你才可以回到“上周二整个项目是什么样子”，找到的不只是某一个被还原的文件，而是每个文件都准确回到那一天的样子，彼此一致，就像一张房间的照片展示的是整个房间，而不是房间里的某一个物件。快照拍的是**项目**，不是**文件**。请抓住这一点；后面几乎所有好东西，都是从这里长出来的。
