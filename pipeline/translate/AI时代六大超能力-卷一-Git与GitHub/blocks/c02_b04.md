### 1.5 练习

本书中的练习不是操练。没有什么要计算，也没有什么要背诵。它们在这里，是为了让你在真正遇见工具之前先**预测**工具会做什么，并练习那个唯一重要的技能：把你想要的东西转成你可以提出的请求，并知道该检查什么。读每个问题，静静想一会儿，然后再读讨论。


#### 概念检查

**Q1.** 看看你现在最重要的项目，不管它存在哪里。你有没有某种版本的“FINAL_v2_REALLY_final”文件夹？数一数那些近似重复的文件。每一次你制作其中一个副本时，具体来说，你当时害怕的是什么？

提示
你每次害怕的并不是同一件事。有些副本是“在大改之前”；有些是“在别人碰它之前”；有些是“我不明白为什么这东西能用，也不想把它弄坏”。把你的副本分分类。

**答案：** 几乎每个人都会在那个文件夹里发现两种不同的恐惧。第一种是**不可逆**：“如果这个更改不好，我想回去”，快照和返回过去（第 2 章到第 4 章）会完整回答它。第二种是**碰撞**：“如果别人在我编辑时也编辑了这个，我们会互相覆盖”，分支和远端（第 5 章到第 8 章）会回答它。说清哪些副本来自哪种恐惧，是使用地图的第一个动作：你会注意到，工具对每一种恐惧都有具体且分开的解决方案，而且两种方案都不是“再做一个副本”。


#### 应用题

**Q1.** 想一个你一直**没有**对自己在乎的项目做出的大胆更改（一次重组、一次重写、一次冒险实验），原因正是它可能毁掉当前能用的版本。用一句白话写下：如果尝试它是免费的，并且你总能回到现在一模一样的状态，你会尝试什么。

提示
不要描述命令（你不知道任何命令，而这没关系）。描述你**想要的结果**和你**需要的安全**：“我想尝试 X，同时不丢失 Y。”

**答案：** 你刚写下的句子，几乎正是你会在第 5 章交给智能体的白话请求，比如“启动一个单独的版本，让我可以尝试这次重组，而不碰那个能用的版本”。注意它有两半：你想尝试什么，以及你绝不能失去什么。本书中每一个安全请求都有这个形状。现在把这个形状记在心里，意味着当工具出现时，它会感觉像是为了回答你早已拥有的问题而建造的，因为它确实如此。
