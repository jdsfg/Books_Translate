到上一章结束时，向导已经住在不止一个地方。它在 Maya 的笔记本电脑上，在 Theo 的笔记本电脑上，也在他们推送到互联网某个共享家园的第三份副本里。三本完整相册，每一本都有每一个快照，并且每当他们中的任何一人完成一段工作，就通过一句直白的请求让智能体使它们保持同步。一台笔记本电脑丢了也不会丢东西。这就是他们买来的平静。

但第三份副本，也就是互联网上的那一份，正在做另外两份做不到的事。Maya 的笔记本电脑是工作的地方。共享副本则是另一种东西。它有一个你可以交给别人的地址。它有一个陌生人也能看到的面孔。而一个项目一旦有了面孔，它就不再只是一个你私下保存安全的东西，而变成一个其他人可以找到你、阅读你做出的东西、并告诉你某些你不知道的事情的地方。

第三份副本住在一个地方；截至 2026 年，它是人类曾经建造过的同类地方中最大的一个。本章讲的就是它是什么、为什么存在，以及那个改变 Maya 和 Theo 一切的小而普通的事件：一位朋友读了他们的向导，并告诉他们有一家咖啡馆已经关门。


### 9.1 世界的工作坊

上一章里，我们把第三份副本称作“共享家园”，并且故意说得含糊。现在我们给它命名。Maya 和 Theo 推送向导的地方是一个**工作坊**，而且不是随便哪个工作坊。它是世界的工作坊，一个单一网站；截至 2026 年，大约 180 million 名开发者在那里保存自己的工作、阅读彼此的工作，并一起改进它。

想象一座巨大的建筑，里面满是工作台。每张工作台上放着一个项目：它的整本相册、每一个快照、完整历史。大多数工作台都有一块可以拉上的帘子，只有你邀请的人才能看到里面的工作。有些工作台则向整个房间敞开：任何人都可以走上前，阅读上面的内容，并且（这正是了不起的地方）留下一张说明，甚至提出一个更改。Maya 和 Theo 租了一张工作台，并拉上了帘子。他们的向导在那里，完整而安全，但现在只有他们两个人能看见。

大多数人说到这种地方时，指的是 **GitHub**。Maya 推送向导的地方就是那里。但从一开始就精确区分两件容易混在一起的事，会很有帮助。

第一，GitHub 是一个工作坊，不是唯一的工作坊。还有其他工作坊存在，并且按相同原则运行：**GitLab** 和 **Codeberg** 是你会听到的两个名字。你在这本书里学习的地图，不是某家公司大楼的地图；它是一张关于这些工作坊如何运作的地图，而且可以迁移。如果你在这里学会了 issue 是什么、拟议更改是什么，你在任何地方都会认出它们。这本书不是任何一个工作坊的广告。它是一张地图，而一张好地图不会向你推销目的地。
