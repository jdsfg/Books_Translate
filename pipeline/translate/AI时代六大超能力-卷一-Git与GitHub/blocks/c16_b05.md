#### 定义：忽略列表

**忽略列表**是一个小文件，你在里面告诉 Git 它绝不能拍下什么：这是一个长期指令，让某些文件、文件夹或某类文件对每一个快照都自动、永远不可见，而不需要你每次都记得。保存这份列表的文件按惯例命名为 `.gitignore`。你不必手写它，也不必记住它的格式；你告诉智能体哪些东西要排除在外，它来维护这份列表。重点是这个概念：有些东西可以待在你的工作文件夹里，但绝不能进入历史。

忽略列表里应该放什么？有几类很清楚。

* **与你的工作放在一起的私人信息。** 一份个人笔记文件，一份带有家庭住址或电话号码的文档，任何为了方便而放在项目文件夹里、但不应该被发布或记住的敏感内容。如果 Maya 把到达安排放在一个单独的笔记文件中，并把它加入忽略列表，地址就根本不会进入快照。
* **技术意义上的秘密。** 密码、密钥、登录令牌：这类东西会在本系列后续卷中被认真对待。你在这里学到的习惯——“告诉工具它绝不能拍下什么”——是一切密钥卫生的种子：泄露的密钥就是已经泄露的密钥，而忽略列表是一堵墙，在密钥泄露之前就把它们挡在历史之外。密钥和密码与 Maya 的地址属于同一类，只是风险更高。
* **机器杂物。** 大型生成文件、临时垃圾、电脑会自行重建的东西。给这些东西拍照会让相册膨胀，却没有捕捉任何值得保存的内容。

忽略列表是一种预防习惯，它让整个危险消失。改写历史以移除泄露的秘密是手术。忽略列表是疫苗。设置它只需要 1 句白话，它会保护每一个未来快照。

**安全请求：** **永远不要拍下这个文件；它有私人信息，不能进入历史。** 对你的智能体说 1 次，这个指令就会成为长期规则。这是 Maya 希望自己早 1 周说过的句子，也是本可以省掉整场慌乱的句子。

注意本书的 3 条线索如何在这里汇合。到底会改变什么（预检 #1）？不会有敏感内容，因为忽略列表会把它拦下。我们能回去吗（#2）？能，而同一种持久记忆也正是泄露会持续存在的原因。这被共享了吗（#3）？正是泄露之所以重要的原因。判断层不是额外拧上去的规则；它就是这 3 个问题，在会咬人的边缘被问出来。
