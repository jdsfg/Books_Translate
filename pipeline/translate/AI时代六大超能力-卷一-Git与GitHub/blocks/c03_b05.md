### 2.4 你实际要提出的请求

还记得第 1 章说过，你的双手是一位AI智能体。你不会亲自操作这个工具；你会做决定、下指令，而AI智能体会执行，并向你展示它做了什么。

所以在你的真实生活里，拍快照这个动作就是一句话。Maya 不会输入咒语。她用普通话说出接近这样的一句话：**“在我开始编辑之前，拍一个我可以回来的快照，并注明这是引言已完成的版本。”**AI智能体会完成机械工作，处理其中那些隐秘的词汇，然后回报：它已经拍好快照，这是它保存的说明，这是你现在可以返回的时刻。Maya 读到这些，点点头，开始编辑；而这是她第一次没有那种小小的背景恐惧，因为她身后现在有一扇标记清楚、带着日期的门敞开着。

这就是整个动作。技能不在于操作。技能在于两件事：知道这是你可以请求的一件事，以及写下一条以后值得读的说明。这两件事都属于你，而且没有一件是技术性的。

我现在想种下一个习惯，它会贯穿本书接下来的部分，因为它区分了两种人：一种人安全地使用这个工具，另一种人最终会被它伤到。在你指示任何值得认真考虑的改变之前，先停一下，问三个小问题。本章让你获得前两个；第三个要到后面才会真正变得有力，但我现在先把它命名出来，好让这一组从一开始就是完整的。

  1. **到底会改变什么？**在你说同意之前，你想用普通话知道AI智能体接下来要做什么。拍快照是这个问题最安全的答案，因为快照对你的工作**什么也不改变**；它只记录已经在那里的一切。这是唯一一个永远不会让你付出代价的动作。
  2. **我们能回得去吗？**你拍快照的理由，就是要保证答案是能。你拍下的每一个快照，都是你为以后存下的一个“能”，一个你可以返回的标记位置。
  3. **这段历史已经被分享出去了吗？**这个问题现在还没有真正的锋利，因为到目前为止，你的快照只和你在一起。一旦其他人开始和你并肩工作，它就会变成本书中最重要的问题；等我们走到那里，会给它真正的重量。现在，只要注意它的形状：**我正要改变的，是只有我拥有的东西，还是别人正在依赖的东西？**

这三个问题，是后面一切事情的判断层。你会在每一章里再次见到它们，只要那一章里有某些东西值得谨慎对待；到最后，它们会变成自动发生的事，成为你批准任何事情之前在脑中运行的安静清单。拍快照，是你第一次练习它们的地方，而且是在最安全的动作上练习，这样当赌注升高时，这个习惯已经被磨得顺手了。
