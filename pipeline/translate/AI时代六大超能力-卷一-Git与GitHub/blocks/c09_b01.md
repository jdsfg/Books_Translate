Theo 把咖啡洒在了他的笔记本电脑上。

这不是那种戏剧性的泼洒。只是四分之一杯咖啡，被手肘碰倒，流进一台用了五年、已经威胁要死掉一整年的机器键盘里。它发出一声轻微而最终的响动，屏幕暗了下去，而且这一次再也没有亮回来。维修店说硬盘可能能恢复，也可能不能，星期四再来。

一年前，这句话会是一场灾难。指南就住在那台笔记本电脑上。他们做过的每一个快照、每一个分支、从第一次忐忑的提交到昨晚工作的整本相册，所有这些，都随着一台死掉的机器和一个陌生人的耸肩消失了。Maya 感到那种旧日的寒意袭来，身体比头脑更早理解了失去。

但这次没有发生。因为指南不只住在 Theo 的笔记本电脑上。它也完整地住在 Maya 的电脑上，还住在第三个地方，一个他们俩都没有把咖啡杯放在旁边的地方。Theo 当晚买了一台便宜的替换机器。到他们睡觉时，指南已经在上面了：每一个快照、每一个分支、整个历史，都和那天早上一模一样。什么都没有丢。相册里一张照片都没有少。

本章讲的就是这怎么可能，以及它为什么会改变你敢于尝试的事。第 7 章里，我们处理了在同一个地方一起工作时最后一件困难的事：两个人编辑同一个句子，由人类选择来解决。现在，工作根本不再只生活在一个地方。而它一旦生活在不止一个地方，你一生中一直带着的两个恐惧就会悄悄退休。


### 8.1 相册，在不止一个地方

到目前为止，你学到的一切都发生在一台机器上。快照（第 2 章）、容纳它们的相册（第 3 章）、分支（第 5 章）、合并和那一次冲突：所有这些都住在一台笔记本电脑的一个文件夹里。也就是说，所有这些都和那台笔记本电脑共享同一个命运。被偷、摔落、洒上一杯咖啡，整段美丽的历史就会随硬盘一起暗下去。

解决办法不是用你一直以来的方式做备份：在云端文件夹里放一份惶恐的额外副本，把整个项目压缩后发邮件给自己，或者使用那块你想起来才会更新、而你永远想不起来的外置硬盘。那些是**文件**的副本，是它们**此刻**的样子。它们不携带相册。它们不携带历史、分支、关于为什么这样做的备注。如果你从一个压缩包恢复，你得到的是今天的文件，而它们背后的每一个快照都已经丢了。你又回到了 `FINAL_v2` 的世界，只是文件夹更大了。

Maya 和 Theo 拥有的，是整本相册同时生活在不止一个地方。不是当前文件的扁平副本。而是真正的东西，带着历史和全部内容，在三个位置之间保持同步，这样其中任何一个位置都可以消失，而项目仍会从另外两个位置中的任意一个继续下去，毫发无损。

让这一切运转起来的那个地方，有一个名字。
