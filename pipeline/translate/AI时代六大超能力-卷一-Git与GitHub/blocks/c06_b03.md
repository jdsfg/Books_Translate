#### 常见误解

> **“分支就是我所有文件的一份完整副本。我创建一个分支时，工具会复制我的整个项目，于是我现在什么都有两份。”**

这是头号心智模型错误，值得一出现就把它消灭。

让我们推理一下，如果它是真的，会**意味着**什么。Theo 的指南连同所有照片，并不算小。如果创建分支意味着复制整个项目，每一章、每张图片、每份草稿都要复制，那么打开一个分支就会花费真正的时间和真正的空间。一个大项目创建分支会很慢，而且每次都会吃掉存储空间。分支会变成一个**决定**，一种你会三思的事情，就像在电脑上复制一个巨大文件夹之前会三思一样。人们会节省着使用分支。只有当他们觉得成本值得时，才会重新变得勇敢。

现在看看分支实际上的行为方式，让这个矛盾落下来。用这种方式工作的人会不断打开分支：为了一行修复，为了一个五分钟实验，为了一个“让我随便试试”，十分钟后就会扔掉。他们在远比 Theo 的指南更大的项目上瞬间打开分支，而不会对空间或时间有一丝犹豫。如果分支是一份副本，这种行为是不可能的。如此便宜、如此快速的东西，不可能正在复制你的整个项目。分支的日常现实本身，就证明了“副本”这幅图是错的。

那么，如果分支不是副本，它是什么？回到书签。当你在同一本书里放两个书签时，你并没有印出第二本书；你只是标记了已经拥有的那本书里的两个位置。分支就是这样。在底层，工具已经把你的完整历史保存成一串快照链条（第 2 章和第 3 章）。分支本质上是**一个指向链条中某个快照的标记**，一张写着“这条工作线在**这里**”的便条。创建一个分支只是放下一个新标记。它几乎没有成本，因为一个标记几乎什么都不是。它是一个指针，不是一堆文件。

当 Theo 在他的实验分支上工作并创建快照时，工具只记录**实际不同**于前一个状态的内容：重新排列过的章节，而不是每张未改变照片的新副本。两个宇宙共享的材料只存一次，然后由两边都指向它。这就是你在第 3 章见过的同一种节俭：我们说过，历史不会因为快照而膨胀，是因为快照共享未改变的部分。分支搭乘的也是同一种节俭：那些没有改变的大块内容从不被复制。

所以，你应该带着完全信心、不打折扣地从本章带走的真实句子是：**分支很便宜。分支是书签，不是副本。** 它便宜，是因为它不会复制你的工作；它只是标记一个位置。这不是一个锦上添花的细节。正是它让分支成为你一天可以做几十次的事，而不是一个项目只做一次的事；因此，“在安全的东西旁边尝试大胆的东西”才是一种真实的日常自由，而不是昂贵的折磨。

（关于这个比喻，有一个诚实的说明。“平行宇宙”抓住的是**体验**：两个现实版本，都是真实的，并排发展。“书签”抓住的是**成本**：几乎免费，只是一个标记。两者都要拿着：一个分支感觉像一个完整的另一个宇宙，可以在里面工作；而它的成本大约只相当于把书页一角折起来。魔法恰恰在于，这两件事同时为真。）
