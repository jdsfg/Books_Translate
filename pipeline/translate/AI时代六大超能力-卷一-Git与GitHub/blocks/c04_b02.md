### 3.1 快照会连成一条链

单个快照，是某一刻的一张照片。但这些时刻不是散落的。每个快照都知道自己前面是哪一个。

Maya 拍下"重写了 Alfama 步行路线"这个快照时，它是接在前一个快照**之上**拍下的。它不是自由漂浮的。它实际上在说：**我是这次改动之后项目的状态，而我紧接着的，是那边那个快照。** 那个快照又指向更早的一个，再往前还有一个，一直回到这本指南的第一个快照。所以你真正建立起来的，不是一堆东西。它是一条**链**：一条连在一起的线，从你拍下的第一张照片，一直延伸到五分钟前拍下的那一张。

这条链就是你项目的历史。值得停下来看看，它和第 1 章里的那个文件夹有多不一样。

那个装着 `guide_FINAL_v2_REALLY_final.docx` 文件的文件夹，是一堆东西。那些副本并排躺在那里，彼此没有关系。没有任何东西记录哪一个在前、哪一个在后，或者它们为什么存在，或者一个和下一个之间改了什么。六个月后，你盯着它们看，却拼不回故事。一堆东西没有顺序，也没有记忆。

一条链两者都有。每一环都有日期，带着关于"为什么"的说明，也知道自己在顺序里的准确位置。你可以从开头沿着链往前走，也可以从现在沿着链往回走；每一步，你都能读到改了什么、为什么改。那堆文件是副本的墓地。这条链是工作的故事，由工作自己讲出来。

这是本章的第一个大想法，而且它足够稳，可以直接说出来：**历史是一条由快照组成的链，你可以沿着它走。** 它不是一团需要解开的乱麻。它是一条你随时可以沿着两个方向走的路，而且不会碰到现在。
