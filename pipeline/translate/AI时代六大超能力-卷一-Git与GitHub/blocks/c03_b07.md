#### 应用题

**Q1.** 下面是同一次工作的两条 commit 说明。用白话说说，是什么让一条有用、另一条没用；再把那条差的改写成一条好的。

* 说明 A：**“改动”**
* 说明 B：**“删掉过时的‘夜生活’小节，并把里面两家还在营业的酒吧移到‘傍晚散步’这一章；旧小节留在上一个快照里，以防我们想把它找回来。”**

提示

想象一下，六个月后你只读这些说明，完全看不到实际做了什么。哪一条把故事讲给了你？哪一条可以拿来描述任何事情？

**答案：** 说明 A 可以描述世界上任何一次 commit；它没有带来任何信息，六个月后读起来只会像一张空白的脸。说明 B 把整个故事都讲清楚了：删掉了什么、搬去了哪里，以及那份安心感——没有东西真的丢失。一个陌生人，或者未来的 Maya，只读说明 B，不打开文件，也能准确明白发生了什么以及为什么发生。这就是一条好说明的测试：它能独自站住，像一句历史记录。说明 A 的一个可用改写可以是：“修正 Belém 步行路线里的电车编号（是 15，不是 25），并改正那家咖啡馆的营业时间。”注意，它说出了**什么**；在原因并不显而易见时，也说出了**为什么**。这条说明是写给一个看不到实际工作的人看的，因为那个看不到的人，就是以后的你。
