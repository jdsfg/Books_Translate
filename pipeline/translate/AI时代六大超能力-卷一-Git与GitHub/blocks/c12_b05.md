### 11.4 危险：批准你没有读过的东西

审阅的核心有一种诱惑，而且你越信任带来更改的人，这种诱惑就越强。

Núria 是朋友。Núria 懂里斯本。Núria 从来没有把她们带错方向。Maya 看见提议上 Núria 的名字，感到信任带来的温暖，然后不读差异的任何一行就点击批准，这本来会**太容易**了。这个更改大概没问题。阅读它甚至感觉有点像冒犯，就像复查朋友的算术题。

不要这样做。这是所有协作工作中最常见、代价也最高的错误；我想现在就直截了当地把它说出来，因为第 15 章会带着全部重量回到这里。

**当你批准一个更改时，你背书的不是那个人。你背书的是那个更改。**你的“是”会进入项目历史，并带着你的理解一起进入。如果那个更改包含了错误，比如一家也已经关门的咖啡馆、一个和下一节内容相矛盾的“修正”，或者一段不小心贴进去的私人细节，那么“可是 Núria 通常很可靠”根本不能安慰任何人，因为错误的东西现在已经在指南里、已经发布了，而且署名责任和她一样也在你身上。

来源越友好，审阅就越重要，而不是更不重要；因为信任恰恰会诱惑你跳过阅读，而一个你没有读过的提议，就不是一个你真正作出的更改。你只是继承了它。如果批准未读内容变成一种习惯，你就已经悄悄把自己的判断交了出去，而本书的整个要点也随之坍塌：**你**才是作决定的人，智能体只是双手。智能体可以在几秒钟内用普通话总结差异。没有任何诚实的借口可以解释为什么你没有读它。

这不是不信任 Núria。Maya 完全信任 Núria，而且**仍然**读了每一行，而且**仍然**发现了街区问题，指南也因此变得更好。认真阅读朋友的更改不是一种冒犯。它是一种尊重：认真到愿意思考他们的贡献。真正的冒犯，是没有阅读就挥手放行，好像它不值得被看一眼。

阅读差异。每一次都读。它只需要一分钟，而这就是全部工作。
