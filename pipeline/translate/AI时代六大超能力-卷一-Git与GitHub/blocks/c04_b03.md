#### 定义：仓库（repository）

**仓库（repository）** 是把一个项目和它曾经拍下的每一个快照的完整链条放在一起的地方：既有你文件的当前状态，**也有**它们的全部历史，作为一个整体保存。

用白话说：仓库就是**相册**。它不是一张照片，而是那本把所有照片按顺序、永久放在一起的相册。Maya 第一次请求拍快照时，智能体悄悄把他们那个普通文件夹变成了一个 仓库：一本相册。从那时起，它会保存他们拍下的每一个快照，并记住顺序。

这里会自然推出几件事，而且很容易被忽略，所以我把它们摊开来说。

仓库 不是别的地方。它不是一块单独的备份硬盘，也不是一个你需要登录的云账号。它就和你的文件待在一起，作为项目文件夹里一个普通的组成部分，在你工作时安静地保管这本相册。Maya 打开指南开始写作时，她就在 仓库 里。她请求智能体拍快照时，快照会进入那个已经在那里的相册。处理项目和保存项目历史，不是两个地方的两件杂活。它们在同一个地方。

而且 仓库 保存**所有东西**，不只是最新版本。这是很多人第一次遇到时仍然会惊讶的地方。相册里不只装着今天的指南；它装着今天的指南，**也装着**上个星期天的指南，装着 Theo 放进照片之前的那个版本，装着最早的粗草稿，一直往下，全部都在。表面上看，你的项目文件夹像是只保存了一份你的工作。可在下面的 仓库 里，它保存着整条链。Maya "回去看星期天的版本"时，她不是打开了另一个文件。她是在请相册向她展示它自己早些时候的一页。

所以，从现在开始，当本书说"这本指南"时，这个短语背后有一个更完整的真相。这本指南不是一个文件。这本指南是一个 仓库：当前草稿加上它被记住的整个过去，作为一个你可以走进去浏览的整体，住在一起。
