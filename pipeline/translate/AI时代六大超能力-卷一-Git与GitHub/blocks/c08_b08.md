#### 深入思考

**Q1.** 冲突迫使人类做一个工具拒绝做的选择。可是第 1 章我们一直在庆祝：你的智能体会处理机械性的工作，所以你不必亲自处理。这里有矛盾吗？冲突是不是把工具本该吸收的工作又“漏”回给了你？智能体应该决定什么、你又必须决定什么，这条线究竟在哪里？

提示

把两种工作分开：知道**怎样**做某件事（命令、机械操作），以及知道结果**应该是什么**（判断、意图）。冲突把哪一种交还给了你？

**讨论：** 这里没有真正的矛盾，而弄清原因会让本书的整个前提更清晰。智能体吸收的是**机械性**工作：运行命令、编织不重叠的编辑、把有争议的位置围起来、清楚地向你展示两个版本。这些它都做了。它交还给你的根本不是机械工作；那是一个**关于意义的判断**：开头应该温暖还是干脆，主张应该谨慎还是有力，小节应该叫“Transport”还是“Getting Around”。这从来都不该由智能体决定，你也不会希望它决定。两者之间的界线，正是本书从第一页起一直在画的那条线：智能体有词汇和双手；你有意图和品味。冲突不是工作漏回到了你身上；它是工具正确地把一个决定**路由**给唯一有资格做决定的一方。还要注意，一旦你已经告诉了它你的意图，一个经过人类认可的智能体也可以代表你解决冲突（“如果我们在语气上发生冲突，总是优先选择更温暖的版本”）。即便如此，**判断**仍然源自你；智能体是在执行一个长期有效的决定，而不是自己发明一个。冲突并没有违反“你的双手是一个智能体”这个模型。它揭示了这个模型最锋利的边缘：机器会做除了决定你的作品应该意味着什么以外的一切，而且它足够谨慎，知道其中的区别。


#### 对你的 AI 这样说

到现在，你的智能体已经知道怎样创建快照、显示历史、回到过去、创建分支，以及编织版本。本章新增的是这样的请求：一个用普通话说出的请求，把冲突从可怕的东西变成例行的东西。它建立在此前所有内容之上；你仍然不用输入任何命令。

> “我们都编辑了同一行，所以把两个版本并排展示给我，让我选择。”

而当你信任这个模式之后，自然的后续请求是：

> “把这两个版本编织到一起；如果有任何地方冲突，不要猜。停下来，把两个版本都展示给我，让我决定。”

注意它们和目前清单里的每一个请求有什么共同点：它们描述的是一个**结果和安全措施**，而不是一种机制。你是在告诉智能体走到岔路口时该做什么，而不是告诉它怎样走那条路。

**本章退休的恐惧：** **尝试大胆的事很危险。** 现在你知道，最后一道活板门已经被钉死：即使两个人伸手去改完全同一个句子，工具也会拒绝丢掉任何人的工作，并叫来人类做选择。你尝试的任何事，都不再有沉默而彻底的负面后果。无论独自工作还是与别人并肩工作，你都可以像你的想法一样大胆，敢于去做从第一页开始就一直拖着没做的重构。
