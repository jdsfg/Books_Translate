### 4.3 为什么过去（大多）是安全的：只追加

在这个工具里，回到过去之所以让人安心，是有原因的。即使你永远不会亲自操作那些机器，也值得在观念层面理解它。这是整个系统里最让人放心的单一事实；它有一个稍微技术一点的名字，我们会把它说得普通一些：历史是**只追加的**。

把相册想象成一条照片链，它实际也正是如此。每一个新快照都会被加到链条最前面。链条向前生长。这里有一个安静的奇迹：这个工具的日常普通操作，不会回到链条里去修改旧环节。它们会**添加新环节**。当 Maya 恢复那段文字时，工具并没有偷偷钻进上周二那张照片里，把那段文字粘回去。上周二的照片仍然显示那段文字不在，因为在上周二，它确实不在。照片的意义，正是忠实于它自己的时刻。相反，工具为今天拍了一张全新的照片，照片里那段文字存在，然后把它加到了最前面。

只追加的意思是，改变历史的普通方式是**延伸**它，而不是覆盖它。你修正记录的方式，是在底部写下一行新的、更真实的内容，就像诚实的账本修正错误一样：不是擦掉旧条目，而是加上一条新的，说“前面的数字错了；正确的是这个”。两行都留下。以后任何读到这里的人，都能看见发生了什么，以及是什么时候发生的。

#### 常见误解

**“撤销会删除过去。如果我回去了，就会失去那之后做过的一切。”**

这是每个人从“副本文件夹”世界里带来的恐惧；在那个世界里，这种恐惧完全有道理。在那里，“回到旧版本”意味着打开旧文件，并从它开始工作；这也意味着今天的版本现在变成了有可能丢失或被遗忘的那个。回去是一种**牺牲**：为了找回过去，你花掉了现在。

在这个工具里，在通常情况下，回到过去做的事情正好不是删除，而是**添加**。当你“撤销”一个改动时，通常的机制不是一块橡皮，把那次糟糕改动从历史中擦掉；它是一个放在最前面的**新快照**，只是这个新快照恰好看起来像你想要的状态。那次糟糕改动仍然在链条后面，看得见，有日期，也是记录的一部分。你没有抹掉周二到今天之间的一切。你写出了一个新的“现在”，它读起来是你想要的样子，而让你来到这里的每一步，仍然在身后可读。

所以，心里的修正要非常准确：**在这里，撤销的意思是“添加一个快照来恢复我想要的东西”，而不是“删除那些我后悔的快照”。** 过去不会被花掉来购买现在。两者都能幸存。一旦这一点真正落地，回到过去的恐惧大多会消散，因为看看并不会让你失去任何东西；即使是完整还原，也不会摧毁你正在还原掉的那部分内容。那些改动只是停止成为“现在”所展示的样子，同时仍然留在你身后的链条里。
