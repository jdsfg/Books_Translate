### 2.2 没有什么被浪费地复制

这里会浮起一个担心，值得明明白白回答，因为正是这个担心让许多人从来不信任这种工作方式。

如果每个快照都记录**整个**项目，而 Maya 每小时拍一次快照，她最后不会得到一百份完整指南副本、吞掉空间，变成她原本想逃离的那种蔓延开的混乱吗？看起来会是这样。其实不是，而原因安静又漂亮。

工具并不会愚蠢地对待真正发生变化的东西。当 Maya 编辑完一个段落后拍一个新快照时，它不会庄严地重新复制每一张照片和每一章没动过的内容。它会记录那个发生变化的东西的新状态，而对于其他一切，只是简单地**指回**它已经拥有的那个版本。一个项目里，如果你主要只是在编辑引言，那么一百个快照并不会消耗一百份指南那么多的空间；它们大致只消耗一份指南，加上每次真正发生变化的小小轨迹。你几乎不付出什么代价，就得到了一段完整的、可以到处走进去的历史。

你不需要知道它具体怎么做到这一点，我也不打算假装一种我只能编出来的精确。你需要的是直觉，而这个直觉很可靠：**经常拍快照很便宜，而且你本来就应该经常拍。**过去的本能是，“副本很贵，所以只在可怕的事情之前做一个”，在这里恰好反了。快照很便宜。每当你完成了一个值得命名的想法，就拍一个。一天提交十次的人不是在浪费；他们是在善待未来的自己，留下一条标注清楚的路径。频率现在是一种优点，而不是一种成本。
