#### 常见误解

**“打开一个拉取请求会改变项目。”**

这是最重要的误解，必须先清除；几乎每个新接触它的人都会带着这个想法。他们以为提出一个更改有点像提交一个更改，以为朋友一点击按钮，咖啡馆就已经从上线的指南里消失了，而 Maya 现在正在为一个编辑了她书稿的陌生人收拾残局。

事实正相反。**拉取请求什么都不会改变。** 它是一个提议，而提议恰恰就是那个**还没有发生**的东西。朋友的编辑完全存在于它自己的独立空间里。真正的指南，也就是 Maya 和 Theo 已经构建了八章的那一本，仅仅因为这个请求存在而完全不会被触碰。如果 Maya 一个月都不理这个请求，它会保持未被触碰；如果 Maya 决定拒绝它，它会永远保持未被触碰。拟议更改只有在某个有权限的人选择接受它的那一瞬间，才会成为真正的更改，在那之前一秒都不会。

好好感受一下这种反转带来了多少东西。你可以邀请地球上任何人提出建议，而不会给你的工作带来任何风险，因为一个提议伤害不了你。一个陌生人可以花一小时用心修正你的指南，而最坏的结果只是你说一句“不用了，谢谢”，然后什么都不会改变。让你能够把作品向全世界打开的安全感，完全来自这一点：**提出和接受是两个分开的动作，而且只有第二个动作会触碰项目。**
