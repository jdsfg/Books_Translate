#### 常见误解

**“GitHub 就是 Git。它们是一回事，或者 GitHub 只是 Git 的网站版。”**

它们不是一回事，而且这个区别值得牢牢记住，因为把它弄清楚，就是理解本章大部分内容的关键。

**Git** 是工具。它是负责做快照、保存相册、分支到平行宇宙、再把它们合并回来的东西。它运行在你自己的机器上，完全不需要互联网。第 2 章到第 7 章里的所有内容都是 Git，而且每一部分都能在关掉 wifi 的笔记本电脑上工作。Git 是一种技能，也是一件工具；它不属于任何公司。

**GitHub** 是建立在 Git 之上的工作坊。它是一个地方、一门生意、一个网站、一组装满服务器的建筑，人们把自己的 Git 相册放在那里，**这样其他人就能看见它们，并一起在上面工作。** GitHub 没有发明快照或分支；那些是 Git 的东西。GitHub 增加的是那个满是工作台的房间：地址、公开面孔，以及让陌生人阅读你的工作并向它提出更改的能力。

这里有一个能让区别保持清楚的测试。你可以使用 Git 很多年，却从不碰 GitHub；许多写作者保存着从不离开自己笔记本电脑的私有相册。而底下没有 Git 的 GitHub，会是一栋空建筑：工作台上什么也没有。工具是你一直在学习的技能。工作坊是可以把它带去的一个地方。把两者混为一谈，就像把**写作**和**图书馆**混为一谈：一个是你能做的事，另一个是让你做出来的东西变得可被找到、可被分享的地方。

守住这个区别，很多原本令人困惑的事都会变简单。当有人说“把它放到 GitHub 上”时，他们的意思是：把 Git 一直保存的相册带到工作坊里，让其他人能够到达它。相册已经属于你。工作坊只是给了它一扇门。
