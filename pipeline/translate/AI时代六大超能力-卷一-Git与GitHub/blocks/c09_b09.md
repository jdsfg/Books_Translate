#### 对你的 AI 这样说

到第 7 章为止，你能要求的一切仍然成立：修改前先做快照，给我看历史，把我带回过去但不要丢掉今天，为一次冒险尝试创建分支，把它合并回来，给我看发生碰撞的那一行的两个版本，并让我选择。第 8 章增加了一个动作，让所有这些都有了第二个家，并且附带它的安全半句：

* **“把今天的快照发布到我们的共享副本——但暂时不要公开它。”**

用白话说就好；智能体知道咒语。两半同样重要。前半句，**发布到我们的共享副本**，会让“我可能因为一台笔记本电脑坏掉而失去一切”退场：一旦整本相册的完整克隆住在第二个地方，任何单一机器的死亡都无法带走你的历史。后半句，**暂时不要公开它**，会把“什么时候让世界观看”的决定牢牢留在你手里，让它成为独立而审慎的决定，等到你真正准备好那一天再说。这一章里，害怕把毕生作品丢给一台摔坏的笔记本电脑，终于不再合理；它买来的勇气安静却巨大：你现在可以自由地创造，想做多久就做多久，因为你知道作品会活过机器。
