### 9.3 仓库的公开面孔

Maya 在浏览器里打开工作坊，第一次把他们指南的工作台当作一个**页面**而不是一个文件夹来看。那感觉很奇怪。她编辑了好几个星期的同一批文件，现在被排列成了访客会看到的样子。

我将只用概括方式描述她看到的东西，而且这是有意的。每个工作坊安排页面的方式都有些不同，这些安排也会年年变化；某个按钮的精确位置，正属于手册而不是地图。所以：大体上。

工作坊里的项目页面展示的是它的**公开面孔**。靠近顶部的地方，是项目名称和一段简短描述，也就是对“这是什么？”的一句话回答。下面是文件，可以浏览，访客可以点进去阅读。某个显眼位置，会有一份更长的欢迎文档，大多数项目都会把它放在正中央；这个页面用直白的散文说明这个项目是什么、面向谁，以及如何使用或参与贡献。页面里还穿插着一组用于**对话**的地方：开放问题和请求的列表、拟议更改的记录、谁在什么时候做了什么的历史。

最后那部分，正是让工作坊成为工作坊，而不只是互联网上一块硬盘的原因。共享硬盘上的文件夹保存你的文件。工作坊里的工作台保存你的文件，**并且保存一个有结构的地方来谈论它们**：提出问题，提议修复，争论它是不是正确的修复，并记录最终决定。文件是工作本身。对话是有其他人参与时，工作变得更好的方式。

Maya 和 Theo 的指南，在拉上的帘子后面，已经准备好了这一切，只是还没有人使用。然后他们把地址给了一位朋友。


### 9.4 那位注意到的人

他们的朋友 Núria 在这座城市住了十年，像本地人那样对它有自己的看法。Maya 邀请她阅读草稿，把她加入那张私有工作台，让她能看到帘子后面的内容，主要是想听听语气是否真实。

Núria 在一个星期天读了它。大部分内容她都很喜欢。但她读到 Alfama 一家小咖啡馆的条目时，那是陡峭老城区里的一家小店，Maya 曾热情地把它写成一个雨天下午的避难所，有好吃的蛋挞和一只猫；而 Núria 知道，因为她上周二刚从那里走过，它已经关门了。拉下了卷帘。没了。指南正在推荐一扇不再打开的门。

在旧世界里，Núria 会做人们通常会做的事：发一条短信。**“嘿，Alfama 那家咖啡馆关门了，你应该把它删掉。”** Maya 会在三天后看见，半记半忘地想着要修，也许后来就忘了。这个更正会住在一条聊天串里，与指南分离，很容易丢失。

相反，因为指南在工作坊里，Núria 做了一件工作坊让她能够做的事。她打开了一个 **issue**。
