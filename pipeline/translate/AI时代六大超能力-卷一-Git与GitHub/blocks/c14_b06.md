#### 应用题

**Q1.（判断：选择并阅读许可证。）** Maya 和 Theo 希望 _Rainy-Day Lisbon_ 可以被任何人自由阅读、修正和翻译；他们也乐意让别人以它为基础制作自己的指南，但他们希望得到署名，并且不想强迫别人的衍生指南也保持开放。用要点来说，哪一类许可证适合？在决定采用之前，你仍然会告诉他们要做哪一件事？

提示

问出区分这两大类的那个问题：一个人的**衍生**版本是否也必须保持开放？把他们的回答对应到许可证家族。然后想想谁应该阅读实际条款。

**答案：** 他们不想要求衍生指南保持开放，所以相同方式共享（copyleft）家族不适合；**宽松型（类似 MIT）**的形态更匹配：几乎可以做任何事，但保留声明和署名。这满足了“阅读、修正、翻译、在它之上构建，只要给我们署名”。要先做的一件事是：在 choosealicense.com 上阅读具体许可证的真实白话摘要（或让智能体把它找出来），确认署名/声明条件确实是他们以为的那样，**然后**再附上它。许可证要点是一张地图；真正的文本才是领土，而起作用的是领土。这也是本节诚实的边界：你可以教会别人这两大类的形状，但一旦涉及真实条款和真钱，重要的就是文本；如果风险很高，还要听专业人士的意见。要点会把你带到正确的门前；它不会替你签文件。

**Q2.（判断：阅读生命体征。）** 你被一个问题卡住，你的智能体给你指向两个开放项目，它们都声称能解决这个问题。项目 A：40,000 个星标，最后一次提交在四年前，900 个未关闭议题，几乎没有维护者回复。项目 B：400 个星标，最后一次提交在昨天，议题通常在一两天内得到回答。你更倾向依赖哪一个？为什么更有名的那个在这里反而风险更大？

提示

星标衡量的是过去的人群。三个生命体征里，哪一个衡量的是**现在**还有没有人在家？

**答案：** 更倾向项目 B。星标是滞后的受欢迎程度信号；它们告诉你曾经有一群人觉得 A 有用，而不是 A 现在仍然可用，或当它不可用时有人会帮你。决定性的生命体征是**最后提交日期**，再由议题回复模式支撑：A 已经四年没人动过，维护者也停止回答，这让它成了一座有名的废墟，也许仍能运行，但已经被抛下；所以如果它在你的问题上坏掉，不会有人来。B 更小，但明显还活着：最近的提交和得到回答的议题意味着有真人在照看它，并且很可能会看到你的 bug 报告或贡献。对于任何你需要依赖或贡献的东西，“它还活着吗？”每次都胜过“它有名吗？”。在你投入一个下午给其中任意一个项目之前，你会让智能体阅读这两个项目的生命体征，并用一句话交给你正是这样的比较。
