#### 常见误解

**“我提交了私人内容，但我在下一个快照里删掉了，所以它没了。”** 不。新的快照是干净的；旧快照仍然保存着它，因为历史按设计就是会记得。在新照片里删除，不等于把它从相册里移除。任何查看上周版本的人（合作者，或者如果项目后来公开了，就是陌生人）仍然能读到它。那次删除让**今天**变干净了，却没有改变过去。

那么真正的补救是什么？有 2 件事，而且都不是“删掉它然后放心”。

**第一，把秘密视为已经泄露。** 这是诚实、冷静的动作。如果泄露的是密码、密钥或登录信息，就假设有人可能已经看见它，并**更改它**：轮换密码，撤销密钥，签发新的。这是完全可靠的修复，完全在你的控制之内，而且不依赖任何棘手的历史手术。家庭住址没法“轮换”，所以 Maya 真正的问题更窄，也更人性化：谁能访问这段私有历史（只有她和 Theo），以及她是否想尝试把它从相册里擦掉。如果真正的秘密曾经泄露，轮换它才是实际有效的修复。

**第二，如果你确实想把材料从历史中擦除**，这是可能的，但它是真正的历史改写：也就是上一节那种危险的共享历史操作，只不过用来移除旧快照的内容。这正是应该交给你的智能体，并启用预检问题的事情，而不是凭半记得的教程自己尝试。我不会在这里给你精确的清理步骤；任何把它当作快速复制粘贴方案交给你的人，你都应该警惕，因为在共享历史上做错，会造成我们刚刚警告过的那种互相覆盖。正确的话是：**这个文件的历史里有私人信息；帮我理解我的选项，并记住任何泄露过的东西都应该视为已经泄露。** 然后你睁着眼睛做决定。

更深的教训是：泄露之后再清理很别扭，而且永远不会完全令人满意。正因如此，最好的动作远远是从一开始就阻止地址被拍进照片。

### 15.3 忽略列表：Git 绝不能拍下什么

Maya 的错误在于，地址位于一个工具被要求快照的文件**内部**。但项目文件夹里还有很多东西，你永远不想让它被拍下来，永远不想；而工具有一种干净、永久的方法来表达这一点。
