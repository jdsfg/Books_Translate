#### 应用题

**Q1.** 你已经为一个项目保存快照两个月了。现在你想回答一个具体问题：“我是在什么时候、在哪一次改动里，删除了关于雨天市场的那一节？”你现在还不想恢复任何东西；你只想**找到**那个时刻。用一句普通的话说，你会请你的智能体做什么？

提示

你不需要打开旧文件，也不需要比较副本。你需要把相册当作一个列表来阅读，并扫描那些说明。请它以能让你这样做的形式展示历史。

**答案：** 大致可以这样说：“请把这个项目的历史按列表显示给我，最新的在最前，用普通话说明，这样我就能找到雨天市场那一节是在哪里被删除的。”这个请求包含了本章给你的全部东西。**历史按列表显示**：你是在阅读这条链，而不是在文件里乱找。**最新的在最前**：这是标准的、便于浏览的顺序。**用普通话说明**：你要的是说明，而不是机器细节，因为说明才是你认出那个时刻的依据。列表摆在你面前之后，你顺着说明往下扫，直到某一条写着类似“删掉雨天市场一节”的内容；你的答案就在那里：日期、那次改动、那个确切的快照。注意，这种体验的质量完全取决于你在保存快照时写下的说明。这道练习是在安静地提醒你：每一个快照都要好好描述。

#### 深入思考

**Q1.** 本章说仓库，也就是相册，“还不是备份”，并让你去看第 8 章。一位朋友反驳说：“承认这一点好像很奇怪。如果它保存了我的全部历史，那不就等同于备份了吗？为什么要把这个区别划得这么清楚？”你会怎么回答？这个区别为什么真的重要？

**讨论：** 这个区别很重要，因为相册能防住一类灾难，却对完全不同的另一类灾难毫无作用；把两者混为一谈，正是人们在自以为安全时丢掉工作的方式。历史保护你免受**你自己**和**时间**的伤害：不小心覆盖、后悔的重写、再也找不到的版本。面对这些，快照链是真正而完整的防护：之前那个好的版本不会消失，因为相册记得它。但本章里的每一个快照都只存在于一个地方：一台笔记本电脑上的那个文件夹。面对**那个地方的丢失**，无论是被偷、火灾，还是硬盘坏掉，相册都帮不上忙，因为它只有一份。严格地说，备份意味着作品存在于某个地方，即使你的机器丢了也能幸存下来；这需要第二个位置。所以诚实的图景是：相册是一段极好的记忆，但到目前为止，它同时也是单点故障。把界线划清楚不是谦虚，而是安全。一个相信“我有完整历史，所以我已经备份了”的人，会非常自信地把一切都放在一台笔记本上，然后在一次事故中全部失去。真正安全的人，是那个明白“我在**这里**有完整历史，但我仍然需要给它一个第二个家”的人；等第 8 章教他们怎样给相册那个第二个家之后，他们才会真的安全。
