这个提议就在那里，等着星期一早上 Maya 打开指南时看见。

她们的朋友 Núria 在里斯本住了十年，指南一发布就读了它。她做的正是第 10 章说她可以做的事。她没有发一封邮件说：“嘿，Alfama 那家咖啡馆关门了，你哪天该改一下。”她把自己的修正变成了一个**拟议更改**：一个具体、可审阅的东西，带着她的备注，等在项目里，安静地问一个问题：**我可以把这个放进去吗？**

现在，决定权在 Maya 手里。不是打字的工作。智能体可以点个头就把 Núria 的更改放进去，也可以在几秒钟内把它留在外面。真正的问题是决定。一个 Maya 信任的人提出要改动她和 Theo 一起做出的书；而在那项改动成为指南的一部分之前，必须有一个能分辨对错的人来看一看，然后说可以。

这种“看一看”，就是本章的主题。它悄悄地，也是整本书中最重要的技能，因为我们此前学到的一切，都在通向你说出**是的，这个更改很好，让它进来**的那一刻；而整个问题在于，你能不能信任自己的这个“是”。


### 11.1 用白话说清楚更改

Maya 的第一反应，可能也是你的反应：觉得自己不够资格。Núria 编辑了指南。阅读别人做的编辑，听起来像是需要懂得如何读代码，或者至少要懂得如何读这些工具里那种神秘的编辑形式。Maya 已经准备好面对一堆符号。

于是她问智能体一个她唯一知道该问的问题：**用白话带我看一遍，这到底改了什么。**

答案一点也不神秘：

> Núria 提出的更改只动了 Alfama 部分的一段。它删除了推荐 Café Brilhante 的那一行；她注明这家店春天已经关门了。她建议换成附近的 Pastelaria do Rossio，并加了两句话介绍。她还修正了一个拼写：三段之后有一次把 “Alfama” 写成了 “Alafma”。指南里的其他地方都没有动。

事情就这么多。因为第一家咖啡馆关门了，所以把一家咖啡馆换成另一家。顺手抓到一个错别字。用白话读出来，它不是一堵符号墙。它是指南的任何读者都能理解的一句话：**如果你说可以，这里就是具体会变得不同的地方，这里就是原因。**

这就是**差异（diff）**，而且值得好好认识这个词，因为它是你将来每一次审阅的中心对象。
