到上一章结束时，Maya 和 Theo 正好有一个快照。

那是一个很好的快照。像一张干净、带日期的整本指南照片，记录了那天晚上它的样子，还附了一句明白话：**介绍部分的第一版真正草稿，在我们动咖啡馆那一节之前。** 他们选择拍下这个快照，而不是又做一个紧张兮兮的副本。于是，这本指南第一次拥有了一个不会被悄悄覆盖的过去。一个快照。一个开始。

但没有人只在单个快照里工作。一周后，快照已经有九个了。

这就是快照会做的事：它们会积累。每次 Maya 写完一段，或者 Theo 放进一张新照片，或者他们为一个标题争论一番后终于定下来，其中一人就会请智能体拍一个快照，并写一句说明刚才发生了什么。**重写了 Alfama 步行路线。加入 Theo 的雨天照片。把博物馆清单删到真正重要的四个。** 九张小小的、诚实的照片，每张都带着自己的理由。一个下雨的星期二，他们坐在一切开始的那张沙发上，Maya 说了一句三周前根本不可能说出口的话。

"你还记得我星期天重写介绍部分**之前**，它开头是怎么写的吗？我觉得旧版本的第一句更好。"

三周前，这个问题会是一场悲剧。旧版本在她重写的那一刻就没了，就像第 1 章里 Maya 的三段文字那样。现在，这只是一个有答案的问题。"我们去看看，"Theo 说。然后他们真的去看了。他们打开自己项目的历史，沿着它往回浏览，就像翻一本相册，直到他们读到这本指南在上个星期天下午的准确样子。

他们没有恢复任何东西。没有撤销任何东西。他们只是**看了看**过去，然后回到现在。这个小小的、平静的动作——阅读你自己的历史——就是本章要讲的内容，也正是在这里，第 1 章里的那种恐惧终于开始松开手。
