#### 深入思考

**Q1.** 本章把开源世界称为一个**公地**，并坚持说它靠规则运转，而不是靠没有规则来运转。但怀疑者可能会说：如果所有东西都可以免费拿走，为什么还会有人维护项目、回答陌生人的议题，或接受一个无名小卒的错别字修正？到底是什么把公地维系在一起？你第一次修正文档又和这有什么关系？

**讨论：** 认真对待这个怀疑者，因为“为什么会有人费这个劲？”正是公地核心处那个诚实的谜题。答案的一部分是许可证：规则让贡献**可以安心给出**。维护者接受陌生人的修正，部分原因是许可证已经把条款定好了；贡献在已知条件下进入，贡献者的工作也以同样地位加入同一个公地。相同方式共享许可证更进一步，把“向前传递”明说出来：你对他们作品的改进也必须保持开放，所以这个池子不能被悄悄抽干，流进封闭产品里。这就是一条规则在承担信任的工作。

但许可证只是地板。真正让公地保持活力的是：贡献**成本低，而且看得懂**。因为一个修正会作为一个小的、可审阅的、放在上下文里的提案到来（正是这一行，正是这个理由），维护者可以在几秒钟内接受陌生人的错别字修正，几乎没有成本，也几乎没有风险。接受一个好的小改动成本越低，流入的好小改动就越多，公地也就越富足。你的第一次文档修正不是慈善，也不是噪音；它就是公地按设计在运作。电车号码错了；现在它对了；下一个读者得到更好的服务；这份指南更可信；而你进行**第二次**贡献的门槛刚刚降低，因为你已经做过一次，而且天没有塌下来。把这件事乘以 180 million 人，你就得到了这间工作坊。它能维系在一起，不是因为人们都是圣人，而是因为规则让给予变得安全，工具让给予变得便宜。你，带着一个智能体和一个被注意到的错误，现在也是维系它的人之一。
