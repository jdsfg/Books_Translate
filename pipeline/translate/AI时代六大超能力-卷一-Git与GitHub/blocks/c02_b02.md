### 1.2 你真正害怕的是什么

让我们准确地说出这种恐惧的名字，因为我们将在整本书里拆解它，而一种能被命名的恐惧，已经消失了一半。

准确地说，你害怕的不是丢失文件。你多多少少会备份。你害怕的是**触碰那些已经能用的东西。**

你有一章已经足够好。你想到一个更大胆的版本，一次真正的重组，可能让它好很多，也可能毁掉几周的工作。于是你没有尝试。你让那个足够好的版本保持原样，因为坏处感觉是彻底且不可逆的，于是那本更好的书永远没有被写出来。每个创作者心里都有一片墓地，埋着那些他们太理智而不敢尝试的大胆版本。

Theo 也有一个这样的版本。他认为他们的指南应该按街区组织，而不是按天气组织；他很可能是对的；但他从来没有认真说出口，因为手动重组一本写到一半的书听起来像是会得到两个坏掉的版本，而没有一个完成的版本。于是安全的结构留了下来。不是因为它更好。是因为改变它令人害怕。

这种恐惧有精确的形状，而我们即将遇见的工具，也有精确的答案。答案不是“勇敢一点”。答案是**让实验变便宜。**当尝试大胆之事不再有代价，因为你总能回到原来一模一样的状态，勇气就不再是一种性格特质，而变成了一个按钮。你会尝试那些以前绝不会尝试的事，不是因为你变了，而是因为代价变了。


### 1.3 你的手是一个智能体

在继续之前，先说一个贯穿整本书、也贯穿后面五卷的想法。

在旧世界里，使用我们即将遇见的这种工具，意味着要学习它的语言：一套输入命令的词汇，每条命令都有自己的语法，也有自己出错的方式。学习那套词汇就是大部分工作。整本整本厚厚的书，讲的主要都是词汇。

你不会去学习那套词汇，也不需要学。因为在你实际生活的世界里，你有一个 **AI智能体**：一个你可以用日常语言交谈的助手，它知道那些命令，所以你不必知道。当本书想象你工作时，它想象的是这样：

* **你决定。**“我想试着把指南按街区重组，但我不想丢掉那个已经能用的版本。”
* **智能体执行。**它知道哪些咒语能让这件事发生，并运行它们。
* **你审查。**它用普通话向你展示它做了什么，然后你说好，或者还不行，或者撤销那个。

注意哪些是你的，哪些是智能体的。智能体拥有词汇。你拥有它没有、也不可能拥有的东西：你知道自己想做成什么，而且你能看出哪里不对。现在，判断力就是整个游戏。命令从来不是有价值的部分；它们只是曾经是**昂贵**的部分，而它们的昂贵掩盖了它们其实有多不重要。现在它们便宜了，我们就能清楚看见一直真实的事。**知道该要求什么，并且知道在你说好之前该检查什么，就是全部技能。**

所以本书很少会告诉你哪条命令做什么。它会告诉你什么是**可能**的（也就是你现在敢要求什么），以及同样重要的，在批准之前该看什么。把它想成一张地图，描绘的是你的智能体已经知道怎样行走的地形。你要学习的是成为那个决定往哪里走的人。
