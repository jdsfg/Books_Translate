#### 定义：远程

**远程**是你的项目相册的一份副本，生活在你自己机器以外的某个地方：在另一个人的笔记本电脑上，或者更常见的是，在一个你们都能到达的共享位置，比如互联网上的工作间。它保存着和你本地相册一样的历史：同样的快照、同样的分支、同样的备注。现在，你的工作生活在**不止一个地方**，而远程就是那个“另一个地方”。

两个朴素的动作把你的机器和远程连接起来，而且它们彼此正好互为镜像：

* 把你的新快照**发布**到远程，让另一个地方知道你刚刚做了什么。（工具自己的词是**推送**。）
* 把远程的新快照**获取**到你的机器上，让你知道另一个地方做了什么。（工具自己的词是**拉取**。）

这就是整个关系。你像一直以来那样在本地拍下快照；然后，当你准备好时，把它们发布到共享副本。当你的合作者发布了他们的内容时，你把它们获取下来。没有人的工作会覆盖任何人的工作。发布会把你的快照添加到共享相册；获取会把他们的快照添加到你的相册。两本相册都会增长；谁也不会被覆盖。

注意远程**不是什么**。它不是一个你必须理解的“服务器”，不是一种特殊文件，也不是你们两个人同时打字进去的实时文档。它只是同一本相册的另一份副本，保存在比单台笔记本电脑更安全的某个地方，而你们两个人同意通过发布和获取让它保持同步。远程这个词只表示“在别处的相册”。

你不会自己运行这些。你会用普通话说：“把今天的快照发布到我们的共享副本”，智能体知道咒语。你需要的不是命令。你需要的是这幅图像：你的相册，现在生活在第二个地方；当你发布时，它得到你的新快照，当你从另一个地方获取时，它得到另一个地方的新快照。


### 8.2 丢了一台笔记本，什么也不会丢

让 Theo 那杯洒出的咖啡只是令人耸肩、而不是灾难的承诺，可以直白地说成这样：

**当你的项目生活在不止一个地方时，失去任何一个地方都不会失去任何东西。**

这成立，是因为有件事我们还没有完全说清楚。当 Theo 的新笔记本电脑从共享副本把指南拉取下来时，它下载的不是当前文件。它下载的是整本相册：从第一个到最后一个的每一个快照、每一个分支、每一条关于为什么这样做的备注。他的新机器保存着整段历史的一份完整、独立的副本，和那天早上那台死掉的笔记本电脑里保存的东西没有区别。他可以浏览上个月的版本，重新查看他们尝试街区重排的那个分支，阅读任何一次提交上的备注。所有这一切，都在一台只存在了四个小时的机器上。

这种完整副本也有一个名字。
