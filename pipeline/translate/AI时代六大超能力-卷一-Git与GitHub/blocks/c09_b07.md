#### 深入思考

**Q1.** 人们说“把我的工作推送到云端”和“下载最新版本”，听起来就像把一个文件上传到共享文件夹，再把它下载回来。但远程不是共享文件夹，发布快照也不是上传文件。这个“云端文件夹”的心智模型会在哪些地方悄悄误导你？如果你真的相信它，会出什么问题？

**讨论：** 文件夹模型说对了一件事（工作最终到了第二个地方），然后说错了两件事，而咬人的正是那些错的地方。第一，共享文件夹保存的是**今天的文件**；它把历史压平抹掉了。如果你真的相信远程就是云端的一个文件夹，你会以为从它恢复时只能得到当前版本，得不到它背后的任何内容；你也会把本地历史当成过去唯一“真正”的副本。但远程保存的是一个**完整克隆**，也就是整本相册，所以历史并不是只危险地留在你自己机器上的东西；它也完整地住在第二个地方。这正是为什么一台笔记本电脑坏了也不会丢东西，而文件夹模型解释不了这一点。第二，共享文件夹会覆盖：较新的文件替换较旧的文件；如果两个人同时保存，一个保存会赢，另一个会消失：第 1 章的灾难又回来了。但发布快照不会覆盖。它会把你的快照**添加**到共享相册里，和其他人的快照并排放着；没有东西会被冲掉，而当两处编辑确实发生碰撞时，你已经从第 7 章知道，工具会停下来询问人，而不是静悄悄地挑一个赢家。所以文件夹模型的危险在于，它让你害怕错误的事情（文件被覆盖丢失，而这不会发生），同时让你看不见自己真正拥有的安全（你的完整历史有第二份完整副本）。把这个模型换成准确的模型：**另一份完整的相册副本，通过发布和获取保持同步**，恐惧和困惑都会消散。
