### 6.2 “合并很干净”是什么意思

你会听到这个说法，或者你的智能体会这样告诉你：**合并很干净。** 它听起来像行话。其实这是一句简单而让人安心的话，而且值得你确切知道它是什么意思，因为这决定了一个合并是你一眼就能批准，还是需要你认真查看。

**“合并很干净”意思是：两条线改动的是不同的东西，所以工具可以把它们编织在一起，不需要任何猜测。** 实验里的每一处改动，都正好放进了主线没有碰过的位置；主线上的每一处改动，也都待在实验没有碰过的位置。从来没有哪个地方是两条线编辑了同一份材料并且意见不一致。所以没有决定要做，没有硬币要抛，也没有什么需要人来裁断。这个编织是机械的，也是确定的。

这不是运气，也并不罕见。这是正常结果，而且有原因。大多数真实协作天然就是分开的。Maya 写咖啡馆描述；Theo 处理照片和结构。Okonkwo 博士起草她论文的新章节，同时导师的评论落在前面某一章上。Rosa 更新面包店的节日价格，同时她的搭档 Ana 重写过敏提示。两双手，两个区域。人们在不同部分上工作时（他们通常也确实如此，因为这就是“分工”的意思），他们的改动不会重叠，编织每次都会是干净的。

所以，当 Theo 的智能体报告说重新排序已经干净地合并进主指南时，它是在告诉他一件具体而真实的事：**你的重组碰到的是章节的排列；Maya 在这期间做的事没有碰到同一份材料；因此你的工作和她的工作都进去了，没有丢失任何东西，也没有任何需要决定的地方。** 他可以松一口气。现在这本书同时有了他的结构和她的修正，处在同一条历史线上，两个宇宙又重新合为一个。

干净的合并常常几乎没有高潮：你提出请求，智能体进行编织，然后报告说没有任何东西相撞。没有戏剧性，就是好消息。合并里的戏剧性意味着冲突，而冲突意味着需要人。干净的意思是：不需要。
