### 章节总结

每个你现在能像 Maya 和 Theo 那样搭建的项目，也都可能抵达这个工具会咬人的少数时刻，而这样的时刻只有少数几个。**改写共享历史**是第一个：整理或重排你的快照，在历史只属于你时完全安全；一旦别人也持有它，就会真的危险，因为强制推送可能覆盖他们工作所站立的地基。护栏是第 3 个预检问题：**这已经被共享了吗？** 以及长期指令：**在你改写任何共享历史或覆盖发布别人的工作之前，停下来问我。**

第二个是**已经提交的秘密**。历史按设计就是会记得，所以从今天的版本中删除私人细节，会让它仍然完好地留在上周的快照里。对泄露的密码或密钥来说，可靠的补救是把它视为已经泄露并更改它；从共享历史中擦除它是真正的历史改写，应当交给你的智能体，并启用预检问题，而不是交给复制来的教程。而让整个问题消失的预防，是**忽略列表**：告诉 Git 它绝不能拍下什么，这条小小的长期规则会把地址、秘密和杂物挡在每一个未来快照之外，也是后续卷会建立的密钥卫生的种子。还有 2 个更安静的边缘：Git 在大型二进制文件面前会吃力，这些文件更适合放在别处；Git 也不是实时同步共同编辑的正确工具，那是共享实时文档的工作。这些都不构成恐惧的理由。它是一张短而明亮的清单，标出地面松软之处，让你踩上去之前先试探。

接下来，在第 16 章，我们把一切收拢起来。**Rainy-Day Lisbon** 发布了，而你在前 15 章里收集的每一个白话请求（每一个“对你的 AI 这样说”、每一个安全检查、每一个预检问题）都会被铺成一张单独的地图：勇气账本，对你曾经害怕什么、如今可以敢于做什么的一页说明。
