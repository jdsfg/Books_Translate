### 本章小结

把两条工作线编织到一起通常是自动的：当编辑触及项目的不同部分时，工具会毫不张扬地把它们缝成一个，就像第 6 章里 Theo 的整次重组回到主线那样。唯一的例外，是两处改动以不同方式伸向**同一**片内容：同一个句子、同一个标题、同一个价格。在那里，工具无法诚实地猜测，于是它会做它能做的最有价值的事：停下来，向你展示两个版本，并把决定交给人类。这个停顿就是一个**合并冲突。**

冲突不是你弄坏了什么，也不是你造成的错误。它是工具捕捉到了一个只有人能做的决定，并暂停下来，让你在两个版本都安全地摆在面前、什么都没有丢失的情况下做决定。另一种选择，一个“友好”到悄悄保留一个版本、删除另一个版本的工具，才是真正危险的东西，因为它总有一天会无声无息地抹掉你工作中更好的那一半。暂停是一种保护。当 Maya 和 Theo 都重写了指南的开头句时，工具拒绝在温暖和干脆之间替他们选择；Maya 读了两个版本，想了想这本书，然后写出了一个比任何单独版本都更好的开头。工具留在文件里的脚手架，只是它用来隔开两个版本的方式，标明**就在这里，你们两个人意见不一致**，而不是需要你背下来的东西。

这结束了贯穿第 5、6、7 章的分支线索，也连同它一起结束了本书里最古老的恐惧。大胆之所以曾经危险，只是因为代价可能是沉默而彻底的。快照、分支、干净的合并，以及现在的冲突，已经移除了每一道沉默的活板门，包括最后一道：对协作意味着互相覆盖的恐惧。你们不会互相覆盖。工具不会允许这种事发生。

接下来，在第 8 章，我们会让工作同时生活在不止一个地方。到目前为止，一切都发生在一台笔记本电脑上；我们将要给这份指南一个超出它的家，在房间另一边 Theo 的机器上，也在某个他们二人可以相遇的地方，让一台笔记本丢失时什么也不会丢，让两个人真正能够像一个人那样工作。
