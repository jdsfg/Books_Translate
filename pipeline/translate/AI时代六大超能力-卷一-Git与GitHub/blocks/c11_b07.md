#### 深入思考

**Q1.** 本章把拉取请求称为“这个共同创造时代最伟大的社会发明”，比工具本身还重要。这是一个很强的说法。请为反对它的立场提出最有力的论证，然后说明你认为这个说法在哪些地方仍然站得住。

提示

“社会发明”是关于**人**的说法，不是关于软件的说法。问一问：这里重要的是某项技术，还是人类围绕一个共享对象建立关系的新方式？它真的新吗，还是只是像编辑工作那样的旧东西的更快版本？

**讨论：** 最有力的反对意见是：这不过是一种更顺手的编辑流程。几个世纪以来，编辑一直在接收建议、批注文稿，并决定哪些内容进入成品，所以把一个软件功能称为伟大的社会发明，是夸大其词。认真对待这个反对意见；这种连续性是真实存在的。真正新的地方在于**它包含了谁**，以及**它以怎样的规模和成本做到这一点**。旧的编辑机器只能在你已经加入的机构内部运作——一家杂志、一家出版社、一个委员会——而且缓慢、依赖大量人工。拉取请求让一个任何地方的完全陌生人，一个你从未见过、也许永远不会见到的人，完成一次改进的全部工作，并把它作为成品交给你，同时你保持绝对控制，摩擦几乎为零；它每天以数亿次的规模做到这一点。这种组合（陌生人、规模、近乎零成本、所有者保持控制）以前并不存在，它改变了谁可以改善谁的工作。这个说法之所以站得住，不是因为经审阅的贡献这个**想法**是新的，而是因为拉取请求让它几乎以零成本对每个人、对几乎任何东西都可用。还要注意，这个说法关乎**人**：这项发明不是 diff，也不是按钮，而是一种新的关系形状——我可以让你的工作变得更好而不威胁它，你也可以在不先信任我的情况下接受我的帮助。这就是为什么它属于一个关于人的章节，而不是一个关于软件的章节，也就是为什么那对正在写非技术城市指南的伴侣和任何程序员一样能从中受益。

#### 对你的 AI 这样说

现在你已经拥有了整个交接所需的词汇，所以这里是本章的请求：意图层面的表达，没有命令，并建立在前面所有内容之上：

* **“把我的修正变成一个我们朋友能在纳入之前审阅的拟议更改。”**

注意这句话的形状，以及它如何承载整章的意思。你不是在说“把我的修正放进去”。你是在说**提议**它，并且说**在纳入之前**，用朴素的话点明提出和接受之间的那道缝隙，而整章讲的正是这道缝隙。你的智能体会构建拉取请求；而你理解的是：提议还不是更改，并且仍然需要有人做出决定。

而这正是本章让你放下的恐惧。直到现在，把你的作品开放给别人，意味着要在两件令人害怕的事之间选择：把钥匙交给陌生人，或者淹没在所有人建议带来的劳动里。**你不再需要选择。** 你现在可以大胆让地球上任何人对你做出的东西提出改进，也可以大胆邀请他们这样做，因为你知道，在你理解它到底改变了什么并决定说“是”之前，他们提出的任何东西都无法触碰你的工作。
