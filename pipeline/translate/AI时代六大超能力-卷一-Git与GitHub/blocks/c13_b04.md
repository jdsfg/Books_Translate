### 12.3 一页讲完贡献礼仪

工具允许陌生人向你的作品提出变更。这个陌生人会成为受欢迎的协作者，还是让人筋疲力尽的人，和工具无关，和礼貌有关。无论你是提出变更的人，还是做决定的人，这就是完整礼仪，小到可以装进脑子里。

**保持每个变更小而聚焦。** 每个提案只放一个想法。那位添加博物馆小节的家长，应该提出**博物馆小节**，而不是博物馆小节加上他们碰巧不喜欢的引言重写，再加上他们注意到的一处图片说明修正。一个小而聚焦的变更，维护者才能在一次坐下来时真正读完、理解并做决定。一个到处蔓延、碰到所有东西的变更，是没人能安全批准的变更，所以它会放在那里腐烂。如果你有 3 个改进，那就是 3 个提案，不是 1 个。你的智能体可以帮你把它们分开；请它这样做。

**用白话清楚说明为什么。** 拟议变更会带着一条说明到来，而说明才是协作真正发生的地方。“新增了儿童博物馆小节；作为家长，我一直希望有这一节，而且我核对了这 5 个地方目前都提供雨天活动”，这会告诉 Maya 做出有把握决定所需的一切。“随便加了点东西”什么也没有告诉她，还让她自己去做考古。你的为什么越清楚，她的 同意 就越容易。

**尊重维护者说 拒绝 的权利。** 这是最重要的一条，也是人们在为自己的作品自豪时最容易忘记的一条。这是 Maya 的指南。她可以拒绝你的章节，可以请你修改它，也可以因为忙而把它放上一个月。一个 拒绝 不是侮辱，也不是浪费你的努力。你仍然拥有你的 fork、你的副本、你的章节；你可以自由地自己保留，或者拿去别处提议。维护者没有义务满足你。当你向别人的项目提出变更时，你是带着礼物来访的客人，不是提交投诉的顾客。理解这一点的客人会被再次邀请。

那么 3 行就是：**小而聚焦；清楚说明为什么；尊重 拒绝。** 这就是改进别人作品的完整礼貌准则。其他都是装饰。

而且它是双向的。如果你是维护者，而且一旦你的项目公开，你就会是维护者，那么礼仪也有镜像。即使你拒绝提案，也要感谢别人。友善地说明你拒绝的**原因**，因为清楚的 拒绝 会教人；沉默的 拒绝 只会伤人。记住，有人花了自己的晚上，试图让你的东西变得更好。开放形态的健康，建立在双方都保持体面之上；而你会扮演双方的角色，常常就在同一周里。
