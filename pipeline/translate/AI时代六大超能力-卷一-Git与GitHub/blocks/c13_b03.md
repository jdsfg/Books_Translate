#### 常见误解

**“fork 是敌对的。fork 别人的项目意味着偷走它，或者把它分裂出去，或者带着别人的作品走掉。”**

这个词带着来自新闻的包袱：你会听到某个群体在一次激烈争吵后“fork 了”一个项目，愤然离开去做一个竞争版本。这确实会发生，虽然很少，而且它正因为戏剧性才成为人们记住的戏剧性例外。它不是 fork 的本质。

fork 是通往帮助的普通、友善入口。绝大多数时候，fork 只为一个原因存在：有人想贡献，而拿走自己的一份副本，是在把成果交回来之前进行工作的礼貌、安全方式。那位家长 fork 这份指南，不是在偷走它，也不是在分裂它。他们是在卷起袖子。fork 是工作坊说出的这句话：“这里有一张属于你的工作台；在这里完成你的改进，等它准备好了，再拿来给我。”拿一份副本，并不是带着作品离开。它是带着礼物**走向**所有者的第一步。

证据就在接下来发生的事情里。敌对行为会结束关系。通常情况下，一个 fork 会**开启**一段关系；它的存在是为了让拉取请求成为可能。如果 fork 感觉像偷窃，那就不会有人接受拟议变更；然而，接受来自 fork 的拟议变更，正是大型公共项目成长的最常见方式。这个词听起来有攻击性。这个动作本身是慷慨的。
