### 5.5 你现在可以敢做什么

说出本章要让你放下的恐惧，因为每章都会放下一种，而这一章放下的恐惧很大。那种恐惧是：**我不能尝试大胆的事；这个实验可能会毁掉已经能用的版本，所以我只好把更好的想法搁着不做。** 只要尝试大胆的事和保住安全的版本二者不能同时成立，这种恐惧就有现实基础。分支终结了这种二选一。你现在可以同时拥有两者：大胆的尝试和安全的原版，并排存在，都是真实的，想保留多久都可以。

所以，这就是你现在可以敢做的事，以及当你敢做时该怎样提出请求。当你发现自己因为某件事可能毁掉正在工作的版本，而**没有**对项目做它时（一次重组、一次重写、一次彻底的实验），这种退缩现在是一个信号，而不是停车牌。它的意思是：打开一个分支。用通俗的话对你的智能体说，**开一个单独的分支，让我可以试试这个，不要碰已经能用的版本**，然后就按照这个想法应得的程度大胆去做。无论你成功还是失败，已经能用的版本都会在那里等着。

还剩下一件悬着的事，而且是好的一种悬着。Theo 的重组成功了。它正待在一个平行宇宙里，比主指南更好，而它需要回**家**。这条按街区组织的主干必须变成真正的指南，理想情况下还不能丢掉同一个周末 Maya 在 main 上做的说明文字修正和更锐利的引言。两个宇宙现在必须变成一个。把它们编织到一起，是一个独立的想法，有它自己的安静魔法，也有它唯一棘手的情况，而这正是 第 6 章 开始的地方。


### 5.6 练习

这些问题是用来预测和推理的，不是用来计算的。读每一个问题，在打开讨论之前先形成你自己的答案，并特别留意那个要求你思考成本的问题，因为那一个问题里装着整章内容。


#### 概念检查

**Q1.** 用你自己的话，并且不要使用“复制”这个词，说明什么是分支。用两种方式说：它让你能**做**什么，以及它要你付出什么**成本**。

提示

本章有意给了你两个比喻。一个关于体验（两个现实同时存在）。一个关于成本（一个标记，几乎免费）。好的答案会同时用到两者。

**答案：** 分支是项目的一个平行宇宙——一条单独的工作线，你可以在里面自由修改，而你出发时的那个版本会保持原样。这就是它让你能做的事：把一个大胆的实验和一个安全的原版并排拿在手里，两者都真实，同时存在。它的成本则几乎为零，因为分支是一个书签，是一个指向你历史中某个位置的标记，不是你文件的副本。如果你的答案只说出了“平行宇宙”这一半，你就抓住了体验，却没有抓住成本；而正是成本让创建分支成为日常自由，而不是稀有昂贵的事件。如果你的答案只说出了“书签”这一半，你就抓住了节俭，却可能错过人们为什么要费这个劲。两半合在一起，才是完整的想法。
