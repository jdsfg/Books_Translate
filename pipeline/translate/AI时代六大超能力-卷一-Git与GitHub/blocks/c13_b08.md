### 本章小结

共同工作并不是单一的一件事；它有不同的形态。**单人形态**（你、你的智能体，以及未来的你）是基础，即使你从不分享，本书中的一切也都服务于它。**小团队形态**（几个彼此信任的人，人人都有同一个共享家园的钥匙）是分支和干净编织安静发挥作用的地方。而**开放形态**（陌生人在从未见面的情况下改进彼此的工作）则会把世界拓宽，它依靠的是一个你现在已经完全理解的动作。

这个动作就是 **fork**：你拥有的、别人相册的完整副本；你可以自由修改它，然后通过拉取请求把它送回去。没有人发放钥匙；贡献者拿走一个独立副本，安心工作，对原件没有任何风险，然后把自己的修改提议送回原主人那里，由主人接受或拒绝。**Fork、修改、提议送回**：三个步骤，全都建立在你已经拥有的工具之上。而且，“fork”并不像听起来那样带有敌意：它是帮助他人的友好入口，是工作坊给陌生人递上一张属于他们自己的工作台的方式。

让开放形态保持健康的，不是机器，而是礼貌，小到一只手就能握住：让每次修改都**小而聚焦**，用清楚朴素的话说明**为什么**，并且**尊重维护者说不的权利**；当你是维护者时，也遵守镜像规则：一个友善、有理由的“不”会教会对方方向，而沉默的“不”只会伤人。有了这些，真实项目只属于专家的恐惧就会退去。一位家长给旅行指南增加博物馆章节，并不是程序员；他们只是一个在意这件事的人，拿了一份副本，又回馈了一点东西。现在，你可以站在这场交换的任意一边。

接下来，在第 13 章，我们会一路走进这扇开放的大门：世界规模的整个公地，数以百万计的项目都可以自由阅读和改进，由你已经学过的动作维系，再加上一件新事物：它决定你可以如何使用你找到的东西，那就是许可证。
