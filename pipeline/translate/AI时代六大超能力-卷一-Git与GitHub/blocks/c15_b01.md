你现在已经有了整张地图。

回头看看你能叫出名字的东西。快照：给你的整个项目拍一张照片，并附上一句说明为什么。存放那些照片的相册。不丢掉今天的工作也能回到过去。分支，它是一个平行宇宙，从不是一份副本。把两个宇宙合并在一起，以及合并需要人类出面的那一个时刻。你的工作活在不止一个地方。世界的工作坊、被提出的更改、用白话读懂的 diff、被回馈出去的 fork。十三章，每一章都给一座你现在能在黑暗中行走的房子加了一个房间。

当你学习这些时，没有人告诉你一件事。那些概念没有一个是关于代码的。

再看它们一遍。快照是**一个项目**的照片。分支是**你正在制作的某个东西**的平行版本。冲突是两个人编辑**同一句话**。用新鲜的眼睛读这些定义，你会注意到它们一次也没有说“软件”。它们也不可能这么说，因为它们解决的问题比软件更古老，也更宽广。那个问题是：**我在长期制作某样东西，而我害怕碰到已经能用的部分。** 这就是那个下雨的星期六里的 Maya。也是每一位写作者、每一位研究者、每一位拿着价格表的店主、每一对保存食谱盒的伴侣。

本章就是这张地图不再只是 Maya 和 Theo 的指南书故事，而开始成为**你**的故事的地方。我们会走过四个与编程毫无关系的项目（一篇论文、一家面包店的价格表、一套家庭食谱集、一个个人网站），并看着你已经知道的那些动作做完全相同的工作。不是这些动作的隐喻。就是这些动作本身。

然后，因为一张隐藏沼泽的地图会让人迷路，我们会诚实说明这个工具什么时候是错误的工具。有两片沼泽。我会把两者都明明白白地展示出来，这样你就不会误入其中。
