你的电脑上有一个文件夹，或类似的东西，而你早已清楚里面装着什么：`essay_v2`、`essay_FINAL`、`essay_FINAL_v2_REALLY_final`。没人教过你去建它。你造出它，只因一种单一、却合情合理的恐惧：怕动到已经能用的成果，结果弄丢它。这本书讲的，就是消解这种恐惧的工具；也讲为什么，有史以来第一次，你可以不必变成专家也能用上它。

这件工具叫作 Git，而建在它之上的工作坊叫作 GitHub。在它们历史的大部分时间里，它们属于程序员，由一堵需要真功夫才能学会的打字命令之墙守护。改变的，正是这堵墙。你现在已经有——或可以拥有——一个懂那些命令的 AI 智能体，于是你不必自己去学。你用白话说出想要什么。它来念那些咒语。这意味着，一种曾经只属于软件团队的工作方式，突然对任何创造者开放：小说、学位论文、生意上的价目表、旅行指南、食谱集、网站。

**这是一张地图，而不是一本手册。** 这一区分是全书的脊梁，所以我要把承诺说得尽可能锋利，并请你据此检验我：

> 读完这本书后，若你忘掉了每一条命令，却仍能说出快照是什么、分支是**用来做什么**的，以及在发布一处变更之前该核对什么——你就已经拿到了本书的全部价值。若你背下了二十条命令，却说不出分支是用来做什么的——你什么也没拿到。

这里不会出现要你照着敲的命令序列。你会遇到的是**地形**：每件工具让什么成为可能，你现在可以大胆要求什么，以及同样重要的——在说“好”之前该看什么。命令从来不是有价值的那部分。它们只是昂贵的那部分；如今智能体让它们变便宜了，我们终于能看清始终重要的东西：判断。知道该要求什么，以及该核对什么——这就是全部技能。

**本书如何铺开。** 有一个项目贯穿每一章：Maya 与 Theo，一对没有编程背景的夫妇，借助 AI 智能体做机械活，自出版一本小小的城市指南。你会看着他们的指南从第一张快照长大，经过一次在分支上安全尝试的大胆重组，经过两人同一天改写同一句话的那一天，再走向外面的世界——先是朋友、然后是陌生人，来帮忙把它改得更好。在他们身旁，你还会看见同样的动作落到博士论文、面包店的合同、共享网站上，因为真正的承诺是：为你创造的**一切**做版本控制；而智能体，终于让这件事对非程序员也成为现实。

读下去时，有三样东西会逐渐积累。第一，一套持续扩充的**你可以跟智能体说的白话**（“动手改之前，先做一份我能回来的快照”），一章章收成你能贴在桌上的一页词汇。第二，三个**起飞前检查问题**，会变成判断的长久习惯：**到底会改什么？我们回得去吗？这段历史已经被分享过了吗？** 第三，一座**勇气阶梯**：每一章卸下一桩具体恐惧，并命名你现在可以大胆去做的事，直到终章时，那些从未尝试的大胆版本之坟场空空如也。
