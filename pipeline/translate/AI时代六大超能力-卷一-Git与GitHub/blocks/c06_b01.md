上一章悄悄改变了一件巨大的事。一旦 Maya 明白，她可以回到指南的任何早期版本而不失去今天的工作，删掉一个段落就不再像一次小小的死亡。她开始更用力地修剪。文字变得更精瘦。她移除的任何东西都不是真的消失；它只是平静地待在她身后一步，等待着。

看看这种安全感对她的胆量做了什么。回去是免费的，出错就变得便宜；出错变得便宜，大胆的动作就不再吓人。正是在这个时刻，一整类实验变得可行：那种你已经在心里带了好几年，却一直没有尝试的实验，因为它可能会毁掉那个已经能用的东西。Theo 就有一个这样的想法。他从他们完成第一稿之前就一直带着它。

他觉得这本指南的组织方式错了。


### 5.1 Theo 一直不敢做的重组

他们的指南是按天气安排的。**如果下毛毛雨，就走这条路线；如果雨下得很大，就躲进这些博物馆；如果天放晴了，这里是河边路线。** 这是个好想法，是他们自己的想法，同时 Theo 也怀疑它是反过来的。一个站在 Alfama 的旅行者不会想“现在下着毛毛雨，我在哪一节”。他们会想“我在 Alfama，附近有什么”。他越来越确定，指南应该按街区组织，把天气建议折进每个街区里。

这不是一个小编辑。这是整本书的重组：每一节都要移动，每条步行路线都要重新分组，整个骨架都要重建。三周的工作，要重新搭结构。让他沉默了几个月的部分在这里：他并**不知道**这样会更好。它可能更好。也可能变得更糟，或者只是不同，而他会花一个周末拆掉一本已经能用的书，才知道结果。在旧的工作方式里，把这个提议说出口都显得不负责任。要尝试它，他要么必须编辑真正的指南，并冒着最后得到一个半迁移烂摊子、没有干净版本的风险；要么在自己的笔记本电脑上复制整个项目，如果实验成功，再想办法把他的副本和 Maya 期间做出的任何更改对齐。两条路都会通向两个坏掉的版本，没有一个完成品。

所以天气结构留了下来。不是因为有人决定它最好。只是因为改变它很吓人，而且没人有一种便宜的方式去犯错。

这就是本章要让它退役的恐惧。而让它退役的工具，第一次听起来像一个小把戏。
