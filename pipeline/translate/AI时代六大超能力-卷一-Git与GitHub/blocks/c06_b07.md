#### 深入思考

**Q1.（判断。）** 分支很便宜，这意味着你可以打开很多分支。这种自由有没有什么坏处？不是某一个分支本身会出什么问题，而是自由创建分支这个**习惯**可能出什么问题？这种危险会不会触及“分支很便宜”这个耐久的真理？

提示

把两件不同的事分开：**创建**一个分支的成本（几乎为零，始终如此），以及在脑子里**追踪**许多条平行工作线的成本（不是零）。哪一个才是本章平实而笃定的主张？

**讨论：** 那个耐久的主张保持不变：创建分支很便宜，句号，在任何规模的项目上都是如此。危险不在那里。危险在于同时拥有许多活跃实验时的**人类**成本。如果 Theo 打开了七个分支（街区重组、一种新的引言声音、一个博物馆章节、三个半成形的想法、一个他已经忘了目的的分支），工具会毫不费力地处理全部七个，但**他**现在必须记住每个分支是做什么的，哪些值得带回家，哪些已经死掉。平行宇宙可以免费创建，也可以免费放弃，但要把它们**理清楚**并不是免费的。解决办法不是少创建分支；而是有意图地创建分支（每个真正的想法一个分支，并诚实记录它的目的），并且在失败的分支上关上门，而不是让它们不断堆积。注意，这一点丝毫没有削弱核心真理。“分支很便宜”是关于工具的主张，而且无条件正确。“十个未完成的实验很难装在脑子里”是关于**你**的主张，也同样正确。把这两者分清，本身就是本书一直指向的那种判断力的一小次实践：工具的成本和你的成本记在不同账本上，把它们混在一起，人才会要么害怕分支（以为工具很昂贵），要么淹没在分支里（以为它们在所有意义上都是免费的）。它们对工具免费。它们仍然向你提出要求。

**Q2.（苏格拉底式种子。）** 分支让 Theo 可以免费犯错。更早之前，回到过去（Chapter 4）也让 Maya 可以免费犯错。这是同一种安全戴了两顶帽子，还是两种真正不同的自由？有了分支，你能做到哪些仅靠回到过去做不到的事？

提示

回到过去会让你沿着一条历史线移动——在同一份指南上向后或向前穿越时间。分支让两个版本在**同一时间**存在。想一想，如果只靠“回到过去”，Theo 能不能在 Maya 继续编辑 main 的同时完成他的周末实验。
