### 11.3 值得提出的那一个问题

Maya 阅读了差异，并且完全理解了它，但她仍然没有立刻批准。因为有一件小事让她放不下。

Núria 建议的新咖啡馆 Pastelaria do Rossio，如果 Maya 没记错地图，其实并不在 Alfama。它要走上足足十分钟，靠近另一个广场。而这份指南的整个承诺是，Alfama 部分里的每样东西都在**围着 Alfama 走一走**的距离内。所以 Maya 在提议里回了一行，让 Núria 能看到：

> 很喜欢这个，只想确认一点：do Rossio 够近，可以算作 Alfama 吗？还是我们应该把它放到下一节？想让每个街区步行路线都保持紧凑。不管怎样，谢谢你发现 Brilhante 关门了。

这就是全部技艺，而我想放慢一点，看清它多么小，也多么友善。

Maya 没有拒绝。她也没有默默接受一件自己半信半疑的东西。她在公开处提出了**一个清楚的问题**，并把它系在一个作者真的可以评估的理由上：“我们让每个街区步行路线保持紧凑。”她一开始就表达真诚的温暖，因为 Núria 确实帮了她们一个大忙，也应该感受到这一点。她还把决定留成协作式的：**不管怎样，谢谢你。**

这就是“把审阅当守门”和“把审阅当对话”之间的全部差别。守门人要么为了避免摩擦而挥手放行，要么用一句冷冰冰的“街区错了”把它打回去。Maya 做了第三件事，而这件事只有在提议是一场**对话**、而不是一份判决时才存在。她把自己的疑问浮现出来，给了作者解决疑问所需的信息，并信任作者能够作出好的决定。Núria 一小时内回复：**抓得好，严格说它是在 Graça，把它移到那里吧**，于是这个更改变得比她们任何一方一开始提出的都**更好**。这就是审阅按它应有的方式运转。不是是，不是否。是一个更好的更改，由两个人一起达成。

请注意，是什么让这个好问题成为可能：Maya 确实**阅读**了差异。如果她只是扫了一眼 Núria 的备注，就不可能针对街区边界提出一个聪明的问题。阅读让你获得提出有用意见的资格。于是我们来到本章必须点名的危险。
