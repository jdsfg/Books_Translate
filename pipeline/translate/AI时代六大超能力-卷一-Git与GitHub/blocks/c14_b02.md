### 13.2 带着智能体的陌生人

事情起于一封只有三句话的邮件。**很喜欢 Alfama 步行路线。你们为 Graça 观景点列出的电车是 12 路；实际上是 28 路。我已经修正并把修改发给你们了。**

Maya 和 Theo 都不认识发信人。另一个国家的一位读者在工作坊里找到了他们的指南，发现路线说明里的电车号码错了，并且做了一件几年前读者还做不到的事：他没有写信抱怨，没有发差评，而是**做出修正并把它提议送回**。他有一个智能体，和 Maya 与 Theo 使用的是同一种助手。他大致告诉它：“拿一份属于我的他们指南的副本，修正 Graça 章节里的电车号码，然后把这个修正作为一项提议修改送回去。”智能体完成了机械部分。提议以干净、可审阅的修改形式抵达：这里是确切的行，这里是原来写的内容，这里是它应该写成的内容，这里是原因。

这是一次真正的第一份贡献，值得停下来看看它有多小。他没有重写一章。他没有添加功能。他只是修正了一个错误的数字。而这恰恰就是入口。任何人对公地做出的最常见第一份贡献，既不是代码，也不是宏大的东西。它是一个错别字、一个坏链接、一个过时事实、说明里一句让人困惑的话。**文档修正是开源的正门。**它们受欢迎、风险低，正是带着智能体的初学者应该进入的地方，而且它们确实有价值：电车号码正确的指南，就是更好的指南。

注意这个陌生人需要什么，又不需要什么。他不需要获得**阅读**这本指南或为自己使用而**复制**它的许可，因为它在开放之中。他不需要认识 Maya 和 Theo。他需要自己的智能体完成复制和提议的机械动作，也需要这本指南确实接受外部提议。而 Maya 和 Theo 在能够安心地对陌生人这样做说“可以”之前，需要预先决定一件事：条款。这就是许可证。


### 13.3 公地的条款

Maya 读到陌生人的修正时，第一反应是感激，紧接着是一点小小的不安。**他复制了我们的书。这样可以吗？我们是在说任何人复制它都没关系吗？如果有人拿走整本书去卖怎么办？**

这些都是正确的问题，而公地有一种专门回答它们的工具：**许可证**。把一个项目放到开放之处，让人们可以阅读，并不会自动告诉任何人他们可以对它**做**什么。阅读不同于复用、复制、销售，或在它之上继续创作。许可证是附在项目上的简短法律文件，它写明条款：陌生人被允许和不被允许对你的作品做什么。

大多数开源项目会使用少数几种标准的、被充分理解的许可证之一，而不是自己写一份。你选择一种，把它放进项目，从那以后，每个走进来的人都能清楚看到条款。有一个很有名的网站，**choosealicense.com**，它的全部职责就是用朴素语言解释常见许可证，并帮助你选择；那是应该去的地方，而真正起支配作用的是实际的许可证文本。下面只是对两大宽泛形态的一张地图，只到要点层面，足以让你知道自己正在走进哪扇门。它不是法律建议，我也不会引用条款，因为发明或改写法律术语，正是人们把这件事弄错的方式。
