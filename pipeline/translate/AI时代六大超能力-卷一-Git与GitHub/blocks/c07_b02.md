#### 定义：合并

**合并就是把两个平行宇宙编织回一个。** 你有主线，也有从主线分出去的一个实验。合并会把实验上改变的一切带回主线，所以在合并之后，又会有一段单一的历史，同时承载两边的工作。

请保留“编织”的图像，而不是“叠放”的图像。你不是把一个版本放在另一个版本上面，然后让上面的那个获胜。你是在拿两块从同一匹布上裁下来的布料，把它们的线重新穿回一起，让图案连续起来。实验增加了新线的地方，新线会织进去。主线保留旧线不变的地方，旧线会留下来。结果是一块布，比任意一块都更宽，两边的图案都在里面。

当 Theo 要求他的智能体把他的重新排序编织回去时，他要的是这个。不是“用我的版本替换主指南”。不是“丢掉 Maya 的版本，改用我的版本”。他是在请求：**把我在这边做的重组拿过来，放进那边的主书里，让主书现在拥有它。** 一本书，包含他的工作。


#### 常见误解

关于合并，最常见的错误图像是这样的：**“合并意味着一个分支覆盖另一个分支。更大、更新、或修改更多的版本获胜，另一个版本被丢弃。”**

很容易看出人们为什么会相信这一点。保存文件就是这样工作的，而那是我们大多数人学过的唯一一种版本处理方式。在 Chapter 1，当你覆盖保存了 Maya 的草稿时，新文件完全替代了旧文件，旧文件就没了。所以我们会假设合并也是同一个动作，只是名字更高级：两个东西进去，赢家出来，输家被删除。

合并不是那样。合并会**组合**。逐行想一想“编织”在书里真正意味着什么：

* 如果某段文字在**两条线上都没有改变**（Maya 没碰、Theo 也没碰的引言），它就直接留下。没有什么需要决定。它之前是同一个东西，现在仍然是同一个东西。
* 如果实验**改变了主线没有动过的东西**（Theo 的街区顺序，而 Maya 没碰），实验里的版本会进来。他的工作抵达。
* 如果主线**改变了实验没有动过的东西**（Theo 离开去重组时，Maya 在引言里修了一个错字），主线的版本会留下并被保留。她的工作也不会被丢掉。

注意发生了什么：两个人的工作都活了下来。Theo 的重组进来了，**而且** Maya 的错字修正也留下了。这正是“一个覆盖另一个”的反面。合并在好的意义上很贪心：它想保留任何人做过的一切，而且只有在人类明确告诉它时，才会丢弃某个改动。没有人的一个下午会被吃掉。这就是工具的全部意义，也正是“覆盖”图像完全想反的地方。

你可能正在等那个坑。要是 Theo 改了引言，**同时** Maya 也在分开期间改了同一段引言怎么办？那两条线就真的在某个具体位置上有分歧，再聪明的编织也无法猜出该保留谁的措辞。这种情况是真实的，也是 Chapter 7 的全部主题。现在先坐在普通情况里，因为普通情况是压倒性常见的情况：两个人，或者一个人和过去的自己，在同一个项目的**不同部分**工作。当编辑没有重叠时，编织会自动完成。
