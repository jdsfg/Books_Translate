### 14.4 一个个人网站

最后一个是单人项目，也闭合了一个环。

你决定做一个个人网站：几页关于你的工作、一些写作、一个让别人找到你的方式。你不是 Web 开发者。你有一个能搭建这些页面的智能体，也有这本书；这意味着你知道一件大多数第一次做网站的人不知道的事：你知道怎样在它成长时安全地**保存**它。

网站上的每一次有意义的更改都是一个带说明的**快照**：“added the writing page,” “changed the homepage photo,” “rewrote the about section, shorter.” 当你尝试一个大胆的重新设计时，你在一个**分支**上做，所以任何人都可以访问的线上版本会完全保持原样，直到重新设计真正完成，而且你已经看过它的整体。如果你在实验时弄坏了布局，你可以**回去**，而不会丢掉你喜欢的文案。这个网站活在**不止一个地方**，所以它是安全的。这里还有一个专门为网站保留的小魔法：因为这个相册住在世界的工作坊里，工作坊本身可以**把网站提供给访客**，所以一个给世界看的页面，住在同一个你可以沿着历史行走的相册里。你会在后面的卷里见到具体做法；现在只要注意这一点：一个非程序员，带着智能体和这张地图，就能在真实的互联网上搭建并安全演进一个真实的东西，而且不会在这个过程中丢失任何版本。

四个项目。一位历史学家、两个面包师、一对夫妻、一个有网站的人。它们中没有一行代码，而这张地图没有增加任何一个新想法，就适配了每一个。

### 14.5 两片沼泽：这个工具在什么时候是错误的工具

现在到了诚实的部分，而且它不是可选项。一张只给你标出干地、却隐藏沼泽的地图，会让人在它藏起来的沼泽里迷路。这个工具非常擅长一项特定工作，也有两项工作是它**不擅长**的。知道它们，是了解这个工具的一部分。如果某一章曾经把这个工具卖给你，说它什么都擅长，那一章就是对你撒了谎；你应该少信它，而不是多信它。
