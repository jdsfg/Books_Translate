### 4.5 诚实的边界

有一小类情况，回到过去并不是免费的：某种特别激进的改写确实可能丢失历史。诚实要求我把它指出来，尽管我们现在还远没有准备好深入其中。

我告诉你的关于“只追加”的一切，描述的是一个项目的**正常**生活：创建快照、恢复旧材料、通过添加新快照来撤销更改。在这种正常生活里，过去会被保留下来。但这个工具也有少数强大的操作，它们的全部目的就是**改写**历史，重塑链条本身，在别人看到之前把它整理或重新排列。这些操作真的可能丢弃旧链接。它们是唯一一个“撤销不会抹掉过去”不再成立的地方。

现在，记住三件事就够了：

  1. 这些改写历史的动作，**不是**你访问过去、恢复一段文字或撤销一个更改时发生的事。你日常的回到过去是安全的。
  2. 它们只会在一种特定情况下变得真正危险：历史已经被**分享**给其他人。这就是第三个起飞前问题，也是整整一章都值得谨慎对待的内容，我们现在还不打开它。
  3. 这正是你的判断力，而不是你的智能体的流畅能力，保护你的时刻。智能体知道**怎样**改写历史。只有你知道历史**是否应该**被改写。这个差距就是第 15 章要讲的。

我现在只是提前指路，而不是解释，因为现在解释会让你害怕一件你还不该害怕的事。你在本章学到的日常回到过去是安全的，就这么简单。那个少见的锋利边缘有它自己的章节，有它自己谨慎的演练，放在本书接近结尾的地方。当你走到那里时，你会拥有足够的概念，可以平静地处理它。今天，记住这个真实而有用的总结：**我们能回去吗？几乎总是可以，而那个“几乎”住在一个很小、有名字、稍后才会出现的地方，并不会潜伏在你的普通工作里。**


### 4.6 练习

这些不是训练题。它们要求你预测工具会做什么，区分两件相似的事，并练习把一个愿望改写成普通语言的请求。先认真想一想每个问题，再读讨论。

#### 概念检查

**Q1.** 一个朋友说：“我终于把论文放进这种快照系统了，但我害怕去看上个月的草稿，因为我会失去那之后写的所有东西。”旧恐惧到底是从哪里钻回来的？你会怎么告诉他们？

提示

把 4.1 里的两个愿望分开。“看上个月的草稿”到底需要哪一个？

**答案：** 这位朋友悄悄把**访问**和**还原**混在了一起。看上个月的草稿是一种访问：它读取一张旧照片，并让今天的工作完全不受影响。那之后的任何内容都没有风险，因为在相册里，一张照片不会因为被看了一眼就被消耗掉。这个恐惧是从文件夹副本的世界原封不动搬来的，在那里，“看旧版本”意味着“打开旧文件”，而这确实会把当前文件置于危险之中。告诉他们：你可以读上个月的草稿一个小时，今天的版本仍然待在你离开的地方。即使你之后决定想把上个月的一些材料拿回来，恢复它也会在最前面**添加**一个新快照，而不是抹掉中间这些星期。这里没有任何动作需要花掉现在，才能看见过去。
