### 2.3 用快照来思考

所以这里有一个小小的心智转变要发生，而它其实就是本章的整个课程。你正在学习用快照来思考。

一个好的快照有三个品质，而且没有一个是技术性的。

它是**小的。**你是在完成一块连贯的工作时拍下它，而不是在一场马拉松之后才拍，那时你已经改了四十件互不相关的事。一个写着“完成了引言的新语气”的快照，是一个好快照。一个写着“做了一堆东西”的快照，是一张模糊影子的照片。小快照的纪律，就是在开始下一个想法之前先完成一个想法的纪律；即使撇开工具不谈，它也会让你成为一个更整洁的工作者。

它是**有目的的。**你在某个有意义的时刻拍下它：一件事完成了，或者你正要尝试某个有风险的改变，想要一个干净的地方可以回去。Maya 会发现，她最有价值的快照，是那些她在大胆改变**之前**拍下的快照，正因为这样，她才有一个标记清楚的门口可以回去。

它也是**描述清楚的。**那条说明是写给一个陌生人的，而那个陌生人就是六个月后的你，什么都不会记得。“修好了”是一条帮不了任何人的说明。“更正了 Belém 步行路线里的电车编号；是 15，不是 25”是一条能省下一个下午的说明。最好的测试是：如果有人只读你的说明，从不看作品本身，还能理解你建造了什么、为什么建造吗？如果可以，你就把快照拍好了。

同样的纪律可以用在任何东西上，不只是一本文字指南。想象一位研究生 Dr. Okonkwo 正在写论文：她不用 `thesis_ch3_v4_advisor_edits_FINAL.docx`，而是拥有一串干净的快照，每个都配着说明：“重写了方法论论证”“加入了 Prof. Adeyemi 提出的反对意见”“删掉了那段很长的离题内容，先保存起来以防万一”。再想象一家两人经营的面包店 Rosa's，保管一份价目表和一摞供应商合同：每次价格变化都拍一个快照，说明里写上日期和原因，这样当顾客对某笔收费提出异议时，那个价格的完整历史就在眼前，日期诚实清楚，不再是谁的话对谁的话。这些人都不写代码。他们却都得到同一份礼物：一段带标签、可以走进去的自己工作的历史，以及那个装满紧张副本的文件夹的终结。
