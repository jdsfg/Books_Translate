### 15.2 草稿里的地址

第 2 个危险更安静，而且正好抓住了 Maya。

在指南的某个工作草稿深处，在给自己的 1 条备注里，她写下了他们的家庭住址。Theo 的母亲要来拜访，Maya 把到达安排直接记进了手稿，打算稍后删除。她忘了。智能体按要求给整个项目做了快照，地址和其他内容一样被照了进去。那个快照去了 GitHub。指南是私有的，所以没有陌生人看见。但地址现在已经**在历史里**了。

1 周后，Maya 注意到这件事，把地址从草稿中删掉。她以为问题解决了。她给干净版本做了一个新快照，而当前草稿里再也看不到那个地址。

这正是工具会让人意外的地方，所以我要尽可能直白地说，因为这是本章最重要的句子：**从今天的版本里删除地址，并不会把它从历史里移除。历史会记得。**

回想一下快照是什么：在某一刻给整个项目拍下的一张照片。上周那张照片拍到了地址。今天删除地址，会拍下一张**新的**、不含地址的照片，但它不会伸进旧照片里把地址刮掉。旧快照仍然保存着它，安静地坐在相册里，任何回到历史中查看的人都能看见。正是让这个工具值得信任的那个属性——过去被保存，你总能回去——也保存了你的错误。

这不是缺陷。它和让 Maya 在 3 周后找回被删段落的追加式历史是同一个东西。你不可能拥有一种能保护你优秀工作的记忆，同时又要求它按需忘记你的事故。它会保留一切。
