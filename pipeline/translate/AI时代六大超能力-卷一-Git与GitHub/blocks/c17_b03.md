### 16.2 一页账本

这里是完整词汇，放在同一个地方。这就是交付物，也是本书存在的理由。每一行都是一个白话愿望，按用途分组。注意这里没有任何命令语法。你不是在学习操作工具。你是在学习该**请求什么**，而这才是持久的东西；智能体知道咒语，而咒语会随着年月变化，这些愿望不会。

**制作快照**

* “在你改变任何东西之前，做一个我能回来的快照，并说明它的用途。”
* “把这个项目的历史按列表显示给我，最新的在前，用白话说明。”

**回到过去**

* “带我回到上周二 intro 的样子——但不要丢掉今天的工作。”

**分支与合并**

* “开一个单独的分支，让我尝试一次有风险的重组，而不碰那个能运转的版本。”
* “重排成功了——把它合并回主版本，并告诉我有没有东西相撞。”
* “我们都编辑了同一行；把两个版本并排给我看，让我选择。”

**在不止一个地方工作**

* “把今天的快照发布到我们的共享副本——但先不要公开。”
* “把这个项目放进工作坊，设为私有，并为那家已经关门的咖啡馆开一个 issue。”

**与他人协作**

* “把我的修复变成一项拟议改动，让我们的朋友在它进入之前可以审阅。”
* “在我批准之前，用白话带我看清这项拟议改动实际改变了什么。”
* “拿一份他们项目的我自己的副本，这样我可以添加一节，而不打扰他们的版本。”
* “把我的修正提回原项目，并先给我看它的许可证。”

**保持安全**

* “在你改写任何共享历史或覆盖发布别人的工作之前，停下来问我。”
* “永远不要拍下这个文件；它有私人信息，不能进入历史。”

这就是地图。14 句话，以及它们背后的概念，还有一对伴侣在厨房里 1 年无惧工作的方式。再读一遍这份清单，留意其中有多少在一开始会让你觉得不可想象：把陌生人的修正提回给他们，和伴侣编辑同一个文档而不发生碰撞，免费尝试一次价值 3 周工作的重构。现在这些都不再稀奇。它只是星期二。
