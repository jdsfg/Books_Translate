上一章里，Maya 学到相册里保存着一切。她和 Theo 为那份指南保存过的每一个快照都还在那里，按顺序排列，从最新到最旧，每一个都带着一小段说明，记录为什么保存。她可以站在相册门口，看完整整一排照片，一直看到第一张。阅读让人安心。但阅读和伸手取回并不是一回事。

站在门口时，她发现自己有一个真实而迫切的愿望。上周二，她一时想把文字整理得更干净，就从引言里删掉了一段话：那是一小段旁白，写的是里斯本的光线在下雨前怎样变成银色。这不是上一章里那个周日版本，而是更早一点的东西，是她自己做的一次小小删减。Theo 觉得那段太多了。她当时也同意，于是删掉，继续往前。现在，一周过去，又保存了好几个快照之后，她想念那段话。她想把它拿回来。她也害怕，因为把它拿回来似乎意味着要回到**过去**，而回到过去正是烧伤过我们每个人的事。

### 4.1 两个听起来一样、其实不同的愿望

当你说“我想回到过去”时，你几乎总是在表达两个非常不同的愿望之一；而本章的全部安稳，都取决于能不能把它们分清。

第一个愿望是：**我想看看它以前是什么样子。** 你并不是不满意今天的工作。你只是想看一眼上周的版本，再读读那段被删掉的文字，准确记起它原来怎么写。你想要**探访**。

第二个愿望是：**我想让今天的作品重新变成上周的版本。** 自从周二之后出了问题，你想抹掉中间那些变化，再次站到当时的位置。你想要**还原**。

我们之所以把这两件事混在一起，然后又同时害怕它们，是因为第 1 章里的那个文件夹。在 `FINAL_v2_REALLY_final` 文件夹的世界里，没有办法单纯地**探访**过去。你若想看旧版本，就必须**打开**旧文件；而你一开始碰它，就离一次粗心保存把它变成唯一版本只差一步。探访和还原纠缠在一起，因为查看和破坏用的是同一套笨拙动作。所以我们学会了把每一次进入过去都当成危险，结果多数时候干脆不去。

相册把它们解开了。在相册里，你可以抽出一张旧照片看上一个小时，而那张照片不会因为被看过就被消耗掉。探访过去并不会花掉过去。这个简单事实，就是本章要给你的大部分东西。
