在上一章，Maya 坐下来面对一位朋友提出的变更，用白话读它，问了一个小问题，然后批准了它。两个人，一份指南，一个谨慎的点头。这是一种一起工作的形态，而且在本书的大部分篇幅里，这也是你唯一需要的形态。

现在我们把画面拉宽。因为这份指南正在悄悄变得有名。有人在一个 Lisbon 外籍居民群里贴了它的链接；一个旅行博客提到了它。然后在某个星期二，一条来自 Maya 和 Theo 都不认识的名字的消息到了。

**“我很喜欢你们的指南。我是两个孩子的家长，一直希望里面能有一节讲雨天真正适合小孩子的博物馆。我已经起草了一节。我可以加进去吗？”**

这是一个陌生人。不是住在街角的朋友。这个人发现了这份作品，关心它，想让它变得更好；但他们的笔记本电脑不在 Maya 和 Theo 的公寓里，没有访问他们文件的权限，和他们之间除了这份指南本身以外没有任何关系。一个月前，这条消息会开启一场尴尬的邮件文档和复制粘贴之舞。相反，一件更干净的事情即将发生，而且它有一个你大概听过别人当作骂人话来用的名字。到本章结束时，你会把它听成整套工具箱里最友善的词。

### 12.1 三种形态，一套工具

本书里的每一个概念都是为一起工作的人设计的，但“一起”并不是同一种东西。它有不同形态，把它们摊开来看会有帮助，因为你已经在不知不觉中学会了这 3 种形态所需的工具。

**单人形态。** 你、你的智能体，以及未来的你。这是你开始的地方，而且它永远不会消失。哪怕独自一人，你也在和 6 个月后的自己协作；那个人会打开这个项目，却已经忘了你为什么那样做。带着诚实说明的快照，就是写给那个人的消息。当 Maya 浏览去年春天的引言版本时，她正在接收一份来自过去协作者的礼物，而那个协作者恰好是她自己。单人形态并不是低一等的形态。它是基础，而且本书的大部分价值，对那些完全独自工作、从不分享任何东西的人同样可用。

**小团队形态。** 少数彼此信任的人，在一个大家都能触碰的项目上工作。Maya 和 Theo 是最小可能的团队；Rosa 的面包店也是另一个例子，Rosa 和她的伴侣 Ana 一起编辑价格表。在这里，你在分支章节里学到的工具会安静地发挥作用。每个人为自己的实验拿一条自己的分支，等准备好了再合并回来；当两个人编辑同一行时，工具会停下来问人，而不是自己猜。小团队共享一个工作的家，而且每个人都有钥匙。

**开放形态。** 陌生人公开地改进彼此的作品，彼此甚至从未见过面。这就是那位家长的消息刚刚打开的形态，也是本章要讲的形态。在这里，没有人发钥匙。陌生人不会得到 Maya 和 Theo 那份指南之家的访问权限。相反，他们会得到一种更好的东西：它让每个人都安全，并让贡献成为自然、低摩擦的事情。他们拿走自己的一份完整副本。

那份副本有一个名字。
