#### 深入思考

**Q1.** 这里有一个判断场景。一个你非常信任的队友——聪明、谨慎、以前从没出过错——在星期五很晚的时候给你发来一个很大的拟议变更，并附上一条温暖的说明：**“不用细看，都是很直接的内容，方便时直接批准就行。”** 你很累。不读就批准只需要 1 秒，而且显然会让对方高兴。读完整个 diff 要花 20 分钟，而你更想把这 20 分钟用在别的地方。你会怎么做？这个选择真正押上的是什么？

**讨论：** 你读它。不是因为你不信任这个队友——你完全有理由信任对方——而是因为你被要求批准的是**变更**，不是**人**；而你的批准会把你的理解带入项目历史，不管你实际上是否理解了任何东西。让“跳过阅读”看起来安全的那份信任，正是陷阱所在：你越信任来源，就越容易把变更挥手放行，而这种诱惑和**这个具体**变更是否没问题毫无关系。这里同时押上了两件事。小的赌注是这次变更：再谨慎的人也会犯错，而“都很直接”恰恰常常出现在那一行其实并不直接的内容之前。大的赌注是习惯。第一次不读就批准时，你并不是认可了一个变更——你是在悄悄辞去“做决定的人”这个角色，把它交给任何给你发提案的人。本书的每一章都建立在相反的前提上：你才是判断，智能体只是双手。一个你没有读过的批准，就是一个你没有做出的判断。善意而诚实的做法，也是那个要花 20 分钟的做法：读它；如果它真的都很直接，你的 同意 现在才有意义。如果不是，你刚刚救了你们两个人。只要接触到“你的批准到底是什么”这个事实，就不存在任何站得住脚的“不用细看”。第 15 章会展示这个习惯能防止哪些具体灾难；现在，只要知道阅读**就是** 审阅，而跳过阅读就是跳过这份工作，就够了。
