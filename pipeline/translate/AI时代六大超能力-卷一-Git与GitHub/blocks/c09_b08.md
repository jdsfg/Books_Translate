### 本章小结

工作不再只住在一个地方，两个旧恐惧也同时退场了。

**远程** 是你的项目相册保存在自己机器之外的地方：另一台笔记本电脑，或互联网上的共享工作坊。你通过两个镜像动作连接它：把你的新快照**发布**到那里，并把它的新快照**获取**下来。两者都不会覆盖；发布会把你的快照添加到共享相册，获取会把它的快照添加到你的相册。**克隆** 是每个地方所保存的东西：不是当前文件，而是**整本相册**（每一个快照、每一个分支、每一条说明）。这就是为什么一台笔记本电脑丢了也不会丢东西。当每一份副本都是完整的，任何单一副本的死亡都无法带走历史。

由此得到本章直白而诚实的边界：**仓库只有住在第二个地方时，才是备份。** 一台机器上的历史很珍贵，但离遗忘只差一杯泼洒的咖啡。安全从来不只在版本控制本身里；安全在于**第二个家**。一本完整相册不是备份。两本，放在彼此独立的地方，才是备份的开始。而那个第二个家可以是**私有**的：截至 2026 年，主要工作坊都在免费层级提供私有仓库，不过当前条款属于它们自己的文档，不属于这本书；因此你可以获得“笔记本电脑坏了也能活下来”的平静，而不必把一个半成品展示给全世界。请求里的安全半句很重要：发布到共享副本，**并且暂时不要公开它**。什么时候让世界观看，是另一个独立、审慎的决定，而且决定权仍然属于你。

本章里有两个恐惧离开了房间。“我可能因为一台笔记本电脑坏掉而失去一切”已经退场：相册存在于不止一个地方时，坏掉的笔记本电脑只是耸耸肩，然后做一次新的克隆。那个让你紧张地把整个项目囤成一堆云端文件夹副本的恐惧也退场了，因为真正的第二个家承载的不是被压平成今天样子的快照，而是你的完整历史，安全地保存着。你现在可以勇敢做的事是：相信你的作品会活过承载它的机器，并在你准备好展示给任何人之前很久，就把它安全地放在第二个地方。

接下来，在第 9 章，那个第二个地方不再只是一个安全副本，而会变成更有趣的东西：世界的工作坊。在那里，一个项目有了公开面孔；在那里，一个发现某家咖啡馆已经关门的朋友，可以用一种有结构的方式告诉你；在那里，彼此改进作品的整套社会机制开始运转。
