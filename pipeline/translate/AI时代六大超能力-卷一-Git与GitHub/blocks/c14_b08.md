### 本章总结

那个修正电车号码的陌生人，做的正是整个开源世界以数亿人的规模所做的事：在开放处找到别人的作品，改进一个小而真实的东西，然后把它提议回去。那个世界是一个**公地**，是一池共享项目；照看它的人越多，它越富足。而它给你的第一份礼物，早在你贡献任何东西之前就已经到来：当你被卡住时，修正往往已经被某个陌生人找到并留在开放处，而你的智能体可以去读它。

公地靠规则运转，而不是靠没有规则运转。**许可证**设定陌生人可以怎样使用你的作品的条款，而两个要点级别的形状覆盖了大多数情况：**宽松型（类似 MIT）**，意思是几乎可以做任何事，但要保留声明；以及**相同方式共享型（类似 GPL）**，意思是改进也要保持开放。这些是要点，不是法律建议；真正的文本才作数，而 choosealicense.com 是你阅读它的地方。要避开的陷阱是相信**公开可读**就意味着**可以自由做任何事**。不是这样；没有许可证的项目是受限制的情况，不是自由的情况。在依赖或贡献任何项目之前，你要阅读它的**生命体征**：星标显示人群大小，未关闭议题显示有没有人回答，最后提交日期显示脉搏。它们合在一起回答那个唯一重要的问题：它还活着吗？而你自己的第一次贡献可以很小。向一个仍然活着的项目提出文档修正，是体面的正门，也是几乎所有人的起点。

接下来，在 第 14 章，我们兑现这本书从第一页起一直许下的承诺。这十三章里的一切，从快照和分支，到合并和公地，从来都并不真正关乎代码。它是你所创造的一切的版本控制：论文、价格表、食谱集、小说。那个从未见过终端的写作者，就要给她的书创建分支了。
