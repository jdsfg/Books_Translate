#### 概念检查

**Q1.** 用你自己的话说，什么是 diff？为什么阅读 diff 比阅读一句像“对第 3 章做了一些小修正”这样的更改描述更诚实？

提示

想一想含糊的摘要可以藏住什么，以及 diff 不能藏住什么。

**答案：** diff 就是**用普通话说明改了什么**：它精确说明项目现在的样子，和如果这个更改进入之后项目会变成的样子，两者之间的区别；它只展示删除了什么、添加了什么，以及在哪里。它比描述更诚实，因为描述是作者写出的摘要，而摘要可能含糊、不完整，或者无意中误导人：“对第 3 章做了一些小修正”可能藏着一段被删除的文字，或者一个被重写的开头。diff 不是对更改的摘要；它**就是**更改本身，被摊开供人阅读。它不能漏掉任何东西，因为漏掉东西就会让它变成另一个 diff。正因为如此，规则才是“阅读 diff”，而不是“阅读描述”：你批准的是你能看见的东西，不是别人告诉你的东西。
