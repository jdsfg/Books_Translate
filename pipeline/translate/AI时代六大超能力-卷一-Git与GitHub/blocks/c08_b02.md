#### 定义：合并冲突

**合并冲突**指的是，两条工作线各自以**不同**方式改变了项目中的**同一**部分，而负责把它们编织到一起的工具无法判断哪一个改动应该胜出。它不会猜测（也不会冒着悄悄丢掉某个人工作的风险），而是正好在那个位置停下来，向你展示两个版本，并等待一个人（或一个由人批准的智能体）来选择。

请慢慢读这个定义，因为里面每个词都有工作要做。**同一部分**：冲突只发生在两个编辑重叠的地方；其他所有地方都会自动编织在一起，就像第 6 章里一直发生的那样。**无法判断哪一个应该胜出**：工具对你的书没有意见，而且它知道这一点。**不会猜测**：这是核心。**向你展示两个版本**：没有东西被隐藏，没有东西丢失。**由人选择**：因为这个选择是一种判断，而判断属于你。

冲突不是工具没有完成它的工作。冲突是工具正在为你做它能做的最有价值的一件事：拒绝做一个它没有资格做的决定，并且拒绝一边假装已经做了决定，一边丢掉你的工作。
