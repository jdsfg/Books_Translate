#### 应用题

**Q1.** 取 §11.1 中评审人 3 的敌意意见（_“不清楚为什么本文没有围绕 [X] 这个更重要的问题来框定。”_），起草一段认真回应它但不让步于框架改变的回复。使用 §11.6 中的逐条意见模板。

提示

§11.3 中针对评审人 3、意见 5 的例子展示了一种做法。试着用不同的确认措辞或不同的面向未来的姿态写出你自己的版本。

**答案：** 成功的回复会（a）用斜体引用该意见，（b）以一个确认短语开头，该短语不让步于框架批评，但显示评审人的建议已经被考虑，（c）解释为什么没有采纳建议的重新框定（方法不同、范围不同），（d）展示参与（增加了一个段落；承认所引用的文献；加入未来研究说明），并（e）以和解性语言结尾。示例结构：_“我们感谢评审人 3 的建议。修订期间，我们认真考虑了 [X] 框架。我们的分析贡献是 [原始框架]，它与 [X] 框架在 [具体方面] 上不同。[X] 框架需要 [不同的方法/范围]。我们通过增加一个段落（§Y，第 Z 页）来回应评审人的建议，该段落承认 [X] 是未来工作的一个富有成效的方向，并引用了评审人提出的 [X] 文献。尽管我们保留了原始框架，但希望这一处理仍是回应充分的。”_

**Q2.** 取一份你收到过的同行评审（或者，如果没有，就取一篇论文上的教师评分意见），并识别 3 条实质性意见。针对每一条，使用 §11.6 中的逐条意见模板起草回复。提交这些意见、回复，以及一段 200 字的反思，说明最困难的部分是什么。（与第 11 章审校提示的联系：这是同一个练习的扩展应用。）

**答案：** _答案会有所不同。_ 成功的回复会（a）准确引用每条意见，（b）写出确认、参与、行动和引用俱全的回复；（c）始终保持专业语气；（d）把对修改内容的描述校准到实际完成的修改。最有用的反思往往会指出，回复所需时间比预期更长——看似简单的结构（确认/修改/引用）要执行好需要真正细致的处理。
