#### 应用题

**问题 1。** 从你自己的一篇论文中取出方法部分。找出 3 个具体的_说明不足_的决定——也就是合格读者无法仅凭正文复制该选择的地方。对每一个决定，写出能够明确说明它的补充句子。

提示

常见的说明不足包括：软件版本、随机种子、调查题目的精确措辞、纳入/排除标准、统计模型的精确设定、访谈方案的精确内容。

**答案：** _答案会有所不同。_ 成功作答会（1）准确找出 3 处说明不足，并（2）用符合惯例的正文提供缺失细节。在我阅读研究生方法部分的经验中，最常见的说明不足包括：随机种子（完全省略）；软件版本（例如，只说“使用 R”而不说明版本）；统计模型细节（例如，没有说明随机效应结构）；纳入/排除标准（抽象陈述而未操作化）。（与本章启发式原则的联系：拿不准时，就纳入细节。）

**样例作答（一个以米拉草稿为模型的假设案例）：** _3 个说明不足的决定：（1）“访谈被转录并进行主题编码”——编码方案未说明。替换为：“访谈被逐字转录，并在 NVivo 14 中采用归纳式主题路径编码，该路径受布劳恩和克拉克（2006）启发；代码本在前 6 次访谈中形成，并应用于其余 18 次访谈，其中 20% 的双重编码子集用于评估编码者间信度（κ = 0.78）。”（2）“预算数据从市政网站收集”——时间范围和可比性调整未说明。替换为：“年度运营预算和资本预算数字从各市政府公布的 2018–2023 财政年度预算文件中收集；数字使用国际货币基金组织购买力平价汇率转换为 2023 年美元，并按照附录 A 所述方式根据跨国会计差异进行调整。”（3）“案例因多样性而被选择”——选择标准未说明。替换为：“案例使用目的性最大差异设计选取，覆盖 3 个维度：区域背景（东南亚、拉丁美洲、北非）、财政体制（集中式与分权式市政财政）以及适应历史（早期采用者与近期采用者），依据阿莱加特（2013）的分类法。”_

**问题 2。** 阅读你所在领域中 2 篇论文的方法部分——1 篇定量，1 篇定性（如果你的领域在方法论上较为统一，也可以选择 2 篇同类论文）。对每篇论文，列出部分结构（小标题或隐性小节）。这些结构有什么共同点，又在哪里不同？写 200–300 词。

**答案：** _答案会有所不同。_ 一个典型的成功回答会指出，定量方法部分通常围绕_样本 / 材料 / 程序 / 分析_聚集，而定性方法部分包括_场景 / 参与者选择 / 数据收集 / 编码 / 反身性_。两类方法通常都从研究对象开始，转向如何研究，最后说明如何分析——但每一步的操作化都具有领域特定性。这个练习说明，方法结构由惯例驱动，而不是自然形成；你顺手采用的结构部分继承自传统。
