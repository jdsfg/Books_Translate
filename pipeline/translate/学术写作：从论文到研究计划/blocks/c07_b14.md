#### 应用题

**Q1.** 取米拉在 §7.1 中讨论开头的初稿（三句式过度主张）。改写每一句，使主张与证据（3 个案例研究）相校准。使用 §7.4 中的模糊限制词汇矩阵。

提示

对每一句都问：证据支持矩阵中的哪一行？然后使用该行中的动词和短语来改写。

**答案：** 一个成功的改写可以是： _“我们的发现表明，财政限制塑造了中型沿海城市的气候适应。在我们的 3 个案例中，适应由一种排序逻辑所结构化，在这种逻辑中，短期、可见的干预似乎挤出了更长期限的投资。这些发现提出了关于面向特大城市的国际资助项目与中型城市需求之间契合度的问题，尽管本分析不能直接评估资助政策。”_ 变化： _证明_ → _表明_ ； _确凿显示_ → _似乎_ ，并配合范围短语 _在我们的 3 个案例中_ ； _具有深远含义、必须转向_ → _提出问题_ ，并加入明确限制范围的从句。

**Q2.** 取你自己一篇论文中的讨论部分。应用模糊限制矩阵审校：给每一个主张动词画线，将每个动词映射到矩阵的一行，并找出 3 处动词比证据所能支持的强度高出一行的地方。改写这 3 处。提交原文、改写文本和一段 100 词反思。

**答案：** _答案会有所不同。_ 成功的作答会 (a) 准确识别 3 个过度主张的动词，(b) 产出改写，把语言换成更相称的表述，(c) 反思这一变化。最有用的反思常常会指出，这些改写以一种看似悖论的方式 _强化_ 了讨论——经过校准的主张比过度主张更可信，也对未来读者和引用者更有用（Latour 在 §7.8 中的观点）。

**样例作答（来自米拉较早讨论草稿中的 3 个过度主张动词及其改写）：** _(1) 原文：“我们的发现证明，财政限制决定适应选择。”诊断：“证明”声称了一项经验研究无法提供的确定性；“决定”暗示单一原因的充分性，而 3 个案例无法确立这一点。改写：“我们的发现表明，财政限制通过一种排序逻辑塑造适应选择，其影响幅度因案例而异。”(2) 原文：“这些结果确凿地确立了以特大城市为重点的项目在中型语境中会失败。”诊断：“确凿地确立”是过度主张；“失败”是二元判断，而证据支持的是更有梯度的主张。改写：“这些结果表明，以特大城市为重点的项目难以转移到中型语境，尽管这一发现的边界条件仍有待进一步研究。”(3) 原文：“国际资助机构必须将资源转向中型城市。”诊断：“必须”承载着本分析无法支撑的政策权威；从发现跳到政策指令的过程没有模糊限制。改写：“我们的发现提出了关于面向特大城市的资助与中型城市需求之间契合度的问题——这些问题是本分析无法解决但能够富有成效地提出的。”反思：这些改写并没有变弱。原文（“证明……决定……必须”）会被带着怀疑来引用；改写会被引用为谨慎的研究。讨论的权威来自校准，而不是来自自信。_
