# 风格简报 · 社科系列（soc_imagination / soc_inequality / soc_everyday / behavioral_econ / decision_making / psych_social）

> 覆盖：社会学的想象力 / 不平等的形状 / 自我的呈现 / 理性之外：行为经济学 / 明智决策：不确定世界中的理性思考 / 社会心理学。社科+行为科学，**质量 bar = 准确 + 通顺，并保住论证推进的语气与思辨纹理**（非纯技术，含观点推演）。

## 1. 系列定位
社会学 / 行为经济学 / 决策科学 / 社会心理学。既有经验数据，又有理论推演与价值判断。语言偏论述性。

## 2. 质量 bar（核心）
- **保住论证推进的语气**：论点—论据—推论的链条语气保留，不压平成事实罗列。
- **保住思辨纹理**：作者对社会机制的解读口吻还原。
- **数据准确**：统计、百分比、调查结果零容错。

## 3. 人称 / 语气
- 保留作者论述式"我们/你"引导（如有）。
- 不替作者下原书没有的价值判断。

## 4. 术语处理
- 首现加注原文：utility（效用）、incentive（激励）、heuristic（启发式）、bias（偏差）、inequality（不平等）、capital（资本）、norm（规范）、institution（制度）、social fact（社会事实）、confirmation bias（确认偏差）、opportunity cost（机会成本）。
- 学者名、理论名保留通用中译（马克思、韦伯、戈夫曼等）。

## 5. 禁忌译法
- bias = 偏差/偏见（按语境），非"偏见"一刀切。
- capital = 资本（社科语境），非"首都"。
- utility = 效用（经济语境），非"实用"。

## 6. 结构保全
- 数据表、引文、脚注、案例框、标题层级原样。
- 调查/实验编号保留。

## 7. 数字规则
- **统计 / 百分比 / 样本量 / 年份 / 金额**强制阿拉伯数字 + 原单位（"63%"、"n=2,400"、"2021"）。
- 约数可用中文（"数十个国家"），但具体数据保留阿拉伯。

## 8. 示例
- 源：`Confirmation bias leads us to ignore disconfirming evidence.`
- 译：`确认偏差（confirmation bias）会让我们忽略证伪性证据。`
- 源：`63% of respondents reported low social trust.`
- 译：`63% 的受访者表示社会信任度低。`
