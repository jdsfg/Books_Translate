在后催眠雨伞的例子中，被试行为的实际原因是先前催眠暗示——当他听到“红色”一词，他被指示站起来、走到角落、打开伞。他没有对此暗示的有意识记忆。当被问到为什么这么做时，诚实的报告应该是：“我没有意识上的理由；某种力量驱使了我。”

相反他说：“我感觉空气变重了。我觉得可能要下雨。我想在需要之前确认伞能用。” 这个解释是 _连贯_ 的。它把伞（行为）与合理的动机（准备防雨）通过合理的知觉（感知气压变化）联系起来。每一步都讲得通。没有明显裂缝。

它也是 _虚假_ 的。实际原因是后催眠暗示。“感觉空气变重”并不是作为具有解释力的知觉事件发生；它由 Interpreter 组装，以弥合 _我刚打开了一把伞_ 与 _我需要有一个理由_ 之间的鸿沟。连贯的故事占据了真实故事的位置，而从内部看，两者感觉完全相同。

这就是本章核心令人不安的事实：连贯与真实是不同属性，而 Interpreter 可靠地产出前者，而非后者。从内部看，你没有可靠方法区分你脑中哪些理由是既连贯又真实，哪些只是连贯。

**Q3.** 解释为什么 Interpreter 的连贯生成活动被描述为大脑的 _特征_，而不是 _缺陷_。

提示

想象一个无法产生连贯理由的大脑。当它被问到为什么做某事时会发生什么？会有什么社会和实际后果？

**答案：** 一个无法产生连贯理由的大脑，在需要理由的时刻会只剩下 _我不知道_ 或 _某种力量驱使了我_ 之类的报告。在少数情况下——裂脑实验、催眠暗示、直接皮层刺激——这些报告其实是准确的。但在绝大多数日常社会互动中，人们不断被要求给出理由（“你为什么这么做”“你为什么那么说”“你在想什么”），一个无法产生连贯理由的大脑会在社会中处于严重劣势。

连贯理由至少为作为社会生物的我们发挥三种有价值的功能：它们让你与他人进行可理解的沟通（分享理由是协作得以协调的方式），让你跨时间与自我协调（今天的计划需要让明天的你觉得合理），并让你维持稳定的身份（你体验到自己是一个连续的整体，而非一系列断裂冲动的集合）。这三种功能都是真实有用的。它们不是幻觉或错误；它们是 Interpreter 工作的真实社会与认知产物。
