#### 概念检测

**Q1.** 用你自己的话重述 Mercier 与 Sperber 的论证。说理性“演化为说服他人而非寻找真理”是什么意思，这一框架解释了哪些具体经验模式，而“演化为寻找真理”框架无法解释？

提示

该框架重构了理性的用途。这种重构解释了为何个体推理以特定系统方式失败，而集体推理成功。

**答案：** Mercier 与 Sperber 的论证是，外显推理的认知能力并非作为个体真理发现工具演化，而是作为社会说服工具演化。该能力在人类进化史中被选择在争端、辩论和协商中说服他人的压力下发展。因此，其设计反映什么对实现该目的有效：它被建造成产生说服他人的论证、发现别人呈现的论证中的缺陷，明显没有被建造成发现自己产生的论证中的缺陷。这些不对称能力不是要纠正的缺陷，而是系统被建造做什么的结构特征。

该框架解释了“演化为寻找真理”框架无法解释的若干经验模式：

_Wason 选择任务等基本推理任务上的个体失败。_ 如果理性演化为寻找真理，个体推理者应在明确测试推理能力的任务上表现良好。但他们不是——Wason 任务标准形式下个体成功率低于20%，类似模式出现在许多其他推理任务中。为说服演化框架解释：系统被建造成为已采取的立场生产论证（在 Wason 任务中通常是错误的直觉立场），而非通过搜索证伪证据来检验立场。失败不是缺陷；而是系统被建造来做的事。

_两人讨论对个体表现的大幅提升。_ 如果理性演化为寻找真理，个体推理者与群体应表现相似，群体可能只从取平均或工作负载分配中获益。实际模式是，初始观点分歧的一对推理者表现显著优于任何一人单独。为说服演化框架解释：每个推理者擅长发现别人论证中的缺陷；在错误答案被试表达其推理的配对中，正确答案被试能发现错误答案被试自己推理未能暴露的缺陷。交叉检查完成了任何推理者单独无法做的工作。
