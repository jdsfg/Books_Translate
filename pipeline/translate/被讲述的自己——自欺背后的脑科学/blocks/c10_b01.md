# 第9章 理性的局限——Mercier 与 Sperber

如果意识失败、努力也失败——第8章的双重否定结果——那么理性本身到底在发生什么？为什么即使在有动机的实践者持续努力应用的情况下，理性仍不能可靠地找到真理？

答案来自认知科学家 Hugo Mercier 和 Dan Sperber，在他们2017年的著作《理性的谜题》中。他们发展的论证，按某种标准，是本书中最具颠覆性的单一论证。它推翻大多数读者——包括大多数研究者——对理性是什么、为何存在所隐含的假设。一旦掌握这一论证，个体推理无法追踪真理的失败（第二、三部分以多种形式编目的）就不再像一系列无关的缺陷，而开始像一个系统的可预测行为——这个系统的实际功能与我们假设的不同。

论证如下：**理性并非演化为寻找真理。它演化为说服他人。** _你擅长发现别人论证中的缺陷。你不擅长发现自己论证中的缺陷。这不是缺陷；这是设计。_

说得更谨慎一点：外显推理的认知能力——建构论证、评估证据、权衡考虑、通过表达步骤得出结论的能力——在人类进化史中被选择出来，不是作为个体发现真理的工具，而是作为*社会说服*的工具。其设计反映了它演化所受的选择压力。这种选择压力在于在争端、辩论和协商中说服他人。执行工作的系统因此被建造成非常擅长产生说服他人的论证、非常擅长发现别人论证中的缺陷，并明显不擅长发现自己产生的论证中的缺陷。论证生产与自我评估之间的不对称不是系统缺陷；而是系统建造方式的一个特征。

这以一举解释了第二、三部分记录的整个模式。确认偏误在证据搜索中的选择性，如果理性是为了说服，就说得通：你想要支持你所主张立场的证据，而非削弱它的证据。动机性推理被分析能力放大，也说得通：更多分析能力意味着为你所倡导立场提供更好的论证。失调引擎对行动防御信念的保存，说得通：你需要成为你所公开承诺立场的真诚倡导者。偏见盲点对内省的递归抵抗，说得通：发现自己的推理有偏差会削弱你真诚倡导的能力。自传体小说的主角原则，说得通：你需要一个连贯的积极自我，以便在社会情境中捍卫。部落真理，说得通：你的推理服务于你群体的立场，这正是联盟所需要的。甚至理性主义者陷阱也说得通：围绕“做一个审慎推理者”的身份产生特别精致的论证建构，为身份服务，因为这正是系统被建造来做的。

框架解释了失败的模式。它也产生了一个严峻的结论。
