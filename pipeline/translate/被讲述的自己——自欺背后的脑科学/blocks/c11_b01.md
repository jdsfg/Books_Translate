# 第10章 结构性诚实——预测追踪、事前剖析与预先承诺

第三部分结束时关闭了应对架构的标准个体回应：意识失败、努力的身份投入失败、认知系统甚至不是为利害相关问题上的个体真理追踪而建。结构性与集体性工具的理由过度决定。第四部分以第一组工具开启——实践者可在个体尺度应用的结构性实践，利用上一章识别的不对称能力，在最重要问题上产生适度但真实的校准改善。

本章介绍三种具体工具：预测追踪、事前剖析和预先承诺。它们并非唯一可用工具，而是结构性干预如何运作的最干净演示。每种工具通过外化某种判断来运作，否则架构会悄然修订，外化提供架构持续编辑无法到达的外部参照点。三种工具共享共同逻辑——把决策时刻与情绪激活时刻分离——针对不同应用以不同方式实现。

本章必须具体地这样做。第三部分的诊断足够抽象，以至于尚未做过结构性实践的读者没有什么可比较的；第四部分的处方需要足够具体，使读者能在下个月实际执行这些实践。每种工具将描述其工作机制、具体实施步骤、可能阻止其运作的失败模式，以及它产生的现实预期。到本章结束时，读者应至少拥有一种可应用于具体利害相关问题的工具，并掌握如何应用的具体指导。应用正是本书其余部分一直指向的工作；工作产生框架支持的适度降低。

本章也是本书基调从诊断转向建设而不丧失前几章建立的诚实的地方。工具有效——这是本章将描述的经验模式。它们不会以戏剧化方式起作用；不会让实践者变成视野更清晰的思想者；不会产生自助书承诺的那种个人转变。它们在被应用的具体问题上产生具体的校准改善，经过多年累积，并在未被应用之处继续由架构运作。这就是结构性实践产生的现实形态。本章将诚实对待真正的有效性和适度的范围。
