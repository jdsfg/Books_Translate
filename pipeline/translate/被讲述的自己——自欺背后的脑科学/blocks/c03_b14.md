#### 概念检测

**Q1.** 用你自己的话重述四步 Trivers 逻辑，并指出哪一步是令人惊讶的那一步——那一步把 Trivers 的解释与道德失败叙事区分开来。

提示

前三步原则上仍可被一个仍认为自欺是缺陷的人接受。第四步让这一解释 specifically 成为 Trivers 的。

**答案：** 重述如下：

  1. 有效向他人传达信息——包括对自己有利的信息——提供真实的社会与繁殖优势。
  2. 有意识、刻意的欺骗会泄露；身体会广播说话者并不相信自己所说内容的线索。
  3. 如果说话者真诚地相信信息，泄露就消失了，因为内部没有差异可供身体记录。
  4. 因此，进化选择那些能够对那些真诚表达具有社会优势的主张产生真诚信念的认知系统，即使这些主张在证据上并不充分。

令人惊讶的一步是第四步。前三步仍可能被持道德失败观的人接受——他们可以说 _是的，说谎很难，真诚更有说服力_，同时仍认为屈从于自欺是一种应抵抗的品格弱点。第四步彻底改变画面。它说自欺不是一个人偶尔陷入的弱点；而是认知架构的一个设计特征，由大脑主动产生，因为它比任何有意识系统都更优雅地解决泄露问题。这就是 Trivers 解释与道德失败叙事的不同之处：前者预测自欺会是普遍的、自动的、流利的、抗拒内省的；后者预测自律的人大多会避免它。经验图景与 Trivers 的预测一致，而非道德失败叙事的预测。

**Q2.** 为什么道德失败叙事无法解释人群中谁自欺？它会预测什么？经验模式实际上是什么样？

提示

想想按照道德失败叙事，谁应该相对免疫。然后问证据对这个群体实际显示了什么。

**答案：** 道德失败叙事预测自欺是品格缺陷——诚实、自律或愿意面对艰难真相的失败——因此，更努力诚实、更有纪律、更勤于审视自己的人应该自欺更少。应该存在英雄：一小群异常严谨的人，通过持续努力和正直基本摆脱了这一现象。
