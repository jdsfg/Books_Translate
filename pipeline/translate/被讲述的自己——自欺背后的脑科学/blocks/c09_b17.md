#### 概念检测

**Q1.** 总结本章呈现的关于基于意识的去偏的四个主要经验发现。对每一条，解释为何它比“了解偏误就会减少偏误”的流行表述更令人不适。

提示

四个发现共同描绘出一幅与“了解偏误，变得更少偏误”截然不同的图景。逐一过一遍。

**答案：** 四个发现：

  1. _知道一种偏差并不能可靠降低对其的易感性。_ 教会被试某种特定偏差然后测量其成绩的研究通常发现，受过教育的被试与对照组表现相似。知识停留在陈述性记忆中，而偏差继续通过知识无法打断的渠道运作。流行框架假设知道一种偏差就能让人对其进行补偿；经验证据是，知道与补偿在很大程度上是分离的认知操作。

  2. _去偏训练显示微弱的实验室效果，迁移和持续性差。_ 训练项目在与训练材料高度相似的任务上产生一些改善，尤其是在训练刚结束时。随着时间推移、任务形式变化、测量从实验室转向真实生活，改善退化。流行框架假设迁移到日常认知；经验证据是迁移弱。

  3. _受过训练的被试常常更有信心却未必更准确。_ 训练产生“已做审慎工作”的感觉，这种感觉转化为信心提升；实际质量并未可靠改善。在某些情况下，受过训练的被试比未受训练者表现更差，因为提升的信心使他们推翻部分正确的直觉。流行框架假设训练产生效益，或至少无效应；记录有时显示净伤害。

  4. _在已检验案例中，结构性干预优于基于意识的干预。_ 改变决策环境结构的干预比训练决策者更好推理产生更持久的改善。改善来自结构对决策的作用，而非决策者成为更好的推理者。流行框架假设改善是个人成就；证据是改善更可靠地来自独立于个人推理能力的结构性改变。

这四个发现共同描绘出一幅与流行框架截然不同的图景。吸收全部四个的读者应该对仅意识训练——包括本书——能自行产生什么变得显著不那么乐观，并对本书其余部分描述的结构性替代方案产生显著更大兴趣。
