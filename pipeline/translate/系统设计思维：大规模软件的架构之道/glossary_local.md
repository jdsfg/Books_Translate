# 术语库：系统设计思维：大规模软件的架构之道

> 本书为技术教材，术语处理原则：
> - 用户明确列出的缩略语/产品名保留英文：CAP, ACID, BASE, CRUD, API, gRPC, CDN, DNS, TTL, LRU, FIFO, QPS, Redis, Kafka, Cassandra, MongoDB, DynamoDB, Elasticsearch, nginx, HAProxy, Kubernetes, Docker
> - REST 未列入术语库，避免与正文中的普通单词 "rest" 产生误报
> - 一般技术概念译成中文，首现可附英文；verify 以中文标准名为目标
> 格式：`英文原名 | 中文标准名 | 备注`
