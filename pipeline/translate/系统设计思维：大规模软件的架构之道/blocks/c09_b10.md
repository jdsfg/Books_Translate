#### 定义：API 网关

**API 网关** 是位于客户端与后端服务之间的中间服务。它集中处理横切关注点：认证、限流（rate limiting）、SSL 终止、请求路由、协议转换和日志。

通俗语言：API 网关是你的服务的前门。所有请求都通过它进入。它检查凭据、执行限制、路由到正确服务、记录所有日志——然后请求才到达业务逻辑代码。

**API 网关职责：**

**认证/授权：** 对每个请求验证 JWT 令牌或 API key。如果无效，立即拒绝。后端服务只收到已认证请求。

**限流：** 执行每用户或每 API key 的请求配额。防止单个用户每秒发送 10,000 次请求。

**请求路由：** 把 `/api/users` 路由到用户服务，`/api/posts` 路由到帖子服务，`/api/search` 路由到搜索服务。（在微服务架构中，API 网关是路由到多个后端服务的单一入口。）

**协议转换：** 接受来自移动客户端的 REST 请求，并转译为后端服务的 gRPC 请求。

**日志与可观测性：** 记录每个请求的耗时、状态码和客户端身份。
