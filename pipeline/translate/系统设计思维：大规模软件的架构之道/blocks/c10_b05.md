#### 对象存储的局限

**比块存储延迟高：** 对象存储通过 HTTP 访问，不是本地磁盘 I/O。小读延迟 10–100ms——通过互联网提供图片没问题（网络延迟占主导），但对数据库随机读操作不可接受。

**不能直接挂载：** 与文件存储（NFS）不同，你不能把 S3 bucket 挂载成本地磁盘并在其上运行数据库。HTTP API 不是块设备接口。

**最终一致性（历史上）：** S3 等系统在覆盖写方面历史上是最终一致的——如果你上传对象新版本并立即读取，可能拿到旧版本。现代对象存储（2020 年后的 S3）提供强写后读一致性，但对任何具体供应商都值得验证。

**扁平命名空间：** 没有目录，列出所有对象是完整扫描（按前缀过滤）。层级很深的命名需要仔细的 key 命名约定。
