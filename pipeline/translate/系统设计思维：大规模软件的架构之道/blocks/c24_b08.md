#### 概念检测

**Q1.** 为什么视频要切成 2–10 秒片段而非存为单个大文件？

**答案：** 三个原因：(1) **Seeking：** 观众跳到 2 小时电影的 90 分钟处时，可从最近的片段边界下载，而无需下载并丢弃 90 分钟视频数据。(2) **自适应码率切换：** 质量只能在片段之间切换，不能在片段中间切换。更短片段意味着更频繁的质量切换机会，能更快响应变化的网络条件。然而更短片段也会增加开销（更多 HTTP 请求、更多清单条目）。2–10 秒是经验验证过的范围，平衡切换频率与开销。(3) **并行编码：** 每个片段独立编码，可在多台机器上极度并行转码。

**Q2.** 自适应码率流中清单文件的作用是什么？

**答案：** 清单文件是指示播放器有哪些质量级别以及每个质量级别每个片段可在哪里下载的索引。它把逻辑视频（2 小时电影）映射到具体下载 URL 网格：（质量级别 × 时间区间）→ URL。播放器在播放开始时下载一次清单，然后用它请求片段。ABR 算法根据观测带宽和缓冲区健康为每个列（时间段）选择哪一行（质量级别）。没有清单，播放器就不知道存在哪些质量级别或其片段存在哪里。

**Q3.** 举例解释 CDN 缓存层级。为什么要在边缘和源之间维护区域层？

**答案：** CDN 缓存层级是：源（事实来源）→ 区域缓存（服务一个区域如“欧洲”的大型中央缓存）→ 边缘服务器（靠近用户的众多小缓存）。例子：华沙观众请求一个视频片段。华沙边缘服务器检查缓存——未命中。它不去加州源（150ms 往返），而是检查法兰克福欧洲区域缓存（25ms 往返）。法兰克福有该片段；返回给华沙并缓存在华沙。后续华沙、克拉科夫、格但斯克的观众都从华沙边缘缓存获取（5–10ms）。区域层存在是因为：(1) 边缘服务器存储有限，无法缓存该区域可能需要的所有内容。(2) 每个边缘未命中都回源会对源造成巨大负载并为缓存未命中带来高延迟。区域缓存吸收区域内大多数未命中。
