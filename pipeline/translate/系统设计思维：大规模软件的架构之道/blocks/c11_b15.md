修复方案与 Q2 原则相同：把 `local_cache` 换成共享 Redis 存储。预签名 URL 以略短于 URL 实际过期时间的 TTL 存在 Redis 中，这样缓存条目会在 URL 过期前失效。任何服务器重新生成 URL（因上传或过期）时，`DEL` 命令会删除 Redis 条目，随后所有服务器的后续请求都会重新生成并缓存新的 URL。


    def get_presigned_url(user_id):
        cache_key = f"presigned:{user_id}:photo"
        cached = redis.get(cache_key)
        if cached:
            return cached.decode()
        url = object_storage.generate_presigned_url(user_id, expires_in=3600)
        redis.setex(cache_key, 3500, url)  # TTL 略短于 URL 过期时间
        return url


这是无状态要求的直接应用：任何跨服务器不同的状态——甚至是生成产物的缓存——都必须存在于共享基础设施中。
