# 风格简报 · 心理自助 / 科普系列（psych_evo / self_deception / emotions_sci / stoicism / relationships / memory_book / habit_book / training_sci2 / sleep_book / stress_book）

> 覆盖：进化心理学 / 被讲述的自己 / 情绪的科学 / 古老的认知疗法 / 看见彼此 / 记忆——术与道 / 习惯的科学 / 训练的科学·卷二 / 睡眠的科学 / 压力的科学。心理学+科普+轻自助，**质量 bar = 保住文气与可读节奏**（科普散文体，但内容精度仍须保）。

## 1. 系列定位
心理学科普 + 轻自助。既有科学事实，又有面向读者的可读讲述。语言亲和、具节奏感。

## 2. 质量 bar（核心）
- **保住文气与可读节奏**：科普散文体，隐喻、近距"你"的讲述感还原；不压平成教科书。
- **内容精度保底**：机制、脑区、激素、实验结论准确。
- 介于人文与技术之间：文气是验收项，但科学事实零容错。

## 3. 人称 / 语气
- 保留第二人称"你"的对话感（如有）。
- 轻自助的鼓励语气克制保留，不夸大。

## 4. 术语处理
- 首现加注原文：cognitive bias（认知偏差）、attachment（依恋）、neuroplasticity（神经可塑性）、cortisol（皮质醇）、dopamine（多巴胺）、placebo（安慰剂）、amygdala（杏仁核）、prefrontal cortex（前额叶）、fight-or-flight（战或逃）。
- 脑区/激素名用通用中译。

## 5. 禁忌译法
- training 在"训练的科学"语境 = 训练（体能/认知），非 ML 的"训练"。
- attachment = 依恋（心理语境），非"附件"。
- 不把科学术语翻成玄学口语。

## 6. 结构保全
- 实验数据表、引文、脚注、练习框、标题层级原样。
- 研究编号（e.g. Study 2）保留。

## 7. 数字规则（科普散文 + 强制精确并存）
- **精确测量值 / 单位 / 百分比 / 统计 / 剂量 / 年限**保留阿拉伯数字 + 原单位（"7 小时"、"皮质醇上升 23%"、"n=120"）。
- **约整数 / 顺口数词可用中文**（"数十万次"、"每天几十次"）——但精确项仍阿拉伯。
- 本系列是"科普散文可中文数词约化"规则的适用对象（区别于纯技术/统计书）。

## 8. 示例
- 源：`The amygdala triggers a fight-or-flight response in milliseconds.`
- 译：`杏仁核（amygdala）会在毫秒间触发"战或逃"（fight-or-flight）反应。`
- 源：`About 70% of adults report poor sleep quality.`
- 译：`约 70% 的成年人表示睡眠质量差。`
