### 9.4 重构 4：移动（Move）

**信号**：函数放在了错误文件或模块里。它使用另一个模块的数据比当前模块多。它在概念上属于不同领域。

**之前**（在 `src/orders.py` 中）：

    def is_customer_eligible_for_discount(customer):
        if customer.tier == 'enterprise':
            return True
        if customer.is_grandfathered:
            return True
        return False

该函数只接收 `customer`；不用 `orders` 任何东西。它属于 `customers.py`。

**之后**（在 `src/customers.py` 中）：

    def is_eligible_for_discount(customer):
        if customer.tier == 'enterprise':
            return True
        if customer.is_grandfathered:
            return True
        return False

收益：函数现在靠近相关代码；未来读者会在找 customer 逻辑的地方找到它。

**AI 层**：AI 智能体可靠地在同一语言内做函数级移动。跨模块移动并更新 import 通常能正确处理；跨语言移动（例如 Python helper 移到 Rust crate）需要人类指导。


### 9.5 重构 5：用多态替换条件表达式

**信号**：一长串条件判断（`if/elif/else` 或 `switch`）基于类型标签，且同样链在多处重复。

**之前**：

    def compute_shipping_cost(order):
        if order.shipping_type == 'standard':
            return 5.99
        elif order.shipping_type == 'express':
            return 14.99
        elif order.shipping_type == 'overnight':
            return 29.99
        elif order.shipping_type == 'free':
            return 0
        raise ValueError(f"Unknown shipping type: {order.shipping_type}")

    def get_shipping_label(order):
        if order.shipping_type == 'standard':
            return "Standard (5-7 business days)"
        elif order.shipping_type == 'express':
            return "Express (2-3 business days)"
        # ... 依此类推

**之后**：

    class ShippingType(Protocol):
        def cost(self) -> float: ...
        def label(self) -> str: ...

    class StandardShipping:
        def cost(self): return 5.99
        def label(self): return "Standard (5-7 business days)"

    class ExpressShipping:
        def cost(self): return 14.99
        def label(self): return "Express (2-3 business days)"

    # ... 依此类推

收益：条件逻辑被多态取代；增加新 shipping 类型只需加一个类，不用修改每个条件。

这个重构常被过度应用（第 13 章）。信号是*同一条链在多处重复*；孤立的条件可能不需要多态。取舍是以抽象换灵活；按链重复次数权衡。

**AI 层**：AI 智能体能胜任这个重构，但倾向于过度急切应用。人类判断是：链重复到足以 justify 抽象吗？
