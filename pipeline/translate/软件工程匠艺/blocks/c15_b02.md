#### 完整示例

Helix pricing 子系统重构后：

    # Ports（由核心定义）
    class CustomerPort(Protocol):
        def find(self, cid: str) -> Optional[Customer]: ...

    class RuleConfigPort(Protocol):
        def load_rules(self) -> list[Rule]: ...

    class TaxRatePort(Protocol):
        def rate_for(self, region: str) -> Decimal: ...

    class ChargePort(Protocol):
        def charge(self, customer: Customer, amount: Decimal, currency: str) -> ChargeResult: ...

    class AuditLogPort(Protocol):
        def log(self, event: str, data: dict) -> None: ...

    # Core（只依赖 ports 和领域类型）
    class PricingService:
        def __init__(self,
                     customers: CustomerPort,
                     rules: RuleConfigPort,
                     tax: TaxRatePort,
                     charges: ChargePort,
                     audit: AuditLogPort):
            self._customers = customers
            self._rules = rules
            self._tax = tax
            self._charges = charges
            self._audit = audit

        def price_and_charge(self, customer_id: str, product_id: str) -> ChargeResult:
            customer = self._customers.find(customer_id)
            rules = self._rules.load_rules()
            base_price = compute_price(customer, product_id, rules)  # 纯函数
            tax_rate = self._tax.rate_for(customer.region)
            total = base_price * (1 + tax_rate)
            result = self._charges.charge(customer, total, customer.currency)
            self._audit.log('charge_completed', {'customer_id': customer_id, 'amount': str(total)})
            return result

    # Adapters（每个外部系统一个）
    class SqlCustomerAdapter:
        def __init__(self, pool): self._pool = pool
        def find(self, cid): ...  # 真实 SQL

    class S3RuleConfigAdapter:
        def __init__(self, s3_client, bucket, key): ...
        def load_rules(self): ...  # 真实 S3 读取与 Yaml 解析

    class HttpTaxRateAdapter:
        def __init__(self, http_client, base_url): ...
        def rate_for(self, region): ...  # 真实 HTTP 调用

    class StripeChargeAdapter:
        def __init__(self, stripe_key): ...
        def charge(self, customer, amount, currency): ...  # 真实 Stripe 调用

    class CloudWatchAuditLogAdapter:
        def log(self, event, data): ...  # 真实 CloudWatch 调用

收益：核心 `PricingService` 依赖五个抽象 port。测试为每个 port 传入内存 fake。测试主体是 `PricingService` 逻辑，快速且确定。adapter 单独针对真实外部系统做集成式测试。


#### 纯函数嵌入

注意 `price_and_charge` 里的 `compute_price` 函数。它是纯函数：输入 customer、product_id、rules；输出 price。它可以在没有任何 port 的情况下测试。这就是*函数式核心*思想（§14.3）在六边形框架内的应用。
