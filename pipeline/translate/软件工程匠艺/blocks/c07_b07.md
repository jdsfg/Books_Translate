### 6.8 完整示例：再访 ISO 8601 解析器

开篇小插曲里的解析器覆盖率 94%、变异分数 41%，并有闰秒 bug。组合方法：

第 1 步：识别 survive 变异体。典型样本：

* 变异体：`if length > 19` → `if length >= 19`。Survive：没有测试练到长度边界。
* 变异体：`month < 13` → `month <= 13`。Survive：没有 month=13 测试。
* 变异体：`is_leap_year(year)` → `True`。Survive：没有闰年逻辑在边界起作用的测试。
* 变异体：`seconds == 60` → `seconds == 61`。Survive：没有闰秒测试。

第 2 步：为结构属性加基于属性的测试：

    @given(st.datetimes())
    def test_roundtrip(dt):
        assert parse(serialize(dt)) == dt

    @given(st.text(alphabet='0123456789-:TZ ', min_size=1, max_size=30))
    def test_invalid_input_raises(s):
        try:
            result = parse(s)
            # 如果它没有抛出，那必须是合法 datetime
            assert isinstance(result, datetime)
        except ParseError:
            pass  # 多数输入预期会抛异常

第 3 步：为 Hypothesis 没抓住的 survive 变异体加针对性示例测试：

    def test_leap_second():
        assert parse('2024-02-29T23:59:60Z') == datetime(2024, 3, 1, 0, 0, 0, tzinfo=utc)

    def test_half_hour_offset():
        assert parse('2024-01-01T12:00:00+05:30').utcoffset() == timedelta(hours=5, minutes=30)

第 4 步：重新跑变异测试。分数从 41% 升到 87%（开篇小插曲的结果）。上面四个样本变异体：现在全部被杀死。

工作量：一个下午写基于属性测试，两小时针对性示例测试，前后各一次变异测试跑。接下来季度解析器缺陷率为零。
