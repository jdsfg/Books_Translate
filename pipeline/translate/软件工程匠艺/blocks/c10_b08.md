### 9.10 重构 10：用流水线替换循环

**信号**：循环通过过滤和转换构建列表，使用中间累加器。

**之前 / 之后**：

    # 之前
    def get_active_enterprise_emails(customers):
        result = []
        for c in customers:
            if c.tier == 'enterprise' and c.is_active and c.email:
                result.append(c.email.lower())
        return result

    # 之后（Python 推导式）
    def get_active_enterprise_emails(customers):
        return [c.email.lower() for c in customers
                if c.tier == 'enterprise' and c.is_active and c.email]



    // 之后（TypeScript）
    const getActiveEnterpriseEmails = (customers) =>
      customers
        .filter(c => c.tier === 'enterprise' && c.isActive && c.email)
        .map(c => c.email.toLowerCase());

声明式流水线读起来就是数据流本身。语言相关：流水线适合 Python/JS/Rust/Scala；较老的 C 和嵌入式环境可能保留循环形式。

**AI 层**：智能体默认就产出流水线形式；无需特别提示。


### 9.11 重构 11：把函数组合成类

**信号**：多个函数接收相同数据并以相关方式操作它。数据串联穿过函数链；类会让它集中。

**之前 / 之后**：

    # 之前：数据通过独立函数传递
    def parse_csv(text): ...
    def filter_csv(rows, column, value): ...
    def csv_to_json(rows): ...

    rows = parse_csv(text)
    rows = filter_csv(rows, 'region', 'EU')
    result = csv_to_json(rows)

    # 之后：类上的方法，可链式调用
    class CsvProcessor:
        def __init__(self, text):
            self._rows = [r.split(',') for r in text.split('\n')]
        def filter(self, column, value):
            header, *data = self._rows
            idx = header.index(column)  # 列索引
            self._rows = [header] + [r for r in data if r[idx] == value]
            return self
        def to_json(self):
            header, *data = self._rows
            return [dict(zip(header, r)) for r in data]

    result = CsvProcessor(text).filter('region', 'EU').to_json()

数据与操作集中；中间变量消失。**注意**：如果操作*不相关*，这个类就是人为的。信号是*对共享数据的相关操作*。

**AI 层**：被提示时智能体会应用，但很少主动发现机会。人类发现内聚性；智能体做拆分。
