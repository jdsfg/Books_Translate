### 9.6 重构 6：用常量替换魔法数

**信号**：代码中出现没有明显含义的字面量。读者得猜 `0.08` 或 `1024` 代表什么。

**之前**：

    def calculate_total(subtotal):
        return subtotal * 1.08

    def is_file_too_large(path):
        return os.path.getsize(path) > 1024 * 1024 * 10

**之后**：

    SALES_TAX_RATE = 0.08
    MAX_UPLOAD_SIZE_BYTES = 10 * 1024 * 1024

    def calculate_total(subtotal):
        return subtotal * (1 + SALES_TAX_RATE)

    def is_file_too_large(path):
        return os.path.getsize(path) > MAX_UPLOAD_SIZE_BYTES

收益：含义在它所处位置被命名；未来维护者能在一个地方找到并更新常量。

一个细微点：不是每个字面量都需要常量。`0` 和 `1` 很少需要名字；`len(items) > 0` 不需要 `MIN_ITEMS_FOR_PROCESSING = 1`。信号是*无法解释*；如果含义显而易见，保留字面量。

**AI 层**：AI 智能体擅长这个重构，且倾向于过度应用。人类的判断_needed for *命名*：一个命名糟糕的常量比魔法数更糟，因为它暗示了一个可能错误的含义。
