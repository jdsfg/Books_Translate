标签由*后果*决定：必须修才能合并、可选可修可不修、可忽略的小问题、纯正向强化。

**答：**

  1. **Blocking**；安全问题，契约违反。作者必须在合并前修复；Carmen 会复阅修复。无裁量权。
  2. **Suggestion**；改进，非严格必需。作者可选择抽常量（5 分钟，适度收益）或保留（现有代码仍正确）。两种选择都可辩护；Carmen 不会因此阻塞。

  4. **Suggestion**（偏向 neither / observation）；风格偏好，两种做法都合理。有时若团队无偏好是“Nit”；若有轻微倾向是“Suggestion”。作者可采纳或保留；都行。
  5. **Praise**；纯正向。作者不应“修”任何东西；praise 告诉他们*哪里做对了*，从而强化未来 PR 的纪律。
