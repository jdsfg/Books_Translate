### 9.8 重构 8：用组合替换继承

**信号**：一个类为了共享实现而继承，而不是因为它*是一个*父类。症状：继承的方法未被使用、方法被覆盖成空操作、多重继承没有清晰层次。

**之前 / 之后**：

    # 之前：Robot 不是 Animal，却为了共享 eat/sleep stub 而继承
    class Animal:
        def eat(self): pass
        def sleep(self): pass
    class Dog(Animal):
        def bark(self): pass
    class Robot(Animal):
        def beep(self): pass
        def eat(self): pass     # 覆盖成空操作
        def sleep(self): pass   # 覆盖成空操作

    # 之后：通过 has-a 组合（无继承）
    @dataclass
    class Mortal:
        def eat(self): pass
        def sleep(self): pass
    @dataclass
    class Dog:
        mortal: Mortal
        def bark(self): pass
    @dataclass
    class Robot:
        def beep(self): pass    # Robot 不组合 Mortal；它不是 Mortal

当关系是共享实现时，has-a 胜过 is-a。为共享实现而继承是第 13 章的反模式；这个重构是修复。

**AI 层**：智能体倾向于选继承，因为教程代码这样教；`CLAUDE.md` 应显式偏好组合。


### 9.9 重构 9：引入参数对象

**之前 / 之后**：

    # 之前：参数墙

                     shipping_line2, shipping_city, shipping_state, shipping_postal,
                     shipping_country, payment_method, payment_token, billing_address):
        ...

    # 之后：参数对象按概念分组
    @dataclass
    class Address:
        line1: str; line2: str; city: str; state: str; postal_code: str; country: str
    @dataclass
    class Payment:

    @dataclass
    class OrderRequest:
        customer_id: str
        items: list[OrderItem]
        shipping_address: Address
        payment: Payment
        billing_address: Address

    def create_order(request: OrderRequest): ...

签名不再膨胀；每个分组变成可在别处复用的命名领域概念。

**AI 层**：智能体会过度应用；3 参数函数不需要包装。阈值大约 5–7 个参数或 2–3 个分组概念。
