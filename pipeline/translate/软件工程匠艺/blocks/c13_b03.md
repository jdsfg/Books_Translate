#### 2026 年示例

你在把 Stripe 和 PayPal 集成进支付系统。两个 vendor 都有 SDK，但签名不同：

    # Stripe SDK
    stripe.Charge.create(amount=1000, currency='usd', source='tok_visa')

    # PayPal SDK
    paypal_client.create_payment({'amount': '10.00', 'currency': 'USD', 'method': 'paypal'})

应用代码不应按 vendor 分支。Adapter 提供统一接口：

    class PaymentProcessor(Protocol):
        def charge(self, amount_cents: int, currency: str, token: str) -> ChargeResult: ...

    class StripeAdapter:
        def charge(self, amount_cents, currency, token):
            result = stripe.Charge.create(
                amount=amount_cents,
                currency=currency.lower(),
                source=token,
            )
            return ChargeResult(id=result.id, status=result.status)

    class PayPalAdapter:
        def __init__(self, client): self._client = client
        def charge(self, amount_cents, currency, token):
            amount_str = f'{amount_cents / 100:.2f}'
            result = self._client.create_payment({
                'amount': amount_str,
                'currency': currency.upper(),
                'method': 'paypal',
                'token': token,
            })
            return ChargeResult(id=result['id'], status=result['status'])

    # 应用代码
    class CheckoutService:
        def __init__(self, processor: PaymentProcessor):
            self._processor = processor
        def checkout(self, order):
            return self._processor.charge(
                amount_cents=order.total_cents,
                currency=order.currency,
                token=order.payment_token,
            )

收益：应用代码与 vendor 无关；切换 vendor 只需改构造参数；测试应用代码用 fake adapter；vendor 特定细节留在 adapter 里。


#### 何时 Adapter 是正确模式

* **你在集成外部系统**，其接口不受你控制。
* **你希望代码库其余部分依赖稳定接口**，而不是 vendor 接口。
* **你未来可能想切换 vendor**，希望替换局部化。
* **你想在不命中 vendor 的情况下测试应用代码。**

这本质上是第 7 章 Repository 模式推广到数据存储之外：任何外部系统都应该有一个 adapter。


#### 何时 Adapter 是错误模式

如果你只有一个 vendor、一个使用点、也没有测试痛苦，adapter 是过度工程。多数团队在发现 vendor 耦合的痛苦后才加 adapter，而非提前。纪律是：当你*第二次*发现想绕过 vendor SDK 做测试，或想切换 vendor 时，再抽 adapter。
