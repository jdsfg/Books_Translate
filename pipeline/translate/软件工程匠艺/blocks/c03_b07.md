#### 不同之处

AI 生成的代码有一种人类代码很少有的*质感*：

* **局部正确，全局不一致。** 函数做了 docstring 说的事，但导入的工具与代码库其余部分同一目的所用的不同。
* **看似合理的名字。** 名字听起来对（`processOrder`、`validateInput`、`computeMetrics`），但有时太泛化，掩盖了代码库别处实际使用的领域概念。
* **过度解释型注释。** 注释重述代码说了什么，而不是解释为什么。
* **为不可能情况写的防御性代码。** 对类型系统已保证非 `null` 的输入做 `null` 检查，为同步本地调用写重试逻辑。
* **看起来自信的错误处理却吞掉错误。** `try { ... } catch (e) { console.error(e); return null; }` 是线索 C（第 15 章）的红旗。

阅读 AI 生成的代码需要比阅读人类代码*更多*怀疑，而不是更少。人类代码常常在需求上出错；AI 代码常常在代码库上下文上出错。两者都需要仔细读。区别在失效模式。
