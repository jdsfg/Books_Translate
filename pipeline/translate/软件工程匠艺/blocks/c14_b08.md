### 13.7 完整示例：Helix 仓库重构

2024 年，Aki 在 Helix 继承了一个 `CustomerRepositoryFactoryProvider` 及其支撑层次。代码库已成长两年；模式税由原工程师引入，又被一个学习代码库风格的 AI 助手复刻。

清单：

* `CustomerRepositoryFactoryProvider`（一个类，30 行）
* `SqlCustomerRepositoryFactory`、`InMemoryCustomerRepositoryFactory`（两个类，各 20 行）
* `CustomerRepository` 抽象基类（一个类，50 行抽象方法）
* `SqlCustomerRepository`、`InMemoryCustomerRepository`（两个类，真正实现）

总模式税：约 120 行，分散在五个类里，它们存在只是为了推迟该构造哪个 Customer repository 的决定。

重构：

    # 之前：5 个类，120 行间接层
    class CustomerRepositoryFactoryProvider: ...
    class SqlCustomerRepositoryFactory: ...
    class InMemoryCustomerRepositoryFactory: ...
    class CustomerRepository(ABC): ...  # 抽象基
    class SqlCustomerRepository(CustomerRepository): ...
    class InMemoryCustomerRepository(CustomerRepository): ...

    # 之后：1 个函数，2 个类，无间接层
    class CustomerRepository(Protocol):
        def find(self, cid: str) -> Optional[Customer]: ...
        def save(self, c: Customer) -> None: ...

    class SqlCustomerRepository:
        def __init__(self, pool): self._pool = pool
        def find(self, cid): ...
        def save(self, c): ...

    class InMemoryCustomerRepository:
        def __init__(self): self._store = {}
        def find(self, cid): return self._store.get(cid)
        def save(self, c): self._store[c.id] = c

    def make_customer_repository(env='production', pool=None) -> CustomerRepository:
        if env == 'production':
            return SqlCustomerRepository(pool)
        return InMemoryCustomerRepository()

结果：从 120 行变成 50 行。两个具体类加一个 Protocol（运行时零成本，仅类型检查价值）。一个工厂函数替代三层类结构。灵活性（切换实现）完整保留；间接层消失。

Aki 的提交信息抓住了原则：

    refactor(customer-repo): collapse pattern-tax to direct construction

    CustomerRepositoryFactoryProvider 层次为支持一个运行时选择
    （production vs in-memory）增加了三层间接。压缩成单一工厂函数。
    行为不变；删除 70 行；删除 4 个文件。

    Removed:
    - CustomerRepositoryFactoryProvider
    - SqlCustomerRepositoryFactory
    - InMemoryCustomerRepositoryFactory
    - CustomerRepository abstract base (replaced by Protocol)

    只有在构造本身复杂，或多个消费者需要工厂灵活性时，
    才应该把构造推迟给工厂。这里两者都不成立。

PR 二十分钟审查完（第 15 章）；减少的间接层对每个审查者都可见。团队随后在审查中养成了拒绝新模式税的习惯。
