#### 定义：函数式核心 / 命令式外壳

在 FC/IS 中，应用核心是一组纯函数：它们接受输入并返回输出，无副作用。命令式外壳处理 I/O、副作用和编排；它用输入调用纯核心，再用输出驱动副作用。

直白地说：在纯函数里思考；在薄编排层里执行。思考部分可轻松测试；执行部分足够小，可直接测试。


#### 完整示例

pricing 逻辑进一步重构为 FC/IS 形式：

    # 函数式核心（纯）
    def compute_price_decision(customer: Customer,
                               product_id: str,
                               rules: list[Rule],
                               tax_rate: Decimal) -> PriceDecision:
        """纯函数：给定输入，返回应该发生什么。"""
        matching_rule = next((r for r in rules if r.matches(customer, product_id)), None)
        base_price = matching_rule.price if matching_rule else default_price(product_id)
        total = base_price * (1 + tax_rate)
        return PriceDecision(
            base_price=base_price,
            tax_amount=base_price * tax_rate,
            total=total,
            rule_id=matching_rule.id if matching_rule else None,
        )

    # 命令式外壳
    class PricingOrchestrator:
        def __init__(self, customers, rules, tax, charges, audit):
            self._customers = customers
            self._rules = rules
            self._tax = tax
            self._charges = charges
            self._audit = audit

        def price_and_charge(self, customer_id: str, product_id: str) -> ChargeResult:
            # 收集输入（有副作用的读）
            customer = self._customers.find(customer_id)
            rules = self._rules.load_rules()
            tax_rate = self._tax.rate_for(customer.region)

            # 决策（纯）
            decision = compute_price_decision(customer, product_id, rules, tax_rate)

            # 动作（有副作用的写）
            result = self._charges.charge(customer, decision.total, customer.currency)
            self._audit.log('charge_completed', {
                'customer_id': customer_id,
                'amount': str(decision.total),
                'rule_id': decision.rule_id,
            })
            return result

纯函数 `compute_price_decision` 是*决策逻辑*。它可以用数千个基于属性的测试用例（第 6 章）以微秒速度测试。orchestrator 是*协调器*：它做读取、调用纯函数、做写入。协调器很小（几十行），因此可用 fake 直接测试。
