### 9.1 重构 1：抽取函数（Extract Function）

**信号**：函数超过 30–50 行，或包含多个用注释分隔的逻辑段，或有像 `# 现在计算折扣` 这种读起来像函数名的注释。

**之前**：

    def process_order(order, customer):
        # 验证订单
        if not order.items:
            raise InvalidOrderError("no items")
        if order.total < 0:
            raise InvalidOrderError("negative total")
        for item in order.items:
            if item.quantity <= 0:
                raise InvalidOrderError(f"invalid quantity for {item.sku}")

        # 计算折扣
        discount = 0
        if customer.tier == 'enterprise':
            discount += 0.10
        if order.total > 1000:
            discount += 0.05
        if customer.is_grandfathered:
            discount += 0.03

        # 应用折扣
        order.total = order.total * (1 - discount)

        # 保存并通知
        save_order(order)
        notify_customer(customer, order)

**之后**：

    def process_order(order, customer):
        validate_order(order)
        discount = compute_discount(order, customer)
        order.total = order.total * (1 - discount)
        save_order(order)
        notify_customer(customer, order)

    def validate_order(order):
        if not order.items:
            raise InvalidOrderError("no items")
        if order.total < 0:
            raise InvalidOrderError("negative total")
        for item in order.items:
            if item.quantity <= 0:
                raise InvalidOrderError(f"invalid quantity for {item.sku}")

    def compute_discount(order, customer):
        discount = 0
        if customer.tier == 'enterprise':
            discount += 0.10
        if order.total > 1000:
            discount += 0.05
        if customer.is_grandfathered:
            discount += 0.03
        return discount

收益：`process_order` 现在读起来是一系列步骤列表，每一步都用领域语言命名；验证和折扣逻辑可以独立测试。

**AI 层**：AI 智能体可靠地执行抽取函数。风险是它抽取得太急，产生许多 tiny 函数，割裂可读性。人类的判断需要决定*粒度*：什么时候抽取会降低清晰度而不是提高？
