### 9.7 重构 7：抽取类（Extract Class）

**信号**：类职责太多。方法明显分成若干子组，每个子组使用类字段的不同子集。

**之前**：

    class Customer:
        def __init__(self, id, name, email, address_line1, address_line2,
                     city, state, postal_code, country):
            self.id = id
            self.name = name
            self.email = email
            self.address_line1 = address_line1
            self.address_line2 = address_line2
            self.city = city
            self.state = state
            self.postal_code = postal_code
            self.country = country

        def get_full_address(self):
            return f"{self.address_line1}\n{self.address_line2}\n{self.city}, {self.state} {self.postal_code}\n{self.country}"

        def is_us_address(self):
            return self.country == 'US'

        def get_display_name(self):
            return self.name

        def is_email_verified(self):
            return self.email_verified  # 假设该字段存在

**之后**：

    class Address:
        def __init__(self, line1, line2, city, state, postal_code, country):
            self.line1 = line1
            self.line2 = line2
            self.city = city
            self.state = state
            self.postal_code = postal_code
            self.country = country
        def get_full(self):
            return f"{self.line1}\n{self.line2}\n{self.city}, {self.state} {self.postal_code}\n{self.country}"
        def is_us(self):
            return self.country == 'US'

    class Customer:
        def __init__(self, id, name, email, address):
            self.id = id
            self.name = name
            self.email = email
            self.address = address
        def get_display_name(self):
            return self.name
        def is_email_verified(self):
            return self.email_verified

收益：每个类职责聚焦；地址可以独立于客户身份测试和修改。

**AI 层**：当被提示时，AI 智能体会抽取类，但很少主动发现机会。人类发现内聚问题；智能体执行机械拆分。
