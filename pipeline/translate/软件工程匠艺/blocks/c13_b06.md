#### 2026 年示例

Iterator 已如此深入地内置于现代语言，你很少显式实现它。Python 有 `__iter__` 和 `__next__`；JavaScript 有 generator 和 iterator；Rust 有 `Iterator` trait；Go 有 range。该模式以原生方式实现。

    class TreeNode:
        def __init__(self, value, children=None):
            self.value = value
            self.children = children or []
        def __iter__(self):
            # 中序遍历
            yield self.value
            for child in self.children:
                yield from child

    root = TreeNode(1, [TreeNode(2), TreeNode(3, [TreeNode(4)])])
    for value in root:
        print(value)  # 1, 2, 3, 4

收益：调用方无需知道树的结构；遍历方式可以改变（深度优先、广度优先、中序）而不影响调用方代码。


#### 何时 Iterator 是正确模式

* **你向调用方暴露一个集合**（任何包含元素的数据结构）。
* **内部结构可能改变**，但迭代语义不应改变。
* **集合可能是无限或惰性计算**（流、分页 API 结果、生成序列），你不想物化整个集合。
* **多种遍历顺序有价值**（例如树的遍历）。


#### 惰性迭代的超能力

Iterator 实现惰性求值：

    def primes():
        yield 2
        candidates = (i for i in itertools.count(3, 2))  # 3, 5, 7, 9, ...
        found = [2]
        for c in candidates:
            if all(c % p != 0 for p in found if p * p <= c):
                found.append(c)
                yield c

    # 取前 10 个素数，而不用计算所有素数
    first_ten = list(itertools.islice(primes(), 10))

无限素数流是可迭代的，但永远不会完全物化。这是 Iterator 的现代形状，在 2026 年代码库中广泛用于分页 API、日志流、事件源。


#### 何时 Iterator 是错误模式

Iterator 在 2026 年很少是错误模式；它内置于语言，几乎条件反射式适用。错误模式问题更多是“我应该实现显式 Iterator 类，还是使用语言原生迭代？” 答案几乎总是原生迭代；显式 Iterator 类是 Java-1990s 的遗物。


### 12.6 Command（命令）

Command 模式把请求封装成对象，从而可以对请求参数化、排队、记录日志或撤销。


#### 定义：Command

Command 模式将请求表示为对象。该对象封装动作、接收者和参数；调用方不直接调用动作，而是把命令提交给执行器。这允许排队、日志、重试和撤销。

直白地说：把函数调用变成数据对象；传递数据；稍后或以不同方式执行。
