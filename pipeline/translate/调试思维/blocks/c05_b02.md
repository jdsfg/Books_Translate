### 5.2 代码中的二分查找：在中点打印

二分查找调试法最简单的形式是：你有一个函数，它接收输入 A，却产生了错误输出 B。在两者之间的某个地方，数据从正确变成了错误。找到这个转换点。
    
    
    def process_order(order):
        validated = validate_order(order)          # 步骤 1
        priced = apply_pricing(validated)          # 步骤 2
        taxed = calculate_tax(priced)              # 步骤 3
        discounted = apply_discounts(taxed)        # 步骤 4
        formatted = format_receipt(discounted)     # 步骤 5
        saved = save_to_database(formatted)        # 步骤 6
        confirmation = send_confirmation(saved)    # 步骤 7
        return confirmation
    

最终输出是错的。是哪一步引入了错误？

**不使用二分查找**：检查步骤 1，然后步骤 2，然后步骤 3……最多检查 7 次。

**使用二分查找**：检查中点——步骤 4（`discounted`）之后。打印或记录 `discounted` 的值。它正确吗？

* 如果 `discounted` 是正确的：缺陷在步骤 5-7。检查步骤 6 之后（步骤 5-7 的中点）。
* 如果 `discounted` 是错误的：缺陷在步骤 1-4。检查步骤 2 之后（步骤 1-4 的中点）。

最多 3 次检查，你就已经确定了把正确数据转换成错误数据的确切步骤。

实践中，你在中点添加一条打印语句（或使用调试器断点），然后检查数据：
    
    
    def process_order(order):
        validated = validate_order(order)
        priced = apply_pricing(validated)
        taxed = calculate_tax(priced)
        discounted = apply_discounts(taxed)
        print(f"调试中点：discounted = {discounted}")  # 在这里检查
        formatted = format_receipt(discounted)
        saved = save_to_database(formatted)
        confirmation = send_confirmation(saved)
        return confirmation
    

这是“原始”的调试，有些人会嘲笑打印语句。别听他们的。打印语句是现存适用范围最广的调试工具。它们适用于每种语言、每个平台，并且零配置。关键在于_策略性地_使用它们——放在中点，而不是到处都是。
