**Q1.** 阅读下面的错误消息并追踪根因。逐步解释你的推理。
    
    
    Traceback (most recent call last):
      File "main.py", line 28, in <module>
        result = process_data(raw_input)
      File "processor.py", line 15, in process_data
        cleaned = clean_text(data['body'])
      File "utils.py", line 7, in clean_text
        return text.strip().lower()
    AttributeError: 'NoneType' object has no attribute 'strip'
    

提示

从崩溃处反向推理。`text` 是什么？它从哪里来？为什么它是 None？

**答案：** 逐步推理：

  1. **崩溃** ：`utils.py` 第 7 行，`text.strip().lower()` —— `text` 是 `None`，而 `None` 没有 `.strip()` 方法。这是_症状_。

  2. **`text` 来自哪里**：`text` 是传给 `clean_text()` 的参数。看堆栈中上一层：`processor.py` 第 15 行调用 `clean_text(data['body'])`。所以 `text = data['body']`。既然 `text` 是 `None`，这意味着 `data['body']` 是 `None`。

  3. **`data` 来自哪里**：`data` 是 `process_data()` 的参数。再往上一层看：`main.py` 第 28 行调用 `process_data(raw_input)`。所以 `data = raw_input`，而 `raw_input['body']` 是 `None`。

  4. **根因** ：`raw_input` 是一个字典，它有 `'body'` 键，但其值是 `None`。这可能意味着：数据源（API、文件、数据库）返回了一条 body 字段为 null 的记录，或者数据在上游构造不正确。

  5. **修复应该处理** ：要么在把 `raw_input['body']` 传给 `clean_text` 之前进行验证（如果 null body 是一种合法的数据可能性），要么修复产生 null body 值的数据源（如果 body 应当始终存在）。
