### 11.2 Null 和 Undefined：十亿美元错误

Tony Hoare 在 1965 年发明了空引用，他称之为自己的"十亿美元错误"。空引用和 undefined 引用造成的运行时崩溃，比任何其他单一类别的缺陷都更多。

根本问题是：变量本应包含一个值，但实际却包含 null（或 undefined、nil、None，取决于语言）。任何把它当作有值来使用的尝试都会崩溃。
    
    
    // The user object might not exist
    const user = getUser(id);  // Returns null if user not found
    console.log(user.name);    // TypeError: Cannot read property 'name' of null
    

**null 的常见来源：**

  1. **没有找到结果的数据库查询。** 如果用户 99 不存在，`SELECT * FROM users WHERE id = 99` 会返回 null。
  2. **静默失败的 API 调用。** API 返回 null 或空响应，而不是抛出错误。
  3. **可选字段。** 用户对象的 `middleName` 可能是 null，因为不是每个人都有中间名。
  4. **竞态。** 当你试图使用数据时，数据还没有加载完成。
  5. **数组越界访问。** 当数组只有 5 个元素时访问 `array[10]`，在 JavaScript 中会返回 `undefined`（在大多数其他语言中会崩溃）。

**诊断模式** ：`NullPointerException`、`TypeError: Cannot read property 'X' of null/undefined`、`AttributeError: 'NoneType' object has no attribute 'X'`。当你看到这些时，问题是：为什么这个变量是 null？向后追踪（第 8 章），找到它本应在哪里被赋值，以及为什么没有被赋值。

**预防模式** ：

* **使用前做 null 检查** ：`if (user != null) { ... }`
* **默认值** ：`const name = user?.name || "Anonymous"`
* **可选链** ：`user?.address?.city`（如果任何一部分为 null，就返回 undefined，而不是崩溃）
* **类型系统** ：TypeScript、Kotlin、Rust 和其他语言可以在编译时标记潜在的 null 访问


### 11.3 不正确的条件：逻辑出错时

布尔逻辑是精确的。人类思维不是。两者之间的差距会源源不断地产生缺陷。

**反向条件：**
    
    
    # Bug: the condition is backwards
    if user.is_active:
        return "Account suspended"  # Should be for INACTIVE users
    

**错误的运算符：**
    
    
    # Bug: AND should be OR
    if age < 13 and age > 65:  # Impossible — no one is both under 13 AND over 65
        apply_discount()
    
    # Fix:
    if age < 13 or age > 65:
        apply_discount()
    

**缺少否定：**
    
    
    # Bug: missing 'not'
    if user.has_permission("admin"):
        return "Access denied"  # Admins are denied? That's backwards.
    

**条件中的差一错误**（第 11.1 节的一个特殊情况）：
    
    
    # Bug: > should be >=
    if balance > 0:
        allow_withdrawal()
    # A balance of exactly 0 is NOT allowed — is that intended?
    

**诊断模式** ：如果代码做的事情与你预期的_相反_，检查条件。如果它在大多数情况下做对了，但在特定边界情况下出错，检查边界条件和运算符。把条件大声读出来："如果用户是活跃的，那么显示账号已暂停消息"——听到矛盾往往会暴露缺陷。
