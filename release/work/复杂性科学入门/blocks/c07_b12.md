#### 应用题

**Q4.** 实现不同 p 值的 Erdős-Rényi 模型，数值验证巨分量相变。使用 n=5000。绘制最大连通分量占 n 的比例随 np 从 0.5 到 3.0 的变化。

提示

NetworkX 有内置的 Erdős-Rényi 生成器和连通分量查找器。

**答案。** 示例代码：

    import networkx as nx
    import numpy as np
    import matplotlib.pyplot as plt

    n = 5000
    mean_degrees = np.linspace(0.5, 3.0, 25)
    sizes = []
    for kbar in mean_degrees:
        p = kbar / (n - 1)
        G = nx.erdos_renyi_graph(n, p)
        largest = max(nx.connected_components(G), key=len)
        sizes.append(len(largest) / n)

    plt.plot(mean_degrees, sizes, 'o-')
    plt.axvline(1.0, ls='--', color='red')
    plt.xlabel('mean degree')
    plt.ylabel('largest component / n')
    plt.show()


所得图应显示在平均度 1 处有清晰的相变：对于 \bar{k} < 1，最大分量很小（不到图的 5%）；对于 \bar{k} > 1，它连续增长到 \bar{k}=3 时涵盖图的绝大部分。在 \bar{k}=1 处，最大分量约 5% 到 10%（临界标度 n^{2/3}/n = n^{-1/3} ≈ 0.06，对于 n=5000）。转变比 n=1000 时更尖锐，因为有限尺寸效应更小。

经验曲线与理论公式紧密匹配：s = 1 - e^{-\bar{k} s}，其中 s 是巨分量大小。这一隐式方程仅在 \bar{k} > 1 时有非平凡解。对于 n=5000，理论与模拟的匹配非常好。

**Q5.** 在 NetworkX 中构造 Zachary 空手道俱乐部图（内置：`nx.karate_club_graph()`）。计算每个节点的四种中心性度量（度、介数、特征向量、PageRank）。按每种度量识别前 3 个节点。前 3 列表之间有多少重叠？评论解释。

提示

空手道俱乐部图有 34 个节点，其中两个是分裂俱乐部的派系创始人。

**答案。** 示例代码：

    import networkx as nx
    G = nx.karate_club_graph()
    deg = nx.degree_centrality(G)
    btw = nx.betweenness_centrality(G)
    eig = nx.eigenvector_centrality(G)
    pr = nx.pagerank(G)

    for name, cen in [('degree', deg), ('between', btw), ('eigen', eig), ('pagerank', pr)]:
        top3 = sorted(cen.items(), key=lambda x: -x[1])[:3]
        print(name, top3)


预期输出（NetworkX 使用 0 索引节点；著名节点是 0（Mr. Hi，教练）和 33（John A.，主席））：

- 度前 3：{33, 0, 32}
- 介数前 3：{0, 33, 32}
- 特征向量前 3：{33, 0, 2}
- PageRank 前 3：{33, 0, 32}

重叠是显著的：节点 0 和 33（两个派系领袖）在所有四种度量的前 3 中。节点 32 出现在四种中的三种；节点 2 仅出现在特征向量排名中。

解释是四种中心性度量对于这个小而均匀的图在 _最中心_ 节点（0 和 33）上是一致的。它们在第三名上略有分歧：节点 2 和 32 捕捉了"重要邻居"结构的略微不同方面。实践中，当度量在前 K 列表上一致时，排名是稳健的；当它们不一致时，不一致本身关于图的结构是有信息量的。
