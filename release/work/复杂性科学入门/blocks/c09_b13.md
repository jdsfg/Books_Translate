(a) 随机接种：最终流行病规模约为原始网络的 60% 到 80%。随机接种主要移除低度节点（因为无标度网络上大多数节点是低度的），几乎不干扰枢纽-辐射传播骨干。

(b) 定向接种：最终流行病规模约 5% 到 20%。移除最高度的 10% 节点碎片化网络并禁用枢纽骨干。大多数爆发在达到实质规模前消亡。

(c) 熟人免疫：最终流行病规模约 15% 到 30%。比随机好约三到五倍（因为友谊悖论使被提名者偏向更高度节点），但比定向差（因为熟人免疫是统计性的，错过某些枢纽同时免疫某些低度节点）。

定性排序 (b) < (c) < (a) 在参数选择和网络种子间稳健。定量差距取决于具体参数但通常很大：随机和定向接种策略之间最终流行病规模有 2 到 5 倍的差距。这是 2000 年代后期开发的网络感知公共卫生策略及 COVID-19 大流行期间应用的实证依据。

**Q6.** 考虑 n=1000, k=8, p_w=0.05 的 Watts-Strogatz 网络上的 Granovetter 阈值模型。每个代理在至少 30% 的邻居已采纳时采纳行为。初始时，小比例 s_0 的代理被设为采纳者。对 s_0 = 0.05, 0.1, 0.15, 0.2, 0.25，模拟动力学直到稳态并报告最终采纳者比例。讨论阈值行为。

提示

在每步，对每个代理，检查其当前邻居中至少 30% 是否已采纳；如是，代理采纳。

**答案。** 示例代码：

    import networkx as nx, numpy as np

    G = nx.watts_strogatz_graph(1000, 8, 0.05)
    threshold = 0.3
    results = {}
    for s0 in [0.05, 0.1, 0.15, 0.2, 0.25]:
        seeds = set(np.random.choice(1000, int(s0*1000), replace=False))
        adopted = set(seeds)
        while True:
            new_adopt = set()
            for n in G.nodes():
                if n in adopted: continue
                nbs = list(G.neighbors(n))
                if sum(1 for nb in nbs if nb in adopted) / len(nbs) >= threshold:
                    new_adopt.add(n)
            if not new_adopt: break
            adopted |= new_adopt
        results[s0] = len(adopted) / 1000
    print(results)


典型结果：

- s_0 = 0.05：最终比例约 0.05（种子保持孤立；无传播）。
- s_0 = 0.10：最终比例约 0.10 到 0.15（轻微传播但消亡）。
- s_0 = 0.15：最终比例约 0.20 到 0.40（某些簇起飞）。
- s_0 = 0.20：最终比例约 0.60 到 0.85（广泛级联）。
- s_0 = 0.25：最终比例约 0.95+（几乎完全采纳）。

行为显示临界阈值模式：小种子比例几乎不产生传播，而约 15% 到 20% 以上的种子比例产生广泛级联。阈值取决于网络结构和采纳阈值；对于 WS 小世界网络，所选参数下临界种子比例在 15% 到 25% 范围内。
