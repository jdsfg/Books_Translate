### 9.4 平均场理论

相变最简单的解析方法是_平均场理论_。思想是用自旋与所有自旋产生的平均（"平均场"）的相互作用来替代自旋与邻居的实际相互作用。这解耦了自旋并给出可处理的方程。

对于 Ising 模型的平均场近似：每个自旋看到有效场 h_{eff} = h + Jzm，其中 z 是配位数（邻居数），m 是平均磁化，我们已用平均值替代实际邻居构型。

每个自旋按玻尔兹曼分布与此有效场对齐：s = +1 的概率为 P_+ = e^{h_{eff}/(k_B T)} / [e^{h_{eff}/(k_B T)} + e^{-h_{eff}/(k_B T)}]，s = -1 类似。期望自旋值为

\langle s \rangle = P_+ - P_- = \tanh(h_{eff}/(k_B T)) = \tanh\left[\frac{h + J z m}{k_B T}\right].

为自洽，此期望自旋值必须等于 m（我们用来计算有效场的平均）。所以我们有_自洽方程_

m = \tanh\left[\frac{h + J z m}{k_B T}\right].

对于零外场（h = 0），变为

m = \tanh\left[\frac{J z m}{k_B T}\right].

> **记号说明**：§9.2 用 β（无下标）表示序参量临界指数，例如 2D Ising 的 β = 1/8。统计力学中逆温度的传统符号也是 β。为避免本章内混淆，我们将逆温度显式写为 1/(k_B T) 而非引入单独符号。某些教材用 β_{exp} 和 β_{temp} 区分；我们偏好显式形式。

对于高温（小 Jz/(k_B T)），唯一解为 m = 0：无自发磁化。对于低温（大 Jz/(k_B T)），有三个解：m = 0（不稳定）和 m = ±m_0（m_0 > 0，稳定）。转变发生在 tanh(Jzm/(k_B T)) 在 m = 0 处的斜率恰好等于 1 时，即

\frac{J z}{k_B T_c} = 1, \quad k_B T_c = J z.

平均场临界温度正比于耦合和配位数。对于方格上的 2D Ising，z = 4，给出 k_B T_c^{MF} = 4J。Onsager 的精确值为 k_B T_c ≈ 2.269J，所以平均场高估约 75%。平均场理论定性正确（它预测了转变）但定量不准确，因为它忽略了涨落。

在转变附近（小 m），令 u = Jz/(k_B T) 简写，展开 tanh(um) ≈ um - (1/3)(um)^3。代入并整理：

m = um - \frac{(um)^3}{3}

m\left[1 - u + \frac{u^3 m^2}{3}\right] = 0.

对于 m ≠ 0：

m^2 = \frac{3(u - 1)}{u^3}.
