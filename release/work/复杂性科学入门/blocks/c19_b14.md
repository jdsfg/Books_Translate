**Q8.** 在本书中我们使用了三条故事线（A：逻辑斯蒂映射和混沌；B：幂律作为普遍特征；C：聚合结果背离个体意图）作为贯穿线索。每条故事线回到具体里程碑章节进一步发展。读完本书后，识别你希望本书发展的第四条故事线。描述它：贯穿主张是什么，在哪些现有章节中出现（也许隐含地），显式里程碑发展章节会在哪里，以及为什么你觉得此线索值得追踪？

提示

候选："计算在物理和生物系统中的角色"；"均值和方差推理对重尾现象的失败"；"数学类比与物理机制之间的差距"；"AI/ML 对复杂性科学增加了什么（以及没有增加什么）"。

**讨论（使用"跨物理和生物系统的计算"的代表性答案）：**

值得发展的第四条故事线将是："自然界中许多系统可以有效地被视为执行计算，无论它们是否被设计来如此。"贯穿主张是相同的算法和计算框架（状态空间、转换、计算不可约性、甚至普适性结果）适用于物理系统（沙堆、流体流动、晶体生长）、生物系统（免疫系统克隆选择、蚁群觅食、神经处理）、社会系统（市场、投票、分布式协调）和工程系统（元胞自动机、神经网络、分布式算法）——且认识到此共享计算基底本身就是复杂性科学最深刻的贡献之一。

此故事线在现有书中隐含出现的地方：第1章 §1.2 讨论蚁群作为"分布式计算"；第12章发展元胞自动机作为通用计算机；第15章 §15.5 讨论 LLM"涌现能力"作为计算系统中弱涌现的一种形式；第5章结语将萤火虫同步现象框架化为萤火虫"做物理一直在做的事"。连接被做出但没有显式串联。显式里程碑发展章节将：在第1章引入故事线（与故事线 A 和 C 并行）；在第12章形式化"什么算作计算"（与普适性结果并行）；在目前不存在的章节中将视角应用于大脑（在第10章神经雪崩和第13章 Boids 之间）；并在第17章诚实审计（其中"计算"作为隐喻的宽松使用常做的是修辞而非分析工作）。

此故事线值得追踪的原因：它将以当前三条故事线没有的方式统一本书的生物、社会和工程例子。故事线 A 是数学的（一个方程）；故事线 B 是统计的（一种分布形状）；故事线 C 是结构的（微观和宏观之间的关系）。计算故事线将是认识论的：认识到我们视为"做计算"的系统和我们视为"运行自然过程"的系统常是从不同角度看的相同系统。本书将获得跨学科认识的第四透镜。
