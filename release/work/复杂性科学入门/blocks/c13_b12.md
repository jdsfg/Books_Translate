#### 应用题

**Q4.** 在 50×50 环面格上实现 Conway 的生命游戏。从随机初始条件开始（每个细胞以 0.3 概率活）。运行 200 步并报告最终人口（活细胞数）、存在的不同稳定模式数（静物和振荡器）以及出现的任何滑翔机。

提示

使用 §12.2 的代码。模拟后，可以通过检查哪些模式在连续（或隔帧）帧间持续来识别静物和振荡器。

**答案。** 示例分析（结果因随机种子而异）：

从 50×50 格 30% 密度开始，200 步后典型结果约 100 到 150 个活细胞，稳定为约 10 到 20 个不同静物模式（主要是方块、蜂巢和面包）加 2 到 5 个振荡器（主要是闪烁器）。一两个滑翔机通常会出现，要么逃到边缘（在环面上"环绕"继续）要么与稳定模式碰撞自毁。

初始人口存活到第 200 步的比例约 5 到 10%；其余细胞在模拟过程中死亡。动力学显示特征性生命游戏模式：快速初始消亡、小稳定结构形成、以及剩余不稳定模式逐渐消除的缓慢精炼。

对相同初始条件，运行 1000 步将产生基本相同的结果；最终状态通常在几百步内达到并此后保持稳定。这与 R-五连块等"玛士撒拉"起始构型形成对比，后者需要超过千步才稳定。

**Q5.** 实现并可视化初等 CA 规则 110，从 200 细胞行中的单个活细胞开始。运行 200 步。在所得时空图中识别（视觉或计算上）至少三种不同的局部传播结构（滑翔机）。

提示

使用 §12.3 的代码。绘制时空图后，寻找在混沌背景中传播的重复对角条纹。

**答案。** 示例代码：

    import numpy as np, matplotlib.pyplot as plt

    n_cells, n_steps, rule = 200, 200, 110
    grid = np.zeros((n_steps, n_cells), dtype=int)
    grid[0, n_cells//2] = 1
    for t in range(n_steps - 1):
        for i in range(n_cells):
            idx = 4*grid[t, (i-1)%n_cells] + 2*grid[t, i] + grid[t, (i+1)%n_cells]
            grid[t+1, i] = (rule >> idx) & 1

    plt.imshow(grid, cmap='binary')
    plt.show()


输出显示标志性的规则 110 模式：从种子扩展的三角形状，内部结构由看似混沌的背景和清晰可见的对角条纹（滑翔机）组成。

在规则 110 中，著名滑翔机包括：

- "A 滑翔机"（也称"A1"），最慢的，每 7 个时间步移动 0 格。可见为带有微妙结构的静止对角条纹。
- "B 滑翔机"（B），每 13 个时间步向右移动 4 格。随机条件下最常见的滑翔机。
- "C 滑翔机"（C），更复杂，周期更长且速度不同。

学生的图通常显示几个 B 滑翔机（最易发现的）在混沌背景中对角传播。不太明显的滑翔机（A 和 C）也可能出现，取决于边界条件。
