#### 应用题

**Q4.** 通过在地图上直接测量（或使用已发表值），估计某个具体真实世界海岸线、河流系统或其他自然物体的分形维数。记录你的方法（使用了哪些尺度，如何计数）并与可获得的已发表值比较。

提示

你可以在打印的地图上执行盒计数，方法是在越来越精细的尺度上叠加网格并计算包含物体部分的网格单元数。绘制 ln N 对 ln(1/ε) 的图并读出斜率。

**答案。** 使用美国缅因州海岸线的示例答案。

打印缅因州海岸线的地图，使用几种不同尺度（一端分辨率足以看到所有海湾，另一端只看到大致轮廓）。叠加边长 ε 对应（真实世界单位）50 千米、25 千米、10 千米、5 千米、2 千米和 1 千米的网格。对每个网格，计算包含海岸线部分的单元数。

假设你找到以下计数：

* 50 千米：9 个单元
* 25 千米：22 个单元
* 10 千米：70 个单元
* 5 千米：180 个单元
* 2 千米：540 个单元
* 1 千米：1300 个单元

绘制 ln N 对 ln(1/ε) 的图。所得（近似线性）图的斜率就是分形维数。从这些数据得到的斜率约为

\frac{\ln 1300 - \ln 9}{\ln(1/1) - \ln(1/50)} = \frac{7.17 - 2.20}{0 - (-3.91)} = \frac{4.97}{3.91} \approx 1.27.

缅因州海岸线的测得分形维数约为 1.27，与地质文献中已发表的 1.25 至 1.30 相当。斜率在最大尺度处（海岸线由大致轮廓几何主导）和最小尺度处（个别岩石主导）略有不同，但在中间尺度范围内一致地约为 1.27。这是真实分形海岸线的经验标志。

**Q5.** 奇异吸引子分形维数的 Kaplan-Yorke 公式使用李雅普诺夫谱。假设一个三维混沌系统的李雅普诺夫指数为 (λ_1, λ_2, λ_3) = (0.5, 0, -1.5)。计算预测的吸引子分形维数。

提示

找到使 ∑_{i=1}^j λ_i ≥ 0 的最大 j，然后应用公式。

**答案。** ∑_{i=1}^1 λ_i = 0.5 ≥ 0 且 ∑_{i=1}^2 λ_i = 0.5 + 0 = 0.5 ≥ 0。第三个和 0.5 + 0 + (-1.5) = -1.0 为负。所以 j=2。Kaplan-Yorke 维数为

d_{KY} = 2 + \frac{0.5 + 0}{|-1.5|} = 2 + \frac{0.5}{1.5} = 2 + \frac{1}{3} \approx 2.33.

吸引子的维数约为 2.33：三维相空间中的（大致）二维曲面，额外的分数维来自解释吸引子轻微厚度的折叠结构。
