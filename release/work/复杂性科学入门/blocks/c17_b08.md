#### 概念检查

**Q1.** 用自己的话陈述 Simon 的近可分解性原则。给出一个满足近可分解性的系统和一个不满足的例子。

提示

近可分解性关于子系统内和子系统间交互的相对强度。

**答案.** Simon 的近可分解性原则：当系统的组件可以分组为内部交互远强于子系统间交互的子系统时，系统是近可分解的。子系统内动力学快速达到准平衡，而子系统间动力学演化更慢。因此，系统可以在子系统层面为许多目的分析，将子系统内动力学视为已稳定，将子系统间动力学视为缓慢变化的研究对象。

满足近可分解性的系统：人体。细胞在组织内强交互（化学和电信号、机械耦合），组织在器官内中等交互，器官通过系统信号（血液激素、神经系统信号）更弱地相互交互。细胞内动力学快（毫秒到秒）；组织内动力学更慢（秒到小时）；器官内动力学更慢（小时到天）。由于此时间尺度分离，每个层面可以某种程度上独立研究。

不满足近可分解性的系统：2008 年的全球金融系统。银行间风险敞口已增长到如此之大且如此互联，以至于雷曼兄弟的失败在几天内级联通过系统。企业内动力学、企业间动力学和国家间动力学都在大致相同的时间尺度上，没有哪个分析层面（单一银行、银行部门、国家经济）能完全捕捉展开的危机。系统不是近可分解的，许多机构的预测失败反映了这点。

**Q2.** 为什么层级组织在自然界如此普遍？给出三个理由。

提示

理由包括噪声下组装、模块化进化和功能专门化。

**答案.** 层级组织被偏好的三个理由：

_噪声条件下组装_（Simon 的论证）。复杂系统必须在持续扰动（错误、中断、环境噪声）下组装。有稳定子组件的层级系统比没有中间稳定点的单体系统更有可能被成功组装。这对生物组装（从单细胞发育）和工程组装（制造复杂设备）都成立。Simon 寓言的数学显示模块化层级的优势随系统复杂性指数增长。

_模块化进化_。层级系统可以通过一次修改一个模块来进化，而不需要跨整个系统的协调变化。进化通过小修改作用于现有结构；层级提供许多可单独修改的结构来工作。单体系统需要协调的多特征变化，这在随机突变下不太可能且会破坏现有功能。模块性本身是促进进一步进化的高度进化特征。
