### D.3 NetworkX

在附录 B.5-B.7 和 B.16 中用于图操作：随机图生成（Erdős-Rényi、Barabási-Albert、Watts-Strogatz）、连通分量、中心性度量、最短路径。

**优势：** 干净的 API、全面的覆盖、优秀的文档。约 10⁵ 节点以下图的正确工具。

**局限：** 纯 Python 实现，对超过 10⁶ 节点的图慢。对大规模工作，使用：

* graph-tool（C++ 后端，快得多，但更难安装）
* igraph（C 后端，快，更过程式 API）

对本书的一切，NetworkX 足够。

**陷阱：** NetworkX 默认为无向图。如果你想要有向图，显式使用 `nx.DiGraph()`。

### D.4 NetLogo

NetLogo 是基于代理建模的高级平台。它是标准教育 ABM 平台，有大量预构建模型库。

**推荐用途：** 用于 ABM 模型原型和教育探索。Modeling Commons 的模型库包括 Schelling 隔离、Boids、生命游戏和许多其他典范模型。

**优势：** 原型模型非常快；内置可视化；对非程序员可及。

**局限：** 对大型仿真（超过约 10⁴ 代理）慢；与更广泛 Python 数据科学生态系统的集成有限。

**对本书的建议：** 生产工作使用 Python（附录 B）；快速探索典范模型的变体使用 NetLogo。

从 netlogoweb.org 或官方网站下载桌面应用。

* * *


### D.5 Mesa

Mesa 是基于 Python 的代理建模框架，设计为 NetLogo 的对程序员更友好的替代。它与 Python 数据科学栈良好集成并支持比 NetLogo 更大的仿真。

**何时使用：** 你已超越 NetLogo 的性能，或你想将 ABM 与 NumPy/Pandas 分析管道集成，或你偏好 Python 而非 NetLogo 的 Logo 方言。

用 `pip install mesa` 或 `mamba install -c conda-forge mesa` 安装。

本书的 Schelling 和 Boids 实现（附录 B.11、B.12）是独立 Python；对更复杂的 ABM，Mesa 提供有用基础设施（调度器、数据收集、可视化）。

### D.6 Repast（仅提及）

Repast 是非常大代理模型（数百万代理）和高性能计算的选择。基于 Java；学习曲线更陡。主要用于性能比快速迭代更重要的研究应用。

对本书，你不需要 Repast。

### D.7 Jupyter notebooks

Jupyter notebooks 是 Python 中探索性科学计算的标准环境。本书的程序在 notebooks 中干净运行；只需将代码粘贴到单元格中。

**推荐设置：**


    mamba install -c conda-forge jupyter
    jupyter notebook    # or: jupyter lab


JupyterLab 是更现代的界面；经典 Jupyter Notebook 更简单有时更响应。

**附录 B 程序的推荐单元格布局：**

1. 单元格 1：导入
2. 单元格 2：函数定义
3. 单元格 3：参数和主仿真循环
4. 单元格 4：绘图

此结构让你用不同参数（单元格 3）重新运行仿真而无需重新导入或重新定义函数。
