### 17.5 故事线 C 审计：温和偏好真的产生极端结果吗？

故事线 C（聚合结果背离个体意图）是三条故事线中经验最稳健的。Schelling 模型及其许多扩展反复表明温和偏好结合简单移动规则产生极端聚类。对真实居住隔离、组织分类、在线社区形成和许多其他现象的经验工作确认机制在真实系统中运作。

定性主张（"聚合结果可以背离个体意图；温和偏好可以产生极端结果"）是稳健的。定量主张（精确的 Schelling 式聚类阈值；隔离效应的幅度）取决于模型和群体的细节，从模型到真实世界预测的直接映射参半。

故事线 C 的教训对政策讨论有实际影响。反歧视教育本身不够的论证（因为移动和选择的动力学即使从温和偏好也产生隔离）已影响住房、教育、工作场所和社区设计政策的思考。结构性干预方法（改变动力学而非仅偏好）在某些领域显示了真实世界成功，尽管有政策干预在复杂社会系统中常产生自身意外动力学的通常告诫。

故事线 C 审计是三者中最正面的：教训经验稳健、有实际含义、已影响真实政策讨论。这是复杂性科学贡献在其最佳状态的例子。
