这就是 _倍周期分岔通往混沌之路_。随着 r 从 1 增大到约 3.57，映射的长期行为通过一系列倍周期分岔（周期 1，然后 2，然后 4，然后 8，然后 16，然后 32，……）最终到达混沌。每次分岔发生的 r 值不是任意的。它们按照一个精确的模式越来越靠近，Mitchell Feigenbaum 在 1975 年发现了这个模式，我们将在 §3.4 中讨论。


### 3.2 分岔图

映射行为最清晰的视觉总结是 _分岔图_。横轴是参数 r，从 0 到 4。纵轴是序列访问的长期值（或多个值）。对每个 r，我们迭代映射很长时间（比如 1000 步）让它进入长期行为，然后在那个 r 处纵向绘制接下来的几百个值。

该图具有以下特征（读完本段后你应该能凭记忆画出）：

* 对于 0 < r ≤ 1：长期值为 0。种群消亡。
* 对于 1 < r ≤ 3：长期值是 (r-1)/r 处的单个非零不动点。对于 r=2，不动点在 0.5；对于 r=2.5，在 0.6；对于 r=3，在 2/3。
* 在 r=3 处：不动点变得不稳定，系统分岔为周期 2 轨道。图分裂为两支。
* 在 r ≈ 3.4495 处：每支再分裂，给出周期 4。
* 在 r ≈ 3.5441 处：每支再次分裂，给出周期 8。
* 在 r ≈ 3.5644 处：周期 16。
* 在 r ≈ 3.5688 处：周期 32。
* 在 r ≈ 3.5699 处：倍周期级岔 _累积_。超过此点，系统对大多数 r 是混沌的，其中穿插着周期行为的窗口。
* 最大可见的周期窗口在 r ≈ 3.83 附近：出现周期 3 轨道，然后倍增为 6、12、24，……并重新进入混沌。
* 在 r=4 处：系统完全混沌，长期值填满区间 [0, 1]。

如果你手边有 Python 解释器，以下代码可以生成该图：


    import numpy as np
    import matplotlib.pyplot as plt

    R = np.linspace(2.5, 4.0, 2000)
    x = 0.5 * np.ones_like(R)

    # Burn-in
    for _ in range(1000):
        x = R * x * (1 - x)

    # Plot
    points = []
    for _ in range(500):
        x = R * x * (1 - x)
        points.append(x.copy())
    points = np.array(points)

    plt.figure(figsize=(12, 8))
    plt.plot(np.tile(R, 500), points.flatten(), ',k', alpha=0.25)
    plt.xlabel('r')
    plt.ylabel('long-run x')
    plt.title('Bifurcation diagram of the logistic map')
    plt.show()


这幅图是 20 世纪数学中被复制最多的图像之一，这是有充分理由的。它看起来像一棵不断分支为越来越精细分形结构的树，周期行为的突然条带穿过混沌的暗区。我们将在第4章回到它的分形结构。目前，请内化它的形状：r < 3 时一条单干；3 < r < 3.57 时倍周期级岔；3.57 < r < 4 的大部区域为混沌体制，其中散布着周期窗口。
