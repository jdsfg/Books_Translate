**Q4.** 在 30×30 格上实现 2D Ising 模型的 Metropolis Monte Carlo 算法。在 T = 1.5J/k_B 到 T = 3.5J/k_B（以 k_B = J = 1 为单位）范围内运行模拟并测量每个温度下的平均磁化。绘制 |m| 对 T 并识别转变温度。

提示

Metropolis 算法：随机选一个自旋，计算翻转的能量变化 ΔE，以 min(1, e^{-ΔE/T}) 的概率接受翻转。测量前运行许多 sweep 平衡。

**答案。** 示例代码：

    import numpy as np
    import matplotlib.pyplot as plt

    def metropolis(L, T, n_sweeps):
        spins = np.random.choice([-1, 1], size=(L, L))
        for sweep in range(n_sweeps):
            for _ in range(L*L):
                i, j = np.random.randint(L), np.random.randint(L)
                s = spins[i, j]
                nb = (spins[(i+1)%L, j] + spins[(i-1)%L, j] +
                      spins[i, (j+1)%L] + spins[i, (j-1)%L])
                dE = 2 * s * nb
                if dE <= 0 or np.random.random() < np.exp(-dE/T):
                    spins[i, j] = -s
        return spins

    L = 30
    Ts = np.linspace(1.5, 3.5, 25)
    ms = []
    for T in Ts:
        s = metropolis(L, T, 1000)
        # Measure magnetization over the next 1000 sweeps, every 10 sweeps
        samples = []
        for _ in range(1000):
            for _ in range(L*L):
                i, j = np.random.randint(L), np.random.randint(L)
                sp = s[i, j]
                nb = s[(i+1)%L, j] + s[(i-1)%L, j] + s[i, (j+1)%L] + s[i, (j-1)%L]
                dE = 2 * sp * nb
                if dE <= 0 or np.random.random() < np.exp(-dE/T):
                    s[i, j] = -sp
            samples.append(np.abs(s.sum() / (L*L)))
        ms.append(np.mean(samples))

    plt.plot(Ts, ms, 'o-')
    plt.axvline(2.269, ls='--', color='red')
    plt.xlabel('T'); plt.ylabel('|m|'); plt.show()


图应显示磁化在 T = 2.27（精确 2D Ising 临界温度）附近急剧下降。T < T_c 时系统处于铁磁相，|m| 接近 1。T > T_c 时系统顺磁，|m| 接近 0（有限尺寸带来小涨落）。更大的格转变更尖锐；L = 30 时转变因有限尺寸效应有明显圆化。

在 T_c 附近（恰在其下）用双对数轴绘制 |m| 对 T 将显示预测标度 |m| ~ (T_c - T)^{1/8}；小指数使此标度缓慢（T_c - T 增加 10 倍只使 m 增加 10^{1/8} ≈ 1.33 倍），这就是为什么 2D Ising 的磁化即使在转变以下相当远处仍接近 0。
