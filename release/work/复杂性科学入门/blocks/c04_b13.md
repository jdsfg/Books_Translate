#### 应用题

**Q4.** 如果你手边有计算机，通过直接数值实验估计逻辑斯蒂映射在 r=3.7 处的李雅普诺夫指数。使用公式

\lambda \approx \frac{1}{N} \sum_{n=0}^{N-1} \ln |r(1 - 2 x_n)|

取 N=10000 和 x_0=0.5（经过 1000 步预热以进入吸引子）。简要评论结果的符号。

提示

用 Python 编写迭代代码并累加对数导数和。丢弃前 1000 次迭代作为预热。

**答案。** 以下 Python 代码执行该计算：

    import numpy as np
    r = 3.7
    x = 0.5
    # burn-in
    for _ in range(1000):
        x = r * x * (1 - x)
    # accumulate
    total = 0.0
    N = 10000
    for _ in range(N):
        total += np.log(abs(r * (1 - 2*x)))
        x = r * x * (1 - x)
    print(total / N)

结果约为 λ ≈ 0.36。符号为正，确认 r=3.7 处的映射处于混沌体制。解释是邻近轨迹每次迭代大约以 e^{0.36} ≈ 1.43 的因子分离。20 次迭代后，分离因子约为 1.43^{20} ≈ 700。因此千分之一的初始不确定性在大约 20 次迭代内增长到几乎完全不确定。r=3.7 处的系统是混沌的，但与 r=4 相比只是轻微混沌——在 r=4 处 λ=ln 2 ≈ 0.69，轨迹每次迭代以 2 倍分离。

**Q5.** 用二分搜索数值地找到逻辑斯蒂映射的前三个倍周期分岔值 r_1 < r_2 < r_3。（回忆 r_1=3 是第一个。）用这些值通过公式 δ ≈ (r_2 - r_1)/(r_3 - r_2) 估计 Feigenbaum 常数 δ。与精确值 δ ≈ 4.6692 比较。

提示

r_n 处的分岔是周期 2^n 轨道首次出现的值。你可以通过迭代足够长以稳定，然后检查接下来几次迭代中出现多少个不同的值来检测它。

**答案。** 从 §3.2 中列出的值：r_1=3.0，r_2 ≈ 3.4495，r_3 ≈ 3.5441。则

\delta \approx \frac{r_2 - r_1}{r_3 - r_2} = \frac{3.4495 - 3.0}{3.5441 - 3.4495} = \frac{0.4495}{0.0946} \approx 4.75.

这已经近似 Feigenbaum 常数 δ ≈ 4.6692，仅在第三次分岔处。包含更多分岔并对更高 n 使用 (r_n - r_{n-1})/(r_{n+1} - r_n)，到 n ≈ 6 时可收敛到 4 到 5 位小数。

这一数值练习在几分钟内展示了 Feigenbaum 的发现：一个自然界中的普适常数，可从一行迭代映射推导，支配着倍周期级岔向混沌收敛的速率。
