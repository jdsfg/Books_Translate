#### 应用题

**Q4.** 用代码实现 Kuramoto 模型，模拟 500 个振子的群体，自然频率从宽度参数为 1、中心在 0 的洛伦兹（柯西）分布中抽取。计算几个耦合强度 K 值（从 0 到 5）的稳态序参量。绘制 r 对 K 的图并识别临界耦合。与理论值 K_c = 2/(π · 1/π) = 2（单位洛伦兹分布）比较。

提示

洛伦兹分布可通过 ω = tan(π(u - 0.5)) 采样，其中 u ~ U(0, 1)。运行模拟后，对时间序列后半段平均 r。

**答案。** 示例代码：

    import numpy as np
    import matplotlib.pyplot as plt

    N = 500
    np.random.seed(0)
    omega = np.tan(np.pi * (np.random.rand(N) - 0.5))  # unit Lorentzian
    theta0 = 2 * np.pi * np.random.rand(N)
    dt = 0.05; T = 100

    K_values = np.linspace(0.5, 5.0, 10)
    r_steady = []
    for K in K_values:
        th = theta0.copy()
        rs = []
        for step in range(int(T/dt)):
            z = np.mean(np.exp(1j * th))
            r = np.abs(z)
            th = th + dt * (omega + K * r * np.sin(np.angle(z) - th))
            rs.append(r)
        # average over the second half
        r_steady.append(np.mean(rs[len(rs)//2:]))

    plt.plot(K_values, r_steady, 'o-')
    plt.axvline(2.0, ls='--', color='red')
    plt.xlabel('K'); plt.ylabel('steady-state r')
    plt.show()


图应显示 r 在 K ≲ 2 时约为零，在 K > 2 时随 K 增长，与理论值 K_c = 2 一致。增长在阈值上方约为 \sqrt{(K - K_c)/K_c}，如预测。数值曲线在阈值附近会略微圆滑（因为模拟中的有限尺寸效应；真正的尖锐转变只在 N → ∞ 极限下出现）。

**Q5.** 一个 500 人的真实观众在音乐会后鼓掌。假设每个人的拍手速率具有均值为 3 Hz、标准差为 1 Hz 的高斯分布，且每个人能听到所有其他人的鼓掌（因此耦合在 Kuramoto 意义上近似全耦合）。观众在什么耦合强度下会同步？

提示

对高斯分布应用 Kuramoto 公式 K_c = 2/(π g(\bar{ω}))。

**答案。** 均值为 3 Hz、标准差为 1 Hz 的高斯分布在均值处的峰值密度为 g(3) = 1/\sqrt{2π · 1²} = 1/\sqrt{2π} ≈ 0.399。代入：

K_c = \frac{2}{\pi \cdot 0.399} \approx 1.596.
