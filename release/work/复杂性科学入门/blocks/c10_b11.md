#### 概念检查

**Q1.** 区分一阶和二阶相变。各给出两个物理例子和一个非物理例子。

提示

一阶转变涉及不连续跳跃和潜热；二阶转变是连续的。

**答案。** 一阶转变涉及某热力学量在转变处的不连续跳跃，伴随潜热和两相在转变点共存的可能性。例子：水结冰（体积跳跃；潜热 334 J/g；冰和水可在 0 °C 共存）；液晶中的向列-各向同性转变（分子排列的突然无序化及伴随的潜热）。非物理例子：突然的银行挤兑（银行要么有信心要么没有；没有平滑的中间状态，转变不可逆除非外部干预）。

二阶（连续）转变涉及连续变化的序参量，无跳跃或潜热。序参量在一侧为零，在另一侧从零连续增长。例子：铁磁体的居里转变（磁化随温度降到居里点以下连续增长）；超导转变（超导序参量在临界温度以下连续增长）。非物理例子：Kuramoto 式耦合振子的同步（序参量在临界耦合以上连续增长）。

**Q2.** 定义 2D Ising 模型的_序参量_、_控制参量_和_临界指数_。给出 2D Ising 普适类的 β, γ, ν 值。

提示

2D Ising 值列在 §9.2 中。

**答案。** 对于 2D Ising 模型：

_序参量_是磁化 m，每格点的平均自旋。临界温度以上 m = 0；以下 m 从零连续增长。

_控制参量_是温度 T。转变发生在临界温度 T_c ≈ 2.269J/k_B。

_临界指数_描述各量随距临界点距离的标度。对于 2D Ising：

- β = 1/8：磁化在转变以下按 m ~ (T_c - T)^{1/8} 标度。
- γ = 7/4：磁化率按 χ ~ |T - T_c|^{-7/4} 发散。
- ν = 1：关联长度按 ξ ~ |T - T_c|^{-1} 发散。

这些指数满足标度关系 α + 2β + γ = 2，其中 2D Ising 的 α = 0（比热的对数发散）。

**Q3.** 为什么平均场理论对许多不同系统预测相同的临界指数？_上临界维度_的作用是什么？

提示

平均场理论忽略空间涨落；此近似在某维度以上变为精确。

**答案。** 平均场理论用平均值替代每个自由度实际涨落的局部环境。此近似使方程可处理但忽略了邻居间关联涨落的影响。所得临界指数（β = 1/2, γ = 1, α = 0, ν = 1/2）对任何此近似有效的系统都相同，无论微观细节如何。因此平均场是最简单的普适类。
