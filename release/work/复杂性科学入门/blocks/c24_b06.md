**幂律（Power law）。** 分布 P(x)∝x−γP(x) \propto x^{-\gamma}P(x)∝x−γ。_无标度_动力学的特征；出现在许多自然系统中。**定义：**第7章 §7.2；**发展：**第10章 §10.1。

**优先连接（Preferential attachment）。** 新边优先连接到现有高度顶点的增长机制；产生_无标度网络_。**定义：**第7章 §7.2。

**囚徒困境（Prisoner's Dilemma, PD）。** 互相合作是集体最优但个体理性导致互相背叛的两人博弈。典范_博弈论_模型。**定义：**第14章 §14.1。

**随机图（Random graph）。** 由随机过程生成的图。_Erdős-Rényi_是最简单模型。**定义：**第6章 §6.4。

**还原论（Reductionism）。** 将系统分解为部分并独立分析部分的科学策略。对许多问题成功但对_复杂系统_不完整。**定义：**第1章 §1.1。

**重整化群（Renormalization group）。** Wilson 发展的理论框架，通过跟踪系统在重复粗粒化下的行为来解释_相变_中的_普适性_。**提及：**第9章 §9.7。

**复制器动力学（Replicator dynamics）。** 策略按其相对适应度比例增长的进化博弈动力学。**定义：**第14章 §14.3。

**基本再生数（Reproduction number, basic, R0R_0R0​）。** 在完全易感人群中一个初始感染者产生的预期继发感染数。流行病阈值在 R0=1R_0 = 1R0​=1。**定义：**第8章 §8.1。

**沙堆模型（Sandpile model）。** Bak-Tang-Wiesenfeld 模型：在 2D 网格上投放沙粒，推倒超阈值细胞，测量雪崩大小分布。典范_自组织临界_系统。**定义：**第10章 §10.1。

**无标度网络（Scale-free network）。** _度分布_遵循_幂律_的网络。真实世界网络（万维网、互联网、社交）通常是无标度的。**定义：**第7章 §7.2。

**Schelling 隔离模型。** Schelling 1971 年的_基于代理的模型_：有温和同质性偏好的代理产生严重空间隔离。**定义：**第13章 §13.2；**预览：**第11章 §11.5。

**二阶相变（Second-order phase transition）。** 具有连续_序参量_的_相变_。_临界指数_表征_临界点_附近的奇异行为。**定义：**第9章 §9.1。

**自组织（Self-organization）。** 无外部组织力的情况下从局部交互中自发涌现有序结构。**定义：**第2章 §2.4。

**自组织临界性（Self-organized criticality, SOC）。** 系统自身动力学将其驱动到_临界点_而无需外部调谐的现象。**定义：**第10章 §10.1。

**自相似性（Self-similarity）。** 系统的一部分经适当缩放后看起来像整体的性质。在数学_分形_中精确；在真实世界分形对象中统计性。**定义：**第4章 §4.2。

**对初始条件的敏感依赖（Sensitive dependence on initial conditions）。** _混沌_系统的性质：邻近起点产生指数发散的轨迹。**定义：**第3章 §3.3。

**简单传染（Simple contagion）。** 单次接触即可传播的传播过程。传染病的典型特征。与_复杂传染_对比。**定义：**第8章 §8.4。

**Sierpinski 三角形。** 维度为 ln⁡3/ln⁡2≈1.585\ln 3 / \ln 2 \approx 1.585ln3/ln2≈1.585 的经典_分形_。**定义：**第4章 §4.2。

**SIR 模型。** 将人群分为易感、感染和恢复舱室的标准流行病模型。**定义：**第8章 §8.1。
