#### 巨分量相变

G(n, p) 最有趣的特征是 _巨分量相变_。定义 _巨分量_ 为图的最大连通分量。对于低边密度（小 p）的随机图，巨分量很小（其大小增长慢于 n）。对于 p 超过临界值，巨分量变为整个图的有限分数。

具体地，在 n → ∞ 极限下且 \bar{k} = np 固定：

- 对于 \bar{k} < 1：最大分量大小为 O(log n)，远小于 n。
- 对于 \bar{k} = 1：最大分量大小为 O(n^{2/3})，临界标度。
- 对于 \bar{k} > 1：最大分量大小为 sn，其中某个分数 s > 0 随 \bar{k} 增长。

在 \bar{k} = 1 处的转变在极限下是尖锐的，是具有与第5章和第9章相变相同结构特征的真正相变。序参量为 s（巨分量中顶点的比例）；控制参量为 \bar{k}；临界值为 \bar{k}_c = 1；序参量在阈值上方从零连续增长。

直觉是引人注目的。当你逐条向 n 个顶点上的空图添加边时，很长一段时间你得到许多小的互不连通的簇。在一个尖锐时刻（当平均度首次超过 1 时），小簇突然合并为一个包含所有顶点有限分数的巨分量。再加几条边，图的大部分变为连通。继续加，巨分量吸收几乎所有人。

这一相变有许多真实世界回响。电网、社会运动、流行病、道路网络：当其连通性越过阈值时都表现出定性相似的转变。Erdős-Rényi 结果是关于此类转变为何在任何以随机或近随机方式形成成对连接的系统中通有地发生的最清晰数学陈述。

#### 代码：模拟转变

    import numpy as np
    import networkx as nx
    import matplotlib.pyplot as plt

    n = 1000
    k_values = np.linspace(0.2, 3.0, 30)
    giant_size = []

    for k in k_values:
        p = k / (n - 1)
        G = nx.erdos_renyi_graph(n, p)
        largest_cc = max(nx.connected_components(G), key=len)
        giant_size.append(len(largest_cc) / n)

    plt.plot(k_values, giant_size, 'o-')
    plt.axvline(1.0, ls='--', color='red')
    plt.xlabel('mean degree')
    plt.ylabel('giant component size / n')
    plt.show()


图显示在 \bar{k} = 1 处有清晰的相变：巨分量在阈值以下本质为零，在阈值以上连续增长。n=1000 时转变不完全尖锐（有限尺寸效应），但 unmistakable。
