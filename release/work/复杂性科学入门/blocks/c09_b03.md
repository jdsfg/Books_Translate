#### 代码：模拟 SIR

    import numpy as np
    from scipy.integrate import solve_ivp
    import matplotlib.pyplot as plt

    def sir(t, y, beta, gamma, N):
        S, I, R = y
        return [-beta*S*I/N, beta*S*I/N - gamma*I, gamma*I]

    N = 1_000_000
    S0 = N - 100; I0 = 100; R0_init = 0
    beta, gamma = 0.4, 0.15  # R0 = beta/gamma = 2.67

    sol = solve_ivp(sir, (0, 200), [S0, I0, R0_init],
                    args=(beta, gamma, N),
                    t_eval=np.linspace(0, 200, 1000))

    plt.plot(sol.t, sol.y[0], label='S')
    plt.plot(sol.t, sol.y[1], label='I')
    plt.plot(sol.t, sol.y[2], label='R')
    plt.legend(); plt.xlabel('t'); plt.ylabel('count')
    plt.show()


图显示了经典流行病曲线：感染快速上升，约第 60 天达峰，随着易感池耗尽而下降。最终流行病规模 R(∞) 约为 92% 的人口，与最终规模方程预测一致。

### 8.2 网络上的 SIR

充分混合假设是一个强理想化。现实中，个体只与人口的一小部分（其社交和职业接触）交互，这些交互形成网络。为建模真实疾病传播，我们需要将 SIR 动学放在接触网络上。

设 G 为有 n 个节点和邻接矩阵 A 的网络。网络 SIR 模型为每个节点分配一个状态（S、I 或 R）并运行动力学：

- 在每个时间步，每个感染节点 i 以概率 β 感染每个易感邻居 j。
- 每个感染节点在每个时间步以概率 γ 康复。
- 康复节点免疫且不能再次感染。

传播率 β 现在是每条边每时间步，γ 是每时间步的康复率。网络上的有效 R_0 取决于动力学和网络结构：

R_0 = \frac{\beta}{\gamma} \cdot \frac{\langle k^2 \rangle - \langle k \rangle}{\langle k \rangle}.

右边的因子取决于网络的度分布。对于 Erdős-Rényi 图（泊松度），⟨k²⟩ = \bar{k}(1 + \bar{k})，因子简化为 \bar{k}：R_0 = (β/γ)\bar{k}。对于重尾度的无标度网络，⟨k²⟩ 可以远大于 ⟨k⟩，R_0 相应地大得多。
