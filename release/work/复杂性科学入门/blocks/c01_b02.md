#### 本书适合谁

本书面向跨学科的高年级本科生和研究生：物理学、生物学、神经科学、经济学、社会学、计算机科学和工程学。它假定读者熟悉微积分、基本线性代数（向量、矩阵、特征值）、初等概率论以及一定的编程经验（代码示例使用 Python 语言，但概念可以迁移）。不假定读者此前接触过复杂性科学。附录A为需要复习的读者提供了数学预备知识回顾。

没有受过这些领域正式大学训练但具有技术背景的好奇读者也能读懂本书，尽管某些章节会更具挑战性。每章末尾的练习分为三个层次：概念检查题（适合任何读者）、应用题（假定具备技术预备知识）和深入思考题（引导开放性反思）。每道深入思考题现在都附有一份"优秀回答应涉及哪些方面"的评分指南，指出一个深思熟虑的回答应当涵盖的维度——跳过技术练习的读者仍能获得概念性内容；做练习的读者则能更深入地内化方法论。

本书在数学上是严肃的，但数学分量并不重。书中出现的数学（逻辑斯蒂映射；用于中心性的矩阵特征值；用于相变的统计力学论证）按研究生物理标准来说是初等的，但都在做实实在在的工作。当本书要求你手动迭代逻辑斯蒂映射或计算一个混沌系统的李雅普诺夫指数时，这并非教学填充物；对这些现象的直觉来自亲手做迭代，而非仅仅阅读相关内容。
