#### 标准模式

生命游戏最引人注目的特性是从随机或简单起始构型中涌现的模式多样性。分类如下：

_静物_：永不改变的稳定构型。最简单的是_方块_（2×2 活细胞方阵）。其他包括_蜂巢_（六边形排列的六个细胞）、_船_、_面包_等。

_振荡器_：经过固定步数后回到原始状态的构型。最简单的是_闪烁器_（一行三个活细胞，以周期 2 在水平和垂直方向间振荡）。其他包括_蟾蜍_（周期 2）、_信标_（周期 2）、_脉冲星_（周期 3）和_十五振荡器_（周期 15）。

_飞船_：在空间中平移而不改变形状的构型。最简单的是_滑翔机_：五细胞构型，每 4 个时间步对角移动一格。其他包括_轻型飞船_、_中型飞船_和_重型飞船_，都水平移动。

_枪_：周期性发射飞船的构型。_Gosper 滑翔机枪_（Bill Gosper 于 1970 年发现的第一把枪）每 30 个时间步发射一个滑翔机。枪解决了生命游戏是否有界人口的问题：没有。

_玛士撒拉_：在稳定前演化很长时间的小起始构型。R-五连块（R 形五个细胞）演化 1103 代后才稳定为静物、振荡器和滑翔机的稳定混合。橡子（七个细胞）演化 5206 代。

_通用模式_：当正确排列时可以计算任意函数的构型。生命游戏是图灵完备的；你可以在格中使用滑翔机和其他模式构造逻辑与、或、非门、存储单元和时钟。Paul Rendell 于 2010 年在生命游戏中实现了完整图灵机，使用数千个基于滑翔机的组件。

#### 代码：实现生命游戏


    import numpy as np
    import matplotlib.pyplot as plt
    from matplotlib.animation import FuncAnimation

    def step(grid):
        n = grid.shape[0]
        nbcount = np.zeros_like(grid)
        for di in [-1, 0, 1]:
            for dj in [-1, 0, 1]:
                if di == 0 and dj == 0: continue
                nbcount += np.roll(np.roll(grid, di, 0), dj, 1)
        born = (grid == 0) & (nbcount == 3)
        survive = (grid == 1) & ((nbcount == 2) | (nbcount == 3))
        return (born | survive).astype(int)

    # Random initial condition
    np.random.seed(42)
    grid = np.random.choice([0, 1], size=(60, 60), p=[0.7, 0.3])

    fig, ax = plt.subplots()
    im = ax.imshow(grid, cmap='binary')
    def update(frame):
        global grid
        grid = step(grid)
        im.set_data(grid)
        return im,
    ani = FuncAnimation(fig, update, frames=100, interval=100)
    plt.show()


运行此代码，你将在几百步内看到随机初始模式演化为静物、振荡器和几个逃向边缘的滑翔机的稳定构型。总活细胞数波动并逐渐减少直到达到稳态。如此简单规则产生的丰富行为使生命游戏成为标志。
