### 12.3 初等元胞自动机：Wolfram 分类

生命游戏是具有两态和 Moore 邻域的 2D CA。最简单的可能 CA 是_初等元胞自动机_（ECA）：1D、两态、三细胞邻域（细胞本身及其两个紧邻）。不同 ECA 规则的总数有限：2^{2^3} = 256。每条规则由 3 比特输入（细胞及其邻居的当前状态）和 1 比特输出（细胞的下一状态）指定，给出 2^3 = 8 种输入组合和 2^8 = 256 种可能规则。

每条规则按惯例编号 0 到 255，将 8 比特输出序列（对应输入 111、110、101、100、011、010、001、000 的顺序）解释为二进制数。规则 30 是对输入 111 输出 0、110 输出 0、101 输出 0、100 输出 1、011 输出 1、010 输出 1、001 输出 1、000 输出 0 的规则（30 的二进制表示为 00011110）。

Stephen Wolfram 从 1983 年开始，在其 2002 年著作《A New Kind of Science》中达到顶峰，系统模拟了全部 256 条 ECA 规则，观察到它们落入四个行为类：

_类 1_：长期行为无论初始条件如何都均匀的规则。所有细胞最终变为 0（或全 1）。例子：规则 0、规则 8、规则 32。这些是"冻结"CA。

_类 2_：长期行为周期的规则。模式稳定为有限组重复构型。例子：规则 4、规则 19、规则 51。这些是"周期"CA。

_类 3_：长期行为混沌的规则。模式统计复杂且无明显结构，类似随机噪声但由确定性规则生成。例子：规则 30、规则 90、规则 150。这些是"混沌"CA。

_类 4_：长期行为复杂的规则，具有嵌入在混沌或结构化背景中的精细局部结构（类似生命游戏中的滑翔机）。例子：规则 110、规则 54。这些是"复杂"CA，最稀有的类。

四类让人想起我们在逻辑斯蒂映射（第3章）中看到的体制：不动点（类 1）、周期轨道（类 2）、混沌（类 3）和混沌边缘（类 4）。故事线 A 回归：逻辑斯蒂映射和初等元胞自动机，尽管数学结构不同（连续映射迭代 vs 离散格更新），共享动力学体制的四重定性分类。这是复杂性科学现象跨非常不同的数学系统共享深层结构特征的早期暗示之一。
