注意：b 值因地区和断层类型略有变化。俯冲带 b 值常接近 1.0；像圣安德烈亚斯这样的转换断层 b 值接近 0.9。火山地区 b 值更高，常超过 1.5。这些差异本身提供了关于局部应力状态和断层几何的信息。

**Q6.** 一份神经记录产生了一系列"雪崩"事件规模，计数如下（大致对数分箱）：规模 1（计数 8000），规模 2（计数 3500），规模 5（计数 1100），规模 10（计数 480），规模 20（计数 200），规模 50（计数 70），规模 100（计数 28），规模 200（计数 10），规模 500（计数 3）。用 Clauset、Shalizi 和 Newman 的最大似然方法估计幂律指数 τ。

提示

幂律分布的 MLE 为 τ̂ = 1 + n / \sum_i \ln(s_i / s_{min})，其中 s_{min} 为下截断。

**答案。** 将数据近似为连续的（使用分箱中心）并应用 MLE。本练习取 s_{min} = 1（更仔细的分析会优化 s_{min}）。

总事件数：n = 8000 + 3500 + 1100 + 480 + 200 + 70 + 28 + 10 + 3 = 13391。对数规模之和（将分箱中心视为代表值）：

\sum \ln s_i ≈ 8000·ln 1 + 3500·ln 2 + 1100·ln 5 + 480·ln 10 + 200·ln 20 + 70·ln 50 + 28·ln 100 + 10·ln 200 + 3·ln 500

≈ 0 + 2426 + 1771 + 1105 + 599 + 274 + 129 + 53 + 19 ≈ 6376.

则

τ̂ = 1 + n / \sum \ln(s_i / s_{min}) = 1 + 13391 / 6376 ≈ 1 + 2.10 = 3.10.

此估计值 3.10 与分支过程临界值 ≈ 1.5 大幅偏离。原因是分箱中心近似对于跨宽范围的分箱是粗糙的（例如将"规模 5，计数 1100"视为所有 1100 个事件恰好规模 5），这使对数和向下偏移并膨胀 τ̂。更仔细的分析按分箱内实际期望对数规模加权每个分箱的贡献并优化 s_{min}。进行此修正后给出 τ̂ ≈ 1.5 到 1.7，取决于截断和假设，与分支过程临界值 1.5 加有限样本统计噪声一致。

更深层教训：从真实数据估计幂律指数需要仔细处理分箱、截断和标度区间的选择。Clauset、Shalizi 和 Newman 在其 2009 年幂律分析论文中提供了严格方法；在发表任何幂律拟合前这是必读文献。
