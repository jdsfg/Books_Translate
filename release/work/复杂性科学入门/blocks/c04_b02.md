### 3.1 映射本身

考虑方程

x_{n+1} = r\,x_n(1 - x_n)

其中 x_n 是 0 到 1 之间的数，r 是一个参数（可以将其视为"增长率"或"强度"），我们将在 0 到 4 之间变化它。方程说的是：取当前值 x_n，计算 r\,x_n(1-x_n)，将其作为下一个值 x_{n+1}。然后迭代。给定 x_0，该规则生成一个无穷序列 x_0, x_1, x_2, …。

这个方程从何而来？它是一个种群（比如某季节的昆虫）受自身规模限制增长的最简单模型。因子 r\,x_n 代表种群指数增长的趋势；因子 (1-x_n) 代表种群接近承载容量（此标度中的"1"）时施加的限制。将两者结合就得到同时捕捉增长和自限制的最简单方程。Robert May，一位在生态学领域工作的澳大利亚生物学家，在 1976 年一篇著名的 _Nature_ 论文中推广了这个方程，将其惊人特性带入了广泛的科学视野。

注意方程的三个特征。它是 _确定性的_：给定 x_0 和 r，整个序列就固定了。没有任何随机性。它是 _一维的_：每一步只涉及一个数。它是 _非线性的_：右边包含乘积 x_n · x_n，而不仅仅是 x_n 的倍数。非线性是温和的（一个二次项），然而它足以产生本质上所有那些更精巧的洛伦兹方程所产生的东西。这是本章的第一个深刻教训：_混沌不需要复杂的方程_。它只需要非线性和迭代。

让我们手动迭代。取 r=2.5 和 x_0=0.4。则：

* x_1 = 2.5 · 0.4 · (1 - 0.4) = 2.5 · 0.4 · 0.6 = 0.6
* x_2 = 2.5 · 0.6 · 0.4 = 0.6

序列已到达不动点 0.6。继续迭代无限给出相同的值。对于 r=2.5，无论你选择什么初始 x_0（除了 0 或 1），序列都收敛到 0.6。

现在取 r=3.2 和 x_0=0.5：

* x_1 = 3.2 · 0.5 · 0.5 = 0.8
* x_2 = 3.2 · 0.8 · 0.2 = 0.512
* x_3 = 3.2 · 0.512 · 0.488 ≈ 0.7995
* x_4 ≈ 3.2 · 0.7995 · 0.2005 ≈ 0.5129
* x_5 ≈ 0.7995

序列在约 0.5130 和 0.7995 之间跳动。它进入了一个 _周期 2 轨道_：它访问两个值并交替。

现在取 r=3.5 和 x_0=0.5。经过足够多次迭代进入长期行为后，序列循环访问 4 个不同的值：一个周期 4 轨道。在 r=3.55 时，它访问 8 个值。在 r=3.567 时，16 个值。然后，大约在 r=3.57 附近，倍周期不再干净，序列变得表面随机，访问永不重复的值。
