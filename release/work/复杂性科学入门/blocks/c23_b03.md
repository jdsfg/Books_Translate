### D.8 性能提示

对附录 B 中的程序，性能通常不是问题（大多数在标准笔记本上不到一分钟运行完）。如果你扩展程序并发现它运行缓慢：

1. **先分析。** 在 Jupyter 中使用 `%timeit` 或 `python -m cProfile script.py` 识别实际瓶颈。瓶颈很少在你以为的地方。
2. **向量化。** 用 NumPy 对整个数组的操作替换 Python `for` 循环。加速常达 100 倍或更多。
3. **使用正确数据结构。** NetworkX 方便但慢；对性能关键的图代码，切换到使用 NumPy 或稀疏矩阵的邻接矩阵表示。
4. **对热循环使用 Numba 或 Cython。** 如果函数必须在 Python 循环中且不能向量化，`@numba.jit` 装饰器可以以最小代码改动给出 10-100 倍加速。
5. **并行运行。** 对尴尬并行任务（运行许多独立仿真），使用 `multiprocessing.Pool` 跨核分配。

对附录 B 中给定参数规模的典范模型，这些优化都不需要。

### D.9 可重现性

附录 B 中每个使用随机性的程序在开始时设置 `np.random.seed(42)`（或等价）。这使程序可重现：运行两次给出相同输出。

**对你自己的工作：**

* 始终显式设置随机种子。可重现性是调试的前提条件。
* 存储仿真结果时连同参数一起保存随机种子。
* 对 ABM，显式记录更新顺序（顺序 vs 同步、邻居迭代顺序）。不同顺序可给出显著不同的结果。
* 对已发表工作，遵循 ABM 模型描述的 ODD 协议。
