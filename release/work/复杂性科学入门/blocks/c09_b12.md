**Q4.** 在 n=1000, m=3 的 Barabási-Albert 网络上实现 SIR 模型。运行随机模拟，β=0.05（每时间步每条 S-I 边）和 γ=0.1（每时间步每个 I 节点）。从一个随机选择的感染节点开始。运行 100 次模拟并绘制度最终流行病规模（最终被感染的节点比例）的分布。

提示

在每个时间步，遍历边或感染节点；以概率 β 传播，以概率 γ 康复。

**答案。** 示例代码：

    import networkx as nx, numpy as np, matplotlib.pyplot as plt, random

    def sim_sir(G, beta, gamma, seed_node):
        state = {n: 'S' for n in G.nodes()}
        state[seed_node] = 'I'
        while any(s == 'I' for s in state.values()):
            new_state = state.copy()
            for n in G.nodes():
                if state[n] == 'I':
                    if random.random() < gamma:
                        new_state[n] = 'R'
                    for nb in G.neighbors(n):
                        if state[nb] == 'S' and random.random() < beta:
                            new_state[nb] = 'I'
            state = new_state
        return sum(1 for s in state.values() if s == 'R') / len(state)

    G = nx.barabasi_albert_graph(1000, 3)
    sizes = [sim_sir(G, 0.05, 0.1, random.choice(list(G.nodes()))) for _ in range(100)]
    plt.hist(sizes, bins=30)
    plt.xlabel('final epidemic fraction')
    plt.show()


直方图应显示双峰分布。相当一部分模拟（取决于参数和网络种子）以非常小的爆发结束（流行病因种子不幸运而快速消亡），其余以影响网络大部分的大爆发结束。在 m=3 的 BA 网络上 β=0.05, γ=0.1，大爆发通常感染网络的 70% 到 90%，小爆发感染不到 5%。双峰性是真实网络上随机流行病的特征：要么种子位置好（通常靠近枢纽）爆发起飞，要么位置不好而消亡。
