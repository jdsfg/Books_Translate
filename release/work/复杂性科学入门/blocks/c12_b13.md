- 5%：长期 +1 比例 ≈ 0.05 ± 0.01（仅承诺代理自身；少数派不传播）
- 10%：+1 比例 ≈ 0.10 ± 0.05（极少传播）
- 15%：+1 比例 ≈ 0.20 ± 0.15（显著方差；有时传播，有时不）
- 20%：+1 比例 ≈ 0.50 ± 0.30（常翻转群体）
- 25%：+1 比例 ≈ 0.75 ± 0.20（通常翻转）
- 30%：+1 比例 ≈ 0.95 ± 0.05（几乎总是翻转）

从"少数派不传播"到"少数派主导"的转变在此简单 1D Sznajd 模型中集中在 15-20% 附近，阈值附近有显著变异性反映动力学的随机性质。定性模式与 Centola 发现一致（尖锐阈值；以下少数派无关；以上少数派主导）。

此 1D 模型的阈值略低于 Centola 的 25%，因为更简单的网络和 1D 维度。在更高维网络中，阈值倾向于更高。

**Q6.** 假设你观察一个真实社交媒体平台，其级联规模分布遵循幂律，指数 τ = 2.0。所有级联中"大"级联（规模 > 1000）占多少比例？总内容曝光中来自这些大级联的占多少比例？计算，假设分布 P(s) = (τ-1) s^{-τ}，s ≥ 1。

提示

大级联比例为 \int_{1000}^\infty P(s) ds。总曝光比例为 \int_{1000}^\infty s P(s) ds / \int_1^\infty s P(s) ds。

**答案。** 以 P(s) = s^{-2}，s ≥ 1，归一化使 \int_1^\infty P(s) ds = 1：

s > 1000 的级联比例：

\int_{1000}^\infty s^{-2} ds = 1/1000 = 0.001 = 0.1%.

仅 0.1% 的级联是"大"的。

但总内容曝光为 \sum s · P(s)。对 P(s) = s^{-2}，积分 \int_1^\infty s · s^{-2} ds = \int_1^\infty s^{-1} ds 对数发散。实践中，以系统大小为有限截断，积分有限但严重偏向尾部。

如果设截断 s_max = 10^6，总曝光为 \int_1^{10^6} s^{-1} ds = ln 10^6 ≈ 13.8。s > 1000 的曝光为 \int_{1000}^{10^6} s^{-1} ds = ln(10^6/1000) = ln 1000 ≈ 6.9。所以大级联产生约 50% 的总曝光，尽管只占级联的 0.1%。

这是重尾分布对社交媒体的实际后果：极小比例的级联产生大部分总曝光。平均级联规模被罕见大事件主导；中位级联规模远小于均值。描述平台"平均"内容的统计遗漏了大多数人实际看到的，那被超级级联主导。

这对内容审核和政策有直接含义。关注典型级联的策略对整体曝光影响可忽略；关注罕见大级联的策略有超比例影响。现代平台审核反映此不对称性，对病毒内容的审查远多于典型内容。
