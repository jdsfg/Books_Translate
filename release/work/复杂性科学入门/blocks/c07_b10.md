两种度量捕捉不同的东西。度中心性关于量；特征向量中心性关于连接的质量。一个实践含义：当你研究任何真实网络时，计算多种中心性度量并比较它们。度量之间的差异常常揭示任何单一度量会遗漏的有趣结构特征。

**Q3.** 对一个小图应用 PageRank 公式：3 个顶点 A、B、C，有向边 A→B, B→C, C→A, C→B。使用阻尼因子 d=0.85。从初始值 PR(A)=PR(B)=PR(C)=1/3 开始迭代递推计算所有三个顶点的 PageRank 值。

提示

出度：L(A)=1, L(B)=1, L(C)=2。迭代公式数次直到值稳定。

**答案。** 出度：L(A)=1, L(B)=1, L(C)=2。初始值 PR(A)=PR(B)=PR(C)=1/3 ≈ 0.333。应用递推：

PR(A) = (1-0.85)/3 + 0.85·PR(C)/L(C) = 0.05 + 0.85·0.333/2 = 0.05 + 0.142 = 0.192
PR(B) = 0.05 + 0.85·[PR(A)/L(A) + PR(C)/L(C)] = 0.05 + 0.85·[0.333 + 0.167] = 0.05 + 0.425 = 0.475
PR(C) = 0.05 + 0.85·PR(B)/L(B) = 0.05 + 0.85·0.333 = 0.333

迭代 2（使用新值）：

PR(A) = 0.05 + 0.85·0.333/2 = 0.192
PR(B) = 0.05 + 0.85·[0.192 + 0.167] = 0.05 + 0.305 = 0.355
PR(C) = 0.05 + 0.85·0.475 = 0.454

注意 PR(B) 从迭代 1 的 0.475 跳到迭代 2 的 0.355，而 PR(C) 从 0.333 升到 0.454。值在振荡，因为图包含反馈环（A→B→C→A）加一条侧边（C→B）。每次迭代沿环"运送"权重：B 在迭代 1 中从 A 的全部投票获得的提升在迭代 2 中传播到 C；C 的升高值然后在迭代 3 中传播回 A 和 B。

振荡在约十次迭代内衰减，值收敛到稳态 PR(A) ≈ 0.215, PR(B) ≈ 0.397, PR(C) ≈ 0.388。顶点 B 的 PageRank 最高，因为它接收 A 的全部投票（A 只有一条出链）和 C 的半票（C 有两条出链），使 B 成为被投票最多的节点。顶点 C 第二，因为它接收高排名 B 的全部投票。顶点 A 最低，因为它只接收 C 的半票。
