### 16.4 跨层耦合及其不满

虽然层级被偏好，跨层耦合并非完全不存在。某些现象需要跨多层分析，未能这样做会产生误导性结论。

_公共卫生政策_。一个国家的政策层面（联邦、州、地方）名义上是层级的，但真实公共卫生危机（大流行、阿片类药物流行）需要所有层面的协调行动。忽视地方条件的联邦层面分析遗漏重要变异；没有联邦支持的地方层面分析无法动员所需资源。COVID-19 大流行部分是美国和许多其他国家有效跨层协调的失败。

_金融稳定_。银行监管在多层面运作：个体银行（资本要求；压力测试）、国家银行系统（存款保险；央行贷款）、国际金融系统（巴塞尔协议；协调央行行动）。有效监管需要跨层面一致性；层面间的缺口（监管套利）是大多数主要银行危机的来源。2008 年危机暴露了去监管时期增长的国家和国际监管框架之间的缺口。

_气候政策_。有效气候政策必须跨多层面运作：技术选择（个人；企业）、市场结构（行业；部门）、国家政策（碳税；法规）、国际协议（巴黎协定；贸易规则）。跨层耦合是必要的因为市场结构和国际协议塑造技术选择，技术选择反过来改变什么国家和国际政策是可行的。巴黎协定的结构（每个国家设定自己的目标，有国际审查）是处理跨层耦合的尝试，结果参半。

_软件工程_。现代复杂软件（智能手机操作系统；云服务平台）涉及跨层耦合。性能问题可以来自任何层面：慢速磁盘；库中低效算法；服务间设计不良的交互；产生过多负载的用户体验选择。诊断性能问题需要跨多层面分析。现代软件工程工具（分布式追踪、可观测性平台）专门设计来支持跨层分析。

这些例子说明跨层耦合是真实的且重要的。使复杂系统可处理的层级分解也创造了忽视跨层效应的诱惑，此诱惑可能代价高昂。

_故事线 C 的多层形式_。刚才给出的四个例子也是故事线 C 跨层面展开。在 2008 年金融危机中，每个银行按自身资产负债表利益行动；聚合结果是没有任何银行选择的系统性危机。在气候政策中，每个国家按自身短期经济利益行动；聚合结果是没有国家想要的气候轨迹。在 COVID-19 响应中，每个代理（公民、医院、学校、联邦机构）按其局部所见行动；协调的聚合失败不是任何人的意图。在软件系统中，每个服务团队优化自己的性能指标；聚合用户体验可以以没有团队设计的方式退化。
