    import numpy as np
    import matplotlib.pyplot as plt

    def evolve_eca(rule, n_cells, n_steps):
        grid = np.zeros((n_steps, n_cells), dtype=int)
        grid[0, n_cells//2] = 1  # single seed in center
        for t in range(n_steps - 1):
            for i in range(n_cells):
                l = grid[t, (i-1) % n_cells]
                c = grid[t, i]
                r = grid[t, (i+1) % n_cells]
                idx = 4*l + 2*c + r
                grid[t+1, i] = (rule >> idx) & 1
        return grid

    fig, axes = plt.subplots(1, 4, figsize=(16, 4))
    for ax, rule in zip(axes, [30, 90, 110, 184]):
        grid = evolve_eca(rule, 200, 200)
        ax.imshow(grid, cmap='binary')
        ax.set_title(f'Rule {rule}')
    plt.show()


运行此代码给出标志性的 Wolfram 式锥形图像：从单个细胞演化的三角模式。规则 30（混沌）给出噪声但有结构的三角形。规则 90（类 Sierpinski 分形）给出清晰的自相似结构。规则 110（复杂）给出局部结构和混沌区域的混合。规则 184（"交通"CA）给出有序流过格的条纹。

Wolfram 分类即使应用于 ECA 之外也是有用的思维支架。许多元胞自动机（以及许多其他离散动力学系统）可以定性地放入四个类之一，提供其行为的快速描述。

### 12.4 元胞自动机作为离散动力学

元胞自动机是离散动力学系统：时间是离散的，空间是离散的，状态是离散的。它们是研究离散动力学的最干净数学设置，正如微分方程之于连续动力学。我们在连续系统中看到的许多定性现象（混沌、吸引子、相变）在 CA 中出现，通常以更干净的形式。

#### 密度分类：CA 相变

考虑以下问题：给定一个 1D CA，细胞以某密度 ρ 初始化为 0 或 1，设计一个 CA 规则使群体在 ρ > 0.5 时演化为全 1，在 ρ < 0.5 时演化为全 0。这是_密度分类问题_。听起来简单但出人意料地难。

已证明没有两态三细胞邻域的 ECA 能完美解决此问题。已知最好的规则以约 80% 准确率解决。这本身是有趣的结果：密度分类对 CA 是"困难"问题。

#### 自组织和模式形成

许多 CA 展现自组织：从随机初始条件出发，它们演化为结构化模式。Conway 的生命游戏将随机汤演化为少数稳定模式加漂移的滑翔机。反应-扩散 CA（类似 Turing 1952 年的形态发生方程）从随机起始条件产生斑点、条纹和六边形阵列。"Belousov-Zhabotinsky CA"产生类似真实化学振荡器中螺旋波的模式。

CA 中的自组织已被用作各种生物模式形成现象（动物皮毛图案、胚胎发育、生物膜生长）的模型。CA 不捕捉分子细节，但捕捉局部规则产生全局模式的定性动力学。
