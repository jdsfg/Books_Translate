**答案。** 关系可重写为 r = 0.5 K_c^{-1/2} (K - K_c)^{1/2}，所以序参量按距临界耦合距离的 1/2 次幂标度：r ~ (K - K_c)^{1/2}。临界指数为 β = 1/2。

这是_平均场_临界指数。它暗示系统属于平均场普适类，这符合因为 Kuramoto 模型具有有效全耦合。平均场普适类包括任何具有足够高有效维度（在上临界维度以上）的系统，涵盖全耦合系统无论其具体微观细节。

更精细的实验判别将测量额外指数（磁化率 γ、关联长度 ν）并检查是否匹配平均场值 γ = 1, ν = 1/2。如果匹配，平均场归属被确认。如果 γ 或 ν 不同，系统可能属于具有相同 β 的不同普适类（例如，某些无序模型可以有 β = 1/2 但不同的 γ 和 ν）。

**Q6.** 考虑 Erdős-Rényi 巨分量转变。用平均场推理导出序参量指数 β（将巨分量比例 s 与临界平均度以上的距离 \bar{k} - 1 关联）。

提示

隐式方程 s = 1 - e^{-\bar{k} s} 可在阈值以上对小 s 展开。

**答案。** 巨分量比例 s 满足隐式方程

s = 1 - e^{-\bar{k} s}.

恰在阈值 \bar{k} = 1 以上，s 很小，所以可将指数展开到二阶：

s = 1 - [1 - \bar{k} s + (\bar{k} s)^2/2 - \ldots] = \bar{k} s - (\bar{k} s)^2/2 + \ldots

整理：

s[1 - \bar{k}] + (\bar{k} s)^2/2 = 0.

对于 \bar{k} > 1，s ≠ 0，除以 s：

1 - \bar{k} + \bar{k}^2 s / 2 = 0,

s = \frac{2(\bar{k} - 1)}{\bar{k}^2}.

对于 \bar{k} 恰在 1 以上，给出 s ≈ 2(\bar{k} - 1)，所以 s 随 \bar{k} - 1 线性增长。临界指数为 β = 1。

这_不是_典型的平均场值 β = 1/2，需要解释。原因是 Erdős-Rényi 巨分量转变是有效无限维度图上的_渗流_型转变，但其指数结构与通常的平均场磁体略有不同。上临界维度以上（渗流的 d_u = 6）的渗流普适类有 β = 1，反映阈值附近巨分量的底层树状结构。

教训：即使在"类平均场"理论中，不同物理现象可以有不同指数，因为不同问题的适当平均场理论不同。磁性、渗流和同步各有其平均场分析，特征指数源自相关的序参量动力学。
