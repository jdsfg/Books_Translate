#### 无标度网络的消失流行病阈值

最引人注目的后果：对于度指数 γ_d ≤ 3 的无标度网络（注意：我用 γ_d 表示网络指数以避免与康复率 γ 混淆），二阶矩 ⟨k²⟩ 随网络增长发散。有效 R_0 因此无界增长，流行病阈值消失：

\beta_c = \frac{\gamma \langle k \rangle}{\langle k^2 \rangle - \langle k \rangle} \to 0 \text{ as } n \to \infty.

这是网络流行病学中最重要的结果之一，最初由 Pastor-Satorras 和 Vespignani 于 2001 年提出。在 γ_d ≤ 3 的无标度网络上，_任意_正传播率 β 在无限网络极限下都会产生流行病。不存在 β 低于它流行病就不能发生的值。

对于有限真实网络，阈值很小但不恰好为零；公式 β_c ∝ ⟨k⟩/⟨k²⟩ 给出一个小的正值。但它比相应的充分混合阈值小得多，任何实际控制策略都必须应对这一事实。

直觉是直接的。枢纽（高度节点）在维持传播方面非常高效：即使每条边的传播概率很小，一个有数百接触的枢纽在康复前会感染许多人。枢纽有效地创建了"流行病骨干"，即使大多数边传导率低也能维持传播。要打破流行病，你必须禁用枢纽；均匀降低传播概率效果较差。

#### 数值示例

考虑 Barabási-Albert 网络，n=10000, m=3（所以 \bar{k}=6），以及 β=0.05, γ=0.1 的 SIR 过程。充分混合预测给出 R_0 = (0.05/0.1)·6 = 3，暗示相当规模的流行病。网络修正为

R_0 = (\beta/\gamma) \cdot \frac{\langle k^2 \rangle - \langle k \rangle}{\langle k \rangle}.

对于 m=3、n=10000 的 BA 网络，模拟值给出约 ⟨k²⟩ ≈ 200（重尾），所以 R_0 ≈ 0.5·(200-6)/6 ≈ 16。远大于充分混合估计。

直接在 BA 网络上模拟 SIR 动力学通常给出接近 100% 的最终流行病规模，即使在比充分混合分析预测低得多的 β 下也是如此。枢纽快速捕获感染并广泛广播。
