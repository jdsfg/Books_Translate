这种双重关注——关注动力学而非仅偏好，以及关注系统对干预的响应——是复杂性科学对社会政策最有用的输出之一。它不给我们具体政策配方；它改变我们思考问题空间的方式，建议哪些干预值得尝试以及如何衡量其成功。许多善意社会政策的失败可追溯到忽视动力学、将个体视为分析单位、以及未预见系统的结构响应。复杂性科学视角不解决这些问题但至少清楚地命名了它们。

**优秀回答应涉及：** Schelling 的机制（温和偏好 + 移动 → 严重聚类）；结构性 vs 个体干预；结构性干预的具体例子（租金稳定化、公共物品、学校质量、混合收入住房）；诚实承认结构性干预触发自身反弹动力学。

### 本章小结

本章将第9章的相变框架和第10章的临界性框架应用于社会系统。我们调查了选民模型、Sznajd 模型、Galam 少数派影响模型和 Granovetter 阈值模型，各自捕捉舆论动力学的不同方面。我们讨论了 Centola 在实验室设置中 25% 临界点的实验发现、此类临界点的结构起源（复杂传染结合级联动力学），以及将实验室发现应用于现实情境的适当谨慎。

我们预览了 Schelling 隔离模型（在第13章详细展开）作为故事线 C 的经典例子：聚合结果背离个体意图。我们通过 Granovetter 阈值和 Olson 搭便车问题的视角讨论了集体行动；通过有界置信和过滤气泡机制审视了极化；并将社交媒体上的重尾级联规模分布与故事线 B（幂律作为普遍标志，由 SOC 机制解释）联系起来。

我们以三个诚实限定结束：社会系统不在平衡态；代理以物理粒子不具有的方式异质；这些模型的预测通常是定性和结构性的而非定量的。在这些局限内，相变框架是思考社会系统最有用的工具之一，特别是与计算社会科学的经验工作和 Centola 式实验室实验结合时。

第12章开始第 V 部分，从相变转向复杂性科学家使用的计算和建模工具。元胞自动机，最简单的离散动力学系统，是基于代理建模的历史和概念基础，也是本书的主要贯穿例子。

运动不需要多数派。它需要约四分之一。而四分之一，在合适的网络上，可以翻转其余的。
