#### 随机疫苗接种

最简单的策略是均匀随机地为群体中比例 f 的人接种疫苗。这从网络中移除 fn 个随机节点。对于 Erdős-Rényi 网络，这很有效：巨分量在与渗流阈值相关的临界比例 f_c 处碎片化。对于 γ_d ≤ 3 的无标度网络，随机疫苗接种效果显著降低：即使移除 80% 或 90% 的节点仍留下巨分量（因为剩余节点仍有相当的重尾连通性，由存活的枢纽主导）。

#### 定向疫苗接种

为最高度节点接种疫苗有效得多。对于无标度网络，按度移除前约 5% 的节点通常完全碎片化巨分量。这是定向公共卫生策略的网络科学基础，策略聚焦高接触个体（HIV 控制中的性工作者、流感控制中的幼儿和祖父母）。

问题是：实践中，你通常不知道谁是高度节点。真实社交网络不会标注每个人的接触度；该信息是隐私且难以测量的。

#### 熟人免疫

一个巧妙的解决方案，由 Cohen、Havlin 和 ben-Avraham（2003）提出：随机选择群体中一部分人，请每人提名其一个朋友，然后为朋友接种疫苗。提名过程抽样熟人（而非直接抽样人），而熟人因友谊悖论（第7章）偏向高度个体。所以被接种集合在不知晓谁是枢纽的情况下富含枢纽。

对于典型的无标度社交网络，比例为 f 的熟人免疫达到与比例为 f/2 甚至 f/4 的定向免疫相当的流行病抑制效果。对于大规模疫苗接种运动，这一效率提升是实质性的。

一般原则：在无标度网络中，利用边的友谊悖论偏差的策略比忽略网络结构的策略更有效。

### 8.4 信息级联与复杂传染

SIR 框架将传播视为_简单传染_：与感染者的单次接触就足以潜在传播。这对许多传染病是合理的。但对许多其他"传播"的事物不太合适。
