#### 模式

这些构造中的每一个都遵循一个简单的方法。取一个生成器（一种将几何体细分为更小块的方式）并递归应用。极限的维数由公式 d = ln(块数) / ln(缩放因子) 给出。对于康托尔集，2 块缩放 3 给出 ln 2 / ln 3。对于谢尔宾斯基三角形，3 块缩放 2 给出 ln 3 / ln 2。对于科赫曲线，4 块缩放 3 给出 ln 4 / ln 3。维数是非整数的，因为块数与缩放之间的关系是无理的。

#### 定义：分形

_分形_（fractal）是在每个尺度上都有细节且（通常为非整数的）Hausdorff 维数超过其拓扑维数的几何对象。_自相似_ 分形（如上述三个）在每个放大倍率下都有自身的精确小尺度副本。_统计自相似_ 分形（如真实海岸线）具有尺度不变的统计性质但没有精确副本。

用通俗的话说，分形是一个当你看得越近粗糙度就持续存在的对象；你永远无法放大到光滑视图。维数是粗糙度填充空间的激进程度的定量度量。

#### 自然界中的自相似

§4.2 中的数学分形是精确的，通过迭代构造。真实世界的分形在有限尺度范围内是 _统计_ 自相似的。海岸线大约在千米尺度（以上由构造几何主导）和厘米尺度（以下由个别岩石主导）之间近似分形。肺的气道树大约在支气管到肺泡之间近似分形。河流流域大约在分水岭尺度到源头尺度之间近似分形。雪花大约在毫米尺度到微米尺度之间近似分形。

真实世界物体常常具有分形结构的原因已被广泛研究。对于海岸线，主导机制是地质时间尺度上侵蚀和构造隆升的递归相互作用，两者都在多个尺度上运作。对于肺和循环系统，主导机制是在固定体积内最大化表面积的优化问题，这有利于递归分支结构。对于河网，是重力下水流的地形动力学。许多不同物理过程收敛于分形几何这一事实表明，分形性是跨尺度运作的优化或生长过程的通有结果，而非任何单一机制的特殊特征。
