### 4.3 洛伦兹系统的奇异吸引子

洛伦兹吸引子是物理学中最著名的奇异吸引子。它是一个三维对象，存在于 §3.5 引入的洛伦兹方程的相空间中。其形状大约是两个大致椭圆形的瓣在中央鞍点处连接，轨迹在每个瓣上向外螺旋，并以表面随机但实际上确定性的方式切换到另一个瓣。

洛伦兹吸引子的维数是多少？大约 2.06。轨迹在嵌入三维相空间的二维曲面（具有无穷小厚度）上漫游。超过 2 的"额外" 0.06 维反映了曲面折叠回自身处的轻微增厚；你可以将吸引子想象为一张被多次折叠的薄片，每次折叠产生更精细的结构，增加少量有效维数。

奇异吸引子的分形维数在数学上与李雅普诺夫谱相关。对于 n 维混沌系统，有 n 个李雅普诺夫指数 λ_1 ≥ λ_2 ≥ … ≥ λ_n。Kaplan-Yorke 猜想（对许多系统已验证但未完全证明）指出吸引子的分形维数为

d_{KY} = j + \frac{\sum_{i=1}^j \lambda_i}{|\lambda_{j+1}|}

其中 j 是使 ∑_{i=1}^j λ_i ≥ 0 的最大整数。对于洛伦兹系统，三个李雅普诺夫指数约为 (0.9, 0, -14.6)。所以 j=2，且

d_{KY} = 2 + \frac{0.9 + 0}{14.6} \approx 2.06.

奇异吸引子的分形维数可从吸引子上的膨胀速率（正 λ）和收缩速率（负 λ）计算。吸引子存在 _是因为_ 系统同时在某些方向膨胀而在另一些方向收缩；膨胀产生混沌拉伸，收缩产生有界体积。维数是这一平衡的几何记录。

#### 代码：可视化洛伦兹吸引子

    import numpy as np
    from scipy.integrate import solve_ivp
    import matplotlib.pyplot as plt

    def lorenz(t, s, sigma=10, rho=28, beta=8/3):
        x, y, z = s
        return [sigma*(y-x), x*(rho-z)-y, x*y-beta*z]

    sol = solve_ivp(lorenz, (0, 100), [1, 1, 1], t_eval=np.linspace(0, 100, 20000), rtol=1e-8)

    fig = plt.figure(figsize=(10, 8))
    ax = fig.add_subplot(projection='3d')
    ax.plot(sol.y[0], sol.y[1], sol.y[2], lw=0.4)
    ax.set_xlabel('x'); ax.set_ylabel('y'); ax.set_zlabel('z')
    plt.show()


图像是标志性的。经过足够模拟时间后，轨迹似乎填充了一个蝴蝶形曲面。仔细观察会发现曲面并不完全平坦：它具有精细的层状结构，轨迹每次经过时以微小偏移重新访问。这种层状结构就是吸引子的分形本质，其定量度量就是维数 2.06。
