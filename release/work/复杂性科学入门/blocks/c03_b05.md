#### 定义：互信息

X 和 Y 之间的**互信息**为

I(X; Y) = H(Y) - H(Y \mid X) = H(X) - H(X \mid Y).

等价地，通过链式法则展开，

I(X; Y) = H(X) + H(Y) - H(X, Y).

以及其最常用的形式，

I(X; Y) = \sum_{x, y} p(x, y) \log \frac{p(x, y)}{p(x) p(y)} = D(p(x, y) \| p(x) p(y)).

最后一种形式将互信息表示为联合分布与边缘分布乘积之间的 KL 散度。它是证明中最方便的形式。

用通俗语言说，这意味着：I(X; Y) 是知道 X 后对 Y 的不确定性的减少量（或由对称性，反之亦然）。它是 X 和 Y 之间依赖性的度量。

#### 性质

1. **非负性**：I(X; Y) ≥ 0，等号当且仅当 X 和 Y 独立时成立。
2. **对称性**：I(X; Y) = I(Y; X)。X 携带的关于 Y 的信息与 Y 携带的关于 X 的信息相同。
3. **有界性**：I(X; Y) ≤ min(H(X), H(Y))。你无法从 Y 中提取超过 Y 所有的信息，也无法从 X 中提取超过 X 所有的信息。
4. **自互信息**：I(X; X) = H(X)。一个变量关于自身携带的信息恰好等于其自身的熵。

性质 1、3、4 的证明可直接从公式得出；对称性已内含于对称形式 H(X) + H(Y) - H(X, Y) 中。

#### 值得记住的图

信息论者常画一个类似维恩图的图（文字描述，因为我们没有图）：想象两个重叠的圆分别代表 H(X) 和 H(Y)。它们的并为 H(X, Y)。它们的交为 I(X; Y)。H(X) 圆在重叠部分外的月牙为 H(X \mid Y)；H(Y) 圆在重叠部分外的月牙为 H(Y \mid X)。本节中的每个恒等式都可以从此图中读出：

- H(X, Y) = H(X) + H(Y) - I(X; Y)（容斥原理）。
- H(X \mid Y) = H(X) - I(X; Y)（减去重叠部分）。
- I(X; Y) = H(X) + H(Y) - H(X, Y)（从并和部分得重叠）。

维恩图_不是_完全严格的工具；对于三个变量它可能误导，因为 I(X; Y; Z)（三方版本）可以为负。但对于两个变量它是忠实且有用的总结。
