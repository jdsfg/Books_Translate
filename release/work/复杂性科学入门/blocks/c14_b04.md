#### 代码：实现 Schelling

> **运行说明**：此实现是教学性的，非优化的。在 `L=50, n_steps=50000` 下在标准笔记本上约需 30-60 秒，因为每步从头重建不满意列表和空细胞列表。对于更大格或更快迭代，参见附录 B.11 中使用 NumPy 布尔掩码而非 Python 循环的向量化版本。

    import numpy as np
    import matplotlib.pyplot as plt

    def schelling(L, occupancy, frac_red, theta, n_steps):
        n_agents = int(L*L * occupancy)
        n_red = int(n_agents * frac_red)
        grid = np.zeros((L, L), dtype=int)
        positions = np.random.choice(L*L, n_agents, replace=False)
        for k, p in enumerate(positions):
            i, j = p // L, p % L
            grid[i, j] = 1 if k < n_red else 2

        def is_satisfied(i, j):
            if grid[i, j] == 0: return True
            nbs = []
            for di in [-1, 0, 1]:
                for dj in [-1, 0, 1]:
                    if di == 0 and dj == 0: continue
                    if grid[(i+di)%L, (j+dj)%L] != 0:
                        nbs.append(grid[(i+di)%L, (j+dj)%L])
            if not nbs: return True
            same = sum(1 for x in nbs if x == grid[i, j])
            return same / len(nbs) >= theta

        for step in range(n_steps):
            unsatisfied = [(i, j) for i in range(L) for j in range(L)
                           if grid[i, j] != 0 and not is_satisfied(i, j)]
            if not unsatisfied: break
            i, j = unsatisfied[np.random.randint(len(unsatisfied))]
            empty = list(zip(*np.where(grid == 0)))
            if empty:
                i2, j2 = empty[np.random.randint(len(empty))]
                grid[i2, j2] = grid[i, j]
                grid[i, j] = 0
        return grid

    grid = schelling(50, 0.9, 0.5, 0.3, 50000)
    plt.imshow(grid)
    plt.show()


运行此代码产生清晰的隔离模式，红色和蓝色簇由尖锐边界和小空缓冲区分隔。动力学通常在 50×50 格的数万步内收敛；更大的格按比例需要更长时间。

#### 为什么发生隔离？

机制是反馈循环。被大多异类邻居包围的代理不满意并移动。当它移动时，倾向于落在有更多同类型邻居的位置（因为此类位置统计上更可能满足它）。当它落在同类型簇中时，增加了该簇的大小。当它离开混合区域时，耗尽了那里的同类型人口。随时间推移，同类型簇以混合区域为代价增长。

关键点是_动力学偏向同质化_，即使偏好温和。偏差产生因为：

1. 移动总是离开同类型不足的位置并朝向（统计上）同类型丰富的位置。
2. 同类型丰富的位置是稳定的（其居民不移动）。
3. 同类型不足的位置是不稳定的（其居民离开）。

这些共同产生同类型簇的缓慢但不可阻挡的积累。平衡是严重隔离，不是因为任何人想要它，而是因为动力学驱动到那里。
