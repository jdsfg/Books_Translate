### 8.1 SIR 模型

经典模型将人群分为三个仓室：_易感者_（S，可以被感染的人）、_感染者_（I，具有传染性的人）和_康复者_（R，已被感染且不再有传染性或易感的人）。总人口 N = S + I + R 固定（我们忽略感兴趣时间尺度内的出生和死亡）。

仓室之间的转换为：

- 易感到感染：速率为 βSI/N（每对易感-感染者每单位时间以 β/N 的速率产生新感染；β 是_传播率_）。
- 感染到康复：速率为 γI（每个感染者以速率 γ 康复；1/γ 是平均传染期）。

这些给出微分方程

\frac{dS}{dt} = -\beta \frac{SI}{N},
\frac{dI}{dt} = \beta \frac{SI}{N} - \gamma I,
\frac{dR}{dt} = \gamma I.

该模型是最简单的可能。它假设均匀混合群体（每个易感者遇到每个感染者的概率相等），无人口统计结构（无儿童、无老人、无空间变化），无免疫力丧失（康复意味着终身康复），无行为响应（人们不随流行病进展改变行为）。

#### 基本再生数

从 SIR 模型导出的最重要量是_基本再生数_：

R_0 = \frac{\beta}{\gamma}.

R_0 是引入完全易感群体中的单个感染者产生的预期继发感染数。如果 R_0 < 1，每个感染者平均感染不到一人，流行病消亡。如果 R_0 > 1，流行病在早期阶段指数增长并产生大规模爆发。阈值是尖锐的：R_0 = 1 是_流行病阈值_。

这一阈值具有相变的结构（正如我们在第5章同步和第6章巨分量中所见）。控制参量为 R_0；序参量为最终流行病规模（最终被感染的人口比例）；临界值为 R_0 = 1；序参量在阈值上方连续增长。

#### 最终规模方程

如果 R_0 > 1，流行病最终以某比例 R(∞)/N 的人口被感染而结束。这一_最终规模_满足隐式方程：

R(\infty)/N = 1 - e^{-R_0 \cdot R(\infty)/N}.

对于 R_0 略大于 1，R(∞)/N 很小。随着 R_0 增大，R(∞)/N 趋近 1。对于 2020 年初 COVID-19，R_0 ≈ 2.5 且无干预，基本 SIR 模型预测的最终规模约为 90% 的人口。大多数国家的实际结果低得多，部分因为干预，部分因为行为反馈，部分因为基本模型未捕捉到的实质性异质性。
