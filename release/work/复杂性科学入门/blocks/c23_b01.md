### D.1 Python 和科学栈

本书程序使用 Python 3.9 或更高版本及标准科学栈：NumPy、SciPy、Matplotlib、NetworkX。最简单的安装路径：


#### 推荐：Miniforge / Mambaforge

安装 Miniforge（最小 conda 安装器，以 `conda-forge` 为默认频道）。然后创建环境：


    mamba create -n complexity python=3.11 numpy scipy matplotlib networkx jupyter
    mamba activate complexity


这给你一个干净、可重现的环境，包含附录 B 的所有依赖。


#### 替代：pip + venv

如果你偏好标准 Python 工具：


    python3 -m venv complexity-env
    source complexity-env/bin/activate     # Linux/Mac
    complexity-env\Scripts\activate.bat    # Windows
    pip install numpy scipy matplotlib networkx jupyter



#### 跳过什么

* **Anaconda**（完整发行版）：太大，包含过时包，偶尔对机构用户有许可问题。Miniforge 严格更好。
* **Python 2.7**：长期弃用；不要使用。
* **macOS 或 Linux 上的系统 Python**：永远不要将科学包安装到 OS Python 中。始终使用虚拟环境。

### D.2 NumPy 和 SciPy


#### NumPy

所有数值 Python 的基础。附录 B 中几乎每个程序都用于数组、向量化操作和基本线性代数。

**常见陷阱：** 混淆 `np.array`（同构数值数组）和 `list`（异构 Python 容器）。NumPy 数组上的操作是向量化的，比 Python 循环快数量级；Python 列表上的操作不是。当程序运行缓慢时，首先要检查的是是否意外创建了数组列表而非二维数组。

**版本说明：** NumPy 1.25+ 移除了几个遗留别名（如 `np.float`）。附录 B 中的程序仅使用现代 API，兼容 NumPy 1.20 到当前版本。

#### SciPy

在附录 B 中主要用于 `scipy.integrate.solve_ivp`（数值 ODE 积分，Lorenz 系统）和 `scipy.stats.linregress`（线性回归，BTW 幂律拟合）。

**陷阱：** `solve_ivp` 默认使用低容差求解器，可能对混沌系统给出不准确结果。本书 Lorenz 示例因此设置 `rtol=1e-9`。如果你修改示例，保持紧容差。

#### Matplotlib

用于所有绘图。`pyplot` 接口（我们全程使用）是最常见的。

**陷阱：** `plt.show()` 在脚本中阻塞但在 Jupyter 中是隐式的。如果运行脚本且图未出现，检查是否在无头模式（无显示）。在服务器上，在脚本顶部使用 `matplotlib.use('Agg')` 并将 `plt.show()` 替换为 `plt.savefig('output.png')`。

**陷阱：** 默认 Matplotlib 字体不渲染某些 Unicode 字符（如 `\bar{x}` 中的横杠）。对我们书的记号，这很少有问题因为数学在 LaTeX 风格的 markdown 中，不在绘图标签中。
