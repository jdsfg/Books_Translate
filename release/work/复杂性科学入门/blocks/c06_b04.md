#### 同步转变

Kuramoto 在 N → ∞ 极限下解析求解了该模型，其结果是非线性动力学中最优美的结果之一。对于低于临界值 K_c 的耦合强度 K，长期序参量为 r=0：振子保持不相干。对于 K > K_c，r 从零连续增长，满足

r \sim \sqrt{\frac{K - K_c}{K_c}}

恰在转变点之上。转变是 _连续的_（用相变语言说是二阶的）：r 从零开始并作为到临界点距离的平方根增长。远在 K_c 之上，r 趋近 1，群体变为完全同步。

临界耦合取决于群体中自然频率的散布：

K_c = \frac{2}{\pi g(\bar{\omega})}

其中 g(ω) 是自然频率分布，\bar{\omega} 是其均值。自然频率散布越宽（峰值高度 g(\bar{\omega}) 越小），同步所需的耦合越强。散布越窄（峰值越高），越容易同步。

平方根标度与我们在第9章中将看到的物理系统近临界点处二阶相变的标度相同。Kuramoto 模型展现了去同步和同步状态之间的真正相变，其中 r 扮演序参量的角色，K 扮演逆温度的角色。为热力学相变发展的数学工具经适当翻译后可转移到耦合振子的动力学。

因此定性图景是：自然频率足够多样的振子群体在耦合弱时完全不同步。当耦合增加到超过临界阈值时，部分同步出现（一部分群体锁定到共同频率而其余继续漂移）。当耦合进一步增加，越来越多的振子被同步簇捕获。在极强耦合极限下，所有振子锁定在均值频率。
