#### 相变

对于二维 Ising 模型（Onsager 精确求解），转变发生在临界温度

T_c = \frac{2J}{k_B \ln(1 + \sqrt{2})} \approx 2.269 \frac{J}{k_B}.

T_c 以上，平均磁化为零（自旋是顺磁的，随机取向）。T_c 以下，磁化非零（自旋是铁磁的，大多沿某选定方向对齐）。

在转变附近，磁化标度为

m \sim (T_c - T)^{\beta}

其中 β = 1/8 = 0.125 为 2D Ising 模型的值（这是_序参量指数_；在统计力学教材中同一字母 β 有时也用于逆温度 1/(k_B T)，但本书避免这一双重用途——参见下面 §9.4 的记号说明）。

其他几个量也在临界点附近展现幂律标度，各有其特征指数：

- _磁化率_（磁化对场的响应）：χ ~ |T - T_c|^{-γ}，其中 γ = 7/4 为 2D Ising 的值。
- _比热_：C ~ |T - T_c|^{-α}，其中 α = 0（对数发散）为 2D Ising 的值。
- _关联长度_：ξ ~ |T - T_c|^{-ν}，其中 ν = 1 为 2D Ising 的值。

这些指数不是独立的；它们满足从关于自由能奇异部分如何依赖于温度和场的几个基本假设导出的_标度关系_。这些关系包括 α + 2β + γ = 2（对 2D Ising 验证：0 + 2(1/8) + 7/4 = 2）。
