### 4.5 常见错误消息解码

让我们建立一份你会频繁遇到的错误消息速查表。对每一种，我们会解码它实际意味着什么，以及应该调查什么。

**`undefined is not a function` (JavaScript)** 你正在把某个东西当作函数调用，但它是 `undefined`。常见原因：方法名拼错、对象没有你以为它有的方法、导入不正确，或者对象本身是 undefined，而你正试图在它上面调用方法。

**`Cannot read property 'X' of null/undefined` (JavaScript)** 你正在对某个 null 或 undefined 的东西访问属性 X。这意味着问题在_对象_，而不是属性。找到这个对象本应在哪里被赋值，并弄清它为什么没有被赋值。

**`IndentationError` (Python)** 空格和制表符混用了，或者缩进与预期的块结构不匹配。一旦你在编辑器里启用“显示空白字符”，这通常就很明显。不要猜——去看空白字符。

**`KeyError: 'X'` (Python)** 你试图访问字典键 'X'，但它不存在。检查：键是否拼错？字典是否真的拥有你以为它拥有的那些键？打印字典的键来验证。

**`404 Not Found` (HTTP)** URL 与服务器上的任何路由都不匹配。检查：URL 是否正确？服务器是否正在运行？你是否访问了正确的端口？路由是否已注册？路径中是否有拼写错误？

**`CORS error` (Browser)** 浏览器阻止了一个请求，因为服务器没有包含正确的头。这不是服务器错误——请求已经到达服务器并获得了响应。只是浏览器拒绝把它展示给你的 JavaScript。修复方法：配置服务器发送正确的 `Access-Control-Allow-Origin` 头。

**`ECONNREFUSED` (Node.js / any network call)** 连接被拒绝——目标 address:port 上没有任何东西在监听。检查：目标服务是否正在运行？你是否连接到了正确的主机和端口？是否有防火墙阻止它？

**`Segmentation fault` (C/C++)** 你访问了不该访问的内存——通常是 null 指针解引用、数组越界，或释放后使用。这是编程中信息最贫乏的错误。使用调试器或地址消毒器来获取堆栈跟踪。
