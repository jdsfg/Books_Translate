1. **使用维护良好的 HTML sanitizer**（如 DOMPurify、Bleach 或 sanitize-html），剥离危险标签和属性。
  2. **在解析层使用内存安全语言。** 如果解析器是 C/C++ 写的，考虑用内存安全工具包裹它，或用 Go、Rust、Java 中的解析器替换它。
  3. **使用白名单，而不是黑名单。** 允许特定安全 HTML 标签（p、em、strong、a、ul、li），而不是试图阻止危险标签。黑名单总会漏掉东西。
  4. **在沙箱中运行解析器。** 如果解析器崩溃或行为异常，沙箱会限制损害范围。
  5. **添加输出验证。** 渲染后，检查输出 HTML 是否包含意外内容（script 标签、事件处理器、不该出现的数据）。
