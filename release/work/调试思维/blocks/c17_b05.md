#### 概念检查

**Q1.** 业务营收下降与软件缺陷有什么相似之处？把调试循环的每一步映射到业务调查中。

**答案：** 两者都是“意外行为”，都需要系统化调查。映射如下：(1) **观察** → 按产品、地区、分群和时间拆解营收下降，以获得具体数据，就像读取错误消息一样。(2) **假设** → 形成具体理论（定价变化、竞争对手进入、营销削减），就像假设代码原因一样。(3) **预测** → 每个理论都会预测数据中的具体、可测试模式（例如，“如果是定价导致的，客户数量应该稳定”）。(4) **测试** → 查询数据以检查预测，就像添加一条打印语句或运行一个测试。(5) **缩小范围** → 排除不匹配的假设，就像在代码中缩小搜索空间一样。

**Q2.** 把二分查找应用到这个问题：尽管供暖系统开着，你家还是太冷。列出你会检查的“中点”。

**答案：** 对从热源到你的路径做二分查找：(1) **供暖系统 → 温控器** ——温控器设置正确吗？它读到的温度准确吗？如果温控器显示设置正确，问题就在下游。(2) **温控器 → 炉子** ——炉子真的在运行吗？检查它是否在产热。如果是，那么热量已经产生，但没有到达房间。(3) **炉子 → 风管** ——通风口打开了吗？有空气从通风口流出吗？如果有但空气是冷的，说明炉子在运行但没有加热。如果炉子处有暖风但房间仍然冷 → 保温/窗户导致热量流失。(4) **风管 → 房间** ——暖空气到达房间了吗？检查一个通风口——它是暖的吗？如果暖空气到达房间但房间仍然冷 → 热量流失（窗户打开、保温差）。

**Q3.** 科学家的实验产生了意外结果。应用调试方法：他们应该首先检查什么——理论还是实验？为什么？

提示

想想第 3 章的认知偏差。科学家希望他们的理论正确（或者戏剧性地错误）。这里有什么偏差在起作用？

**答案：** 首先检查**实验**。理由：(1) 实验错误（校准错误、污染、流程失误）远比理论错误常见。先检查平凡解释，就像在重新设计架构之前先检查拼写错误一样。(2) **确认偏差**（第 3 章）：如果科学家希望自己的理论是错的（因为那会是一个戏剧性、可发表的发现），他们可能会跳过检查实验。如果他们希望自己的理论是对的，他们可能会把意外结果当作“实验误差”而不调查。无论哪种情况，严谨的方法都是先验证实验。(3) 检查实验更快，也更可行动。重新校准仪器需要一小时。修订理论需要数月。先排除快速解释。
