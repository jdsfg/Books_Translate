5. **如果提交时它是 `true`，但 POST data 中不存在：** form data 构造没有包含复选框。检查 form data 是如何构建的——也许它使用了 `new FormData(form)`，但复选框缺少 `name` 属性，或者复选框位于 `<form>` 元素外部。

**变量隔离：**

* 测试 1：勾选复选框后提交。→ 收到的是未勾选。
* 测试 2：不勾选复选框后提交。→ 收到的是未勾选。
* 测试 3：在控制台中、表单提交前硬编码 `checkbox.checked = true`。→ 仍然收到未勾选。→ 提交时的值_不是_问题；form data 构造才是问题。
* 测试 4：手动把复选框值添加到 form data：`formData.append('newsletter', 'true')`。→ 服务器正确收到它。→ form data 构造漏掉了复选框字段。

根因：复选框位于 `<form>` 元素外部（可能因为 CSS 布局需求，被放在不同的 DOM 子树中），所以 `new FormData(form)` 不会包含它。修复方法：要么把复选框移入 form 内部，要么手动把它的值添加到 form data。
