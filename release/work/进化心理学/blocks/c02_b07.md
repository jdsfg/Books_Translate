#### 分类主张

**Q1.** 一位朋友读到一条新闻标题，告诉你："科学家已经证明人类天生恐惧黑暗。"在决定是否相信它之前，你最应该想知道的第一件事是什么？这个主张，就其表述而言，是一个_可检验的_主张、一个_故事_，还是可能是一件_武器_？

提示

注意"证明"这个词，注意这个主张有多少东西没有说清。如果它是真的，世界会是什么样子？如果它是假的，世界又会是什么样子？

**讨论：** 诚实的第一步是放慢这个主张的速度，因为就其表述而言，它太模糊了，既不能为真也不能为假。"天生"（hardwired）偷偷塞进了我们在 1.2 中刚刚质疑过的决定论。"证明"是一个真正的科学家在面对如此复杂的问题时极少使用的词。要把这条标题变成可检验的东西，你会想知道：是对黑暗本身的恐惧，还是对_黑暗所隐藏之物_（捕食者、伏击、看不见的东西）的恐惧？它是跨文化存在的，还是后天习得的？它是否在婴儿尚不可能学会它的时候就出现了？在没有夜间捕食者的地方，它是否会消退？注意，在这条标题之下藏着一个完全合理的进化假设，因为黑暗对于一个脆弱的、适应日间活动的灵长类来说确实更危险，所以一种对黑暗的恐惧准备是有回报的。但标题中自信的"已证明"已经跑在那个谨慎想法前面好几英里了。这就是在第一页就遇到的差距——一个审慎的适应性假设与一个通过扩音器大喊的恰好如此故事之间的差距。既不要吞下标题，也不要嘲笑其下的科学。这种双重拒绝就是线索 A。


#### 识别谬误

**Q2.** 两个人在争论。一个说："攻击性是人类天性的一部分，它是进化来的，所以试图减少暴力没有意义；我们就是这样。"另一个说："这太冒犯了。说攻击性是天然的只是在为暴力找借口，所以它一定是假的。"两个人都犯了错误。两个错误是什么，它们是同一个错误吗？

提示

看看每个人如何使用"天然的"这个词。一个把_进化而来_当作解决了价值问题。另一个把价值问题当作解决了事实问题。

**讨论：** 它们是镜像式的错误，抓住两者是线索 C 的核心。第一个说话者从_实然_滑向_应然_：从"攻击性是进化来的"直接跳到"因此我们不能也不需要减少它"。但一种进化倾向是起始材料，不是判决；人类不断压制和引导进化冲动，而"它是天然的"本身永远不能决定我们该做什么。第二个说话者反方向滑动，从_应然_滑向_实然_：从"这个主张在道德上对坏人有利"跳到"因此它在事实上是假的"。但一个主张的道德后果不是关于其真假的证据。一个发现不会因为它令人不舒服就变成假的，正如它不会因为它是天然的就变成好的。这两位说话者犯了我们后来将命名为自然主义谬误（naturalistic fallacy）和道德主义谬误（moralistic fallacy）的错误，而请注意关键的一点：抓住_第二个_说话者不意味着站在_第一个_一边。你可以同时拒绝"天然的意味着没问题"和"不受欢迎的意味着假的"。事实上你必须如此，因为每一个都是人们在逃离另一个时落入的陷阱。
