* 预期所有预测变量都相关（真正为 0 的系数很少）
* 预测变量高度相关（LASSO 会从相关变量组中任意挑选 1 个；岭回归会分摊系数）
* 主要目标是预测准确性，而不是变量选择
* 预测变量数量小于观测值数量

**偏好 LASSO 的情况**：

* 预测变量很多，但真正相关的很少（稀疏信号）
* 可解释性要求一个简约模型
* 变量选择与预测同为目标
* 预测变量数量可能超过观测值数量（p > n）——岭回归会退化；LASSO 会选择一个子集

**弹性网**结合了两者：lambda_1 sum |beta_j| + lambda_2 sum beta_j2。当存在成组相关预测变量时很有用——LASSO 倾向于任意选择其中 1 个；弹性网可以选择整个组。

**Q4.** 解释岭回归正则化的贝叶斯含义。为什么这种解释有助于理解正则化为什么有效？

**答案：** 岭回归等价于在每个系数上放置独立正态先验后进行最大后验（MAP）估计：beta_j ~ N(0, sigma2/(2 lambda))。

可以这样看：岭回归最小化 sum(Y - X beta)2 + lambda sum beta_j2。对后验（先验 x 似然）取对数：

log p(beta | data) = log p(data | beta) + sum_j log p(beta_j)

proportional to -1/(2 sigma2) sum(Y_i - X_i' beta)2 - 1/(2 tau2) sum beta_j2

乘以 -2 sigma2 后得到：sum(Y_i - X_i' beta)2 + (sigma2 / tau2) sum beta_j2。这就是 lambda = sigma2 / tau2 时的岭回归目标。最小化岭回归 = 在正态先验下最大化后验。

为什么这有助于理解正则化的有效性：

正态先验 N(0, tau2) 表示：“在看到数据之前，我相信回归系数大概率较小。”这个先验通常是正确的：在大多数实际问题中，大多数预测变量的效应很小或为 0。先验把概率集中在 0 附近，抑制模型给有噪预测变量分配过大的系数。

当某个系数估计不确定（标准误很大）时，先验会把它拉向 0——这是合适的，因为噪声数据中的不确定估计很可能被夸大。当数据信息充分且某个系数明显很大时，先验会被数据压倒。从贝叶斯意义上说，正则化是自适应的：数据信息越少，收缩越强。
