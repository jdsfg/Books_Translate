#### 定义：混杂因子

如果变量 $Z$ 满足以下条件，那么它就是 $X$ 与 $Y$ 关系中的**混杂因子**：

1. $Z$ 与 $X$（感兴趣的原因）相关
2. $Z$ 与 $Y$（结果）相关
3. $Z$ 不在 $X$ 到 $Y$ 的因果路径上

用普通语言说：$Z$ 是 $X$ 和 $Y$ 的“共同原因”，即使二者之间没有直接因果关系，它也会在二者之间制造关联。

经典例子：

* 冰淇淋销量（$X$）与溺水死亡人数（$Y$）：正相关。混杂因子：炎热天气（$Z$）同时导致二者。
* 鞋码（$X$）与儿童阅读能力（$Y$）：正相关。混杂因子：年龄（$Z$）同时推动二者。
* 喝咖啡（$X$）与心血管疾病（$Y$）：一些研究中存在正关联。疑似混杂因子：吸烟（$Z$），它同时与咖啡消费和心脏病相关。

把混杂因子 $Z$ 纳入回归——也就是控制它——会去除它的污染效应，从而揭示 $X$ 与 $Y$ 之间真实的偏关系。当你把 $Z$ 加入回归后，$X$ 的系数大幅下降（或符号反转），你就发现表面上的 $X$-$Y$ 关系有很大一部分来自 $Z$。

#### 线索 B——可重复性危机（连载）

许多重复失败都可以理解为混杂因子问题。一项研究发现“吃黑巧克力会降低抑郁”。在原始研究中，收入没有被控制。高收入个体既消费更多黑巧克力，又有较低的抑郁率（因为压力更低、医疗更好）。混杂因子（收入）制造了巧克力-抑郁相关。一个控制收入的重复研究发现二者没有显著关系。

这种模式——混杂因子导致虚假的显著发现，而这些发现无法重复——是重复失败背后最重要的统计机制之一。控制潜在混杂因子既需要测量它们（这要求在数据收集前思考），也需要把它们纳入模型。没有收集潜在混杂因子的研究无法控制它们，其回归系数可能被显著夸大。
