#### 应用题

**Q1.** 一家制药公司在新闻稿中报告其新型胆固醇药物的如下结果：

“STATINEX 显著降低心脏病发作风险：在我们的里程碑式试验中，与安慰剂相比，服用 Statinex 的患者在 5 年内心脏病发作风险降低 30%（p < 0.0001）。这些结果确认 Statinex 是心血管医学的一项重大突破。”

你了解到：该试验纳入 10000 名患者（每组 5000 人）；对照组 5 年心脏病发作率为 3%；治疗组为 2.1%。

(a) 验证 30% 的相对风险降低。(b) 计算绝对风险降低和 NNT。(c) 改写新闻稿段落，以诚实地沟通这些发现。

**答案：**

**(a) 相对风险降低**：

RRR = (3% - 2.1%) / 3% = 0.9% / 3% = 30%

确认：30% 的相对风险降低是正确的。

**(b) 绝对风险降低和 NNT**：

ARR = 3% - 2.1% = 0.9% = 0.009。NNT = 1 / ARR = 1 / 0.009 ≈ 111。

约 111 名患者必须服用 Statinex 5 年，才能防止 1 例额外心脏病发作。

**ARR 的 95% CI**：比例差的 SE 约为 sqrt(pc(1 - pc) / nc + pt(1 - pt) / nt) = sqrt(0.03 × 0.97 / 5000 + 0.021 × 0.979 / 5000) ≈ sqrt(0.0000058 + 0.0000041) ≈ 0.00315。

95% CI：0.009 ± 1.96 × 0.00315 = 0.009 ± 0.0062，或 (0.3%, 1.5%)。

ARR 的 95% CI 大约从 0.3% 到 1.5%——NNT 范围为 67 到 333。这显示出关于该药价值大小的一个有意义的不确定性范围。

**(c) 诚实的新闻稿段落**：

“一项纳入 10000 名患者的随机、安慰剂对照试验发现，Statinex 将 5 年心脏病发作率从 3.0% 降至 2.1%——相对风险降低 30%（绝对风险降低：0.9%；95% CI：0.3% 到 1.5%；p < 0.0001）。从实践角度看，约 111 名患者需要服用 Statinex 5 年，才能防止 1 例额外心脏病发作（95% CI：67 到 333 名患者）。Statinex 对心血管风险升高的患者是一种有意义的治疗选择；对于低风险患者，绝对收益会更小。在做出治疗决策之前，患者和医生应讨论完整的收益-风险概况，包括成本、副作用以及与现有降胆固醇疗法的比较。”
