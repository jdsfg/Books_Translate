#### 深入思考

**Q2.** 随机化被认为是因果推断的金标准，但有人认为它会制造自身的问题：随机试验招募的是经过选择的志愿者，可能不能代表处理将要应用的人群；罕见伤害可能不会出现在任何可行规模的试验中；而且随机化往往不可行或不合伦理。

描述 3 个随机化不是最佳可用选项的场景，并解释在每种情况下，哪种替代设计能提供最强的可用证据。

**讨论：**

**场景 1——伦理上不可能：吸烟会导致肺癌吗？**

我们不能把人随机分配去吸烟几十年。最好的可用证据来自以下组合：(a) 具有仔细暴露测量的大型前瞻性队列研究，(b) 剂量-反应关系（吸烟越多 → 癌症越多），(c) 许多国家和人群中研究结果的一致性，(d) 合理的生物机制（烟草中的致癌物），以及 (e) 提供机制实验证据的动物实验。

Bradford Hill 标准把如何在没有随机化的情况下提出因果主张形式化：强度、一致性、特异性、时间先后性、生物梯度、合理性、协调性、实验证据类比和类比。没有任何单一研究能替代随机化，但跨多条证据线的优势证据——每条证据线都排除了不同的替代解释——可以让我们对因果结论有高度信心。

**场景 2——规模不可行：最低工资提高是否会减少贫困？**

我们不能把州或国家随机分配到最低工资法律。最好的可用设计是利用自然政策变异的**双重差分（DiD）**分析：提高最低工资的州作为“处理”单元；没有提高的邻近州作为“对照”。Card 和 Krueger 关于新泽西 vs. 宾夕法尼亚的著名研究就是典型例子。

DiD 在以下情况下最强：(a) 处理组和对照组在处理前趋势平行（验证反事实假设），(b) 同一时间没有其他只影响处理州而不影响对照州的政策变化（没有混杂的政策变化），以及 (c) 处理分配具有合理外生性（政策变化不是由本来就会产生该结果的劳动力市场状况造成的）。局限性也很明确：平行趋势假设不可检验，但可以被部分验证。

**场景 3——罕见事件：一种罕见药物副作用（1/10,000 名患者）是否会导致长期肾损伤？**

一个足以检测 1/10,000 发生率的随机试验需要数百万参与者——不可行。最好的可用证据来自：(a) **药物警戒数据库**（药物暴露和结局的大型观察性登记库），(b) **病例-对照研究**（比较有肾损伤的患者与匹配对照的药物暴露），以及 (c) **自我对照病例系列**（比较每位患者在药物暴露期与非暴露期的肾损伤发生率，消除个体间混杂）。

自我对照设计对罕见事件特别有力，因为每位患者都作为自己的对照——消除了所有不随时间变化的混杂因素。它只要求结局独立于暴露时机（没有随暴露期变化的适应证混杂）。
