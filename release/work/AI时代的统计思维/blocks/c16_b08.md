#### 应用题

**Q1.** 一个逻辑回归模型预测一笔信用卡交易是欺诈（Y = 1）还是合法（Y = 0）。对于某笔特定交易，模型输出的对数优势为 -0.8。

(a) 把这个对数优势转换为欺诈概率。(b) 银行的决策阈值是：如果预测概率 > 10%，就把交易标记为欺诈。该交易是否应被标记？(c) 如果银行把阈值降到 5%，这会如何影响第 1 类错误和第 2 类错误之间的权衡？(d) 银行希望确保抓住 90% 的欺诈交易。它们应该使用哪类指标来评估模型表现？该指标与第 2 类错误有何关系？

提示

对于 (a)：使用 p = 1 / (1 + e^{-eta})，其中 eta = -0.8。对于 (c)：思考阈值变化时，假阳性和假阴性会发生什么。

**答案：**

(a) eta = -0.8。使用逻辑函数（sigmoid）：

p = 1 / (1 + e^{-eta}) = 1 / (1 + e^{0.8}) = 1 / (1 + 2.226) = 1 / 3.226 approx 0.310

也可以通过优势验证：logit(p) = -0.8 意味着 p / (1 - p) = e^{-0.8} approx 0.449，因此 p = 0.449 / 1.449 approx 0.310。

**预测欺诈概率约为 31%。**

(b) 由于 31% > 10% 阈值，该交易**应被标记**。

(c) 将阈值从 10% 降到 5% 意味着，只要预测概率 > 5%，就标记交易（对其为欺诈的确定性要求更低）。这会：

* **降低第 2 类错误**（漏掉的欺诈交易更少 = 假阴性更少）：更多交易被标记，因此更少真实欺诈会漏网
* **增加第 1 类错误**（更多合法交易被错误标记 = 假阳性更多）：阈值降低后，更多合法交易会被卷入欺诈筛查网

这种权衡是：以拦截更多合法交易（更高第 1 类错误）、打扰正常客户并增加欺诈调查员工作量为代价，抓住更多欺诈（更低第 2 类错误）。

(d) 为了确保抓住 90% 的欺诈交易，银行应优化**敏感性**（也称召回率或真阳性率）：

Sensitivity = True Positives / (True Positives + False Negatives) = 1 - 第 2 类错误率

达到 90% 敏感性意味着模型正确识别出所有实际欺诈案例中的 90%。这与第 2 类错误直接相关：敏感性 = 1 -（欺诈交易中的第 2 类错误率）。

在 10% 阈值下，当前敏感性可以由模型的混淆矩阵计算。为了达到 90% 敏感性，可能需要降低阈值（接受更多假阳性，以确保漏掉更少欺诈）。
