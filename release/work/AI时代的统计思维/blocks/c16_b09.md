log(mu_i) = log(population_i) + beta0 + beta1 x speed_limit_i + beta2 x road_density_i

结果：beta1 = -0.02（速度限制单位为 km/h），beta2 = 0.05（道路密度单位为 条道路/km²）。

(a) 用通俗语言解释 beta1。更高的速度限制会减少事故吗？(b) 如果 beta0 = -6.5，对于一个人口 100,000、速度限制 80 km/h、道路密度 12 的地区，预测的年度事故数是多少？(c) 研究者惊讶于更高速度限制与更少事故相关。提出 2 个混杂解释。

提示

对于 (b)：记住偏置项 log(population) 会把预测调整为针对特定人口规模。计算 mu = exp(log(100000) + beta0 + beta1 x 80 + beta2 x 12)。对于 (c)：思考哪些类型的道路会有不同的速度限制。

**答案：**

(a) beta1 = -0.02 表示速度限制每增加 1 km/h，在道路密度保持不变时，每人事故率会乘以 e^{-0.02} approx 0.980，即每 km/h 约低 2%。较高速度限制与较低的人均事故率相关。

“较高速度限制是否会减少事故？”这个表述需要谨慎：这是观察性关联，不是因果主张。负系数意味着平均而言，速度限制较高的地区事故率较低，但这并不意味着提高速度限制会减少事故。

(b) log(mu) = log(100000) + (-6.5) + (-0.02)(80) + (0.05)(12)

= 11.513 - 6.5 - 1.6 + 0.6 = 4.013

mu = e^{4.013} approx 55.2

预测年度事故数：约 **55 起事故**。

(c) 对速度限制与事故率之间负相关的 2 个混杂解释：

**混杂因素 1——道路类型**：较高速度限制通常设置在快速路和高速公路上，这些道路是为高速交通专门建造的，具有中央隔离带、清晰视线、受控出入口和更好的路面。按每公里行驶距离计算，这类道路的事故率远低于低速度限制的城市道路。这个关联反映的是道路设计和交通管理，而不是速度限制数字本身的直接作用。

**混杂因素 2——农村与城市地区**：农村地区往往速度限制更高（开阔道路），但交通密度更低，行人-车辆互动更少，整体事故暴露也更低。城市地区速度限制较低，但交通环境更复杂，行人更多，交叉口更多，事故率更高。城市/农村特征是混杂因素：它既导致较低速度限制，也导致较高事故率。

在这两种情况下，速度限制都是道路类型或城市化程度的代理变量，而不是事故的直接原因。控制道路类型或城市化程度后，系数很可能会发生显著变化。
