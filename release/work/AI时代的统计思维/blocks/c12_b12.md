(b) 假设你正在为一种非常罕见的疾病测试一种新检测。你认为该疾病患病率可能低到 0.1%，也可能高到 50%。在这里，Jeffreys 先验比均匀先验更有意义还是更没有意义？请解释。

(c) 对大多数实际问题而言，在 Jeffreys 先验、均匀先验和 Beta(1,1)（它也是均匀先验）之间的选择会有多大影响？什么时候会有影响？

**讨论：**

(a) Jeffreys 先验正比于 $\sqrt{I(p)}$，其中对于 Binomial，$I(p)=1/(p(1-p))$。因此 $\sqrt{I(p)} \propto 1/\sqrt{p(1-p)}$，当 $p$ 接近 0 或 1 时很大，当 $p$ 接近 0.5 时较小。直觉是：当 $p$ 接近 0 或 1 时，大多数观测给出相同结果（全是 0 或全是 1），因此数据中的变异很少——关于 $p$ 精确值的 Fisher 信息较低。Jeffreys 先验通过在这些低信息区域放置更多先验质量来补偿，确保相对于数据能够告诉你的内容，先验更加“铺开”。

(b) 对于一种非常罕见的疾病（患病率可能低到 0.1%），Jeffreys 先验（Beta(1/2, 1/2)）在 0 附近放置了相当多的先验概率。这很好地匹配该情景——它并不假设患病率接近 50%。均匀先验（Beta(1,1)）给患病率 = 0.1% 和患病率 = 50% 赋予相同的概率密度，而对于一种已知罕见的疾病来说，这似乎不太合适。在这种情况下，可以说 Jeffreys 先验比均匀先验更合理。

(c) 对于大多数中等到大样本的实际情形，在 Beta(1/2, 1/2)、Beta(1,1)，甚至 Beta(2,2) 之间选择作为比例的先验，通常影响很小。有 50+ 个观测时，数据会压倒这些弱信息先验中的任何一个，后验几乎相同。选择最重要的情形是：(i) 样本量非常小（n < 10），(ii) 参数接近边界（接近 0 或 1），或者 (iii) 你正在计算对尾部区域中的先验非常敏感的量（例如极端分位数）。在测试次数很少的罕见病筛查情景中，先验选择可能有相当大影响——而 Jeffreys 先验在理论上有更好的动机。
