#### 应用题

**Q1.** 一位公共卫生研究者正在估计一个新群体中高血压的患病率 $p$。她有 3 个先验选项：

**选项 A**（无信息）：$p \sim \text{Beta}(1, 1)$（在 [0,1] 上均匀）**选项 B**（弱信息）：$p \sim \text{Beta}(3, 9)$（先验均值 25%，先验 SD 约 12%）**选项 C**（信息性）：$p \sim \text{Beta}(20, 60)$（先验均值 25%，先验 SD 约 4.8%）

她调查了 $n=30$ 个人，发现 10 人患有高血压。

(a) 对每个先验，计算后验参数（$\text{Beta}(\alpha_0+k, \beta_0+n-k)$）和后验均值。(b) 这 3 个后验如何比较？这告诉你关于样本量与先验强度影响的什么信息？(c) 她把样本增加到 $n=300$（保持相同的 1/3 比例：300 人中有 100 人）。重新计算后验并比较。先验的影响发生了什么？

提示

先验均值：A = 1/(1+1) = 50%，B = 3/(3+9) = 25%，C = 20/(20+60) = 25%。后验均值 = $(\alpha_0+k)/(\alpha_0+\beta_0+n)$。

**答案：**

(a) 当 $n=30$，$k=10$：

**选项 A**：后验 = Beta(1+10, 1+20) = Beta(11, 21)。后验均值 = 11/32 ≈ **34.4%**

**选项 B**：后验 = Beta(3+10, 9+20) = Beta(13, 29)。后验均值 = 13/42 ≈ **31.0%**

**选项 C**：后验 = Beta(20+10, 60+20) = Beta(30, 80)。后验均值 = 30/110 ≈ **27.3%**

(b) 3 个后验使用相同数据（10/30 = 33.3%），但均值不同：34.4%、31.0%、27.3%。样本比例是 33.3%。

选项 A（无信息、没有先验偏好）给出的后验均值最接近样本比例。选项 B 和 C 被拉向 25%（它们的先验均值），其中 C 拉得更强，因为它更信息性。信息性先验（C）显著把后验从数据拉开——从 33% 拉向 27%。

这说明在只有 n = 30 个观测时，即使是中等信息性的先验（B）也会对后验产生有意义的影响。强信息性先验（C）会在相当程度上支配数据。

(c) 当 $n=300$，$k=100$：

**选项 A**：Beta(1+100, 1+200) = Beta(101, 201)。后验均值 = 101/302 ≈ **33.4%**

**选项 B**：Beta(3+100, 9+200) = Beta(103, 209)。后验均值 = 103/312 ≈ **33.0%**

**选项 C**：Beta(20+100, 60+200) = Beta(120, 260)。后验均值 = 120/380 ≈ **31.6%**

当 n = 300 时，所有后验彼此之间以及与样本比例都更加接近。即使强信息性先验（C）也只是把后验移到 31.6%，而样本比例为 33.3%——相差 1.7 个百分点；相比之下，在 n = 30 时差异为 6 个百分点。

**结论**：随着样本量增加，数据会压倒先验。当 n = 30 时，先验选择强烈影响后验。当 n = 300 时，数据是决定性的。这说明了一个基本性质：在数据有限时，贝叶斯推断会因先验不同而产生不同结论；但在数据充足时，无论先验如何，它都会收敛到相同结论。
