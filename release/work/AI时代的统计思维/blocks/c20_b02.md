#### 定义：敏感性与特异性

\(\text{敏感性} = \frac{\text{TP}}{\text{TP} + \text{FN}} = P(\hat{Y} = 1 | Y = 1)\) \(\text{特异性} = \frac{\text{TN}}{\text{TN} + \text{FP}} = P(\hat{Y} = 0 | Y = 0)\)

用日常语言来说：

* **敏感性**（也称为**召回率**或**真阳性率**）衡量的是：“在所有实际为阳性的案例中，模型抓住了多少？”它衡量模型检测阳性的能力。
* **特异性**（也称为**真阴性率**）衡量的是：“在所有实际为阴性的案例中，模型正确排除了多少？”它衡量模型排除阴性的能力。

这些都是模型在_给定真实情况_下的性质。它们告诉你，在给定真实标签时，模型会如何表现。

但作为患者和临床医生，我们真正想知道的问题方向相反——是在给定模型_预测_的条件下：

\(\text{精确率} = \frac{\text{TP}}{\text{TP} + \text{FP}} = P(Y = 1 | \hat{Y} = 1)\) \(\text{阴性预测值} = \frac{\text{TN}}{\text{TN} + \text{FN}} = P(Y = 0 | \hat{Y} = 0)\)

**精确率**（也称为**阳性预测值，PPV**）回答的是：“当模型把某个对象标记为阳性时，它实际上为阳性的频率有多高？”

这一区分正是第 3 章讨论贝叶斯定理时的区分。敏感性是 \(P(\text{测试阳性} | \text{有病})\)。精确率是 \(P(\text{有病} | \text{测试阳性})\)。二者通过贝叶斯定理联系起来，并且会随着患病率（基础率）的不同而大相径庭。

#### 常见误解

一个常见错误是把敏感性和精确率混为一谈——或者以为一个高敏感性的模型，其阳性预测也一定高度准确。这是错的。一个把所有东西都标记为阳性的模型可以达到 100% 的敏感性（它抓住了所有真阳性），但其精确率等于患病率（在低患病率场景中，大多数阳性预测都是错的）。敏感性与精确率之间的区别，正是我们在第 3 章第一次遇到的 \(P(B | A)\) 与 \(P(A | B)\) 之间的区别。
