#### 概念检查

**Q1.** 一个二元分类器被应用于某个人群，其中某种状况的真实阳性率为 2%（低患病率）。该模型的敏感性 = 0.95，特异性 = 0.90。计算精确率（阳性预测值）。直观解释为什么精确率与敏感性如此不同。

提示

像第 3 章乳腺 X 线摄影例子那样应用贝叶斯定理。关键是基础率。

**答案：**

使用贝叶斯定理（第 3 章），患病率为 \(P(Y=1)=0.02\)：

\(\text{精确率} = P(Y=1 | \hat{Y}=1) = \frac{P(\hat{Y}=1 | Y=1) \cdot P(Y=1)}{P(\hat{Y}=1 | Y=1) \cdot P(Y=1) + P(\hat{Y}=1 | Y=0) \cdot P(Y=0)}\)

\(= \frac{0.95 \times 0.02}{0.95 \times 0.02 + (1-0.90) \times 0.98} = \frac{0.019}{0.019 + 0.098} = \frac{0.019}{0.117} \approx 16.2\%\)

尽管敏感性为 95%，但只有 16% 的阳性预测是正确的。在每 100 个被标记的案例中，约有 84 个是误报。

**直观解释**：敏感性衡量的是 \(P(\hat{Y}=1 | Y=1)\)——模型找到真实病例的能力。精确率衡量的是 \(P(Y=1 | \hat{Y}=1)\)——阳性预测有多可靠。这些量通过贝叶斯定理联系起来，其中基础率是关键乘数。

在低患病率人群（2%）中，即使敏感性很高，真阳性也很少。但假阳性来自庞大的阴性案例池（98%），即使 10% 的假阳性率应用于 98% 的人群，也会产生远多于真阳性的误报。基础率淹没了信号。这正是第 3 章乳腺 X 线摄影示例：数学完全相同。

**Q2.** 用你自己的话解释 ROC 曲线。曲线下面积（AUC）衡量什么？AUC 为 0.72 在实践中告诉你什么？

**答案：** ROC 曲线展示了当决策阈值从 0 到 1 变化时，分类器的真阳性率和假阳性率如何变化。曲线上的每个点对应一个特定阈值设置：预测概率必须有多严格，才会触发阳性预测？

曲线从 (0, 0) 开始——阈值高到没有任何对象被预测为阳性——并在 (1, 1) 结束——阈值低到所有对象都被预测为阳性。一个好的模型会在保持低假阳性率（不会标记太多阴性）的同时达到高真阳性率（抓住大多数真阳性）——它会向左上角弯曲。

AUC = 这条曲线下面积 = 对模型在所有阈值下区分能力的概括。

**统计解释**：AUC 等于如果你随机抽取一个阳性案例和一个阴性案例，模型给阳性案例分配更高分数的概率。AUC 是一种成对排序准确率：模型有多经常把阳性排在阴性之上？
