#### Ridge = 高斯先验

Ridge 回归最小化 \(\sum (y - f(x))^2 + \lambda\|\beta\|_2^2\)。如第 17 章所示，这就是在每个系数上放置独立的 \(N(0, \sigma^2/\lambda)\) 先验后得到的 MAP 估计。这个先验说：“我相信大多数系数都很小。除非数据强烈要求，否则就向 0 收缩。”

#### LASSO = 拉普拉斯先验

LASSO 回归最小化 \(\sum (y - f(x))^2 + \lambda\|\beta\|_1\)。这是带有拉普拉斯先验的 MAP：

\[
p(\beta_j) \propto \exp(-\lambda\lvert\beta_j\rvert)
\]

与正态分布相比，拉普拉斯分布在 0 处有更尖的峰，并且尾部更厚。这就是为什么 LASSO 会把系数精确地设为 0（稀疏解）：这个先验要求我们相信大多数系数恰好为 0。

#### Dropout = 贝叶斯模型平均

**Dropout** 是神经网络特有的一种正则化技术：在每个训练步骤中，以概率 \(p\) 随机“丢弃”（置零）每个神经元。在测试时，将权重按 \(1-p\) 缩放。

为什么这有效？直观地说，dropout 训练的是一个由略有不同的网络组成的集成（每个网络被丢弃的神经元不同），并对它们的预测取平均。平均会降低方差——这与统计学中的集成方法有效的原因相同（回想第 17 章的偏差-方差权衡）。

更形式化地说，dropout 可以解释为一种**变分贝叶斯推断**：每个 dropout 掩码对应于从网络权重的近似后验中抽取的一个不同样本。在测试时对 dropout 掩码求平均，近似于对这些后验进行边缘化。

Dropout 说：“我不确定这个网络的精确权重。我会把它们看作有一个分布，并在这个分布上求平均。”这就是第 11 章 Thread C 插曲中的贝叶斯神经网络思想，如今被操作化为一个简单的工程技巧。

#### 早停 = 隐式正则化

**早停**指在模型完全收敛到最小训练损失之前停止训练。这也是正则化：提前停止会让参数保持在其初始化值附近，相当于惩罚远离初始化的解。

这种等价关系是精确的：梯度下降中的早停近似等价于 Ridge 正则化。训练步数扮演 \(1/\lambda\) 的角色——步数越少，对应的正则化越强。

统计直觉是：我们把参数初始化在接近 0 的位置（或接近某种先验信念的位置）。随着训练推进，参数会离初始化越来越远，以便更好地拟合训练数据。提前停止意味着保持接近先验——这正是 Ridge 正则化所做的事情。
