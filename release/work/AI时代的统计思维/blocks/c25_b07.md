当我们计算 \(y_t\) 对 \(x_t\)（2 个独立随机游走）的回归系数，并检验其是否显著不同于 0 时，标准 t 检验是为 i.i.d. 数据设计的。对于随机游走，检验统计量不服从 t 分布——它服从尾部厚得多的分布。即使序列真的独立，在天真地使用标准检验时，拒绝“无关系”原假设的概率也可能达到 70–80% 或更高。这就是 Yule 的“无意义相关”——回归看起来高度显著，不是因为序列相关，而是因为标准推断在非平稳序列上失效了。

**修正方法——一阶差分**：

对 2 个序列都做一阶差分：\(\Delta y_t = y_t - y_{t-1}\) 和 \(\Delta x_t = x_t - x_{t-1}\)。对于随机游走，\(\Delta y_t = \varepsilon_t\)——纯白噪声、i.i.d. 且均值为 0。一阶差分后的序列是平稳的。

把 \(\Delta y_t\) 对 \(\Delta x_t\) 做回归，检验的是 \(x\) 的变化是否预测 \(y\) 的变化。如果这些序列确实是独立随机游走，那么 \(\Delta y_t\) 与 \(\Delta x_t\) 将相互独立，标准 t 检验会正确地具有 I 类错误率 \(\alpha\)。

或者，如果 2 个非平稳序列之间存在真实的长期关系（称为协整），一阶差分会移除这种长期信息。在这种情况下，结合差分项和水平项的误差修正模型更合适。

**Q3.** 一位商业分析师使用平滑参数 \(\alpha = 0.2\) 的指数平滑模型预测下个月收入。当前收入是 1.2M USD，当前预测是 1.0M USD。(a) 新预测是多少？(b) \(\alpha = 0.2\) 对模型学习方式意味着什么？

**答案：**

**(a) 新预测**：

\(\hat{y}_{t+1} = \alpha y_t + (1-\alpha)\hat{y}_t = 0.2 \times 1.2 + 0.8 \times 1.0 = 0.24 + 0.80 = 1.04\text{M USD}\)

下个月预测为 1.04M USD——尽管实际收入比预测高 20%，但相较于之前的 1.0M USD 预测只略有变化。

**(b) \(\alpha = 0.2\) 的含义**：

\(\alpha = 0.2\) 是较低的平滑参数——模型适应得“慢”。它给当前观测 20% 的权重，给运行中的预测 80% 的权重。模型的有效记忆跨越许多时期：\(k\) 个时期前观测的权重是 \(0.2 \times 0.8^{k-1}\)。10 个时期前的观测仍得到 \(0.2 \times 0.8^9 \approx 0.027 = 2.7\%\) 的权重。

实际含义是：低 \(\alpha\) 会产生平滑、稳定的预测，但对真实趋势变化反应较慢。当序列有较高测量噪声且真实变化很少发生时，这很合适。当底层过程快速变化时，这并不合适——模型会持续滞后于真实变化。

高 \(\alpha\)（例如 0.8）会快速响应新观测。当序列确实快速变化时，这很合适，但它会产生对一次性噪声尖峰敏感的预测。
