\(\alpha\) 的最优值通常通过最小化训练数据上的一步向前预测误差平方和来估计——使用的正是我们在第 17 章讨论过的模型选择原则（留出验证）。

**Q4.** 一个 ARIMA 模型被描述为 ARIMA(\(p\), \(d\), \(q\))。解释这 3 个参数各自代表什么，并用通俗语言描述 ARIMA(1, 1, 0) 模型说明了怎样的数据生成过程。

**答案：**

**\(p\)——自回归阶数**：用作预测变量的序列滞后取值个数。AR(\(p\)) 组成部分把当前取值建模为前 \(p\) 个观测的线性函数。较高的 \(p\) 表示当前取值依赖许多过去取值。

**\(d\)——差分阶数**：为达到平稳性，序列必须被差分的次数。如果 \(d = 1\)，模型拟合一阶差分 \(\Delta y_t = y_t - y_{t-1}\)；如果 \(d = 2\)，则拟合二阶差分 \(\Delta^2 y_t\)。具有随机趋势（随机游走）的序列需要 \(d = 1\) 次差分才能变得平稳。

**\(q\)——移动平均阶数**：作为预测变量纳入的滞后预测误差（创新）个数。MA(\(q\)) 组成部分把当前取值建模为最近 \(q\) 个预测误差的函数：\(y_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q}\)。

**ARIMA(1, 1, 0) 的通俗解释**：这个模型表示：

* \(d = 1\)：序列有随机趋势——其水平值非平稳，必须做一阶差分。序列不会回归到固定均值，而是可以朝任意方向漂移。
* \(p = 1\)：一阶差分之后，得到的变化 \(\Delta y_t\) 由前一期变化 \(\Delta y_{t-1}\) 预测。如果 AR 系数为正，上一期的正变化会预测本期的正变化。
* \(q = 0\)：没有移动平均组成部分——模型不把过去预测误差作为预测变量。

合在一起就是：“该序列遵循带漂移的随机游走，其中任一时期的漂移倾向于从上一时期延续。”用经济学语言说，这可能描述一种股票价格或汇率，其中今天变化的方向会部分预测明天变化的方向。
