#### 为什么幻觉在统计上不可避免

在这个框架下，幻觉并不神秘——它在数学上就是预期会发生的。

考虑“巴黎”和“1872年人口”在模型学得的分布中分别代表什么。模型见过成千上万份讨论巴黎的文档：它的地理、历史、文化和著名事实。在训练数据中，token 序列“The capital of France is”后面以压倒性概率跟着“Paris”。模型的条件分布几乎把全部概率质量都放在“Paris”上。从这个分布中采样，会可靠地产生正确答案。

现在考虑“The population of Paris in the 1872 census was...”这个序列。它在训练数据中罕见得多。模型见过一些人口普查数据、一些历史文档、一些数字。下1个 token（1个数字）的条件分布是弥散的——分散在许多听起来合理的数字上。模型会采样其中1个数字。它可能是对的（如果相似信息出现在训练数据中），也可能是错的（如果模型是在相关模式之间插值）。无论哪种情况，模型都会用同样“不带置信信号”的文字生成被采样的 token，因为它没有机制来表示自身的不确定性。

**根本问题**：模型输出是从1个分布中抽出的样本。样本就是样本——它不会带着1个标签说明“这是从1个确信的分布中采样的”或“这是从1个弥散而不确定的分布中采样的”。无论哪种情况，输出文本看起来都一样。

这是偶然不确定性（第4章的说法）：采样过程中的随机性。但还存在认知不确定性——由于训练数据有偏或不完整，模型可能在整个领域上系统性地出错。而模型无法区分这两者。


#### 重新审视温度

回忆第4章：**温度**参数 $T$ 控制采样分布的扩散程度。采样前，模型的 logits（原始分数）会除以 $T$：

$p_i \propto \exp\left(\frac{\text{logit}_i}{T}\right)$

* **$T = 1$**：从学得的分布中进行默认采样。
* **$T < 1$**：“冷却”分布——把概率质量集中到高概率 token 上。更可预测、创造性更低、重复性更强。
* **$T > 1$**：“加热”分布——让概率质量分布得更均匀。更有创造性和多样性，但更可能采样到低概率（可能错误或不连贯）的 token。

对于事实回忆任务：低温度更好。对于创意写作：高温度通常更可取。

**Top-p 采样（核采样）**是另一种选择：不改变温度，而是把分布截断为累积概率超过 $p$ 的最小 token 集合（例如 $p = 0.95$），并从该集合中采样。无论极低概率 token 的具体数值如何，这都会自适应地将它们截掉。

对用户来说，关键点是：温度和 top-p 是控制模型采样行为的**统计旋钮**。把温度设为 0（贪婪解码——总是选择最可能的 token）会降低方差，但不会消除错误答案的可能性，因为最可能的 token 仍然可能是错的。
