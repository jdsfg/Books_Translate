(a) 解释岭回归如何等价于对系数具有某种特定先验的贝叶斯线性回归。岭回归隐含使用什么先验？

(b) 一位数据科学家提出：“我们用训练数据上的交叉验证调优了 $\lambda$——所以我们的先验是由数据选择的，而不是事先选择的。这难道不会使贝叶斯解释失效吗？”她应该如何看待这一点？

(c) 团队还考虑 LASSO 回归，它使用 $L_1$ 惩罚而不是 $L_2$ 惩罚。LASSO 产生稀疏解，其中许多系数恰好为 0。什么样的系数先验对应于 LASSO？

提示

对于 (a)：使后验在 MAP 估计处最大化的先验，对应于先验的负对数。对于岭回归（$L_2$ 惩罚），惩罚是 $\lambda \sum \beta_j^2$。什么先验具有 $-\log p(\beta) \propto \beta^2$？

**答案：**

(a) 岭回归最小化 $\text{RSS} + \lambda \sum_j \beta_j^2$。在贝叶斯框架中，MAP（最大后验）估计最大化后验 $\log p(\beta | \text{data}) = \log p(\text{data} | \beta) + \log p(\beta) + \text{const}$。对于 Gaussian 似然，$\log p(\text{data} | \beta) \propto -\text{RSS}$。要使岭回归等价于 MAP，我们需要 $\log p(\beta) \propto -\lambda \sum_j \beta_j^2$，这意味着 $p(\beta) \propto \exp(-\lambda \beta_j^2)$。这是一个 **Gaussian（Normal）先验**：$\beta_j \sim \mathcal{N}(0, 1/(2\lambda))$——以 0 为中心，精度与 $\lambda$ 成正比。岭回归隐含假设每个系数上都有独立的、以 0 为中心的 Normal 先验。

(b) 按照这个说法，担忧是有效的，但在实践中可管理。用交叉验证选择 $\lambda$ 确实使用了数据来设定先验，这就是经验贝叶斯。其含义是：(i) 后验方差被低估（我们把 $\lambda$ 当作已知，而它其实是估计出来的），以及 (ii) 交叉验证对 $\lambda$ 的选择把数据同时用于先验和推断。不过，交叉验证是基于留出数据上的预测性能选择 $\lambda$——它是在选择能产生最佳预测的先验，这是一个合理目标。对于特定系数的推断，应该使用留出集或 bootstrap，以适当考虑 $\lambda$ 中的不确定性。

(c) LASSO 最小化 $\text{RSS} + \lambda \sum_j |\beta_j|$。对应的先验是 $p(\beta) \propto \exp(-\lambda |\beta_j|)$，这是一个 **Laplace（双指数）先验**：$\beta_j \sim \text{Laplace}(0, 1/\lambda)$。Laplace 分布相较于 Normal 在中心附近有更尖的峰且尾部更重，这正是产生 LASSO 稀疏性的原因——许多系数被恰好收缩到 0。Normal 先验（岭回归）产生软收缩，但永远不会恰好为 0；Laplace 先验（LASSO）则会把小系数硬收缩到 0。
