#### 概念检查

**Q1.** 用你自己的话解释维数灾难。给出两个它在实际数据分析中如何表现的具体例子。

**答案：**

维数灾难指的是当维度（特征）数量相对于观测数量变得很大时出现的一组问题。其核心在于：在高维中，空间如此巨大，以至于数据变得极其稀疏，而来自2维或3维的基于距离的直觉会彻底失效。

**例子1——最近邻分类失效**：一位数据科学家使用1,000个患者特征（实验室指标、症状、人口统计信息、遗传标记）来构建用于医学诊断的 k 近邻分类器。训练患者有500人。在1,000维空间中，新患者的“最近邻”在任何临床上有意义的层面上都可能任意不相似——因为在高维欧氏空间中，所有500个训练患者到这个新患者的距离都大致相同。“最近”的邻居可能并没有真正接近。这个分类器实际上会像是在猜测。

**例子2——回归中的过拟合**：一个基因组研究希望用500,000个遗传变异（p = 500,000）来预测2,000名患者（n = 2,000）的疾病风险。OLS 回归没有定义（p > n），但即使是 λ 很小的 Ridge 回归也会严重过拟合：相对于观测数量，自由度太多，模型可以通过利用噪声几乎完美地拟合训练数据，却无法很好地泛化。没有强正则化（用于稀疏性的 LASSO，或 λ 很大的 Ridge），这个模型对新患者没有用。

**Q2.** LASSO 和 Ridge 回归有什么区别？在高维场景中，分别什么时候适用？

**答案：** 我们在第17章已经讨论过这个问题；这里从高维视角重新审视。

**LASSO**（L1惩罚 λ||β||_1）：把许多系数设为恰好0。它同时执行估计和变量选择。得到的模型只使用 p 个特征中的一个子集。

**Ridge**（L2惩罚 λ||β||_2^2）：把所有系数向0收缩，但从不把系数设为恰好0。它使用所有 p 个特征，只是系数较小。

**在高维中**：

**LASSO 适用的情形**：真实模型是稀疏的——只有少数 s ≪ p 个特征真正相关。LASSO 将（在适当条件下）识别这些 s 个特征，并把其余 p - s 个系数设为0。当 p ≫ n 时，这一点尤其有价值，因为被选择出的模型有可解释、可估计的系数。

**Ridge 适用的情形**：许多特征都有小但非零的效应——真实模型是稠密的，而不是稀疏的。Ridge 比 LASSO 更善于处理高度相关的特征（LASSO 往往会从一组相关特征中任意选择一个）。即使 p > n，Ridge 也总是有唯一解。

**弹性网**把两者结合起来：当存在成组相关的相关特征时很有用（LASSO 会选择其中一个；弹性网可以选择整组）。L1 与 L2 之间的平衡由混合参数控制。

实践中，λ（以及弹性网的 L1/L2 混合参数）通常通过交叉验证来选择，而在 LASSO 和 Ridge 之间的选择，部分取决于稀疏信号还是稠密信号在科学上是否合理。
