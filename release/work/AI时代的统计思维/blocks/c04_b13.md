#### 深入思考

**Q1.** 我们说 LLM 产生"幻觉"部分是因为从分布中采样不能保证采样内容为真。但从一个校准良好的分布中采样应该以与其赋予的概率成比例的频率产生真实陈述。一个 LLM 在生成方面"校准良好"意味着什么？这可以实现吗，它能解决幻觉问题吗？

**讨论：** 这个问题探究了 LLM 概率框架的局限。

一个"校准良好"的语言模型，大致来说，会对真实陈述赋予比虚假陈述更高的概率——它不会生成自信的虚假内容。在统计意义上，校准意味着：当模型以高概率说某事时，它在大部分时间应该是真的。

但即使精确定义这一点也有根本困难：

_事实校准 vs. 语言校准_：LLM 在以下意义上是校准的——它们对常见、听起来合理的文本续写赋予高概率。但"常见且听起来合理"不等于"真实"。一个许多人在训练数据中自信地写过的陈述会获得高概率——即使许多人错了。LLM 的分布校准于文本的分布，而非真理的分布。

_认知不确定性 vs. 偶然不确定性_：即使一个完美追踪真理的 LLM 有时也会生成虚假陈述，因为某些真理是概率性的。"凯撒渡过卢比孔河"是确定的；"凯撒有红发"是未知的。一个校准的 LLM 应该对前者赋予高置信度，对后者赋予低置信度。当前 LLM 往往对两者都赋予高置信度——它们并不总是区分"训练数据一致地说 X"和"X 确定为真"。

_所有可能续写的分布_：在生成的任何时刻，模型的分布覆盖整个词表。在每一步对该分布的"校准"并不意味着整个生成的序列是连贯和真实的——错误可以累积。

_良好的校准能解决幻觉吗？_ 部分可以。一个校准良好且不确定的模型会表达那种不确定性（产生"我不确定，但……"而非自信的虚假陈述）。这会使幻觉即使不减少频率也不那么危险。但它不会消除模型因为训练数据自信地错误而自信地错误的情况。

这联系到本章最深的挑战：分布描述数据中的模式，而非真理。统计推断从模式推理到真理，但该推断需要关于数据如何生成的仔细假设。LLM 学习文本的分布；要做出关于世界的可靠声明，你需要的不只是好的文本分布——你需要追踪真理的推理。这就是为什么"AI 这么说"不是一个统计论证。
