#### 预测的根本限制

时间序列预测有硬性限制：

1. **不确定性随期限增长**：预测不确定性（预测区间的宽度）会随着预测期限延长而增长。对于每一步方差为 \(\sigma^2\) 的随机游走，提前 \(h\) 步的预测区间按 \(\pm z_{0.975}\sigma\sqrt{h}\) 增长。提前 4 步的预测，其不确定性是提前 1 步的 2 倍。没有任何方法能从根本上改变这一点——这是不确定性累积的数学结果。

2. **状态转换不可预测**：用 1 个状态下的数据训练出的模型，无法预测状态何时变化。COVID-19 大流行使得基于疫情前数据训练的模型无法用于 2020 年预测。结构性断点——数据生成过程中的突然变化——按定义就无法被那些假设过程稳定的模型预测。

3. **长期期限由不确定性主导**：在足够长的期限上，预测区间会覆盖整个合理的结果范围。30 年经济预测不是预测——它是对情景的描述。对长期预测的信心反映的是过度自信偏差（第 1 章），而不是统计精度。

#### 指数平滑

最简单且有用的预测方法是**指数平滑**。下一期预测是当前观测值与当前预测的加权平均，权重 \(\alpha\)（平滑参数）控制预测适应新信息的速度：

\(\hat{y}_{t+1} = \alpha y_t + (1-\alpha)\hat{y}_t\)

当 \(\alpha\) 接近 1 时：预测会紧跟最近观测值（反应快但波动大）。当 \(\alpha\) 接近 0 时：预测变化缓慢（稳定但对真实趋势变化适应慢）。

指数平滑赋予近期观测比旧观测更高的权重。展开递归可见，时间 \(t+1\) 的预测是所有过去观测的加权平均，权重按几何级数衰减：\(\alpha, \alpha(1-\alpha), \alpha(1-\alpha)^2, \ldots\)。

#### AR 模型：用过去预测未来

**\(p\) 阶自回归模型**（AR(\(p\))）把当前取值建模为前 \(p\) 个取值的线性函数加噪声：

\(y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + \varepsilon_t\)

其中 \(c\) 是常数，\(\phi_i\) 是自回归系数，\(\varepsilon_t \sim \mathcal{N}(0, \sigma^2)\) 是白噪声（不相关）。

AR(1) 模型是最简单的非平凡情形：

\(y_t = c + \phi_1 y_{t-1} + \varepsilon_t\)

如果 \(|\phi_1| < 1\)：该过程是平稳的——它倾向于回到均值 \(\mu = c/(1-\phi_1)\)。如果 \(\phi_1 = 1\)：该过程是随机游走（非平稳）。如果 \(|\phi_1| > 1\)：该过程是爆炸性的（在经济学中少见）。

AR(1) 模型的 ACF 按指数衰减：\(\rho_k = \phi_1^k\)。当 \(\phi_1 = 0.8\) 时，\(\rho_1 = 0.8\)，\(\rho_2 = 0.64\)，\(\rho_{10} = 0.8^{10} = 0.107\)。与过去的相关性会衰减，但衰减很慢。
