#### 概念检查

**Q1.** 把 Bobo 玩偶研究的判定拆成两个部分，并解释为什么把它们混淆是错误的。

提示

一个部分关乎即时情境中的模仿；另一个关乎现实世界媒体效应。哪个是 robust，哪个是 contested？

**答案：** _第一部分，研究本身：_ **robust**。儿童确实会模仿观察到的攻击行为，更广泛的 _观察/社会学习_ 现象（通过观看榜样，尤其是受奖励或受人崇拜的榜样来习得行为）证据充分，并已广泛重复验证。相信这一点。_第二部分，跃迁到“媒体暴力导致现实世界或社会暴力”：_ 这是一个 **独立的 contested** 主张；尤其自大约 2017 年以来，一旦校正发表偏倚并使用更严谨设计，其证据已经转向 _很小或接近于零_ 的效应（Ferguson、Hilgard 等人的工作），不过它仍然真正存在争论。混淆二者是错误的，因为 Bobo 研究只显示儿童会在 _即时情境中、使用同一个道具、片刻之后_ 模仿一个攻击性榜样；它们本身并不确立消费暴力电视、电影或游戏会导致现实世界攻击出现有意义的增加。借 robust 的实验室发现来夹带 contested 的社会结论（“研究证明媒体暴力让孩子变暴力”），是在本书的判定纪律所防范的方式上夸大证据。诚实拆分是：观察学习是 robust 的；社会暴力推论是 contested 且正趋向怀疑；把二者分开，也要抵抗相反但同样过度的说法，即媒体暴力 _绝对_ 没有效果，因为 contested 证据也不支持这一点。

**Q2.** 说明宣泄假说的判定，并解释 _为什么_ 发泄不能减少攻击。

提示

发泄实际上在演练什么？当它与反刍结合时会发生什么？

**答案：** 判定是 **false**，是本书少见的干净失败之一。谨慎实验（尤其是 Bushman 的研究）显示，发泄愤怒并 _不会_ 减少攻击，反而往往会 _增加_ 它，尤其是当它与 _反刍_（发泄时沉溺于挑衅）结合时：被激怒的参与者如果一边想着激怒自己的人一边击打沙袋，之后比什么都不做的人 _更愤怒、更具攻击性_；什么都不做比“发泄出来”更有效。它 _为什么_ 失败：宣泄模型假定一种错误的液压式“心智物理学”，认为愤怒是一种压力储罐，释放出来就会得到缓解。事实上，发泄并不会排空愤怒；它会 _演练和强化_ 攻击反应，练习攻击，并让挑衅在心中保持鲜活，因此治疗反而喂养了疾病。这使宣泄不仅没有支持，而且是 _反着来的_：被推荐的补救办法（出出气、打枕头）让攻击更糟。实践教训是，减少愤怒支持的不是演练它，而是 _不_ 演练它；分心、延迟、重新评价、平复生理唤醒，比戏剧化释放更好。这也清楚说明为什么民间智慧必须被检验，而不能被信任，因为宣泄感觉正确，有古老谱系，但它是 false。
