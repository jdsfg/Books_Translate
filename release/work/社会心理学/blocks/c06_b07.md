#### 应用题

**Q1.** 一篇流行文章写道：“与西方人不同，东亚人不会犯基本归因错误；他们会自然地用情境解释行为。”指出这句话错在哪里，并正确表述这个发现。

提示

差异是在_默认_判断中，还是在_校正_中？错误版本又对一个庞大、多样的人群做了什么？

**答案：** 这句话把方向弄错了，并且在这样做时制造了刻板印象。谨慎的发现是，东亚、集体主义环境中的人_也_表现出个体倾向偏差；在默认情况下，他们也会过度归因于人本身。文化差异不是他们没有这种偏差，或偏差在他们那里被反转，而是当_情境信息变得显著_时，他们更容易_校正_它，把判断朝情境性解释调整。因此，差异在于**校正，而不在于默认值**：被减弱，不是被反转，也不是默认就更弱。流行版本同时犯了两个错误。在经验层面，它误述了结果，在证据显示共享偏差但校正更容易的地方，声称偏差不存在。在社会层面，它把一个庞大、多样的人群压平成一个整齐的特质（“东亚人天生按情境思考”），这正是后面章节会剖析的刻板印象。诚实的表述既尊重真实的跨文化差异，也尊重共同的底层偏差，并且不漫画化任何一种文化。这也是关于文化调节主张的一课：它们是真实的，但在流行写作中被严重过度套用，应该被保持在真实而有限的尺寸上。

**Q2.** 一名经理断定，一个错过 3 次截止日期的员工“就是不够投入”。请带这位经理走一遍“第二想法”，并解释为什么知道基本归因错误本身并不能阻止第一个判断。

提示

偏差是自动的；知识实际上增加了什么？

**答案：** 这位经理的“就是不够投入”是一种快速、自动的个体倾向性归因，是偏差在反思之前启动；本章明确说，知道这个错误_并不能_阻止这个第一想法，因为偏差先于反思，会在知识能够介入之前启动。知识增加的是_第二步动作_：在自动判断之后，经理可以有意地问：“什么情境可能让一个完全普通、投入的人错过 3 次截止日期？”并认真对待它。只要开始寻找，候选的情境原因很多：不可管理的工作量、优先级不清、依赖的另一个人迟到、个人危机、资源缺失、截止日期含糊；每一种都意味着与“不够投入”完全不同的回应（重新界定工作范围，而不是质疑忠诚）。自律之处不在于压制第一想法，那无法可靠做到，而在于建立第二想法的习惯，尤其是在个体倾向式裁决显得显而易见时，因为“显而易见”的感觉本身就是偏差的症状。还要注意，经理也受_自我—他人不对称_影响：如果是经理自己错过 3 次截止日期，他们会很容易引用自己的情境；注意到这种双重标准，是通向更好判断的一条快捷路径。
