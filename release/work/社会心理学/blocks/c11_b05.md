#### 概念检查

**Q1.** 区分通向说服的中枢路径与外周路径，并解释为什么中枢路径的说服往往更持久。

提示

每条路径基于什么？当线索消失时，通过外周形成的态度会发生什么？

**答案：** _中枢路径_涉及对信息实际内容进行认真、费力的思考，因此态度改变取决于论证_质量_；它在人们既有动机（议题对他们重要）又有能力（有注意力可用）认真思考时运作。_外周路径_几乎不涉及认真思考，而是依赖表层线索、信息来源的吸引力或权威、论点数量、情绪基调、简单联想，而不是依赖实质优劣；它在人们分心、漠不关心或不堪重负时运作。中枢路径说服更持久，是因为你是被_仍然可以看见并重新审视的理由_说服的：态度锚定在论证质量上，所以能抵抗反击，并在说服事件之后持续存在。通过外周形成的态度很脆弱，因为它们建立在与议题实质无关的线索上，所以当线索消失时会褪去（名人被遗忘），也可能在更强线索或更好论证出现时逆转。实践结论是：持久说服来自真正好的论证与正在思考的受众相遇，而基于线索的说服容易制造，也容易失去。

**Q2.** 给西奥迪尼的影响原则作总体判定，并解释为什么互惠和社会认同比登门槛技术得到更好支持。

提示

其中 2 条原则其实是较早、已充分确立的现象换了外衣；具名技巧真实存在，但强度如何？

**答案：** 总体判定是 **mixed**：这是一个有用的组织框架，但其中原则获得的支持差异很大，而且它们不是定律。互惠和社会认同得到最好的支持，是因为它们连接到_已经充分确立的现象_：社会认同本质上就是第2章的_信息性社会影响_（把他人的行为作为关于该做什么的证据），互惠则是一种深厚、跨文化 robust 的规范；它们站在坚实地面上，不是因为西奥迪尼的具体演示个个不可动摇，而是因为它们是穿着新标签的老而坚固的效应。相比之下，_登门槛_技术（一个小的初始请求让后来更大的请求更可能被接受）及其镜像_门面拒绝_，是_真实但微小且可变_的：它们出现在许多研究中，也会在另一些研究中缩小或失败，平均效应温和，并且取决于请求大小、延迟时间、谁在请求和所在领域。因此，把登门槛当作可靠杠杆，夸大了一种真实但较弱、依赖条件的效应，而这正是判定透镜要防范的过度自信。自律姿态是按实际证据给每一条原则做判定，而不是把这个目录背成一套可靠定律。
