#### 应用题

**Q1.** 一个犬儒者说：“慈善是假的。人们捐款是为了让自己感觉良好、显得慷慨，所以这其实只是自私。”使用本章的经验/道德区分，指出其中埋着的两个独立主张，并分别评价它们。

提示

一个主张关乎捐赠的动机；另一个主张关乎自我收益是否会抵消道德价值。二者是否同生共死？

**答案：** 这个犬儒者把两个必须独立评价的主张融合在了一起。_主张一（经验）：_ 捐赠至少部分由自我收益驱动，比如感觉良好、显得慷慨。这在很大程度上 _真实且不令人意外_：助人常常确实涉及自我指向成分（情绪、名声、避免内疚），本章对此坦然承认；共情—利他主义证据甚至倾向于认为还存在 _额外的_ 他人指向动机，但没有人否认自我收益通常 _也_ 在场。因此，主张一大体正确，但没有它听起来那么强：“涉及某种自我收益”并不等于“_只有_ 自利”；全局式“其实只是自私”超出了证据所显示的范围（Batson 的工作表明，真正关切通常 _也_ 在运作，而全局利己主义主张面对不可证伪性问题）。_主张二（道德）：_ _因为_ 捐赠涉及自我收益，所以它就是“假的”，不值得赞扬。这个结论并 _不_ 从主张一推出，而这正是犬儒论证真正失败的地方。人们可以同时有 _多种动机_；真诚关心他人福祉，_同时也_ 觉得这有回报，并不矛盾，反而可能正是健康道德心理 _本来的样子_。“任何自我收益都会抵消道德价值”这一前提，是一个被夹带进来的、可争议的 _哲学_ 主张，却被说得像已经确立一样；许多人会主张相反观点：一个人的共情和自利指向同一方向（已经开始觉得助人有回报）时，他比一个只是在逆着自身倾向助人的人 _更_ 可敬，也更可靠。因此，犬儒动作只有在从一个真实但温和的经验主张（助人涉及自我收益）滑向一个贬损性的道德结论（所以它不算）且不注意其间裂缝时才成立，这正是本章的经验—道德防火墙所阻断的跃迁。评价是：主张一部分为真且被夸大；主张二并不随之成立，并依赖一个隐藏且可争议的前提；单凭自我收益的存在，并不能显示慈善是“假的”。
