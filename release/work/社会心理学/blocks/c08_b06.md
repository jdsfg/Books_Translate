#### 概念检查

**Q1.** 什么是“镜中我”，它如何支持自我概念是社会建构的这一主张？

提示

这个隐喻中的“镜”是什么？你的自我图式内容从哪里来？

**答案：** _镜中我_ 是这样一种观念：我们很大程度上是按照我们相信别人如何看待我们来学会看待自己，把周围人的反应当作一面反映“我们是谁”的镜子（“glass”）。它支持社会建构的主张，因为自我概念的 _内容_，即自我图式——你相信自己有趣、聪明、笨拙、擅长运动——压倒性地起源于社会反馈：你学会认为自己有趣，是因为人们会笑；认为自己聪明，是因为你受到称赞，诸如此类。没有一条纯粹内部的、非社会的路径可以形成这些自我信念；它们是由他人的回应组装而成的。本章更强的说法是，在真空中建成的自我并不是一个稀薄的自我，而是 _根本没有自我_，因为身份是由社会材料制成的。镜子并不完美（我们会误读他人，也会有选择地接受某些映像），所以这并不是说我们只是别人怎么说就是什么；但基本架构——从社会反映中启动自我认识——正是使自我概念成为社会性的、而非自我生成的东西。

**Q2.** 为什么本章拒绝把社会比较简单判定为“robust”？它给出的判定又是什么？

提示

社会比较是一个被测量的单一效应，还是一组主张？这套文献的历史有什么特别之处？

**答案：** 本章拒绝干净利落地盖上“robust”印章，是因为社会比较不是一个测量良好的单一效应，而是一个 _有影响力的理论框架_，即费斯廷格的一组相互关联的假设，其 _组成_ 预测在不同条件下的成立程度各不相同。一般现象（人们会通过与他人比较来评价自己）是真实且几乎无法否认的，但许多具体主张（关于我们和谁比较、上行比较与下行比较何时有帮助或有伤害）只在有条件的情况下得到支持，因此这个框架是一个肥沃的组织性观念，而不是一条具有单一效应量的定律。给它盖上“robust”会犯这样的错误：把“总体上显然为真”当作“在每一种具体声称的形式中都为真”。还有一个针对这套文献的谨慎理由：社会比较研究记录中的一部分背负着 _造假包袱_，尤其是迪德里克·斯塔佩尔案，在该案中，一位著名研究者被发现，在横跨社会心理学多个领域的许多论文中伪造数据。这并不会证伪底层观念，但意味着这一领域中某些著名的具体发现值得格外怀疑。因此，诚实的判定不是简单的“robust”，而是“一个有影响力的框架，作为现象是真实的，但其具体效应各不相同，记录也部分受损”。
