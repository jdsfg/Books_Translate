#### 应用题

**Q1.** 回想开篇中电话那头的护士。写出对她行为最强的_个体倾向_解释（关于她这个人），以及最强的_情境_解释（关于她所处的设置）。然后说，哪一种更能预测_其他_具有不同人格的护士在同一情境中会做什么。

提示

如果几乎所有人在一个情境中都以同样方式行动，这说明人格是否是主要驱动因素？

**答案：** _个体倾向：_她异常恭顺、回避冲突，或对自己的判断不够自信；一个更有主见的人会拒绝。_情境：_她独自一人，在夜里，睡眠不足，面对呈现为合法医学权威的东西，身处一个职业和制度之中，而这个职业和制度在多数时候出于极好的理由训练人们迅速遵从医生的医嘱；违反规则是真实的，但每一个单独的危险信号都能在当下被合理化，房间里也没有盟友来打破这种魔力。现在关键动作来了：研究中_几乎每一名_护士都开始走向药柜。当一个情境让人格很不相同的人产生同一种行为时，正在提供解释的是情境，而不是人格。这是整个领域的发动机，也是为什么情境说明在你第一次读到时感觉像较弱的故事，实际上却是更强的预测者。这就是线索 A 的微缩版，而我们会在第3章以完整力量随米尔格拉姆回到它。

**Q2.** 一篇新闻报道说，“一项经典心理学实验已被推翻”。使用五级判定，列出在你接受“被推翻”这个词之前，你想要得到答案的问题。

提示

“被推翻”是在用 5 种判定中的一种替所有 5 种做工。它抹去了哪些区别？

**答案：** “被推翻”把几种非常不同的情形压扁在一起，所以要问：（1）是_效应_未能复现，还是一个真实效应的某个戏剧性_解释_受到了挑战？这分别是 **failed** 与 **contested interpretation**，二者相差极远。（2）是整件事都倒下了，还是一个组成部分倒下了？这是 **failed** 与 **mixed** 之间的区别。（3）挑战的是_实验_，还是关于它的_通俗故事_？有时科学本身没有问题，错的只是传奇，这就是 **myth versus record**。（4）是谁在提出这个主张，原作者或其他实验室有没有回应？一篇批判性论文是一场对话的开始，不是结束。在你知道自己面对的是哪一种之前，“被推翻”只是标题，不是裁决。学会提出这些问题，正是本书要给你的技能。
