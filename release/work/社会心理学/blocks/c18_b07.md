#### 应用题

**Q1.** 一位学校辅导员设立了一个“愤怒房”，让压力很大的学生可以砸东西来“释放愤怒、冷静下来”。使用本章内容评价这一干预，并提出有证据支持的替代方案。

提示

哪个被判定的发现直接对应“释放愤怒”？预期效果是冷静，还是相反？

**答案：** 愤怒房建立在 **宣泄假说** 之上，而本章把它判定为 **false**，所以这一干预很可能 _适得其反_。在愤怒时砸东西，正是 Bushman 的工作显示会 _增加_ 而不是减少愤怒和攻击的发泄加反刍场景：该活动 _演练并强化_ 攻击反应，让挑衅保持活跃；什么都不做反而更能冷静。因此，愤怒房可能不会帮助学生“冷静下来”，而是让他们 _更愤怒_、更容易攻击，同时误导性地感觉它帮了忙（主观上的释放感正是 false 信念持续存在的一部分原因）。有证据支持的替代方案应针对愤怒减少的实际机制：_分心和延迟_（把注意从挑衅上移开，让生理唤醒在行动前下降，“数到十”的直觉比发泄更有支持）、_认知重新评价_（重新框定挑衅情境，质疑滋养愤怒的解释）、_直接平复唤醒_（缓慢呼吸、身体放松、并不被框定为攻击挑衅者替身的运动），以及在可能时 _解决_ 潜在挫折（回想修订后的挫折—攻击观点：处理不正当或出乎意料的阻碍）。辅导员还应考虑本章的 _情境性_ 杠杆：减少环境中的挑衅、线索、炎热和不适，因为这些因素塑造攻击，不只是学生的“愤怒水平”在起作用。更深一点说，这又一次加倍体现了本书的主题：愤怒房既是信任 false 民间智慧（宣泄）的例子，也是一个 _个体倾向式_ 修复方案（排空个体的愤怒），而证据更支持 _情境式_ 方法（减少挑衅和唤醒，培养重新评价技能）；把两课都学到，干预就会反转。
