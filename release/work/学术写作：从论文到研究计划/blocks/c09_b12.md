#### 概念检查

**问题 1.** 区分研究计划书与研究论文的核心修辞倒置是什么？

提示

本章开头和 Przeworski–Salomon 画像（§9.8）直接点明了这一倒置。

**答案：** 研究论文报告已经存在的发现；评审者问的是“你是否发现了你所说的发现？”研究计划书推销尚不存在的发现；评审者问的是“你是否会发现任何值得资助这场探寻的东西？”研究计划书必须对尚未完成的工作的重要性、方法和预期结果作出具体说明——在体裁要求承诺之处作出承诺，同时在适当之处承认未知。

**问题 2.** 请说出并界定本章所使用的 _特定目标_。

**答案：** 特定目标是拟议项目中聚焦且可实现的子目标，其表述应足够具体，使其可从可行性和贡献两个方面接受评价。大多数获得资助的研究计划书围绕 2–4 个特定目标组织；目标应当具体（评审者能看出提议做什么）、相关但独立（任何单一失败都不会使项目崩溃），并且相称（能在拟议时间和预算内完成）。

**问题 3.** 什么是 _钩子测试_，它提出哪 3 个问题？

**答案：** 钩子测试是对研究计划书第一句话的诊断。它提出：（1）这句话是否说明了利害所在？（2）它是否可能成为任何其他研究计划书的第一句话？（3）忙碌的评审者会不会想读第二句？未通过的钩子通常需要重写；这种重写往往是整份研究计划书中杠杆率最高的半小时工作。

**问题 4.** 为什么本章认为，在研究计划书中过度使用模糊限制是错误的，尽管它在讨论中是一种优点？

**答案：** 因为研究计划书是在请求资助方为未来工作提供资金；过度使用模糊限制会传达出作者不确定该项目是否值得资助，这会自我削弱。惯例是在专门部分（应急方案、替代结果）承认风险，同时作出具体承诺。经校准的承诺——对你将要做什么（方法、交付成果、时间线）作出承诺；对自然将揭示什么（具体发现）使用模糊限制——就是研究计划书的语气。
