#### 图

图擅长：

* **随时间变化的趋势**（预算增长逐年的折线图）
* **分布**（直方图、密度图）
* 比较**模式**而非精确数值（间距充足的条形图）
* **空间关系**（地图、网络图）
* 面向**略读的读者**沟通（设计良好的图即使在文字未被阅读时，也能承载标题式发现）

图不擅长：

* **精确数值**（读者无法从条形图中提取“670 万美元”）
* **一次呈现许多变量**（线条、颜色或分面太多的图会变成噪声）

Tufte 规则同样适用：最大化数据-墨水比（每一个视觉元素都应传达数据，而不是装饰）；避免 3D 效果、彩虹色板和图表垃圾；尽可能直接标注，而不是依赖图例；选择与数据结构相匹配的图表类型。

对_本_书而言，图的设计没有_是否决定使用_图那么重要，因为我们是在纯文本 Markdown 中工作，不能包含图像。（本书的真实纸质版本会有许多图；文本版依赖表格。）可迁移的原则是：当发现是一个_模式_——趋势、分布、比较形状——图比文字沟通得更好。

#### 文字

文字擅长：

* **解释**——数据说明了什么，什么令人意外，什么重要
* **把发现连接到引言的问题**——回答“我们是否发现了原本想寻找的东西？”
* **框定接下来发生什么**——把读者引向讨论
* **处理例外、限定和边缘案例**，即那些不能整齐放入表格或图的内容

文字不擅长：

* **连续报告许多数字**（米拉的例子）
* **显示比较结构**（表格在这方面做得更好）
* **传达分布中的模式**（图在这方面做得更好）

结果部分中的文字应当进行解释，而不是复制数据。一个有用的测试是：阅读你结果部分的每一个段落，并问：_"如果表格和图的引用被移除，这个段落仍然说得通吗？"_ 如果是，你的文字就在做文字的工作。如果不是——如果段落没有表格就垮掉——你的文字就在_复制_表格数据，你应该删减它。


#### 定义：学术写作中的展示与讲述

在学术写作中，**展示**意味着以读者可以直接检视的形式呈现证据——数据、例子、引文。**讲述**意味着用解释性语言陈述关于这些证据的主张。写得好的结果部分主要进行_展示_，并用文字_讲述_读者在展示中应该看什么。

用普通语言说：展示是表格、图、引用摘录。讲述则是说明_表格证明了什么，图揭示了什么，摘录说明了什么_的句子。新写作者常常只_讲述_而不_展示_（没有证据的断言）；有经验的写作者则容易犯相反的错误（只展示而不讲述，让读者自己弄清意义）。恰当的平衡是充分展示、精确讲述，而且讲述要把读者指向展示中重要的部分。
