#### 应用题

**问题 1.** 取米拉在 §9.1 中第一稿研究计划书开头（论文式开头），将其重写为一个能通过钩子测试的研究计划书钩子。将 3 个钩子测试问题应用到你的重写版本上。

提示

§9.1 的例子展示了一种可能的重写。试着用不同的利害命名方式产出你自己的版本（例如，以不同方式命名政策利害，或更突出地命名理论利害）。

**答案：** 成功的作答会（1）产出一个命名具体利害的钩子（而不只是“日益受到关注的话题”），（2）具有辨识度（不可能作为任何其他研究计划书的开头），（3）让评审者想读第二句，并且（4）明确依据 3 个钩子测试问题评价重写版本。成功重写中最常见的改进，是从 _抽象的话题识别_（“某话题很重要”）转向 _具体的利害命名_（“某话题被错误配置 / 未被研究 / 存在争议”）。

**问题 2.** 取一份你自己当前或近期的研究计划书，应用 §9.9 中的审校：钩子测试加目标审校。提交原始钩子、重写后的钩子、原始目标、重写后的目标（如有修订），以及一段 200 字的反思，说明发生了什么变化。（如果你没有自己的研究计划书，就使用一份公开存档的已获资助研究计划书——许多资助机构会发布示例——并应用审校。）

**答案：** _答案会有所不同。_ 成功的作答会（1）准确识别原始钩子中的弱点，（2）产出一个通过钩子测试的重写版本，（3）从具体性、独立性和相称性审校目标，并且（4）反思发生了什么变化。最有用的反思常常会指出，研究计划书的表面弱点并不是方法或贡献，而是 _框定_——钩子和目标没有完成体裁所要求的说服工作。（与第 4 章的联系：研究计划书的钩子类似于 CARS（创建研究空间）引言，但更具进攻性；语步相似，但校准更偏向承诺。）
