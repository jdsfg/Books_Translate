**答案：** _答案会有所不同。_ 成功作答会 (a) 预期可预测的问题（主线；累积贡献；方法；替代解释；局限；下一项研究），(b) 提供具体、经过校准的回答，并 (c) 在适当处引用学位论文的章节。常见观察包括：起草清单会暴露出写作者此前没有预期到的问题；有些问题的回答还需要写作者进一步发展。

**Q3.** 取一份近期被拒稿的材料（同行评审、基金、会议投稿），使用 §16.6 的模板进行一次拒稿后自我评审。哪些是实质性批评？哪些是风格性批评？哪些是发表渠道特定的批评？在重新提交前，这项工作需要哪些修订？写250字。（与第11章的连接：这把回应信技艺延伸到拒稿后的规划阶段。）

**答案：** _答案会有所不同。_ 成功作答会 (a) 诚实区分实质性批评与风格性批评（而不是把所有批评都说成误读），(b) 识别哪些修订可以转移到下一个发表渠道，哪些是发表渠道特定的，(c) 规划一种修订方法。常见观察包括：在情绪恢复到足够程度之后进行拒稿后自我评审，往往会显示比写作者最初感觉到的更多批评是实质性的——而下一次投稿也因此可以明显更强。

**Q4.** 与一位同事配对：你们各自评审对方的一份草稿。然后反思外部评审捕捉到了哪些你自己的内部评审漏掉的内容（或没有漏掉），以及你的内部评审捕捉到了哪些外部评审漏掉的内容。写200字。（连接：这会把你的内在敌意读者与实际外部评审进行校准。）

**答案：** _答案会有所不同。_ 典型的成功作答会指出写作者内部评审中的具体缺口（常见的有：写作者离具体主张太近，因而看不到过度主张；写作者的语气一致性检查漏掉了新读者能发现的不一致；写作者的预期异议清单漏掉了相邻子领域中的异议）。这个练习会校准内在读者：经常与外部评审进行比较的写作者，可以磨利自己的内在读者，使其捕捉到更多原本需要外部评审才能发现的内容。
