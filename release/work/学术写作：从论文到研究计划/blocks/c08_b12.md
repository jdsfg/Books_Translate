**Q3.** 阅读你的目标发表渠道中的 3 篇摘要（与第 2 章的三篇论文阅读法相同）。对每篇摘要识别：结构（按时间顺序 / 倒金字塔 / 结构式）；语气（主动 / 被动 / 混合）；校准（过度声称 / 已校准 / 声称不足）；引用密度（通常为 0）；以及长度。写一段 250 词评论，说明你的发表渠道奖励什么，以及你自己的摘要在哪些地方偏离。

**答案：** _答案会有所不同。_ 典型的成功作答会指出，发表渠道的惯例比作者原先以为的更紧——倒金字塔比作者意识到的更占主导，校准比作者草稿中表现出的更保守，长度规范比作者投稿时设想的更严格。这个练习会磨利语步 1（第 2 章）所说的发表渠道特定眼光。

**Q4.** 为一篇你_目前并没有_在写的论文撰写一篇 200 词倒金字塔式摘要——一篇你所在领域的假想论文。这个练习会在低风险情境中教会你这一结构，然后再把它应用到真实投稿中。（与第 4 章假想引言练习的联系：逻辑相同，体裁不同。）

**答案：** _答案会有所不同。_ 成功作答会（a）在第 1 句以贡献开头，（b）包含所有常规组成部分（动机、方法、发现、启示），（c）达到字数限制，并且（d）按照第 7 章的矩阵进行校准。初次尝试最常见的失败模式是：贡献太泛泛；启示只是装饰；摘要超过 200 词。如果第一次尝试出现这些问题中的任何一个，就值得做两遍。
