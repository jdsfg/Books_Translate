### 5.5 模板与示例

模板很少能够在不同方法之间顺利迁移（一篇定量回归研究的方法部分，和一篇定性案例研究的方法部分完全不同），但少数句子层面的模式可以迁移。

**样本/参与者：**

> _“样本包括 [N] 名参与者（平均年龄 = [X]，标准差 = [Y]；[人口统计构成]）。参与者通过 [方法] 从 [来源] 招募。样本量由 [检验力分析 / 理论饱和 / 可获得性] 确定，得到 [N]，这为感兴趣维度提供了 [足够检验力 / 跨维度的理论饱和 / 覆盖]。”_

**程序：**

> _“每位参与者在一次 [时长] 的环节中完成 [任务/访谈/方案]。程序如下。首先，[步骤 1，含相关细节]。其次，[步骤 2]。第三，[步骤 3]。完整方案作为补充材料提供。”_

**分析（定性）：**

> _“文件被导入 [软件]。初始编码采用归纳路径，并受 [框架] 启发。在 [N] 份文件完成编码后，代码本被审阅并修订；[N1] 个代码被合并，[N2] 个新代码被加入，较早编码的材料则按照修订后的代码本重新编码。编码者间信度在 20% 的双重编码子集上评估，得到 [κ = X]。”_

**分析（定量）：**

> _“统计分析在 [软件，版本] 中进行。我们使用 [模型类型] 对 [结果变量] 建模，并纳入 [预测变量] 和 [随机效应 / 聚类结构]。系数与 [95% 置信区间 / 标准误] 一并报告。所有检验均为双尾检验，α = 0.05。用于复制的代码和数据可在 [存储库] 获取。”_

**方法中的局限（与讨论中的局限相对）：**

> _“我们在这里描述的方法有若干局限。第一，[局限 1，简要说明]。第二，[局限 2]。我们在 §[讨论部分编号] 中讨论这些局限对研究发现的影响。”_

模板是起点，不是完成的正文。技艺在于你填入的细节。
