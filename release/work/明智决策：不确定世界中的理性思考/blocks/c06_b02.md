#### 定义：得克萨斯神枪手谬误

得克萨斯神枪手谬误发生在我们先观察数据，再挑选支持某一结论的模式，而非在看数据之前预先指定假设之时。

用大白话说：我们看一片数据的海洋，在某处找到一个模式，构建一个故事说该模式是有意义的信号，并把其余所有数据当作噪声忽略。

这一谬误出现在极其广泛的领域：

**在医学中：** 一项研究观察到喝咖啡的人某一种特定癌症的发病率更低。一个引人入胜的故事被构建出来：咖啡预防癌症。但如果研究者检验了 50 种癌症，仅凭偶然就会期望找到 2–3 个"统计显著"的结果（在 p < 0.05 阈值下）。研究在噪声中找到了模式——然后在它周围画上了靶心。

**在金融中：** 基金经理 X 连续 5 年跑赢市场。一个引人入胜的故事被讲述：X 有非凡的技能。但鉴于有数百名基金经理，仅凭偶然就会有一些人连续 5 年跑赢市场。故事把 X 选为技能的证据，忽略了从中选出 X 的广大经理群体。

**在历史中：** 德国二战后的快速经济复苏被引为纪律与勤奋带来繁荣的证据。但马歇尔计划、冷战地缘政治对西方投资的激励、作为反共措施对工会议价的压制、有利的战争债务条件，以及人口因素都有贡献。"纪律与勤奋"的故事挑选了某些因素而忽略了其他——在一个偏好的模式周围画上了靶心。


#### 常见误解

*"如果一个模式是统计显著的，它就不可能是得克萨斯神枪手的结果。"*

这是不正确的。统计显著仅意味着：在零假设下——即效应为零的假设——看到一个*至少与所观察一样极端*的模式的概率低于某个阈值（通常是 5%）。但如果你检验 50 个模式，你会期望仅凭偶然得到 2–3 个"显著"结果。显著性检验假定你在看数据之前有预先指定的假设。当模式是事后从数据中挑选的——如得克萨斯神枪手情景——显著性检验给你一种虚假的安全感。这在科学文献中被称为"p 值操纵"（p-hacking）或"数据挖掘"（data dredging），它要对未能复现的研究中相当大一部分负责。
