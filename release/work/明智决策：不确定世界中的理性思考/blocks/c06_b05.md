#### 概念检查

**Q1.** 用你自己的话解释得克萨斯神枪手谬误。为什么"靶心"是在_看过_数据*之后*画上的这一点很重要？

**答案：** 得克萨斯神枪手谬误发生在某人观察数据、在其中找到一个模式，然后把该模式呈现得仿佛是预先指定假设的结果——而非事后挑选的。时机至关重要，因为统计检验被设计来评估：如果零假设为真，找到某个特定模式的概率。但这一概率计算假定你心里有一个预先指定的模式。如果你先看数据再选择报告哪个模式，你实际上在隐式地运行许多检验（对应你评估并丢弃的每一个模式）却没有对这种多重检验做任何校正。在一个大数据集中仅凭偶然找到某个"显著"模式的概率非常高——远高于 5%。在开枪之后再画靶心，意味着子弹总是命中；谷仓上的弹孔不再是技能的证据。

**Q2.** 幸存者偏差如何影响商业图书这一体裁？为什么畅销商业书中的建议可能是系统性误导的？

**答案：** 商业书压倒性地聚焦成功的公司与创业者。隐含论证是："公司 X 做了做法 A、B、C——并成功了；因此 A、B、C 导致成功。"但这犯了幸存者错误。许多失败的公司也做了 A、B、C——失败案例被排除，因为出版商不卖关于失败公司的书（或失败公司很少有人为它们写书）。成功公司中可见的做法可能在失败公司中也同样广泛存在——那样的话它们就不能预测成功。菲尔·罗森茨魏格（Phil Rosenzweig）的著作《光环效应》（_The Halo Effect_）专门记录了这一点：当公司成功时，观察者将其做法（去中心化管理、以客户为中心、强大文化）归因于成功；当同样的公司后来失败时，完全相同的做法被重新描述为失败的原因（结构不聚焦、对客户过度迁就、邪教般的封闭）。因果故事变了；做法没有变。
