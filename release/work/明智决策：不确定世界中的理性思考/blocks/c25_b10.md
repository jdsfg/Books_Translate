**Q4.** 一位有前列腺癌家族史的 62 岁男性被提供 PSA 筛查。他的医生解释 PSA 筛查有 70% 敏感性、25% 假阳性率，且他年龄与家族史男性中临床显著前列腺癌的基础概率约 3%。他将需要决定是否筛查。他需要什么信息做知情决策，他应如何权衡权衡？

提示

计算给定阳性结果时真正癌症的概率。然后考虑接下来发生什么（活检、治疗），以及过度诊断关切在实践中意味着什么。

**答案：** 用他剖面 10,000 名男性的贝叶斯计算：

**有临床显著前列腺癌的男性：** 3% × 10,000 = 300  **无的男性：** 9,700

**在 300 名有癌症者中：** 70% 敏感性 → 210 真阳性；90 假阴性  **在 9,700 名无癌症者中：** 25% 假阳性率 → 2,425 假阳性；7,275 真阴性

**总阳性 PSA 结果：** 210 + 2,425 = 2,635  **给定阳性 PSA 的显著癌症概率：** 210 / 2,635 ≈ **8%**

他需要理解以做完整知情决策的：（1）阳性 PSA 结果指示约 8% 临床显著癌症概率——意味着约 92% 阳性结果将导致活检并最终不是临床显著癌症。这不意味着筛查无用——它把他的概率从 3% 实质升高——但意味着他应准备高可能进一步检测最终不确认癌症。（2）**过度诊断关切：** 前列腺癌存在于光谱上；许多检测到的癌症生长缓慢，永不会造成症状或死亡。筛查检测到其中一些，导致造成副作用（失禁、性功能障碍）而不延长生命的治疗（手术、放疗）。这是前列腺癌筛查特有的过度诊断问题。（3）**他的价值：** 他想知道可能永不会伤害他的生长缓慢癌症吗？他如何权衡假阳性的焦虑与干预风险相对早期检测侵袭性癌症的潜在收益？（4）**家族史语境：** 他的家族史增加侵袭性前列腺癌可能性，后者更可能从早期检测受益——这相对无家族史男性把收益-风险计算移向有利于筛查。
