**步骤 3：AI 助手（生成替代方案并挑战你的推理）。** 与 LLM 分享决策框架："这是我在做的职业决策、我在考虑的选项，以及我当前的推理。我错过了什么替代方案？我推理中的什么假设可能错？反对我当前首选选项的最强论证是什么？"用 LLM 的输出测试你是否考虑了完整选项空间，并钢人化反对你首选选择的理由。不要把 LLM 的推荐当作决定性——它缺乏对你特定情境的知识。用它扩展你的思维并识别盲点。

**整合：** 若步骤 3 浮现你未考虑的新选项或替代方案，修订你的决策树。带着对关键剩余不确定性的显式承认，以及界定的监测计划做最终决策（什么信号会告诉你决策是否按预期运作，你将在什么点重新评估？）。
