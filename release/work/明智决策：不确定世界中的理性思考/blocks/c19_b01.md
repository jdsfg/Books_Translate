杰夫·贝索斯有一个简单的决策心智模型：有些决策像走过一扇双向摆动的门——若你不喜欢另一边，可以回来。另一些像走过一扇单向门——一旦穿过，就无法返回。

他称之为 Type 1 与 Type 2 决策。Type 1 决策是后果重大且不可逆的：收购、重大产品方向、根本架构选择。Type 2 决策可逆且易于更改。他的洞见来自运营一家以巨大规模做决策的公司：多数组织把 Type 2 决策当 Type 1 对待——对可以轻易撤销的选择施加沉重流程与谨慎。两个方向都是错误。Type 1 决策要求极端小心；Type 2 决策要求速度。

决策的可逆性，是做出决策前关于它最重要的事情之一。


### 18.1 不可逆性光谱

决策并不整齐落入两个类别。它们存在于从完全可逆到完全不可逆的光谱上，大多数真实选择介于两者之间。


#### 定义：可逆性

若一项决策能以零成本撤销——精确回到先前状态——它就是完全可逆的。若撤销不可能或代价高得令人却步，它就是完全不可逆的。大多数决策是部分可逆的：它们可以改变，但只能以时间、金钱、努力或机会的某种成本。

什么决定一项决策落在可逆性光谱的何处？

**沉没资源：** 消耗不可收回资源（已花费的时间、形成或破裂的关系、对环境的物理改变）的决策更不可逆。你无法"取消花费"一天。

**第三方不可逆性：** 若你的决策影响他人，使他们采取有后果的回应行动，撤销你的决策可能无法撤销他们的回应。你可以撤回工作邀约；你无法撤销候选人对前任雇主辞职的决定。

**物理不可逆性：** 有些改变无论多少资源都无法撤销：你无法"取消知道"某事、"取消说出"某事，或"取消损害"信任关系。

**市场不可逆性：** 在市场中，你的决策影响价格与可得性。买入创造影响价格的需求；卖出影响市场信号。你往往可以向另一方向交易，但市场已经移动。

**心理不可逆性：** 经验与信息改变你。即便外部环境被恢复，"回来"的人也与离开的人不同。


#### 常见误解

_"可逆决策不太重要——你总能撤销它们。"_

可逆性并不意味着决策不重要。一项做得糟糕并反复做出的可逆决策——同样的错误一次又一次——累积成显著成本。更精确地说：可逆性决定_所需审议量_，而非_重要性_。可逆决策值得速度与实验；不可逆决策值得深度审议，无论表面利害如何。
