**答案：** 评估框架：（1）**LLM 实际知道什么？** 它知道你告诉它的（5 年经验、当前薪资、竞争邀约）以及训练数据中谈判建议的一般模式。它不知道：你特定公司的薪资带与典型还价区间、你经理的谈判风格与权限、你竞争邀约之外的杠杆、你的非薪资优先级（股权、头衔、灵活性）、你特定技术栈与地理的就业市场，或你对谈判失败的风险承受力。（2）**LLM 可能在做什么？** 生成匹配常见谈判启发式的建议："在竞争邀约之上再要 10–15%"，或"高锚定"，或"不要透露底线"。这些启发式可能适用也可能不适用于你的特定情境。（3）**它可能在哪里错？** 竞争邀约语境差异巨大：来自 FAANG 公司的竞争邀约与来自初创的信号不同。LLM 可能不适当加权这些差异。薪资带与典型谈判空间因公司规模、行业与地理而异。（4）**如何使用它：** LLM 的回应作为起始框架、以及你可能未考虑之选项的来源有用。对照近期、领域特定来源（行业薪资调查、类似角色的同事）核实一般启发式。具体数字应由你自己对公司薪资带的研究（Glassdoor、Levels.fyi）以及与曾与该雇主谈判之人的交谈告知。用 LLM 准备你的谈话要点并预见反驳——这是 LLM 增加真正价值的地方。
