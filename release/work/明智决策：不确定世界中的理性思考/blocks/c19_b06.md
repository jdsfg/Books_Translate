#### 概念检查

**Q1.** 什么使一项决策不可逆？给出三种降低可逆性的不同机制。

**答案：** 当一项决策无法以零成本撤销——回到先前状态不可能或代价高得令人却步——它就是不可逆的。三种降低可逆性的机制：（1）**已消耗资源：** 无论你下一步做什么，已花费的时间、金钱或努力都无法收回。辞去工作、花掉储蓄，或在一条路径上投入数年，创造了真正消失的沉没成本——你可以做新决策，但无法收回已花费资源。（2）**第三方行动：** 当你的决策促使他人采取他们自己的不可逆行动时，级联难以逆转。宣布合并使交易对手重组；裁员使员工找到新工作；违背承诺使他人停止信任你——即便你撤销原始决策，这些都不易撤销。（3）**关系与声誉效应：** 信任一旦破裂，无论随后行为如何都无法完全恢复。被决策改变的关系——结束的友谊、变味的合伙、移动的声誉——可能被永久改变。这些心理与社会不可逆性往往相对财务不可逆性被低估。

**Q2.** 杰夫·贝索斯区分 Type 1（单向门）与 Type 2（双向门）决策。决策类型应如何改变决策过程？

**答案：** Type 1（单向门，不可逆）决策要求：（1）更多审议——承诺前收集更多信息，因为没有纠正机会；（2）更多利益相关者——当错误无法撤销时，更广咨询合理；（3）更显式地考虑下行情景——失败看起来像什么，它可存活吗？；（4）事前复盘思维——事先想象失败以浮现被忽略的风险。Type 2（双向门，可逆）决策要求：（1）速度——对可逆决策的缓慢审议是浪费，既有时间成本，也有行动本会生成的有价值信息的延迟；（2）实验——既然决策可撤销，尝试并从结果学习往往优于延长分析；（3）授权——可逆决策可以下推到组织或个人层级的较低层次，那里情境更丰富、速度更高，而无显著下行风险。贝索斯的洞见：多数组织混淆类型，对 Type 2 决策应用 Type 1 过程（太慢），偶尔又对 Type 1 决策过于随意（太冒险）。诊断——这是哪一类型？——是好过程设计的第一步。
