#### 定义：改写历史

**改写历史**指的是改变已经存在的快照：把几个合成 1 个，编辑旧说明，丢弃某个快照，重排链条。普通工作只是在末尾**添加**新快照；改写则伸手回到过去，改变链条本身。对于私人、未共享的工作，它是在别人到来前整理内容的安全方式。对于共享历史，它是 1 个常见操作中真正可能毁掉别人工作的那个，因为别人的副本是建立在你正在替换的版本之上的。

执行共享改写的机制通常是**强制推送**：用一种压过并替换共享版本的方式发布你的改写版本，而不是礼貌地添加到它之后。正常发布会拒绝覆盖；强制推送会坚持覆盖。你不需要记住这个词，也不需要记住任何命令。你只需要记住它**做了什么**：它是工具在说“把共享的东西替换成我的版本，哪怕它们不一致。”这正是值得完全停下来的动作。

**安全请求：** **在你改写任何共享历史或覆盖发布别人的工作之前，停下来问我。** 把这 1 句话交给你的智能体，就能把险些出事变成普通的星期二。智能体已经知道如何检查历史是否被共享。你的工作是确保它总是在那条线前暂停，让人来决定。

Maya 做了什么？她反过来问智能体：这段历史还私有吗？答案是否定的；它在 GitHub 上，也在 Theo 的笔记本电脑上。所以她没有整理它。1 条写着“fix again”的混乱说明，是一个微小、无害的瑕疵。为了去掉那个瑕疵而覆盖合作者的地基，并不是值得做的交换。她让历史保持原样，并从此开始写更好的说明。她想要的清理，是给**未来**的私人工作用的，在共享之前完成；那才是改写该待的地方。

#### 常见误解

**“改写历史是高手才会用的高级操作。”** 它是一个工具，而像大多数工具一样，它在一个地方很好用，在另一个地方就是危险物。对你自己的未共享工作来说，整理历史确实有用，而且完全安全。对共享历史来说，它是合作者互相覆盖的最常见方式。技能不在于把它用得多漂亮；技能在于学会那个能告诉你自己处在哪种情形的问题。问“这被共享了吗？”危险就会自行分类。
