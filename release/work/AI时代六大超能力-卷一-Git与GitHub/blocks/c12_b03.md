### 11.2 面向别人作品的三个问题

从第 2 章开始，你一直带着三个起飞前检查问题；到目前为止，你一直把它们用于自己的更改。在改动之前，你会问：**具体会改什么？我们能回去吗？这段历史已经分享出去了吗？**

这些问题安静的力量在于，当它们指向**别人**的更改时，也同样有效。Maya 把三个问题都用在 Núria 的提议上，你可以看到它们多么自然地转换过去。

**具体会改什么？** 这就是用白话读出来的差异。一个咖啡馆移出，一个咖啡馆移入，一个错别字修正。Maya 现在准确知道这些，而不是含糊知道。她批准的不是“Núria 的改进”。她批准的是**这两个具体编辑，而且没有别的。**如果差异显示了她没预料到的更改，比如一个她从未讨论过的开头段落被重写，或者某一节被悄悄删除，这个问题就会抓住它。批准意味着你已经诚实回答了这个问题。

**我们能回去吗？** 几乎总是可以，而这里还让人加倍安心。接受 Núria 的更改，本身也只是相册里的另一个快照（第 3 章）；这意味着如果新的咖啡馆后来也被证明不对，回去只是一个平静的步骤（第 4 章）。批准一个更改，不是一扇在你身后上锁的门。它是一步你可以沿路退回的脚步。正是这种认知让你能**不带恐惧地**批准：你不是在拿整本书押注自己一定正确。

**这段历史已经分享出去了吗？** 对于把一个拟议更改接受进指南的主线，诚实的答案是：你是在向共享历史中**添加**，而不是重写它；这是安全的方向。这个问题危险的版本，也就是重写别人已经拥有的历史，属于第 15 章，而 Maya 离那还很远。接受一个结构良好的提议，只是在相册里延伸出又一个好的快照。它不会扰动此前的任何东西。

三个问题都回答了，决定也安静地清晰起来。但还有一件小事留下来了，也正是它把真正的审阅和盖橡皮章区分开来。
