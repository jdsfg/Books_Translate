#### 常见误解

**“冲突意味着我弄坏了什么。”**

这是几乎每个人第一次看到一次合并停下来并宣布有冲突时都会感到的恐惧。这个词本身听起来就像警报。屏幕可能会在你的文字周围显示陌生的脚手架标记。你的本能，被一生中电脑因为小错误惩罚你的经历训练出来的本能，会让你以为自己做错了什么，而且现在工作处在一种脆弱、受损的状态里，你一碰就可能让它更糟。

这些都不是真的，而且值得强调。冲突不是破损。它不是你造成的错误。它不是工具在抱怨。**冲突是工具捕捉到了一个只有人才能做的决定，并暂停下来，让你来做。** 你的两个工作版本都完全安全，而这正是暂停的全部意义。没有东西丢失，没有东西在你背后被选中，也没有东西处在危险中。工具只是走到了一个它不允许独自穿过的岔路口，于是停下来，让你指出方向。

想一想另一种情况会是什么样。想象一个工具面对同一行的两种重写时，悄悄保留一个、删除另一个，好给你一个没有麻烦的“干净”合并。那个工具会显得更友好。它也会在某一天，悄悄抹掉你开头那一行里更好的版本，而你永远不会知道这件事发生过。冲突正是在保护你免受这种情况伤害。暂停是一份礼物。那个更友好的工具才是危险的。

所以当冲突出现时，正确的感受不是恐慌。它应该是一声平静的小小的**啊——我们两个人碰到了同一个地方；该选择了。** 你不是在修复损坏。你是在投出一票，而工具足够谨慎，知道这一票它不能替你投。
