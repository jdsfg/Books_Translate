Maya 在那个下雨的星期六，把一整天都花在了三个段落上。

那是她和 Theo 一起写的那本指南的开头。那是一本关于他们移居城市的小小自出版作品。经过几周的反复起头又推倒之后，她终于找到了它该有的声音。不是宣传册的声音。是朋友的声音。是那种你在火车上读到，会心想，**我想去这个人去过的地方**的段落。她把它大声读了两遍，改了一个词，然后感到那种少有的、安静的咔嗒一声：某件东西终于对了。

然后她打开 Theo 那天早上发给她的版本，想从里面复制一条照片说明，结果把它保存覆盖到了桌面上的文件。文件名一样。`rainy-day-lisbon.docx`。那个小对话框问她是否确定。她当时想着那张照片。她点了是。

那三个段落不见了。不在废纸篓里，不在备份里，哪里都没有。Theo 早上的版本里没有它们，因为她是在他发送之后才写的。它们存在了六个小时，现在它们哪里都不存在了，再怎么点击也带不回来。她一动不动地坐了一会儿，就像人在身体已经明白损失、而头脑还不愿同意时会有的那样。

如果你曾经在电脑上做过任何东西，你就知道这种感觉。你也知道它会制造出哪个文件夹。

### 1.1 我们都有的那个文件夹

看看你存放重要工作的地方，你大概会找到它：那个装满近乎相同文件的文件夹，每一个文件都是一座小小的恐惧纪念碑。


    essay.docx
    essay_v2.docx
    essay_v2_edited.docx
    essay_FINAL.docx
    essay_FINAL_v2.docx
    essay_FINAL_v2_REALLY_final.docx
    essay_FINAL_use_this_one.docx


没有人教我们这么做。我们所有人都是各自发明出来的，因为我们学到的是 Maya 刚刚重新学到的同一个教训：电脑会兴高采烈地让你用一次点击毁掉自己的工作，而且不会第二次确认。所以我们囤积。每次大改之前，我们都做一个副本，因为副本是我们知道的唯一安全感。然后我们淹没在副本里，六个月后已经记不得哪个 `FINAL` 才是真的最终版，又不敢删掉任何一个，生怕里面有我们需要的东西。

这不是个人失败。这是缺少工具。在计算的大部分历史里，能解决这个问题的工具一直存在，但它住在一堵由晦涩命令筑成的墙后面，而入场代价是你要成为那种面对这些命令也能自在的人。大多数人很理智地拒绝了。他们继续制作副本。

变化发生在这里，也正是这本书为什么现在才存在、而且十年前还不可能如此有用的原因：**那堵墙倒下了。**不是因为工具变简单了，而是因为你不再必须亲自操作它。你有，或者可以有，一个同时会说两种语言的助手：一种是晦涩的语言，另一种是你的语言。你用白话说出你想要什么。它处理那些咒语。

这意味着，过去昂贵的东西现在变便宜了；过去只留给程序员的一整套工作方式，突然对任何创造东西的人都可用了。这就是本书的主题。
