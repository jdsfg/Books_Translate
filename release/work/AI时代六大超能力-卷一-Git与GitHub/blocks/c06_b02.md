### 5.2 一个可以大胆尝试的独立地方

Theo 现在真正能做的事，也是你可以对任何用这种方式保存的项目做的事，是这样的。

他可以在一瞬间打开一条**独立的工作线**，一个地方，让他可以把整本指南拆开，按街区重新搭建，自由地、破坏性地、完全不用谨慎；与此同时，那个已经能用的版本会完整地不受触碰，保持原样，Maya 也可以同时继续打磨它。如果他的重组结果非常出色，他们就把它带回主指南。如果结果一团糟，他就放弃它，而主指南甚至不知道这件事发生过。没有什么需要对齐。没有什么需要清理。他只是走回那个能用的版本，实验就蒸发了。

这条独立的工作线叫作**分支**。Theo 对智能体的白话请求不过是：**开一个独立分支，这样我就能尝试一个有风险的重组，而不碰那个能用的版本。** 剩下的事由智能体完成。

在我们精确定义它之前，先感受一下这让什么成为可能。Theo 一直不敢做重组，是因为实验和安全版本无法共存：尝试大胆的东西，就意味着拿好东西冒险。分支恰好化解了这一点。大胆的东西和安全的东西现在并排存在，同时存在，并且都是真实的。他可以知道自己到底是不是对的，而不必拿整本书下注。

#### 定义：分支

> **分支**是你的项目的一个**平行宇宙**：一条独立的工作线，你可以在其中自由更改，而你来自的那个版本会保持原样。把它想成一个**书签**，标记了一条开发线，于是你可以在它旁边开始另一条线，而不打扰第一条线。你在分支上做大胆、不确定的工作；如果成功，就把它带回来；如果失败，就转身离开，原来的版本不受触碰，因为它从来没有被碰过。

每个这样的项目至少已经有一个分支：主工作线，也就是大家的编辑一直落到的那条线。惯例称它为 **main**（有些项目把这条主线叫作别的名字，比如 **master** —— 名字不重要；只是有一条主线）。当 Theo 打开他的实验时，他不是离开 main，也不是让它陷入危险；他是在它旁边打开一个**第二个**宇宙。他可以在它们之间自由跳转：在街区重组上工作一小时，跳回 main 修一个 Maya 发现的错字，再跳回他的实验。两条线互不干扰。这正是它们分开的全部意义。

注意这对三个起飞前检查问题做了什么。**到底会改变什么？** 只有实验分支；main 从结构上就是安全的。**我们能回去吗？** 你从来没有离开；main 就在那里。**这段历史已经被分享了吗？** 还没有，所以 Theo 可以随心所欲地大胆。分支给这三个问题的答案，是它们能得到的最令人安心的答案。

### 5.3 几乎每个人一开始都会犯的错误

现在我们必须小心，因为几乎每个人第一次接触分支时，都会形成一幅错误图像，而它会悄悄毒害后面的一切。如果你把这一点想对，分支在你余生都会显得轻巧而明显。如果你想错，它们就会显得沉重而危险，而你会因为 Theo 当初回避重组的同一个原因去回避它们。
