在第 12 章，一个你从未见过的人拿走了你项目的完整副本，修改了它，又把修改送了回来。那是一个陌生人，而这件事成功了，什么也没有坏掉。先 fork，再提议。这个曾经让朋友修好一家关门咖啡馆的动作，现在让任何地方的任何人都能改进你做出来的东西。

本章要讲的是：当你不再把这件事看成偶然，而开始把它看成一个地方时，会发生什么。此时此刻，数以百万计的人正在公开地对彼此的工作做这件事，规模大到难以想象。Maya 和 Theo 将从另一端感受到它：一个他们永远不会见到的人，在一座他们从未去过的城市里，马上要让他们的指南稍微更准确一点。而为了让这件事安全发生，他们必须回答一个他们一直在默默回避的问题。确切地说，他们允许陌生人对他们的书做什么？


### 13.1 一个地方，不只是一个技巧

来自陌生人的提议，并不是偶尔发生的聪明技巧。它是人类曾经建造过的最大协作工作坊的奠基习惯。截至 2026 年，大约有 180 百万 甚至更多的人把自己的工作放在这里，横跨超过 630 百万 个项目。这不是一个放着一些代码的网站。这是一片公地。

**公地**这个词很古老，也值得保留。公地是一种共享之物，每个人都可以使用它，而且照料它的人越多，它就越富足：村里的草坪、公共图书馆、一组民歌。没有人拥有它的全部。人们从中取用，也向其中添加，而添加本身就是重点。世界的工作坊是一片由项目组成的公地：照片编辑工具、字体、食谱格式、一首古诗的译本、一座多雨城市的指南。它的大部分都是开放的。你可以走进去，阅读它是如何建成的；如果你有东西可以添加，也可以添加进去。

这里有一个会悄悄改变你生活的部分，远在你真正贡献任何东西之前。当你卡住时，解决办法很常常已经被某个陌生人找到，并公开留在他们的项目里，供任何人阅读。你可以去看。不是看一个关于那件事的论坛帖子，而是看那件事本身：真实运转的项目、它的历史、某个人在撞上与你完全相同的墙时做出的那一次精确修改。为了寻找答案而阅读陌生人的项目，本身就是一项技能；你现在已经可以使用它，因为你的智能体可以阅读一个项目的历史和差异，并用朴素的话告诉你，别人是怎样解决你眼前这个问题的。

你不必是程序员，这件事也同样重要。公地里有文档模板、电子表格格式、清单、译文、教学材料。Maya 想知道其他自出版指南是如何处理目录的，诚实的答案是：有几十本就是开放的，就在那里，每一次修订都看得见。她可以阅读一本正在运作的指南实际是怎样组装起来的，而不是阅读某个人口头说它应该怎样组装。
