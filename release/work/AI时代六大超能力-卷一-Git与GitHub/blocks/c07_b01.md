Theo 的重新排序成功了。

整个周末，他一直生活在那个平行版本里：在那个版本中，指南按街区组织，而不是按天气组织。与此同时，那个已经能用的版本安全地待在一边，毫发无损。这就是 第 5 章 给他的约定：大胆的事可以零成本尝试，因为原版会待在原地。所以他试了。他把 Alfama 的咖啡馆放到一起，把河边的博物馆收拢成一条步行路线，把下雨时可以钻进去的小地方放到它们真正所属的街区下面。然后，在周末的某个时刻，他不再担心这会不会成功，开始看见它确实成功了。读起来更好。读起来像一本有人会带在身上的书。

这给他留下了一个他开始时并没有真正想过的快乐问题。他现在有了两份指南。main 上那份，也就是 Maya 一直在打磨的、足够好的版本。还有他那份，重组后的版本，待在自己的平行宇宙里，而且更好。他不想要两份指南。他想要一份指南，里面有他的重组。

他想把这个宇宙带回来。


### 6.1 两个宇宙，一本书

想象一下 Theo 现在实际处在什么位置。回到 第 5 章，指南的历史还是一串单一的快照链，沿着时间向前延伸。当 Theo 开始实验时，这条链分叉了：主线继续跟着 Maya 的工作往前走，第二条线分出去，Theo 在那里做他的重新排序。两条线并排运行，在分开的那一刻之前共享一切，在那之后不再共享。

这种“并排”就是你需要的完整图像。**主线**是每个人都信任的版本，是你会因为把它弄坏而感到难堪的那个版本。Theo 的线是**实验**，一次大胆的重做，现在已经证明了自己。它们不是两个文件在争抢同一个名字。它们是同一本书的两段诚实历史：对过去意见一致，对现在意见不同。

Theo 面前的问题，也是整章要回答的问题：你怎样把两段已经漂开的历史重新变成一段，同时不丢掉任何一边做过的事？

旧答案，也就是工具出现之前的答案，很痛苦，而且你很可能经历过。你在两个窗口里打开两个版本，然后手工一段段检查。这一段，我在这边改过吗？改过。复制过去。这一节，Maya 在我离开时动过吗？也许。眯着眼比较。复制看起来更新的那个。祈祷。它很慢，容易出错，而且整个过程中你都会有一种恶心的感觉：只要一个走神，你就可能把错误版本复制到正确版本上，重新引发 第 1 章 的灾难。人们确实这样做。就在你读到这本书的这个年份，人们仍然在手工对书稿、法律合同和电子表格做这种事。

有一种更好的办法，而且它有一个名字。
