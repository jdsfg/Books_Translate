#### 概念检查

**Q1.** 一位同事告诉你：“我这个周末终于学会 Git 了，我注册了一个 GitHub 账号。”根据本章内容，你的同事实际上做了什么，又可能**还没有**做什么？

提示

把工具和工作坊分开看。哪一个是一种需要练习的技能，哪一个是一个你注册进入的地方？

**答案：**注册 GitHub 账号，就像是在工作坊里租下一个工作台：它给你一个放项目的地方，也给这些项目一个公开露面的身份。它并不等同于学习 Git；Git 才是底层技能，包括制作快照、创建分支、编织合并，以及阅读历史。你的同事可能两件事都做了，但单有账号并不能证明这一点；你可以在两分钟内开一个 GitHub 账号，却仍然不知道一个 commit 或一个分支是**用来做什么的**。暴露问题的说法是把“学会 Git”等同于“注册了 GitHub 账号”。Git 是工具，也是技能；GitHub 是你可以把它带去的一个工作坊。完全可能有人非常熟悉 Git，却从未注册过 GitHub 账号；也完全可能有人注册了账号，却根本不懂 Git。温和地说：他们租下了工作台。至于他们是否学会了手艺，是另一个问题。
