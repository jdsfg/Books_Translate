#### 深入思考

**Q1.** 本书声称，有价值的技能不再是知道命令，而是知道该要求什么、该检查什么。这是不是太方便了？反对它的最强理由是什么？你认为这个说法真正成立的边界在哪里？

**讨论：** 请认真对待这个反对意见，因为一张隐藏沼泽的地图会让人迷路。最强的反对理由是：如果判断力完全没有建立在对工具运作方式的理解上，它可能会**自信地错误**：如果你完全不知道“分支”或“共享历史”是什么，就无法看出你的智能体即将做一件危险的事，而“直接批准助手建议的一切”正是人们删除那些无法恢复之物的方式。这个反对意见是正确的，也正因为如此，本书并不是“让智能体处理就好”。这就是为什么每一章都会把**概念**讲到足以让你判断（什么是快照、历史被共享意味着什么、合并冲突实际是什么），这样当你审查时，你是在理解之中审查，而不是一路点头。本书的主张恰好成立在它所行走的那条线上：你不需要**命令**，但你非常需要**地图**。地图让你能在正确的时刻说不。失去命令不会让你损失什么；失去地图会让你损失自己的工作。第 15 章完整讲的就是这种区别救下你的那些时刻。

**（你会注意到，本章没有“这样对你的 AI 说”的清单。这是有意为之：你还没有遇见一个工具，所以现在没有什么诚实的请求可以提出。从下一章开始，每章都会以一小组你现在可以对智能体说的白话结尾，而且它们会不断累积：到最后一章时，它们会形成一页你可以贴在书桌上方的清单。）**


### 本章小结
我们从灾难内部开始，因为你经历过它：被覆盖的草稿，装满 `FINAL_v2_REALLY_final` 副本的文件夹，那个你从未尝试过的大胆版本，因为它可能毁掉能用的版本。在这一切下面，是一种单一的恐惧：害怕触碰那些已经能用的东西；而我们之所以都带着这种恐惧，是因为在计算的大部分历史中，那个能溶解这种恐惧的工具，被锁在一种只有专家才会学习的语言后面。

坏掉的是那把锁。不是工具的难度，而是**你**必须亲自操作它这个要求。有了 AI智能体作为你的双手，晦涩词汇就成了智能体的工作，而你的工作变成了一直以来真正的工作：决定要做什么，并判断一个更改是否正确。本书是关于这个工具让什么成为可能的地图，写给那个负责做决定的人。它的承诺是：如果你留下地图，忘掉每一条命令，你没有失去任何真正重要的东西。

接下来，在第 2 章，我们迈出离开副本囤积世界的第一步，也是最重要的一步：不再保存另一个紧张兮兮的重复文件，而是学会拍下一个**快照**（一张整个项目的照片，并附上一条说明解释为什么），并第一次开始无惧地工作。
