#### 应用题

**Q1.（预测工具。）** 假设一个分支真的就是项目里每个文件的完整副本——也就是本章提醒你不要相信的误解。预测一下后果：什么会变慢或变贵？这会怎样改变人们使用分支的方式？然后反过来用你的预测说明，分支实际上必然是什么。

提示

想象一下，给一个有几千张照片的项目创建分支，或者给一个十年档案创建分支。如果每个分支都会复制全部内容，那么打开一个分支在时间和空间上会花费什么？现在再回想本章里人们怎样描述创建分支：一天几十次、瞬间完成、为了很小的实验。两件事可能同时为真吗？

**答案：** 如果分支是完整副本，那么每次给大型项目创建分支都会真的花时间，也真的占存储；一个有几千张照片的项目创建分支会很慢，而且每多一个分支，体积都会膨胀。创建分支会变成一个沉重决定；人们会节省分支，犹豫着才打开它们，然后又回到不敢做大胆实验的状态，因为实验本身就有成本。但这和分支实际的表现正好相反：人们会不断、瞬间地打开分支，为了一个五分钟后就会丢掉的小实验也会这么做，而且项目规模远大于 Theo 的指南。这两幅图不可能同时正确。某个这么快、这么便宜的东西，**不是**在复制你的整个项目。所以分支一定比副本轻得多：它是一个标记，指向你历史中的一个快照，瞬间放下，共享所有未改变的材料，而不是复制它们。你刚刚只凭成本重新推导出了正确模型。这正是本书希望你能做到的动作：当一个心智图像预测出了你从未真正见过的行为时，那个图像就是错的，而真实行为会告诉你这个东西必然是什么。

**Q2.（“对你的 AI 这样说”排练。）** Theo 想尝试按街区重组指南。写出他应该给智能体的通俗请求。然后说说他**不**应该包含什么，以及为什么。

提示

本书里的每个安全请求都有两半：你想尝试什么，以及你绝不能失去什么。请求里不应该有任何命令或工具语法。

**答案：** 一个好的请求可以是这样：**“开一个单独的分支，让我可以试着按街区重组这份指南，同时不要碰已经能用的版本。”** 它包含了每个安全请求都有的两半：要尝试什么（重组），以及要保护什么（正在工作的版本）。Theo **不**应该包含任何命令、分支命名语法，或关于工具怎样完成这件事的指示。那是智能体负责的一半工作。他说清意图和安全边界；智能体提供机制。如果你发现自己想去够那些你并不掌握的工具词汇，那正是该注意并放手的直觉；你从来不需要它。整个技能就是把这两半说清楚。
