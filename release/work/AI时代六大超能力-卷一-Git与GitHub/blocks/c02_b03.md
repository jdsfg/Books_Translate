#### 试金石

下面是本书的承诺，我会尽可能尖锐地说出来，这样你就可以用它来要求我：

> 一个读者读完本书后忘记了每一条命令，但能说清什么是快照、分支是用来做什么的、发布一个更改之前该检查什么，那么他已经得到了本书的全部价值。一个读者背下了二十条命令，却说不清分支是**用来做什么的**，那么他什么也没有得到。

如果在任何时候，某一章开始让你觉得它像是可以从工具自己的手册里读到的东西，一串要输入的命令列表，那就是我失败了，你大可以略读它。地图才是重点。手册是给智能体用的。


### 1.4 什么会变得可能

让我给你看看我们将要前往之处的轮廓，好让前面的章节有一个落点。

想象一下，每当你完成一段有意义的工作时，你都给整个项目拍一张照片——不是杂乱文件夹里的一个副本，而是一个干净的、有日期的快照，并附上一条说明，写下你刚做了什么以及为什么。想象你可以把这些照片排成一列，沿着它们往回走，到达任何一个时刻，并准确看到在你做出那个令人后悔的更改之前一天，作品是什么样子。想象回去不花任何代价，也不会丢失任何东西。

现在再想象，当你想尝试那个大胆重组时，你可以从整个项目分出一个**平行版本**，在里面自由玩耍；如果它成功了，就把你的更改编回主版本；如果没有成功，就直接离开它，原来的版本毫发无损。不是一个需要你手动调和的副本。而是一个真正的平行宇宙，打开不花代价，关闭也不花代价。

现在想象 Theo 坐在房间另一边自己的笔记本电脑前，可以同时在同一个项目里工作；当你的编辑和他的编辑碰到同一句话时，工具不会悄悄选一个赢家并毁掉另一个。它会停下来，向你展示两个版本，让人来选择。

现在再想象，一个热爱这座城市的朋友可以读你的指南，发现你推荐的一家咖啡馆已经关门，然后**向你提出这项修正**——不是一封你还得找到并重新输入的邮件，而是一项具体的、可审查的更改，你可以查看、讨论，并点头接受。想象世界各地的陌生人用这种方式彼此改进作品，数以百万计，公开进行。

这些事情每一件都是真实的、普通的，并且每天都被并不比你更聪明的人使用。那些照片叫做快照。那些平行宇宙叫做分支。陌生人彼此改进作品的地方，是人类有史以来建造的最大此类工作坊。到本书结束时，你会知道它们每一个都是**用来做什么的**，而且你能够用白话向你的智能体要求这一切。

顺便说一句，Maya 后来找回了那三个段落，不是在那个星期六，而是在几周之后，当她和 Theo 开始用本书描述的方式工作以后。当她删掉一段拿不准的文字时，它并没有消失。它在她身后安静地退后一步，等在那里，以防她想要它。此后她开始更勇敢地删改。书变得更好了。这就是这一切的用途。
