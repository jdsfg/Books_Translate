#### 定义：回到过去（探访 vs. 还原）

**回到过去**包含两个不同的动作。即使命令本身是智能体要操心的事，你也值得在脑中把它们的名字分清楚。

* **探访**，是去看项目在某个更早快照时的样子：阅读它，从里面复制一段文字出来，重新记起它；同时，你当前的工作保持原样。你今天拥有的一切都不会被触碰。你是在阅读一张旧照片，而不是搬进去住。
* **还原**，是决定让某个更早的状态重新成为**当前**状态，也就是让今天的版本读起来像上周二那样。这会改变“现在”所包含的内容。

Maya 的愿望几乎完全是第一种，只是披着第二种的外衣。她以为自己需要把整篇引言还原到上周二。她真正需要的是**探访**上周二，取出一段文字，再把它带回今天。今天其余的工作，也就是她这一周来很满意的编辑，她都想保留。清楚地区分之后，她那个吓人的“回到过去”就变成了一件小而安全的事：“回去看看，把一件东西带回来。”

这就是本章的实践核心。大多数时候，“我们能回去吗？”并不是一个关于时间旅行的问题。它问的是：你能不能伸手进入过去，取回某个东西，同时不放弃现在？在这个工具里，答案几乎总是可以。

### 4.2 Maya 实际做了什么

下面是整件事的全过程，用白话说出来，因为它会成为你以后每一次“我想把那个拿回来”的模型。

Maya 像对一个能干的助手说话那样，告诉她的智能体自己想要什么：**带我回去看看上周二引言是什么样子，但不要丢掉今天的工作。** 注意这句话的形状。它有本书里每个安全请求都有的两个部分：她想触达什么，以及她绝不能失去什么。她没有说“还原这个文件”。她说的是“让我看看旧版本，并且保留新的版本”。

智能体完成了机械部分。它在相册里找到了上周二的快照，打开了当时引言的样子，并把它展示给她：那段银色光线的文字也在里面，正像她当初写下的那样，安安静静地坐在那里，没有被一周的删除碰坏。她读了它。她仍然喜欢它。她请智能体把这一段带回今天的引言里，智能体照做了。

现在，重要的地方来了。之后她再看相册时，上周二的快照**仍然在那里**，没有改变。今天的工作也**仍然在那里**，除了她选择恢复的那一段之外，没有改变。而相册最前面多了一张新照片，最新的一张，记录着“把银色光线旁白恢复到引言中”。没有任何东西被抹掉。她伸手进入过去，拿出了想要的东西；这个动作没有在链条中间留下一个洞，而是在链条最前方留下了一个新的标记。

她坐在那里想了一秒，就像第 1 章那个下雨的周六她曾经静静坐着一样，但这一次的感受完全相反。那个周六，三段文字存在了六个小时，然后哪里都不存在了。现在，一段她一周前亲手删掉的文字，因为一句话就回来了，而且没有为此付出任何代价。整片“从未尝试过的大胆版本”的墓地，忽然看起来不像自然法则，而更像一种她可以放下的习惯。
