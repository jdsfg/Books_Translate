### 章节总结

**Rainy-Day Lisbon** 发布了，而开启本书的那场灾难变得不可能：不是被避免，而是不可能，因为 Maya 和 Theo 现在的工作方式中没有任何东西能重现一次沉默、不可恢复的覆盖。整条弧线从一次丢失走向一个快照，走向相册，走向无惧地回到过去；然后走向分支、合并和由人决定的冲突；再走向第 2 个地方、世界的工作坊、朋友的 issue 和被审阅的改动；再走向 fork、陌生人的贡献和许可证；再走向同样动作在论文和面包店账本上的应用；最后走向被 3 个问题抓住的险些出事。每一步都是一个白话请求和一个判断时刻，没有一步要求你变成程序员。

账本就是交付物：14 个白话愿望，按用途分组，不含任何命令语法，因为你学会的是请求什么，而不是如何操作工具；请求什么才是持久的东西，工具会漂移。账本之下，是这个习惯：到底会改变什么，我们能回去吗，这段历史已经被共享了吗。勇气账本则收集了整段攀登：每一种恐惧退场，每一种新的胆量获得——大胆删改，自由实验，无碰撞协作，为世界的工作做贡献，并留下一条你的继任者能跟上的可读轨迹。你没有学会 Git。你获得了一张地图和一种请求方式，而它们比底下将来运行的每一种工具都更持久。

还有下一卷。你一直访问的工作坊运行在开放网络上；同一种让你 fork 陌生人指南的本能，也能让你在自己的机器上私下运行有能力的 AI，什么都不发送到任何地方。第 II 卷会诚实而不匆忙地介绍开源语言模型，以及如何自己运行一个。那是另一种超能力，可以等一等。现在，合上这本书，打开你自己最重要的项目，请求第 1 个快照。那些你因为太理智而不敢尝试的大胆版本，它们的墓园已经关闭。去做那个更好的东西。
