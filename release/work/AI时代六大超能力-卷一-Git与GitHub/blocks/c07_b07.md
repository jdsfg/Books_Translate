### 章节总结

Theo 大胆的重组奏效了，本章讲的是把它带回家：把那个已经在自己的平行宇宙里证明可行的实验，编织回所有人都信任的主版本，让书重新成为一本，而不是两本。

**合并**就是这种编织。它不是一个版本覆盖另一个版本，这是最常见的错误图像。它是**组合**：两条线上都没有改变的材料会保留下来；实验带来的改动会进入；主线上的改动也会保留；每个人的工作都会幸存下来。当两条线改动的是不同的东西时，编织就是自动的，这就是“**它干净地合并了**”的意思：不同的编辑，不同的位置，不需要猜测。这也是常态，正因为协作通常会把工作分到不同的领地里。

本章反复训练的判断，是合并前的第一个预检问题：**到底会改变什么？** 在合并时提出这个问题：在你批准一次编织之前，你会请你的智能体展示它会带入什么（什么会移动，什么是新的，是否有什么会被移除），并且只有在你看过之后才点头。一次合并会一次性带来大量变化，而这也正是意外编辑最容易藏身的时候，所以查看不是可选项。

还有一种情况，自动编织处理不了：当两条线编辑了完全相同的东西，并且意见不一致时。这时工具会拒绝猜测，展示两个版本，并请人来选择。这种拒绝，是工具最值得信任的时刻；第 7 章也正是从这里开始——当两只手编辑同一行，编织需要一个人来决定。


#### 对你的 AI 这样说

到现在，你已经可以请求快照、阅读历史、安全回到过去，并打开一个分支来尝试大胆的事情。本章增加的是把它带回家的动作：

* **“重新排序成功了——把它编织回主版本，并告诉我是否有任何地方相撞。”**
* 以及在你批准之前说出的预检习惯：**“在你合并之前，先给我看清楚这会把什么带进主版本——什么会移动，什么是新的，以及是否有任何东西会被移除。”**

本章消除的恐惧是：**“如果我离开主线去做实验，我会被困在两个版本之间，不得不手工调和它们，而且我会弄错。”** 现在你知道，你不会。实验和主线会重新编织在一起；当你的改动和其他人的改动落在不同地方时，它会自动完成；当它们没有落在不同地方时，它会交给一个诚实的人类决定。你可以开启大胆的分支，并且知道有一条干净、平静的路可以回来。你现在敢做的事：完成一个实验，并把它合并回家，而不用屏住呼吸。
