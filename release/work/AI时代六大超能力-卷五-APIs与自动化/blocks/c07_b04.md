#### 常见误解

_“密钥基本上就是密码，而我对密码很小心，所以没问题。”_

这种小心是对的；但这个心智模型小了一号。密码是 _你_ 偶尔输入的东西，用来证明你人在键盘前。密钥是 _机器_ 代表你不断携带的东西，常常在你没有看着的时候，用来证明你即使睡着了也“在场”。这种差别改变了风险。密钥会待在文件、设置和运行中的自动化里，待在比密码多得多的地方，而且会被全天候替你行动的东西更频繁地使用。所以照看它必须是结构性的，而不只是个人性的：不是“我会记得小心”，而是“这把密钥的 scopes 很窄，它住在我被跟踪的文件之外，它从未在公开处被粘贴过，而我清楚知道如何在十秒钟内撤销它。”把密钥当成它真正所是的东西：借给机器的你的身份，于是合适的小心水平就会变得显而易见。


### 6.5 凌晨 3 点的问题

这里有一种思考习惯，会在本书剩下的部分反复出现；之所以在这里介绍，是因为这一章是利害第一次变得真实的地方。在你让任何自动化带着密钥行动之前，先问自己一个问题：

_如果这条管道在凌晨 3 点误触发，而我正在睡觉、没有看着，最坏会发生什么？_

这个时刻本身就是重点。自动化并不只在你看着、心情不错、随时准备按下停止的时候运行。它会自己运行，在黑暗里运行；如果它要出错，很可能就是在那时出错。所以你要诚实地想象那个时刻。如果答案是“最坏也只是多读取一次我的订单”，你可以放松；那是一条读取管道，爆炸半径有边界，也无害。如果答案是“最坏会给我所有客户发送邮件，或者无限制地花钱，或者删除我的库存”，那么你就已经以低廉的代价、提前发现了你究竟需要在哪些地方使用 scopes、测试密钥、消费限额，以及放一只人的手在扳机上。

凌晨 3 点的问题不是恐惧。它是恐惧的反面；它是一种具体、可回答的行动，用来把飘在空中的焦虑 _替换_ 成一张具体的、需要加边界的事项清单。在 Mara 让她的助手发送一封真实邮件或碰真钱之前，我们还会更完整地再问一次。现在先把它种下：你交出去的每一把密钥，都要在已经回答过凌晨 3 点问题之后再交出去。
