### 本章小结

一个服务是一座有两扇门的建筑。前门是网站，为人而造，耐心且有装饰。侧门是**柜台窗口**，即 **API**，为机器而造：你走近，以约定格式把请求从窗口递进去，答案也以约定格式递回来，中间没有人。把它想象成一叠预先印好的表格，有的用于*读取*，有的用于*更改*，每张都有服务在行动前必须填好的特定空白。你永远不会亲手填这些表，但能想象它们，才能向助手要合理的东西，并核对回来的结果。

柜台窗口一直都在；新的是它现在对*你*开放了——因为你的助手会说它的语言，于是你的工作从敲语法上移到决定问什么、并核对答案。那是本系列反复回到的尊严上移。我们直接建立在第1章「读取与发送」的区分上（这里变成了读取表与更改表），以及你是柜台窗口之间的信使这一想法。接下来，第3章我们学习阅读透过玻璃回来的答案——那种叫 JSON 的友善贴签盒格式——因为读不懂的答案，就是不可信的自动化。
